# Kanoulas et al. — CLEF 2019 Technology Assisted Reviews in Empirical Medicine Overview

本文介绍医学系统综述的高召回文献检索与标题/摘要筛查评测。2019 年有两个任务，但仅第二个任务收到提交；原始检索式、候选集、两级相关性标签及停止阈值各有明确语义，不能合并成一般文档问答。关键结果：DTA/摘要标签下 ILPS abs-hh-ratio 的 MAP 0.493、阈值召回 0.815（Table 9）。已阅读正文，并核对数据统计和 DTA 结果表；未逐项审计全部附录运行及曲线。
