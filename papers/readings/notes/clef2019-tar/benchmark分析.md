# 评测与边界

**提交与方法**：3 队共提交 Task 2 的 36 runs；Task 1 没有提交，不能给它虚构实测结论。方法包括 BM25、交互式 BM25、持续主动学习、相关性反馈和不同停止条件。

**指标**：AP、前 5/10/20/30% 候选的召回率、WSS@95/100、阈值召回，以及结合漏检/努力的 Reliability。

**实验 1（Table 9，DTA/摘要标签）**：

| Run | MAP | 阈值召回 |
|---|---|---|
| ILPS abs-hh-ratio | 0.493 | 0.815 |
| Padua baseline_bm25_t500 | 0.119 | 0.638 |

这不是控制所有其他因素后的单一算法消融；原文承认多参数同时变化难以归因。

**边界**：

- 为支持迭代算法直接提供测试 qrels，不能称为完全盲测。
- 未判断文献被假定无关，原布尔查询之外的相关研究被排除；所以评测召回不等于对全部医学证据的真实召回。
- §6 指出缺乏全文可得性、真实双人筛查成本和标注分歧建模。

依据：[CLEF 2019，CEUR Vol.2380 paper_250，31 页](https://ceur-ws.org/Vol-2380/paper_250.pdf)，§4–6、Table 9，PDF pp.9–11、16。
