# 贡献与评价

**原文贡献**（§1，PDF p.3）：MADON 数据集；在 200 多份试点判决上反复修订的标注指南；300,511 份捷克判决的继续预训练语料；对 Llama 3.1 8B、ModernBERT、MLP 在三项任务上的比较，以及"过滤→论证分类→MLP"三阶段流水线；对捷克两家最高法院的首次实证分析。

**标注可靠性**：4 名法学学生由法学博士生带领，每份判决至少两人独立标注，分歧由资深仲裁人裁定；整体标签 Cohen's κ=0.65。论证类型的 Krippendorff αu 差异很大（Table 1，PDF p.10）：

| 论证类型 | Part I | Part II |
|---|---|---|
| CL 判例 | 0.95 | 0.94 |
| D 学说 | 0.94 | 0.90 |
| HI 历史解释 | 0.68 | 0.80 |
| PL 法律原则/价值 | 0.76 | 0.65 |
| TI 目的解释 | 0.63 | 0.65 |
| LIN 文义解释 | 0.54 | 0.28 |
| SI 体系解释 | 0.35 | 0.42 |
| PC 实际后果 | 0.20 | 0.21 |

作者保留低一致性类别，并公布全部原始标注（§3.4.1，PDF pp.9–11）。

**阅读者分析（评价）**：

- 主要新意在于把一个有争议的法学概念拆成可标注的论证类型 + 整体判断，并用结果回应法学争论；模型本身是常规的继续预训练、全量微调与非对称损失。
- "黄金论证特征 + MLP" 达到 Bal-F1 91.7%，说明论证分布与整体标签高度相关；但整体标签由同一批标注者在看过论证后给出，这一相关性部分可能来自标注过程本身。
- §4.1 列出分层抽样为 SC 民事 122、刑事 58、SAC 90，合计 270，而全文其他处为 272 份、SC 182 份，相差 2 份未解释。

依据：§1、§3.4、§4.1、§5.4.3，PDF pp.3、9–12、18–21。
