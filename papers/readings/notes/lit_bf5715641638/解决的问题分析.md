# 解决的问题

综述要回答的问题：如何按自主程度区分数据智能体、各级别目前有哪些系统、跨级别的瓶颈是什么（§I-D 贡献，p.3）。

六级分类（§II，pp.3–4）：

| 级别 | 人的角色 | 智能体能力 |
|---|---|---|
| L0 无自主 | 独自完成 | 不参与 |
| L1 辅助 | 主导，负责与环境交互、集成和验证输出 | 无状态“提示—响应”，生成答案或代码片段 |
| L2 部分自主 | 编排管线并保持主导 | 能感知并与环境（数据湖、代码解释器、API）交互，利用记忆、工具与反馈在人定义的流程中执行 |
| L3 有条件自主 | 监督者 | 自主编排定制管线，覆盖多样任务 |
| L4 高度自主 | 旁观者 | 无需监督，主动发现值得研究的问题 |
| L5 完全自主 | 不参与 | 发明新方法与新范式 |

形式化：L1 中人负责编排 π_H 与执行 ε_H；L2 中 A 执行 ε_A 由人编排的管线；L3 中 A 同时负责 π_A 与 ε_A；L4 中 A 还自主发现任务 T′；L5 中 A 发明新过程 Φ（§III–§VI）。

文献覆盖单位：按“任务（数据管理/准备/分析的九个子任务）× 自主级别”组织；Tables II–IV 比较代表性 L1、L2、Proto-L3 系统。

阅读者分析：级别划分依据是“谁编排管线、谁承担主导与责任”，而不是模型能力或任务难度；同一系统在不同任务下的定级标准在正文中未给出可操作的判定规则。

依据：[arXiv:2510.23587v2，20 页](https://arxiv.org/abs/2510.23587)，§I-D、§II、§III-A、§IV-A、§V-A、§VI，PDF pp.3–16。
