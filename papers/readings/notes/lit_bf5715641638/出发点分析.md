# 出发点

原文立场（§I-A、§I-B，pp.2–3）：数据智能体被定义为由 LLM 驱动、编排 Data+AI 生态以自主完成数据相关任务的架构，形式为 A:(T,D,E,M)→O。与通用 LLM 智能体相比（Table I），它面对的是规模大、异构、含噪的数据湖，需主动探索（采样、探查模式、改进查询），调用专门工具（SQL 等价检查器、DBMS 工具、可视化库），且错误会向下游级联。

问题：“data agent”一词同时指代“提示—响应”式的原子任务助手和自主编排管线的复杂系统，作者列出三类风险：
- **用户侧**：预期错配，要么拒绝正确输出，要么过度依赖错误输出；
- **治理侧**：越能力边界使用造成数据泄露、误导分析等后果时责任不清；
- **产业侧**：缺乏统一分类使系统难以客观比较，助长夸大宣传。

作者借鉴 SAE J3016 的经验：通过明确人机责任分配，为用户、厂商、监管者提供共同语言。

阅读者分析：标题中的“Overstated Hype?”对应的是术语与宣传层面的混乱，综述并没有用实证方法评估现有系统的实际能力。

依据：[arXiv:2510.23587v2，20 页](https://arxiv.org/abs/2510.23587)，§I-A–I-C、Table I，PDF pp.1–3。
