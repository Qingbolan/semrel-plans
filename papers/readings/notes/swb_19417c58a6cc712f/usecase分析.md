# 具体用例

**策展一条预测性证据**：策展者读到一篇关于某基因变异与靶向药物疗效的临床研究。按 SOP，他输入基因名（类型提示检索 Entrez）和最具体的变异名（例如来源报告单个位点时写 KRAS G12/G13，而不是笼统的 KRAS Exon 2 Mutation），选择来源类型 PubMed 并核对 PMID 自动生成的引文（pp.4–6）。

随后他依次填写（pp.6–8）：

- 变异来源（Somatic 等）和最具体的 Disease Ontology 疾病；
- 证据类型 Predictive、证据等级（如多于 5 名患者的临床试验为 B）、方向（Supports / Does not support）、临床意义（如 Sensitivity/Response）；
- NCIt 药物名；
- 1–3 句不照抄原文、含研究设计、样本量与统计量的 Evidence Statement；
- 1–5 星评级。

提交后由 Editor 审核接受。若同一变异在同一疾病下积累了多条已接受的证据，可再建 Assertion，按 AMP-ASCO-CAP 给出 Tier I–IV 和 Level A–D，并注明是否有 FDA 批准或伴随诊断（pp.8–10，Fig. 5a）。

原文还举出 Reduced Sensitivity 的限制：它只能用于同一治疗场景下不同变异的比较，而不能用于同一变异下不同药物疗效的比较（Conclusions p.11）。
