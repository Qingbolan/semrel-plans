# 出发点

临床指南（如 NCCN、AHA）通常以决策树表达，按指南执行是安全、一致的循证诊疗基础。作者认为已有医学 LLM 评测多考察事实记忆或一般推理，很少直接检验模型能否遵循正式的多步临床路径；已有的指南遵循研究范围有限（§1、§2，PDF pp.1–3）。

NCCN 指南以 PDF 形式放在登录门户后，不便被 LLM 直接摄取；因此作者需要先把决策树解析为结构化 JSON，再造题（§3.1，PDF p.4）。

阅读者分析：出发点是"规则遵循"而非"医学知识"，但最终题目仍是单步多选，实际上把多步路径压缩为"给出完整病史、选叶子节点"，对多步顺序推理的考察是间接的。

依据：§1–§3.1，PDF pp.1–4。
