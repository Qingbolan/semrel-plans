# 评测与边界

**设置**：25 个模型，温度 0；指标为准确率与按选项数加权的准确率（§4.1–4.2，PDF p.7）。

**实验 1（主结果，附录 Table 3，PDF p.21）**：

| 模型 | 准确率 | 加权准确率 |
|---|---|---|
| GPT-4.1 | 0.6439 | 0.6254 |
| O1 | 0.6239 | 0.6049 |
| O4-mini | 0.6075 | 0.5890 |
| DeepSeek-R1 | 0.6006 | 0.5812 |
| Llama-3.1-70B | 0.5654 | 0.5431 |
| Qwen3-32B | 0.5553 | 0.5366 |
| ClinicalCamel-70B | 0.4683 | 0.4360 |
| Meditron-70B | 0.2530 | 0.2295 |
| Meditron-7B | 0.1701 | 0.1458 |

医学模型全部偏低；Qwen3-14B/32B 并未明显优于 4B（§4.3，PDF p.7）。

**实验 2（相关性）**：与 MMLU-ProMed Spearman ρ=0.85，与 IFEval ρ=0.71；Pearson 分别为 0.81、0.75（§4.4，PDF p.8；Figure 8，PDF p.23）。

**实验 3（Method I 指南入上下文，Table 4，PDF p.24）**：17 个模型中多数提升，如 GPT-4.1 0.6439→0.7746，Meditron-70B 加权 0.2295→0.4628（+102%）；DeepSeek-V3 基本不变，Medalpaca-7B 略降。

**实验 4（Method II 继续预训练，8 epoch）**：只做了 6 个模型，多数仅小幅提升，Meditron-7B 接近翻倍；具体数值只以 Figure 6/11 给出（§5.2，PDF p.9；PDF p.27）。

**边界**：作者承认仅覆盖 NCCN 肿瘤指南（附录 B，PDF p.17）。阅读者分析：结论称"指南接入收益有限"，与 Method I 多数模型 20–40% 的相对提升不完全一致；Method I 是否使用金标准树还是分类器选出的树，正文未明确；未报告多次运行方差或显著性。

依据：§4–§5、附录 B、H、I，PDF pp.7–9、17、21–27。
