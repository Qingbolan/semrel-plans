# STARD: A Chinese Statute Retrieval Dataset Derived from Real-life Queries by Non-professionals

STARD 是中文法条检索数据集：1,543 个非专业人士的真实法律问题，对 55,348 条候选法条做检索。关键结果：在本数据上微调的 Dense-STARD R@100 为 0.9065（Table 3）；下游 RAG 并非所有配置都受益。
