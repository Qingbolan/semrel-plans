**内容基准**：随机填充不含 JOIN、省略 FROM 的 SQL 模板（可含聚合、GROUP BY、HAVING、ORDER BY），由 LLM 转为问题，再做改写（避免照抄列名/长单元格值）和回译 SQL 精确匹配一致性检查；包含 SQL 所引用列和值的其他表也标为答案（§6.1，pp.10–12）。

**上下文基准**：用 Meta-Llama-3-8B-Instruct 扮演数据创建者回答 Datasheets 的 51 个问题（约 4 分钟/表）；按 51 题×20 分层抽 1,020 份上下文生成问题，并由 LLM 标注其他可回答的表（§6.2，p.12）。

**规模**：总体评测共约 2k 题，内容与上下文各约 1k（§7.1，pp.13–15）。阅读者分析：正文未写清 1k 是每个数据集还是合计。BIRD 取 1,595 道能由单表完整回答的问题；BIRD（annotated）中 120 题（7.5%）有两张及以上正确表（§7.1.2，p.15）。
