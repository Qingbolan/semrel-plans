# 解决的问题

**任务**：长文本问答。输入一篇长文档 D 和一个问题 Q，输出答案；LLM 每次调用的输入窗口限制为 4k token（§3、§4.1，PDF pp.2–4）。

**图的定义**（§3.1–3.2，PDF pp.2–3）：
- 文档按段落边界切成不超过 L 的块（默认 2k token）；
- 每块由 LLM 总结为原子事实，再从原子事实中抽取关键元素（名词、动词、形容词等），归一化后成为节点；
- 节点 = 关键元素 + 相关原子事实集合；若一个节点的关键元素出现在另一个节点的原子事实中，则两点相连。

**探索过程**（§3.3，PDF pp.3–4）：智能体先写“理性计划”（rational plan）并选 N 个初始节点（默认 5）。对每个节点先读按块分组的原子事实，再用 `read_chunk` 读选中的原文块；读块时可调用 `search_more`、`read_previous_chunk`、`read_subsequent_chunk` 或 `termination`；读完后用 `read_neighbor_node` 转到相邻节点或终止。每条路径的函数调用上限为 10。

**答案生成**（§3.4，PDF p.4）：汇总 N 条路径的笔记，用思维链和多数投票处理冲突，生成最终答案。

**工作单元**：一个问题样本；图可以在同一文档的多个问题间复用（§4.4，PDF p.8）。

依据：§3–4，PDF pp.2–4、8。
