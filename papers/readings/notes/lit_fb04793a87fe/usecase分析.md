# 具体用例

**用例：SMS 垃圾短信检测**（Figure 1，p.2）。

用户指令：需要一个检测 SMS Spam Collection 数据集中垃圾短信的方案；要求模型轻量，可以是精简的 LSTM 或 GRU；准确率高于 95%；在移动设备上每条消息延迟低于 100 ms。

处理过程：
1. Agent Manager 先做请求验证；
2. Prompt Agent 把指令解析成 JSON，问题域为 NLP 文本分类，约束为准确率和延迟；
3. RAP 检索相关知识，生成 3 个计划；Data Agent 和 Model Agent 模拟执行，返回预期指标；
4. 选出最佳计划，由 Operation Agent 实现。

Figure 1 展示的输出为准确率 98.9%，推理延迟约 76 ms。

**评分方式**：在有约束设置下，成功率按 0 / 0.25（模型可运行）/ 0.5（可部署）/ 0.75（部分满足约束）/ 1.0（完全满足约束）分级（附录 B.4，p.21）。

Figure 1 是示意性展示，不在 14 个评测数据集中，没有对应的重复运行统计（阅读者分析）。

依据：[arXiv:2410.02958v2，48 页](https://arxiv.org/pdf/2410.02958v2)，§1、Figure 1，PDF p.2；附录 B.4，p.21。
