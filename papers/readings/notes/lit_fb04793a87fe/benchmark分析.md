# 评测与边界

**基线**（§4.1，p.7）：
- Human Models：取 Papers with Code 或 Kaggle notebook 中的最佳结果；
- AutoGluon；
- DS-Agent；
- GPT-3.5 和 GPT-4 零样本。

LLM 基线统一使用 gpt-4o-2024-05-13 作为骨干。

**指标**：SR（成功率分级）；NPS（准确率、F1 取原值，RMSLE 取 1/(1+s)；不可运行时记 0）；CS = 0.5×SR + 0.5×NPS（附录 B.4）。

**实验 1（14 个数据集的平均，Tables 6–8，pp.45–46）**：

| 方法 | SR 无约束/有约束 | NPS 无约束/有约束 | CS 无约束/有约束 |
|---|---|---|---|
| GPT-3.5 | 0.057 / 0.039 | 0.081 / 0.116 | 0.069 / 0.077 |
| GPT-4 | 0.314 / 0.221 | 0.217 / 0.241 | 0.266 / 0.231 |
| DS-Agent | 0.457 / 0.268 | 0.331 / 0.266 | 0.394 / 0.267 |
| AutoML-Agent | 1.000 / 0.871 | 0.804 / 0.810 | 0.902 / 0.841 |

无约束设置下，Human Models 的平均 NPS 为 0.754，AutoGluon 为 0.755（4 个数据集为 N/A）。在 Butterfly、Software、Citeseer 上，Human Models 的 NPS 高于 AutoML-Agent。

**实验 2（消融，Table 9，5 类任务）**：只用 RAP 时 CS 为 0.366，加入计划分解后为 0.763，再加入验证的完整版本为 0.971（时间序列预测任务只有完整版本能跑通）。

**实验 3（与 SELA 比较，Table 12）**：搜索时间约快 8 倍，6 个数据集的平均分为 0.612，SELA 为 0.599。

**实验 4（成本，Figure 7）**：单次运行平均约 525 秒、0.30 美元（GPT-4o）。

**边界**（附录 A.2、A.4，pp.13–14）：
- 依赖强骨干模型和骨架代码，GPT-4 与 GPT-3.5 之间差距明显；
- 尚未支持强化学习、推荐系统等需要不同流水线的任务；
- 小模型无法完成任务。

SR 的分级包括“可部署”这一项，这是 AutoML-Agent 的设计目标，而 GPT 基线只用零样本提示，对比条件并不对等（阅读者分析）。
