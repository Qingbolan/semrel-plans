# Musa et al. — C3PA: An Open Dataset of Expert-Annotated and Regulation-Aware Privacy Policies to Enable Scalable Regulatory Compliance Audits

本文发布 C3PA：由 6 名法学学生按加州消费者隐私法（CCPA）的 12 项披露要求，对 411 家机构（241 家注册数据经纪商、170 个热门网站）的隐私政策逐段标注，共 48,947 条标注。作者用文本片段 F1 衡量标注一致性（8 周内从 0.46 升到 0.70），并显示：在 C3PA 上微调的 DistilBERT 对"收集的个人信息类别"（L4）的识别优于在 OPP-115 上训练的模型（F1 75 vs 68）。已通读正文和附录。
