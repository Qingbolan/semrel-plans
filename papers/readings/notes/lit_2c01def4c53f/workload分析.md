# 工作负载

| 数据集 | 规模（论文所述） | 评测切分 | 指标 |
|---|---|---|---|
| Spider | 训练 7,000 对、开发 1,034 对；200 个数据库、138 个领域 | dev 与已开源的 test | EX（Table 4 另报 EM） |
| BIRD | 95 个大规模真实数据库，存储量达 33.4GB，37 个专业领域；问题附 evidence 外部知识 | dev 与隐藏测试集（提交官方评测） | EX、VES |

论文未给出 BIRD 的问题条数或 Spider test 的条数；BIRD dev 按 Simple / Moderate / Challenging 三档难度报告消融。

**指标定义**：EM 把每个子句视为集合与参考 SQL 比较，不考虑取值；EX 为预测与标准 SQL 执行结果相同的比例；VES 衡量有效 SQL（结果集与标准一致）的执行效率。

**输入表示**：schema 描述包括数据库 ID、表名、列名、列全名/说明，以及按列类型、唯一值与最大长度筛选的高频单元格取值；纯数值列以及 URL、邮件等非常规值被忽略。

**成本**：作者估计用 GPT-4 完整跑一次 Spider dev 与 BIRD dev 分别约消耗 600 万与 1,000 万 token，因此 few-shot 只试到 2-shot。

**训练数据**：SQL-Llama 的指令数据来自 BIRD 与 Spider 训练集，约 1 万条，覆盖三类智能体任务。
