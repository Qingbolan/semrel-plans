# 贡献与评价

**作者声明的贡献**（§1，p.2）：
1. 提出基于智能体的 OM 设计范式与 Agent-OM 框架：LLM 作中央控制器，两套 CoT 规划模块，借助 ICL/RAG 的 OM 工具，以及对话加混合数据库的共享记忆。
2. 实现了概念验证系统，处理了经济的实体信息检索、候选选择和基于检索的匹配。
3. 实验显示在简单任务上接近长期最优，在复杂和少样本任务上显著提升。作者称这是首个面向 OM 的 LLM 智能体框架（§2，p.3）。

**技术要点**：把 O(N_s×N_t) 的成对 LLM 判断改为"先检索入库，再向量检索 top-k，最后只对 k 个候选做 LLM 验证"。作者估算复杂度为 (k+1)(N_s+N_t)（§6.1.4，p.10）。另有双向合并、自检验证两个降低幻觉的组件（§6.1.5–6.1.6，pp.10–11）。

阅读者分析：
- 新意主要在系统组合，即 RAG、混合检索、RRF、自检和双向一致性。各部件均有出处（文中引用 RRF、SelfCheckGPT、RAG-Fusion），"智能体"的规划部分实际是固定流程，由 LangChain 工具调用或 chain 实现（§4，p.4）。
- 证据强度有限：主结果按单次运行报告（§5.2，p.8），与 OAEI 参赛系统的比较用的是作者复现的赛道和公开参考，Agent-OM 本身并未参加 OAEI 2022/2023（致谢，p.12）。正文多给排名，几乎不给数值。
- 结论段称 "Agent-OM is all you need"，并说 100% 准确、全自动 OM 似乎"触手可及"（§10，p.12）。这比实验所能支撑的结论强得多。

依据：§1–§2、§4、§6、§10，pp.1–12。
