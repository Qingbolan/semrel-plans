# Cardoso et al. — CSTNews: A Discourse-Annotated Corpus for Single and Multi-Document Summarization of News Texts in Brazilian Portuguese

本文介绍巴西葡萄牙语新闻语料 CSTNews 的话语标注：50 个新闻簇、140 篇文本，同时按单文档的修辞结构理论（RST）和跨文档结构理论（CST）标注，服务于单/多文档摘要研究。论文的“评测”是标注一致性：RST 关系一致性 F=0.66，CST 关系 kappa=0.50、关系类型 kappa=0.61。论文没有训练或评测任何自动摘要系统。已阅读全文（正文与参考文献）。
