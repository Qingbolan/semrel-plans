# 出发点

作者所在的 SUCINTO 项目研究通用与主题导向的多文档新闻摘要，要处理冗余、互补、矛盾信息，以及不同写作风格和事件演化等多文档现象。项目以语料为驱动，因此需要一个高质量参考语料。

RST 描述单篇文本内部命题之间的关系及核心/卫星（nucleus/satellite）区分，可用于判断哪些命题更重要；CST 描述同一话题不同文本片段之间的关系，可用于识别冗余等多文档现象。作者指出两者此前从未一起用于摘要，原因之一是缺少同时具有可靠 RST 与 CST 标注的资源：已有语料只标其一，CST 只有英文的 CSTBank。

阅读者分析：所以本文的核心价值是“同一批文本上叠加两层话语标注”，而不是新的摘要方法。

依据：[RST 2011 workshop，pp.88–105，18 页](https://sites.icmc.usp.br/taspardo/RST2011-CardosoEtAl1.pdf)，§1，PDF pp.1–3（印刷 pp.88–90）。
