# 解决的问题

两项任务相互关联：把法律、法规和解释性判例中的规则条件连接成 rule tree；把裁决中的句子或子句按推理角色标注。规则树节点附权威出处，句子类型区分证据内容、事实认定和支持认定的推理。医生提出的意见不能因为出现在裁决书里就被当成 BVA 的最终认定。此处是表示与标注问题，不是直接预测案件胜负的实验。

依据：[ICAIL 2017 作者预出版稿，LLTLab/VetClaims 仓库，10 页](https://raw.githubusercontent.com/LLTLab/VetClaims/master/WalkerEtAl-ConnectivesSentenceRoles-ICAIL2017-PrePubCopy.pdf)，§4.1、§5.1.7–5.1.9，PDF pp.3–4、8–9。
