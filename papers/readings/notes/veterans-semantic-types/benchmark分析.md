# 评测与边界

本文可复核的定量内容是 Table 3 样本频次，而非机器学习榜单。引用句约 18%、规则句约 13%、关键 PTSD 事实认定句约 4%；原文指出这些角色常共享术语，因此一致标注困难。没有报告分类模型的 P/R/F1、标注者一致性数值或独立测试集。§7 仍计划扩充 BVA 与上诉决定、改进协议并测试自动标注；因此不能用 2019 年分类论文的结果填入本论文，也不能从任意选取的 20 份文书推断整个裁判体系的频率。
