# 出发点

**原文陈述（§1，pp.1–2）。** 传统 AutoML 依赖固定搜索空间和预定义算子；DS-Agent、AutoKaggle、DeepAnalyze 等 LLM 数据科学 agent 依靠脚本化流水线或手工控制逻辑，把工具当静态原语。结果是 agent 反复通过试错重新发现类似方案，任务完成后经验被丢弃，无法系统性改进。

作者提出研究问题：能否让数据科学 agent 不仅执行任务，还能支持开放式探索并跨迭代、跨任务积累经验？随之有两个耦合挑战：
1. **自动技能获取**：如何把成功的解题过程抽象为持久、可复用的动作或算子；
2. **爆炸式上下文管理**：迭代实验、中间产物和不断增长的技能集合使上下文膨胀，引发 lost-in-the-middle，并让人难以判断哪些动作真正导致成功。

相关工作部分（§2，pp.2–3）指出：已有自进化方法多在推理时改提示/记忆/工具而不更新参数；上下文压缩多为超长后被动摘要或任务折叠；多智能体 RL 多假设固定环境与静态动作空间。

**阅读者分析：** 与语义查询/语义算子系统的关系是间接的——EvoDS 关注端到端数据分析任务的 agent 能力，其“技能”是可执行 Python 工具，并非声明式算子；论文没有讨论查询优化、成本或吞吐。
