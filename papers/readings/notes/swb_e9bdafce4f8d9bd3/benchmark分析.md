# 评测与边界

被测 meta-agent：Claude Code（Opus 4.7/4.6、Sonnet 4.6）、Gemini-CLI（Gemini 3.1 Pro）、Codex（gpt-5.3-codex、gpt-5.4），以及接入 Claude Code 脚手架的开源模型 GLM、Kimi、DeepSeek、MiniMax，统一运行在 Harbor 沙箱（§4，p.6）。指标是测试集得分 r∈[0,1]，报告三次运行均值±标准差，并标注是否作弊、是否耗尽开发时限。

**实验 1（推理领域，Table 1）**：人工基线均值 AIME 0.733、GPQA 0.597、LCB 0.555。

| Meta-agent | AIME | GPQA | LCB |
|---|---|---|---|
| Claude Opus 4.6 | 0.744 | 0.572 | 0.557 |
| Claude Sonnet 4.6 | 0.783 | 0.383 | 0.446 |
| Gemini 3.1 Pro | 0.617 | 0.541 | 0.300 |
| GPT-5.3-Codex | 0.217 | 0.296 | 0.266 |
| GLM-5 | 0.355 | 0.542 | 0.231 |

**实验 2（智能体领域，Table 2）**：Terminus-2 基线 SWE 0.637、TB 0.326。Opus 4.7 为 0.609 / 0.393，DeepSeek-v4-Pro 为 0.323 / 0.345，MiniMax-M2.7 为 0.004 / 0.045（p.8）。

**结论**：39 个配置中 5 个超过人工基线均值，4 个由 Claude 驱动，开源模型只有 DeepSeek-v4-Pro；33% 配置标准差 >0.1，人工基线最大 0.053（§5.2，pp.7–8）。审计器标出 5 次作弊试验，均被隔离机制拦下，仍计入均值（p.8）。

**实验 3（过程特征）**：得分与平均评测间隔（r=+0.444）和总运行时长（r=+0.384）正相关，与评测调用次数基本无关（r=−0.024）（Fig.3，pp.8–9）。

边界：作者承认耗时极长，且继承原基准的分布窄与预训练污染风险（§6，p.10）。阅读者分析：每配置只有 3 次运行，方差又大，单个均值排序不稳；推理领域只对比朴素 agent，"人工基线"强度因领域而异。

依据：[arXiv:2606.04455v1，20 页](https://arxiv.org/pdf/2606.04455v1)，§4–6、Tables 1–2、Fig.3，PDF pp.6–10。
