# 贡献与评价

原文主张（§1，PDF p.2）：

1. 一个用于获取真实案例的网页搜索代理流水线，应对来源分散、格式多样、信息噪声三个难题。
2. 基于 12,985 条人工整理规则收集 106,009 个案例，称为首个大规模、多领域、以规则为依据的真实安全合规数据集。
3. 实验显示规则与案例高度对齐，并对多种 LLM 做了安全合规基准评测。

阅读者分析：

- "真实案例"的含义需要谨慎理解。案例文本是 LLM 总结的；搜索提示要求每条规则找 8–10 个例子，"若无完全匹配，可找相近的类比例子"，reference_link 可以是"可靠的搜索词或描述"（附录 Table 6，PDF p.18）。论文没有报告案例真实性或链接有效性的核验，只核验了规则–案例相关性。
- 提示还要求背景描述避免出现"attack、malicious"等易区分词，这会影响任务难度，但对此没有分析。
- 生成数据的 Grok-4.1 也是被评测模型之一（平均 85.60），存在自评偏差的可能，原文未讨论。
