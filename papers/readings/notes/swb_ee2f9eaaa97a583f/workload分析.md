# 工作负载

**规模**（Table 2，PDF p.3）：74 部法规/政策、9 个领域、12,985 条规则、106,009 个案例；标签分布为 permitted 40,385、prohibited 65,624（§4.1）。

| 类别（示例） | 规则数 | 案例数 |
|---|---|---|
| EU AI Act | 1,245 | 11,205 |
| HIPAA | 1,436 | 12,913 |
| GDPR | 667 | 6,065 |
| 平台政策：GitHub / Reddit | 1,243 / 977 | 11,221 / 8,832 |
| 医疗器械（EU） | 1,110 | 9,991 |
| 反洗钱（EU） | 854 | 7,726 |
| MITRE 缓解措施 | 1,342 | 1,020 |
| 教育：偏见/歧视 | 18 | 159 |

其余包括 SB 53、Data Act、CCPA、中国个人信息保护法/数据安全法/网络安全法/生成式 AI 暂行办法、X/WeChat/Google/OpenAI 政策、学术诚信、在线学习、跨境支付、电子货币、加密资产、基本权利宪章（附录 A）。

**划分**：论文没有训练/测试划分，全部 106,009 个案例都作为评测集使用。规则整理由 3 名计算语言学博士生用一个月完成（§3.1.1）。

阅读者分析：各类别规模差异很大（教育偏见类只有 159 个案例），按类别比较时样本量不可忽略。MITRE 规则多于案例（1,342 vs 1,020），说明不少规则没有检索到案例，但原文未报告无案例规则的数量。
