# 贡献与评价

**原文陈述的贡献**：

- 首个在经济领域进行的、与 ACE 兼容的有监督细粒度事件抽取试点研究；作者称尚不知道其他公开的经济领域细粒度 ACE 式事件抽取方法（§2，p.2）。
- 在新数据集上为触发词与论元识别/分类建立基线，并与 ACE05 对比（§5）。
- 误差分析指出单 token 触发词不足以区分语义和上下文高度重叠的经济事件类别（摘要、§5、§7）。
- 公开源代码、DYGIE 格式的预处理数据和最佳模型（OSF），原始数据集在项目结束后公开，此前可申请获取（§6，p.8）。

**模型变体**（§4，pp.5–6）：BERT+LSTM（BERT-Large 冻结，接双向 LSTM）、BERT 微调（BERT-Base）、FinBERT 替换、开启事件传播、去掉 NER 子任务。SENTiVENT 没有人工实体标注，NER 特征来自在 ACE05 上训练的实体模型（实体 F1 90.7%）给出的银标准标签。

**阅读者分析：**

- 本文的方法贡献有限：模型直接沿用 DYGIE++，主要价值在于数据集和"ACE 方法移植到经济领域会显著退化"的诊断。数据集本身的完整描述、标注流程和一致性研究在 Jacobs & Hoste（2020）中，本文未给出一致性数字。
- 与 ACE05 的对比并非严格同条件：数据集规模、事件密度、标注原则（SENTiVENT 不按句法规则和实体类型约束论元）和触发词单位都不同（§3），差距不能全部归因于领域难度。
- 作者把触发词压缩归为最大误差源（34%），这一结论来自对一半测试文档的人工复查（Table 5），而未做"多 token 触发词模型"的对照实验，作为假设提出、留待后续工作（§7）。

依据：FNP 2020，§2–7、Tables 1、5，PDF pp.2–8。
