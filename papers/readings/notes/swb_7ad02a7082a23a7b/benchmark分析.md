# 评测与边界

**基线与选择**：所有变体基于 DYGIE++；最佳配置按 Trig-C 与 Arg-C 平均 F1 最高选择（§5，p.6）。原文未明确说明该选择基于开发集还是测试集（阅读者分析）。ACE05 对比使用相同架构的单模型，因此分数低于 Wadden et al.（2019b）报告的集成结果（§5 脚注 2）。

**实验 1（最佳系统与 ACE05 对比，Table 2，p.6）**：BERT-Large+LSTM，F1 如下。

| 子任务 | SENTiVENT | ACE05 |
|---|---|---|
| Trig-ID | 52.71 | 76.22 |
| Trig-C | 42.46 | 72.76 |
| Arg-ID | 39.49 | 62.01 |
| Arg-C | 38.01 | 56.33 |

**实验 2（模型变体，Table 3，p.6）**：F1。

| 变体 | Trig-C | Arg-C |
|---|---|---|
| BERT+LSTM | 42.46 | 38.01 |
| FinBERT+LSTM | 41.78 | 35.44 |
| FinBERT 微调 | 42.34 | 29.19 |
| BERT 微调 | 42.22 | 29.41 |
| +事件传播 | 41.13 | 31.61 |
| −NER | 40.03 | 33.64 |

领域内 FinBERT 没有带来提升；微调降低性能，作者推测是触发词检测器在论元检测器训完前就过拟合；事件传播无益；去掉银标准 NER 特征会降低性能（§5，p.6）。

**实验 3（误差分析，Tables 4–5，p.7）**：最佳系统在测试集上的错误类型分布（Table 4）：

| 对象 | 漏报 | 多报 | 误分类 |
|---|---|---|---|
| 触发词 | 51.7% | 34.7% | 13.6% |
| 论元 | 70.8% | 27.9% | 1.3% |

人工复查一半测试文档的触发词错误（Table 5）：

| 原因 | 占比 |
|---|---|
| 单 token 预处理 | 34.1% |
| 触发词歧义 | 20.1% |
| 合理的多余预测 | 16.4% |
| 专业/创造性语言 | 12.4% |
| 词汇稀疏 | 9.1% |

**边界**：只分类主类型；触发词被压缩为单 token；无人工实体标注；单次运行，未报告方差或显著性（阅读者分析）；未评估事件属性（否定、情态、共指）。作者计划转向任意长度触发词的建模（§7）。

依据：FNP 2020，§5、§7、Tables 2–5，PDF pp.6–8。
