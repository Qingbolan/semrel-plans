# 解决的问题

**事件定义**：经济事件是"文本报道的、涉及公司和企业的现实发生、行动、关系与状况"。触发词是最简洁表达事件类型的最小文本跨度（单词或短语），论元是承担某种原型语义角色的参与实体（§3，p.2）。

**输入**：分句、分词后的文档 token 序列；模型在句内枚举所有长度不超过阈值的候选跨度（§4，p.4）。

**输出**（四个子任务，§4，p.4）：

| 子任务 | 判对条件 |
|---|---|
| Trig-ID 触发词识别 | token 位置与参考触发词匹配 |
| Trig-C 触发词分类 | 识别正确且事件主类型正确 |
| Arg-ID 论元识别 | 跨度匹配且所属事件类型正确 |
| Arg-C 论元分类 | 识别正确且角色正确（如 Employee） |

指标均为微平均 P/R/F1。实验只分类 18 个主类型，不分类子类型（§3，p.3）。

**关键预处理**：SENTiVENT 触发词可以多词且不连续（42% 为多词，13% 既多词又不连续），而 DYGIE++ 基本配置要求单 token 触发词。作者用 spaCy 依存分析在触发词跨度内选根部名词或动词（名词优先于动词，再优先于其他词性），如 "improve margins" → "margins"；该优先链在 15% 的触发词子样本上经验确定（§3–4，pp.4–5）。论元保持连续多 token 跨度，无需转换。

阅读者分析：评测对象是被压缩成单 token 的触发词，而非原始标注的多词触发词，因此结果并不直接衡量原始任务定义。

依据：FNP 2020，§3–4，PDF pp.2–5。
