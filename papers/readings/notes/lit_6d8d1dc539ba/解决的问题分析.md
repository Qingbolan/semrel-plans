# 解决的问题

- 输入：图表的 Vega-Lite 规格与数据表（不使用图表图像），单维或多维时间序列折线图（§1、§4，PDF pp.1、4）。
- 输出：一段自然语言摘要，覆盖 Lundgard 与 Satyanarayan 框架中的 L1（图表构造，如标题、坐标轴）、L2（统计概念，如关键极值、增长率）和 L3（感知现象，如上升/下降/平稳/周期/振荡趋势，以及同向、反向、差距等多维关系）。L4 领域语境不在目标范围内（§3.2，PDF p.3）。
- 质量目标：语义丰富且减少幻觉。幻觉按 §3.3 分类：L2 有极值错误、数值错误；L3 有趋势方向、多维趋势、区间、周期性、稳定性错误；另有细节遗漏、空泛描述、比例感知错误 3 类“摘要局限”（PDF pp.3–4）。
- 评测单位：摘要中的句子。幻觉率=幻觉数/句子数，可能大于 1；语义丰富度=L2 与 L3 句子占比（§6.2，PDF p.8）。

“幻觉”在本文中被扩展到细节遗漏、空泛描述等完整性和风格问题，不只是与数据不符的陈述；比较幻觉率时需注意这一口径。（阅读者分析）
