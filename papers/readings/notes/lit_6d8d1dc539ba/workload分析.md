# 工作负载

**幻觉分类研究（§3.3，PDF pp.3–4）**：20 张真实时间序列折线图，涉及金融、能源、政治、教育、环境。4 个 LLM 共生成 80 份摘要、1,083 句，标出 199 个幻觉。占比最高的是细节遗漏与趋势方向错误（各 22.1%），其次是极值错误 12.6%、空泛描述 12.1%、多维趋势错误 10.0%（Fig.3）。

**基准（§5，PDF p.7）**：

| 项目 | 内容 |
|---|---|
| 图表 | 75 张折线图，来自经济、环境、能源等公开数据集；简单、中等、复杂各 25 张 |
| 复杂度依据 | 峰数（简单 1–2、中等 3–4、复杂 >4）、序列长度、维度、变化模式；由三位作者讨论确定 |
| 每图内容 | 数据、Vega-Lite 规格、图像、1 份金标准摘要、GPT-4/VL2NL/ChartInsighter 各 1 份摘要 |
| 规模 | 75 组图表-摘要，共 2,693 句（§1，PDF p.2） |
| 标注 | 6 名可视化背景参与者，对生成摘要逐句标注幻觉类型，按 $10/小时付酬 |

金标准摘要的制作方式：若已有专家摘要则按指南修改，否则先用 LLM 起草再人工编辑（§5）。基准没有训练/测试划分，仅用于评测。

金标准摘要部分由 LLM 起草；参与者知道幻觉定义，但原文未说明标注时是否对系统身份做盲化，也未报告标注一致性。（阅读者分析）
