# 贡献与评价

**原文声称的贡献**（§1，p.2）：

1. 在 4 个 LLM 上系统比较 5 种问题表示、2 种提示成分、4 种示例选择、3 种示例组织。
2. 自称首次同时探索开源 LLM 的上下文学习与监督微调。
3. 从 token 效率角度比较不同提示。
4. 提出 DAIL-SQL，在 Spider 排行榜以 86.6% 执行准确率超过此前最好方法 1.3 个百分点，且 token 更少。

**阅读者分析**：贡献重心是“基准式”的受控比较和经验结论，DAIL-SQL 本身是对已有 MQS（掩码问题相似）与 QRS（查询相似）选择的组合，加上一种折中的示例组织。其核心假设——LLM 从“问题 → SQL 骨架”的映射中学习——由 Table 2 中相似度与准确率的相关性支持，并用以真实 SQL 选例的 Upper Limit 作参照，但不是因果验证（阅读者分析）。

另外几个经验发现有实际参考价值：微调后的开源模型加入示例反而下降（Table 4，p.11）；CodeLLaMA-34B 零样本平均执行准确率比 LLaMA-2-CHAT-70B 高 20.6 个百分点，说明训练语料比规模更关键（§4.4.2，p.10）。

**口径提示**：86.2%/86.6% 是 Spider 隐藏测试集排行榜成绩（附录 F，p.21）；正文实验均在 Spider-dev 上，最好为 83.5%。附录 Table 12 中 DAIL-SQL + GPT-4 的 Dev 为 83.1%，与正文 83.5% 不同，原文未解释，可能来自不同配置（阅读者分析）。

依据：§1、§3.3、§4.3–4.4、Tables 2、4、12、附录 F，PDF pp.2、5–11、18、21。
