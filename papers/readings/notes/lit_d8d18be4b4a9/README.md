# Sultanum & Srinivasan — DataTales: Investigating the use of Large Language Models for Authoring Data-Driven Articles

DataTales 是 Tableau Research 的原型系统：作者给定一张图表并可选地在图上做标注，系统用 gpt-3.5-turbo 生成配套的叙述文本与标题，并把文中句子与图上的数据标记联动高亮。论文以该原型为设计探针，对 11 名数据从业者做了定性研究，归纳出 13 条结论（T1–T13）。这是一篇 4 页正文的短文，没有定量实验；已阅读全文。
