# 解决的问题

论文研究的问题是：用 LLM 为给定图表生成叙述文本，是否可行、对作者有何价值（§1，p.1）。它不是一个有标准答案的预测任务，而是交互式写作辅助的设计探索。

**系统输入**（§3，p.2）：一张预定义图表（柱状图及堆叠/分组变体、散点图、单/多序列折线图、等值区域地图），以及可选的标注：选中标记、图例取值范围、坐标轴范围，可组合使用。

**提示模板**（§3，p.2）：

`Write a narrative based on a [chartType] showing the following data: [chartData] on the topic "[chartTitle]" focusing on: [chartAnnotations*]`

其中 `chartData` 是绑定到图形标记的数据数组，`chartAnnotations` 只在有标注时加入，例如 `{Year : 2000, Country : Australia}` 或 `{Year between [1980, 2001]}`。生成叙述后再用 `Suggest a title for the following narrative: [narrativeText]` 生成标题。

**系统输出**：标题加叙述文本；系统再用依存句法分析和关键词匹配把句子映射到图中的属性与取值，悬停时高亮对应标记；作者手动编辑的部分以斜体区分（§3，pp.2–3）。

**研究的单位**是参与者的写作会话（每人一次 20 分钟任务加访谈），不是单条生成文本（§4，p.3）。

依据：§1、§3、§4 开头，Figures 1–2，PDF pp.1–3。
