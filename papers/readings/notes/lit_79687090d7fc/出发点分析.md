# 出发点

科学数据可视化能直接展示复杂信息、帮助发现隐含规律，但把原始数据做成清晰的图仍然费时费力（§1，p.1）。作者认为用 LLM 做这件事的研究还很少。

相近的文生图（扩散模型）偏重艺术表达，而科学可视化要求信息清晰、精确，二者目标不一致（§1，p.1）。因此作者选择让代码 LLM 写绘图代码，再用多模态 LLM 看图找错，模仿人类“画草稿—看—改”的过程（§1、§4）。

第二个动机是缺乏评测：DS-1000 虽含 Matplotlib 题，但参考解平均只有三行，难以衡量当代智能体处理实际问题的能力（§3，p.3）。于是作者构造了更接近真实场景的 MatPlotBench，并设计自动评分以便大规模比较。

依据：Abstract、§1、§3 开头，PDF pp.1–3。
