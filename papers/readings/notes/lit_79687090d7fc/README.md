# Yang et al. — MatPlotAgent: Method and Evaluation for LLM-Based Agentic Scientific Data Visualization

本文同时提出科学数据可视化基准 MatPlotBench（100 个经人工核验的“查询＋原始数据＋标准图”三元组，用 GPT-4V 打 0–100 分）和智能体框架 MatPlotAgent（查询扩展、带自调试的代码智能体、基于多模态模型的视觉反馈）。GPT-4 直接生成得 48.86 分，接入 MatPlotAgent 后得 61.16 分；去掉视觉反馈为 53.44 分。已阅读正文 §1–8 及附录 A–B（评测、模块提示词、人工评测说明）；Figure 5 等图像案例只读了说明文字。
