# Friedrich & Palmer — Situation Entity Annotation

本文提出“情境实体”（situation entity, SE）类型的子句级标注方案：给文本中每个限定子句标注其引入话语的情境类型（事件、状态、概括句、类指句、事实、命题、疑问、祈使），并以主指称特定/类指、基本体貌类、惯常性三项特征辅助判定。在 MASC 的新闻、书信、笑话三个体裁上双人标注 7,869 个片段，SE 类型 Cohen's κ 为 0.64（REPORT 并入 EVENT 时 0.68）；主指称类型与抽象实体的一致性仍不理想。已通读全文。
