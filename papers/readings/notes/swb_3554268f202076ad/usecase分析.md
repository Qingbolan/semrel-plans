# 具体用例

**例 1：同一动词、不同 SE 类型**（§3.2.2，p.152）。“build a house” 的基本体貌类都是 dynamic，但：

- “John built a house.” → EVENT（一次性事件）；
- “John builds houses.” → GENERALIZING SENTENCE（特定主指称的惯常模式）；
- “John is going to build a house.” → STATE（将来时导致的派生类型）。

**例 2：标注者分歧的诊断**（§4.3，pp.154–155）。在 B、C 一致但与 A 不一致的 183 个子句中，超过 92% 是 B、C 标 specific 而 A 标 generic。作者估计约 40% 源于 A 误解特征定义，约 30% 确有两种读法，例如“every kid in New York”可指纽约全部孩子这一具体集合，也可指纽约儿童这一类；书信中的 “you” 可泛指，也可特指读者。

**例 3：体裁差异**（§4.3，p.155）。募捐信里祈使句多，如 “Please help Goodwill. // Use the enclosed card // and give a generous gift today.”

阅读者分析：若把 SE 类型作为语义算子的标签输出（例如“筛选描述惯常行为的子句”），应保留特征层级与多解情况，而不应假设单一金标准；这是项目侧推论，原文未讨论此类用法。
