# 解决的问题

**定义**（§3.1，p.3）：两个 SQL 的执行结果不同（忽略版式差异），则二者不等价。给定 schema 和取值都已知的数据库 D，若问题 s 映射到的非等价 SQL 集合基数不少于 2，则 s 有歧义。

以下情况被排除：数据管理层面的歧义（格式、覆盖范围、NULL 处理）以及输出格式未指定。

**任务**：
- 输入：自然语言问题，加上数据库完整的 CREATE TABLE 与 INSERT INTO 语句（schema 与全部数据都放进上下文）；
- 输出：一个或多个 SQL；
- 理想行为：识别出歧义，并为每种解读各给一条 SQL（§4，p.7）。

**三类歧义**（§3.2，p.4；Figure 1）：

| 类型 | 例子 | 解读 |
|---|---|---|
| 范围歧义 | “What activities does each gym offer?” | 集合读法（所有健身房共有的课程）/ 分配读法（每个健身房各自的课程） |
| 附着歧义 | “writers and editors on a work-for-hire” | 高附着（两者都是 work-for-hire）/ 低附着（只有 editors 是） |
| 模糊性 | “Who issued CD Special?” | bank / branch / 两者 |

样本单位是“歧义问题 + 数据库”。每个歧义问题对应 2–3 条金标 SQL，每条解读本身是一个只对应一条 SQL 的无歧义问题。

依据：[arXiv:2406.19073v2，29 页](https://arxiv.org/pdf/2406.19073v2)，§3.1–3.2、§3.4，PDF pp.3–7。
