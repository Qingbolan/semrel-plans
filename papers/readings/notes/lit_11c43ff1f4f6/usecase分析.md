# 具体用例

原文 Listing 2 的医院场景（§2，PDF p.2）：
- 表 `health.csv` 的血型列 `BT` 存在 `NULL`；
- 血型属于不会出现在公开世界知识中的私有信息，但可能存在于医院本地数据库；
- 用户把 `/Users/hosp_tables/`（CSV 文件夹）指定为数据湖，`relevant_columns = ALL`，并设 `is_local_model = True`，出于隐私使用本地模型。

执行过程：
1. 索引数据湖全部元组；
2. 对脏元组 t2 检索 top-n 候选，由 Reranker 缩至 top-k；
3. Reasoner 逐对判断候选是否与 t2 为同一实体，并抽取血型值（如 B）；
4. 同时返回值来源的元组与属性（§2、§4.4，PDF pp.2–3）。

对比用例：Listing 1 用云端 GPT 按姓名和年龄补全 `Gender`，属于不依赖数据湖的场景 1。

若把它当作语义填补或语义连接算子用例，需注意“是否同一实体”的判断本质上是实体匹配，填补正确率取决于数据湖覆盖率；本文没有评测数据湖中缺少答案时的拒答行为（阅读者分析）。
