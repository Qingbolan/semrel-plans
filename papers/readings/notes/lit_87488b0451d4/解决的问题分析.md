# 解决的问题

**被测对象**：数据智能体，在结构化库集合 D 与非结构化来源集合 K 上，通过工具集合 T 迭代交互：每步根据状态（查询、D、K、历史）选择工具调用或给出最终答案，直到 final 或达到预算 B；基准记录动作序列以计算 Tool F1、成功率、延迟和成本（§3.1，式 1–2，p.3）。

**任务输入**：自然语言分析查询 + 对应数据库 + 冻结的非结构化证据（文档切块以 FAISS 索引并带来源元数据，评测时可重放）（§4.1，p.4）。

**任务输出**（§4.2.1，p.4）：

- 单选（SC）：正确选项由 SQL 执行结果加上下文解释决定；
- 多选（MC）：需综合 D 与 K 中证据选出全部正确选项；
- 报告：要求结合数据库证据与外部上下文写出分析报告。

**金标准**：选择题有执行验证的答案；报告题有加权评分细则 B 与金标准任务 DAG G（节点类型如 `SQL_QUERY`、`RETRIEVE_DOC`、`COMPUTE`、`VALIDATE`，边类型 `HARD_DEP`、`SOFT_DEP`、`ALT_GROUP`）（§4.3，p.5；附录 C，p.12）。

**约束**：凡仅用 D 或仅用 K 即可回答的任务都被剔除，保证必须跨源推理（§4.2.2 Phase 3，p.5）。

依据：§3.1、§4，附录 C，PDF pp.3–5、12。
