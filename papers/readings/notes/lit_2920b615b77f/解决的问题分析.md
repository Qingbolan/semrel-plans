# 解决的问题

**任务**：给定数据库 schema 与自然语言问题，生成对应 SQL；跨域设置下训练、开发、测试集的数据库不重叠（§1，p.1）。

**形式化**（§3，p.3）：`S = LLM(I, D, Q, E)`，I 为指令，D 为数据库 schema，Q 为问题，E 为示例列表 `(Di, Qi, Pi)`，Pi 是包含正确 SQL 的答案提示。作者据此把可调因素归为三类：

| 因素 | 本文做法 | 位置 |
|---|---|---|
| schema 提示格式 | 5 种：Table(Column)、加主外键、Create 语句（无键/列尾/表尾加键），并可附每表 c 行数据 | §3.1，p.3 |
| 示例选择 | 混合策略：ns 个随机静态示例 + nd 个按问题相似度选的动态示例 | §3.2，pp.3–4 |
| 答案提示 | 自动 CoT：列→最相关问题片段，余下表→片段，再列出值，最后给 SQL | §3.3，pp.4–5 |

**多轮扩展**（§3.4，p.5）：先用 LLM 把多轮问题改写为去上下文依赖的单轮问题（每个数据集人工标注 10 个改写示例），再套用单轮方法。

输出单位为一条 SQL；评测用 EM（不看值）、EX（执行结果）、TS（多个数据库实例下执行正确），多轮另用 QM 与 IM（§4.1，p.6）。

依据：§1、§3–4.1，PDF pp.1–6。
