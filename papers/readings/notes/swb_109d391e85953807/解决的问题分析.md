# 解决的问题

**单位与输入**：每个样本是一段商品文本或一张商品图片，与包含该数据类型全部规则的文本 prompt 拼接；文本输入 LLM，图文对输入 VLM（§3.1，p.3）。图片常含嵌入文字，需要 OCR 加视觉理解。

**输出**：一个违规类别集合（多标签）。其中隐含约束是 `Z.other`（无违规）不能与任何违规类别同时出现（§5.4，pp.6–7）。

**两个任务**（§4.1，p.4）：

- **Single-Violation**：按六个商品类别分别使用较短的专用 prompt（614–3,379 token），平均约 5 个类别可选，考察窄语境下的细粒度判断。
- **All-in-One**：把六类规则合并为一个指令，prompt 从约 1K 增至 7K token，类别扩展到 26 个，并合并语义重叠的规则；又分为 Simplified Instruction（只给定义）和 Detailed Instruction（附正反例）。

**指标**（§4.2，p.5）：Full Accuracy 要求预测集合等于金标准集合；Partial Accuracy 只要求交集非空。作者认为后者更贴近实务，因为审核员关心是否违规，而不是具体类型。

依据：§3.1、§4.1–4.2、§5.4，PDF pp.3–7。
