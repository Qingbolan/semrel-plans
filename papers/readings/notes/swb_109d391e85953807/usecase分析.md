# 具体用例

**场景**：电商平台审核一张"增高"商品的推广图。商家用遮挡、变形或隐喻图像暗示"保证长高"之类的违规功效，图中还有被噪声遮掩的嵌入文字。

**流程**：审核系统把这张图片与 Height Growth 类别的全部规则（953 token）拼成 prompt 交给 VLM（Single-Violation）；也可以用合并后的 7K token 全量规则，在 26 个类别中选择（All-in-One）。模型输出违规类别集合；若输出 `Z.other`，则不能同时含其他类别。平台通常只关心"是否违规"，对应 Partial Accuracy（§4.2）。

**观察到的失败**：错误分析（Table 5，p.6）从每个模型的错误中随机抽 100 条归因。Qwen2.5-VL-7B 的主要错误是"找对证据但找不到对应规则"（38）、有意省略或错误的信息（26）和规则误解（26）；SFT 后这三项降为 6、8、3。GPT-4o 的错误中，规则匹配失败（46）和误解（33）最多，作者称更强的模型更常误读 prompt 规则。

**变体**：§5.5 的两阶段做法先用 GPT-4o 或 Claude-3.7 把图片转成文字描述，再交给 LLM 推理，不再输入图片本身（Table 6，p.7）。

依据：§4.1–4.2、§5.4–5.5、Tables 1、5–6，PDF pp.3–7。
