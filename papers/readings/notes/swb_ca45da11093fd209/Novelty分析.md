# 贡献与评价

**作者声称的贡献**（§1，pp.2–3）：

1. 由法律专业人士贡献任务的协作式构建：2022 年 8 月发布征集，提交任务经法律正确性与任务有效性审查，贡献者列为作者；
2. 源自 IRAC 等法律界框架的推理类型学，为律师与 LLM 开发者提供共同词汇；
3. 作为研究平台，配套任务文档、基础提示和规则适用评分指南；
4. 对 20 个 LLM 的评测与提示工程微研究。作者称其为首个开源法律基准构建项目（据其所知）。

**任务来源**：既有数据集重构（如把 CUAD 长文档片段抽取改为每类条款一个二分类任务）、法律学者以往手工编码但未发布的数据、专为 LegalBench 新建的任务。

主要新意在构建流程与组织方式，而非新的评测方法。类型分布极不均衡——解释类 119 个任务，规则回忆仅 5 个；规则适用与规则结论共用同一组 16 个任务，所以按类型统计的任务数相加（182）大于 162（阅读者分析）。大量解释类任务来自 CUAD、MAUD 等既有数据的重构，类别平均分容易被这些任务族主导。

阅读者分析：附录 E.2 把任务分为“已发表 / 原创但已公开 / 原创未公开”三类以应对训练数据泄漏，这是比同期许多基准更细的处理，但论文没有按此分组报告结果差异。

依据：§1，pp.2–3；§4.1–4.2，pp.7–8；附录 E.2–E.3、Tables 5–6，pp.26–27。
