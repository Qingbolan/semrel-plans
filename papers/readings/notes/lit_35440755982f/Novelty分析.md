# novelty

作者声称：(1) CIPHER 能同时处理封闭与开放的企业分析任务；(2) DES 框架把候选生成（N）与选择执行（M）显式解耦，是测试时扩展设计空间中的新设计点；(3) 对 DES 设计做大规模实证，识别哪些轴把额外推理算力转化为准确率；并称首次在匹配模型下同时评测封闭与开放任务。

设计要点：Ensemble 生成用 E=2 个提示、概率各 0.5——原始提示与一个由 LLM 改写、强制计划结构的版本；作者称此模式在多轮 agent 测试时扩展中是新的。选择侧用 Titan Text Embeddings v2（1024 维）做贪心 maximin（MaxEnt）或 k-means 代表点，或由 Claude 3.5 Sonnet 作为评审挑选 M 个计划。

阅读者评价：实证结论本身否定了"选择"这一新增环节的价值——四种选择策略与随机选择基本无法区分（MaxEnt +0.44pp，p=0.040，量级小），作者也因此推荐随机选择。因此真正起作用的是"两种提示的计划多样性 + 并行执行 M=5 + 更强聚合器"，这与已有的多样化采样/自洽思路接近。工作的价值主要在设计空间的系统性消融和带 bootstrap 置信区间的配对比较。

依据：[arXiv:2607.14386v2，17 页](https://arxiv.org/abs/2607.14386)，§1–3、§4.1，附录 A、C.2–C.3，PDF pp.1–5、8、10–11。
