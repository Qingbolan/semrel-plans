# 解决的问题

这是一篇综述，要回答的问题是：LLM 数据智能体由哪些部件构成、现有系统在这些部件上如何取舍、还剩下哪些挑战。

**被综述对象的输入与输出**（§3.1，pp.6–8；Figure 3）：输入是自然语言任务和数据文件（如 CSV），LLM 生成代码，在沙箱（Python、R、Jupyter、SQL 等）中执行并取回结果，输出为分析结论、图表、模型或报告。

**分类维度**（Table 1，p.9）：

| 维度 | 取值 |
|---|---|
| 方法 | Conversational（多轮反馈）/ End-to-end（单个提示后自主完成） |
| 用户界面 | IDE-based、独立系统、CLI、OS-based |
| 规划 | Basic IO、Linear、Hierarchical |
| 其他 | Human-in-the-loop、Self-correcting、Expandable |

工作单元是“一个数据分析任务”。综述本身不定义可执行的评测任务，也不给统一的成功判据；§4 的案例只做定性展示。

依据：[arXiv:2412.14222v2，46 页](https://arxiv.org/pdf/2412.14222v2)，§3.1–3.4、Table 1，PDF pp.6–13。
