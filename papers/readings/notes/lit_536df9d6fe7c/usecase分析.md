# 具体用例

**案例 2（残差诊断与异方差检验）**（§4.2，p.21；Figure 7）：用户向 LAMBDA 提出“用 horsepower 和 weight 拟合预测 mpg 的线性回归，画残差图，并做异方差检验”。

智能体的执行过程：
1. 读入 Auto MPG 数据，把 horsepower 中的非数值项转为缺失并删除；
2. 用 statsmodels 拟合 OLS；
3. 计算并绘制残差；
4. 执行 Breusch–Pagan 检验，输出 LM 统计量与 p 值，结论是同方差假设被明显违反；
5. 建议使用稳健标准误或对模型做变换。

原文称 GPT-4o 也完成了同一任务，记录放在补充材料中。

这个用例的价值在于展示“统计推断链条”能否完整走下来；但原文只呈现成功轨迹，没有报告失败率，也没有核对数值正确性的标准。§6.1 也承认，不同提示措辞会导致选用的检验或图表不同（阅读者分析）。

依据：[arXiv:2412.14222v2，46 页](https://arxiv.org/pdf/2412.14222v2)，§4.2、Figure 7，PDF pp.21–22；§6.1，p.29。
