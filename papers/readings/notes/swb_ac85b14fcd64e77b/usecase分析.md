# usecase

以注册商确认延迟（B2）为例：规则要求注册商在收到机构核验请求后 2 个工作日内提供注册数据。作者从每份裁决书中抽取"向注册商请求日期"（e2）、"注册商回复日期"（e3）和注册商名（e13），计算间隔；考虑到各国工作日和节假日不同，按 3 个工作日内视为按时。结果显示多数注册商按时回复，少数长期拖延 1–12 个工作日；2020 年 1 月起的请求中有 927 次（7.14%）迟回复。24 个注册商的周请求量与迟回复数显著正相关（Spearman，r̄=0.44），它们处理了 28,686 件案件。

阅读者分析：这一用例说明从半结构化法律文书中批量抽取日期和角色、再与规则时限比较的工作流。若项目把它转成语义查询（如"找出所有确认超过 3 个工作日的案件"），应保留"只用中位 F>75% 的机构"、英文限定和 NER 误差等边界；这是项目派生任务，原文未评测查询准确率。

依据：[Adjibi et al., NDSS 2026，作者站点终稿 PDF，18 页](https://astrolavos.gatech.edu/articles/Manuscript_UDRP_final.pdf)，§VI-B1、Fig.9，PDF p.10。
