# 解决的问题

**任务**：跨域 Text-to-SQL。输入为用户问题 `Q_u`、可选提示 `H_u`（BIRD 的 evidence）、目标数据库 `D`（schema、元数据、值）；输出一条可在 SQLite 上执行的 SQL。评测单位是一个问题–SQL 对，以执行结果是否与金标准 SQL 一致计正确（EX）（§3、§4.1，pp.3、7）。

**流水线四个组件**（§3.1，p.3）：

| 组件 | 输入 → 输出 |
|---|---|
| 值检索 | 问题 → LLM 抽关键词，LSH 召回相似值，再按嵌入相似度与编辑距离重排（§3.2，p.3） |
| 候选生成 | 问题+schema+检索值 → 多条候选 SQL；三种生成器 DC/QP/OS（§3.3，pp.3–5） |
| 查询修正 | 语法错误或空结果的 SQL → 自反思修正，最多 β=3 次（§3.4，p.5） |
| 选择代理 | 候选集合 C → 一条最终 SQL（§3.5，pp.5–6） |

**挑选的形式化**：Eq.1 用选择模型对 k 个候选打分并取累计分最高者；作者取 k=2。Alg.3 对每对候选：执行结果相同则直接记一方胜，不同则在两者用到的 schema 并集上调用二元分类器判胜负，最终取得分最高者，平局任选（p.6）。

**选择模型训练**：在训练集上运行生成器、按执行结果聚类；当同时存在正确和错误簇时构造 `(Q_u, C_i, C_j, D_ij, y_ij)` 样本并随机打乱顺序（§3.5，p.6）。附录 A.2 写明用 BIRD 训练集生成的 3.8K 样本，以 LoRA rank 16 在 Vertex AI 上微调 Gemini 1.5 Flash 10 个 epoch（p.14）。
