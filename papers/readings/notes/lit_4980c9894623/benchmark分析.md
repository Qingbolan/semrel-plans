# 评测与边界

**指标**：执行准确率 EX（BIRD 与 Spider 官方排行榜指标）（§4.1，p.7）。

**实验 1（BIRD 端到端，Table 2，p.7）**：

| 方法 | EX Dev | EX Test |
|---|---|---|
| CHASE-SQL + Gemini 1.5 | 73.01 | 73.0 |
| CHASE-SQL + Claude 3.5 Sonnet | 69.53 | – |
| Distillery + GPT-4o | 67.21 | 71.83 |
| CHESS | 65.00 | 66.69 |
| MCS-SQL + GPT-4 | 63.36 | 65.45 |
| AskData + GPT-4o（未公开方法） | 72.03 | 72.39 |

**实验 2（Spider test，Table 3，p.7）**：CHASE-SQL 87.6%，排第二；第一名 MCS-SQL + GPT-4 为 89.6%，但后者使用了 Spider 训练。

**实验 3（单生成器，Table 4，p.8）**：基线（BIRD 原提示 + 零样本 CoT）57.75%；QP/DC/OS 分别 63.62/63.92/67.09%；加修正器后为 65.51/65.77/68.02%。

**实验 4（选择模型二元准确率，Table 5，p.8）**：Claude-3.5-sonnet 60.21%，Gemini-1.5-pro 63.98%，微调 Gemma 2 9B 64.28%，微调 Gemini-1.5-flash 71.01%。仅统计一对中恰有一个正确的情况。

**实验 5（挑选方法，Table 6，pp.9–10）**：六种生成器×温度设置下，选择代理 70.4–71.73%，self-consistency 64.41–67.34%，上界 74.77–80.44%。

**实验 6（消融，BIRD dev EX，Table 7，p.11）**：

| 设置 | EX | 变化 |
|---|---|---|
| 完整 CHASE-SQL | 73.01 | — |
| 改用 self-consistency | 68.84 | −4.17 |
| 改用一次性排序代理 | 65.51 | −7.50 |
| 去 LSH 值检索 | 70.09 | −2.92 |
| 去查询修正器 | 69.23 | −3.78 |
| 去 QP / OS / DC 生成器 | 72.36 / 72.16 / 71.77 | −0.65 / −0.85 / −1.24 |

**错误分析（附录 A.4，p.16）**：BIRD dev 上最终正确 72.9%，正确候选存在但未选中 10.4%，无正确候选 6.7%，金标准本身错误 10.0%。

**边界**：无独立局限章节；无成本/延迟报告；除 Spider 外所有消融只在 BIRD dev 上；选择模型在 BIRD 训练集上微调，BIRD dev 提升可能部分来自同分布训练（阅读者分析）。金标准错误占 10% 意味着 EX 上限本身受标注质量影响（附录 A.4，p.16）。
