# 贡献与评价

原文声称的贡献：

1. 首个同时包含 PK 与 PD 相互作用的 DDI 语料，文档数、实体数与关系数均大于先前药物语料中的 DDI 部分（§1、§5，PDF pp.3、6）。
2. 唯一专门标注药物类别（group）和未批准物质（drug_n）的语料（§5，p.6）。
3. 关系分类（mechanism/effect/advice）依据临床管理 DDI 的信息需求设计（§3.2，p.5）。
4. 公开标注指南，覆盖不连续名称、缩写、嵌套实体等现象；报告精确匹配下的一致性（§3.2、§3.4）。
5. 作为 SemEval-2013 DDIExtraction 金标准，吸引 14 支队伍（摘要，p.2）。

阅读者分析：贡献主要是资源和指南。原文对人员的描述不完全一致：§3 说“两名专家和两名文本挖掘人员”参与，§3.3 则说两名药剂师标注、一名文本挖掘人员协助协调；第二名标注者只标了部分句子，因此全语料大部分只经过一名主标注者加协调流程，不是全量双人标注。系统评测细节不在本文。
