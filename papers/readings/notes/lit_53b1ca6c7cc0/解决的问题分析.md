# 解决的问题

**输入**：一个上下文化时间序列 X = (X_{1:T}, C)，其中 X_{1:T} ∈ R^{N×T} 是 N 变量、T 时间戳的数值序列，C 是关联上下文（文本描述、类别元数据、外部约束、领域知识）；本文聚焦“文本 + 时间序列”混合这一特例（§2.1，式 1–3，p.2）。外加自然语言指令 q。

**任务实例**：τ = (q, X, Y, y*, ℓ)，Y 是输出空间，y* 是目标，ℓ 是评测函数；目标是输出 ŷ = f(q, X) 使 ℓ(ŷ, y*) 最小（式 4–5，pp.2–3）。Y 可以是数值预测、标签、排序、文本解释、决策、可执行动作或其组合——即“开放式上下文化时间推理”，任务目标与输出格式由自然语言指定，而非固定映射 X_{1:T}→X_{T+1:T+H}。

**工作单元**：每个任务把 X_{1:T} 装入任务局部工作区 W（经 MCP 访问，保持全精度）；冻结策略 π_θ 产生轨迹 ζ = (a_1,o_1,…,a_K,o_K,ŷ)，动作是调用运行时操作或推理步，观测是工具返回的紧凑结构化结果（§3.1，式 8–9，p.4）。harness 要求每个数值结论都来自某个工具观测，而非自由文本推理（§3.2，p.4）。

**系统输出**：除最终答案 ŷ 外，还产出可审计的解题轨迹，供能力演化与记忆复用（§3.2–3.4）。

阅读者分析：这里的“问题”是一个通用 agent 框架问题，而非单一可判定的预测任务；不同基准的 ŷ 类型完全不同（CiK 是概率预测轨迹，TSRBench/TSAIA 是多选题准确率），论文用同一 harness 覆盖它们。

依据：[arXiv 2606.05404v1](https://arxiv.org/abs/2606.05404)，§2.1、§3.1–3.2，PDF pp.2–4。
