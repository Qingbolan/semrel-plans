# 贡献与评价

论文的贡献：(1) 把 ADAS 定义为一个研究方向，并拆成搜索空间、搜索算法、评估函数三要素；(2) 主张用代码作为搜索空间，理由是图灵完备、可读、可直接复用已有框架（如 LangChain）、并能利用 FM 的编程能力；(3) Meta Agent Search 算法：元智能体基于存档提出新设计，经两轮自我反思检查新颖性，评估时出错最多修复 5 次，然后加入存档。

ARC 实验展示了“踏脚石”式的演化：第 3 轮出现“多条 CoT 生成答案、精炼再集成”的模式，最佳智能体的反馈机制由第 5、11、12 轮的想法组合而来。

阅读者分析：算法本身很简单，作者也承认搜索算法和评估函数都较朴素。存档初始化为手工基线，而附录 I 显示 MGSM 上从空存档出发反而更好（67.5 vs 53.4），说明结果对初始化和随机性较敏感。所有实验都是单步问答，没有多步交互环境。
