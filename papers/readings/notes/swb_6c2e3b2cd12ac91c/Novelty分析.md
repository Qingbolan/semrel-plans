# 贡献与评价

**论文自述**（Statement of Significance，p.3；§1，p.3）：

- 把 CEDAR 字段约束当作运行时执行的“可执行规范”，让 LLM 实时获取模板并查询 BioPortal（超过 1,200 个本体），而不是假定模型记得合规值。
- 使用少见的专家整理参考标准，可以直接用精确匹配评估，而不是用代理质量指标。
- 显示机器可执行的元数据标准不仅支持前瞻性标注，也支持大规模回溯标准化。

**评价**：消融实验把两类工具分开（§3.3，p.8；补充材料 B）：

| 设置 | 本体字段 P / R | 非本体字段 P / R |
|---|---|---|
| 基线 | 0.365 / 0.331 | 0.704 / 0.626 |
| 仅模板 | 0.599 / 0.554 | 0.944 / 0.881 |
| 仅术语检索 | 0.803 / 0.572 | 未给数值（图中与基线接近） |
| 完整 ARMS | 0.919 / 0.799 | 0.942 / 0.878 |

只给模板时非本体字段已接近完整 ARMS；只给术语检索时本体字段大幅提升，但仍低于完整 ARMS。这比只报告总分更有说服力。去重评分还揭示，非本体字段的召回提升主要来自重复值的一致纠正，去重后召回无显著差异（0.848 对 0.843，p=0.6641，§3.2，p.8）。

阅读者分析：方法层面是“LLM + 领域工具”的常见范式，新意主要在任务设定（模板约束下的遗留元数据回溯标准化）和较严格的评测设计。基线是作者前作，未与 SPIRES 等外部系统直接比较；全部评测局限于单一仓库（HuBMAP）和单一框架（CEDAR），作者在 §4.1 承认这一点（p.12）。

依据：§1、§3.2–3.3、§4.1，PDF pp.3、8、12。
