# Hardi et al. — Automated Standardization of Legacy Biomedical Metadata Using an Ontology-Constrained LLM Agent

论文提出 ARMS：一个通过 MCP 调用工具的 LLM 智能体，运行时获取完整的 CEDAR 元数据模板，并在 BioPortal 中按指定本体或本体分支检索标准术语，把遗留的 HuBMAP 实验元数据记录转换为符合标准的记录。在 839 条由专家标准化的参考记录上，与只在提示中给出字段名和本体名的基线相比，字段级精确率从 0.56 升至 0.93，召回率从 0.51 升至 0.85；本体约束字段的精确率从 0.36 升至 0.92。已阅读正文全部章节及补充材料 A、D、E、F 的说明部分。
