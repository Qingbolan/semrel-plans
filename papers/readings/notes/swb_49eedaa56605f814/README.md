# Park, Blake & Cardie — Toward Machine-assisted Participation in eRulemaking: An Argumentation Model of Evaluability

这是一篇 ICAIL 2015 短文，为在线立法征求意见（eRulemaking）的公众评论提出“可评估性”论证模型：定义五种基本单元（Policy、Value、Fact、Testimony、Reference）、两类支持关系（Reason、Evidence）及“可评估论证”的形式定义，并用三条 regulationroom.org 评论示例说明。文中没有数据集、标注实验或自动系统评测。已通读全文 5 页。
