# 贡献与评价

原文贡献是一个面向“可评估性”的论证模型，而不是数据集或算法（摘要、§4）：

- 在 fact/value/policy 三分法上，区分经验事实（Testimony）与非经验事实（Fact），并把 Testimony 视为无需进一步支持的证据（§3.1）。理由有三：个人经历通常无法提供客观证据，证据可能涉及隐私，而且机构接受个人经历类评论。
- 新增 Reference 单元，涵盖 URL 和文献引用（§3.1）。
- 把 Toulmin 与 Hitchcock 的“正当依据”映射到这些单元类型（Table 2）。
- 用集合形式定义论证、子论证和可评估论证（定义 3.1–3.3）。

阅读者分析：价值在于把“缺理由/缺证据”变成可操作的类型约束，适合驱动评论提示；但全文只有三个示例，没有标注一致性或可行性证据。“每个命题有至少一个支持就更易评估”是作者明示的简化假设，攻击关系也留作未来工作（§3.3、§4）。

依据：[ICAIL 2015，5 页](https://facultystaff.richmond.edu/~jpark/papers/jpark_icail15.pdf)，§3–§4、Tables 1–3，PDF pp.2–5。
