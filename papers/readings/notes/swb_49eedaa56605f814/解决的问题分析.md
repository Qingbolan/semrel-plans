# 解决的问题

问题：如何形式化判断一条用户评论中的论证是否“可评估”，并据此指出还缺什么支持（§3）。

**输入**：评论被切分为命题级基本单元。每个单元属于五类之一：Policy（应采取的行动）、Value（价值判断）、Fact（可用客观证据验证的非经验事实）、Testimony（关于作者自身状态或经历的客观命题）、Reference（URL 或文献引用）（§3.1）。

**关系**：Reason（X 解释 Y 为何成立）和 Evidence（Testimony 或 Reference 证实命题）（§3.2）。

**输出**：按定义 3.3，论证 {R,E,c} 及其所有子论证需满足以下之一才算可评估：结论为 Testimony；结论为 Policy/Value 且至少有一个命题理由；结论为 Fact 且有 Fact 理由；或结论为 Fact 且有证据（§3.3）。Table 3 的最后一列给出每个结论“还需要的支持”。

阅读者分析：处理单元是评论中的论证命题；论文没有给出切分规则或自动分类方法，这些留给后续系统实现。

依据：[ICAIL 2015，5 页](https://facultystaff.richmond.edu/~jpark/papers/jpark_icail15.pdf)，§3.1–§3.3、Table 3，PDF pp.2–5。
