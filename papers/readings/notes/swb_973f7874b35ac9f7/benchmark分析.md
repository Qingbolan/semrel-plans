# 评测与边界

**固定配置**：PyMuPDF4LLM（PDF）、Mammoth+Markdownify（DOCX），段长 1536，paraphrase-multilingual-mpnet-base-v2，gpt-4o，Faiss，top-5（§4，PDF p.3）。每次只改一个组件。

**实验 1（文本抽取，Tables 1–2，6 个项目）**：PDF 平均总体准确率 PyMuPDF4LLM 54.19、MarkerPDF 52.21、Docling 53.03；DOCX 中 Docx2txt 58.44 最高，但会把表格单元拆行，作者仍选 Mammoth+Markdownify（55.46）。作者结论是没有统一最优库。

**实验 2（段长与相邻段，Table 3）**：

| 相邻段 | 512 | 1024 | 1536 |
|---|---|---|---|
| 含前后段 | 54.27 / 75.76 | 55.51 / 74.59 | 55.45 / 74.51 |
| 不含 | 47.72 / 74.74 | 48.87 / 74.32 | 51.40 / 74.91 |

（总体准确率 / yes/no 准确率，%）即使温度为 0，重复测试仍有约 1% 波动。

**实验 3（嵌入模型，Table 4）**：mpnet 55.45 / 74.51；bge-m3 66.81 / 76.91；微调 bge-m3 70.73 / 78.46。

**实验 4（重排序，§4.4）**：先取 20 段再用 bge-reranker-v2-m3 重排，总体 58.8 对 55.45，yes/no 75.26 对 74.51；耗时从 3.5 小时增至 27 小时，因此未采用。

**边界**：无人工或非 RAG 基线；无检索层面指标；未报方差或显著性；提示改造无定量结果；未区分检索失败与 LLM 误读（§5，PDF pp.6–7）。阅读者分析：重排序实验以 mpnet 为底，未与最佳的微调 bge-m3 组合测试。
