# 具体用例

**投标保证金核查**（§3，PDF p.2）：系统先回答前提 `question0`："采购标的是否分批？"若为 no，则该项记 n/a；若为 yes，再验证"每批投标保证金不超过该批估算合同价的 2%（不含增值税）"。系统检索与问题最相似的 5 个片段并附上相邻片段，填入 JSON 输出提示：要求返回 answer（yes/no/缺信息）、rate（低/中/高置信度）、explanation（引用支持片段，或说明缺什么信息）（附录 2，PDF p.8）。

**绿色采购核查**（附录 3，PDF p.8）：复杂问题被拆成子问题。Q1：评审标准是否提及绿色公共采购原则（含《公共采购法》第 19 条）；Q2：绿色标准是否符合比例原则、基于客观理由。Q1 为否则答 n/a，Q1、Q2 均为是则答 yes，其余答 no，并以 JSON 返回各子问题及解释。法律条文和采购文件分别放在 `<law>` 和 `<context>` 标签中。

阅读者分析：这是"文档集合 × 检查清单"的批量语义判定，每题带条件依赖和可追溯引用。
