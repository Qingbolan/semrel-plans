# 解决的问题

**输入**：一个采购项目的 PDF/DOCX 文件集合，加上 YAML 问题文件。每个问题指定所用提示模板，可附带相关法律条文（§3，PDF p.2）。

**问题结构**：部分问题分两部分。`question0` 是前提（如"采购是否分批？"）；`question` 是待验证陈述（如"每批投标保证金不超过该批估算合同价的 2%（不含增值税）"）。

**输出与标签**：

| 来源 | 取值 |
|---|---|
| 人工参考答案 | yes、no、n/a |
| LLM 允许输出 | yes、no、context does not have information |
| 派生规则 | `question0` 为 no 时该题记 n/a；上下文缺信息时，本题及其所有子题记 X |

**指标**（§3，PDF p.3）：总体准确率 = 与参考答案一致数 / 全部答案数；yes/no 准确率只统计 LLM 输出 yes 或 no 的题，不计"缺信息"和 X。作者明确说后者偏高，因为排除了模型不确定的题。

**流程**：抽取为 Markdown → 按标题与长度切分 → 嵌入存入 Faiss → 对每题检索最相似的 5 段，与法律信息、问题一起填入模板，交给 LLM（Figure 1，PDF pp.2–3）。
