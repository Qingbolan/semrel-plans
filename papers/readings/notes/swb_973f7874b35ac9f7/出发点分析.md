# 出发点

欧盟资助的公共采购项目须符合欧盟法规，在拉脱维亚由中央财政与合同署（CFLA）按详细检查清单人工核查。作者希望用 RAG 自动化这一核查，以减少人工（§1，PDF p.1）。

难点在于文档为拉脱维亚语，采用正式的法律文体，而主流 LLM 主要用英语等高资源语言训练（§1，PDF p.1）。RAG 让 LLM 无需领域微调即可基于检索到的片段作答（摘要、§1）。

相关工作部分列举了医药合规、金融、建筑合同、法律审阅中的 RAG 应用，并提到嵌入模型选择、领域微调等改进方向（§2，PDF p.2）。

阅读者分析：动机是具体的行政自动化需求；论文定位为工程配置研究，而非新算法。
