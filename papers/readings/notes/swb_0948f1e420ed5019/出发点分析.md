# 出发点

人们越来越依赖互联网完成日常事务，网络犯罪、数据失窃和身份盗用也随之增加；安全相关事件数量太多，无法人工审阅，需要机器从文本中发现并汇集威胁信息。为此需要标准的事件模型来存储网络安全信息，以及能从文本中填充这些模型的信息抽取系统（摘要，PDF p.1）。

通用事件抽取主要基于 ACE2005 和 TAC 数据，面向人和组织的一般事件；网络安全领域已有工作多停留在命名实体抽取或"是否发生攻击"的判断，少数抽取攻击者、受害者等细节，作者认为尚无全面抽取网络安全事件信息的研究（第 1 章，印刷 pp.1–2）。

目标是把安全新闻转为结构化事件框架（如 Table 1.1 的钓鱼事件框架），既方便非技术人员理解，也能填充语义知识图谱（§1.1，印刷 pp.3–4）。

依据：摘要、第 1 章，印刷 pp.1–5（PDF pp.1、15–19）。
