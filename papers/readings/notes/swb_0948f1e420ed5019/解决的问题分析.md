# 解决的问题

**论文命题**：通过定义全面的事件模式、构建标注语料并应用深度学习文本分析，可以自动化网络安全事件信息抽取（§1.2，印刷 p.5）。

**输入与输出**：输入一篇新闻文本，输出 JSON 事件对象，并可映射为使用作者网络安全本体的 RDF 知识图谱，实体链接到 Wikidata（第 5 章、第 12 章，印刷 pp.69、134–135）。

**流水线子任务**（第 5 章，印刷 pp.69–82）：

| 子任务 | 单位与输出 |
|---|---|
| 事件触发词（nugget）检测 | 词序列标注，5 类事件 |
| realis 识别 | 每个触发词判为 Actual / Generic / Other |
| 论元检测 | 词序列标注，20 类论元 |
| 论元-角色链接 | 只处理可填多个角色的论元，按事件类型约束分类 |
| 事件共指 | 文档内把触发词聚为事件簇 |
| 知识图谱映射 | 生成 RDF；Purpose 与 Capabilities 角色再细分子类型（后者对应 CAPEC Meta 层攻击模式） |

**标注约束**：论元只有在前后各一句的上下文中出现事件触发词时才标注（§4.2，印刷 p.51）。

依据：§1.2、第 4–5 章、第 12 章，印刷 pp.5、49–82、134–138。
