# 贡献与评价

**原文贡献**（§1.3，印刷 pp.5–6）：

1. 网络安全事件模式：5 类事件、20 类论元、语义角色（§1.3 写 26 个，第 14 章写 23 个）；第 3.5 节还示范了新增 Attack.DDoS 类型；
2. 适合网络安全文本的标注规则与指南；
3. 1,000 篇新闻的标注语料；
4. CASIE 流水线系统，使用领域 Word2vec、BERT、Bi-LSTM(-CRF)、注意力和外部知识库特征；
5. 公开语料与代码。

**标注质量**：3 名计算机科学背景标注者，按多数投票合成最终标注；token 级 Cohen's κ=0.81。主要分歧是标注边界（是否把整个短语纳入）以及 Purpose 与 PII、数据泄露触发词之间的混淆（§4.5，印刷 pp.64–68）。

**阅读者分析（评价）**：

- 主要价值在于领域事件模式与带角色、realis、共指的全文标注语料。模型部分是当时常见的组件化流水线。
- 计数口径不一致：§1.3 称 3,903 个事件（916/955/944/528/560），Table 4.2 和第 14 章为 7,708 个触发词，而 Table 6.1 训练 + 测试合计 8,485 个触发词；3,903 恰等于 Table 6.5 的单例簇加多实例簇总数，说明"事件"指共指簇（阅读者计算）。
- 论元 Person 数量正文写 3,806，Table 4.3 为 3,836。

依据：§1.3、第 3–4 章、第 6 章，印刷 pp.5–6、27–68、87–91。
