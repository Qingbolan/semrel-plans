# 出发点

作者观察到语言模型在代码基准上表现很强，智能体脚手架也在自动化开发流程，但缺少能整体衡量“自主端到端 ML 工程”的基准（§1，p.1）。

设计上有两个目标：（1）任务要有挑战性，并代表当前 ML 工程工作，例如训练模型、准备数据集、运行实验；（2）结果能与人类水平直接比较（§1，p.1）。Kaggle 竞赛满足这两点：有真实数据、预先定义的指标和公开排行榜。

另一个动机来自安全评估：能自主完成这类任务的智能体可能加速科研，作者明确提到 MLE-bench 可作为 OpenAI Preparedness Framework 中“模型自主性”的度量，并对应 Anthropic RSP、Google DeepMind Frontier Safety Framework 中的相关能力（§1，pp.1–2；Ethics Statement，p.11）。

与已有工作的区别：MLAgentBench 只有 13 个任务且给出基线方案，看能否改进 10%；MLE-bench 任务更多、更复杂，要求从零开始（§5，p.9）。

依据：§1、§5、Ethics Statement，PDF pp.1–2、9、11。
