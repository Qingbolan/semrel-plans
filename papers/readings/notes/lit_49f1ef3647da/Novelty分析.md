# 贡献与评价

**原文声称的贡献**：
1. 实证显示真实对话中混合数据问题很常见；
2. 提出第一个面向混合知识库的形式化查询语言 SUQL；
3. 提出第一个能处理混合数据源的语义解析器（少样本 LLM）；
4. 提出一个优化编译器（§1、§5、§7，PDF pp.2、5–6、9）。

编译器的三项优化：
- 对 `ANSWER` 过滤先用稠密检索预计算嵌入取候选，再用 LLM 复核整个子句；多个文本约束用 max-sim 求和聚合；
- 对 ENUM 列重载 `=`，用零样本 LLM 的 `CLASSIFY` 把 “coffee” 映射到 “coffee & tea”“cafe”；
- 把过滤条件转为 DNF，先执行非 `ANSWER` 谓词，并在有 `LIMIT` 时惰性停止（§5.1–5.3，PDF pp.5–6）。

**评价**：把 LLM 调用封装为 SQL 中的 UDF 式算子，并做谓词排序和检索预筛，是语义算子方向的早期代表之一。不过，“完备于关系代数与 NLP 操作”只是设计论证，没有形式证明；编译器优化没有单独的成本或延迟实验，也没有消融。检索预筛只取 top 候选，可能漏掉满足条件但相似度不高的行，论文没有量化这一召回损失（阅读者分析）
