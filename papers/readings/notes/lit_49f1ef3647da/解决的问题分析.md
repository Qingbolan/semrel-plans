# 解决的问题

**语言层（§4、Table 1，PDF p.4）**：
- `ANSWER(t, q)` 输入文本或文本数组 t 和问题 q，返回文本答案，可作为过滤条件，例如 `ANSWER(reviews,'is this restaurant family-friendly?') = 'Yes'`；
- `SUMMARY(t)` 是 `ANSWER(t,'what is the summary of this document?')` 的语法糖；
- 两者可出现在任何允许文本值的位置，因而能与 SQL 的投影、过滤、排序和聚合任意组合（Table 2 给出 HybridQA 的 6 类问题示例）。

**对话层（§3.2，PDF p.4）**：给定模式 S、历史轮次（用户和系统话语、每轮 SUQL）及最新用户话语 tn，若 tn 包含查询，就预测本轮 SUQL `qn`。解析分两步：先判断是否需要查库，再生成 SUQL。

**输出**：执行 SUQL 得到的行，经 LLM 生成自然语言回复。系统会说明“搜了什么”，无结果时明确告知无结果。

工作单位是“一轮用户话语 → 一条 SUQL → 结果集”。HybridQA 实验中要求输出简短答案；无结果时最多重试 2 次（§6.1，PDF p.6）（阅读者分析）
