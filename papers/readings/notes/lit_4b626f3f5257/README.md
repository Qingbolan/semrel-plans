# Tan, Li, Wang et al. — Large Language Models for Data Annotation and Synthesis: A Survey

这是一篇 EMNLP 2024 综述，按“生成—评估—利用”三段组织 LLM 数据标注与合成的研究：生成部分覆盖指令与回复、标签、推理依据、成对反馈、文本反馈和领域数据；评估部分覆盖人工/任务特定/LLM-as-a-judge 评估及规则、外部信号、LLM 驱动的过滤；利用部分覆盖监督微调、对齐调优和推理阶段使用。全文没有实验或新数据集，附录列出标注工具与带代码链接的论文表。已阅读正文 §1–7、Limitations 和附录 A–C，附录论文表只抽查了格式与若干条目。
