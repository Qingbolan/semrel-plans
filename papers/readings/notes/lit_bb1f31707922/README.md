# Zhu et al. — StatABench: Dataset and Framework for Evaluating Statistical Analysis Capabilities of LLMs

StatABench 是统计分析能力基准，分两部分：Stat-Closed 含 404 道有标准答案的题（18 个统计主题，选择、填空、判断/决策、实际应用四类，其中 198 道实际应用题需调用 35 个函数的 SAToolKit），Stat-Open 含 30 道改编自建模竞赛的开放式建模任务，由 Gemini 3 Pro 按七个维度打分。GPT-5.1 在 Stat-Closed 上总准确率 68.6%，最佳开源模型 Qwen2.5-72B 为 60.6%；Stat-Open 上最佳框架平均 61.86 分。已读正文、局限段与附录 A–H 的主要内容。
