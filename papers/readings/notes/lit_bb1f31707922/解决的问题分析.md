# 解决的问题

Stat-Closed（§3.1–3.4，pp.3–5）：
- 输入：一道统计题；实际应用题还附带数据集，模型需通过 LangChain MCP 调用 SAToolKit（35 个函数，如 ci_normal、contingency_test、fit_cox_model、estimate_did_effect）。
- 输出：按固定格式给出的最终答案 "The answer is <…>"。
- 判分：选择、决策、数值题直接匹配；语义等价的填空和需文字解释的实际应用题由 LLM 判定预测与参考答案在统计结论、数值与解释上是否一致。实际应用题的参考答案由正确参数执行函数得到确定结果，再交给 DeepSeek-V3 改写为可读答案。
- 单位：一题一分，报告分主题和总准确率。

Stat-Open（§3.3–3.4，pp.4–6）：
- 输入：竞赛题面 + 数据文件；输出：结构化建模报告（PDF/Markdown）。
- 判分：LLM-as-Judge，四个大维度（结构连贯、方法质量、实用与科学有效性、结果解释与偏差分析），表 5 中细分为七个子项，等权平均，0–100 分。
- 单位：一个完整建模项目，包括数据清洗、方法选择、代码执行、结果解释与报告写作。
