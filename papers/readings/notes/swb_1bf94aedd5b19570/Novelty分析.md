# 贡献与评价

**论文声称的贡献**：

1. 不依赖单一红旗，而是把采购三个阶段的多个红旗组合成综合指标。理由是腐败手段可以相互替代：取消某个例外程序后，腐败可能换一种手法（§2.1，p.6）。
2. 用回归系数确定红旗是否入选及其权重，并用残差分布寻找连续变量的阈值，避免任意设定（§6，pp.19–24）。
3. 数据覆盖全体合同，因此显著性采用 Monte Carlo 置换检验，而非基于抽样的 Fisher 检验（pp.24–25）。
4. 用 4 个外部硬指标做效度检验（§6.2），并论证该方法可在约 50 个国家复制（§8，p.45；附录 B）。

**阅读者评价**：权重并非直接取回归系数，而是“每个显著组件权重为 1，组件内各类别按影响大小排序后取 1、0.75、0.5…”，再除以组件数 13 和观测最大值 0.805（pp.35–36）。这是半主观规则，作者也承认要结合理论与定性判断。

效度检验只显示组间均值差异较小（如政治关联企业 CRI 高 0.01），属于相关性证据。作者明确说回归模型“不做因果解释”（§3.2，p.9）。

依据：§2.1、§3.2、§6–8，PDF pp.5–45。
