# 具体用例

**审计资源分配**：监管者可以按发包机构聚合 CRI，优先审计长期高 CRI 的机构或合同（§8，p.45）。作者指出，单份合同的 CRI 可能受随机波动影响；组织持续高 CRI 时，更可能是真正的腐败组织而非数据噪声（§3.2，p.11）。

**一份合同的打分示意**（权重取自 Table 5，p.38）：

| 红旗 | 组件权重 |
|---|---|
| 只收到一份投标 | 0.096 |
| 未在官方公报发布招标公告 | 0.096 |
| 谈判程序 | 0.072 |
| 利用周末的超短提交期 | 0.096 |
| 决策期超过 182 个工作日 | 0.096 |

阅读者分析：如果一份合同同时触发上表 5 项，其他组件为 0，CRI 约为 0.456。这落在作者所说“约 0.45–0.50 以上为特别高风险”的区间（§6.2，p.39）。作者还提到，访谈者认为同时出现 3–4 个红旗（CRI=0.27–0.36）基本就是腐败（p.36）。以上为阅读者按表格权重做的算术示例，并非原文案例；若调用方缺少招标公告或合同完成公告，表注说明要按可得变量重新加权。

依据：§3.2、§6.1–6.2、§8，Table 5，PDF pp.11、35–39、45。
