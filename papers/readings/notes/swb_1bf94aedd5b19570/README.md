# Fazekas, Tóth & King — An Objective Corruption Risk Index Using Public Procurement Data

本文基于 2009–2012 年匈牙利全部公共采购公告（超过 53,000 份合同），构建合同级“腐败风险指数”（CRI）。方法是用回归把 14 个程序性“红旗”（招标阶段的输入）与三个疑似腐败结果（单一投标、仅剩一份有效标、中标方在发包方处的份额）关联起来，挑出 13 个组件并加权求和。随后用利润率、价格比、政治关联、避税地注册四个外部指标做效度检验。主要结果：多数红旗在回归中方向符合预期；利润率最高三分位公司的 CRI 比最低三分位高 0.024（约高 10%），CRI 与最终价/预估价相关 0.14，政治关联企业 CRI 平均高 0.01，差异小但显著（§6.2，pp.39–44）。已读全文正文（§1–8）及附录 A、B、D、E 的说明部分；附录 C、F 的描述统计表只粗看。
