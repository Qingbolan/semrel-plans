# 解决的问题

**输入**：接入 IGinX 的数据源，含自动抽取的模式或元数据；用户的自然语言查询或关键词；图界面上的点击展开操作（§2.1，p.2）。

**输出**：

- 层次化目录：最高层为少量主题，逐层展开到表与列（§2.2，p.3）。
- 语义检索结果：与查询最接近的 n 个表/列，在已有图中高亮，或从空视图出发组织成新的层次图（§2.3，p.3）。
- 关系边：新展开节点与原节点间的相似度（边的粗细）及 LLM 生成的关系描述，用于发现可连接或可合并的表（§2.3，p.3）。

**目录生成步骤**（§2.2，p.3）：对每列汇集六类信息——数据源信息、源-表-列路径、兄弟列、列值特征、该列参与过的任务、列描述（如有）；由 LLM 总结后做语义嵌入（作者选择这一方案，而非对六类信息分别嵌入再融合）；把节点组成图，反复聚类到给定数目 K，并让 LLM 用短语概括每个簇，直到节点数达到 K。

**检索步骤**：LLM 按示例查询改写用户查询，再嵌入并在 Milvus 向量库中检索（§2.3，p.3）。

**工作单元**：列（目录生成与检索的基本对象），以及展开时的一对节点（关系分析）。

阅读者分析：论文未定义检索的相关性标准，也未给出 K、n、m 的取值。
