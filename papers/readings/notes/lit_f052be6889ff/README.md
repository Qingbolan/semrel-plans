# An et al. — LEDD: Large Language Model-Empowered Data Discovery in Data Lakes

LEDD 是建立在联邦数据湖系统 IGinX 之上的系统演示（demo）：用 LLM 把列的六类信息总结后做嵌入，再迭代聚类并由 LLM 为每个簇命名，生成层次化的全局语义目录；同时支持自然语言表/列语义检索和展开节点时的实时关系分析。演示数据为 SchemaPile 的 221,171 个数据库模式（约 1,000 万列）。论文只有系统描述和演示场景，没有定量实验结果。已阅读全文。
