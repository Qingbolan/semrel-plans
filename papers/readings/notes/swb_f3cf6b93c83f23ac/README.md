# Barale et al. — AsyLex: A Dataset for Legal Language Processing of Refugee Claims

AsyLex 是一个加拿大难民身份认定（RSD）判决文书数据集：59,112 份 1996–2022 年的决定文书，配有专家参与设计的实体标注（人工金标准、规则抽取和模型推断的银标准）及案件结果标签，服务“案件审查”中的实体抽取与判决结果预测两类任务。作者用 7 种 BERT 系模型做基线：基于“裁定句”分类的准确率约 99%，而仅用案件封面实体预测结果的准确率约 72–75%。已阅读全文正文、局限、伦理声明及附录 A–E。
