# 解决的问题

问题定义（§2.1，PDF pp.2–3）：给定自然语言查询和由表 {T1,…,Tn} 组成的数据库，生成一条准确表达原查询语义的 SQL。

| 挑战类别 | 内容（§2.1，p.3） |
|---|---|
| 自然语言侧 | 查询有歧义或说明不足，难以推断确切意图 |
| 数据库侧 | 真实模式结构复杂、关系模糊，数据可能不完整、不一致或有噪声 |
| 翻译侧 | SQL 语法严格；一条查询可对应多条合法 SQL；不同模式设计会得到不同 SQL |

Figure 2(a) 把难度分为五级：前三级已解决或正在解决，第四级是 LLM 方法当前处理的挑战，第五级是作者对未来五年的展望（p.3）。

结果调试被定义为：判断生成的 SQL 与原查询在语义上是否等价，并在不等价时追溯原因、加以修正（§1、§2.6，pp.1、4）。

阅读者分析：教程的"工作单位"是单条自然语言—SQL 对。多数据库查询被列为开放问题，而非已覆盖的范围（§2.7，p.4）。
