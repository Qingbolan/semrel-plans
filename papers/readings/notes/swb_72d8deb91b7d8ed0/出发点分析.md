# 出发点

LLM 推理能力强但推理成本高，研究者希望把能力迁移到小模型（sLM）。主流做法是 CoT 蒸馏：让小模型通过下一词预测模仿教师 LLM 的思维链（§1，PDF p.2）。

问题在于，蒸馏后的小模型容易幻觉、算不准。作者举例：“2010 年投资 Apple 股票 100 美元到 2020 年值多少？”需要股价历史知识和算术；教师 LLM 可凭记忆用 CoT 答对，但学生只记住了这条推理，面对“2015 年投资 Nvidia 300 美元”时会编造“无拆股”等事实（Figure 2，PDF p.2）。

作者的思路是蒸馏“行动能力”：让小模型学会检索事实、执行代码，把精力放在“如何推理与行动”，而不是记忆知识与计算，从而更好地泛化到需要新事实或新计算的问题（§1，PDF p.2）。

剩下的难点是：能否把这种复杂的智能体行为从 >30B 教师蒸馏到 0.5–3B 学生。作者指出两个具体障碍：智能体行为相对于教师与学生的指令微调分布是分布外的；小模型常生成格式错误或误用库函数的代码（§4，PDF p.4）。
