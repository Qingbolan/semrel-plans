# 出发点

数据故事把可视化与文字结合，用于传达洞察和因果关系；其核心是找出数据中的"故事片段"，以图文呈现，再组织成有整体信息的叙事（§1，p.1）。Figure 1 的 GapMinder 例子展示了 Hans Rosling 如何用四页图文讲述全球生育率从约 5 降到 2.5（p.1）。

手工制作数据故事需要数据分析、可视化、设计与叙事技能，耗时费力。已有自动化方法（DataShot、Calliope 等）多基于规则，生成的多是简单事实，缺少有效叙事结构（§1–§2.1，pp.1–2）。LLM 已用于图表摘要、图表问答和文本故事生成，但"从数据表生成故事"的能力尚未被系统研究，部分原因是缺少基准（§1，p.2）。DataTales 用 LLM 从图表图像生成叙述，但只输出文字、不产生图表（§2.2，p.2）。

作者还以 LLM 智能体在规划类任务上的表现为动机，提出模仿人类"写作-修改"流程的智能体框架（§1，p.2）。

论文同时解决"缺基准"和"缺方法"两个问题，基准的规模与质量（自动抽取的训练集）因此是评估其可复用性的关键（阅读者分析）。
