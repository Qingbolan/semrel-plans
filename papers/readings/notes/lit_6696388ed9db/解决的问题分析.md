# 解决的问题

**任务定义**（§4.1，p.5）：

| 要素 | 内容 |
|---|---|
| 输入 | 一张或多张数据表及其标题 D；用户意图 I（故事主旨，语料中取报告/故事标题）；附加指引 G |
| 输出 | 连贯的数据故事 S：多段文字 + 对应的可视化规格（图表类型、x/y 轴取值与标签等），规格随后用于渲染图表 |
| 工作单元 | 一个故事；Pew 平均每故事约 4.5 张图及对应段落（§3.3，p.5） |

**框架三步**（§4.2–4.3，pp.5–6）：

1. 反思：Generator 描述数据中的关键趋势、模式与异常；Critic 对照表格核查并给出修订计划；Generator 修订得到 `R_f`。
2. 提纲：基于 `R_f`、D、I 生成开头-中段-结尾的线性提纲，含简单可视化规格；Critic 检查与数据一致性及与意图的契合度。
3. 叙述：生成正文与详细可视化规格；Critic 检查与提纲对齐、洞察有数据支撑、规格正确。

每步调用 LLM 三次（两次生成、一次评审），共 9 次（p.6）。

输出中的图表是"规格"而非渲染结果，评测的可视化质量取决于评审对规格的理解；输入表格对 Pew 而言多为模型从图像抽取的结果（阅读者分析）。
