# 评测与边界

**实验 1（Task 9.1，6 队 16 个 run，Table 3–5）**：全测试集严格 F1 最好为 WBI run 3 的 0.715（CRF + ChemSpot 特征，训练时还用了 9.2 测试集的实体），NLM_LHC 词典方法 run 2 为 0.704。各类中 brand 最容易，drug_n 最难；DrugBank 上的结果远好于 MedLine。

| 系统（全测试集） | STRICT | EXACT | DRUG | BRAND | GROUP | DRUG_N |
|---|---|---|---|---|---|---|
| WBI run 3 | 0.715 | 0.833 | 0.79 | 0.836 | 0.776 | 0.141 |
| NLM_LHC run 2 | 0.704 | 0.792 | 0.81 | 0.846 | 0.643 | 0 |
| UTurku run 3 | 0.648 | 0.666 | 0.783 | 0.912 | 0.485 | 0.076 |

**实验 2（Task 9.2，8 队 22 个 run，Table 6–8）**：FBK-irst run 2 的检测并分类（CLA）F1 最高 0.651，检测（DEC）0.80，int 0.547。WBI run 3 为 0.609。多数系统基于 SVM。2011 年最好检测 F1 为 65.74%，但两届数据集不同，作者明确不可直接比较。

**边界**：结果表只给 F1，完整排名在任务网站；原文没有给出 P/R。作者承认 drug_n 识别失败、两个子任务都仍有提升空间。阅读者分析：WBI 9.1 最优 run 使用了 9.2 测试集的实体做训练，这在任务规则内，但与只用训练集的 run 不完全同口径。

依据：[SemEval 2013，pp.341–350](https://aclanthology.org/S13-2056.pdf)，§3.2，Table 3–5，PDF pp.4–5；§4.2，Table 6–8，pp.6–8；§5，p.8。
