# 解决的问题

输入：一个检索语料（实验中通常是单篇长文档）和一个问题。输出：不超过 token 预算的检索上下文，交给阅读模型（UnifiedQA、GPT-3 或 GPT-4）生成答案。

**建树**：按约 100 token 切块，句子不截断；用 SBERT（`multi-qa-mpnet-base-cos-v1`）嵌入为叶节点。用 UMAP 降维后，以 GMM 做软聚类（一个节点可属多个簇），先全局再局部，以 BIC 选簇数；簇内文本超出摘要模型上限时再递归聚类。用 gpt-3.5-turbo 摘要每簇，摘要重新嵌入后重复，直到无法再聚类。

**检索**：

- tree traversal：从根层逐层取 top-k，再在其子节点中取 top-k。
- collapsed tree：把所有层节点放在一起按余弦相似度排序，加入直到 token 上限。

在 QASPER 20 篇文档上，collapsed tree 表现更好，主实验采用 2,000 token（约 top-20 节点）；UnifiedQA 因上限 512 token 只给 400 token，基线给同样 token 数。

依据：[arXiv:2401.18059v1](https://arxiv.org/pdf/2401.18059v1)，§3、Figures 1–3、附录 D、F，PDF pp.3–6。
