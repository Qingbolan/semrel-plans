# 贡献与评价

原文主张的贡献（Abstract、§1、§7）：

1. 第一个能覆盖全部可能 tlink 的时间线式标注框架，且每个 tlink 都有人工标注支撑，而不是由闭包规则推断。
2. 用三种机制（事件类型、分支、事实性）处理欠指定；作者称这是首次把体（aspect）与事件顺序信息合并到同一标注单元（§3.1，PDF p.3）。
3. TimeBankNT 语料（36 篇、双人独立全量标注）、标注指南、开源标注工具和 TimeML 转换脚本（MIT 许可）。
4. LongT5 关系分类基线。

阅读者分析：密度优势来自"时间线等价于全部成对关系"这一表示，比较对象的 tlink 也没有闭包补全，作者明确说明二者不完全可比。IAA 虽与既有工作相当，但标注者就是指南作者本人，外部标注者能否达到同样水平未验证。作者还主张时间标注应放弃单一金标准、建模不同解读（§6），这更像立场而非已验证结论。
