# 评测与边界

共指使用 MUC、B³、CEAFe、BLANC；其余任务使用 micro-P/R/F1，报告五次随机实验均值和标准差。联合训练后时间/因果/子事件 F1 为 56.0/31.5/27.5，独立训练为 55.8/30.6/26.7；不能笼统描述为全面大幅提升。Appendix C 报告 RTX 3090 上联合训练实验约 3.4 小时。与旧资源比较时还改变了因果方向性、负例采样等设定，必须保留这些条件。
