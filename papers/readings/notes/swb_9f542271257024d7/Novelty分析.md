# 贡献与评价

| 贡献 | 位置 |
|---|---|
| 基于 Cochrane 与非 Cochrane 综述的风险判定基准 | §4.1，pp.3–4 |
| 两个新子任务 SSR 与 SJS，把判定拆成检索与推理 | §3、§4.4–4.5，pp.2、5–6 |
| 支持判断到原文句子的对齐流水线：GPT-4 先把支持判断分解为互不重叠的要点，再逐句判断某句是否“覆盖”某要点，汇总为多对多映射 | §4.3，p.4 |
| 检索/推理交叉消融与传统模型比较 | §6.3–6.6，pp.7–9 |

**标注质量**：50 篇论文、13,575 个（要点，句子）对，两组研究生各两人。人—人 κ 73.1，人—GPT-4 κ 71.4，差异不显著（p=0.54）；OpenAI-v3-large 嵌入只有 29.7，显著更低（Table 2，p.5）。流水线 API 费用约 1,000 美元（p.4）。

阅读者分析：子任务把“判断依据”变成可度量对象，这是相对于只预测标签的先前工作的主要区别。但 SSR 金标准由 GPT-4 自动生成，仅在 50 个样本上做了人工一致性验证；人—人一致性本身只有 70 出头，说明“覆盖”的定义存在解释空间。SJS 用多选题代替生成，作者承认这是对生成任务的代理（§4.5）。

依据：§3–4，PDF pp.2–6；§6，pp.7–9。
