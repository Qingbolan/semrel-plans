# 解决的问题

**数据模型**：扩展关系模型，单元格可存图像或音频（实际存文件路径）（§3.1，PDF p.3）。

**算子**（Table 1，PDF p.4）：`sem_filter`（自然语言谓词选行）、`sem_join`（两表行对满足条件）、`sem_map`（按描述变换）、`sem_rank`（按描述排序取前 k）、`sem_classify`（分到预定义类）。每条查询都含语义算子，且语义算子开销主导总成本（§3.2）。

**真值**：用原始 Kaggle 等数据集的人工标签替换 LLM 调用，执行等价 SQL 得到（§3.3，PDF p.4）。

**质量指标**按查询类型而定：

| 查询类型 | 指标 | 归一化 |
|---|---|---|
| 聚合 | 相对误差 | 1/(1+relative_error) |
| 检索 | F1（召回=真值被覆盖比例，精确=结果行在真值中比例） | 原值 |
| 排序 | Spearman 等级相关 | 实测均 >0，不再归一化 |
| 分组类（分类、部分映射与连接） | ARI | 实测均 >0，不再归一化 |

**开销指标**：执行时间、LLM 费用、内存；扩展性按数据规模（而非并发用户）衡量（§3.3、§5.1，PDF pp.4、7）。

依据：§3、§5.1、Table 1，PDF pp.3–4、7。
