# 贡献与评价

原文列出的贡献：（1）四角色多智能体框架，分工为查错、批评、重写和经验沉淀；（2）多轮修正机制，每轮只针对第一个错误步，且 Refiner 只看到错误步之前的链，避免被原错误链带偏；（3）自演化模板树：叶节点是具体错误类型（如 Row Error、Column Error）并存放批评模板，Curator 在一次修正成功后可向叶节点加模板、纵向细分叶节点或横向增加新分支（如 Final Query Error）；（4）在相近或更低成本下优于多数投票。

阅读者分析：方法新意主要在提示编排与“按错误类型检索批评模板”的经验库，底层仍是同一 LLM 的提示调用，没有训练或外部校验器。模板树在测试过程中持续演化，相当于在测试集上做在线经验积累；自演化的消融增益为 1.1–1.8 个点，小于多轮批评框架整体带来的增益（Table 2 净增 8.9/2.9）。附录 A 声称这是第一个用于表格推理的多智能体框架，这一“首次”说法未经本阅读核实。

依据：[ACL 2025，pp.17432–17451，20 页](https://aclanthology.org/2025.acl-long.853/)，§1、§3.2–3.4、§4.6、附录 A、D，PDF pp.2–5、8、12–14。
