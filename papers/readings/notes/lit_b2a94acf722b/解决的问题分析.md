# 解决的问题

**输入**：一张表 T、一个问题 q（WikiTQ 为问答，TabFact 为事实核验陈述），以及由 Chain-of-Table 产生的初始推理链 τ={s1,…,sn}（每一步是选行、选列、生成子表等操作及最终查询）。框架本身声称也可接其他方法的推理链，但实验只用 Chain-of-Table（脚注 1）。

**输出**：修正后的完整推理链 τ′ 及预测答案；副产物是更新后的模板树。

**工作单元**：单个（表，问题）样本上的一次“判定—批评—重写”迭代。Judge 输出逐步错误分析 E、整体状态 P∈{Correct, Incorrect} 和模板树路由 R；Critic 输出批评 C 与第一个错误步序号 I；Refiner 只拿到 s1…sI 及批评，重写并补完其余步骤。迭代直到 Judge 判为正确或达到上限 K。所有角色都是同一底座 LLM 的不同提示，不训练（附录 B.2）。

阅读者分析：终止条件完全依赖 Judge 的自评而非标签，因此“判为正确”并不等于真正正确；论文用 Table 2 的纠正率/破坏率间接衡量这一点。

依据：[ACL 2025，pp.17432–17451，20 页](https://aclanthology.org/2025.acl-long.853/)，§3.1–3.3、附录 B，PDF pp.3–5、12–13。
