# 评测与边界

完整任务的组合模型分类 micro/macro accuracy 为 0.619/0.689，BLEU-4 为 0.344；神经基线对应 0.448/0.428 与 0.078。分类、追问文本重合度及整段对话是否正确完成是不同指标；BLEU 高不自动说明追问最有效。无情境分类分数不能代表带背景知识的任务。正文另提到 oracle 用户研究，本轮未核对其额外附录，不把该研究的速度提升归给已训练模型。

依据：[EMNLP 2018, pp.2087–2097](https://aclanthology.org/D18-1233.pdf)，§5、Table 5，PDF pp.6–8；§1 oracle 描述，PDF p.2。
