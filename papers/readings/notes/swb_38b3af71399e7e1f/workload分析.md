# 工作负载

**来源与过滤**：从 USCIS 网站抓取 EB-1A（表格代码 B2203）与 NIW（B5203）类全部公开非先例决定，共 13,520 份 PDF（2005-01 至 2026-03）。去掉 O-1 申请、文本少于 2,000 字符的文件和少量重复后，剩 12,375 份。

**主要统计（Table 2）**：

| 项 | 数量 |
|---|---|
| NIW（Dhanasar，2016 年后） / NIW（NYSDOT，2016 年前） | 3,484 / 1,280 |
| EB-1A（Kazarian） / 仅 EB-2 门槛 / 其他程序性 | 6,486 / 2,626 / 499 |
| 维持原拒（Dismissed/rejected） / 发回 / 改判（Sustained） | 10,373（83.8%） / 975（7.9%） / 674（5.4%） |
| 2017 年前扫描件 / 2017 年后原生文本 | 6,051 / 6,324 |
| 逐条认定 | 45,290：not_met 56.2%、reserved 19.8%、met 18.0%、waived 3.4%、not_addressed 2.6% |

**划分**：论文没有给出训练/验证/测试划分。它建议用 Dhanasar 切换作为时间上的分布外划分，并提醒评测时应删去开头的结果宣告，避免模型直接抄答案。

**内部不一致（阅读者分析）**：Table 2 五个框架行相加为 14,375，比总数 12,375 多 2,000。其余对照如下（阅读者分析）：

| 引用中位数 | 10 | Figure 6：11 |
| 含批评原话的记录 | 4,377 | Figure 6：4,709 |
