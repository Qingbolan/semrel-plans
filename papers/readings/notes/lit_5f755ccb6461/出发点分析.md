# 出发点

原文认为现有 LLM 数据分析工具多为通用型，缺乏执行聚类、预测建模、趋势分析等“高级分析”的结构，常依赖基础统计或需要用户手动选择方法；多智能体系统（如 InfiAgent、Data Interpreter）缺少对分析方法、数据特征和领域技能用法的指引，产出流于描述性统计且依赖低效的迭代调试（§1–2，pp.1–3）。

评测方面有两个缺口：（1）现有基准领域窄、任务简单，如 InsightBench 偏商业分析的基础统计，DS-1000、DA-Code 等偏代码；（2）洞见质量主观，人评需要专业背景、难以扩展，静态提示或微调的 LLM 评审器难以对齐人类偏好或成本高（§1–2）。

阅读者分析：出发点是“方法选择”这一步——把分析方法显式化为可检索的技能文档，从而让 LLM 选对方法；它不涉及多表、非结构化数据或大规模数据（作者在 §7 列为未来工作）。
