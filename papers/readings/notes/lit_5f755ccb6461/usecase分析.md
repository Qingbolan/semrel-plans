# 具体用例

Fig.1（p.2）的例子：persona 为“在气象机构工作、用该数据集支持环境规划的气象学者”，目标为“分析天气时间序列以识别异常用于预报”。通用智能体只给出“年中温度峰值、冬季下降、存在季节性”等描述；AgentAda 检索到“用 statsmodels 进行时间序列分解（趋势/季节/残差）”技能，给出约 ±1°C 的稳定高频周期、7 月约 20°C 到 1 月约 5°C 的趋势，以及常见 ±3°C 噪声、偶发 ±4°C 异常。

Fig.2（p.4）的零售例子：问题为考察客户分群随时间的行为变化，技能匹配器给 K-Means、PCA、Cohort、Time Series、Anomaly 打分后选 K-Means，结论为基于年收入与消费得分的 5 个客户群，最大群 81 人、最小群 22 人。

Table 1（p.7）也给出反例：在只需计数连通分量的问题上，带技能版本使用 PageRank，人评更偏好无技能的简单答案——技能引入了不必要的复杂度。

阅读者分析：对本项目而言，这类用例是“目标驱动的探索式分析”，答案开放、以 LLM/人评为主；与有确定答案的语义查询不同，若从中派生查询，需另行定义可判定的输出。
