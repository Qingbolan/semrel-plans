# 评测与边界

**基线**：原始表（不清洗）和直接提示（DP，一次生成整个工作流，上下文与本方法相同）。模型为 Llama 3.1-8B、Mistral-7B、Gemma 2-9B/27B，温度 0.1，若没有返回有效操作则升到 0.3，运行在 4 张 A100 上（§6.1，pp.7–8）。

**指标**（§5.2，p.7）：
- 答案：精确率、召回、F1，以及字符级 Similarity；
- 列值：Column Ratio（目标列中与金标匹配的单元格比例）；
- 工作流：完全匹配率，以及与 silver 工作流的操作重合度（精确率、召回、F1）。

**实验 1（合并结果，Table 7，p.8）**：

| 设置 | 答案 F1 | Column Ratio | 工作流 F1 |
|---|---|---|---|
| 原始表 | 0.2201 | 0.4262 | – |
| Llama 3.1-8B DP / 本方法 | 0.2811 / 0.5181 | 0.5817 / 0.7475 | 0.2053 / 0.6447 |
| Mistral-7B DP / 本方法 | 0.2612 / 0.3320 | 0.4884 / 0.6004 | 0.0536 / 0.5065 |
| Gemma 2-9B DP / 本方法 | 0.3030 / 0.3479 | 0.6032 / 0.6575 | 0.2042 / 0.6640 |
| Gemma 2-27B DP / 本方法 | 0.2956 / 0.6256 | 0.5967 / 0.7900 | 0.1353 / 0.6456 |

显著性用配对 t 检验。工作流完全匹配率很低，最高为 0.1056。

**实验 2（分数据集，附录 Table 8，p.15）**：在 PPP 上，Mistral-7B 加本方法的答案 F1 为 0.3191，低于原始表的 0.3309。这说明本方法不是在每个数据集上都优于不清洗（阅读者分析）。

**边界**（§9，pp.9–10）：
- I：噪声高时难以从示例中学习；
- II：错误会在迭代中传播，且没有人工介入；
- III：只做单列修复，忽略列间依赖；
- IV：受算力限制，最大模型为 27B；
- V：采样可能漏掉罕见错误，示例选择也存在偏差。

阅读者分析：原文没有报告运行次数或方差，也没有报告 token 或延迟成本。
