# 解决的问题

**问题定义**（§4，p.4）：
- 输入：脏表 T 和分析目的 P（一个自然语言问题，例如“找出在最高风险等级下被检查的主要设施类型”）；
- 输出：清洗工作流 W_N 和清洗后的表 T_N = W_N ∘ T，要求在 T_N 上执行 P 能得到正确答案 A。

**迭代流程**（Figure 2，p.3；§4.1–4.3，pp.4–5）：
1. 选择目标列：确定与 P 相关的列，得到列表 L；
2. 检查列质量：生成数据质量报告，评估准确性、相关性、完整性、简洁性四个维度。时效性和一致性被排除：前者缺少时间戳，后者需要跨列规则，而 OpenRefine 以单列操作为主；
3. 生成操作与参数：从 upper、trim、numeric、date、mass_edit、regexr_transform 六种操作中选一个，生成参数后交给 OpenRefine 执行；
4. 循环，直到所有目标列的四个维度都为 True。

样本单位是“目的 + 表”。每个目的只关联一张表。

阅读者分析：这里的“目的”在形式上就是一个分析查询。清洗的范围由查询涉及的列决定，所以本质是查询驱动的局部清洗。

依据：[arXiv:2412.06724v3，15 页](https://arxiv.org/pdf/2412.06724v3)，§3–§4、Figure 2、Table 3，PDF pp.3–5。
