# 贡献与评价

**原文所述贡献**（§1，p.2）：
1. 三阶段 LLM 流程：选择目标列 → 检查列质量 → 生成操作与参数。作者称这是第一个全自动生成清洗工作流的方法（§8，p.9）。
2. 一个基准：包含目的、答案、原始表、人工清洗表和人工工作流，并在答案、列值、工作流三个维度上评测。
3. 对 Llama 3.1-8B、Mistral-7B、Gemma 2-9B/27B 的评测。

**阅读者分析**：
- 优点：输出是 OpenRefine 可复现的工作流，而不只是清洗后的表，因此便于审计；评测同时看答案、数据和过程三个层面。
- 局限 1：错误是人工注入的，只有四类（重复变体、格式不一致、大小写、类型错误），见 §5.1.1（p.6）。真实数据中的脏值分布可能更复杂。
- 局限 2：工作流金标只出自一位专家，作者明确称之为 silver standard（§5.1.3，p.6）。
- 局限 3：列值匹配公式中，δ 在“T 为数值”时直接记 1（Equation 2，p.7）。按字面理解，数值列不论是否与金标一致都算匹配，这会抬高 Column Ratio。原文没有解释这一点（阅读者分析）。
- 局限 4：唯一的 LLM 基线是一次性生成整个工作流的直接提示（DP），没有与 CleanAgent 等已有系统比较。

依据：[arXiv:2412.06724v3，15 页](https://arxiv.org/pdf/2412.06724v3)，§1、§5.1、§5.2.2、§8，PDF pp.1–2、6–7、9。
