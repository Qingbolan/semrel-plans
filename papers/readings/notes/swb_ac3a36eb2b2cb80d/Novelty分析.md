# 贡献与评价

原文主张的贡献：

1. 把匹配定义为“临床推荐”而非资格分类：输出分级类别、fit score 和结构化解释，并支持按站点配置的匹配策略。
2. 覆盖政府研究机构、患者倡导组织、学术中心和社区放疗的多中心回顾性评测，以及一项 6 个月前瞻性肿瘤委员会评测。
3. 发布 NIH-TrialBench：24 位研究者为 11 个 NIH 研究所/中心撰写 126 个合成病例，每个病例有一个预设目标试验。
4. 实际部署的 Web 界面，以及对 7 项负责任 AI 要素的设计对应（Fig. 1e）。

相较 TrialGPT 1.0，2.0 把逐条标准评估加聚合，改为单次试验级评估。公开基准上，平均 MAP 提升 10.2%，推理速度提高 3.20 倍，输入/输出 token 分别减少 58%/73%（PDF p.12）。

阅读者分析：主要新意在评测设计和临床推荐定位，模型本身仍是提示工程化的 LLM 管线。部分对比的条件不对等（见 benchmark 栏）；前瞻性评测只有单一站点 27 例。

依据：[arXiv:2609.01202v2，44 页](https://arxiv.org/abs/2609.01202)，Introduction、Results、Discussion，PDF pp.2–16。
