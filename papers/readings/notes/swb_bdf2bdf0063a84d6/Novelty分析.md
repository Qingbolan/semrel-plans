# 贡献与评价

原文声明的四项贡献：

1. 构建 10.8K 件美国集体诉讼起诉状数据集（2012–2022），带二元结果标签；作者称这是普通法系、英语中首个以原告诉状为输入的 PJP 数据集。
2. 用积分梯度（IG）和温度缩放分析模型可解释性与校准。
3. 在 200 件随机样本上收集法律专家预测，显示 Longformer 在准确率和校准上都超过专家。
4. 公开 3,000 件样本、专家标注与实验代码。

**评价（阅读者分析）**：主要新意在于输入设定（起诉状而非法院摘要）和领域（集体诉讼）。方法上只使用现成预训练模型微调，没有提出新模型。公开部分只有 3,000 件，全部 10.8K 不可得，因此表 2 的结果无法用公开数据完整复现。

**文中数字不一致（阅读者分析）**：§8 称最佳模型为 LegalRoBERTa、准确率 66.8%，但 Table 2 中 66.82 属于 Separated Allegations 下的 CaseLawBERT，LegalRoBERTa 为 65.97；Table 5 中 LegalBERT 与 CaseLawBERT 的准确率也与 Table 2 对调。Table 1 中 win 合计为 5,292，而 §4.3 写为 5,290（阅读者分析）。

依据：[arXiv:2211.00582v1，16 页](https://arxiv.org/abs/2211.00582)，§1 Contributions、Table 1、Table 2、§8、附录 B.3 Table 5，PDF pp.2–3、5–6、9、15。
