# 具体用例

原文的典型使用场景：律师或当事人在案件提起时只有原告起诉状，希望估计原告胜诉（和解或其他有利结果）的可能性。系统读取起诉状中的事实与指控，输出 win/lose 及置信度；经过温度缩放后，置信度可用于丢弃低把握预测。

**例**：§6.2 用 IG 分析 LegalBERT 时，模型在某份起诉状中最关注“flsa”（《公平劳动标准法》，涉及最低工资与加班），以及“work”“wages”等词。说明模型可能依赖法律领域（如劳动工资类案件）与结果之间的相关性；§8 也提到某些法律领域与特定标签强相关。

**人工对照**：200 件随机案件中，专家只看事实与指控，判断胜负并给出 1–5 级把握；作者确保他们不检索新闻或其他平台的结果信息。

阅读者分析：若项目把该数据用于语义过滤或分类算子，应保留“只用起诉状、不含元数据和背景信息”的输入边界和标签映射口径；按领域聚合可能获得较强信号，但这属于派生用途，原文未评测。

依据：[arXiv:2211.00582v1，16 页](https://arxiv.org/abs/2211.00582)，§6.1–6.2、Figure 5、§7、§8、Ethics Statement，PDF pp.7–10。
