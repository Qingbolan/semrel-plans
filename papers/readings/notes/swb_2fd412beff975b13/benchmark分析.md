# 评测与边界

**没有实验**：本文不含模型、基线、指标或结果表；Table 1 与 Table 2 只是数据规模统计。论文也没有报告标注一致性（IAA）、标注人数或审校流程，只提到英文转换中需人工判断的改动由 2–3 名标注者复核（§5.1，PDF p.7）。

**原文明确的难点与未完成部分**：

| 方面 | 内容（位置） |
|---|---|
| 汉语 | 无空格分词、形态贫乏、隐含代词与话语关系；动词复合词要按组合性、语法化程度、能产性分类处理（§4.2，p.5） |
| 阿拉帕霍语 | 若整词作谓词将产生成千上万很少复现的复杂谓词；词缀能由其他图结构表示时去掉，规范仍待细化（§4.3，p.5） |
| 纳瓦霍语 | 命名构式、呼格、移动描述中的施事/受事/客体区分困难（§4.4，pp.5–6） |
| 萨纳帕纳语 | 话语指示、省略的引述动词需补出 say 事件（§4.5，p.6） |
| 库卡马语 | 时体和复数标记可省略，初始标注须与语言专家复核（§4.6，p.6） |
| 指南 | 不能涵盖每种语言的全部细节，具体语言仍需补充约定（§6.1，p.9） |
| 扩展 | 英语转换、半自动构建、多模态均在进行中（§5，pp.7–8） |

阅读者分析：若把 UMR 作为基准使用，需要自行确定评测指标（如 AMR 常用的 Smatch 类图匹配，本文未提及）和数据划分；各语言规模不均且偏小，跨语言比较时要注意样本量差异（阅读者分析）。
