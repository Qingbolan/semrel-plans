# 解决的问题

**语料构建任务**（§3，PDF pp.4–8）：

| 要素 | 内容 |
|---|---|
| 输入 | 波斯语新闻社论/分析短文（经字符与词形规范化） |
| 输出 | 每篇文本一棵 RST 树（rstweb 导出的 XML），含 EDU 切分、span、核/卫星、关系标签 |
| EDU 单位 | 小句；仅含强篇章标记的短语也可成为 EDU |
| 关系集 | Carlson & Marcu (2001) 的粗粒度关系，Table 4 列出 18 个标签（含 Span、Same-Unit） |

标注规则包括：单核关系每次只合并两个单元（不允许 Fig.2 的一对多），不允许 S-N-S 结构；核性难判定时以“哪段应进入摘要”为准；同一 span 满足两种关系时选更具体（更少见）的关系，如 Cause 优先于 Elaboration（§3.2.2–3.2.4，p.8）。

**解析任务**（§4，pp.9、13–14）：

- 分割：二分类 SVM 判断每个 token 是否为 EDU 边界，特征为窗口 ±2 内的词、词性、依存标签及中心词方向。
- 解析：给定金标准 EDU，用 DPLP（移进-归约 + 大间隔 SVM + 表层特征投影）构建树，评测 span（S）、核性（N）、关系（R）F1。

阅读者分析：报告的解析分数建立在金标准切分上，不是端到端从原始文本解析的结果。
