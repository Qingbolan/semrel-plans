# 解决的问题

**任务输入**：一个 CSV 表格数据集（500 行，部分主题为两张表组合）、数据集概述/schema，以及一个标注者撰写的 SMART 目标，例如“分析各类别事件分配的不均衡”（§2.1.4、§3，PDF pp.5–6）。目标被设计为给出方向而不泄露答案。

**任务输出**：一组自由文本 insight（每条对应一个问题、代码与图）以及一段总结和行动建议（§2.1.4、§3.1，PDF pp.5–7）。

**参考答案**：每个数据集对应一个专家标注的 Jupyter notebook，含数据集概述、SMART 目标、逐步问题（每题带 Python 代码、图与 JSON 形式的 insight 元数据）及最终总结（§2.1.4，PDF p.5）。insight 分为描述性、诊断性、预测性、规范性四类（§2.1.2，PDF p.4）。

**评分单位**：两级。insight 级对每条 ground-truth insight 取与之得分最高的预测 insight，再对 |GT| 取平均（Eq.1）；summary 级比较预测总结与参考总结。评分器为 LLaMA-3-70b 版 G-Eval（称 LLaMA-3-Eval），同时报告 ROUGE-1；最后对 100 个数据集取平均（§2.2，PDF p.5）。

阅读者分析：Eq.1 只对每条 GT 取最大匹配，不惩罚多余或错误的预测 insight，因此该分数近似“召回”，不衡量精确率或幻觉。原文只在趋势强度实验中检查了“负斜率下是否误报”（§4，PDF p.9）。

依据：§2.1–2.2、§3、§4，PDF pp.4–9。
