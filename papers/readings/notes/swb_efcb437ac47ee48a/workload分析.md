# 工作负载

**来源**（§3，PDF p.2）：已有语料（如 SPACCC）以及 PubMed 摘要、SciELO、Pan African Medical Journal 中的临床病例。

**分层目标**（§3.1，p.2）：

| 层 | 规模（每语言） | 标注 |
|---|---|---|
| L1 | 约 25K token，约 80 篇 | 实体、时间、事实性全人工 |
| L2 | 50–100K token | 实体自动标注，约 10% 人工检查 |
| L3 | 约 1M token | 不标注，不必是临床叙述 |

L1 按长度平衡选文：短（<200 token）、中（200–400）、长（400–600），作者假设越长时间图越复杂。巴斯克语 L2（14K token）和 L3（600K token）只部分覆盖。

**各层文档数**（Table 1，PDF p.2）：

| 语言 | L1 | L2 | L3 |
|---|---|---|---|
| Spanish | 81 | 162 | 1,772 |
| Basque | 88 | 113 | 1,232 |
| English | 84 | 171 | 9,986 |
| French | 81 | 168 | 9,111 |
| Italian | 84 | 174 | 10,217 |

作者指出 L1 文档数也就是能构建的不同时间图（病程年表）数量（§3.1）。

**人员**（§4，p.3）：时间与实体指南分别由 3 人和 4 人专家组制定；8 人做时间标注，5 人做实体标注，写作时仍在进行。本文未给出标注后的实体、事件或关系数量。
