# problem

**输入**：自然语言问题 q、证据/外部知识（evidence）、关系数据库 D 及其模式（§1、Figure 2，p.2）。**输出**：一条 HRA 查询、其优化后的执行计划，以及执行得到的答案。

**查询生成**（Problem 3.1，p.4）：给定 q 与 D，构造由语义数据模型 S、问题分解 I、示例集 E 组成的提示，用 LLM M_q 取 φ̂ = argmax P(φ | q,S,I,E)。φ̂ 需满足三项正确性：语法有效（符合 HRA 文法且通过解析与模式一致性检查）、语义正确（φ̂(D)=φ*(D)，无 φ* 时人工检查或预设测试）、可执行（执行不报错）。

**HRA 与 LLM UDF**（Def. 2.1、Table 1，pp.3–4）：LLM UDF U^l_M 以自然语言表达式 l 和输入列 T[C] 构造提示，由模型 M 输出 y。UDF 可嵌入选择（布尔谓词）、投影（派生新列）、连接（行对布尔谓词）、TopK（成对比较器）和聚合（对一组行做语义汇总）。

**优化问题**（§4，pp.6–7）：查询计划为有根树；代价 = 关系算子代价之和 + 语义算子代价之和；单元算子代价 β_op×|T|，二元算子 β_op×f(|L|,|R|)；β 和选择率由工作负载采样初估，基数估计采用谓词独立假设。Problem 4.1（p.6）：给定计划与语义算子集合 M，找语义等价且代价最小的放置；论文称全局最优计划求解为 NP-hard，因此采用两阶段：先用标准关系优化（谓词下推、连接顺序）定骨架，再用代价算法放置 LLM UDF。

**工作单位**：一题一查询；优化以“语义算子集合在计划树中的放置”为单位；执行时语义算子以输入列的去重值为单位调用 LLM（选择/投影/连接/TopK，p.8），语义连接以“批对”为单位。

阅读者分析：系统把 LLM UDF 在等价验证中视为确定性的未解释函数（脚注 2，p.7），这是一个明确的建模假设；实际 LLM 输出随批大小、提示变化，等价只在符号层面成立。
