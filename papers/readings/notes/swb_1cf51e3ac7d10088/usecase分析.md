# 具体用例

**报告给出的用例**：采购政策分析人员想了解葡萄牙能源采购市场是否竞争充分，以及竞争是否影响价格（pp.1–8）。

1. **门户概览**：在 ProACT 中筛选“石油产品、燃料、电力及其他能源”市场，看到 11,297 份合同、透明度 77、诚信 50（Fig.1）。
2. **下钻子市场**：按支出与合同数比较三个子市场，发现电力类为少量高价值合同，燃料类为大量小合同（Fig.2）。
3. **看集中度**：查看前列供应商与买方份额，最大供应商仅占 4.74%，集中度低（Fig.5）。
4. **看竞争**：单一投标占 57.92%，98% 合同给本国供应商（Figs.6–7）。
5. **网络视图**：随机选取 BP Portugal，查看其 17 个买方的收入分布（Fig.8）。
6. **下载数据回归**：门户不支持回归，下载合同级数据后在控制地区、买方类型、合同规模、年份、CPV 子市场后，估计相对价格与投标人数、供应商份额的关系（Figs.10–11、Annex）。

**报告对“低集中度却低竞争”的解释**（pp.6–7）：市场在地理或产品子组上高度本地化，每个本地市场只容纳少数企业，单笔交易竞争弱，但没有企业能占据全市场高份额。

阅读者分析：在语义数据处理场景中，这对应“按 CPV 编码过滤合同 → 按供应商/买方聚合 → 与投标人数、估计价格连接后建模”的结构化分析流程；关键难点在于跨合同的供应商身份对齐与价格字段缺失，报告结论也强调这两类数据的重要性（阅读者分析）。
