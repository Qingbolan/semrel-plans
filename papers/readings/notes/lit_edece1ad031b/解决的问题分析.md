# problem

评测单位是一个 session S = {D, Q, H0}：D 为数据集，Q = {q1,…,qn} 为逻辑相连的子问题序列，H0 为初始上下文（§3.2，p.4）。智能体每步根据当前问题、历史与上一步观测生成思考与 Python 代码；沙箱执行后返回多模态观测 o_t = {文本日志, 表格/DataFrame 预览, 生成图像}，内核状态在整个 session 内保持（p.4）。

输出为两件产物：完整代码 Notebook N 与文字报告 R。评委模型 J 将 (N, R) 与软参考答案 G（由 GPT-5、Grok-4 从源 notebook 合成的问题–推理–答案三元组）比较，按 S_overall = 0.3·S_reason + 0.3·S_code + 0.4·S_result 打分；结果维度明确接受与参考不同但合理或更优的解法（§3.3，p.5）。分数尺度为 0–10（附录 K 以“最终分低于 10”定义不完美轨迹，p.34）。

运行约束：每 session 最多 20 轮交互、每轮 1 小时超时，沙箱配 4 张 A100 80GB（§4.1，p.6）。

依据：[arXiv:2601.13591v3，35 页](https://arxiv.org/pdf/2601.13591)，§3.2–3.3、§4.1，PDF pp.4–6。
