# 评测与边界

**实验 1（可接受性）**：娱乐工具中，低素养诊所认为信息"多于想要"的比例为 40.0%，高素养诊所为 8.8%；认为"太长"的分别为 10.8% 与 42.6%（Table 3）。在低素养诊所内，小册子的清晰度评分高于娱乐工具（χ²(3)=9.75，P<.05），但两种工具都有 90% 以上的人认为大部分或全部清楚（§3.2）。

**实验 2（参与度，仅娱乐组）**：0–100 分，低素养对高素养诊所为肥皂剧 90.2 对 80.3（P=0.002）、价值澄清 97.7 对 80.9（P<0.001）、名人陈述 96.1 对 87.9（P=0.006）、总体观感 69.3 对 66.3（P=0.510）（Table 4）。

**实验 3（知识，主要结局）**：两个诊所的知识都显著提高，两种工具之间无显著差异；正文没有给出知识得分的数值表（§3.4）。

**原文承认的局限**（§4.2）：仅两个诊所，泛化受限；低素养诊所随访率约 60%，完成随访者更倾向筛查，可能放大效应；娱乐工具更长，无法拆分成分作用；名人参与可能被理解为背书；未对个体测量素养；不能排除其他诊所间因素。§4.3 还指出工具可能太长，不适合在就诊前立即使用。

原文对完成随访者年龄的描述在 §3.1 与 §4.2 中自相矛盾，按 Table 2 实为完成者更年长，详见工作负载页（阅读者分析）。
