# 贡献与评价

**原文声称的贡献（§1，PDF p.2）**：
1. 第一个面向复杂真实科学数据库、由领域专家参与验证的 NL-to-SQL 基准；
2. 面向几乎无训练数据数据库的自动训练数据生成方法；
3. 评测 3 个 SOTA NL-to-SQL 系统和 2 个 LLM，显示其准确率只有约 25–60%。

与已有工作的区别：已有增强方法多限于单表、模板或 RNN 生成；本文在多表数据库上用 AST 模板加大模型回译生成更流畅的问题（§6.1，PDF pp.11–12）。与 BIRD 相比，本文库数更少，但单库的表数和规模更大，原文称二者互补（§3.1，PDF p.3）。

**阅读者分析（评价）**：
- 基准的价值主要在三个高复杂度真实库和专家 Dev 集，但每库只有 100 条 Dev 问题，统计功效有限；
- 合成数据的复杂度低于人工数据（§3.4），OncoMX 的合成集没有 Hard 和 Extra Hard；
- 引言称基准含“超过 6,000”对，按 Table 1 计算为 3×200 人工 + 1,306 + 2,061 + 1,065 合成 = 5,032 对，二者不一致（阅读者分析）。
