# 出发点

LLM 不仅有显式上下文长度上限，而且即使输入未超限，性能也会随长度增加而下降，并容易受无关信息干扰（§1，p.1；§2，p.2）。

作者借用模糊痕迹理论（fuzzy-trace theory）：人会很快忘记逐字信息，却长期保留“要点”记忆；阅读又是交互式的，需要细节时会回去翻原文（§1 与脚注 1，p.1）。用全局的要点记忆把握整体、再针对局部细节回查，被认为是人类高效处理超长文本的方式（§1，pp.1–2）。

因此 ReadAgent 只用提示实现三步：分页（决定哪些内容存为一个记忆片段）、要点化（压缩每页）、交互回查（按需读原文页）（§1，p.2）。

阅读者分析：该出发点与 RAG 的区别在于“由 LLM 在全局要点上下文中推理该取哪页”，而非用独立的相关性打分器；论文也指出，这种做法适合页面之间相互关联的长文档，但要点记忆本身受上下文长度限制，不能像常规检索那样扩展到任意大的库（§2，p.2）。

依据：§1–§2，PDF pp.1–2。
