# 出发点

短视频平台每天新增大量视频，有害内容对用户尤其是未成年人的心理健康构成威胁。作者归纳现有审核的三类不足（摘要、§1，PDF pp.1–2）：

- **人工审核**：成本高，审核员承受心理负担并带有个人偏差。
- **自动方法**：关键词规则和小分类器理解力不足；基于 LLM 的方法难以处理复杂多模态内容，更难从用户视角评估视频。
- **规则更新慢**：平台规则体系类似"大陆法"，依靠穷举条文，难以跟上由社会事件驱动的快速变化的趋势。

此外，工业部署要求在百万级日活和新增视频上同时保证准确率和成本，先前研究缺少真实平台部署验证（§1，PDF p.2）。作者还指出该领域缺少带真实用户反馈的短视频审核基准（§1 贡献列表）。

"判例法"类比：以不断累积的案例而非静态条文决定是否违规，案例代表共识并随社会演进（§1，PDF p.2）。

阅读者分析：所谓"VLM as Policy"指把审核模型视作强化学习中的策略，策略随用户反馈更新，而非指政策文本。

依据：摘要、§1，PDF pp.1–3。
