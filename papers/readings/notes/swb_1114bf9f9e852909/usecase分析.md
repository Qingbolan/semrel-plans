# 具体用例

附录 Figure A-2c（PDF p.19）给出一个违规案例的完整 5 状态推理：

1. **内容抽取**：两名穿迷彩服的男子到一名未成年人家中，使用暴力后将其带上车，疑似送往军事化管理学校。
2. **内容分析**：标题带有"#军事化管理学校""#叛逆孩子学校"等标签，OCR/ASR 讲述育儿困难与工作人员上门带走男孩的过程。
3. **中期检查**：疑似虐待儿童，需要参考用户评论。
4. **用户反馈分析**：评论中有冒犯和侮辱性言论。
5. **最终总结**：判定为"虐待儿童"（Child Abuse）。

Figure A-3（PDF p.20）给出对照的正常案例：户外徒步、健身舞蹈视频，各状态均未发现问题，标为"正常"。

线上使用分两种（§6.2，PDF p.12）：在 NEBULA 与 Featured 中，对被举报超过 5 次的视频由 KuaiMod 判别，违规者停止推广；在主站中，KuaiMod 的判决作为推荐特征，实现"个性化审核"，只有部分类型允许个性化保留，明显违法或严重有害的仍被严格过滤。

阅读者分析：从语义算子视角，这是对多模态记录（帧 + 文本 + 评论）做细粒度语义分类，并输出可审计的推理链；中期检查决定是否读取评论，相当于按需扩展上下文。

依据：§6.2，附录 A.2，Figures A-2c、A-3，PDF pp.12、18–20。
