# 贡献与评价

**原文声称的贡献（§1，PDF p.3）**：

1. 首个带真实用户反馈的短视频审核基准，去除隐私和非法内容后开源。
2. "判例法"式审核框架：以案例驱动策略，可按用户反馈每日更新，准确率与人工审核相当且超过所有基线。
3. 工业部署：多个场景 A/B 测试中举报率下降约 20%，并在推荐中提升 DAU。

**技术要点**：Tag2CoT（已知标签，让 20B 模型解释为何违规）+ CoT2Tag（把解释重组为从元数据到标签的 5 状态推理流程）；离线 SFT + 以错误为导向的 DPO；线上以模型与用户反馈冲突的样本做 DPO 迭代（§4.2–4.4）。

**阅读者分析**：

- 基础模型 YuanQi 为快手自研，消融显示换成 Intern-VL 准确率从 0.9240 降到 0.8980，因此部分优势与私有基础模型相关，外部难以复现训练流程。
- 训练数据 24,562 条与测试集来自同一平台、同一采样和标注流程，基线中 API 方法（Perspective、GPT-4o）未经该数据训练，对比并不对称；作者也将其解释为"实时更新的重要性"。
- "RLUF"实际是用人工复核后的偏好对做 DPO，并非在线强化学习；奖励（举报率）不直接进入损失。
- 线上 A/B 只报告相对变化，未给出置信区间或显著性检验。

依据：§1、§4–6，Tables 2–5，PDF pp.2–12。
