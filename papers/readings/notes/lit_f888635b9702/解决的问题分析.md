# 解决的问题

目标：给定一个解码器式语言模型 M（GPT-3.5、ChatGPT），构造训练数据继续训练得到 TableTune(M)，使其在多种表格任务上优于 M，且能按自然语言指令完成训练中未出现的新表格任务（§4.4，p.10）。

**工作单位**：一个表格任务实例 t =（Ins, T, C），Ins 是自然语言指令，T 是输入表（以 Markdown 序列化），C 是期望完成，可以是 JSON 文本、表格或二者组合（Definition 1，p.5）。训练时把序列化的（Ins, T）当 prompt、C 当 completion，最小化语言模型损失（§4.4，p.10）。

**“更好的表格基础模型”的判据**：在四种场景下都优于 M——开箱零样本、开箱随机少样本、单任务提示工程、单任务微调（§4.4，p.10）。

**输入/输出边界**：输入是单张表或两张表（如实体匹配、模式匹配），输出为单元格位置、列名、类型、SQL、表格等。论文不处理多表数据库检索或大表超出上下文的情况；测试表大小未在正文统计（阅读者分析：从附录样例看多为小表，此判断未经全量核对）。

依据：Definition 1、§4.4、Table 2，PDF pp.5–6、10。
