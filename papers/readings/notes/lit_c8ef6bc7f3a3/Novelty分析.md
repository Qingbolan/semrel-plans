# 贡献与评价

作者自述贡献（§1）：
1. 论证仅用合成公开数据不足，引入四个含真实人工缩写的非公开/企业/科学数据集（Finance、University、AW、EDI）；
2. 提出同义词感知 EM（及相应 F1、BERT-F1）：作者从五个数据集中人工整理同义词对，生成金标准变体，预测匹配任一变体即算对（§4）；
3. Columbo 由三个模块组成：
   - Summarizer：让 LLM 每批 k=30 张表做聚类并给出组摘要与表摘要，再全局合并同摘要组；
   - Generator：每批 p=10 列，提供目标表名及同组最多 q=100 张表的名称与摘要、9 条规则和 token 级 CoT；
   - Reviser：找出有多种扩展的 token（如 dt→date / dt→data），把组摘要、各规则频次与示例 schema 交给 LLM 判定是否应统一（单字符 token 不送审）（§5）；
4. 实验显示五个数据集上全面优于 NameGuess，并已在 EDI 生产使用。

方法是精心设计的提示流水线而非新模型；同义词表由作者根据数据集自行构建，新指标与评测数据同源，可能对所有方法都偏宽松，论文未报告同义词表规模或独立核验。两个企业数据集（Finance、University）不可公开，限制了复现（阅读者分析）。

依据：[Cai, Sheen & Doan，arXiv:2508.09403v3，19 页](https://arxiv.org/abs/2508.09403)，§1、§4–§5，pp.2–6。
