# 具体用例

以电子表格 Deepening 为例（§3、§4.2，pp.4–8）：起点是 Anthropic 官方 xlsx skill。Qwen3.5-122B agent 带着该 skill 在 200 道 SpreadsheetBench-Verified 演化题上各运行一次，产生成功和失败轨迹。

失败轨迹交给错误分析者：它可以打开产出的 xlsx 文件、对照标准答案、尝试修复并验证，再写出针对 skill 的补丁；成功轨迹交给成功分析者，总结可复用行为。随后，所有补丁每 32 个一组分层合并。

据 §4.2，122B Deepening +Combined 一次运行的 323 个 map 补丁中，有四条 SoP 占主导，每条被 16%–55% 的补丁引用。例如：写入后重新计算并回读公式、提交前核对目标单元格、按不会破坏数据的顺序删除行。任务特有的细节被放到按需加载的 `references/` 文件中。

得到的 skill 在 122B 用户的 200 道测试题上 Vrf 从 48.33 升至 69.83（+21.50，Table 1/Table 5）。

阅读者分析：把这一流程用于语义算子或数据处理管线，需要先有可自动判定的任务正确性；原文没有涉及此类场景。
