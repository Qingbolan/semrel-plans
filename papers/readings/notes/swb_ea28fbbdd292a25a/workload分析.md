# 工作负载

**来源**：regulationroom.org 上与 CFPB 合作讨论的 CDCP 规则评论。自愿调查显示约 64% 来自消费者、22% 来自催收方，其余来自消费者权益组织等（§4，p.3）。

**标注流程**：每条评论由两名标注者用 GATE 独立标注，第三人裁决冲突（§4）。一致性 Krippendorff α：单元类型 64.8%，支持关系 44.1%（关系以被支持单元 ID 作为标签计算）。

**规模**（Table 2，731 条评论）：

| 类型 | 数量 |
|---|---|
| POLICY | 815 |
| VALUE | 2,182 |
| FACT | 785 |
| TESTIMONY | 1,117 |
| REFERENCE | 32 |
| 基本单元合计 | 4,931 |
| Reason | 1,174 |
| Evidence | 46 |
| 支持关系合计 | 1,220（正文写 1,221） |

**分布特点**（§5，pp.4–5）：约 45% 单元为 VALUE；51% 的 POLICY 有支持，VALUE 仅 28%；约 75% 支持关系发生在相邻单元之间。论文未给出数据划分，也未说明评论平均长度。

依据：[LREC 2018，ACL Anthology L18-1257，6 页](https://aclanthology.org/L18-1257.pdf)，§4–5、Table 2、Figure 2，PDF pp.3–5。
