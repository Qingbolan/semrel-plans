# 解决的问题

形式化问题 CASQO（Problem 8.1，p.17）：给定查询 Q、数据库 D、目标 T=(ρ,γ,δ)、带价格的决策模型集合和策略类 C，在与 Q 预言机等价的逻辑计划 L 和策略 Π∈C 上最小化期望成本，约束为 (L,Π) 满足输出级目标。

| 要素 | 定义（原文） |
|---|---|
| 查询语言 | 语义关系代数 SRA：正关系代数加语义选择、语义连接、语义投影（分类）、语义排序；聚合与否定延后（Def 2.2） |
| 正确答案 | 预言机语义 Q*(D)：所有语义算子用其预期解释求值（Def 2.3） |
| 物理计划 | P=(L,Π)，Π 对每个决策实例选择 Accept/Reject/Escalate/Skip（Def 3.4、3.6） |
| 工作单位 | 决策实例 (s,κ)：语义算子及其读取的属性值；同一逻辑等价计划呈现的实例多重集不同（Def 3.1、Ex 3.2） |
| 质量 | 相对 Q*(D) 的输出级召回/精确率（bag 默认，set 为变体，Def 4.1）；预测质量由 Σ c_i(1−conf_i) 计算（Def 4.2） |
| 成本 | 模型调用价格×token 加关系算子成本（Def 3.7） |

变体包括算子级与实例级分配、判官相对与预言机相对目标、期望与高概率约束（§8）。

阅读者分析：这里“查询”是带语义谓词的 SPJ 查询，目标是同时决定逻辑计划与逐元组动作，而不是只给每个算子一个阈值。

依据：[arXiv:2610.08089v2，31 页](https://arxiv.org/abs/2610.08089)，§2–§4、§8，PDF pp.4–8、17。
