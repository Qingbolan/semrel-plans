# 评测与边界

本文不设基线，不报告自有指标或结果；以下几点是综述转述的评测相关事实。

- 半结构化分析：作者称 TEMPTABQA、SPREADSHEETBENCH 等基准显示现有方法存在较大差距（§1.2，PDF p.4），具体数值需查阅原基准论文。
- 效率：现有基于 LLM 的查询优化器每个查询需数分钟，而传统统计方法为毫秒级（§4.2.4，PDF p.47）。
- 数据评估：数据集质量往往只能在训练模型后间接判断；已有工作提出可靠性、难度、有效性三个维度，作者认为仍不完整（§4.1.4，PDF p.46）。
- 开放问题：统一的多类型数据分析系统；私有领域知识；非序列/非文本数据的表示（例如表格被拉平成序列会丢失行列关系，基数/直方图等统计信号被忽略）；预算约束下的 LLM 使用，例如 LLM 与传统技术混合或在多个模型间按成本调度（§4.2，PDF pp.46–47）。

阅读者分析：综述没有统一的比较口径，不同方法的结果来自各自论文的不同数据与设置，不能横向排名。引用本文时应把它当作文献地图，而不是实证证据。
