# 解决的问题

这是综述，不定义单一计算任务；“工作单元”是一套二分法分类体系。

| 方向 | 子领域 | 输入 → 输出（按综述描述） | 位置 |
|---|---|---|---|
| DATA4LLM | 数据处理：采集、去重、过滤、选择、配比、蒸馏/合成、端到端流水线 | 原始语料 → 适合各训练阶段的数据集 | §2.3，pp.8–24 |
| DATA4LLM | 数据存储：格式、分布、组织（向量/图 RAG 索引）、移动、容错、KV cache | 数据/模型状态 → 存储与访问方案 | §2.4，pp.24–31 |
| DATA4LLM | 数据服务：shuffling、压缩、packing、provenance | 训练/推理输入 → 选择、排序、压缩后的输入 | §2.5，pp.31–34 |
| LLM4DATA | 数据操作：清洗（标准化、纠错、补全）、集成（实体/模式匹配）、发现（profiling、标注） | 表或数据集 → 清洗后数据、匹配关系、元数据 | §3.1，pp.34–38 |
| LLM4DATA | 数据分析：关系表（NL2SQL、NL2Code、多步 QA、端到端 QA）、图（NL2GQL）、半结构化、非结构化（文档、程序） | 自然语言问题 + 数据 → 查询/代码/答案 | §3.2，pp.38–43 |
| LLM4DATA | 系统优化：参数调优、查询优化、异常诊断 | 负载与系统状态 → 配置、改写、根因 | §3.3，pp.43–45 |

§2.2 与 Table 1 还按预训练、增量预训练、SFT、RL、RAG、推理和评估等阶段，给出了各类技术是否已有报道（✓/×/N/A）（PDF pp.6–7）。
