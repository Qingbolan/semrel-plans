# 贡献与评价

原文主张的贡献（§1.3，PDF p.5）：
1. 提出 IaaS 概念，把 LLM 数据质量拆成包容性（领域、任务、来源、语言、模态覆盖）、充足度（规模与配比）、表达性（格式规范、指导性、逐步推理）和净化性（隐私、去毒、伦理、风险）四个维度（§2.1，PDF p.6）。
2. 按 LLM 生命周期分析各阶段的数据特征（Figure 2）及技术对照（Table 1）。
3. 按处理、存储、服务给出 DATA4LLM 的分类，并与只关注去重过滤、数据选择或数据标注的综述作对比。
4. 整理 LLM4DATA 的进展，覆盖面超出此前“经典 ML 用于数据管理”的综述。
5. 提出两侧的开放问题。

阅读者评估：本文的贡献在于覆盖面和组织方式，没有新算法或新实验。IaaS 是定性框架，文中没有给出可计算的指标或验证。Table 1 的 ✓/×/N/A 是作者对文献的判断，无法逐格复核。按关键词检索提取文本（阅读者自查），正文未提及 LOTUS、Palimpzest、DocETL 等语义算子系统；LLM4DATA 的分析部分以 NL2SQL、表格 QA、文档/程序分析为主，未将语义算子查询处理作为独立类别。
