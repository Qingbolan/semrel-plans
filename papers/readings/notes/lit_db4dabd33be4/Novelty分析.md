# 贡献与评价

**论文自述贡献**（§1，p.2）：

1. LLM 为中心的数据库运维框架；
2. 数据收集机制：从文档抽取经验、用匹配算法接入外部工具；
3. 结合 LLM 与树搜索的根因分析；
4. 多 LLM 协作诊断；
5. 初步实验表明 D-Bot 能高效、有效地诊断根因。

**评价**：各组件多为既有技术的组合，作者也分别引用了来源：工具检索用 BM25/稠密检索，树搜索用 UCT 公式，提示生成借鉴 LLM 自动提示工程（Zhou et al. 2022），多智能体通信引用 AgentVerse 和 ChatDev 类工作（§5–8，pp.4–5）。

阅读者分析：贡献主要是把文档经验抽取、工具调用、树搜索与多智能体组合用于数据库诊断这一问题设定，并给出具体的经验格式。第 5 点"高效"在正文实验中没有任何时间或成本数据支撑。§5 提示生成中的评分函数、抽取经验的总量、所用文档的范围（仅提到"100 多页的维护指南"）均未量化，难以复现。论文结论也自称"vision"，并说会继续完善（§10，p.7）。

依据：§1、§4–8、§10，PDF pp.2–7。
