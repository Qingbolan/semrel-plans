# 解决的问题

本文包含三个子任务（§1 贡献列表，p.1）：

**1. 语义类型标注**：输入为 AAE 中已标注好的论证成分（ADU）及其所在段落与作文上下文；输出为每个 claim 的类型（policy / value / fact，层级 policy > value > fact）和每个 premise 的类型（testimony / statistics / hypothetical-instance / real-example / common-ground，另有 other；按此顺序取优先级）。标注单位是逐段落的单个 ADU（§3.2–3.3，pp.2–4）。

**2. 自动分类**：输入仅为 ADU 文本片段，不含上下文；按 ADU 类型（major claim、claim、premise，以及合并的 major claim+claim）分别训练分类器，输出语义类型（§4，p.5）。

**3. 模式分析**：把作文中的语义类型按文本位置线性化为 semantic flow，再合并连续重复得到 semantic change flow；在段落级（首段/中段/末段）和全文级（仅 claim）统计最常见的流，并分析 claim 与其直接支持 premise 的类型搭配、题目（prompt）类型与作者个体对 claim 类型分布的影响（§5，pp.6–8）。

阅读者分析：模式分析使用的是人工标注，不是分类器预测；分类实验与模式分析是两条独立线索。
