# 贡献与评价

**原文主张的贡献**（§1，p.2；§4，pp.3–5）：

1. 首个面向企业场景的 CI 智能体评测，按组织沟通分类给出五个信息流方向：向下、向上、横向、斜向（跨部门）、对外。
2. 构建流程：人工种子 + Gemini-3-Pro 扩写并有人实时把关；单次生成全部必要/敏感条目后，用"盲分类—批判—改写"的自迭代修正（Algorithm 1）让条目标签与意图一致。
3. 轨迹模拟器基于 ToolEmu 与 PrivacyLens 改造，可同时实例化多条条目，并允许把敏感原子与无害内容混写进同一份工件（如会议纪要）。
4. 实证发现：效用与泄露正相关；用户施压造成"隐私与效用双降"；GPT-4.1 系列中模型越大泄露越多（作者称为 inverse scaling）；提升推理强度收益很小（§5.1–5.4，pp.5–7）。

**阅读者评价**：

- 新意主要在领域（企业层级）与评测设计（多条并行条目、同时量化效用），方法组件多沿用 PrivacyLens/ToolEmu。
- 生成与评测都使用 GPT-5.2（§4.5，p.5），评测数据、情节和工具观察均为合成，存在同一模型族"自出题自判卷"的风险；人工验证覆盖 20% 用例（附录 C，p.12）可部分缓解。
- inverse scaling 的结论只基于 GPT-4.1 nano/mini/full 三档（§5.4，p.7），作者的两点解释（小模型召回不足、大模型更谄媚）未被单独实验验证（阅读者分析）。
- Table 1 中写的是 Grok-3，而附录 B（p.12）列出的是 Grok-4，原文前后不一致（阅读者分析）。
