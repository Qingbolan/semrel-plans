# Fu et al. — CI-Work: Benchmarking Contextual Integrity in Enterprise LLM Agents

CI-Work 是一个以情境完整性（Contextual Integrity, CI）理论为依据的企业 LLM 智能体隐私评测：在模拟的邮件、聊天、日历等企业工具中，智能体需要把"必要条目"传递给收件人，同时不泄露同时检索到的"敏感条目"。在 125 个种子、1,000 条情境条目上，9 个前沿模型的违规率为 15.80%–50.87%，平均泄露率最高 26.66%，且传递率越高往往泄露越多。已阅读正文 §1–§6、伦理声明及附录 A–E、G 与部分提示模板；未逐例审阅附录 I 的定性样例。
