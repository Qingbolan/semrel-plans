# 评测与边界

**Q1 错误率**（§4.3，PDF pp.5–6）：BIRD Mini-Dev 263/498 = 52.8%（含 Arcwise 已报告的 161 例），比 Arcwise 报告的 32.3% 高约 20.5 个百分点；Spider 2.0-Snow 76/121 = 62.8%。

**Q2 对排行榜的影响**（§5.3–5.5，PDF pp.8–10；Table 9，p.18）

| 智能体 | 原子集 EX / 排名 | 修正子集 EX / 排名 |
|---|---|---|
| Contextual-SQL | 73 / 1 | 71 / 7 |
| OpenSearch-SQL | 71 / 2 | 69 / 11 |
| GSR | 66 / 4 | 68 / 13 |
| CHESS | 62 / 7 | 81 / 1 |
| GenaSQL | 64 / 6 | 81 / 1 |
| MAC-SQL | 58 / 14 | 75 / 5 |
| SFT CodeS-15B | 56 / 15 | 52 / 16 |

- 16 个中 12 个 EX 上升；平均每个智能体 16.4 例由错转对、8.0 例由对转错；排名平均变化 5 位。
- 原子集排名与完整 Dev 排行榜相关 r_s=0.85（p=3.26e-5），说明 100 例抽样有代表性；原子集与修正子集排名相关仅 r_s=0.32（p=0.23）。

**消融（§7，Figure 11，PDF pp.11–12）**：修正子集有/无数据库修改的排名相关 r_s=0.95；与"仅用 SAR-Agent 修 SQL"相关 0.73，与"仅由人工按原问题修 SQL"相关 0.59——说明只修 SQL、不修问题与外部知识不够。

**Q3 SAR-Agent 效果（Table 7、Figure 10，PDF p.11）**：BIRD Mini-Dev 标出 274 例，核验 228 例属实，精度 83%；Spider 2.0-Snow 标出 79 例，70 例属实，精度 89%；Arcwise 161 例中检出 138 例（命中率 85.7%），总检出数比 Arcwise 多 41.6%；平均成本 $0.44/5.1 步（BIRD）、$1.11/7.6 步（Spider 2.0-Snow）。

阅读者分析的局限：
- 只报告精度，没有报告召回：未被 SAR-Agent 标出且未被补充检查覆盖的错误无从得知，52.8%/62.8% 更接近下界。
- 修正子集仅 100 例，一例即 1 个百分点，多个智能体 EX 相同而并列；论文未给出 EX 的置信区间。
- 部分智能体未按排行榜原配置运行：TA-SQL、MAC-SQL、DAIL-SQL、DIN-SQL 因预算用 GPT-4o 替代 GPT-4，CHESS、GenaSQL 因云平台访问限制改用 GPT-4o（Table 8 脚注，PDF p.17）。
- 错误判定与修正由作者完成并以与 SAR-Agent 达成一致为终止条件，缺少独立第三方标注者与一致性统计（如 Kappa）。
