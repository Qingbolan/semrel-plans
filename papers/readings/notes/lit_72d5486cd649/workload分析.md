# 工作负载

**审查对象**（§2.1、§4.1，PDF pp.3、5）

| 基准 | 规模 | 说明 |
|---|---|---|
| BIRD Mini-Dev | 500 例 SELECT-only，去重后 498 例 | BIRD 团队从 Dev 集挑选的官方子集；因 Mini-Dev 自带数据库行数较少，实验改用 BIRD Dev 的数据库；排行榜方法数最多（100 个） |
| Spider 2.0-Snow | 547 例，其中 121 例公开金标准 SQL | 只审查这 121 例；使用 2025-08-20 版本的金标准（该团队于 2025-10-29 更新过）；金标准 SQL 平均 161.8 个 token，六个基准中最复杂 |
| BIRD Dev 子集 | 随机 100 例（简单 62、中等 28、困难 10），取自 1,534 例 Dev | 用于修正与重评 |

**错误分布（Table 1，PDF p.5，单例可属多类）**

| 类型 | BIRD Mini-Dev（263 个错误例中） | Spider 2.0-Snow（76 个错误例中） |
|---|---|---|
| E1 | 77（29.28%） | 37（48.68%） |
| E2 | 152（57.79%） | 44（57.89%） |
| E3 | 28（10.65%） | 9（11.84%） |
| E4 | 78（29.66%） | 18（23.68%） |

**修正统计（Table 4，PDF p.8）**：100 例中修正 48 例；其中改问题 19、改外部知识 17、改 SQL 41、改模式 1、修改数据库 6（插入区分性记录，使错误 SQL 不再碰巧得到正确结果）。

**被评测的 16 个智能体**（§5.2，Table 8，PDF pp.8、17）：Contextual-SQL、CSC-SQL、GenaSQL、OpenSearch-SQL、OmniSQL、CHESS、Alpha-SQL、GSR、RSL-SQL、E-SQL、TA-SQL、DTS-SQL、MAC-SQL、SFT CodeS-15B、DAIL-SQL、DIN-SQL（以 2025-08-20 排行榜为准，限可本地复现者）。

阅读者分析：工作负载单位是"一个 (问题, 金标准 SQL, 数据库) 三元组"。对于本项目引用 BIRD/Spider 2.0 的查询，这篇论文提示：以执行结果为金标准时，约一半样例可能本身有误，且 E2（对数据/模式理解不足）最常见。
