# 贡献与评价

**原文贡献**（§1，PDF p.2）：
1. 经 SQL 专家深入人工审查，得出 BIRD Mini-Dev 52.8%、Spider 2.0-Snow 62.8% 的标注错误率；
2. 在原始与修正后的 BIRD Dev 子集上重评排行榜上全部 16 个开源智能体，发现相对表现变化 −7%～31%、排名变化 −9～+9；
3. 发布 SAR-Agent 与 SAPAR 工具链用于检测与修正标注错误；另外发布两个修正版 Mini-Dev（Arcwise-Plat-SQL 只修 SQL、保留问题歧义；Arcwise-Plat 同时修正 SQL 与歧义）（§6，PDF p.10）。

**与已有工作的关系**：Arcwise 已经对 BIRD Mini-Dev 做过人工审计（161 个错误例），本文在其基础上扩展；本文称是首个全面审查 Spider 2.0-Snow 的工作，也是首个辅助专家发现 Text-to-SQL 标注错误的 AI 智能体（§1、§8，PDF pp.1–2、12）。附录 A.4 还显示 Spider 2.0 团队 2025-07-13 的问题改写只把错误率从 66.1% 降到 62.8%，且改写本身会引入新错误（Figure 14，PDF p.16）。

阅读者分析：
- 最大的价值在于把"标注错误"从错误率统计推进到"排行榜排名是否可信"的定量证据，这比单纯报告错误率更有说服力。
- "SQL 专家"实际上是论文作者本人；修正过程要求"与 SAR-Agent 达成一致"（最多三轮，§5.1，PDF p.8），存在修正结果偏向 SAR-Agent（o3）解读的可能。正文的 52.8% 也不是 SAR-Agent 单独检出的比例，而是 SAR-Agent 确认的 228 例、补充人工检查与 Arcwise 结果的并集（263 例）。
- 标题"破坏排行榜"的主证据来自 100 个样例，因此结论更适合理解为"排名对标注高度敏感"，而非对完整 Dev 集排名的精确重排。
