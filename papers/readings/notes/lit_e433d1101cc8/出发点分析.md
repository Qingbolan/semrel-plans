# 出发点

作者认为机器学习研究进展的核心是实验迭代：设计方法、运行实验、分析结果、再改进。这一过程要求研究者具备大量方法先验、能写出可运行代码并能解读实验结果，门槛很高。NAS 与 AutoML 已自动化了其中部分环节；LLM 能理解并生成文本与代码，为端到端自动化实验提供了新可能。

核心问题是：由强 LLM 驱动的智能体能否有效完成 ML 实验？作者称 MLAgentBench 是首个评测这种能力的基准。设计上强调三点：任务目标明确且可自动评测；执行代价低（单次实验在分钟量级）；同时纳入发布于 LLM 训练之后的 Kaggle 挑战与研究数据集，以检验泛化并缓解数据污染。

作者也强调可解释性：虽然以自动化来表述，但智能体的计划与行动应可供人理解，以便研究者介入、修改工作区或计划。
