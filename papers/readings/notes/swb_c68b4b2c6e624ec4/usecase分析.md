# 具体用例

**例子：2017 年个税计算**（Figure 1，PDF p.2）。案情：Alice 2017 年收入 $36,266，自 2017 年 2 月 3 日与 Bob 结婚，Bob 当年无收入，二人分开申报。相关法条包括 §151(b) 配偶免税额（配偶零收入、不是他人受抚养人、且未联合申报时可申请）与 §63(c) 基本标准扣除（夫妻分开申报等“其他情形”为 $3,000）。

符号工作流分三步：（1）模型阅读完整问题上下文，识别并应用相关规则；（2）把法条写成 Prolog 规则，如 `spouse_exemption_allowed(Taxpayer,Year)`，把案情写成事实，如 `filing_status(alice,2017,married_separate)`；（3）由 SWI-Prolog 执行，得到 “Alice Has to Pay $5460 in 2017”。

**失败方式**（§4.3、Table 4，PDF pp.8–9）：SARA 中常见的是“规则对、事实编码错”（如申报状态、抚养关系）；Housing 与 USCIS-AAO 中主要是用错法条或误解资格条件；Airline 主要是算术或阈值错误。

阅读者分析：这个例子展示了“长文档规则 + 案情 → 结构化事实抽取 → 可执行推理”的流水线，适合对照需要先从文本抽取实体/属性、再按规则计算的语义查询；但基准本身只评测最终答案，不单独评测中间抽取质量。
