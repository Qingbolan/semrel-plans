# 解决的问题

**统一任务格式**（§2.1，PDF p.3）：输入是法条/政策文本（statute）加案情事实（case facts）与问题；输出视领域而定。

| 领域 | 输出 | 指标 |
|---|---|---|
| SARA Numeric | 应纳税额（数值） | 准确率，容差 $1 |
| Airline | 行李总费用（数值） | 准确率，容差 $1 |
| SARA Binary | 蕴含 / 矛盾 | macro-F1 |
| Housing | 是 / 否 | macro-F1 |
| USCIS-AAO | 上诉被接受 / 驳回 | macro-F1 |

来源：§2.2–2.3、§3.2，PDF pp.3、6；附录 B.3，PDF p.16。

**三种提示设置**（§3.1，PDF p.6）：Direct 直接预测答案、不生成 Prolog；Zero-shot 根据法条与案情生成完整可执行 Prolog；Few-shot 在同一格式下加入上下文示例。Prolog 程序不可执行或直接输出无法解析时记为“弃权”，并按错误计分：数值任务赋 −1 美元，二分类任务映射为相反类别（附录 B.3，PDF p.16）。

**评测单元**：每个案例采样 K 次（SARA 两类与 USCIS-AAO 为 K=4，Airline 与 Housing 为 K=3），用 1,000 次 bootstrap 给出 95% 置信区间，主表只在困难子集上计算（§3.2，PDF p.6；附录 B.3，PDF p.16）。

与原 SARA 的区别：原 SARA 假定整部税法已编码为背景 Prolog 规则，本基准要求模型针对每个案例从法条与案情即时生成 Prolog（§2.2，PDF p.3）。
