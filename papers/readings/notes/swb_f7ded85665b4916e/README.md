# Paul, Goyal & Ghosh — LeSICiN: A Heterogeneous Graph-based Approach for Automatic Legal Statute Identification from Indian Legal Documents

本文把法律条文识别（给定案件事实，找出相关的印度刑法典 IPC 条款）建模为异构引文网络上的归纳式链接预测：训练时同时学习文本表示和图结构表示，并让二者对齐；测试时新事实只有文本。作者还构建了 ILSI 数据集（66,090 条事实、100 个 IPC 条款）。LeSICiN 的宏 F1 为 28.45%，比最强基线 DPAM（23.86%）高 19.2%（相对值）。已阅读全文与附录。
