# 贡献与评价

**论文声称的贡献**（§1，p.2；§3–§4，pp.3–6）：

1. 数据合成：18 类细粒度任务分类（每类 4–6 个示例）+ 递归由易到难组合（串联 2–5 次）生成问题。
2. 轨迹合成：按类别手写高层流程知识引导 DeepSeek-V3.1 采样 N=3 条轨迹，由 GPT-4o-mini 做自一致性过滤和最优选择；不一致时把判定理由回馈给模型反思重采；再做格式、长度（答案 ≤1,024 token）、语言完整性三种规则过滤，得到 11,707 条轨迹。
3. 训练目标：SFT 与 DAPO 损失按动态系数 γ 加权（余弦从 0.9 退火到 0.05），并屏蔽含"空轮"的轨迹。
4. rollout 工程：生成与代码执行异步、只保存代码文本而非全局变量池、每条轨迹沙箱隔离与资源上限。

**评价**：动态混合 SFT/RL 明确沿用 Zhang et al. (2025c)（§4，p.5），DAPO 也是已有算法；新意主要在数据合成配方与工程组合。作者自己承认大部分提升来自数据：仅 SFT 即从 11.26% 升到 62.54%（§5.3，p.8）。

阅读者分析：评测与训练奖励用同一 GPT-4o-mini 判官，作者用 Qwen-2.5-72B 复评（Pearson 0.96）缓解但未消除自评偏差；"超越 GPT-5"指的是 ReAct 零样本设定下的闭源模型，并非与闭源智能体系统比较（阅读者分析）。

依据：§1、§3–§5，pp.2–10；附录 G.2，p.21。
