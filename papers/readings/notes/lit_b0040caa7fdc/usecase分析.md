# 具体用例

**论文示例**（Fig.2，p.3）：用户提供一份薪资表 `salary_bras.csv`（图中可见列 Year、AsianMen、AsianW…、BlackMen 等，按年记录中位年薪），提问"2020 年亚裔男性与黑人男性的年薪中位数相差多少？"。

智能体流程：

1. 在 `<think>` 中规划步骤（加载数据、定位 2020 行、取两列求差）。
2. 在 `<code>` 中写 pandas 代码，如 `pd.read_csv('data/files/salary_bras.csv')`。
3. 代码解释器把结果放入 `<interpreter>` 返回；智能体可以继续多轮写代码。
4. 最后在 `<answer>` 中给出差值。

训练时同一问题会采样多条轨迹，由判官检查答案一致性；RL 阶段按格式、答案正确性和长度给奖励，正确且答案短于 256 token 得满分，超过 1,024 token 只得 0.5（§4，Eq.8，p.6）。

阅读者分析：这一示例本质是单表上的过滤+算术，可由一条 SQL 完成；论文的价值在于让模型在不同文件格式上自主写代码，而不是对查询做优化或给出可审计的执行计划（阅读者分析）。

依据：Fig.2，p.3；§2、§4，pp.3–6。
