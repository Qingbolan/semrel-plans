# SciDTB: Discourse Dependency TreeBank for Scientific Abstracts

SciDTB 为科学摘要构建篇章依存树库（798 篇摘要、18,978 个关系），并给出转移式和图解析基线。关键结果：两阶段转移解析测试 LAS 0.545，人类标注一致性为 0.622（Table 5）。
