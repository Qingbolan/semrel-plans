# 解决的问题

论文定义了三个以句子为单位的任务（§4，PDF p.6）：

| 任务 | 输入 | 输出 |
|---|---|---|
| 测量句识别 | 单个句子 | 三分类：MEASUREMENT / QUAL_MEAS / 其他（两类同时出现时归为 MEASUREMENT） |
| 命名实体识别 | 句子 token 序列 | 14 种可嵌套实体（MAT、FORM、NUM、UNIT、VALUE、PROPERTY、TECHNIQUE、SAMPLE 等）的 span 与类型 |
| 关系抽取 | 句子及句中全部实体（金标或预测） | 实体对之间的关系标签，或"无关系" |

关系分两类：以 MEASUREMENT 触发词为根的测量框架关系（measuresProperty、conditionSampleFeatures、usesTechnique、conditionInstrument、propertyValue、conditionEnvironment、takenFrom 等），以及与测量无关的材料关系（hasForm、usedIn、usedAs、dopedBy、usedTogether）。属性未显式出现时，VALUE 直接连到 MEASUREMENT，使树变成图（§3.2.2，PDF pp.3–4）。

阅读者分析：评价单位都是单句；论文不处理跨句测量、文档级聚合或语义检索本身，检索只是动机中的应用设想。

依据：§3.2、§4，PDF pp.3–6。
