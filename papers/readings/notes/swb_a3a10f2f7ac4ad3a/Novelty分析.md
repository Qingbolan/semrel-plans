# 贡献与评价

**文中呈现的贡献**：

1. 两份 50 万词、多层一致标注的加泰罗尼亚语/西班牙语参考语料，可免费用于研究（引言，pp.2–3）。
2. 一套逐层递进、自动/半自动/人工结合的标注方法，人工层采用“多人平行标注 → 讨论 → 修订指南”的循环，直到一致率至少达到 95% 再转为单人标注（§2.1.2，p.5）。
3. AnCora-Verb 词典：从树库中抽取每个动词义项的句法框架，手工声明句法功能到论元/题元的映射，并以此半自动标注题元角色（§2.1.3、§2.2，pp.6–7）。
4. 基于 LSS 的动词语义类体系：4 个事件类细分为 13 个类，覆盖西班牙语 1,809 个、加泰罗尼亚语 2,073 个动词（§5.1.4，p.31）。
5. 选择成分标注并自动转换为依存格式；转换也用来发现原标注错误（§2.3，pp.8–11）。

**阅读者评价**：这是资源与方法描述文，没有下游模型实验或与其他树库的定量对比。质量证据集中在句法成分一致性（Table 3）；NE 和义项层只说达到“至少 95%”，没有给出具体表格。“至少 95% 一致”与 Table 3 最后一轮 LP 0.869 的关系，文中没有说明（阅读者分析）。

依据：引言、§2–5，Table 3，PDF pp.2–31。
