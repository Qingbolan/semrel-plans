# workload

**选文**（Corpus assembly，Table 4）：文章须同时满足两点：在 MGI/MGD 中被用作小鼠基因或基因产物的 GO 和/或 MP 注释证据来源；在 PMC 中以开放获取 XML 形式提供。三类候选数分别为 27（仅 GO）、66（仅 MP）、5（GO 和 MP），合计 98 篇，其中 1 篇当时无法获得全文，因此语料为 97 篇。67 篇首发集与留出的测试集之间，用单因素 ANOVA 检验了概念标注分布，没有显著差异。

**67 篇首发集的规模**：

- 每篇平均 1,491 条标注；各类的中位数都低于均值，说明分布右偏。
- Table 1 脚注：GO BP/MF 当时仍在复核，统计可能变化；GO 的 "cell" 概念占 CC 标注的一半以上，作者建议训练和评测时考虑排除。

**本体版本**（Methods）：ChEBI v45（19,633 个术语）；GO 1.9 修订版（BP 14,306、CC 2,047、MF 7,984）；PRO 2011-04-22 版；SO 1.45 版（1,610 个术语）。

与图谱查询的关系（阅读者分析）：图谱中引用本文的查询是"抽取 ChEBI 化学概念提及（含不连续片段）"，对应 ChEBI 这一遍标注和不连续 span 规则。注意：GPML 格式会丢弃不连续标注，应使用 Knowtator、RDF 或 UIMA 格式。
