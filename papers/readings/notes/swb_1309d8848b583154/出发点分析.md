# motivation

人工标注的金标准语料对生物医学 NLP 的训练和评测都很关键。Background 部分列举了多项研究：在领域标注数据上训练，能显著提升分词、词性标注、句法分析和概念识别的效果。

作者认为已有语料存在以下不足（Background、Discussion，Table 3）：
- 文档多为句子或摘要，而不是全文；
- 领域较窄；
- 概念 schema 小，通常只有几个到几十个类；
- 自建 schema 难以复用；
- span 边界规则不清，导致标注不一致；
- 常按"属于某领域"来标注，即把比标注类更具体的提及也归到这个类，造成语义损失。

同时，开放生物医学本体（OBO）已相当成熟，而且在基因注释等下游分析中被广泛使用。因此，作者希望用完整的社区本体对全文进行"语义等同"式的概念标注，为文本挖掘提供高质量的金标准（Background、Discussion）。

依据：[BMC Bioinformatics 13:161，PMC3476437 全文 XML](https://doi.org/10.1186/1471-2105-13-161)，Background、Discussion。
