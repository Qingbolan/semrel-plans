# A Declarative System for Optimizing AI Workloads

Palimpzest 是声明式 AI 工作负载系统：用户写逻辑流水线，优化器在质量、成本、延迟约束下选择模型与物理实现。关键结果：最高 90.3 倍加速、9.1 倍降本，但该倍率来自 32 个 worker 对单线程 GPT-4，且法律发现 F1 从 0.97 降到 0.81（§5.5）。
