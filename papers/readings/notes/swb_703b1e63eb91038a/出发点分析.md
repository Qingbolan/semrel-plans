# 出发点

低空无人机事件几乎每天都有报告，但很少被深入分析。多数司法辖区只在严重伤害或重大财产损失时才要求正式报告：例如美国 Part 107 的门槛是严重伤害或超过 500 美元的第三方财产损失；而 NTSB 的典型调查需要 12–24 个月才能得出可能原因。大量轻微事件因此没有系统调查，形成数据缺口（§1，p.2）。

作者认为，从初始事件报告中提取人因线索是务实的做法：人为错误仍是事故的主要成因，而飞手的报告往往是唯一稳定可得的证据（§1，p.2）。另一方面，这类报告碎片化、不完整、术语密集；通用 LLM 在无人机领域推理上表现不足（摘要、§1，pp.1–2）。

文献层面：航空安全 NLP 研究中涉及无人机的不到 2%（§2.3，p.6）；HFACS 8.0 原版没有充分表达远程驾驶、自动化依赖、数据链脆弱性和地面站界面等无人机特点（§1，p.3）。作者据此提出 HFACS-UAV，并构建端到端的人在环系统。
