# 贡献与评价

原文声称的价值（§1）：葡萄牙语公共采购领域最大的数据集，超过 37 万份文档、超过 9,000 条人工标注；覆盖红旗分类、关键短语抽取、标的与章节分类等任务；所有文档、预处理脚本和模型在 Hugging Face 公开（DOI 10.57967/hf/3256）。

方法上的要点：

- 用 Parsr 把 PDF/Word 转成 Markdown 文本，去除图片、表格、页眉页脚并修正抽取错误；按专家定义的最低要求（必须有 Object 章节，且至少有参与条件、资格、授权代表、评审之一）筛选（§4.1）。
- 发现章节标题用正则抽取不可靠（含 "OBJECT" 的标题可能讲交付条件），于是训练章节分类器（§4.2、Table 3）。
- 红旗标注采用 Snorkel 正则标注函数，由 3 组专家（每组 2 人+1 名裁决者）迭代验证并修正；再人工标注 1,818 份公告作金标准，训练 BERT 模型标注全部数据（§4.4、Table 8、Fig. 4）。
- 构造同义替换的对抗样本，检验模型对规避检测改写的鲁棒性（§4.6.5）。

阅读者分析：贡献主要在数据与工程流程，模型均为现成 BERT 微调，没有新方法。"9 个侧面"中 4 个是同一红旗任务的不同标签来源。论文未报告人工标注的一致性系数，弱监督标签质量也没有与金标准直接比较，因此弱标签与模型标签的可靠性只能间接推断。
