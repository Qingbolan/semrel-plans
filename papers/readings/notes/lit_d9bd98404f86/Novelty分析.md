# 贡献与评价

**论文声称的贡献**：作者称据其所知，DBG-PT 是第一个利用已执行计划信息、借助 LLM 调试回退查询的方法。与 DB-BERT、GPTuner、λ-Tune 等通过调参优化整体负载的工作不同，也与依据执行指标排障的 Panda 和检测数据库异常的 D-Bot 不同，DBG-PT 比较同一查询的不同已执行计划来诊断并修复回退（§4，p.4）。

**系统组件**（§2，pp.2–3）：交互式查询执行器（IQE，可执行注册或临时查询、修改调优开关、查看性能曲线）、查询指标库、回退调试器、提示生成器。集成只需兼容 Python DB-API（PEP 249）并支持 `EXPLAIN`，无需重新训练（§1，p.2）。

方法本质是“两份计划 + 上下文 → 提示模板 → LLM”，技术增量较小，价值在于把回退调试的输入限定为计划对比这一问题设定。论文没有说明使用哪个 LLM，也没有报告修复成功率、误修复或建议是否经过安全校验；“first approach” 的定位只能作为作者自述（阅读者分析）

依据：§1、§2、§4，PDF pp.1–4（4337–4340）。
