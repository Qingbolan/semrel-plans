# 评测与边界

**评测情况**：本文是演示论文，没有基线、指标或定量结果。§3 只描述了三类演示场景（索引相关、调优开关相关、运行时错误），以及用户可自建回退案例的流程；Fig. 2 是性能曲线界面截图（pp.3–4）。结论只称 DBG-PT “处于早期阶段”，但“已显示出有前景的能力”，没有给出数据支持（§4，p.4）。

**相关工作对比**（§4，p.4）为定性描述：

| 工作 | 依据的信息 | 目标 |
|---|---|---|
| DB-BERT | 数据库手册 + 强化学习 | 调参 |
| GPTuner | 手册 + LLM + 贝叶斯优化 | 调参 |
| D-Bot | LLM | 检测并缓解数据库异常 |
| Panda | 执行指标 | 性能排障建议 |
| DBG-PT | 同一查询的已执行计划对比 | 修复单条查询回退 |

缺少的关键评估包括修复成功率、建议引入新回退的比例、对 LLM 型号与提示的敏感性，以及大计划超出上下文长度时的处理。使用本文时只能引用其问题设定与系统设计，不能引用效果数字（阅读者分析）
