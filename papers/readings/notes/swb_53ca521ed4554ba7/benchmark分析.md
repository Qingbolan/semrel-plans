# 评测与边界

本文没有模型基线或预测指标。评测回答三个问题：语料与已有工作相比如何、能否揭示执法趋势、能否减少合规不确定性（§5，PDF p.8）。

**实验 1（覆盖范围，§5.1、Figure 3）**：GDPRxiv 的先例为 3,343 份，约为 Enforcement Tracker（1,428）和 GDPRhub（1,594）的 2 倍；加入指南后为 8,943 份，约为 5 倍。多出的部分主要是未罚款的执法（未违规、警告、谴责、训诫）。逐案比对发现，有 86 个案件在 Enforcement Tracker 中而不在 GDPRxiv 中，作者解释为来自非官方来源或链接失效（PDF p.8）。

**实验 2（执法趋势，§5.2）**：

| 发现 | 数值 |
|---|---|
| 平均每日执法数 | 2.03 |
| 第 1–4 年执法数 | 275 / 663 / 1,021 / 1,012（约 2.7 倍） |
| 无罚款执法占比 | 46% |
| 罚款不超过 1 万欧元的占比 | 80% |
| 百万欧元级罚款占比 | <2%（Table 1 写作 1.8%） |
| 欧盟罚款总额 | 18.7 亿欧元；前 3 国（卢森堡、爱尔兰、法国）占 80% 以上 |
| 执法数前 3 国（西班牙、丹麦、波兰） | 占 54% |
| 第 5、6、32 条 | 至少其一出现在 78.5% 的引用中 |

（Figures 4–5、Tables 1、3，PDF pp.2、9–10）

**实验 3（RTBF）**：从 175 份决定中归纳 16 类失败、5 个功能组（§5.3，PDF pp.10–12）。

**边界**：

- 只覆盖官方 GDPR 机构已裁决或发布指南的问题；对删除时延、可证明删除、AI 训练数据等尚无先例的问题无法给出答案（§3.4、§5.3.3，PDF pp.5–6、12）。
- 结论是失败清单，不是合规配方，也不穷尽（§5.3.3，PDF p.12）。
- 翻译依赖 Google Translate，未做质量检查；执法元数据依赖人工标注（§4.2–4.4，PDF pp.6–7）。

阅读者分析：Table 1 称"三条款约占全部引用的近 50%"，§5.2 又写"至少其一出现在 78.5% 的引用中"，两个口径不同，原文未解释。

依据：[PoPETs 2023(4)，16 页](https://lawfulcomputing.org/papers/pets2023.pdf)，§3.4、§4.2–4.4、§5.1–5.3、Tables 1–3、Figures 3–7，PDF pp.2、5–12。
