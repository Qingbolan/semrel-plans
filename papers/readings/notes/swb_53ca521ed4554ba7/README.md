# Sun et al. — GDPRxiv: Establishing the State of the Art in GDPR Enforcement

本文提出"GDPR 执法现状（SOTA）"的概念，即所有未通过现行 GDPR 合规标准的技术、设计、配置与运营做法，并构建自动爬取与整理官方执法文件的系统 GDPRxiv：共收录 3,343 份执法先例与 5,600 份官方指南，合计 8,943 份。论文基于该语料分析 4.5 年间的执法趋势，并对 175 份引用第 17 条（被遗忘权，RTBF）的决定做开放编码，归纳出 16 类常见失败。主要发现：80% 的罚款不超过 1 万欧元，百万欧元级罚款仅占 1.8%；RTBF 失败中 UI 与策略类合计占 80%（§5.2–5.3）。已阅读正文 §1–§7 与附录 A 的结构；未逐条核对附录 A 中的案件列表。
