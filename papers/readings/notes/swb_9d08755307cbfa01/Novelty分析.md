# 贡献与评价

**原文声明的贡献**（Introduction，PDF p.2）：

1. 一个锚定 ClinGen 的基准，覆盖摘要筛选和全文功能证据抽取两级。
2. 在显式的变异匹配门控下评估两个推理行为不同的多模态 LLM，以降低把结果归到错误变异上的风险。
3. AcmGENTIC：输入变异坐标，经过标识符扩展、LitVar2 文献检索、LLM 摘要过滤、PDF 获取、多模态抽取，最后生成供专家审阅的 HTML/PDF 报告或 JSON。它还带有一个基于 OCR、版面分析和图表工具的“agentic”模式。

**基准构建**（Methods，PDF p.2）：用 gpt-4.1-mini 把 ClinGen 专家评论解析成 PMID、PS3/BS3 等级和相关叙述，再用 metapub 获取摘要和开放获取 PDF。

阅读者分析：

- 标签来自 LLM 对专家评论的解析，原文没有报告这一步的抽取准确率，因此标签本身带有未量化的噪声。
- 全部结果只用了 Direct 模式（整篇 PDF 一次调用），agentic 模式没有定量评估（PDF pp.3、7），不能把它算作已验证的贡献。
- 只比较了两个 OpenAI 模型，作者自己也把这一点列为局限（PDF p.7）。
