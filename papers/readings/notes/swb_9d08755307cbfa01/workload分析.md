**构建漏斗**（Methods、Results，PDF pp.2–4）：

| 步骤 | 规模 |
|---|---|
| ClinGen 专家注释变异 | 11,527 |
| 带任一强度 PS3/BS3 的变异 | 1,709 |
| 可程序化获取 PDF 的 ClinGen 阳性“变异—论文”对 | 529 |
| 经 VariantValidator（MANE Select）标准化与标识符一致性检查后 | 466（排除 63） |
| 摘要筛选集 | 1,058（阳性 529，阴性 529） |

**摘要筛选的正负例**：阳性为与 PS3/BS3 变异关联的论文摘要；阴性从“没有 PS3/BS3 注释的变异”的专家评论所引论文中随机抽取（PDF p.3）。

**全文变异匹配**（附表 Table 2，PDF p.8）：

| 匹配状态 | gpt-4o-mini | o4-mini |
|---|---|---|
| 精确匹配 | 283 | 278 |
| 启发式匹配 | 56 | 42 |
| 单变异研究匹配 | 0 | 3 |
| 匹配失败 | 121 | 137 |
| NA | 3 | 3 |
| 成功合计 | 339 | 323 |

原文没有给出 PS3 与 BS3 在 466 对中的各自数量，也没有训练/测试划分（纯零样本评测）。阅读者分析：Table 2 每列合计为 463，比正文的 466 少 3，原文未解释；26–30% 的匹配失败率按 463 计算为 121/463≈26.1%、137/463≈29.6%（阅读者分析）。
