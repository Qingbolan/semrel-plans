# 出发点

数据清洗对模型性能很关键，却是数据科学家最耗时、最乏味的工作之一；“什么算错误”随数据集而变，通用的全自动方法难以部署，实际做法仍是人工探索、提假设、修正、反复迭代（§1，p.1）。

已有 LLM 在机器学习中的研究多集中于特征选择、模型调参与优化（如 MLAgentBench、MLE-bench），目标是改架构和特征处理，而不是提高原始数据质量（§1，p.1；§2.2，p.2）。已有 LLM 清洗工作（如 IterClean、CleanAgent）多在传统清洗基准上评测，而这些基准中的脏数据版本对下游任务性能影响不大（§2.1，p.2；§3.1，p.3）。

因此作者提出的问题是：如果预处理和训练流水线保持不变，LLM 能否仅靠发现并纠正数据中的错误来提升模型性能（§1，p.1）。

依据：§1–3.1，PDF pp.1–3。
