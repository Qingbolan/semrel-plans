# 贡献与评价

论文声称的主要贡献是一个简单框架，用于系统研究 LLM 与数据集交互、以提升下游 ML 训练数据质量为目标的能力，并给出初步分析（§1，p.2）。具体包括：

1. 自建干净/脏数据版本：在 Kaggle 数据上注入三类系统性错误（数值偏移、NaN 损坏、类别偏移），并要求错误可通过统计或上下文发现、且不需要原始干净数据即可缓解（§3.1，pp.3–4）。
2. 智能体设置：只开放 IPython 与评估工具，流水线固定（§3.2）。
3. 实证观察：模型偏重 `.describe()`、`.head()` 等单值/单行检查，常用任意缩放或填 `Other` 之类的处理；频繁无效提交、暴力反复提交、忽视 IPython 状态保留（§4.2）。

阅读者分析：这是研讨会规模的探索性工作。只有 3 个数据集、每个 3 个由作者手工注入的错误，作者自己也承认这限制了多样性并可能引入偏差（§5.2）。正文没有给出 P_Clean、P_Dirty 的绝对值及各模型的精确提升数值（主要在 Fig. 2 中以柱状图呈现），也没有方差统计，结论更适合作为定性证据。

依据：§1、§3–5，PDF pp.2–9。
