# Overview of CAIL2018: Legal Judgment Prediction Competition

这篇文章总结 CAIL2018 竞赛的任务、评分和参赛方法。它与 CAIL2018 数据集介绍是两篇独立文献，测试集合和报告指标不能互换。关键结果：第二阶段 nevermore 罪名 micro-F1 0.962、macro-F1 0.836；刑期最高分为 HFL 的 77.70（Table 1）。
