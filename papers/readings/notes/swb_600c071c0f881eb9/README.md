# Mayfield & Black — Analyzing Wikipedia Deletion Debates with a Group Decision-Making Forecast Model

本文发布英文维基百科 Articles for Deletion（AfD）2005–2018 年的结构化讨论语料（抽取 402,440 场，分析 369,592 场），并用作者此前提出的结果预测模型（BERT 句向量加票数特征，逻辑回归）定义“预测偏移”（forecast shift），衡量每条发言对预测结局的影响。全讨论预测准确率为 93.5%（κ=0.83）。作者据此复现并扩展了先前关于早期投票、关注度政策、活跃用户和政策引用的研究结论。已读正文全部与附录 A（标签归一、用户抽取、JSON 格式）。
