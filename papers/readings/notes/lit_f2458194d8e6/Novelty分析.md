# 贡献与评价

原文贡献是一个面向 Text-to-SQL 的描述生成流程及开源工具（XiYan-DBDescGen）。具体设计点：先整体后局部的上下文、维度类型细分、同类列对比以区分相似字段、限制描述长度（作者称过长列描述会损害 NL2SQL，PDF p.3）。

阅读者分析：

- 这是一份 5 页技术报告，没有消融：未验证粗到细、细到粗、同类列对比或长度限制各自的贡献；
- 未说明生成描述所用的 LLM 及其规模，复现需依赖代码仓库；
- 未与其他自动描述方法比较，只与“无描述”和“人工描述”比较；
- 数字表述不一致：摘要写提升 0.93%、达到人工水平的 37%，§1 写 0.98%、37%，§3 写 0.93%、39%，结论写 0.98%。按 Table 1 计算，平均增益为 (1.55+0.42+0.81)/3 ≈ 0.93 个百分点，人工描述平均增益 ≈ 2.33，比值约 0.40，逐模型比值的平均约 0.39；“37%”与“0.98%”无法从表中复算（阅读者分析）。

依据：摘要、§1–4、Table 1，PDF pp.1–4。
