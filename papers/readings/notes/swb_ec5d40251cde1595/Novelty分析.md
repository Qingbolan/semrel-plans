# 贡献与评价

**论文声称的贡献**：（1）端到端人机协作系统，从政策文本到可执行规则再到理赔上的解释性结果；（2）无需标注数据的 NLP 抽取管线，结合本体引导的语义角色标注与依存树语义推理，并用 Optuna 超参优化调配置（pp.12–13）；（3）开源本体与 141 条真值规则（Discussion p.9；Data availability p.15）；（4）用 15 名专业人员的用户研究评估有用性（pp.7–9）。

**执行层设计**：规则被编译成 filter / splitter / evaluator 三类组件的流水线，按患者并行执行，表达式用 SpEL 编写（p.14）。

方法核心是本体模板 + 传统 NLP（非 LLM），抽取组件多来自作者先前工作（refs 24–26），本文增量主要在系统整合、执行管线与评测。规则执行的高 F1 有一定“同源”成分：真值标签由专家按同一政策手写算法产生，Clais 执行的是同一政策抽取出的规则，因此执行评测主要检验抽取是否忠实，而非发现真实欺诈。基线不做特征工程，也使这一比较对 ML 方法偏不利（作者在 p.11、p.14 说明了理由）（阅读者分析）。

依据：Discussion pp.9–11，Method pp.11–14。
