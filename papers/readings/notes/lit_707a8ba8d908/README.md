# Zhao et al. — ProactiveVA: Proactive Visual Analytics with LLM-Based UI Agent

本文是一项可视分析（VA）人机交互研究：作者先通过 10 人形成性研究归纳用户何时需要帮助、需要什么帮助，再设计一个基于 DeepSeek-V3 的 UI 智能体。该智能体监测交互日志，检测“需要帮助”的事件，主动给出提示，并能自己读数、选择、过滤来操作界面。评测包括 100 个 LLM 生成任务的批量模拟、两个专家案例和 10 人用户研究；后者与形成性研究相比，报告事件数约从 2 增至 4，正确率从 0.78 增至 0.95。已阅读全文；正文引用的附录不在 arXiv PDF 中。
