# 出发点

基于 LLM、交替进行推理与工具执行（SQL、Python）的数据智能体已被 Databricks Genie、Snowflake Cortex Analyst、BigQuery 等平台集成，但难以泛化到未见过的数据环境和分析流程，尤其是异构的企业环境（§1，PDF p.1）。

作者认为，针对给定数据环境合成高质量“轨迹”（推理、工具调用、执行结果组成的多步序列）可以弥合这一差距：轨迹既可作 SFT 数据使模型适应目标领域，也可作 ICL 示例指导通用 LLM（摘要、Figure 1，PDF p.1）。

现有合成方式的不足（§1，PDF p.2）：单次生成在任一步失败时丢弃全部进展；Best-of-N 在相互独立的尝试间重复计算。作者归纳三项挑战：C1 自动构造真实、可解且扎根于数据环境的任务（直接让 LLM 看 schema 出题常得到平凡或不可解的问题）；C2 在随步数指数增长的轨迹空间中搜索；C3 每步选择合适的推理配置（哪个 LLM、多少上下文、是否开启扩展思考）。
