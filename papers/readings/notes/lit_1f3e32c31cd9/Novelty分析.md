# 贡献与评价

**论文自述的贡献**（§1，p.2）：

1. 提出 LongRAG 范式，相对长上下文 LLM 最高提升 6.94%、相对高级 RAG 6.16%、相对 Vanilla RAG 17.25%。
2. 两个即插即用组件：信息抽取器（全局信息）和 CoT 引导过滤器（事实细节）。
3. 自动化的微调数据构造流程 LRGinstruction 与多任务训练策略，只需约 2,600 条样本。

**数据构造**：以 ChatGLM3-32B-128k 为教师模型，从 HotpotQA、2WikiMQA、MuSiQue 训练集及 QASPER 构造四类数据（抽取器、CoT 引导、过滤、问答任务），并用 LLM 自评器筛除无效样本（§3.2，附录 C，pp.3–4、15–16）。

**阅读者评价**：

- 方法上的新意是组合：把检索 chunk 回扩到源段落再做 LLM 摘要，与逐 chunk 相关性判断并行，两者本身都有先例（论文也引用了 CRAG、Self-RAG 的过滤思路）。差异在于过滤前先生成一条“全局 CoT”作为判断依据。（阅读者分析）
- 摘要中的“%”实为 F1 绝对点数差。6.94 = 46.88−39.94（LongRAG-Llama2-13B 对 LongLoRA-13B），6.16 = 46.79−40.63（GPT-3.5 版对 Self-RAG），17.25 为 Vicuna 版对其自身 Vanilla RAG（Table 1）。各对比的骨干模型不同。（阅读者分析）
- 微调中的 2,600 条样本来自与测试集同源的三个数据集的训练集（附录 C.5）；跨领域迁移能力论文只在 §7 作为局限提及，未实测。

依据：§1、§3.2、Table 1，PDF pp.2–6；附录 C.5、Table 15，pp.16、22；§7，p.9。
