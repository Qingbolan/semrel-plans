# 评测与边界

**基线与指标**：对照对象是 nvBench 真值图（案例 1、4）、NL4DV 的输出（案例 2、3）和 ADVISor 论文中的图（案例 3）。没有数值指标，只由作者目视判断正确性和合适程度（§3.4，p.8）。

**主要观察**（§4，pp.8–12）：
- **实验 1（easy）**：三个模型都正确；GPT-3 与 Codex 结果相同；ChatGPT 旋转了标签，标题更完整。
- **实验 3**：Codex 漏掉了 2004 年起的过滤；ADVISor 也没有过滤，但高亮了 2004 年以后的点。
- **实验 4（Extra Hard）**：三者都与真值相近；Codex 的代码结构不够好，出现重复绘制柱子的问题。
- **实验 5（拼写错误）**：三者都正确；ChatGPT 按数量降序排列，GPT-3 和 Codex 按字母排序。
- **实验 6（"tomatoes"）**：三者都关联到 Rotten Tomatoes Rating 列。GPT-3 画了它与 IMDb Rating 的关系；Codex 为每个标题画一个点，图过于拥挤、不可用；ChatGPT 画了分布图。

**作者承认的局限**（§5.1，p.13）：
- 背景色、网格线、线条颜色等样式很难通过提示稳定控制。
- 同一提示重复提交会得到不同的图。
- 理想提示因模型而异。
- 案例数量有限，缺少终端用户评测和基于 nvBench 的定量对比。

阅读者分析：
- 第 5 节由案例推出"准确、高效、成本低"并称 LLM 是"最可行的方案"（§5，p.12）。这种外推超出了证据范围。
- ChatGPT 是通过网页手工调用的，无法控制温度等参数，三个模型的对比条件并不对等。

依据：§3.4–§5，Figures 5–10，pp.8–13。
