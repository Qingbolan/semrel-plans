# 解决的问题

§2 把数据科学求解建模为在解空间 S 上搜索 s* = argmax η：每个解是三元组 (p, σ, η)，p 为文本计划、σ 为 Python 代码、η 为执行后提取的验证集指标（PDF p.2）。作者强调这比通用智能体的累积回报建模更简单。

输入：竞赛任务描述与数据文件（Docker 容器内）、检索到的论文与技巧；输出：最终提交文件，由官方排行榜或任务指标打分。工作单位是“一个竞赛任务的一次 24 小时运行”，每任务重复 3 次（§4.1，PDF p.5）。

解树节点分为 valid、buggy、dead（超过最大调试深度），best 节点为验证指标最优的 valid 节点（§3.2，PDF p.4）。

阅读者分析：η 是智能体自己划分的验证集指标，最终以测试排行榜衡量，两者可能不一致；原文未分析验证—测试偏差。

依据：§2–3、§4.1，PDF pp.2–5。
