# 工作负载

**总体规模**（§7、附录 Table 2，PDF pp.5、12）：26 种语言，455,629 句、9,264,811 token、平均句长 20.3，共 127,498 个 VMWE。

| IAV | 7,375 |
| VPC.semi | 6,443 |
| MVC | 5,032 |
| LVC.cause | 3,238 |
| LS.ICV | 37 |

**语言间差异**（Table 2，PDF pp.11–12）：

- 罗马尼亚语最大：56,664 句、约 101 万 token、9,508 个 VMWE；
- 汉语：10,819 个 VMWE，其中 VPC.semi 4,629、MVC 3,826；
- 英语：只有 7,436 句、1,114 个 VMWE，且训练集（2,150 句）小于测试集（3,984 句）；
- 爱尔兰语：共 1,705 句、659 个 VMWE。

按"未见 VMWE 数固定"的规则划分，导致小语种测试集常大于训练集（如 LT 训练 2,281 句、测试 6,642 句）。

**类别分布**（§7，PDF p.5）：VID 与 LVC.full 在所有语言中都存在；LVC.cause 在捷克语和土耳其语中未标注；IRV 存在于所有斯拉夫和罗曼语；IAV 为可选标注，有无取决于团队而非语言本身。

阅读者分析：如果用作抽取类工作负载，样本单位是句子、标签是可不连续的词元集合加类别；各语言训练规模差异可达数十倍，跨语言汇总分数要谨慎。
