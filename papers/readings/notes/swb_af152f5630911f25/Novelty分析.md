# 贡献与评价

**贡献**：

1. 同一组新闻同时具备实体、事件、时间、数值、语义角色、时序/因果关系，以及文档内和跨文档共指的多层标注（§3）。
2. 四种语言平行，并通过对齐得到跨语言实体与事件共指（§4、Table 3）。
3. 提出在 markable 层面（而非 token 层面）按语义对齐的跨语言标注投射方法（§2 末，PDF p.2）。
4. 针对意大利语和西班牙语的空主语，用不消耗文本的标签标注，并与实体实例链接（§3.1，PDF p.2）。

**投射流程**（§4.1，PDF p.3）：意大利语和西班牙语分五步。

1. 用 CAT 标出 markable 的文本范围。
2. 在句对齐基础上，手工把每个 markable 对齐到英文 markable。
3. 用 Python 脚本导入与语言无关的属性、实例和关系。
4. 人工复核。
5. 投射跨文档共指。

荷兰语的文档级标注全部人工完成，之后再对齐并投射跨文档标注（§4.2）。

**阅读者分析**：

- 主要价值在于标注层次全、跨语言对齐，而非规模；英文文档级标注只有 2,096 个事件提及。
- 原文没有报告标注者间一致性、标注质量评估或投射误差率，因此标注质量无法从本文判断。
- 文档级标注只覆盖前 5 句，限制了长距离文档级任务的使用。
