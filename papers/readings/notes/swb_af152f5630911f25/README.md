# Minard et al. — MEANTIME, the NewsReader Multilingual Event and Time Corpus

MEANTIME 是 NewsReader 项目构建的多语种语义标注新闻语料，包含 120 篇英文 Wikinews 文章及其西班牙语、意大利语、荷兰语专业译文，共 480 篇。文档内标注实体、事件、时间表达式、数值表达式及其时序、因果、语义角色等关系；跨文档标注实体与事件共指，并借助译文对齐实现跨语言共指。这是一篇语料描述论文，没有模型实验，也没有报告标注一致性或数据划分。已阅读全文（6 页）。
