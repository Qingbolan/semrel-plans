# Sun et al. — LAMBDA: A Large Model Based Data Agent

LAMBDA 是一个开源、免写代码的多智能体数据分析系统：“程序员”智能体按用户自然语言指令写 Python 代码并在 IPython 内核执行，“检查员”智能体在报错时给出修改建议，用户可随时直接改代码介入；另有基于键值知识库的知识整合机制（Full/Core 两种模式）接入用户自定义算法。

评测主要是把 LAMBDA 在经典分类/回归数据集上的 5 折交叉验证结果与作者手工用 R 做的同类分析对比，以及三个领域任务上与其他数据智能体的打分对比；附录消融显示加入检查员使执行通过率从 68.06% 升到 95.37%。已阅读正文 §1–6 与补充材料 A.2、D（Tables S.2–S.4）、Table S.6；未逐页阅读补充材料中的长提示与案例对话。
