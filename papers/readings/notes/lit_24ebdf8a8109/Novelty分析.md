# 贡献与评价

**论文声称的贡献（§1，pp.2–3）**：
1. 把“任务条件下的自主数据工程”作为一级研究问题提出，数据状态而非模型代码是主要优化对象；
2. DataMaster：DataTree 把数据工程组织为对数据状态的树搜索，红/黑两类节点分离“外部探索”和“数据利用”，配合共享 Data Pool 与 Global Memory；
3. 在 MLE-Bench Lite 与 PostTrainBench 两类设置上验证。作者自称是“第一个”把数据状态作为主要优化目标、统一外部数据发现、可执行精炼和累积记忆的数据智能体框架（§1，p.2）。

**组件证据（Table 2，p.10，10 个 MLE-Bench Lite 任务）**：完整系统最佳节点奖牌率 90%、金牌率 80%、超越率 69.96%；去掉 Memory 后超越率 28.57%、金牌率 20%（增益归零）；去掉红节点超越率反而升至 72.40% 但金牌率降到 70%；去掉黑节点奖牌率 70%。

**诚实评估（阅读者分析）**：
- 树搜索 + 记忆的框架与 AIDE、ML-Master 的代码树搜索同构，新意主要在把动作空间限制到数据侧并加入外部数据发现与共享候选池；UCB 调度是标准做法。
- “第一个”属于作者自述，阅读者未做独立核查。
- 组件消融只有 10 个任务、单次运行，百分比粒度为 10%，不足以给出显著性。
- 基线的预算与设置不完全对齐：PostTrainBench 上 Codex 数据取自原 PostTrainBench 论文（GPT-5.2-Codex），DataFlex 直接拿 DataMaster 最佳节点的数据集，DatasetResearch 由 Claude Code 适配（附录 B.3，p.18），因此对比并不全是同条件端到端。
