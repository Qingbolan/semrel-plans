# 贡献与评价

**作者声称的四项贡献**（§1，PDF p.1）：

1. 收集并发布有助于理解医保覆盖规则的文本语料；
2. 提出申诉裁决任务；
3. 整理并发布带标注的数据集作为基准；
4. 训练并评估基线模型。

**与已有工作的区别**：作者认为本文是少数针对法律与医学交叉领域整理预训练数据的工作之一。与西班牙语临床记录上的覆盖预测（[18]）相比，本文是三分类、英文，并接受专家与非专家的描述。另一项医保拒付任务（[19]）没有公开权重和数据，本文承诺完全开源。语料与 Pile of Law、Meditron Guidance 部分重叠，作者特别注重去除冗余，例如只取各州法典最新年度版本（§3、§4，附录 A，PDF pp.1–2、12）。

**伪标注流程**（§5.6，PDF pp.5–6）：人工标注 1,000 条案件描述（三个来源各三分之一）的"非泄漏背景"片段和 1–4 级充分度；据此微调两个 DistilBERT 模型，一个做片段抽取，一个做充分/不充分二分类（分数不低于 3 为充分）；再用它们处理全部 74,007 条描述，生成三分类伪标签。

**阅读者评价**：

- 最有价值的是"去泄漏"的任务设计和带标签的权威语料，后者支持确定性的标签过滤检索。
- 基准标签很大程度上由模型产生：背景片段由抽取模型生成，"不足"类由充分度模型判定。测试集也来自同一流程，因此 Table 2 衡量的是对伪标注流程的拟合，而非对人工金标的拟合。
- 人工标注只有 1,000 条，作者明确说尚无标注者一致性结果（§5.6.1，PDF p.5）。
- 片段抽取模型"足够好"的判断是主观的，尽管附注报告了 token 级 F1 91.2%（§5.6.2 脚注 6，PDF p.6）。
