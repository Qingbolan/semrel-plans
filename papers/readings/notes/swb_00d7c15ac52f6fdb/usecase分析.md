# 具体用例

论文中的典型使用方式是：报关或合规人员输入产品描述，模型返回 10 位 HTS 美国编码和一段推理说明（§2.2，p.3）。

例如，一条 CROSS 裁定被 GPT-4o-mini 改写为：
- 用户：“What is the HTS US Code for [产品描述]?”
- 模型：“HTS US Code -> [编码]”，“Reasoning -> [推理路径]”。

§2.4 举的易混淆例子是半导体晶圆：部分加工的晶圆与完全加工的晶圆归入不同编码（p.3）。§3.3 也以“半导体晶圆 vs 成品芯片”说明对比学习可能有帮助（p.5）。

部署诉求：汽车、工业、半导体等行业希望自托管模型，以免敏感贸易数据离开内部环境（摘要、§1.1，pp.1–2）。

阅读者分析：在语义数据处理场景中，这是“对每条商品记录做一次层级标签分配”的语义映射算子，可按 6 位和 10 位两级检查结果。论文没有给出某个具体测试样本的模型输入、输出和对错分析，上述模板来自数据构造提示，而非评测样例。

依据：摘要、§1.1、§2.2–2.4、§3.3，PDF pp.1–5。
