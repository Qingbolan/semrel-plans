# 具体用例

贯穿全文的 GAAP 示例（§2.3、Fig.2、§3.3）：用户问“分析产品 X 有效用户的平均 GAAP 值”。

1. 规划：Host 调用 Skill-Hub 路由/规划技能，生成 DAG——取数、异常检测、按用户类型与地区并行下钻、因果分析、生成报告；计划先交用户批准或修改。
2. 取数：DataBridge 通过 KG 把“有效用户”解析为财年累计 GAAP ≥ 10，通过 MG 定位 GAAP 指标到表 dws_gaap_di 的 gaap_val 列；Host 在沙箱中执行 SQL，结果登记为产物。
3. 分析：用异常检测脚本发现 3.10 的 GAAP 异常高（图中示例 50K）；下钻得到学生用户贡献约 70%、北区约 65%；KG 中的事件（3.8 学生年度订阅续费活动、3.7 北区企业合同续签）支撑归因。
4. 报告：报告技能生成交互式 HTML 报告，每个结论链接回数据。
5. 自演化：用户追加西区新用户的转化分析并给出“扣除内部测试与计费前取消”的口径；Learn 将净转化率写入 MG 指标、将排除规则写入 KG、把“异常检测跳过周末噪声”写入 TG；Govern 处理列改名 gaap_val→gaap_val_new 并废弃旧字段。

阅读者分析：这是作者构造的示意场景（数字为图示），不是评测样例。
