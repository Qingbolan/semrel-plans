# 贡献与评价

原文列出的贡献（§1，p.2）：

- 发布 ExCyTIn-Bench，自称首个评测 LLM 智能体威胁调查能力的基准，智能体须查询日志进行调查。
- 提出从二部"告警—实体"事件图用 LLM 生成问答的方法：任取两个告警作为起止点，取彼此最远的实体作为上下文与答案，用最短路径生成分步解法（Algorithms 1、3）。
- 对多种模型和提示/测试时扩展方法（ReAct、Expel、Best-of-N、Reflection）做系统实验。

附带贡献：基于解法路径的衰减过程奖励（Algorithm 2），作者认为可用于 RL 训练（§5，p.9）；PII 匿名化流程（C.3，pp.14–15）。

**阅读者分析：**

- 新意主要在"以图锚定的自动出题 + 可验证答案 + 过程奖励"，使问题可扩展到其他 SIEM（C.1 称可迁移到 GCP、AWS，p.14），但迁移未实测。
- 所谓"真实"有边界：租户与公司虚构，攻击为对已知真实攻击的模拟，背景噪声为随机模拟（§3.1、C.1，pp.3、13）。
- 问题由 LLM 生成，未报告人工质量审核比例；评审一致性只在 163 个样本上人工核对（C.5）。
- 正文内部有几处口径不一：引言称 59 张日志表，§3.1/C.4 为 57 张，Table 5 的全量 44 天日志为 61 张；§3.1 称时间段 2 小时至 5 天，而 Table 1 时间列以分钟计，最短为 11（322 号事件）（阅读者分析）。

依据：arXiv:2507.14201v3，§1–3、§5、附录 C.1、C.3、C.5，PDF pp.1–5、9、13–15。
