# 贡献与评价

论文自述贡献（§1）：
1. DataPRM：利用环境交互与三值奖励解决数据分析中的落地错误与静默错误；
2. 步级过程监督数据生成管线：多样性驱动的轨迹生成 + 知识增强的步级标注，得到 7K+ 标注实例；
3. 在 TTS 与 RL 两种设置中验证，相比同类大规模基线有 58 倍参数效率（4B vs Qwen3-235B 自奖励）。作者称这是 PRM 在数据分析领域的首个系统研究（§6.1）。

数据管线细节（§4.2）：按 AutoSDT 方法爬取 GitHub 上的科学数据分析文件，专家修订扩展一部分；DeepSeek-V3.2 合成推理类查询，可视化任务直接采用 AutoSDT 查询；Qwen3-235B 对每个查询并行采样 K=4 条轨迹，仅当 DeepSeek-V3.2 判定最终答案不完全一致时保留（聚焦边界样本）；Qwen3-235B 初标并归因，AutoManual 合并错误类别，人工核验后作为 few-shot，再由 DeepSeek-V3.2 给三值分数。100 条人工抽检：原始准确率 86.0%，二次加权 Cohen’s κ 0.83。

阅读者分析：“让验证器自己执行代码”的思路与 TaTToo 等工具化 PRM 相近，本文的特色在数据分析场景下的三值奖励和对落地/静默错误的先导诊断。4B DataPRM 的底座模型在正文中未点名。主表中的优势幅度不大（见 benchmark），先导研究使用的 DABStep 子集规模也未说明。

依据：[arXiv 2604.24198v2，12 页](https://arxiv.org/pdf/2604.24198v2)，§1、§4.2、§6.1，PDF pp.2、5、9。
