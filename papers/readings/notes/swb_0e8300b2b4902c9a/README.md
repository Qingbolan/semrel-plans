# O'Gorman, Wright-Bettner & Palmer — Richer Event Description: Integrating event coreference with temporal, causal and bridging annotation

本文介绍 Richer Event Description（RED）语料的标注方法：在同一批 95 篇新闻和论坛文档上统一标注实体、事件、时间表达，以及它们之间的共指、桥接、时序、因果和子事件关系。论文的"评测"是标注一致性分析（标注者之间、标注者对裁决金标），没有训练或评测任何自动系统。已通读全文 §1–5。
