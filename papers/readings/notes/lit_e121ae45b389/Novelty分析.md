# 贡献与评价

**论文自述贡献**（§1，p.2）：

1. 一个从 ML 会议竞赛整理的动态基准，问题开放、影响大、可客观测量，并要求新方法。
2. 对多种前沿 LLM 与代表性代理框架的大规模客观评测，显示它们难以提出并实现带来显著提升的新方案。
3. 指出主观评测的缺陷：LLM 判断的想法新颖性与实际效果不一致。

**设计要点**：

- 任务筛选三条标准：研究导向（不能靠暴力调参解决）、非平凡（不能直接套 XGBoost 或提示工程）、可行（代码、划分、评测公开可复现）（§3.2，p.5）。
- 持续更新、淘汰饱和任务；认为竞赛方案多以报告形式公开、很少出现在预训练数据中，可降低污染（§3.2，p.5）。
- Table 2 与 AI Scientist、MLAgentBench、MLGym-Bench 等对比：MLRC-Bench 覆盖方法提出与实现、有算力约束、可持续更新（p.3）。

**评价（阅读者分析）**：

- 与 MLE-Bench/MLAgentBench 的主要差异在任务来源（研究型竞赛）、仓库级代码和"相对人类最佳"的归一化，而非新的评测技术。
- 7 个任务规模小，且每个配置只取 8 次 trial 中的最好一次，单任务分数波动可能很大（如 Claude 在 machine-unlearning 上 −94.7）。
- "难以污染"的论证是推断性的，论文没有给出污染检测实验。
