# 具体用例

**用例：NeurIPS 2024 LLM Merging 任务**（Figure 1，p.4；附录 A，p.24）。

1. **输入**：任务描述要求"开发一种把多个预训练语言模型合并为通用模型的方法"，在时间约束内提升隐藏测试集表现；人类想法示例是 TIES Merging（三步处理后把合并的任务向量缩放加回基座模型）。
2. **仓库**：`data/dev.jsonl`、`data/test.jsonl`、只读的 `evaluation.py` 与 `main.py`，代理只能编辑 `methods/BaseMethod.py` 旁边的 `MyMethod.py`，或新增如 `MyAwesomeMethod.py` 的方法文件。
3. **代理过程**：MLAB 代理按 ReAct 方式循环"构思—写代码—执行—调试"，每次修改都被快照并在 dev 集上记录指标。
4. **评测**：取 dev 最好的快照在 test 上运行一次，按"相对人类最佳"归一化；同时记录运行时间和逻辑代码行数。
5. **主观分析（不计入排行榜）**：o1 先把带注释的代码解释成想法，再按有效性、清晰度、严谨性、泛化性、创新性打 1–5 分（§4.3，p.7）。

**结果**：Table 3 中该任务 MLAB（gemini-exp-1206）与 MLAB（claude-3-5-sonnet-v2）均为 5.0，o3-mini 和 Llama 为 −1.0（p.7）。

阅读者分析：该基准评测的是"代理改写研究代码并在固定预算内取得可测提升"，与本项目常见的逐条语义算子负载不是同一类任务（阅读者分析）。
