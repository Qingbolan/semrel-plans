# 出发点

整合多来源数据能回答单一数据集无法回答的问题，例如整合基因组、转录组、蛋白组与临床数据做泛癌分析，或结合卫星影像与地面传感器提升气候模型（§1，PDF p.1）。但即使有 FAIR 倡议，发现与集成数据集仍然困难：数据分散在只支持关键词搜索的仓库中，且不同数据集对同一属性用不同术语、或用同一术语指不同概念（PDF pp.1–2）。

作者认为数据集发现与数据集成共享一个根本难题：理解表格数据的模式和属性语义。例如集成两个数据集需要找属性对应，而按表查表的发现同样需要这些对应来判断可连接或可合并（§1，PDF p.2）。

LLM 编码了大量世界知识，可以把数据集的模式与内容放到真实语义中理解，并且不经任务微调也能完成数据集成任务（PDF p.2）。作者指出已有综述多聚焦 BERT 等较小模型，或忽视了 LLM 用于数据集发现的特定挑战，这是本文的切入点（PDF p.2）。

§2（PDF p.3）进一步说明 LLM 处理表格的困难：大表序列化使 token 数暴涨，测试时扩展方法加剧上下文消耗；表格内容高度异构；野外表格元数据经常缺失，网页抓取表甚至没有列名。

依据：§1–2，PDF pp.1–4。
