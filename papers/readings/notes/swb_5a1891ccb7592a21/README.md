# Vaghefi, Hachcham et al. — AI for Climate Finance: Agentic Retrieval and Multi-Step Reasoning for Early Warning System Investments

本文是系统演示论文：EW4All Financial Tracking AI-Assistant，用 Docling 解析多边开发银行（MDB）项目 PDF，经混合检索和 LLM 智能体多步推理，把预警系统（EWS）投资分到五个支柱并给出带证据片段的预算分配。在人工标注的 CREWS 基金语料上，智能体报告准确率 0.87、精确率 0.89、召回率 0.83，高于四个基线；另与 Gemini 2.5 Flash、OpenAI Assistants 做了对比。已读正文和附录 A–K 及 Limitations；正文与 Table 1 的提升幅度不一致，评测集合规模也有部分缺失，见评测栏。
