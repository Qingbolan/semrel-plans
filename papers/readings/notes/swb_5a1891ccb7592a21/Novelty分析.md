# 贡献与评价

**原文声明的贡献**（§1）：（1）集成子查询生成、混合语义/词法检索、自我验证护栏和按 schema 合并的智能体 RAG 流水线；（2）公开部署的网页系统；（3）CREWS 语料上的评测；（4）与黑盒助手的对比；（5）承诺开源标注语料、基准和提示词。摘要明确说各组件本身都是已有技术，贡献在于把它们整合进针对 MDB 报告的领域流程。

**方法要点**（§3、附录 A）：Docling 解析后把表格与正文分开切块，每块附 LLM 生成的文档级上下文摘要；用 OpenAI text-embedding-3-small 和 BM25F 检索，以 RRF（K=60）融合取前 5 块；智能体规划子任务和查询，检索结果不足时重新查询（"自愈"循环），最后按 schema 输出。

**评价**（阅读者分析）：
- 新意主要在工程集成和领域落地，不是检索或推理算法。
- 推理用的 OpenAI 模型名称和版本未写明（§4.3 只说"可配置"）。
- §6 称用 Monte Carlo dropout 估计不确定性，但系统通过 API 调用闭源 LLM，原文没有说明该方法作用在哪个组件上。
- 开源属于承诺（脚注 1、Reproducibility Statement），文中没有给出数据仓库地址。

依据：[EACL 2026 Demo，2026.eacl-demo.34，20 页](https://aclanthology.org/2026.eacl-demo.34)，Abstract、§1、§3、§4.3、§6、附录 A，PDF pp.1–3、5–8。
