# 具体用例

**用例：判断改写式参考译文 Human-P 的质量（英→德，Table 6a，p.7）。**

Human-P 由语言专家尽量改写现有参考译文得到，鼓励使用同义词和不同句式（§4.1(i)，p.8）。在不同评测下它的排名差异很大：

| 评测 | Human-P 得分（排名） |
|---|---|
| WMT（z 分） | 0.299（第 10） |
| WMT RAW | 84.2（第 9） |
| cSQM | 5.04（第 5） |
| pSQM | 4.32（第 3） |
| MQM（越低越好） | 1.41（第 3） |

作者据此认为众包者偏好直译、易评的译文而低估 Human-P；专业译者能看出改写译文是正确的，排名高于任何 MT。MQM 要求评分者用错误跨度为扣分辩护，有助于避免惩罚非直译译文（§4.1(i)，p.8）。

**另一个流程示例**：评分者看到一段译文，若"在孤立情况下可疑但在文档上下文中没问题"，不应标错；反之若某译法只在别的上下文中可接受，则应标错（Table 1，p.4）。

阅读者分析：这说明同一批输出在不同评测协议下可以得出相反结论；若用人工评分作语义任务的金标准，评分者资质与是否看到上下文是需要显式记录的变量。

依据：TACL 2021，§4.1、Tables 1、6，PDF pp.4、7–8。
