# 贡献与评价

论文声明三项贡献（§1，PDF p.2）：

| 贡献 | 内容 | 位置 |
|---|---|---|
| InfiAgent-DABench | DAEval 数据集 + 智能体框架（ReAct、文件交互、Docker 沙箱，支持 API 模型和 vLLM 本地模型） | §2，PDF pp.3–5 |
| 34 个 LLM 的评测 | 专有模型、开源通用模型、开源代码模型、智能体框架四组 | §3，PDF pp.6–8 |
| DAInstruct 与 DAAgent | 5,131 条样本、631 个 CSV，平均 ReAct 轮数 5.18；在 CodeLlama 上微调得到 7B/13B/34B 模型 | §2.5、附录 L，PDF pp.5–6、14 |

**关键方法**是格式提示（format-prompting）：让 GPT-4 为开放式问题生成约束和格式要求，使答案唯一、可解析（§2.1，PDF pp.3–4）。标签由 ADA 生成，每题询问 3 次，只保留三次一致的答案（§2.1，PDF p.4）。

阅读者分析：把开放问题转成“约束 + 结构化答案槽”的思路，使评测不依赖 LLM 评分，这是主要价值。代价是：问题的方法被约束写死，测的更像“按规定步骤正确执行分析”，而不是自主选择分析方法；标签来自 ADA 一致输出并经人工检查，本质上仍可能偏向 GPT 系模型的解法。可视化类问题被排除（附录 A，PDF p.12）。

依据：§1–2.5、附录 A、L，PDF pp.2–6、12、14。
