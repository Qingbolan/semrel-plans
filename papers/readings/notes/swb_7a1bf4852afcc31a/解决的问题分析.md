# 解决的问题

原文把任务看作检索与语义角色标注的结合，拆为三个子任务（§1，p.2；§4，p.4）：

1. **实验句识别**：输入一句，输出二值标签（是否描述 SOFC 相关实验）。凡含至少一个 EXPERIMENT 触发词的句子即为正例（§3.1，p.3）。
2. **实体识别与分类**：输入实验描述句，输出 MATERIAL、VALUE、DEVICE 以及 EXPERIMENT 触发词的 BIO 序列（§6，p.6）。
3. **槽位填充**：输入实验描述句，为 token 标上 16 种槽位之一，如 AnodeMaterial、FuelUsed、WorkingTemperature、PowerDensity（§3.3，p.3；Table 11）。

原始标注是以触发词为根的图，槽位是触发词到实体的边，并有 same_exp、exp_variation 链接（§3.3–3.4，pp.3–4）。建模时假设"一句一实验"，把槽位当作语境中的细粒度实体类型做序列标注（§4，p.4）。

阅读者分析：这一简化丢弃了图结构和跨句链接；补充 B 显示训练集 703 个实验句中有 135 句含多个触发词（p.12）。

依据：[ACL 2020，2020.acl-main.116，14 页](https://aclanthology.org/2020.acl-main.116.pdf)，§1、§3–4、§6，PDF pp.1–6；补充 B，p.12。
