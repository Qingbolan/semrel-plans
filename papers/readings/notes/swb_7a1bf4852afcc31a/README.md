# Friedrich et al. — The SOFC-Exp Corpus and Neural Approaches to Information Extraction in the Materials Science Domain

本文发布 SOFC-Exp：45 篇固体氧化物燃料电池（SOFC）开放获取论文，由领域专家按"Experiment"框架标注实验描述句、实体（MATERIAL/VALUE/DEVICE）和 16 种实验槽位。论文定义三个子任务（实验句识别、实体识别与分类、槽位填充）并给出 SVM/CRF、BiLSTM 与 (Sci)BERT 基线；槽位填充测试集宏 F1 最高 62.6，人类一致性 83.4。已通读正文与补充材料。
