# 解决的问题

**输入**：一条自然语言分析查询，以及包含表格、半结构化数据和文本的数据湖。**输出**：查询结果。系统先找出相关数据，再生成并执行由语义算子组成的管线（§2.1，pp.59–60）。

**离线阶段**：把各类数据嵌入同一语义空间，用 Louvain 社区发现得到分层的数据块，建立向量索引，并针对跨模态检索中的分布外问题另建 OOD 向量索引（§2.1、§2.3，pp.60、62–64）。

**语义算子（Table 1，p.60）**：共 7 类 21 个，例如：

- 变换类：OrderBy、Compare、Refine、Translate、Transform、Validate；
- 检索类：Scan、Filter、Augment；
- 抽取类：Extract、Conceptualize；
- 划分类：GroupBy、Cluster、Classify；
- 聚合类：SetOP、Integrate、Aggregate、Summarize；
- 其余为生成类（Generate、Explain）和关联类（Link）。

每个逻辑算子有多种物理实现，分为基于 LLM 的实现和预编程实现（如正则匹配）。用户自定义函数由 LLM 生成代码（§2.2，pp.61–62）。

**基本单位**：一个算子步骤。编排过程中维护中间变量列表，LLM 为每个中间结果写一段简短描述，用来决定后续算子的输入（§2.4，p.65）。

依据：§2.1–§2.4、Table 1，印刷页 pp.59–65（PDF pp.3–9）。
