# 贡献与评价

**原文主张**：

1. 提出用已决的法律案例作为真值、规模化评估“黑箱”商标检索引擎的方法；作者称这是首次以这种数据量做此类评估（§2.1，p.3）。
2. 首次比较 EUIPO 与 BOIP 两个官方图像检索系统，发现两者差距很大，EUIPO 结果“出奇地好”（摘要、§4）。
3. 统计检验与分组分析（KS 检验、按 LoC 结果分组），用于推测系统的内部行为（§3.3–3.4）。
4. 公开决定清单和逐决定的性能（GitHub Excel），但出于文本与数据挖掘例外的限制，不公开检索输出和决定原文（§2.1 脚注 11–12）。

**阅读者评价**：

- 方法可推广到任何只能通过界面访问的检索系统，但真值稀疏（每个查询一个相关项），因此更适合比较系统之间的召回差异，而不是衡量排序质量。（阅读者分析）
- 作者的主要假设是 EUIPO 系统可能就是用这些决定（或其主要子集）训练的，因为它近乎总在第 2 位命中。若属实，EUIPO 的高分反映的是训练集泄漏，而非泛化能力（§4，p.8）。原文明确说需要用另一组决定验证。
- 按 LoC 结果分组后，两系统表现差别很小（Table 5），说明它们未体现法律意义上的相关性。这是对“检索 ≠ 法律判断”的有力证据。（阅读者分析，依据 §3.4）
- 小的不一致：§3.2 称权利人 ID 标准的匹配率高于商标 ID，但 Table 4 中 EUIPO-50 的权利人 ID 为 61.94%，商标 ID 为 62.01%，Table 3 中两者相同（61.96%）。（阅读者分析）

依据：[ICAIL 2023, pp.343–350，8 页](https://orbi.uliege.be/bitstream/2268/322890/1/ICAIL2023.pdf)，摘要、§2–4、Tables 3–5，PDF pp.1–8。
