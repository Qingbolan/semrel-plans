# 工作负载

**来源**：AskExtension（连接公众与美国赠地大学合作推广专家的在线问答服务）。2012 年 12 月至 2025 年 4 月共汇集 21.8 万条单轮对话（§3.1，p.5）；§1 称从中精选出 37,512 段高质量对话（p.2）。

**MMST 统计**（附录 C.1，Table 4，p.27）：

| 项目 | Standard | Contextual | Standard 训练集 |
|---|---|---|---|
| 样本数 | 8,184 | 3,934 | 17,532 |
| 图像数 | 15,069 | 8,069 | 33,120 |
| 平均问题词数 / 答案词数 | 69.57 / 163.13 | 80.94 / 222.97 | 67.53 / 171.18 |
| 平均图像数 | 1.84 | 2.05 | 1.89 |
| 识别任务（植物 / 害虫 / 病害） | 4,324（2,600 / 1,146 / 578） | — | 7,398 |
| 管理任务 | 3,860 | 3,934 | 8,957 |
| 实体（植物 / 害虫 / 病害） | 4,485 / 1,732 / 639 | 999 / 306 / 200 | 1,725 / 840 / 320 |

三个子集合计 29,650 条交互、超过 5.6 万张图像。Contextual 只包含管理类任务。

**MMMT 统计**（附录 G.1，Table 25，p.56）：861 个样本，其中 Clarify 487（56.6%）、Respond 374（43.4%）；每个样本平均 2.11 张图、1.52 轮，最多 3 张图、14 轮；用户轮平均 109.9 词，专家轮平均 80.6 词。§2.1 称完整多轮语料有 6,306 段对话（约 1.2 万轮），评测集为其中 861 段。

**划分与已见/未见**：MMST 的 Standard 训练集用于 LoRA 微调；评测集中包含“数千个未见物种”（§2.1）。附录对未见实体的解释是：如果某实体名从未出现在微调集中，微调就帮不上忙（p.40）。正文未给出已见/未见实体各自的样本数。

**规模单位**：MMST 一条样本 = 一个问题 + 1–3 张图 + 元数据 + 专家答案；MMMT 一条样本 = 一个以用户话语结尾的对话片段 + 决策标签。

阅读者分析：§1 的 37,512 与附录的 29,650（MMST）+ 6,306（MMMT 全语料）= 35,956 对不上，摘要又写“超过 35,000”。几处汇总口径不同，使用时应以附录各表为准。
