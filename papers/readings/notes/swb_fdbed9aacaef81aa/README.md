# Abend & Rappoport — Universal Conceptual Cognitive Annotation (UCCA)

本文提出 UCCA：一种基于 Basic Linguistic Theory 与认知语言学、刻意脱离具体句法形式的多层语义表示框架，并详细定义了其粗粒度的基础层（以 Scene 为核心，共 12 个边类别、用 DAG 表示）。论文还介绍了一个以英文维基名人条目为主的 UCCA 语料（已标注 148 段、56,890 token）。主要量化结果为：无语言学背景的标注者能较快学会（与金标准的括号 F1 从 67–78% 升至约 78–84%），专家修正后的一致性为 93.7%，与 PropBank 对比的无标签 F1 为 89.4%。已阅读全文。
