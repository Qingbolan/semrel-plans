# Zhang et al. — DataSciBench: An LLM Agent Benchmark for Data Science

DataSciBench 是数据科学方向的 LLM 评测：222 个提示、519 个测试用例，用 Task-Function-Code（TFC）元组和 25 个聚合函数对代码执行结果打分，共测 23 个模型。GPT-4o 总分最高（64.51），开源模型中 Deepseek-Coder-33B-Instruct 最高（56.76）。已读正文及数据构造、评分规则相关附录，Table 2 已渲染核对；附录逐例案例只浏览了部分。
