# 解决的问题

评测单位是一个提示，包含输入数据或文件、任务说明和要求输出的文件（§3.2 专家审核第 2 阶段）。被测模型通过 Data Interpreter 风格的 agent 生成并执行代码，产出文件。

每个提示对应一个 TFC 列表 R={(Ti,Fi,Ci)}。T 是六类任务之一：清洗与预处理、探索与统计、可视化、预测建模、挖掘与模式识别、可解释性与报告；F 是评价函数；C 是评价代码（§3.1、§3.3）。

评价代码的初始输出是布尔值或 0–1 小数；小数按阈值转为布尔值（如轮廓系数阈值 0.5），再与真值比较得到 0/1（§3.3 Programmatic Rules）。

真值来源：BigCodeBench 题用原测试用例验证后人工复核；其余题多次采样做 self-consistency，再由 6 位作者核对，存疑项由 3 位作者交叉验证（§3.3）。
