# problem

输入是一篇英文议论文（按段落、句子、token 切分）。输出是论证结构：(1) token 级的论证成分边界（IOB：Arg-B/Arg-I/O）；(2) 成分类型 MajorClaim/Claim/Premise，主张带 for/against 立场；(3) 段落内的有向关系，每个前提恰有一条出边指向主张或另一前提，主张无出边；(4) 支持/攻击立场。整篇建模为以主要主张为根的连通树，段落内可以形成多棵树（允许未连接成分）。

解析器是五步流水线：CRF 成分识别 → SVM 成分分类 → SVM 关系识别 → ILP 树生成（联合优化前两个分类器的输出，约束每个成分至多一条出边、至少一个根、无自环、无环）→ SVM 立场识别。除识别步骤外，下游模型评测时使用金标准成分边界。主要主张与主张之间的关系不显式标注（主张总连到主要主张）。

依据：[Stab & Gurevych, Computational Linguistics 43(3):619–660, 2017，42 页](https://aclanthology.org/J17-3005.pdf)，§3.2、§5、§5.3.3，PDF pp.9–11、16–17、25–26。
