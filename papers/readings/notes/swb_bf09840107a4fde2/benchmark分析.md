# 评测与边界

**设置**（§3.1、附录 C.6，PDF pp.6、52）：3 个闭源模型（GPT-4o、Claude-3.7-Sonnet、Gemini-2.0-flash）、7 个开源指令模型、2 个推理模型（QwQ-32B、EXAONE-Deep-32B，只跑 CoT）；零样本与自由 CoT 两种提示；温度 0，vLLM 推理。随机基线为 20 次随机作答的平均。

**实验 1（三项任务基线，Table 2 自定义分，PDF p.6）**：

| 模型 | PAR4PC ZS / CoT | PI4PC ZS / CoT | NOC4PC ZS / CoT |
|---|---|---|---|
| 随机 | 5.63 | 27.10 | 32.33 |
| GPT-4o | 47.34 / 56.95 | 63.33 / 62.62 | 34.69 / 32.19 |
| Claude-3.7-Sonnet | 40.12 / 40.29 | 57.33 / 60.55 | 35.84 / 45.40 |
| Qwen2.5-32B | 68.94 / 55.05 | 60.55 / 59.94 | 26.88 / 33.85 |
| Gemma-3-12B | 56.47 / 77.30 | 44.34 / 31.11 | 32.54 / 17.67 |

原文结论：检索与段落定位多数模型明显高于随机；NOC4PC 多数模型低于或略高于 32.33，若干模型把预测塌缩到单一类别（如 GPT-4o 零样本偏向 §103，CoT 偏向 ALLOW）（§3.2–3.4，pp.7–8）。PI4PC 上多数模型零样本反而优于 CoT（§3.3，p.8）。

**实验 2（SFT，Table 3，PDF p.8）**：3 个 7–8B 模型只在零样本设置下微调（缺少真实 CoT），PAR4PC 升至 77.98–82.92，PI4PC 65.84–69.95，NOC4PC 48.34–51.71。

**边界**（§4，p.9）：基准抽象了真实审查；尚未验证专家在这些任务上的难度，也未验证基准分数能否预测实际审查表现；仅限 USPTO；缺少"为何允许"的理由。

阅读者核对：§3.2 正文说 Qwen2.5-32B 零样本最高为 47.34，但 Table 2 中 47.34 属于 GPT-4o，Qwen2.5-32B 为 68.94；§2.3 称专家验证分 60 个 bundle，附录 B.4.1 则写 20 个 bundle（阅读者分析）。
