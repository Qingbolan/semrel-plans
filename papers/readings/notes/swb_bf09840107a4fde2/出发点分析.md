# 出发点

专利审查要判断一项权利要求相对于现有技术是否具备新颖性（35 U.S.C. §102）与非显而易见性（§103），需要深入领域知识与细致比对（§1，PDF p.1）。作者指出，以往 NLP 研究多把它当作预测任务——预测授权结果、用相似度或基于历史标签的分类器做代理——忽略了审查员逐步评估的过程以及审查意见书中写明的理由，因此也难以衡量技术在审查各环节的真实水平（摘要、§1，PDF p.1）。

作者主张把注意力从"预测准确率"转向"与专家判断对齐的可专利性评估"，需要把审查员的工作流和决策轨迹拆成可度量的数据与任务（§1，PDF pp.1–2）。

阅读者分析：这一动机与"语义算子"类工作相关——任务实质是在长文档集合上做逐条比对、证据定位与判定，而且有真实的审查员理由可作参照；但原文只做 LLM 提示与微调基线，未涉及系统层优化。
