# Wilson et al. — The Creation and Analysis of a Website Privacy Policy Corpus

本文发布 OPP-115 语料：115 份美国网站英文隐私政策（266,713 词），由法学学生按专家设计的 10 类数据实践方案逐段标注，共 23,194 条数据实践、128,347 个属性值和 102,576 个文本片段。论文还给出多标注者合并（consolidation）方法，并在 3,792 个段落上用 LR、SVM、HMM 做段落类别多标签预测，SVM 微平均 F1 为 0.66。已读正文 §1–§7 与 Tables 1–3；Figures 2–3 的曲线只按正文描述引用。
