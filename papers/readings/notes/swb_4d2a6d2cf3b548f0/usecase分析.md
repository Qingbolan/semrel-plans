# usecase

论文 Fig.2 的例句说明了事件结构：
- "sell" 是单词触发词；
- "sales … stall" 和 "revenues … rise" 是不连续的多词触发词，分别对应 SalesVolume、Revenue 等类型的变化子类型（§4，PDF p.9）。

一个分析师场景：从公司新闻中找出某公司的分析师评级事件。例如 Rating 类型，子类型包括 Buy/outperform、Upgrade、Price target 等（Table 2）。需要抽取：
- 评级机构（参与者论元）；
- 目标价（填充论元）；
- 时间（填充论元）；
- 否定和情态，用于过滤推测性或没有发生的事件（作者明确把事实性用于知识库填充和市场建模，p.10）。

误差分析显示了难点（§7.4，p.26）：
- 缺少强词汇线索时，需要文档级上下文才能判断；
- 触发词有歧义，例如 "Buy" 可能是评级，也可能是并购；"Spending" 可能是 SalesVolume，也可能是 Expense。

阅读者分析：把该语料用作语义过滤或结构化抽取工作负载时，应保留不连续触发词、跨句论元和共指链。按句子独立处理会丢失部分论元和事件。

依据：[LRE 56:225–257，33 页](https://doi.org/10.1007/s10579-021-09562-4)，§4、§7.4，Fig.2、Table 2，PDF pp.9–13、26。
