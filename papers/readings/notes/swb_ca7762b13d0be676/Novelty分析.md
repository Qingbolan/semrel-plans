# 贡献与评价

**原文声称的三项贡献**（§1，p.2）：

1. 一个融合分层待证事实、证据与经验的 schema（改造自 Wigmore/Anderson 图示法）。
2. 新任务 TL，以及众包数据和对应指标；作者称这是该任务首个众包数据集。
3. TL Agent：ReAct 式策略，工具包括事实/证据抽取头、向量检索（chroma + bge-large-zh-v1.5）、法律知识、多角色检查（律师/法官/警察投票）、反思、情感检查、模式匹配（§4）。

**阅读者评价**：

- 新意主要在任务形式化：把“经验法则”作为显式节点，可监督地生成。指标全部基于 ROUGE 和三元组重合，无法检验推理是否在法律上成立。（阅读者分析）
- 训练/验证集先由 LLM 预标注、再由人工修订；测试集为“全面人工标注”（§3.1–3.2）。预标注可能把 LLM 的表述风格带入训练数据，原文未分析其影响。（阅读者分析）
- 一致性只报告“Spearman 与 Pearson 相关均高于 0.93”，未说明计算对象（附录 B）；可靠性检查只用 15 个样本问卷，95% 被判正确（附录 C）。
- 原文自承：TL Agent 结果好的原因未深入研究；开放式提示需要领域专家设计 schema，耗时（Limitations）。
- 数字核对（阅读者分析）：Table 1 中证据（14,578）和事实（2,627）总数与正文一致，但经验总数 9,550+1,863+4,450=15,863，正文写 16,414；指令数据规模正文先写“超过 40,000”（§3.2），后写“5w”（§5.1）。

依据：[Findings of ACL 2025, pp.17252–17274，23 页](https://aclanthology.org/2025.findings-acl.887.pdf)，§1、§3–4、Limitations、Table 1、附录 B–C，PDF pp.1–6、9、13–14。
