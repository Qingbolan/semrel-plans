# 解决的问题

**任务形式**（§5）：把抽取式摘要表述为句子级二分类——输入一篇评论中的每个句子及其特征，输出该句是否进入摘要（关键句）。

**金标准单位**（§3、§3.1）：每篇文本由标注者选出 3 个"最能代表文本核心"的句子并排序；排序信息用于协调双标注，模型训练只用"是否关键句"。

**特征**（§5.1、Table 2）：

| 类别 | 特征 |
|---|---|
| 语篇（RST，人工标注树） | 句子级核/卫星、所属关系、深度分（取句内 EDU 最大值）、是否含 most-nuclear EDU |
| 非语篇 | 句长（token）、相对位置 |
| 嵌入 | S-BERT 多语句向量；作者提出的"带文档上下文"句向量（整篇输入后按句界平均 token 向量） |

**输出与指标**：关键句类（少数类）的 F1、R、P 以及整体准确率；另报告测试集 ROUGE-1（§5.3）。

阅读者分析：RST 特征来自 PCC 的人工树，而非自动句法分析器；论文结论描述的是"金标准语篇结构"可提供的信息上限，原文在结论中也把自动解析留作后续（§7）。

依据：[COLING 2022，10 页](https://aclanthology.org/2022.coling-1.63)，§3、§5、§7、Table 2，PDF pp.2–3、6–9。
