# 出发点

作者认为传统数据分析流水线虽然能提取统计规律，但依赖领域专长、手工特征工程与多种专用工具，随数据规模、复杂度与异构性增加而更难用（§1.1，p.1）。原文归纳四个局限（p.2）：

| 编号 | 局限 | 原文示例 |
|---|---|---|
| L1 | 封闭世界假设：系统针对特定数据类型优化 | 分析带时间戳描述的视频时需人工对齐帧与文档 |
| L2 | 工具强耦合 | 从知识图谱取统计量再做回归，需先写 GQL 再换 ML 库 |
| L3 | 仅字面分析 | SQL 只能匹配关键词，无法理解长文本单元格的情感、意图 |
| L4 | 依赖手工开发 | "上季度高级客户平均配送时间"需人工找表、写多表连接、对齐时间语义 |

对应地提出 LLM 带来的四个机会（§1.2，pp.2–3）：跨模态开放世界数据支持、以自然语言为接口的工具无关交互、语义算子（语义聚合、过滤、连接）、自动的工作流编排与演化。

阅读者分析：与以往只覆盖单一模态或任务（NL2SQL、表格问答、文档或图表理解）的综述相比，本文的出发点是把这些分散方向放进一张"模态 × 交互语言"的总图里（§1.4，p.5）。

依据：§1.1–1.2、§1.4，pp.1–3、5。
