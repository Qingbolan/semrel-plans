# 解决的问题

**任务**：给定自然语言问题 q 和数据库模式 s（若干表，每表若干列），生成能回答 q 的数据可视化查询 v（DVQ）（§2，p.3）。

**DVQ**：Luo 等提出的中间表示，先在数据库上执行查询取数，再定义可视化细节；不绑定某一种可视化语言，可转换为 Vega-Lite 等规格。Figure 1 的例子是 `Visualize BAR SELECT Date_Claim_Settled, COUNT(Date_Claim_Settled) FROM Settlements ORDER BY ... BIN Date_Claim_Settled BY YEAR`，再转换为 Vega-Lite JSON（Figure 1、§2，pp.2–3）。

**上下文学习形式**：训练集 D 由（question, schema, dvq）三元组组成；对目标问题选 K 个示例构成提示 P，由 LLM g 生成 v_t = g(P, (q_t, s_t))（§3.1，Eq.1，p.3）。

**两个子问题**：

1. 示例挑选：以“问题”为单位，从训练集中选出 K 个有效示例（§3.2，p.3）。
2. 模式过滤：以“表”为单位，选出覆盖金标准 DVQ 所用模式元素的子集，且远小于完整模式（§3.3，p.5）。作者选表而非列，因为自然语言与列名往往没有直接语义联系，且 DVQ 可能跨多表多列操作。

**评测单位**：一条（问题，数据库）样本生成一条 DVQ，按可视化类型、坐标轴、数据部分与整体是否与金标准一致计准确率（§4.1.3，p.5）。

依据：§2–§4.1，PDF pp.2–5。
