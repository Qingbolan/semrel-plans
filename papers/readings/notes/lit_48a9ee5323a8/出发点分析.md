# 出发点

声明式可视化语言（Vega-Lite、ggplot2、ECharts 等）要求用户熟悉数据和语法，门槛高；text-to-vis 旨在把自然语言问题直接转换为可视化查询（§1，p.1）。

已有方法包括规则/语义解析系统（DeepEye、NL4DV）、编码器—解码器神经网络（Seq2Vis、ncNet）和检索—修订框架（RGVisNet）。作者认为它们性能仍不理想，尤其在测试数据来自不同领域时（§1，pp.1–2）。

LLM 的上下文学习不依赖大规模标注、不需更新参数，作者认为可借此缓解泛化不足；但 LLM 对示例选择敏感，而且把整个数据库模式编码进提示既昂贵又会引入无关信息。这两点分别对应示例挖掘与模式过滤两个模块（§1，p.2）。

阅读者分析：与 2025 年的 nvAgent、nvBench 2.0 相比，本文时间更早（2024 年 1 月预印本），对比对象是 LLM 之前的神经网络基线，没有与其他 LLM 可视化系统（Chat2Vis、LIDA）做实验比较，后者只在相关工作中提及（§5.2，p.9）。

依据：§1、§5，PDF pp.1–2、8–9。
