# 具体用例

**用例：四家 IT 公司股价数据视频**（§3，pp.2–3；Figure 2）

1. **感知（A）**：系统用 LLM 根据数据标题和内容生成自然语言描述，概述数据主题并说明每列语义。
2. **洞察（B）**：数据分析师智能体提取多条不同类型的洞察。
3. **可视化（C）**：用折线图展示各公司股价随时间的变化；提示要求折线图包含数据点。
4. **旁白（D）**：先概述，再逐一介绍每家公司的表现，最后总结。
5. **注释（F）**：设计师根据旁白，在每家公司的折线上加点和文字注释，突出其显著特征。
6. **动画（E）**：视频以展示全部元素的入场动画开始；讲到某家公司时单独高亮该折线。Figure 2 底部的关键帧编号对应旁白中的时间戳。
7. **合成**：控制器调用 TTS、Vega-Lite 渲染器和视频合成器生成最终视频。

作者对结果的评价是"叙事流畅、可视化与动画设计得当、视频引人入胜"（§3，p.3），这是作者自评，没有用户研究或评分。

阅读者分析：单案例无法说明系统在其他数据（如分类数据、饼图场景）上的稳定性；原文也未报告是否需要人工挑选或多次重试才得到该结果。
