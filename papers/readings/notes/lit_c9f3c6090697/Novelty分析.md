# 贡献与评价

**论文声称的贡献**（§1，p.2）：

1. 提示生成：用 LLM 从少量输入输出对生成候选指令，按评分排序并用蒙特卡洛搜索改进；示例选择用输入编码器与示例编码器的 L2 距离取 top-k，并按相似度升序排在输入前；用 Q-learning 等强化学习模型降低示例选择开销；兼顾提示长度与效果（§2.2，pp.3–4）。
2. 微调：将数据分布（如分位数）和并发查询关联图嵌入后与文本嵌入拼接；用对比式成对比较扩增样本（k 个配置可得 C(k,2) 对）、用 LLM 生成推理标注；用 adapter 与 LoRA 式低秩分解做 delta tuning（§2.3，pp.5–6）。
3. 数据库专用 LLM：用 SMT 求解器或学习式检查层校验输出有效性；用 “[Table Data][Query]→[Logical Plan]→[Physical Plan]→[Result][Execution Time]” 序列训练；用外部记忆的长程注意力；用联邦学习与蒸馏保护隐私（§2.4，pp.6–7）。

阅读者分析：第 2、3 条只停留在设想（Vision），没有实现或实验；已实现的部分是提示生成加 PostgreSQL 对比，实验规模很小（12 条查询、IMDB 负载）。作为 2023 年中的早期愿景文，其价值在于系统梳理研究议程，不在实证结论。

依据：§1–§3，PDF pp.2–8。
