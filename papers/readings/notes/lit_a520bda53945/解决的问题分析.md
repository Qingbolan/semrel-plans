# 解决的问题

形式化（§2.1，p.2）：给定任务 Q、数据集集合 D={d1..dn}、预定义算子集合 O。画像智能体离线在 D 上构建画像图 G(D)；规划智能体生成计划 P=plan(Q, G(D), O)；校验器与记忆给出批评反馈 C(P)，迭代更新 P_{i+1}=argmin C(P_i)；优化器降低执行成本与延迟，执行器运行优化后计划输出结果。

- 输入：自然语言问题；结构化表（PG/Oracle/MySQL、CSV）、半结构化 JSON、文本文件，以及经 MCP 接入的 Web 搜索（Fig.1，p.2）。
- 输出：问题答案；中间产物是树形语义逻辑计划——叶子是数据访问方法，中间节点是 9 种关系算子与 6 种语义算子，另可由 LLM 生成代码支持未预定义算子（§2.1、§4.3，pp.2、6）。
- 关键子问题：画像图（节点为表或文档的摘要/schema/样例/嵌入，边为向量、BM25、关键词 Jaccard 相似发现的关联与可连接属性，§3，pp.3–4）；数据选择（关键词 Jaccard≥0.75 或 BM25≥0.75，按余弦取 top-10，再加图上关键路径上的间接相关数据，§4.2，p.5）；复杂问题拆分为子任务并物化中间结果（§4.3，p.6）。

阅读者分析：评测单位是“一个问题的最终答案是否正确”，而不是计划本身的正确性。
