# Sun, Li et al.（清华）— AgenticData: An Agentic Data Analytics System for Heterogeneous Data

AgenticData 把自然语言分析问题翻译成由关系算子与语义算子（Semantic Scan/Extract/Filter/Group/Join/Classify）组成的树形语义计划，核心是数据画像图、MDP 式多步规划、语法/语义/数据缺失校验和“好/坏计划”记忆。在 DABStep、DABench、Spider-2.0-Lite、Real-Bank、Wikipedia 五个基准上报告了最高或接近最高的准确率（如 DABStep-hard 72.2%，Fig.8），并称已部署于银行和电网。已读全文正文 §1–9；Fig.8 已渲染核对读数。
