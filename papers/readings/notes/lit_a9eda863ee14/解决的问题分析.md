# 解决的问题

**形式化**：表 T 有 t 列 r 行，每列 C_i 映射行号到字符串。列名和表元数据可以有，但不强制（§3，p.4）。
- **微调 LLM-CTA**（Def. 3.1）：标签集 L 在训练时固定，生成式模型 M(σ, L) 要输出 L 中的正确标签。
- **零样本 LLM-CTA**（Def. 3.2）：行数小到无法微调，L 在测试时给定，同一张表可以定义多套 L（p.4）。

**工作单元**：单列。ArcheType 采用逐列（column-at-once）序列化，只把待分类的那一列送入 LLM，而基线方法是整表输入（§3.3，pp.6–7）。

**四个阶段**（§3.1–3.5，pp.5–8）：
1. **上下文采样**：在唯一值集合 U_i 上按重要性函数 f 加权抽 φ 个样本。Amstr 用"是否包含任一类名"作为 f，取值 1 或 0.1；其余数据集用字符串长度（Algorithm 1）。
2. **提示序列化**：零样本时把提示风格当作超参，在六种模板 C/K/I/S/N/B 中搜索；全数值列只保留数值标签（Figure 3）。
3. **模型查询**：零样本用 T5、UL2、GPT；微调用 LLAMA-7B（Alpaca 格式）。
4. **标签重映射**：把超出 L 的输出映射回 L，方法有 contains、resample（k 次改变温度等参数重新调用）和 similarity（S3Bert 余弦）。另有每个数据集最多两小时人工编写的规则重映射，结果中用 "+" 标出（Table 2）。

依据：§3，pp.4–8。
