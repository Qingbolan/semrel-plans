# 具体用例

**Vial（药瓶）检测**：单个装有透明起泡液体的药瓶，用平面背光照明以显露全透明或半透明的污染物，例如小塑料膜颗粒（§3.5，p.6）。缺陷包括异物污染、二维码损坏或缺失、液位偏差、瓶盖打开或缺失（Table 3，p.5）。难点是瓶身与缺陷透明、缺陷小且对比度低，以及瓶子旋转、气泡、二维码导致的正常态变化。

测试时额外加 3 个 LED 点光源：一个从上方造成不均匀照明，两个制造镜面高光（§3.5，p.6）。模型只用正常药瓶训练，提交的是像素异常图；按 Table 7，PatchCore 在 Vial 上的 AU-PRO0.05 由 TESTpriv 的 62.2% 降到 TESTpriv,mix 的 59.1%，MSFlow 则由 38.0% 跌到 4.0%（p.10）。

阅读者分析：该用例的产出是像素图与"合格/拒收"判定，不涉及文本查询。

依据：[arXiv:2503.21622v1，21 页](https://arxiv.org/pdf/2503.21622v1)，§3.5、Tables 3、7，PDF pp.5–6、10。
