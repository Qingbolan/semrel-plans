# 评测与边界

**指标**：触发词分类的 micro P/R/F1。序列标注模型用基于 span 的指标（§5.2，PDF pp.6–7）。

**实验 1（总体结果，Table 5，PDF p.7；10 次均值）**：

| 模型 | ACE 2005 F1 | MAVEN F1 |
|---|---|---|
| DMCNN | 68.0 | 60.6 |
| BiLSTM | 76.8 | 62.8 |
| BiLSTM+CRF | 75.4 | 64.1 |
| MOGANED | 72.1 | 63.8 |
| DMBERT | 74.3 | 67.1 |
| BERT+CRF | 74.1 | 67.8 |

所有模型在 MAVEN 上都更低，且标准差更小。在 ACE 上 BiLSTM 反而好于 BERT 模型，作者认为这说明小数据集无法稳定评测（§5.3）。CRF 在 MAVEN 上有明显收益，作者归因于一句多事件的现象更常见（§5.3、Figure 3）。

**实验 2（数据量与类型数，Figures 4–5，PDF p.7）**：训练数据越多 F1 越高；要区分的类型越多，F1 越低。

**实验 3（迁移到 ACE，Table 6，PDF p.8）**：

- 直接把 18,729 个 MAVEN 实例加入 ACE 训练集，DMBERT 的 F1 从 74.3 降到 72.4。
- 先在 MAVEN 上做中间预训练，F1 升到 75.1。
- 两个数据集的类型映射是人工构建的不完整映射（附录 B）。

**实验 4（错误分析，Table 7，PDF p.8；开发集）**：识别错误（FP/FN）最常见。在类型错误中，父子类错误占 13.1–15.5%，兄弟类错误占 14.6–19.8%，错分到数据量前 50% 类型的占 86.8–90.3%。

**边界**：

- 复现模型的超参数经过手工调整，结果可能与原论文不同（§5.2）。
- 第一阶段标注一致性较低（§3.4）。
- 只覆盖英文维基百科。
- 不含论元和事件关系，作者把这些列为后续工作（§7，PDF p.9）。
