# 具体用例

**原文示例**（§1，PDF p.1）：在句子 "Bill Gates founded Microsoft in 1975" 中，模型应识别出 "founded" 是 Found 类事件的触发词。

**MAVEN 中的标注流程**（§3.3–3.4，PDF p.4）：

1. 用 NLTK 把句中的实词和能匹配 FrameNet 的短语列为候选。
2. 框架语义解析器为部分候选预填类型，并按 GloVe 词向量相似度为每个候选推荐 15 个类型。
3. 两名众包标注者独立选定类型或将候选标为非触发词，并合并指向同一事件的提及。
4. 第二阶段由专家定稿。

**层级类型的作用**（§3.1、§5.6，PDF pp.3、8）：例如 Theft 和 Robbery 是细类型，Committing crime 是粗类型。错误分析显示，模型常把类型错分到父/子类或兄弟类。作者认为层级 schema 可以帮助区分相近类型。

阅读者分析：如果把 MAVEN 用作"从文档中筛出某类事件句"的语义过滤负载，候选集合、细/粗类型的选择规则以及事件与提及的区别都会影响计数方式。
