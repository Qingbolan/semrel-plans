# 解决的问题

论文定义三个任务（§2.1，PDF p.3）：

| 任务 | 输入 | 输出 |
|---|---|---|
| Description-to-Chart | 图表描述 x | 生成该图的 Matplotlib（3.8）代码 c |
| Raw Data-to-Chart | 原始数据表 d | 中间推理步骤 r（分析数据特征、候选图类型），再生成最适合图类型的描述 x |
| Code-to-Description | 绘图代码 c | 详细描述 x |

数据单元是元组 (x, c, d, r, y)：描述、代码、数据表、推理步骤、渲染出的图像 y；其中 d 和 r 仅 8,166 条具备（§2，PDF p.3）。

**训练问题**：三个任务各训练一个策略模型 π1、π2、π3。先做 SFT，再用 PPO 联合优化 π1（偏好奖励）和 π3（对齐奖励）；π2 只做 SFT（§3，Algorithm 1，PDF pp.4–5）。

- 偏好奖励：把真值代码作为偏好样本 c+、SFT 模型输出作为非偏好样本 c−，训练奖励模型 Rϕ。
- 对齐奖励：π1 从描述生成代码，π3 再从代码复原描述，用 BERTScore 衡量原描述与复原描述的相似度（§3.2，PDF p.5）。

阅读者分析：任务 2 输出的是"描述"，不是直接的图；评测时还要再把描述交给另一个模型生成代码（阅读者分析，依据 §4 评测指标，PDF pp.5–6）。
