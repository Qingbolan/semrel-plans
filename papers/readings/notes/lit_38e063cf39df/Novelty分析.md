# 贡献与评价

**作者声明的贡献**（§1，PDF p.2）：

1. 分层数据生成流水线：主题生成 → 描述生成（GPT-3.5，GPT-4 自评过滤）→ 代码生成（GPT-4，必须能无错误运行）→ 数据表与推理步骤（GPT-4）→ 循环一致性校验。
2. Text2Chart31 数据集：31 种图类型、11.1K 元组，Shannon 多样性 0.980，Distinct-n 内容多样性 0.674（Table 1，PDF p.4）。
3. 首个用于图表生成的 RL 指令微调方法，奖励无需人工反馈。

**与已有数据集比较（Table 1）**：ChartLlama 有 7.8K 描述到代码数据、10 种图类型；ChartX 有 6K、16 种；Text2Chart31 有 11.1K 描述到代码、8.2K 原始数据到描述、31 种类型，并覆盖 3D/体数据 5 种。

**评价**：

- 原文事实：数据全部由 LLM 生成，Ethics Statement 明确这些数据点不代表真实事实（PDF p.9）。
- 数据集与评测真值都由 GPT-4 生成，并以 GPT-4 循环一致性过滤，测试集风格与 GPT 系列输出相近；把它当作对闭源 GPT 的公平对比时需保留这一偏差（阅读者分析）。
- 阅读者分析：RL 带来的增益较小，例如 L3I-8B 总错误率 16.09→14.55、CLI-13B 9.49→9.21，CLI-13B 的 METEOR 和 CodeBLEU 反而下降（0.581→0.566、0.481→0.467），且未报告多次运行方差（阅读者分析，依据 Table 2，PDF p.7）。
