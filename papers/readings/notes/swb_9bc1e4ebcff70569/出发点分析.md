# 出发点

金融、法律、医疗等领域的文档理解主要靠人工，费时且难以扩展。文档 VQA 要求模型利用文本、版面和图像信息回答问题（§1）。

现有数据集各有欠缺：DocVQA 多为 1960–2000 年的低分辨率行业文档，答案均可抽取；VisualMRC 和 WebSRC 是网页截图；InfographicVQA 针对信息图（§2.2）。这些数据集都不针对“半结构化表格 + 文本 + 大量数字”的商业文档，也几乎没有工作研究这类文档上的离散推理（§1、§2.3）。

作者因此在 TAT-QA（人工挑选的单表格 + 相关文本）基础上，回到原始财报页面，构建更接近真实场景的数据集：一个文档可含多张表，文本也不一定与表格相关，且可跨多页（§3.2）。

依据：[arXiv:2207.11871v3，10 页](https://arxiv.org/abs/2207.11871)，§1–§3.2，PDF pp.1–3。
