# 评测与边界

**基线**：NumNet+ V2（文本离散推理）和 TagOp（TAT-QA SOTA）。两者都改为把 TF-IDF 排序后的文本块作为输入；TagOp 不做表格处理（§5.1）。

**实验 1（TAT-DQA，Table 4）**：

| 方法 | 开发 EM/F1 | 测试 EM/F1 |
|---|---|---|
| 人类专家 | – | 84.1 / 90.8 |
| NumNet+ V2 | 28.1 / 36.6 | 30.6 / 40.1 |
| TagOp | 32.3 / 39.6 | 33.7 / 42.5 |
| MHST（RoBERTa-L，纯文本） | 37.1 / 43.6 | 39.8 / 47.6 |
| MHST（LayoutLMv2-L） | 39.1 / 47.4 | 41.5 / 50.7 |

**实验 2（按答案类型，测试 F1，Table 5）**：Span 58.3、Spans 43.3、Counting 43.2、Arithmetic 42.7。

**实验 3（TAT-QA，Table 6）**：MHST（RoBERTa）测试集 EM/F1 为 63.6/72.7，TagOp 为 50.1/58.0。

**实验 4（挑战分析）**：给基线加上表格块检测后，TagOp 的 F1 提升 3.9%（Fig. 3）。多页文档明显差于单页，长文档明显差于短文档（Figs. 4–5）。

**实验 5（错误分析）**：随机抽取 100 个错误，Span 预测 37%、表达式树 34%、序列标注 25%、scale 4%（Table 7）。

**边界**：人类表现只在测试集上报告；多页/长度分析使用纯文本 MHST，并只在单页子集上比较长度（§5.3.3）。

阅读者分析：没有报告方差或多次运行；人类专家的评测样本量和流程，正文未说明（阅读者分析）。

依据：[arXiv:2207.11871v3，10 页](https://arxiv.org/abs/2207.11871)，§5、Tables 4–7、Figs. 3–5，PDF pp.6–8。
