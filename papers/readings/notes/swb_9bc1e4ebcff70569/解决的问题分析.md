# 解决的问题

**任务定义**（§3.1）：给定一个含表格和文本、共 1–3 页的视觉富文档 D，以及问题 Q，模型 F 输出答案 a，即 F(D,Q)=a。每页由 PDF 解析或 OCR 转为图像加带 bbox 的词列表。

**答案类型**（§3.2.1）：

- Span：单个连续文本片段。
- Spans：多个不连续片段。
- Counting：计数得到的整数。
- Arithmetic：加减乘除及其组合计算出的数值。

此外，每个答案都有 scale（None / Thousands / Millions / Billions / Percent）；Counting 和 Arithmetic 问题还保留推导式。

**工作单元**：问答对，每个问答对对应一个文档。划分按文档进行，同一文档的问题只出现在一个子集中（§3.3）。

例（Fig. 1）：问“2019 年 Wireless 含频谱许可费的总成本”，推导为 1,320 + 1,731 = 3,051，scale 为 Millions，答案为 3,051,000,000。

依据：[arXiv:2207.11871v3，10 页](https://arxiv.org/abs/2207.11871)，§3.1–§3.3、Fig. 1，PDF pp.1、3–4。
