# 解决的问题

任务定义（§4）：检索函数 R:(q, D)→D_r。输入查询案件 q，含事实 q_f 与时间戳 q_t；候选集合 D 只包含时间早于 q 的判决，每篇含事实 d_f、推理 d_l 和时间戳。输出按相关分数排序的候选列表。工作单位是"一个案件的事实部分 → 一个排序列表"。

相关性标签来自该查询判决推理部分对既往判决的引用（经抽取并映射到具体文档版本），不是人工逐对标注。候选文档默认使用事实+推理全文；§5.5 另外只用事实或只用推理做对照，用来检验 Halsbury（推理具有约束力）与 Goodhart（事实类比）两种关于 ratio decidendi 的观点。

阅读者分析：标签只代表"法院实际引用了"，未被引用但实质相关的案件被当作负例；作者在 §5.3 解释难负例失效时也承认可能存在这种假负例。

依据：§3.3、§4、§5.3、§5.5，PDF pp.4–5、7–8。
