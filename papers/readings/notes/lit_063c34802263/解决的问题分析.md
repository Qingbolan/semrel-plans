# 解决的问题

任务形式沿用 SpreadsheetBench（§3.1，p.4）：输入为一个或多个初始表 Di 与自然语言指令 T；智能体（LLM）在多轮中交替推理与调用工具，执行一串表格操作得到最终表 DA；目标是与 oracle 表 DO 在"操作区域 M"（目标 sheet 与单元格范围）上一致。M 只用于奖励计算，不提供给模型。

奖励（式 1，p.6）：无有效输出为 0，否则为 allcellsmatch(Dpred, Do)，即操作区域内全部单元格匹配时为 1。比较前按 SpreadsheetBench 规范归一化：数字四舍五入到 2 位小数、日期转 Excel 序列日、空串与 None 等价，类型不符算不匹配（附录 A.10，p.18）。比较的是 Excel 重算后的缓存值，因此需要在 Windows Excel 上异步重算（A.11）。

训练目标为 KL 正则的期望奖励最大化，用 GRPO 优化（式 2–4，pp.6–7、20）。工作单元是"一个任务的一条完整多轮轨迹"，每轮最多 20 个 assistant 轮次。
