# 工作负载

**查询来源**：Spider Text2SQL 数据集（200 个数据库，每个附 SQL 与自然语言改写）。作者筛出 46 条预期能由现有 LLM 回答的查询：排除依赖 Spider 特定关系数据的查询（如“有多少部门负责人年龄超过 56 岁”），只保留世界地理、机场等通用主题查询（如“1950 年后独立的国家名称”）。同一问题有多条改写时取第一条。

**查询类别**（Table 2 列）：全部、仅选择、聚合、连接。论文未给出每类查询的条数。

**四种结果**（对每个 LLM M、查询 q、Spider 关系 D、NL 问题 t）：

| 结果 | 含义 | 数据来源 |
|---|---|---|
| R_M | Galois 在 M 上执行 q | LLM |
| R_D | 在 Spider 关系上执行 q（标准答案） | 数据库 |
| T_M | 在 M 上直接问 t | LLM |
| T_M^C | 用固定的人工链式思维示例问 t | LLM |

**模型**：Flan-T5-large、TK-instruct-large（均 783M 参数）、InstructGPT-3、GPT-3.5-turbo（论文均写 175B 参数）；除 ChatGPT 通过 API 外都在本地运行。GPT-3 提示带 6 个少样本问答示例（Figure 4），未知答案要求回“Unknown”。

标准答案是 Spider 数据库中的取值，可能早于 LLM 训练数据或与现实不一致（如“现任市长”），因此“匹配率”混合了 LLM 错误与基准数据陈旧两种因素，论文未分离（阅读者分析）。
