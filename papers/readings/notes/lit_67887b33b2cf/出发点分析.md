# 出发点

Web 表格常缺列名和列间关系，CTA 要为列赋予一个或多个语义类型，服务于数据质量控制和数据发现。预训练语言模型方法（如 TURL 系）需要针对任务和数据集精调并依赖标注；LLM 方法（Korini & Bizer、CHORUS、ArcheType、Table-GPT）零样本能力强，但都只用模型内部知识，会遇到知识过时、事实错误和长尾领域问题。

知识图谱以（主体、关系、客体）三元组提供简洁、结构化的外部知识，已在其他任务中与 LLM 结合，但作者称尚无工作针对 CTA。最相关的 KGLink 在 PLM 训练阶段引入 KG，仍需训练。RACOON 想做到不训练、把 KG 和 LLM 当黑盒即插即用。

依据：[arXiv:2409.14556v2](https://arxiv.org/pdf/2409.14556v2)，摘要、§1，PDF pp.1–2。
