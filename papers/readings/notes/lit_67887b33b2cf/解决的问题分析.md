# 解决的问题

输入：一张表（CSV 序列化）、要标注的列、候选类型集合（实验中 255 个 Freebase 类型）、外部 KG（Wikidata）、一个 LLM。输出：该列的类型列表，以 JSON `{'type': []}` 返回；多标签设置可选多个，单标签设置只选一个。

处理单位是逐列：整张表保留在提示中作参考。组件包括：

- **Retriever**：Parser 选出 C 个单元格（目前用全部单元格），KG-Linker 把每个单元格文本链接到 KG 实体 ID，再取实体标签和一跳邻居。
- **Processor**：压缩成两种表示。ENTITY-LABELS 只给规范实体名（如“15 Sge”对应 15_Sagittae）；ENTITY-TRIPLETS 给（实体, `instance_of`, 类型）三元组。按列统计各节点/三元组出现次数。
- **Augmentor**：把列级统计写成自然语言 KG-Context，插入原始提示，例如“该列单元格是以下 Wikidata 实体的实例：human (6 cells)”。

若一个单元格也链接不上，回退为普通提示。

依据：[arXiv:2409.14556v2](https://arxiv.org/pdf/2409.14556v2)，§2、Figure 2–3、附录 A，PDF pp.2–4、8。
