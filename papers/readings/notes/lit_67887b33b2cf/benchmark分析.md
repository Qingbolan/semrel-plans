# 评测与边界

**基线**：同一 GPT-3.5 的普通提示（作者称 CHORUS 与 ArcheType 也用这种普通 LLM 推理），不含 KG 上下文。**指标**：micro-F1。

**实验 1（Table 1，micro-F1）**：

| KG-Linker | EL | 多标签 基线 / ETL / ETT | 单标签 基线 / ETL / ETT |
|---|---|---|---|
| 真值 | 1.0000 | 0.2609 / 0.4023 / 0.4500 | 0.4631 / 0.564 / 0.6814 |
| MediaWiki API | 0.4018 | 0.2609 / 0.3582 / 0.3494 | 0.4631 / 0.4927 / 0.5222 |
| ReFinED | 0.6255 | 0.2609 / 0.3698 / 0.3678 | 0.4631 / 0.4900 / 0.5705 |

“最高 0.21 提升”对应单标签、真值链接下 ETT 与基线之差（0.6814−0.4631≈0.218）。（阅读者分析）

**主要观察**：真值链接下 ETT 最好；换成实际链接器后两种表示都下降，ETT 降得更多，说明链接错误时扩展信息反而有害；ReFinED 下降较少。不过在多标签设置下 ReFinED 的 ETL 略高于 ETT，在单标签设置下 ReFinED 的 ETL（0.4900）低于 MediaWiki（0.4927），正文“ReFinED 下降较少”的说法并非每一格都成立。（阅读者分析）

**边界**：单一数据集、单一 LLM、单一普通基线；单标签评分把落在真值集合内的任一预测都算对，比较宽松；没有方差、成本或显著性报告；单元格选择留待未来工作。
