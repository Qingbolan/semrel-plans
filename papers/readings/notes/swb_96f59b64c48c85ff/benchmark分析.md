# 评测与边界

**设置**：各模型取开发集综合表现最好的检查点；词级 BIO 标签 F1，报告 Macro F1；单一随机种子（§4.4、§4.5.1，PDF pp.17、23）。

**实验 1（主结果，Table 5，PDF p.18）**：

| 模型 | 类型 Dev | 类型 Test | 主体 Dev | 主体 Test |
|---|---|---|---|---|
| Legal-BERT | 39.42 | 37.38 | 84.82 | 91.79 |
| RoBERTa-Large | 40.10 | 39.14 | 86.30 | 90.83 |
| Leg-RoBERTaL-13k | 42.95 | 41.30 | 88.44 | 91.55 |
| Leg-RoBERTaL-15k | 42.81 | 43.13 | 87.68 | 91.36 |

继续预训练提升论证类型识别；主体识别四个模型在测试集上相差不到 1 个百分点，Legal-BERT 最高。

**实验 2（按标签，Table 6–7，PDF p.19）**：数据越多的类越好；系统解释、推翻先例、文义解释、适当性等稀有类全部为 0。

**实验 3（第 3 条迁移，Tables 8–9，PDF pp.22–23）**：15k 模型在 20 份第 3 条案件上类型 Macro F1 43.13→31.49（−27%），主体 91.36→83.15（−9%）；必要性/比例性与裁量余地完全失败。

**实验 4（重要性预测，Table 11，PDF p.25）**：线性 SVM 测试 Macro F1 0.38，高于多数类基线 0.15 和随机基线 0.32；作者结论是仅靠论证特征无法可靠区分重要性。

**实验 5（从头预训练，附录 D，PDF pp.38–39）**：在 CaseLaw 与 ECHR 上从头预训练，损失约 5,000 步后停滞，作者视为失败。

**作者承认的局限**：只跑一个种子；BIO 词级评测偏悲观，边界不匹配即算错；段落级输入缺乏上下文（§4.4.1、§4.5.1，PDF pp.20–23）。

阅读者分析：结论称"最多提升 11%"，按 Table 5 计算，15k 相对 RoBERTa-Large 为 +10.2%、相对 Legal-BERT 为 +15.4%，口径未说明（阅读者分析）。

依据：§4.4–4.6、§5、附录 D，PDF pp.17–28、38–39。
