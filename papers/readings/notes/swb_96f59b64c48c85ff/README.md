# Habernal et al. — Mining Legal Arguments in Court Decisions

本文提出以法学理论为基础的欧洲人权法院（ECHR）判决论证标注方案（16 种论证类型 × 5 种论证主体），发布 LAM:ECHR 语料（373 份判决、约 240 万 token、15,205 个论证片段），并用在欧洲法律文本上继续预训练的 RoBERTa-Large 做多任务序列标注。论证类型测试 Macro F1 最高 43.13，主体 91.36；迁移到第 3 条案件时类型 F1 降至 31.49；用论证特征预测案件重要性仅达 Macro F1 0.38。已阅读正文 §1–§5 及附录 C–D，未复现实验。
