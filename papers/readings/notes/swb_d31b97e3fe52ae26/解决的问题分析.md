# problem

| 项 | 内容 |
|---|---|
| 输入 | 一张真实的视觉挑战图像（或其 GPT-4o 编辑生成的对抗版本）+ 一个二值 VQA 问题 |
| 输出 | 是/否答案；对推理模型或经逐步提示的普通模型，还评估其推理链 |
| 题目结构 | 每张图通常有两个二值问题：主问题（答案"否"）和对抗问题（答案"是"）；原图与对抗图组成一组共 4 题 |
| 指标 | No-Acc、Yes-Acc；按 NaturalBench 的 Q-Acc、I-Acc（同一图像两题都对）、G-Acc（一组四题全对）；CoT-Score |

CoT-Score：以标注的关键推理步骤为参照，由 GPT-4o 打分，"识别细致视觉线索"1 分、"推断真实情况"1 分，允许多种有效路径，直接但逻辑正确的回答也可得满分 2 分，归一化到 [0,1]。所有评测为零样本。

阅读者分析：原文把 Q-Acc 写成"either question correct"，但 Table 1 中 Q-Acc 基本等于 No-Acc 与 Yes-Acc 的平均（如 GPT-4o：(0.616+0.523)/2≈0.570，表中 0.571），更像逐题准确率；以表中数值为准理解。

依据：[NeurIPS 2025 D&B 论文集 PDF，20 页](https://proceedings.neurips.cc/paper_files/paper/2025/file/2b76873e897f3de3069b2f360c65e0c2-Paper-Datasets_and_Benchmarks_Track.pdf)，§3、§4.1，PDF pp.3–6。
