# 出发点

数据科学要从大量异构数据中提取洞见，传统上依赖大量人工与专长；LLM 智能体因能自动化数据分析、建模与决策而受到关注（§1，p.1）。作者的核心问题是"如何组织 LLM 智能体来承担数据科学家的职能"，并拆成五个递进的研究问题（§1，pp.1–2）：

| 编号 | 问题 |
|---|---|
| RQ1 | 如何定义智能体角色与职责以分解复杂分析任务 |
| RQ2 | 各角色如何推理和使用工具以可靠执行 |
| RQ3 | 应接入哪些外部知识，如何融入决策 |
| RQ4 | 需要什么反思与自我纠错机制 |
| RQ5 | 这些能力如何支撑迭代的端到端数据科学循环 |

§3 开头（pp.3–4）给出动机：裸 LLM 会幻觉出列名、统计结果或处理步骤；生成的代码因类型不一致、缺依赖等易崩溃；长流程中会目标漂移、遗忘假设。因此需要结构化的智能体架构来弥补。

阅读者分析：与已有多智能体综述相比，作者强调的差异是把模块化视角落到数据科学工作流，并关注动态编排与把反思当作跨阶段控制机制（§2，pp.2–3）。

依据：§1–3，pp.1–4。
