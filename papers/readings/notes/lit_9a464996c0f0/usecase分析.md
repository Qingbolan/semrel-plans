# 具体用例

**警务记录事件匹配**（§1，p.1；Fig. 1–3，pp.2–4）：

- 场景：加州警务记录公开项目（作者与记者、公设辩护人合作）中，目击报告、证词、法庭文件、调查报告等需按“是否描述同一事件”配对，原本由记者手工完成；这是一个语义自连接。连接提示为 “Does the police report in {right_column_name} refer to the same incident as the police report in {left_column_name}?”（附录 I，p.21）。
- FDJ 的分解：三个特征——日期、地点、警员姓名。例如“抽取的日期相差不超过两天”，“抽取的警员姓名语义距离不超过 0.3”，按 CNF 组合。
- 执行：对每份文件各抽取一次特征（线性成本），用分解对所有文件对给出候选匹配，再让 LLM 复核候选对去掉假阳性。

**效果**（Table 3，p.11）：在 T=90% 时，BARGAIN 的成本比为 81.3，FDJ 为 44.7（约 0.55×），理想级联为 66.6。作者把 Police Records 归为“相关特征存在但对结果是较弱指示”的类别（§8.2，p.10）。

阅读者分析：对语义算子系统而言，这说明连接可以改写为“逐行语义抽取（map）+ 关系型谓词连接 + 少量 LLM 复核”，把平方级 LLM 调用转为线性级。

依据：§1、§3.1、§8.2、附录 I，PDF pp.1–4、10–11、21。
