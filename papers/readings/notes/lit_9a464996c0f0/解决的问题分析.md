# 解决的问题

**输入**（定义 2.1，p.2）：两组字符串 L、R，连接条件 p（如“Do {l} and {r} describe the same incident?”），召回目标 T_R、精确率目标 T_P、失败概率 δ、LLM L、嵌入模型 E。

**真值**：Y = {(l, r) | L_p(l, r) = 1}，即以 LLM 对每对的判定作为“真”连接结果（§2，p.2）。

**输出**：结果集 Ŷ，满足 P(精确率 < T_P 或 召回 < T_R) ≤ δ，并使 LLM 与嵌入的货币成本（按输入输出 token 计）最小（p.2）。主文默认 T_P = 1，§7 扩展到 T_P < 1。

**FDJ 的三步**（§3.1，pp.3–4，Fig. 2）：

1. 构造特征化分解：抽样并由 LLM 标注一部分对；由 LLM 生成特征抽取函数 X_L、X_R（可为 LLM 调用或代码）与距离函数 d（词重叠、语义、算术、日期四类），谓词形如 `d(X_L(l), X_R(r)) ≤ θ`，析取成子句、再合取成 CNF。
2. 用分解对全部对估计是否满足条件（特征抽取对每条记录做一次）。
3. 精化：对估计为正的对调用 LLM 去除假阳性，因而精确率为 100%，召回取决于分解。

**难点**：最小成本特征化分解（MCFD）被证明是 NP-hard（由集合覆盖归约，定理 4.2，p.4）；多阈值同时选择带来多重假设检验问题（§4.2，p.5）。

依据：§2–4，PDF pp.2–5。
