# problem

**任务形式（§3.1，式 3–4）**：成对偏好判断。
- 输入 X = (I, D_rep, {C0, C1}, P)：任务描述 I、数据分析报告 D_rep、两份候选方案代码、系统提示词。
- 输出 Y = (cot, ŷ, c)：推理过程、预测胜者 ŷ∈{0,1}、置信度 c∈[0,1]。c 在 ForeAgent 中作门控阈值。
- 工作单元：一个"方案对"。标签为两方案执行后哪个更优（Table 4 明确以测试集指标 M_test 为参照，验证集 M_val 只是代理）。

**数据分析报告（§3.4）**：因 LLM 不擅处理原始数值且上下文装不下整份数据，作者用"剖析—核验—语言化"流程生成报告：GPT-5.1 写屏蔽标签的数据剖析脚本 → 沙箱执行，人工专家对日志做通过/不通过检查 → GPT-5.1 将日志转写为语义结论（如"正类 8.5%，严重不平衡，不宜用准确率"）。

**更上层的问题（§2.1、§6）**：ML 任务是在代码空间中找使指标 M(I,C,D) 最大的 C*。预测器的用途是在智能体搜索中把 m 个候选先按偏好筛选，只执行少数。

阅读者分析：任务只判断两两相对优劣，不预测绝对分数，也不预测运行时长或成本。附录 Table 3 显示把它推广到列表排序时效果明显下降（N=5 时 Acc@1 仅 31.1%，Spearman ρ≈0.22）。
