# 解决的问题

**形式化**（§3）：给定查询 q 与文档集合 D={d1,…,dM}，每份文档有若干页；目标是生成答案文本 â。答案依据可能分布在一份或多份文档的不同页中。系统先在页、段落或文本块层面检索证据，再据此生成答案。

**基准单元**：三元组 (q, D, â)，D 中包含目标文档和若干随机干扰文档；附带标注证据，用于评检索。

**方法输入输出**：VisDoMRAG 输入 q 与 D 的 PDF；文本管线输出证据、推理链、答案，视觉管线输出同样三项；融合步骤输入两组输出，输出最终答案。检索评测输出 top-k 文本块或页面，并判断多数检索结果是否来自正确源文档。

阅读者分析：每个查询的答案原则上只来自一份目标文档（经人工确认的一对一映射），因此该基准考察的是“在干扰中定位+单文档多模态理解”，而不是需要跨文档聚合的多跳问题。

依据：[NAACL 2025，pp.6088–6109，22 页](https://aclanthology.org/2025.naacl-long.310.pdf)，§3–5，pp.3–6。
