# 出发点

金融、法律、科研等领域的 PDF 混合了段落、表格、图表和图片。真实的文档问答通常面向一组文档，系统要先找到包含答案的那份文档，类似“大海捞针”。作者指出两点空缺：

一是数据：现有多文档基准（LongBench、Loong）以文本为主，而包含表格、图表、幻灯片的基准（MPDocVQA、UDA、MMLongBench-Doc）都是单文档（Table 1）。

二是方法：现有 RAG 只依赖一种模态。文本 RAG 擅长语言推理但会忽略表格和图；视觉 RAG 能取回页面图像，但受限于多模态 LLM 的视觉推理，在同样上下文下文本输入往往更好，这与语言偏置和视觉幻觉有关。

依据：[NAACL 2025，pp.6088–6109，22 页](https://aclanthology.org/2025.naacl-long.310.pdf)，§1–2、Table 1，pp.1–3。
