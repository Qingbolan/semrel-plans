# 具体用例

**Purple 检查员簇**：Purple 簇在训练集中的命中率最高（0.406），其指示变量系数为 1.555，对应赔率比 4.735。也就是说，只要一家店上次由 Purple 簇检查，即便上次没有 critical 或 serious 违规，模型也会大幅抬高其风险。在两个月 1,637 次检查的测试集中，上次由 Purple 检查的 99 家店（占 6.0%）全部被排进前 234 次检查（占 14.3%），其中 43 家被查出至少一项 critical 违规（原文写 43.3%）。

作者认为，店家无法控制由谁来检查，这个变量把合规店与不合规店仅按检查员归为一类，不应进入风险分数，更不应成为决定性因素。

阅读者分析：43/99 按算术约为 43.4%，与原文 43.3% 有 0.1 个百分点差异，可能是舍入问题（阅读者分析）。

依据：[arXiv:1910.04906v1，8 页](https://arxiv.org/pdf/1910.04906)，§2.1 Table 2、§2.2 Table 3、§3 Finding 1，PDF pp.3–4。
