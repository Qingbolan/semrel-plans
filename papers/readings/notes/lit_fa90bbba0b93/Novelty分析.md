# 贡献与评价

**原文声称的贡献**（§1，PDF p.3）：
1. 统一渐进图搜索、回顾式记忆和分层自适应代码生成的自演化多智能体框架；
2. Progressive MCGS：在 MCTS 主干上加入不参与回传的参考边（分支内演化、跨分支参考、多分支聚合三种扩展），并用随时间衰减的 w(t) 在 UCT 与精英利用之间软切换；Retrospective Memory：冷启动领域知识库 + 运行期全局记忆，检索时不需额外 LLM 反思；
3. MLE-Bench 12 小时下 65.3% 奖牌率，并在数学优化任务上超过 AlphaEvolve / AlphaEvolve-v2。

**与先前图搜索的区别**：作者强调传统 MCGS 用于合并相同状态以压缩搜索空间，而这里每个节点是不同候选解，图结构用于跨分支信息流和方案组合（§2.2，PDF p.3）。附录 C 给出两个命题：多分支聚合在一次扩展中实现分支暴露图的完全团；精英选择带来的复用集中度（PDF pp.17–18，未逐步核对证明）。

阅读者分析：
- 各组件单独看都有前例（跨分支借鉴类似进化/岛模型的迁移，经验记忆类似 MARS/ML-Master 2.0，diff 编辑类似 AlphaEvolve 的补丁式修改），新意主要在组合方式与"参考边不参与信用分配"这一工程化设计。
- "熵启发"只是描述性的：w(t) 由固定时间比例（0.5→0.7 软切换、w_min=0.2）控制，并非依据实时熵自适应（Table 4，PDF p.19）；Figure 3 是事后测量的有效分支数。
- 记忆"无需额外 LLM"指不做显式反思总结，但规划、调试阶段仍由 LLM 消费检索结果。
