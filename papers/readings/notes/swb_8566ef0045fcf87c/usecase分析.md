# 具体用例

**凭证外泄后的 Unauthorized Access 调查**（§1，PDF p.2；§3.2，PDF p.5；Table 2）。

OUAT 先搭建带跨账户信任关系的 IAM 角色和 S3 桶，然后模拟一组攻击动作：泄露访问密钥、跨账户扮演角色、枚举 S3 对象、把数据外传到外部端点。

智能体收到告警后，需要调用 CloudTrail:LookupEvents、IAM:ListRolePolicies 等工具，自行发现告警中没有的事实，例如被扮演的是哪个角色、访问了哪些桶、数据流向哪个外部 IP，最后给出 TP 结论。

评分方式如下：

- 结论正确，计入 M1；
- 新发现与真值发现的 ROUGE-L 超过 0.42，计入 M2。

在该类别上，SIR 智能体的 M1_TP 为 97.3%，新发现覆盖率为 41.9%，61.2% 的用例发现了 5 个以上新发现（Tables 4、6，PDF pp.8、10）。

阅读者分析：这相当于在日志表上做多跳的证据检索与关联。可评分的单位是“发现”文本，而不是 SQL 结果，因此对查询结果的语义等价判断依赖 ROUGE-L 这一字面相似度。
