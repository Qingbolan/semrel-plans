# 评测与边界

**实验 1（M1 分诊，Tables 3–4，PDF p.8）**：SIR 智能体漏报 14/475 个 TP，误报 85/319 个 FP。

| 类别 | M1_TP | M1_FP | M1_F3 |
|---|---|---|---|
| Brute Force | 99.3% | 61.0% | 0.958 |
| Unauthorized Access | 97.3% | 76.8% | 0.951 |
| Misconfiguration | 94.0% | 82.7% | 0.929 |
| Malicious File Execution | 96.3% | 47.8% | 0.891 |
| 整体 | 97.1% | 73.4% | 0.942 |

人类 Tier-2 分析师的参考值来自 SOC 运营数据：TP 检出 85–90%，FP 排除 70–80%，F3 约 0.86（§4.1，PDF p.7）。

**实验 2（M2 调查深度，Tables 5–6，PDF pp.9–10）**：TP 用例的新发现覆盖率为 41.9%，平均每例 5.67 个新发现；68.4% 的用例发现 5 个以上，47.4% 发现 7 个以上。Malicious File Execution 只有 18.0%，作者归因于 CloudTrail 看不到实例内活动。

**实验 3（M3）**：工具覆盖率达 100%，因此 M3 被降为可选指标（§4.3，PDF p.10）。

**阅读者核对的数值问题**（阅读者分析）：

- 按式 (3) 原样代入 97.1%/73.4%，得到 F3≈0.752，而不是 0.942。把分母改为 β²·M1_FP + M1_TP 后得 0.941，与表值相符，说明公式与表值所用口径不一致。各类别的 F3 用任一形式都不能精确复现。
- Table 6 整体行的 Hit 3+ 为 64.6%，低于 Hit 5+ 的 68.4%，逻辑上不可能。
- 整体新发现覆盖率 41.9% 等于各类别中的最大值，与加权平均不符。

**其他边界**：只评测了一个智能体；10 次运行的平均没有给出各类别的方差；只用 CloudTrail 遥测；数据和 OUAT 尚未发布（§6，PDF p.11）。
