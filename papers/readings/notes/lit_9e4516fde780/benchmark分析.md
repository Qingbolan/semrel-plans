# 评测与边界

**实验 1（渲染性能）**：在 RTX 4090 上，3DGS 推理始终超过 100 FPS，与体数据大小无关。ParaView 的 DVR 渲染 4.32 GB 的 chameleon 时只有 5.09 FPS。作者称快"最多 20×"（§4，PDF p.6）。

**实验 2（用户研究，8 人）**：参与者先看 10 分钟教程，再自由探索，然后完成 23 项任务并填写 5 点量表问卷（§4.2，p.8）。Table 3 的均值如下：

| 指标 | 均值 | 范围或说明 |
|---|---|---|
| 探索时间 | 9.9 分钟 | 4–24 分钟 |
| 任务完成时间 | 35.1 分钟 | 32–42 分钟 |
| 自然语言交互次数 | 24.4 | 其中有效 20.6 |
| 非自然语言交互次数 | 3.4 | — |
| 自然语言使用率 | 88.1% | P4 为 64%，P2 为 100% |
| 知识问答正确数 | 8.75/9 | — |

问卷（Figure 10，pp.8–9）中，Q1 高效交互 4.38，Q4 易学 5.0，Q5 语音功能有用 3.38，后者最低。参与者最常提到的问题是延迟。

**实验 3（附录 TTFT）**：首个 token 延迟随消息数增加。以 GPT-4o 为例，2 条消息时 3.08 秒，30 条时 12.89 秒。因此系统把消息上限设为 10（附录 §2、附表 1，p.10）。

**实验 4（附录 top-k 消融）**：在 backpack 和 carp 上，k≥3 时 CLIP 相似度对 k 不敏感，建议取 5–10（附录 §4，p.11）。

边界：没有与其他自然语言体可视化系统的任务级对比，也没有测开放词汇查询的准确率；用户研究只有 8 人，任务对所有人相同，没有对照组。§5 还提到工具输出缺乏验证、规则式分层结构会带来延迟和单点故障（p.9）。

依据：[arXiv:2507.12621v1（2025-07-16，IEEE TVCG 模板预印本，含附录），13 页](https://arxiv.org/pdf/2507.12621v1)，§4–5、Table 3、附录 §2、§4，PDF pp.6–11。
