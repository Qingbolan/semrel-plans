# 解决的问题

系统输入是一个体数据集，以及用户的文本或语音指令；输出是实时更新的渲染图、自然语言或语音回复，以及动作日志（§3、§3.5，PDF pp.3–6）。交互单位是一轮用户指令，由智能体在"可视化—感知—行动"（VPA）循环中反复执行，直到核心智能体判断目标已达成，或达到迭代上限（§3.4，p.5）。

| 步骤 | 做法 |
|---|---|
| 多视角语义分割 | 用 ParaView 按预设 TF 渲染多视角图像；可选预分割标签、TF、SAM 2 跨帧跟踪、LangSplat/SAGD 等方法（§3.1，p.4） |
| 场景理解 | 按不透明度通道的熵选出 top-k 视图，取 CLIP 图像嵌入的均值；有文本标签时再与文本嵌入平均；查询时用余弦相似度匹配（§3.2，p.4） |
| 可编辑高斯训练 | 每个部件训练一个 iVR-GS 基础场景，支持改颜色、不透明度、光照，并通过拼接参数组合成完整场景（§3.3，pp.4–5） |
| 多智能体交互 | 基于规则的分层协作：意图解析、开放词汇查询、对话、命令生成等智能体，使用函数调用工具与声明式命令（§3.4，p.5） |

函数调用工具包括：开放词汇对象查询、场景编辑、基于知识的问答、最佳视角选择，以及用 InstructPix2Pix（IP2P）做 2D 风格化（§3.4，p.5）。

依据：[arXiv:2507.12621v1（2025-07-16，IEEE TVCG 模板预印本，含附录），13 页](https://arxiv.org/pdf/2507.12621v1)，§3.1–3.5、Figure 2，PDF pp.3–6。
