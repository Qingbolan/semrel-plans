# novelty

原文贡献（§1，PDF p.2）：(1) 数据科学技能框架与基于它的基准，开源测试平台；(2) 层次技能抽取算法：LLM 将 6,510 个 Stack Overflow 解答分解为 29,602 条步骤技能 → Qwen3-Embedding + UMAP + GMM 软聚类 → LLM 按上层技能拆分簇、DBSCAN 合并同义 → 递归直至顶层技能数低于阈值 → 用 token 子集关系消除“纠缠”技能 → 专家审查，得 433 个顶层技能（§4，PDF pp.5–6）；(3) 技能覆盖驱动的任务选择（贪心最大覆盖，1−1/e 近似）与生成（技能图随机游走采样技能组合、结构化数据画像、基于技能的工作流合成、动态采样惩罚）（§5，PDF pp.6–7）；(4) 对主流数据智能体的细粒度实证研究，得出四条 Finding。

阅读者分析：与已有基准相比的增量主要是 (a) 引入真实金融 B2B 业务任务与 GB 级数据，(b) 每题人工标注技能用于失败归因。技能级评分本身依赖 LLM 判断（§3.3、§6.3），作者用“技能分与任务分大体一致”来支持有效性（PDF p.11），但未报告 LLM 判分与人工判分的一致性。真实业务数据为蚂蚁集团匿名生产数据，正文未说明能否公开获取（仅称开源 testbed），复现性需另行确认。

依据：[arXiv:2607.01647v1，14 页](https://arxiv.org/abs/2607.01647)，§1、§4–6，PDF pp.2、5–11。
