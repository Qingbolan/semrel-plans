# 解决的问题

**两个子任务**（§5，PDF p.8）：

| 子任务 | 输入 | 输出 |
|---|---|---|
| MRC | 信号问题 + 上下文（支持句前后至多各 3 句） | 支持该判断的证据片段 |
| RoB 推断 | 证据片段（答案） | 二分类：yes = 低风险；no/未报告 = 高/不明风险 |

形式化：MRC 学习 `f: (C, Q) → A`；RoB 推断学习 `g: A → Y`，Y ∈ {0,1}（§2.2、§5）。论文只处理 yes/no 型问题。

**实例单位**：一个（试验论文，偏倚类型/信号问题）对。字段为偏倚类型、问题、上下文、支持句、答案起始偏移、RoB 标签，外加 CDSR 综述编号、PubMed ID 等溯源信息（§4.1，PDF pp.5–6）。

**偏倚类型**：选择（随机序列生成、分配隐藏两个问题）、实施、检测、失访（attrition）、报告及其他偏倚，共 7 个信号问题（§4.2，PDF pp.7–8）。

阅读者分析：上下文是围绕金标支持句截取的 7 句窗口，而非整篇论文，所以 MRC 任务比"在全文中找证据"容易得多；论文没有评测全文级检索。
