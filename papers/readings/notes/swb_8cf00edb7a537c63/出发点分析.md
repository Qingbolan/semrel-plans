# 出发点

XBRL 自 1999 年起成为机器可读财报的全球标准，已在 65 个国家采用。实际标注需要把每份文件中成千上万个数字落实到混合的表格与文本证据上，并对齐到逾 17,000 个标准概念，至今仍以人工为主、易出错（§1）。

作者认为已有 XBRL 基准（FiNER、FNXL）偏重标注便利而非语义难度（§1–2、Table 1）：
- 把任务简化为截断标签集上的分类（FiNER 139 个、FNXL 2,800 个，全集 17,688 个），无法评估长尾泛化；
- 采用封闭集极端分类，当完整分类体系无法放入上下文时容易产生无效或幻觉标签；
- 大多去掉了表格，而表格才是数值披露的主要载体。

财务 QA 基准（FinQA、TAT-QA 等）虽然做表文联合数值推理，但不要求对齐到标准会计概念；XBRL-Agent 等 LLM 工具也没有做端到端的"事实 → 分类体系"评测（§2）。

依据：[arXiv 2505.20650v5，17 页](https://arxiv.org/abs/2505.20650)，§1–2、Table 1，PDF pp.1–3。
