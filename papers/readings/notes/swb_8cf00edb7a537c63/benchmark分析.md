# 评测与边界

**设定**（§3.6）：零样本评测 GPT-4o、DeepSeek-V3、Qwen3 系列、Llama 系列、gemma-2-27b、Fino1-8B 等 13 个 LLM，并与在附录 G 数据上微调的 BERT-large、FinBERT、SECBERT 比较；输入上限 FinNI 24,576、FinCL 8,192 token，约 500 GPU 小时和 1,500 美元 API 费用。

**实验 1（整体三元组，Table 5，选列）**：

| 模型 | 宏 F1 | 微 P | 微 R | 微 F1 |
|---|---|---|---|---|
| DeepSeek-V3 | 0.0659 | 0.1074 | 0.1264 | 0.1162 |
| GPT-4o | 0.0569 | 0.1052 | 0.0731 | 0.0863 |
| Llama-4-Scout | 0.0400 | 0.1045 | 0.0526 | 0.0699 |
| Qwen3-32B | 0.0324 | 0.1127 | 0.0230 | 0.0382 |
| Fino1-8B | 0.0151 | 0.0419 | 0.0128 | 0.0197 |
| SECBERT（微调） | 0.0203 | 0.1870 | 0.1697 | 0.1779 |
| BERT-large（微调） | 0.0205 | 0.1518 | 0.1283 | 0.1391 |

**实验 2（子任务，Table 6）**：FinNI F1 最高 DeepSeek-V3 0.6932（召回 0.8430），GPT-4o 0.5397；Qwen3 系列精确率高而召回极低。FinCL 准确率最高 DeepSeek-V3 0.1889、GPT-4o 0.1829。

**实验 3（极端分类消融，Table 7）**：GPT-4o、DeepSeek-V3、Fino1-8B 直接从全量概念中选标签时三元组 F1 全为 0；本框架下为 0.1026/0.1356/0.0197。

**实验 4（误差传递，Table 8）**：所有模型均为流水线 < FinCL < 仅重排；仅重排最高 0.2144。

**附加**：附录 A 给出模型两两 bootstrap 显著性矩阵（Figure 4）。

**边界**：正文无独立局限节；作者在 §4.2 承认检索覆盖有限（整体 Acc@200 约 0.33），细粒度 US-GAAP 消歧本身困难。阅读者分析：Table 8 的"Pipeline"列与 Table 5 的微平均精确率几乎逐项相同（Qwen3-1.7B、0.6B 除外），而 Table 7 的三元组 F1 又与 Table 5 微 F1 不同，论文未解释各表口径。（阅读者分析）
