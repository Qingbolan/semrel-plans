# 工作负载

Voyager 不使用固定数据集，工作负载是在 Minecraft 模拟环境中的交互运行。

**环境与模型（§3.1，附录 B.1）**：MineDojo + Mineflayer JavaScript API；gpt-4-0314 用于课程、代码生成与自我验证，gpt-3.5-turbo-0301 用于自问自答与技能描述，text-embedding-ada-002 用于嵌入。课程温度 0.1，其余为 0。机器人死亡后在附近复活并保留物品栏。

**评测设置**：

| 实验 | 规模 | 位置 |
|---|---|---|
| 探索（独特物品数） | 每个方法 3 次试验，最多 160 次提示迭代 | Fig. 1、附录 B.4.1 |
| 科技树（木/石/铁/钻石工具） | 3 次试验，最多 160 次迭代 | Table 1 |
| 地图覆盖 | 3 次试验，以包含轨迹的最小圆比较 | Fig. 7、附录 B.4.2 |
| 零样本泛化 | 新世界、清空物品栏；4 个未见任务各 3 次，最多 50 次迭代 | Table 2 |
| 技能检索准确率 | 309 个样本 | 附录 Table A.4 |

零样本任务为：钻石镐、金剑、岩浆桶、指南针。基线的统一任务描述为"explore the world and get as many items as possible"（附录 B.2）。

**消融用的课程**：手工课程为挖钻石的 10 步序列；随机课程从 Voyager 获得过的 101 种物品中随机抽取下一任务（附录 B.3，PDF p.39）。

阅读者分析：单位是"提示迭代"而不是 token 或美元，论文未报告每次运行的 API 费用，只在 §4 说明 GPT-4 价格是 GPT-3.5 的 15 倍。

依据：§3.1–3.3，Tables 1–2，附录 B，PDF pp.6–8、38–42。
