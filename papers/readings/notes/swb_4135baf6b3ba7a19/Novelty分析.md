# 贡献与评价

**贡献**（Abstract、§1、§5）：

1. 把事件抽取的目标扩展到亚细胞直至生物体层面，并以社区标准本体为依据。
2. 制定详细的标注指南。
3. 发布 MLEE 语料，含 8,000 多个实体和 6,000 多个事件。
4. 改造现有实体识别（NERsuite）和事件抽取（EventMine）方法用于新任务并评测。

**兼容性设计**：分子层面的类型尽量沿用 BioNLP 共享任务五个主任务语料的范围与指南，使 MLEE 可以和这些语料合用（§2.3）。叠加 GE 训练模型（stacking）后 F1 小幅提升，作者以此作为兼容性目标达成的证据（§4.3）。

**作者强调的发现**：涉及解剖实体的事件比分子层面的事件更容易抽取，F1 分别为 76.22 和 71.86（Table 8）。

**阅读者分析**：

- 主标注只由一名资深博士生物学家完成；一致性评估放在补充材料，本次没有读到，无法核实（阅读者分析）。
- stacking 带来的提升只有 1.09 个 F1 点，且是单次实验，没有方差，作为"兼容性"的证据偏弱（阅读者分析）。
- 语料只覆盖血管生成单一主题，作者在 §5 也把扩展领域独立性列为未来工作。

依据：§1–5、Tables 7–8。
