# 具体用例

一份证监会内幕交易行政处罚决定书描述：某人通过职务或亲属关系知悉公司重组的内幕信息，在信息公开前买入股票并获利。标准输入模式下，模型只拿到"资深法律专家"角色设定、"综合法律与证据分析当事人行为并认定法律责任、给出完整推理链"的任务说明和案情描述（Listing 4.1，PDF p.6）。

人工设计 CoT 模式额外要求按"内幕信息形成 → 知悉信息 → 交易行为 → 违法所得 → 法律适用 → 处罚结果"逐步分析；自拟 CoT 模式要求模型先根据案情自行构造最合理的推理顺序，再严格照此分析。输出的推理链与专家 IRAC-Trace 的字段逐项比对算 IRAC Recall，并交由 DeepSeek-R1 评 A/B/C 等级（§4.3，PDF pp.6–7）。

专家对自拟路径的分类显示，三个模型生成的路径都覆盖七类核心要素：内幕信息、知悉、交易活动、因果链、意图与抗辩、违法所得、法律适用与结果；其中"意图与抗辩"覆盖率最低（QwQ-32B 为 30.74%）（Figure 5，PDF p.10）。

阅读者分析：上面的案件情节是对论文任务形式的概括，原文正文没有给出一份具体案件的完整输入输出示例。若在语义查询场景中复用，可把"从决定书抽取 43 个字段"视为一个带金标准的结构化抽取任务（阅读者分析）。
