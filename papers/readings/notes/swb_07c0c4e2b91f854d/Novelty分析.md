# 贡献与评价

原文列出四项贡献（§1，PDF pp.2–3）：

| 贡献 | 内容 |
|---|---|
| MSLR 数据集 | 首个按 IRAC 对齐的中文多步法律推理基准，1,389 份决定书、59,771 个步骤级标注，平均每份 43.03 个结构化字段 |
| PPP 标注流程 | 准备（专家制定模板与金标准）→ 预筛（多个 LLM 与金标准比较，选出性价比最佳的 DeepSeek-V3）→ 精调（针对难字段改提示，并由法律专家逐项复核） |
| 双重过程指标 | IRAC Recall（与专家轨迹对齐）与 LLM Score（逻辑连贯性），二者显著相关 |
| CoT 发现 | 人工设计 CoT 效果因模型而异，自拟 CoT 优于人工设计 CoT |

金标准阶段：研究生两周培训、50 例试标需与教授一致达 95%，正式标注采用"2+1"（两人独标、第三人裁决），得到 900 余例金标准，Krippendorff's α=0.832（§3.2，PDF p.4）。

阅读者分析：
- 数据和流程是主要价值；"首个"仅限中文、IRAC 对齐的多步法律决策设定。
- 所谓"步骤"实为结构化字段（如内幕信息形成、交易行为、违法所得），IRAC Recall 本质是字段级召回，并不检验步骤之间的推理依赖。
- 自拟 CoT 的结论只在 3 个模型上验证，且其数值与标准输入几乎相同（见 benchmark 分析），"自拟 CoT 优于人工 CoT"成立，但"自拟 CoT 提升推理"证据较弱。
- 去污染检查只与 Lawyer LLaMA 的一个训练语料比较（附录 A），对闭源模型无法证明无污染。
