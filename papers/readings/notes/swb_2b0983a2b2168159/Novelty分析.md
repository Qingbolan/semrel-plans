# 贡献与评价

作者列出五项贡献（§1，PDF p.2）：

1. 在 95 个真实法律决策模型上，对 law-to-code 生成中的结构化表示做受控评估；
2. 发现 io 规格大幅提升生成质量（结构相似度 +37–54%），srl 的额外收益很小；
3. 分析结构相似与结果等价的关系，发现二者互补；
4. 发现 LLM 会合理地简化模型，去掉冗余的建模惯例；
5. 公开数据集与代码。

**与已有工作的区别**：作者认为先前工作已证明 LLM 法律形式化（如 GPT-4 生成结构化表示、交通规则转 Prolog）和 DMN 抽取的可行性，但没有系统比较"丰富源文本"与"约束目标"，也没有深入分析结构相似与行为等价之间的差距（§2.5，PDF p.3）。

**阅读者评价**：

- 最有价值的是数据：生产级 DMN 与法条一一对应，并配有可穷举执行的测试场景。这比依赖人工构造金标的研究更有说服力。
- 方法上只用一个模型（GPT-5.1）、1-shot、温度 0.1，且禁用思维链。结论"io 优于 srl"仅在此设置下成立，作者在 §5.1 已承认。
- "LLM 合理简化"的论证主要依赖身份节点统计和个案（AlarminstallatieHebben），属于有说服力的定性分析，但不是对所有简化都做了等价性证明。
- srl 只用一个 Dutch BERT 抽取器，未评估其抽取质量，因此"srl 用处小"可能部分源于抽取噪声（阅读者分析）。

依据：[arXiv:2604.17153v1，10 页](https://arxiv.org/abs/2604.17153)，§1、§2.5、§4.1.3、§4.3、§5.1，PDF pp.2–3、6–9。
