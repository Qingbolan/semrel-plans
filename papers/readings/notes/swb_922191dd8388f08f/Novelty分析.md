# 贡献与评价

论文列出四项贡献（§1，PDF p.2）：

- C1：把技能发现限定在 FSM 场景；
- C2：把技能形式化为参数化控制流子图；
- C3：提出 SKILL-DISCO 框架；
- C4：实验验证。

**五个阶段**（§3.2–3.3，PDF pp.5–6）：

1. 由 LLM 把原始 ReAct 轨迹转写为带循环和分支、实体变量化的 Python 式程序；
2. 抽取子目标级操作 o = (名称, 摘要, 原始动作序列, 代码片段)，丢弃长度为 1 的操作；
3. 先分组、再合并，对操作做两轮 LLM 聚类，按轨迹覆盖率打分；
4. 为每个技能生成规格：签名、描述、前置/后置条件、元数据；
5. 合成 Python 实现，在留出任务上验证运行正确性、后置条件和动作节省，失败时最多重试 R 次，仍失败则丢弃。

阅读者评价：主要新意在于“跨轨迹聚类”与“编译加验证”的组合。与 ASI 的逐轨迹技能相比，技能库小得多（ALFWorld 上 5 个对 110 个）。

但需注意以下几点：

- 聚类和规格都依赖 LLM 判断，可复现性取决于提示与模型。
- 论文未给出重试上限 R 的取值，也未说明验证用的留出集有多大。
- 只在两个基准上实验。
