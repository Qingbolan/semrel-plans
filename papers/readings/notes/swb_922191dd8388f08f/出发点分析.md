# 出发点

LLM 智能体在交互任务中往往每次都从头求解，反复重新发现相同的低层动作模式，导致推理成本高、轨迹长、泛化脆弱（§1，PDF p.1）。

已有的经验复用工作主要有两类：AWM 从轨迹中提取文本工作流，ASI 归纳可执行技能。作者认为两者都没有回答两个问题：哪些场景存在程序性技能？多条成功轨迹之间的共享结构该如何表示？

直接让 LLM 从单条轨迹合成技能，库会变得碎片化、冗余，偏向轨迹特有的表面模式（§1，PDF p.1）。作者因此把范围限定在 FSM 可定义的场景：状态有限、动作有限、转移确定。在这类场景中，技能对应“帮助到达目标状态的重复转移结构”（§1–2，PDF pp.1–3）。

依据：§1–2，PDF pp.1–3。
