# 贡献与评价

| 贡献 | 内容 | 位置 |
|---|---|---|
| 以泄露为中心的评测 | 不把泄露当成整个数据集的二元属性，而是在事后文本内部定位、度量并干预 | §1，p.4 |
| 诉求级 UK LJP | 作者称此前没有学术工作对英国判决中的单个诉求建模 | §1，p.5 |
| 资源发布 | 诉求级 CLC UKET 数据、人工结果标签、人工泄露判断与人类基准 | §1，p.5 |
| 诊断方法 | 泄露差距、系数分布分析、三项屏蔽干预的组合 | §2.4–2.5 |

阅读者分析：结论“去除泄露后性能几乎不变”只在 TF-IDF 三元词模型、且只屏蔽 LLM 认定的 200 个三元词上成立；LLM 审计与两位法律专家的一致率仅 53%/67%（30 个特征样本），未识别的泄露表述仍可能留在文本中，所以“剩余信号是合法预测信号”是推断而非证明。输入的案件事实本身是 LLM 生成的摘要，提示设计时已试图排除结果描述，泄露程度与摘要提示相关。

依据：[arXiv:2607.04261v2](https://arxiv.org/pdf/2607.04261v2)，§2.1、§2.4、§3.4，PDF pp.6、8、13–14。
