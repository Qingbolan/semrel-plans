# 出发点

LLM 零样本标注在通用任务上表现不错，但金标基准有特定约定：实体范围、灰色地带、边界取舍。作者认为 LLM 在这类基准上的差距主要不是缺少知识，而是与基准约定不一致（§1、§6.1，PDF pp.1、8）。

传统语料项目用标注指南统一人工标注者，并通过"审核"阶段迭代澄清指南。作者因此提出三个假设（§1，PDF pp.1–2）：

- H1：提示中加入标注指南能提升 LLM 标注质量；
- H2：推理型模型优于同族非推理模型（应用规则是演绎，修订规则是归纳）；
- H3：在极少监督下，指南可通过审核过程有效改进。

阅读者分析：出发点是"复用已有人工资产对齐 LLM"，而不是提出新的 NER 模型；方法依赖已有详细指南的存在。
