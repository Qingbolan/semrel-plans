# 解决的问题

**任务**：把为人工标注者写的指南改造成能约束 LLM 的提示，并在少量金标上迭代修订（§3.1，PDF p.3）。

**单位**：NER 标注为三元组（起始字符偏移、结束偏移、实体类型），以 PubAnnotation JSON 表示；评测用严格匹配（边界与类型都一致）的 F1，作者称其为 IAA 率（§3.3、§4.1，PDF pp.3、5）。

**循环**（Figure 1，PDF p.3）：

1. 第 k 轮用指南 `G_k` 标注开发集 D，得到 `A_k`；
2. 与金标比较；若 F1 ≥ τ，或修订后不再提升（`IAA_k ≤ IAA_{k-1}`），则停止并丢弃最后一次修订；
3. 否则做审核：差异分析 → 模式解释 → 原则生成 → 指南修订，得到 `G_{k+1}`。

差异分析用软匹配（至少重叠一个字符）把错误分为标签不符、边界不符、FN、FP 四类，按（金标标签，预测标签）有向分组，选最频繁的一组作为本轮目标；每个案例带 60 字符上下文（§3.4.1，PDF pp.4–5）。原则须为 IF/THEN 形式并带排除条件；修订时提供已正确的样例作为"不得翻转"的检查（§3.4.3–3.4.4，PDF p.5）。
