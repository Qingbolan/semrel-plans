# 贡献与评价

原文声称的贡献（§1，pp.2–3；§6，pp.11–12）：

1. 把黑板架构作为 LLM 多智能体的通信范式：主智能体广播请求而不点名分派，子智能体自主决定是否参与，区别于主从式和"共享记忆 + 中心分派"式。
2. 将该范式落地到需数据发现的数据科学任务：按簇划分数据湖给 file agent，并加入 web search agent。
3. 改造 DSBench 与 DA-Code，去掉"问题→文件"的直接映射并人工过滤缺乏发现线索的问题，构成带发现环节的评测（附录 A，p.19）。

阅读者分析：方法核心是"广播 + 自选"的通信协议，组件本身（ReAct、文件预览、Google 检索）都很常规。与主从基线相比，差异只在请求是否点名，因此主表对比基本是对通信方式的受控比较，这是本文实验设计的优点。黑板思想在 LLM 多智能体中并非首次出现（参考文献含 Han & Zhang 2025 基于黑板的 LLM 多智能体探索，p.13），本文新意更多在于把它与数据湖分区结合并做系统评测。

阅读者分析：DSBench/DA-Code 的过滤是人工判断"是否有足够发现线索"，改造后的集合并非独立第三方基准，跨论文比较时要注意。原文没有独立的局限性章节；未来工作只提到推广到其他领域与自适应数据划分（§6，p.12）。

依据：§1、§5–6，pp.2–3、11–12；附录 A，p.19。
