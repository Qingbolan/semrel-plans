# Li et al. — AutoKaggle: A Multi-Agent Framework for Autonomous Data Science Competitions

AutoKaggle 是一个面向表格数据竞赛的多智能体框架。它把流程拆成六个阶段，由 Reader、Planner、Developer、Reviewer、Summarizer 五个智能体分工完成，并结合迭代调试、每阶段单元测试和一个机器学习工具库。在 8 个 Kaggle 竞赛、每个 5 次试验的设置下，GPT-4o 版本的平均有效提交率为 0.83（生成提交文件的比例为 0.85），综合得分为 0.821；基线 AIDE 分别为 0.58 和 0.641。已阅读正文 §1–§5，以及附录 B 数据描述和 C.2 单元测试。
