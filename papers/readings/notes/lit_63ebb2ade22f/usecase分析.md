# 具体用例

论文的贯穿例子（Fig. 2，§2，p.3）是**多维度作文评审**，采用 branch-solve-merge 提示：

1. 把图片与作文加入提示，用 `select` 判断作文是否与图片相关（yes/no）；不相关则直接返回。
2. 相关时 `fork` 出 3 个分支，分别从 Clarity、Originality、Evidence 三个维度用 `gen` 生成评语，以 “END” 停止。
3. 合并三段评语，生成总结与字母等级。
4. 用 `gen(regex=...)` 输出符合 `{"summary": ..., "grade": "[ABCD][+-]?"}` 模式的 JSON。

作者称等价的 OpenAI 式接口实现需要 2.1 倍代码行（p.3）。运行时在此例中可用到三项优化：分支共享前缀的 KV 复用、正则约束的快速解码、API 模型的推测执行（Fig. 2 注释）。

阅读者分析：该例形态类似语义过滤（相关性判断）后接多属性语义抽取与结构化输出，是语义算子在单条记录上的执行模式；批量处理多篇作文时，系统提示与图片 KV 均可共享。
