# 贡献与评价

**相对 1.0 版的新内容**（§1、§3–6）：

1. 重新设计类别体系：新增 LVC.cause、VPC.semi、MVC、LS.ICV，ID 改为 VID 并吸收 OTH，IReflV 改名为 IRV。
2. 用统一判定树取代"先识别后分类"的两阶段流程。
3. 新增阿拉伯语、巴斯克语、克罗地亚语、英语、印地语；捷克语、马耳他语、瑞典语因语料未更新而不再包含。
4. 推出合并 conllu 与 parsemetsv 的 cupt 格式。
5. 新增四类现象专门指标：连续/不连续、单/多 token、训练中见过/未见、与训练相同/变体。
6. 按子语料来源分层划分 train/dev/test。

**评价**：这是共享任务综述，主要贡献是多语言数据和评测框架，没有提出新模型。作者坦承由于人力不足大部分语料没有双人标注，只双标了至少含 100 个 VMWE 的样本；一致性差异很大，κspan 从西班牙语 0.227 到土耳其语 0.984（§4.2，p.7）。

阅读者分析：现象专门指标把"见过/未见"的差距（平均约 50 个 F1 点）明确量化出来，这一点比总体 F1 更有参考价值；但这些宏平均把 19 种语言等权平均，缺失的提交按 P=R=0 计入，因此只覆盖部分语言的系统排名天然偏低（阅读者分析）。

依据：§1、§3–7，PDF pp.1–9。
