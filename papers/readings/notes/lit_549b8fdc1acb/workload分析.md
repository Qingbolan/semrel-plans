# 工作负载

| 数据集 | 规模（原文） | 任务 | 指标 |
|---|---|---|---|
| WikiTQ | 18,496 个问题 | 单表问答 | denotation accuracy |
| FeTaQA | 9,329 个问答对 | 单表自由文本回答 | ROUGE-1/2/L |
| TabFact | small test，1,998 对 | 单表事实核验 | 字符串匹配 |
| PingCAP 工业数据集 | 超过 300 GiB；平均每题涉及 4 张表 | 多表计费分析 | 结果准确率，由资深工程师审核 |

工业数据包括 TiDB Cloud 的汇总与明细计费数据、数据库事件和运行状态数据，任务包括检测租户账单显著变化、下钻找最大贡献单元、判断变化是否由数据库操作或异常 SQL 引起；实时数据通过 API 和连接器接入。论文没有给出工业数据集的题目数量，也没有说明 WikiTQ 与 FeTaQA 使用的评测划分。作者为工业数据集人工标注了 5 个 few-shot 示例。

依据：§5.1.2–5.1.3，PDF pp.8–9。
