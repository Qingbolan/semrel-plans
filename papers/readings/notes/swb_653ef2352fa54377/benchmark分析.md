# 评测与边界

- 基线与指标：论文没有设置基线系统，也没有报告 GPT-4 管线的精确率、召回率或 F1；“benchmark” 指数据可作为人工或自动抽取的评测基准。唯一的一致性数字是专家在 97% 情况下同意其中一名非专家（约 3% 另给值）。
- 质量控制（Technical Validation）：检查缺失判断与标注者 ID、逐报告行数离群人工检查、判断与改值不一致自动修正、为人工补录记录建 ID；非专家改值不一致时人工检查；最后检查金标准逻辑一致性。
- 局限（原文）：报告数量少，推广性有限；“两名非专家一致即为金标准”可能带偏差，存疑时应只用经专家裁决的报告；Scope 3 为可选披露，“总量”由企业自己定义，可比性差；GHGP 排放多为活动量×排放因子估算而非实测；人工可能存在确认偏差。

阅读者分析：使用者若要用本数据评测抽取系统，需自行定义匹配规则（数值与单位、归一化单位、页码是否计入）和对“无合格值”报告的处理；由于 LLM 预抽取产生了初始候选，金标准可能偏向 GPT-4 检索到的页面，这一点原文只以确认偏差的形式提及。

依据：[Scientific Data 12:1497 (2025)，9 页](https://www.nature.com/articles/s41597-025-05664-8)，Data Records（p.7）、Technical Validation（pp.7–8）、Limitations（p.8）。
