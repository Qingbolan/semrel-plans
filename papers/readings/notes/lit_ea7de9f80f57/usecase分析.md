# usecase

Table 2 的“综合决策”示例（p.4，原文为节选）：2022 年某汽车制造商在选址前按给定评分规则为各省的产业配套能力打分，问配套综合指数最高的省份的指数值是多少。

智能体需要：在不知道哪些文件相关的情况下浏览 18 个源文件；识别地区行业统计表、可能还有企业表；处理单位不一致、实体名歧义和缺失值；按题目给出的规则计算各省指标并排序；最后给出一个数值。评测按唯一答案判 Acc，并检查中间里程碑（例如是否正确取出各省对应指标）计算 GPR。

更简单的“企业–行业分析”示例：2022 年 X 公司营业收入是否高于其所在省份同行业的营业收入总额（2–5 步）。§4 Q7 指出，“实体属性查找”失败时智能体最常主动放弃（45.7%），而聚合计数/求和类失败时 69.0% 给出错误答案后停止（Table 6，pp.7–8）。

阅读者分析：这类题本质是跨表查找 + 聚合 + 排序，但 schema 与连接键需要自己发现。若本项目将其转写为 SQL 或语义算子查询，属于派生任务，且会去掉原基准最核心的“发现数据源”负担。

依据：[arXiv:2605.02503v3，25 页](https://arxiv.org/pdf/2605.02503)，Table 2、§4 Q7、Table 6，PDF pp.4、7–8。
