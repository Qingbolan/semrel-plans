# Deng & Wiebe — MPQA 3.0: An Entity/Event-Level Sentiment Corpus

本文在 MPQA 2.0 的跨度级观点标注之上增加实体/事件级情感目标（eTarget）标注，形成 MPQA 3.0。eTarget 锚定到名词短语或动词短语的中心词，并链接到已有的情感态度或带极性的 ESE。正式一致性研究用 4 篇文档、292 个 eTarget，平均 agr 为 0.82；当前语料 70 篇文档、4,459 个 eTarget。这是一篇 6 页短文，没有自动模型实验；已通读全文。
