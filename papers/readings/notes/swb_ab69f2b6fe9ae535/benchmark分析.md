# 评测与边界

**实验 1（标注一致性）**：两名标注者独立标注 4 篇文档。对每个态度或 ESE，把标注者 X、Y 的 eTarget 集合 A、B 轮流当作金标准，计算平均 F 值 agr(A,B) = (|A∩B|/|B| + |A∩B|/|A|)/2。四篇文档平均 agr 为 0.82，作者称一致性良好（§3，p.4）。

**分歧分析**：

| 分歧类型 | 占比 |
|---|---|
| 边界情形：句子是否确实传达了对某实体/事件的态度（如 Mugabe 是否为 eTarget） | 29% |
| 多个态度跨度重叠、来源与极性相同但强度不同，新 eTarget 应链接到哪个 | 8% |
| 疏忽：讨论后承认漏标 | 31% |
| 其余：填错 id 等操作错误 | 未给出具体数字 |

阅读者核算：其余类型约占 32%（100−29−8−31），原文未写出该数字（阅读者分析）。

**没有的评测**：无自动系统、基线或下游任务指标；没有报告 Cohen κ 等机会校正指标。

**边界**：客观言语事件尚未加 eTarget；中性 ESE 被排除；一致性样本仅 4 篇；语料只有 70 篇，部分为单人标注（§2、§3、§5）。

依据：§2–5，PDF pp.2–5。
