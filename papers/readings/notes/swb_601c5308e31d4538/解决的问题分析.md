# 解决的问题

**StoryLine Extraction 任务**（§2 开头，PDF p.2）：给定同一话题（seminal event）下跨时间分布的多篇新闻，完成三个子任务：

1. 事件检测与分类；
2. 时间锚定：把事件提及锚定到其发生时间的时间表达式，以及文档创建时间（DCT）；
3. 解释关系识别与分类：选出时间上和逻辑上相连的事件对，并分类关系类型。

另有事件共指消解（文档内与跨文档），用于去重（§2，p.2）。

**标注单位**（§2.1–§2.4，PDF pp.2–5）：

- 事件：沿用 ECB+ 定义，只标承载动作意义的中心词；7 类（5 个 TimeML 类 + ACTION_CAUSATIVE、ACTION_GENERIC）；
- TLINK 只标锚定关系：事件–DCT 取 before/after/overlap/contains，事件–时间表达式只取 contains，方向从时间指向事件；
- PLOT LINK：事件对之间的不对称、非传递关系，分为 rising_action（情境、原因或使能）与 falling_action（推测与后果）；只在 ACTION_OCCURRENCE、ACTION_PERCEPTION、ACTION_STATE 类事件间标注；另有 cause / caused_by 二值属性和 signal 属性标显式因果。

**实验设定**（§3，PDF p.6）：使用金标准的事件跨度、时间表达式跨度与值、事件共指，只预测 PLOT LINK。
