# Discourse Structure and Dialogue Acts in Multiparty Dialogue: the STAC Corpus

STAC 是在线 Catan 游戏中的多人对话语料，标注协商行为与 SDRT 话语关系。语料表示可以是图，论文介绍的部分解析实验却先移除复杂话语单元；使用时必须区分原始标注和转换后的评测对象。关键结果：标注一致性 κ 连接 0.72、标签 0.58；相邻连接基线 LAST 的 F1 为 58.4%。
