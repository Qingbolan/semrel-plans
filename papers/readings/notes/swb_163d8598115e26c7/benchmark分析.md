# 评测与边界

**指标**：实例级评测。从 K 个候选中选中确切真匹配才算成功，选错同时计为一个假阳性和一个假阴性。F1id 衡量有匹配锚的选择准确性，F1none 衡量无匹配锚的拒绝能力，F1macro 为两者平均。效率分数为 F1macro/ln(1+成本)。

**实验 1（主结果，Table 2，GPT-4o mini 后端）**：

| 方法 | 训练 | 平均 F1macro | 推理成本（美元） | 效率分数 |
|---|---|---|---|---|
| DITTO | 每数据集监督 | 85.64 | 2.22 | 73.2 |
| Matching | 无 | 46.66 | 2.19 | 40.2 |
| Comparing | 无 | 58.08 | 0.54 | 134.4 |
| Selecting | 无 | 69.94 | 0.15 | 499.7 |
| COMEM | 无 | 74.25 | 0.59 | 160.0 |
| CaRL-EM | 仅 AB | 76.09 | 0.13 | 623.7 |

CaRL-EM 并非每个数据集都最好：在 DA、DS 上低于 Comparing，在 WA 上（64.60）明显低于 COMEM（78.76）。

**实验 2（迁移与换后端，Table 3）**：DITTO 只在 AB 训练后迁移，F1macro 从 85.64 降到 59.75。换后端不重训控制器时，Llama-3.1 为 69.36，Qwen3 为 79.37，成本为 0.07–0.48 美元。阅读者分析：Table 3 中 COMEM 的 F1macro 为 73.22，与 Table 2 的 74.25 不一致，论文未解释。

**实验 3（消融，Table 4）**：去掉成本项 F1 基本不变（76.07），成本升至 0.15；去掉 MATCH 后 F1none 降到 49.86；去掉 SELECT 后 F1id 降到 75.13，跨数据集标准差升到 20.60。ρ 从 2.5 改为 5 时 F1macro 为 77.20（附录 C）。

**实验 4（位置偏差）**：把真匹配固定在 0–9 各位置并重复 10 次。Selecting 对位置更敏感，CaRL-EM 跨位置与跨数据集更稳定（Figure 5）。

**边界**：只覆盖 clean-clean、至多一个真匹配；候选池小（top-10），更大候选集需要不同设计；两级抽象成本不反映真实计费，换到不同成本环境可能需重新校准或重训。端到端成本含训练时高于 DITTO（附录 Table 7），见 Novelty 分栏。
