# 贡献与评价

**论文自述贡献**：

1. 问题形式化：作者称首次把 LLM 驱动的多候选 EM 表述为成本感知的序列 RL 过程；
2. CaRL-EM 控制器：组合 MATCH/COMPARE/SELECT/DECIDE 与两级抽象成本，控制器与具体 LLM 解耦，测试时可换后端而不重训；
3. 效率与效果：在 7 个基准上超过最佳人工组合管线，称成本降低 78%；约达到监督模型 89% 的效果，成本降低 94%。

**阅读者评价**：算子集合（MATCH、COMPARE、SELECT）直接沿用 COMEM，新意在用 RL 策略替代固定管线去调度它们，并加入成本惩罚。

阅读者分析：“成本降低 94%”比较的是 CaRL-EM 的推理成本（0.13 美元）与 DITTO 的训练加推理成本（2.22 美元）。附录 Table 7 计入 CaRL-EM 一次性 PPO 训练（16.45 美元）后，端到端成本为 16.59 美元，高于 DITTO 的 2.23 美元。只有在多个目标数据集上复用同一控制器、摊销训练成本时，这一比较才成立。

阅读者分析：成本模型只有两档，作者在局限中承认没有建模提示长度、按 token 计费、延迟与批处理等真实成本。

依据：[ACL 2026 long 1258，13 页](https://aclanthology.org/2026.acl-long.1258.pdf)，§1 贡献列表，PDF p.2；§5.1–5.2、Table 2，PDF pp.6–7；附录 F Tables 7、10，PDF pp.12–13；Limitations，PDF p.9。
