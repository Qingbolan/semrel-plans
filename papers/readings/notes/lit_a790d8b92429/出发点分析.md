# 出发点

数据标准化指把同一列中的异构格式统一为一种目标格式（如日期统一为 MM/DD/YYYY HH:MM:SS），是数据集成与分析的前置步骤。用 Pandas 手写时，每种列类型都要做类型识别、逐单元格校验（如正则）和转换，可能写上百行代码（§1 Example 2 给出地址标准化的正则示例）。直接让 LLM（如 ChatGPT）生成标准化代码虽可行，但仍需细致的提示工程和多轮对话（引 ChatPipe），且要求用户具备编程能力。

作者的核心想法：与其让 LLM 生成冗长的过程式代码，不如提供声明式、统一的类型专用 API，让 LLM 只需把自然语言需求翻译成几行 API 调用；再用多 agent 框架让用户“只提一次需求”即可全自动完成。

依据：[Qi, Miao & Wang，VLDB 2025 Workshop DATAI，4 页](https://www.vldb.org/2025/Workshops/VLDB-Workshops-2025/DATAI/DATAI25_8.pdf)，§1，p.1–2。
