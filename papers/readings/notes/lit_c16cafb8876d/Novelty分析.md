# 贡献与评价

原文声明的贡献（§1，PDF p.2）：

1. 研究 LLM 执行旋钮剪枝、模型初始化、旋钮推荐三个子任务的能力，并为每个子任务设计提示。
2. 全面评估开源与闭源 LLM（GPT-3.5、GPT-4-Turbo、GPT-4o、Claude-3-Opus、Llama3-8B/70B-Instruct、Qwen2-7B）。
3. 跨基准、数据库引擎、硬件环境评估泛化。
4. 总结研究机会（§9.2 的五条，PDF p.12）。

**主要发现**（§9.1，PDF p.12）：LLM 在三项子任务上可匹敌或超过传统方法，尤其推荐任务迭代极少；输出呈“思维链”式解释，可解释性更好；不同 LLM 各有所长，没有单一模型始终最好；仅靠调整提示即可泛化到新场景。

阅读者分析（评价）：

- 方法新意有限，核心是提示工程与系统化实验对比，属于评测/实验论文。
- 所有表格都是单次运行的单一数值，原文未报告重复次数、方差或显著性；不同表中同一基线数值也不同（VBO 在 Table 2 为 154.73，在 Table 3 为 155.10，PDF pp.8–9），说明存在运行间波动。
- TES 只计迭代次数，不计 LLM 调用的时延和费用；LLM 推荐最多 30 轮，而传统方法跑 400 轮（§7.2、§6.1，PDF pp.7–9），两类方法的预算不对等。
- 剪枝的人工基线只有一位行业专家（§5.1，PDF p.6）。
- “可解释性”只以 Figure 5 的示例输出说明，没有对解释正确性的评测（§7.3，PDF p.9）。

依据：§1、§5–7、§9，Tables 2–3、Figure 5，PDF pp.2、6–9、12。
