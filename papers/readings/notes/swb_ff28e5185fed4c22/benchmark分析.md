# 评测与边界

**系统**：16 个——Claude Code（Opus 5、Sonnet 5）、Codex（GPT-5.6-Sol、GPT-5.6-Luna、GPT-5.5、GPT-5.4、GPT-5.4-mini）、Gemini CLI（Gemini 3.6 Flash、3.5 Flash、3.1 Pro），以及 opencode 框架上的 6 个开源权重模型。均经 MCP 连接环境，禁用 web。

**指标**：四分类准确率、Macro-F1、无缺陷准确率与缺陷差（Gap）、过程分、过度承诺率、过度弃权率、ECE、证据与政策 grounding、重复运行的 avg@k / pass^k、资源与成本。

**实验 1（主榜，Table 3，750 例）**：节选如下（%，ECE 为 0–1）。

| 系统 | Acc | 无缺陷 | Gap | 过程分 | 过度承诺 | ECE |
|---|---|---|---|---|---|---|
| Codex GPT-5.5 | 76.1 | 71.3 | 4.8 | 78.6 | 38.7 | 0.090 |
| Claude Code Opus 5 | 75.6 | 70.0 | 5.6 | 82.0 | 32.0 | 0.064 |
| opencode GLM-5.2 | 73.6 | 64.8 | 8.8 | 76.4 | 42.0 | 0.130 |
| Gemini CLI 3.1 Pro | 72.7 | 57.9 | 14.8 | 56.4 | 21.3 | 0.256 |
| opencode Qwen-3.7-Plus | 65.3 | 53.1 | 12.3 | 65.9 | 46.0 | 0.187 |

所有系统的过度承诺率（21.3–55.3%）都高于过度弃权率（7.3–16.5%）。逐场景看排名不稳，16 个系统中 14 个至少在一个场景上最好；场景平均准确率从 91.7%（eol-goal-concordance）到 37.1%（pneumonia-curb65）。

**实验 2（grounding）**：记录标识精度 0.985–1.000，区分不出系统；陈述级精度按框架家族分层（Codex 0.965、opencode 0.922、Gemini CLI 0.898、Claude Code 0.877），与准确率排名无正相关。政策文档召回最高不超过 0.703。

**实验 3（消融，148 例开发子集）**：撤掉政策库对准确率无可靠影响（McNemar p=0.21–1.00）；三次运行 pass^3 比 avg@3 低 8.3–12.6 点；固定模型换框架准确率差不超过 4.1 点，但完成 token 相差 4.3 倍；提高推理强度不提升准确率。

**边界（原文）**：单一医疗中心数据；分层抽样分布不代表患病率；参考标签由模型集成产生并仅抽样校准，非全量独立临床复核；临床委员会结果不应视为人机对比；每场景仅 30 例。陈述精度与发现覆盖由 GPT-5.5 单独评判，独立评判复现留作后续。

依据：[arXiv:2608.07796v1，52 页](https://arxiv.org/abs/2608.07796)，§6.1–6.2、Table 3、Figures 4–7，PDF pp.21–29；§6.4–6.6、Tables 5–11，PDF pp.29–34；§6.7–§7，PDF pp.34–36。
