# Li, Zhou, Zhao — LLM for Data Management

这是 VLDB 2024 的一篇 4 页教程提案（tutorial proposal），概述如何用 LLM 优化数据管理系统：围绕 RAG、领域微调、提示管理、LLM agent 与向量数据库五个组件给出一个通用架构，并点名查询改写、数据库诊断、数据处理与自然语言数据分析等应用。全文没有实验、数据集或量化结果；它的价值在于议题地图和组件划分，而不是可复用的评测。已通读全文（含大纲、开放问题与讲者介绍）。
