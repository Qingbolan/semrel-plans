# 工作负载

本文没有工作负载：不使用任何数据集、查询集或基准，也没有训练/测试划分或规模数字。

教程只列出它会讨论的任务类别（§2.2）：

| 类别 | 任务 | 教程描述 |
|---|---|---|
| 配置调优 | knob tuning | 用 LLM 提取调优经验或直接推荐参数值（引 LLMTune、DB-BERT） |
| 查询优化 | query rewrite | 生成改写规则、探索规则应用顺序（引 Liu & Mozafari） |
| 系统诊断 | root-cause 诊断 | 由查询/数据库/系统统计识别根因并给出修复（引 D-Bot） |
| 数据处理 | 错误检测、缺失值填补、模式匹配 | 替代依赖经验规则的方法 |
| 数据分析 | NL2SQL、NL2Vis、代码生成 | 降低非专业用户的分析门槛 |

阅读者分析：若需要这些任务的实际负载规模，应查阅教程引用的原始论文（例如 BIRD [14]、D-Bot [31]），本文不能作为其数据来源。

依据：[PVLDB 17(12) 4213–4216](https://www.vldb.org/pvldb/vol17/p4213-li.pdf)，§2.2，PDF pp.3–4。
