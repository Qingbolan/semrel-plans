# novelty

作为评测综述，本文的贡献是任务设定、数据与评测协议以及对参赛方法的总结，而不是新模型。具体包括：(1) 人工标注的合成岗位–简历语料，其生成依据从真实简历和职位描述中统计出的技能共现模式（来自组织方内部数据库），并人工审查以防数据泄漏；(2) 加入性别扰动下的排序稳健性评测；(3) 用分级相关度把技能类型编码进 NDCG；(4) 用 Codabench 维持赛后的持续评测。方法层面，Task A 的优胜系统以多阶段检索为主：稠密 + BM25 混合召回、交叉编码器或 LLM 列表式重排、秩融合，有的先用 LLM 把文档解析为结构化 JSON，或接入 ESCO 图；Task B 更依赖对比学习微调编码器，再配合 HyDE 查询扩展和 LLM 重排。

阅读者分析：Task B 的开发/测试查询与上届相同，只扩充修订了语料，而组织方提到参赛者复用了上届资源，因此存在一定的泄漏风险。数据生成与标注细节不在本文中，可审计性依赖另两篇任务综述。
