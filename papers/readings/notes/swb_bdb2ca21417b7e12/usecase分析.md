# 具体用例

**显式关系补义项**：Listing 1 的句子意为"FDP 成员 Möllemann 正积极访问近东地区，以便为此做好准备，并推荐自己为新任自由派外长"。2.1 版中关系 5 有连接词 und（and）、Arg1 为"für diesen Fall gerüstet zu sein"、Arg2 为"sich als neuer liberaler Außenminister zu empfehlen."，但没有义项（§3，p.2）。2.2 版的 standoff XML 为其加上 `pdtb3sense="Expansion.Conjunction"`，并按 token ID 列出连接词与两个论元（Listing 2，p.3）。

**隐式关系的分歧**：例 (1) 两句都在说 Helga Kaden 关店；一位标注者标为 Expansion.Level-of-detail.Arg2-as-detail 的隐式关系，另一位标为 EntRel（同一实体但无明确关系）。例 (2) 节前购物一例则在 Level-of-detail 与 Contingency.Cause.Reason 之间分歧，对应的隐含连接词分别是 genauer gesagt 与 denn（§4.1，p.4）。

依据：[LREC 2020，2020.lrec-1.133，6 页](https://aclanthology.org/2020.lrec-1.133.pdf)，§3–4.1、Listings 1–2，PDF pp.2–4。
