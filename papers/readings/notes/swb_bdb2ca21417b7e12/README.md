# Bourgonje & Stede — The Potsdam Commentary Corpus 2.2: Extending Annotations for Shallow Discourse Parsing

本文发布德语新闻评论语料 PCC 2.2：为已有的显式连接词—论元层补上 PDTB 3.0 体系的关系义项，并新增句间隐式关系、AltLex、EntRel、NoRel 层，使其在标注方案上对齐 PDTB。全库 2,208 个关系；显式关系义项 Cohen's κ 为 0.74，而新关系类型的 κ 只有 0.28。已通读全文 6 页；论文没有训练或测试解析器。
