# 贡献与评价

原文所述新增内容（§1，p.1；§5，p.5）：

1. 为显式连接词—论元层补充 PDTB 3.0 义项，并修正少量不一致。
2. 新增隐式关系与 AltLex、EntRel、NoRel 三种关系类型。
3. 从行内 XML 转为 standoff XML，便于自动处理。
4. 报告新标注的一致性，并与 PDTB 2.0 比较分布。

标注流程：义项直接写入 XML 属性；隐式关系导出为每行一句的制表符文件，在电子表格中填写类型、义项和连接词后再转回 XML，随后做语法与一致性检查（§3，pp.2–3）。未使用 Connanno（只由显式连接词触发）或 PDTB Annotator（需改造以跳过已标内容）。

阅读者分析：新意在于德语资源补齐而非方法。全库新标注由第一作者单人完成，双标只覆盖小样本；新关系类型 κ=0.28 偏低，说明隐式层的可靠性有限，作为训练数据时需谨慎。

依据：[LREC 2020，2020.lrec-1.133，6 页](https://aclanthology.org/2020.lrec-1.133.pdf)，§1、§3–5，PDF pp.1–5。
