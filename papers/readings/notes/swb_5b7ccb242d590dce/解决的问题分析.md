# 解决的问题

**任务 1：可能不公平条款检测**（§4.1，PDF pp.10–11；§5，p.12）。

- 输入：ToS 中的一个句子（句子级分类），或整篇文档的句子序列（集体分类）。
- 输出：二值标签，正类表示该句包含可能不公平的条款。
- 正类既可以是 8 类不公平句子的并集，也可以只取单一类别。

**任务 2：不公平类别分类**（§5，p.14）。

- 输入：已知为可能不公平的条款。
- 输出：属于 8 个类别中的哪一类，用 8 个一对其余的 SVM 实现。

**8 个类别**（§2，p.3；Table 1，p.6）：仲裁 `<a>`、单方变更 `<ch>`、内容删除 `<cr>`、管辖 `<j>`、法律选择 `<law>`、责任限制 `<ltd>`、单方终止 `<ter>`、使用即同意 `<use>`。前 5 类来自 Loos 与 Luzak 的归纳，后 3 类为作者新增。

**标注层级**（§3.1，p.5）：每个标签后加数字表示公平程度，1=明显公平，2=可能不公平，3=明显不公平；同时属于多类的片段使用嵌套标签。实验中的"正类"指含可能不公平条款的句子，原文未单独给出 2 与 3 级的分开实验（阅读者分析）。

**样本单位**：句子，由 Stanford CoreNLP 切分；评测按文档做宏平均（§5，p.12）。
