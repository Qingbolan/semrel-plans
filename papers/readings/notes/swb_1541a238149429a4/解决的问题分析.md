# 解决的问题

本文定义并标注一个面向 IPF 机制的信息抽取任务集合，单位是一篇摘要中的文本跨度及其结构（Methods，pp.2–6）：

| 层次 | 内容 | 说明 |
|---|---|---|
| 实体 | 15 类，含 Disorder、GGPs、Subject、Anatomical_entity、Cell、Measurement 等，以及 Negation/Speculation/Method 三类提示词 | Table 1，p.3 |
| 事件 | 15 类，触发词 + 论元（Theme、Cause、Participant、Product、atLoc 等），新增 `disorder` 论元 | Table 2，p.4 |
| 事件修饰 | Negated、Speculated | 由提示词连接确定，p.4 |
| 关系 | part_of、member_of、Subject_Disorder、Disorder_association | Table 3，p.6 |
| 归一化 | 实体和事件触发词赋 UMLS 2018AB ID（必要时查 NCI Metathesaurus） | p.4 |

评测任务因此是：输入一篇摘要原文，输出实体/触发词跨度（精确边界）、UMLS 链接、事件结构及关系（Evaluation，pp.6–7）。Regulation 事件可递归以其他事件为 Theme/Cause；Correlation 用于因果不明的关联，可连接两个以上论元（pp.3–4）。

依据：Methods and materials，PDF pp.2–7；Tables 1–3。
