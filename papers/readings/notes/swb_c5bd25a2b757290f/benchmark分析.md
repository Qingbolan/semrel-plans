# 评测与边界

**实验 1（标注者一致性，第一阶段后，Tables 8–9，pp.8–9）**：用 F1 而非 kappa，因为标注者既要定类型又要定边界。部分匹配用 Hopcroft-Karp 二分图最大匹配，保证一对一。

| 设置 | 实体宏平均 F1 | 关系宏平均 F1 |
|---|---|---|
| 精确匹配，不考虑层级 | 57.4 | 47.3 |
| 精确匹配，考虑层级 | 63.8 | 47.1 |
| 部分匹配，不考虑层级 | 68.7 | 50.3 |
| 部分匹配，考虑层级 | 76.1 | 53.8 |
| 部分匹配，考虑层级，不计方向 | — | 57.0 |

化学物、基因、单倍型、疾病在最严格设置下也超过 70；表型、基因组变异的边界分歧大，例如 Pharmacodynamic_phenotype 精确匹配只有 31.7。作者据此在两阶段之间修订了指南。

**实验 2（预标注修正，Table 10，p.10）**：以最终标注为金标准，预标注在"部分匹配 + 类型可不同"时 P/R/F1 = 94.1/64.0/76.2；在"精确匹配 + 同类型"时为 66.9/45.5/54.2。关系不做预标注。

**实验 3（基线，10 折交叉验证，Tables 11–12，pp.10–11）**：NER 用 CNN 变体，RE 用多通道 CNN。NER 宏平均 F1 在精确/不考虑层级时为 49.15，在部分/考虑层级时为 71.93；Gene_or_protein 最高（85.72–90.58），Genomic_variation 精确匹配只有 2.67。RE 宏平均 F1 不考虑层级为 45.67，考虑层级为 49.56；isEquivalentTo 79.76，increases 17.94；把 PGx 关系合并为一类时为 54.04。

**原文承认的局限**（pp.10–11）：NER 不处理不连续实体，并把它们当作负例；RE 对每个实体对独立预测，没有全局推断；否定与假设关系被当作普通关系；训练时不利用层级；稀有类别标准差很大（如 Haplotype 19.34）。

依据：Technical Validation、Tables 8–12，PDF pp.7–11。
