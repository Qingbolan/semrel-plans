# 解决的问题

**任务**：从 PubMed 句子中抽取 PGx 实体及其关系。基线拆为两步：NER 和关系抽取（RE）。

| 要素 | 内容 |
|---|---|
| 输入 | PubMed 摘要中的单个句子（含标题句） |
| 输出 | 实体（类型 + 可能嵌套或不连续的区间）；实体对之间的有向关系（类型 + 模态） |
| 样本单位 | 句子（945 句）；评测单位为实体与关系 |
| 实体层级（Fig. 4） | Chemical；Genomic_factor → Gene_or_protein、Genomic_variation → Limited_variation、Haplotype；Phenotype → Disease、Pharmacokinetic_phenotype、Pharmacodynamic_phenotype |
| 关系层级（Fig. 5） | isAssociatedWith → influences → causes、decreases、increases、metabolizes、transports；以及 treats、isEquivalentTo |
| 模态 | 正文 p.3 写"positive、hypothetical、negative 或 both"四值；指南描述为 affirmed、negated、hypothetical（p.6） |

**类型选择**（p.5）：用 Chemical 而不用 Drug，因为 PubTator 不区分药物与化学物，这样也能覆盖代谢物和未上市药物。用 Gene_or_protein，因为基因名与蛋白名在 NLP 中难以区分。

**嵌套与不连续实体**（p.3）："acenocoumarol sensitivity" 是包含药物 "acenocoumarol" 的嵌套表型实体；"VKORC1 genotypes" 是不连续实体（Fig. 1）。

依据：Statistics、Methods、Figs. 1、4、5、Table 5，PDF pp.3–7。
