# 贡献与评价

**原文声称的贡献**（pp.2–3、11）：

1. 作者称这是第一个在同一句中同时标注药物、基因组因素和表型三类关键实体，并标注 PGx 专属关系的语料：92% 的句子（874/945）含全部三类实体，47% 的关系（1,353/2,871）涉及这三类实体。
2. 实体与关系都有层级，支持嵌套与不连续实体。
3. 规模上，标注关系数是 SNPPhenA 和 EU-ADR 的 2–3 倍；无关系句子只占 2.7%。
4. 提供 NER 与 RE 基线，以及 BRAT 在线浏览、figshare、GitHub 发布；许可证为 CC-BY 4.0。

**构建方法的特点**（pp.4–7）：PubTator 预标注关键实体，再用 PHARE 本体结合依存句法，把预标注扩展为复合实体（如 "drug + sensitivity → DrugSensitivity → Phenotype"）。每句由两人独立标注，再由一位资深标注者复核，最后统一同质化。

**阅读者分析（评价）**：

- 新意在 PGx 专属的实体/关系模式和三类实体共现的句子；规模（945 句）仍然偏小。
- 关系标注者一致性很低：严格设置下宏平均 F1 为 47.3，isAssociatedWith 只有 12.6（Table 9）。这说明任务定义本身存在较大歧义，基线分数的上限也受此影响。
- 选句要求含药物和遗传因素，有约一半随机抽取的句子被标注者丢弃（952/1,897），说明筛选条件精度有限。

依据：Background、Statistics、Methods、Technical Validation，PDF pp.2–11。
