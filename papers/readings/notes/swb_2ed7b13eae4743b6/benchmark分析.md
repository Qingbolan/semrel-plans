# 评测与边界

**实验 1（基线对比，Table 2，测试集）**：

| 方法 | 执行准确率 | 程序准确率 |
|---|---|---|
| TF-IDF + 单步除法 | 1.01 | 0.90 |
| 检索器 + 直接生成答案 | 0.30 | – |
| 预训练 Longformer（base，整页输入） | 21.90 | 20.48 |
| 检索器 + Seq2seq | 19.71 | 18.38 |
| 检索器 + NeRd（BERT-base） | 48.57 | 46.76 |
| FinQANet（FinBert / BERT-base / BERT-large） | 50.10 / 50.00 / 53.52 | 47.52 / 48.00 / 51.62 |
| FinQANet（RoBERTa-base / large） | 56.10 / 61.24 | 54.38 / 58.86 |
| FinQANet-Gold（金标准事实） | 70.00 | 68.76 |
| 人类专家 / 普通众包 | 91.16 / 50.68 | 87.49 / 48.17 |

BERT 检索器 top-3 召回 89.66%，top-5 召回 93.63%；TF-IDF top-5 召回 82.91%（§6.1）。

**实验 2（细分，Table 3，RoBERTa-large）**：

**实验 3（错误分析，§6.3）**：50 个错误中 15% 来自检索；其余一半缺金融知识，一半为数值推理错误（多步、单位换算、数字与年份匹配）。

**边界**：人类专家结果来自 200 个随机样例，两位专家执行准确率 92.25%/90.06%，一致率 92.65%（§4.3）；未处理复杂表格（§3）；系统定位为辅助而非替代专家（§8）。阅读者分析：未报告多次运行方差。

依据：[EMNLP 2021，14 页](https://aclanthology.org/2021.emnlp-main.300)，§3、§4.3、§6、§8、Tables 2–3，PDF pp.3–4、7–9。
