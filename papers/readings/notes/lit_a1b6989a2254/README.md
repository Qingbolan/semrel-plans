# Chai, Wang, Luo, Niu & Li — Data Management for Machine Learning: A Survey

这是一篇综述，按 ML 流程把数据库技术如何服务 ML 分为三部分：训练前的数据准备（数据发现、清洗、标注），训练中的加速（特征选择、模型选择、训练/推理加速），训练后的模型管理（存储与查询、诊断、部署与服务、流水线调试），最后给出研究挑战。论文没有自己的实验，主要价值是分类框架和各类方法的比较表（Tables 1–6）。已阅读 §1、§2、§5、§6 全文，§3–4 以小节开头与比较表为主做选择性阅读。
