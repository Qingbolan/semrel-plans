# 贡献与评价

**论文自述贡献**（§1.4，pp.3–4）：综述 Pre-ML（§2）、In-ML（§3）、Post-ML（§4）三部分技术，并在 §5 提出研究挑战与方向。

**比较表**是最有用的产出：

| 表 | 内容 | 页 |
|---|---|---|
| Table 1 | 数据发现方法：粒度、目标（数据/ML 导向）、来源、适用模型、是否语义感知 | p.4 |
| Table 2 | 面向 ML 的清洗方法（ActiveClean、BoostClean、CPClean、DAGAN、SampleClean） | p.6 |
| Table 3 | CleanML 基准的结论汇总 | p.7 |
| Table 4 | 标注方法在质量、成本、延迟、模型感知上的定性比较 | p.8 |
| Table 5 | 特征选择方法的质量/效率比较 | p.10 |
| Table 6 | 模型选择并行方法的可扩展性、收敛性、可复现性 | p.11 |

**§5 提出的方向**（pp.17–18）：面向 ML 的元组级数据发现、更通用的面向 ML 清洗、标注的理论保证、数据准备效率、端到端 ML 优化器、库内深度学习、DB 与 ML 混合优化器、系统容错学习、流式模型管理、模型分解与重组、系统化协作式流水线调试。

Tables 4–6 中的"高/中/低"是作者的定性判断，正文没有给出统一的测量依据。稿件 2021 年 6 月收到，2022 年 1 月修订（p.1），因此不覆盖 LLM 用于数据准备的工作。作者在 §1.2 明确以 DB 社区视角组织 In-ML 部分，ML 社区方法只简要介绍（阅读者分析）
