# 具体用例

**用例：用 RC-4 为"朝鲜洪灾"新闻组（CSTNews C12）生成摘要（Quadro 7.7、Figura 7.19，印刷 p.136，PDF p.138）。**

RC-4 的步骤：

1. 对每篇文本的 RST 树，用 Marcu（1997）的算法给句子打分，并按树高归一化。
2. 计算每句收到的 CST 跨文档关系数，作为 CST 分。
3. 句子最终分 = RST 分 + CST 分，合并为全组统一排序。
4. 删除"卫星句"（只由一个卫星命题构成的句子）。
5. 依次取排序最高的候选句：若与已选句为完全冗余，按 Quadro 7.6 的规则处理；若为 SUBSUMPTION，保留包含另一句的那句；若为 OVERLAP 或其他关系、无关系，则加入候选句。
6. 重复直到达到压缩率。

生成的摘要有三句：至少 549 人死亡、295 人失踪；据亲平壤的日本报纸《朝鲜新报》，7 月下旬暴雨造成"大量破坏"；朝鲜拒绝国际机构援助，但表示会接受韩国无条件援助。

作者指出这类方法的已知缺陷：多文档中重要的句子若在原文中是卫星，会被删掉；OVERLAP 关系未处理，可能保留部分冗余（如 RC-3 的 Figura 7.18 中 S1 与 S2 重复）（§7.1.3，印刷 pp.135–137）。

阅读者分析：这一流程可视为"先在单文档内按篇章核性打分、再按跨文档关联度加权、最后去冗余"的语义选择管线；但它要求输入已有人工 RST 与 CST 关系。

依据：Cardoso 2014，§7.1.3、Quadros 7.6–7.7、Figuras 7.18–7.19，印刷 pp.133–137（PDF pp.135–139）。
