# 贡献与评价

**论文的主张**：把人工"先形成预期、再看数据、最后判断差异"的探索过程分解为语义上下文、语义画像、语义复核三步，交由 LLM 完成，并系统地套用到 Profiler 研究过的各类数据错误上（§1，p.2；Table 1，p.3）。

**与已有工作的区别**（§2，p.2）：传统错误检测先从数据分布中学规则，再标出违例，但系统性错误（如采集设备故障导致整列错误）会让"干净分布"本身有误；以往画像工具依赖人工解读统计图表。Cocoon 用 LLM 提供这一层语义，作者把它定位为 Text-to-SQL、数据变换等 LLM 数据任务的"上游系统"。

**评价**：设计清晰，Table 1 为每类错误给出统计画像、语义画像和复核规则三者的对应，可直接复用为提示模板。

阅读者分析：贡献主要是系统设计和分类框架，没有定量验证。论文没有报告误报、漏报率，没有与 Profiler 或纯统计方法做对照，也没有报告 LLM 型号；摘要称用户研究显示"高度有效"，但支持这一点的只有两名参与者的定性访谈（§4，p.6）。

阅读者分析：高阶类型（地理实体、类别）目前只做分类、不做错误检测（§3.2.2，p.4），基于约束的错误也列为未来工作（§3.2.10，p.5）。
