# 贡献与评价

**论文自述贡献**（§1，p.3）：

1. 支持任意（不限等值）自然语言连接条件的多种语义连接算法：元组嵌套循环（Algorithm 1）、块嵌套循环（Algorithm 2）、自适应连接（Algorithm 3）。
2. 基于 token 消耗的代价分析与调参公式：Theorem 5.2 证明应让每次调用用满 token 上限；Lemma 5.4 给出 b2 关于 b1 的最优表达；Theorem 5.6 给出 b1 的闭式最优解（pp.6–7）。
3. 自适应算法从乐观选择率估计出发，遇溢出则乘以 α；Theorem 6.5/6.6 证明在估计落在 [σ, ασ] 时，费用不超过最优的 α·g 倍，并随数据增大收敛到此界（pp.8–9）。
4. 模拟与 GPT-4 实测，与 LOTUS 及嵌入连接比较。

**与传统块嵌套循环的差异**（§8，p.12）：传统模型只需一页输出缓冲，选择率不影响批大小；LLM 中输出占用输入预算，且每次调用都要重新读全部输入，因此“一表极大、一表极小”的传统策略并非最优。

**阅读者评价**：思路直接，把“批量多行进一个提示”形式化为带输出预算的优化问题，理论部分完整；证明依赖连续化假设（忽略取整）和常量行大小。实证规模很小（每表 10–100 行），场景大多由模板合成，准确率结论只有三个点，尚不能说明块连接在大批量下的召回稳定性。与 LOTUS 的比较中，后者并行执行而本文顺序执行，时延对比不对等，作者已说明。
