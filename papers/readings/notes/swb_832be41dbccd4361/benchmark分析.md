# benchmark

**骨干比较**：固定 ReAct 式 DataSpace-Agent，每任务限 60 轮模型调用、50 次工具动作、1,800 秒，资源 4 CPU/16 GiB（Table 3）。

| 骨干 | 解出 / 410 | 准确率 |
|---|---|---|
| Grok 4.5 | 272 | 66.34% |
| GPT-5.6 Sol | 265 | 64.63% |
| Kimi K3 | 219 | 53.41% |
| MiMo-V2.5 | 161 | 39.27% |
| Claude Sonnet 5 | 135 | 32.93% |
| MiniMax M3 | 117 | 28.54% |

56 个任务六个模型都能解出，76 个都解不出，并集可解 334 个（81.46%）。

**Harness 比较**（固定 MiMo-V2.5，只设 1,800 秒期限、不设统一动作上限）：Grok Build 46.34%、Claude Code 44.63%、DataSpace-Agent 39.27%、Codex 34.88%、Smolagents 30.98%。

**其他发现**：
- 效率：GPT-5.6 Sol 比 Grok 少用 74.2% 的 token；MiMo-V2.5 每任务只需 $0.011。
- 分层：多模态任务比单模态低 1.8–14.0 点，需要连接的任务低 9.7–19.8 点；作者声明这些差异只是描述性的。
- 失败分析（Grok 4.5 的 136 个失败，人工）：答案物化错误 71 个（52.2%），任务意图理解错误 31 个（22.8%），只有 3 个是选错证据源。

**边界**：论文没有局限性章节。DeepAnalyze、AgenticData 因接口或实现不可用而未评测。论文未报告重复运行次数或方差。

阅读者分析：harness 比较放开了动作上限，与骨干比较的预算条件不同，两组数字不宜直接横向比较；竞赛期间的判分规则也与本文最终评测协议不同（附录 B）。
