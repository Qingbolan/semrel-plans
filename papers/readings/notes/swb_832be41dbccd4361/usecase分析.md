# usecase

Figure 1 的基金风险任务问：“哪些基金跑赢了 2023 年所属类别的基准，同时触发了视频中定义的回撤警报？返回基金、类别、收益、基准、最大回撤与严重度排名。”工作区包含 fund.csv（2,100 余行）、category.json（87 条映射）、daily_nav.sqlite（2022–2023 年日净值）、bench2023.pdf（90 余页）、risk_brief.mp4（8 分 17 秒）和 Knowledge.md（5 万余字符）。代理要从视频获得警报规则（图中标注为最大回撤阈值），从长 PDF 抽取类别基准，从 SQLite 查询日净值并计算最大回撤，对齐基金与类别实体，再过滤、排序并导出完整表格。

阅读者分析：这一用例对应“文档字段抽取 + 视频条件抽取 + 关系计算”的混合计划。抽取对象是 LLM 按源表生成的文档和视频，答案可以由原 SQL 精确复算；若在本项目中把它改写为语义算子计划，属于派生任务，不是论文直接评测的内容。

依据：[arXiv:2608.03451v1（2026-08-04），24 页](https://arxiv.org/abs/2608.03451)，§1、§4.3，Figure 1，PDF pp.1、5。
