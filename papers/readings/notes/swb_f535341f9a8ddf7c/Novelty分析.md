# 贡献与评价

**原文声称的贡献**（pp.2、9–13）：

1. 作者称 LCT 是公开的、人工标注的入排标准语料中规模最大、覆盖最全的一个。
2. 标注方案比 EliIE/Chia 更细：新增 Contraindication、Name 实体、细粒度时间/比较实体，以及 Abbrev-Of、Example-Of、Duration、Temporality 等关系。
3. 质量验证：标注者一致性、单/双标注对比、人工/半自动部分互测。
4. NER 与关系抽取基线，以及原型网页应用；展示标注到 DAG 的转换（Fig. 4）。

**与已有语料对比**（Table 1，p.2）：

| 指标 | EliIE | Chia | LCT |
|---|---|---|---|
| 疾病领域 | 阿尔茨海默病 | 全部 | 全部 |
| 文档数 | 230 | 1,000 | 1,006 |
| 标注数 | 15,596 | 68,174 | 105,816 |
| 实体/关系类型 | 8/3 | 15/12 | 50/51 |
| 平均每文档实体/关系 | — | 46/19 | 105/49 |

**阅读者分析（评价）**：

- 新意主要在标注粒度与面向查询的设计；文档数与 Chia 相当，主要差异是标注密度。
- 原文承认的核心缺口是：语料不含查询，也没有定义量化"语义表达能力"的方法，因此"更利于查询生成"的说法尚未被实证（Limitations，p.12）。
- 约 88% 的文档只有单人标注，约一半文档由模型预标注后人工修正，存在偏差风险；作者用交叉训练结果论证一致性，但这只能说明可学习性相近，不能直接证明标注正确。

依据：Background、Table 1、Technical Validation、Limitations，PDF pp.1–2、9–12。
