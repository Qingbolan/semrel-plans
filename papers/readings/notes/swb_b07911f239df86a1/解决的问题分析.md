# problem

这不是计算任务论文，而是语料构建与质量评估。对象：25 篇英文网络文本，来自四种文体（Wikinews 新闻与访谈、wikiHow 操作指南、Wikivoyage 旅行指南），每名学生自选一篇 500–1000 词的文本，并在整个学期中对它做多层标注。

**标注层与产出**：
1. 分词与 POS：扩展 Penn Treebank 标签集，手工从头标注；另有未校正的 CLAWS5 层。
2. TEI 结构标注：14 种元素，含句子 `<s>`。
3. 句法：Stanford parser 自动生成成分树并保留，转换成 Stanford 依存后由学生在 Arborator 中校正。
4. 实体类型（由 OntoNotes 合并而来的 11 类）、信息状态（giv/acc/new）、共指（ana、cata、appos、bridge、coref 五类），用 WebAnno 标注。
5. RST 语篇结构：20 种关系，用 RSTTool。

**评估方法**：与教师/助教裁定后的版本比较，而不是独立标注者之间的一致性。

依据：[Zeldes, The GUM Corpus，作者预出版稿 PDF，32 页](https://gucorpling.org/amir/pdf/GUM_paper_prepub.pdf)，§2–3、Tables 1–4、7，PDF pp.3–20。
