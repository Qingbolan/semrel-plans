# Ma et al. — SpreadsheetBench: Towards Challenging Real World Spreadsheet Manipulation

SpreadsheetBench 是一个电子表格操作基准：从四个 Excel 论坛/博客收集 912 个真实用户问题，配 2,729 个测试用例（平均每题 3 个），要求模型生成代码修改 XLSX 文件，并用在线评测（OJ）式的多测试用例精确匹配打分。最好的 GPT-4o 单轮总体软分 18.35%，Excel 专家为 71.33%。已阅读正文 §1–4 及附录 A–D（局限、数据来源与标注、推理设置、指标人工核验）；附录中的示例图和提示词只做了浏览。
