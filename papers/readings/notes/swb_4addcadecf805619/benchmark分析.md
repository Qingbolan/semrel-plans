# 评测与边界

**设置**（§3，p.8）：单轮时提示中给出表格前几行，模型一次生成代码；多轮时加入 ReAct 与代码执行反馈，最多 5 轮。LLM 温度和 top_p 均为 1（附录 C.2）。TableQA 模型对每个测试用例单独输出文本答案。SheetCopilot 与 Copilot in Excel 由作者在产品中手工评测，只用 50 条指令、每条 1 个测试用例。

**实验 1（主结果，总体分数，Table 2，p.9）**：

| 模型 | 软分 | 硬分 |
|---|---|---|
| Binder (GPT-3.5) | 1.17 | 0.00 |
| DeepseekCoder 33B（多轮） | 5.31 | 3.85 |
| Llama-3 70B（多轮） | 3.74 | 3.18 |
| GPT-3.5（多轮） | 7.09 | 5.37 |
| GPT-4o（单轮） | 18.35 | 15.02 |
| GPT-4o（多轮） | 16.96 | 13.27 |
| SheetCopilot (GPT-4)* | 14.00 | — |
| Copilot in Excel* | 20.00 | — |
| 人类专家 | 71.33 | 62.00 |

TaPEx、TaPas 所有指标为 0，未列入表中。代码模型优于同类通用模型；多数模型多轮后提升，GPT-4o 略降（p.9）。

**实验 2（复杂度子集，GPT-4o 软分，Table 3，p.8）**：

| 子集 | 占比 % | GPT-4o 软分 |
|---|---|---|
| 行数 ≤50 | 75.19 | 20.63 |
| 行数 >50 | 24.81 | 11.50 |
| 单表 | 62.90 | 21.12 |
| 多表 | 37.10 | 13.71 |
| 关系表 | 55.54 | 19.50 |
| 非标准表 | 44.46 | 16.95 |

**实验 3（推理设置，200 样本 4 次平均，Table 5，p.18）**：GPT-4o 单轮 12.79，“多轮+执行反馈+5 行”16.08 最高；加入 ReAct 反而下降。这修正了主表中 GPT-4o 多轮更差的单次结论。

**实验 4（指标人工核验，附录 D.3，pp.19–20）**：50 条指令的 GPT-4o 结果中，自动判对者无一被人工判错；自动判错的测试用例有 3.8% 实为正确，原因是代码输出了答案位置之外的额外内容。

**边界**：作者承认数据选择排除了没有确认解答或难以形式化的帖子，测试用例未系统设计全部边界情况（附录 A.1，p.14）。原始帖子数据不再二次分发（A.3）。

阅读者分析：正文称 GPT-4o 约 17%，但 Table 2 单轮为 18.35、多轮为 16.96；产品类结果与人类结果只基于 50 条指令，与全量 912 条的模型分数不可直接比较。

依据：§3、Table 2–3，pp.8–10；附录 A、C–D，pp.14、17–20。
