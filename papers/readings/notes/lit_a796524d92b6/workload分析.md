# 工作负载

原文没有数据集、查询集合、数据划分或实验规模，不能从本文抽取任何工作负载数字。

正文只按类型提到工作负载。LLM4Data：点查询与聚合查询；非结构化文档分析；先抽取 schema，再用 SQL、表格问答或 NL2SQL 回答；混合多模态数据湖上的 schema linking 与查询规划（§2.2.2）。

Data4LLM：预训练数据的领域配比、coreset 选择、过滤与去重、增强、标注、合成；训练检查点与数据并行；推理中的 prefill/decode、KV cache 存储与淘汰、向量数据库。推理指标仅概念性提到 TTFT 与 TBT 两个 SLO，没有数值（§2.3.2）。

若要作为工作负载来源，只能引用本文点名的下游系统论文；本文本身不构成 benchmark（阅读者分析）。

依据：§2.2.2、§2.3.2，PDF pp.3–6。
