# 评测与边界

本文没有实验、基线、指标或主要结果，因此没有可报告的 benchmark 数值。唯一涉及评价的是概念指标：推理服务用 TTFT（反映 prefill）和 TBT（反映 decode）衡量 SLO（§2.3.2）。

**原文列出的开放问题（§2.4）**：推理侧尚未充分利用数据层优化，如查询批处理与调度、高频 token 缓存、GPU/CPU 数据放置、prefill/decode 分离；数据准备依赖多个独立工具，需要端到端、LLM-in-the-loop 的统一系统；数据飞轮面临数据质量、系统集成、扩展、隐私等挑战。

§2.2.2 末段另指出 schema linking 与规划的联合优化尚未解决。

本文只能当领域地图和文献索引使用，不能作为性能证据引用（阅读者分析）。

依据：§2.2.2、§2.3.2、§2.4，PDF pp.5–6。
