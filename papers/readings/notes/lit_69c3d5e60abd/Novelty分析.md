# 贡献与评价

论文自述贡献（§1）：S1 逐步编排学习框架，把过程组织与子任务执行分离；S2 Search-to-Policy Learning；S3 实验与经验发现。

Search-to-Policy Learning 的组成：
1. MCTS 工作流探索（§4.2、Algorithm 1）：节点是编排状态、边是动作；UCT 选择（式 7）；扩展时同一动作可在非零温度下多次采样；模拟到终止后用执行一致性奖励（式 8）——额外采样 K 个 SQL，看执行结果被复现的比例，不可执行则为 0；每题 N_rollout=24。
2. 监督整理（§4.3、Algorithm 2）：按动作序列（工作流骨架）分组，成功与否按与金标准执行一致判断，稳定性 p̂_τ=(s_τ+1)/(n_τ+2)（Beta(1,1) 先验的 Laplace 平滑，式 11）；每题取 top-k（k=3）个骨架，各随机取一条成功轨迹，再让 LLM 为每步补写“为何调用该动作”的理由。
3. 稳定性加权 SFT（§4.4）：屏蔽 &lt;results&gt; 段的损失，只训练策略生成的推理与调用；同题内权重 w_τ ∝ p̂_τ^α，α=2（式 16–17）。
4. 课程 RL（§4.5）：只选 MCTS 成功率 ρ 低于阈值 γ 的难题；GRPO；奖励 = λ·r_out + (1−λ)·r_exe，r_out 在完全正确时为 1+ExecF1，否则为 ExecF1（式 23–27）。

阅读者分析：MCTS 搜索 Text-to-SQL 推理路径（Alpha-SQL）和先规划后执行（SquRL）已有先例；本文新意在于把离线搜索结果蒸馏成在线逐步策略，以及用稳定性而非“首个正确”选择监督。课程阈值 γ 的取值以及 BIRD-Train 实际使用的题量，正文未给出。
