# 解决的问题

任务（§2.1）：给定自然语言问题 q 和数据库 D，输出 SQL y；以执行准确率 EX 评价，即 Exec_D(y) = Exec_D(y*)。

编排形式化（§2.2）：动作空间 A={a(1)…a(K)}，工作流 τ=(a_1…a_T)；执行产生轨迹 ξ=(s_0, a_1, o_1, s_1, …)，o_t=a_t(s_{t−1}, D)。逐步编排为 a_t = π(s_{t−1})，与一次性规划 τ=π(q, D) 相对。

本文动作空间（§4.1，式 6）：a_dec 问题分解、a_val 相关值抽取、a_op 操作识别（聚合、分组、排序、嵌套等）、a_sch 模式剪枝（可反复调用）、a_gen SQL 生成（DAIL-SQL 式少样本，生成后执行并把反馈写入状态）、a_ref SQL 修正（DeepEye-SQL 式 fail-fast 工具链：语法、执行、逻辑、质量检查）、a_term 终止并输出最新 SQL。前六个由冻结的 LLM 执行，策略只决定调用哪个。

在线推理（Algorithm 3）：策略输出 &lt;reasoning&gt;…&lt;/reasoning&gt;&lt;call&gt;动作&lt;/call&gt;，系统解析并调用动作模块，结果写回上下文；选择终止或到达 T_max=10 步时输出 SQL。

工作单位：一个 (问题, 数据库) 对产生的一条多步编排轨迹。

依据：[arXiv 2606.23537v1，14 页](https://arxiv.org/pdf/2606.23537v1)，§2、§4.1、§4.6、Algorithm 3，PDF pp.2–4、8–9。
