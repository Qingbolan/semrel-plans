# 解决的问题

**任务格式（§3.1）**：每个任务给出自然语言提示，含 Question（如“2023 年哪个卡组织平均欺诈率最高？”或“若商户 X 改变业务类别，费用会如何变化？”）、Guidance（答案格式，如“以 scheme:fee 给出，fee 保留两位小数”）、Context（所需数据与文档文件）和 Level（Easy/Hard）。

**输入**：问题 + 挂载的上下文文件；agent 可在隔离环境中调用 Python 内核执行代码（§4.1）。**输出**：一个事实型答案——字符串、数字或逗号分隔列表；每题仅有一个正确答案（§3.3）。

**评分（附录 A.2，Algorithm 1）**：先归一化；数值提取后带容差比较；列表拆分、排序、逐元素递归比较；字符串清洗后精确匹配，否则模糊相似度 >0.95 也判对。作者用 75 个模型答案、两名标注者人工判定（一致率 97.3%，κ=0.94）验证，评分函数与人工判断 75/75 一致。

数值容差在正文写为“如 10⁻⁴”，而 Algorithm 1 写为 10⁻²，两处不一致；实际实现以代码仓库为准，论文本身未澄清（阅读者分析）。

依据：[Egg et al.，arXiv:2506.23719v1，26 页](https://arxiv.org/abs/2506.23719)，§3.1、§3.3、§4.1、附录 A.2，pp.5–7、13–14。
