# 贡献与评价

作者自述贡献（§1）：
1. **数据**：450+ 个真实数据分析任务，测试多步推理与规划，数据源包括 10 万级以上交易的支付数据集；
2. **事实型评测框架**：二值对错，配以灵活评分处理格式差异；
3. **基线**：开源与闭源 LLM agent 的结果与失败模式；
4. **社区平台**：开发集、快速上手 notebook、开源基线代码和在线排行榜。

特色设计：借鉴 GSM-Symbolic，对核心任务按时间范围、商户名、阈值等参数系统扩展（95 个核心 → 450 个实例），以减少记忆与侥幸命中，并检验同一推理在不同输入下的一致性（§3.1）。隐藏测试集只在排行榜评测，另发布带答案的小型开发集（§3.3）。

创新主要在“真实业务来源 + 结构化/文档混合 + 客观评分”的组合；参数化意味着 378 个 Hard 实例只来自 23 个核心问题，实例间高度相关，有效独立任务数远小于 450。基线是轻量 smolagents 包装的 ReAct，而非专门的数据 agent 系统（阅读者分析）。

依据：[Egg et al.，arXiv:2506.23719v1，26 页](https://arxiv.org/abs/2506.23719)，§1、§3.1–3.3，pp.2、5–6。
