# 评测与边界

**设置（§4.1）**：多数模型使用通用 ReAct 风格提示（数据分析师角色，Python 执行工具，结构化输出）；o4-mini、o3-mini、o1、R1、Gemini 2.5 Pro 使用统一的“推理提示”变体。每题最多 10 步（Table 1 题注；推理模型除外）。开源模型在 4×A100 80GB 上本地运行；包装层为 smolagents，不使用复杂 agent 框架。评测于 2025 年第一季度。

Easy 集最高的是 GPT 4.1（80.56%），而非 Hard 集第一的 o4-mini。成本为按 2025 年第一季度公开价格与 token 用量估算。

**失败模式（§4.3）**：规划与隐含规则遵循不足；复杂任务中代码趋于低效（显式循环）；输出格式指令不遵循（对话文本、舍入、分隔符错误）；推理模型对提示敏感，R1、o1 在标准 ReAct 提示下一度接近 0%。作者称结果为未优化提示下的下界。

**局限（§5）**：首版只支持文本输入与事实型输出，无图表/PDF 视觉推理和开放式分析；仅金融支付单一领域。

**评测边界**：未报告重复运行方差；正文与附录对交易数（100k+/138k+）和数值容差（10⁻⁴/10⁻²）表述不一致（阅读者分析）。

依据：[Egg et al.，arXiv:2506.23719v1，26 页](https://arxiv.org/abs/2506.23719)，§4–§5、Table 1，pp.3、6–9。
