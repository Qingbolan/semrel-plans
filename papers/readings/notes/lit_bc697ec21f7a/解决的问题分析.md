# 解决的问题

**输入（弱提示）**：S = (C, E, I)，分别是待转换列、示例和转换意图。示例可以是实例级的输入输出对，也可以是抽象级的类型、格式说明（§3.1、Table 1，p.5）。

**中间产物（强提示）**：轻量 LLM 推断指令 I = (O, D)。O 是六种算子之一：format、extract、discrete_map、continuous_map、unit_convert、misc_transform；D 是具体的编码说明（§2.2、§3.1，pp.4–5）。强提示由弱提示加上这条指令组成。

**输出**：一段 Python 函数 `solution(input)`，对该列每个值执行转换。

**流程**：生成中间代码，执行并检查是否通过全部测试用例；未通过时，若错误在清单内则由 LLM 生成修复建议，最多尝试 k=3 次；清单外的错误写入日志，交给 Lazy-RAG（§2.3、Algorithm 1，pp.4、6）。

**评测单位**：一个转换任务。每个任务的前 3 个示例放入提示，其余示例作为测试用例；准确率是成功完成的任务比例，主实验报告 Pass@3（§6.1，p.9）。

依据：§2–§4、Algorithm 1、§6.1，PDF pp.3–6、9。
