# 具体用例

**反思流程示例（Example 3、Fig.6，p.7）**：任务是把女鞋尺码转换为男鞋尺码，示例为 7.5→6、14→12.5、8→6.5。

1. GPT-4o 根据强提示生成中间代码，逻辑是减去 1.5，但变量名写成了带撇号的 `women's_size`。
2. 执行器捕获 `SyntaxError: unterminated string literal`。
3. 该错误在清单内，于是由 Reflector 生成修复建议：Python 变量名不能含撇号。
4. 重新生成的 `womens_size` 版本通过测试，作为最终代码输出。

**检索示例（Fig.8，p.9）**：涉及 pyproj、hijri_converter、mgrs 等库的任务，在代码引用这些包时触发 Lazy-RAG，检索到的文档追加到强提示中。

阅读者分析：Fig.6 的算子标签写作 `domain_map()`，不属于 §2.2 定义的六种算子之一，可能是早期命名遗留。

阅读者分析：这类“对一列逐值套用一段可复用代码”的模式，可以作为语义映射算子的低成本实现参照；但本文只处理单列、逐值的转换。

依据：§4、§5、Example 3、Figs.6、8，PDF pp.6–9。
