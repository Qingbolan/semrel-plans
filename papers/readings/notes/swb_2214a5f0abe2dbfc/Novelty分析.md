# 贡献与评价

**原文声明的贡献**（§1）：（1）首个法语原生、由专家标注的法条检索数据集 BSARD；（2）在其上建立词法与稠密检索基线；（3）公开数据和代码（CC BY-NC-SA 4.0，Zenodo 发布）。

**数据构建的特点**（§3.1）：问题来自 Droits Quotidiens 的"模型问题"——法律专家把每年约 4,000 封求助邮件中的常见问题改写成匿名的通俗问题，并为之查找法条。作者收集 3,200 多个此类问题，把带情境描述的分类标签（如"我是布鲁塞尔的租客"）拼到问题前以消除约三分之一的重复，再用正则把文本引用解析到法条 id，过滤掉引用非法典文件的问题，最后剩 1,108 个。

**评价**（阅读者分析）：数据集价值在于真实需求来源和专家标注；模型部分只是标准 BM25 与 DPR 式双编码器，不是方法创新。问题经过专家改写，不是原始邮件，因此比真实用户提问更规范。只保留可映射到 32 部法典的引用，会让部分问题的标签不完整（作者在 §6.1 也承认）。

依据：[ACL 2022，2022.acl-long.468，15 页](https://aclanthology.org/2022.acl-long.468)，§1、§3.1、§6.1，PDF pp.1–4、8。
