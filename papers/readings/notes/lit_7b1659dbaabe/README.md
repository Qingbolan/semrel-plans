# Majumder et al. — Data-driven Discovery with Large Generative Models

这是一篇立场论文（position paper），主张用大型生成模型（LGM）构建端到端"数据驱动发现"系统：仅凭给定数据集搜索并验证假设，不再额外采集数据或做物理实验。作者列出理想系统应具备的功能，并用基于 GPT-4 与 AutoGen 的多智能体原型 DataVoyager 做定性演示；全文没有定量实验、基准或指标。已阅读正文 §1–7 与附录 Figures 4–20 的图注。
