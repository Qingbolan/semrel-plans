# 出发点

作者认为企业"数据智能"流程包含两段：数据工程把原始源表加工成可分析的表，数据分析再把这些表转成面向决策的洞见。现有基准各缺一条轴：

- **Hard 轴（工程真实性）**：现有 text-to-SQL / 数据科学基准把工程简化为单条 SQL 或单个脚本，没有多层 DAG 的编排与在需求变更下的演化。
- **Soft 轴（分析开放性）**：现有分析基准多要求确定性答案，无法评价规划、多步探索、洞见综合、可视化与报告写作。

Table 1 将 DAComp 与 SWE-Bench、Spider 2.0、BIRD、DA-Code、DSBench、KramaBench、BLADE、DABStep 等对比：DAComp 是表中唯一同时"仓库级 + 开放式 + 执行比对与 LLM 评审并用"的数据智能体基准（作者自述）。

阅读者分析：其出发点是"代码正确率不足以衡量数据智能体"，因此在设计上把编排失败（级联错误）与分析综合能力当成首要测量对象，而非单节点 SQL 正确率。
