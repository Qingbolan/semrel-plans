# 解决的问题

**形式化（§4.1，pp.5–6）**：网页数据科学任务是映射 f: W × Q → Y × A，分解为 f = f_α ∘ f_a ∘ f_d：

- f_d：在网页环境中收集原始数据；
- f_a：把数据转化为分析结果（报告、模型、可视化）；
- f_α：可选的下游动作，也可以不做动作（a = ∅）。

**输入与观察**：每个任务从固定入口网址和一条自然语言目标开始。观察可以是 HTML、DOM、截图或 AXTree，并允许下载 CSV、JSON 等数据。benchmark 不限定动作空间，Python、Bash、SQL 等工具可以自行启用（§3，p.4；App. 8.5，p.16）。

**输出与判定**：有参考答案的任务，由 LLM 把最终输出或动作与参考答案比对，给出成功/不成功的二值结果。开放式任务由 LLM 评审对完整轨迹的（观察，动作，下一观察）三元组打 1–5 分（§5.1，pp.7–8）。

**评测单位**：一个任务；结果按领域、属性和难度分别统计（§3，p.5）。

依据：§3–§5.1，PDF pp.4–8；Appendix 8.5，PDF p.16。
