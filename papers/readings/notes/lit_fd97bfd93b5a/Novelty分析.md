# novelty

原文声明的贡献（§I，PDF p.1；§VI，PDF pp.5–6）：(1) 首个结合规则 teacher、bandit 探索与知识蒸馏做约束感知查询优化的框架；(2) 跨 schema 的“通用 schema 处理”；(3) 通过奖励塑形与约束监控显式满足内存/延迟约束；(4) 单文件 Python 可复现实现（GitHub 开源）；(5) NYC Taxi 与 IMDB 上的评测与消融。

组件：UCB1（式 4）、50 棵树的随机森林延迟模型（特征：6 个计划开关、表/连接/谓词数、表规模与列基数、当前内存与 CPU 负载）、LR 或 HistGradientBoosting student（交叉熵训练）。

阅读者分析（诚实评估）：各组件均为标准方法，组合本身是主要新意；“首个”声明缺少系统检索支撑。teacher 的动作空间只有 2^6 种开关组合，bandit 理论保证与查询优化场景的契合未作讨论。“通用 schema / 多领域泛化”仅基于 2 个数据集、共 40 个模板，证据有限。论文正文篇幅约 5 页，方法与实验细节（训练/测试划分、是否在同一模板上训练和测试 student）均未说明。

依据：[arXiv:2605.17831v1，6 页](https://arxiv.org/abs/2605.17831)，§I、§III、§VI，PDF pp.1–3、5–6。
