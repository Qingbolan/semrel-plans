# 贡献与评价

**作者声明的贡献**（§1，PDF p.3）：

1. 发现可以利用文档集合中的模板来支持临时分析查询。
2. 提出 SHT 及其高效抽取方法：先对单文档按视觉模式聚类，每簇最多抽 k 个短语让 LLM 判断是否标题，再按模板前缀匹配把结构推广到同模板的其他文档，无需再调 LLM（§3.2–3.3）。
3. 简单的 SQL 扩展：声明文档表、按需添加属性。
4. 利用 SHT 的查询引擎：依据代价与选择率对昂贵谓词排序，投影上拉；以表的估计 LLM 成本贪心构建左深连接树；节点摘要由祖先标题、NLTK 抽取式摘要、与谓词最相似的一句组成，用于自顶向下的树搜索（§6.1–6.2）。
5. 在三个真实数据集上实现并评测。

**原文报告的抽取有效性**：作者检查 16 个数据集、六个领域的 200 多个文档；k=10 时，GPT-4 在 97% 的文档上正确剔除非标题簇，总成本 $0.37（§3.2，PDF p.5）。

**评价**：

- 相对 Palimpzest、LOTUS 等语义算子系统，本文的独特点是把文档内部结构当作索引来缩小 LLM 上下文；查询优化部分（谓词排序、左深连接）基本沿用经典思路（阅读者分析）。
- 正确性保证依赖"格式良好"和"LLM 正确识别标题"两项前提；无模板或模板噪声大的情形被作者列为未来工作（§9，PDF p.14）（阅读者分析）。
