# Hettiarachchi, Dridi et al. — CODE-ACCORD: A Corpus of building regulatory data for rule generation towards automatic compliance checking

CODE-ACCORD 是一份面向建筑法规自动合规检查（ACC）的英文标注语料：从英格兰和芬兰建筑法规中筛出"自包含"规则句，随机抽取 862 句，由 12 名标注者标注 4 类实体、10 类关系，最终含 4,297 个实体与 4,329 个关系（含 1,000 个抽样的 `none`）。这是一篇数据描述论文，没有模型实验或基线结果。已阅读全文（方法、数据记录、描述统计、技术验证），并渲染核对 PDF p.9–10 的分布图。
