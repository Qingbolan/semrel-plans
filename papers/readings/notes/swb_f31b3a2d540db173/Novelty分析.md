# 贡献与评价

**原文主张的贡献**（Background pp.1–2；Methods pp.3–8）：

1. 一套与具体本体和子领域无关的通用标注策略：4 类实体、10 类关系，并发布完整标注手册；
2. 覆盖英格兰与芬兰两国、多个子领域（结构、消防、无障碍、能效等）的英文语料；
3. 半自动的句子收集流程：PDF 转文本、NLTK 断句、关键词过滤（量化要求、主观要求、义务逻辑三类特征）、人工去误报、人工挑选自包含句；
4. 作者称已有 NLP 建筑规范研究基本没有处理"主观要求"（如 should be、recommended）和义务逻辑（must、shall），本文把它们纳入筛选（p.4）；
5. 数据与各预处理阶段的中间文件均公开在 Zenodo 和 GitHub（pp.8、11）。

**阅读者评价**：

- 价值主要在开放数据与标注规范；类别设计参考已有工作，刻意保持简单，换来通用性但牺牲了表达力，例如没有例外、适用条件等 RASE 式结构。
- 只保留自包含句，回避了跨句引用和表格，而这些在真实法规中很常见；芬兰部分使用英文译本（p.3），并非原文。
- 实体一致性偏低（均值 0.37），关系完全没有报告一致性（p.11），依靠 3 名策展人裁决来保证质量。
- 论文没有提供任何基线模型结果，可用性尚未在本文中验证（阅读者分析）。
