# problem

**表示层面**（§3，PDF pp.10–17）：一篇文档的 eRST 分析由三部分组成：
1. 主树：单根、带标签、投射的 n 元成分树，叶子为互不重叠、覆盖全文的 EDU；每个非终结节点至少一个 nucleus，且禁止一元派生和同一节点挂两个无序 satellite（PDF pp.11–12）。GUM 关系集共 32 个标签（含 SAME-UNIT）。
2. 次级边集合（可为空）：有向、可非投射/成环；只能在有“充分信号”时添加（孤立 DM 即 orphan DM，或未被主树覆盖的转述引语、名词修饰从句等形态句法信号），同一有向路径不重复、不自连、不得新建节点（PDF pp.12–13）。因此任意两节点间最多三条边。
3. 信号集合：每个信号 = (所属主/次边, 信号类型标签, token 集合)；类型包括 DM 及 graphical、lexical、morphological、numerical、reference、semantic、syntactic 等（Table 1，PDF p.15）。

**解析任务**（§5.1，PDF pp.28–31）：输入为 token 化文本及给定的 EDU 切分；输出为主树、次级边及信号（类型 + 锚定 token）。工作单位是整篇文档，评价单元是“解析决策”（span、nuclearity/direction、label）与信号。

依据：[Computational Linguistics 51(1), 2025，ACL Anthology 2025.cl-1.3，50 页](https://aclanthology.org/2025.cl-1.3)，§3、§5.1，PDF pp.10–17、28–31。
