# motivation

RST 把整篇文档递归组织成带核心/卫星区分的标注树，适合摘要和对话规划，但它只允许相邻、连续跨度之间的单一关系，无法表达树外（tree-breaking）、非投射或并存的多重关系，也不说明关系由哪些词语或结构“标示”出来。SDRT 支持非投射与嵌套关系、PDTB 区分显式/隐式连接词、CCR 有特征化的关系分类，但各自又缺少层级结构、相对显著性（prominence）或完整文档覆盖（§1，PDF pp.2–3；§2.1–2.5，pp.4–10）。作者明确说，eRST 的主要动机不是提升某项 NLP 任务分数，而是给出更完整、可解释（带证据信号）的话语关系表示，能找回 RST 主树中缺失但文本中存在的关系（PDF p.3）。

阅读者分析：作者的出发点是“表示能力 + 可追溯证据”，而非建模效率；因此用 eRST 数据做下游任务时，应把信号视为关系的理由而非独立标签。

依据：[Computational Linguistics 51(1), 2025，ACL Anthology 2025.cl-1.3，50 页](https://aclanthology.org/2025.cl-1.3)，§1–2，PDF pp.1–10。
