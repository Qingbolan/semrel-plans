# 贡献与评价

**原文声称的贡献**（p.2；p.10 总结）：

1. 作者称 NLM-Chem 是当时规模最大、粒度最细的化学实体全文标注语料：150 篇全文全部双人标注，经三轮标注后分歧全部消解。
2. 新的端到端化学 NER 与归一化系统：BlueBERT + MTCR，性能优于此前的 TaggerOne。
3. 语料与识别结果公开：Dryad、NCBI 网站，以及 PubTator API 对全部 PubMed 的每日更新。

**与已有资源的差异**（p.8）：70% 的不同化学名在此前语料中没有出现；全文贡献了 70% 以上的不同 MeSH ID 和 78% 以上的不同化学名。

**阅读者分析（评价）**：

- 主要价值在高质量的人力投入（资深标引员、匿名配对、三轮流程）和"全文"这一覆盖面。
- 选文刻意偏向"现有工具难识别、化学提及丰富"的文章（工具间分歧加权、与已选文章不相似加权），这使测试集比随机全文更难，也更偏化学期刊；作者在 p.9 用期刊分布分析为这种选择辩护。
- 基线只与本组的 TaggerOne 比较，没有和其他公开化学 NER 系统比较。
- 原文没有独立的局限章节。

依据：Background、Methods、Technical Validation、Usage Notes，PDF pp.2–10。
