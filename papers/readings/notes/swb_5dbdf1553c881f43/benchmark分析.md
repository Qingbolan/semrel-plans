# 评测与边界

**实验 1（标注者一致性，Table 3，p.7）**：采用严格定义，提及和 ID 都一致才算完全一致；部分重叠算两个单人标注。

| 批次 | 第 1 轮完全一致 | 第 2 轮完全一致 | 第 2 轮仅单人标注 |
|---|---|---|---|
| 1 | 42.2% | 74.1% | 20.3% |
| 2 | 73.7% | 81.8% | 17.2% |
| 3 | 72.9% | 81.2% | 14.5% |

分歧主要来自漏标，而非边界或 ID 不同；第 3 轮配对讨论后达到 100% 一致。

**实验 2（预标注准确率，Table 4，p.8）**：以最终标注为准，TaggerOne 预标注的提及 F1 在批次 1–3 分别为 60.8%、74.8%、72.7%，ID F1 为 53.3%、68.0%、74.9%。作者据此认为标注者没有被工具带偏。

**实验 3（基线，Table 7，p.10，NLM-Chem 测试集 50 篇）**：

| 系统 | 训练数据 | 提及 P/R/F | MeSH ID P/R/F |
|---|---|---|---|
| TaggerOne | BC5CDR | 0.580/0.414/0.483 | 0.470/0.508/0.488 |
| TaggerOne | +NLM-Chem | 0.724/0.615/0.665 | 0.653/0.681/0.666 |
| BlueBERT+MTCR | BC5CDR | 0.731/0.523/0.610 | 0.792/0.599/0.682 |
| BlueBERT+MTCR | +NLM-Chem | 0.810/0.711/0.757 | 0.822/0.728/0.772 |

开发集用于早停（TaggerOne 连续 5 轮无提升即停止）。作者称最佳结果"离人类一致性不远"。

**边界**：

- 原文没有单独的局限章节。
- 选文偏向难例，绝对分数不能直接外推到随机全文。
- 只与本组系统比较；测试集只有 50 篇，按文章计数的样本量有限。

作者把 0.757/0.772 与人类一致性（约 81% 完全一致）相比，但两者口径不同：一致性按提及和 ID 同时一致计算，而基线把提及与 ID 分开评测（阅读者分析）。

依据：Technical Validation、Usage Notes、Tables 3–4、7，PDF pp.6–10。
