# 解决的问题

**任务**：跨领域 text-to-SQL。输入为自然语言问题和数据库模式（表、列、外键）；BIRD 上额外输入每表若干样本行和数据集提供的外部知识提示（§5.3，p.7）。输出为一条可执行 SQL。样本单位是一条"问题–SQL"对。

**约束**：只用提示，不做微调；少样本示例来自对应基准的训练集（§4，p.4）。Spider 设置中不使用数据库内容（§5.5.1，p.8）。

**分解后的子问题**（§4，pp.4–6）：

| 模块 | 输入 | 输出 |
|---|---|---|
| 模式链接 | 问题、模式 | 问题中提及的列/表及可能的单元格值 |
| 分类与分解 | 问题、模式、链接 | 类别（easy / non-nested complex / nested complex）、待连接表、子问题 |
| SQL 生成 | 以上全部 | easy 直接出 SQL；non-nested 先出 NatSQL 中间表示；nested 先解子查询再出 SQL |
| 自我修正 | 生成的 SQL | 修正后的 SQL（零样本；generic 或 gentle 提示） |

评测目标是 Spider 的执行准确率 EX 与精确集合匹配 EM、BIRD 的 EX 与有效效率分 VES（§5.4，pp.7–8）。

依据：§4.1–4.4、§5.3–5.4，Figures 2–3，PDF pp.4–8。
