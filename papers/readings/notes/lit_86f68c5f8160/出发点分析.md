# 出发点

论文指出，2023 年初用 LLM 做 text-to-SQL 的提示方法明显落后于微调模型：Table 1 中 Spider 开发集上，少样本 GPT-4 执行准确率 67.4%，而微调的 RESDSQL-3B + NatSQL 为 84.5%，差距集中在中等和复杂查询（§1，p.1–2）。

作者希望知道 LLM 在哪里失败、能否在不微调的情况下补齐。§3 在 Spider 训练集中随机抽 500 条（排除提示所用数据库），对 CodeX Davinci 少样本失败案例人工归类：模式链接 37%、JOIN 21%、GROUP BY 13%、嵌套与集合运算 13%、其他 13%、无效 SQL 3%（Figure 1，p.3，已渲染核对）。论文未给出失败案例的绝对数量。

动机落点是：SQL 是声明式语言，步骤边界不如数学题清楚，但可以按"找相关表列 → 判断查询结构 → 写子查询 → 写最终 SQL"的思维过程拆分（§4，p.4）。

阅读者分析：失败分类是在训练集上、对单一模型做的人工标注，用来驱动模块设计合理，但不是独立的错误分布测量。

依据：§1、§3、§4 开头，Table 1、Figure 1，PDF pp.1–4。
