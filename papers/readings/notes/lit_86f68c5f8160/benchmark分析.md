# 评测与边界

**指标**（§5.4，pp.7–8）：EX 比较预测 SQL 与金标准 SQL 在数据库实例上的执行结果；EM 把每个子句当集合比较、不看取值；VES 衡量正确查询的执行效率，同时考虑正确性与执行时间。

**实验 1（Spider 隐藏测试集，Table 2，p.7）**：

| 方法 | EX | EM |
|---|---|---|
| DIN-SQL + GPT-4 | 85.3 | 60 |
| RESDSQL-3B + NatSQL（用 DB 内容） | 79.9 | 72 |
| DIN-SQL + CodeX Davinci | 78.2 | 57 |
| Graphix-3B + PICARD（用 DB 内容） | 77.6 | 74 |

EX 最高，但 EM 明显低于微调模型；作者解释为少样本方法不模仿测试集的书写风格（§1，p.2）。

**实验 2（BIRD，Table 3，p.9）**：测试集 DIN-SQL + GPT-4 的 EX 55.9、VES 59.44；GPT-4 基线 EX 54.89、VES 60.77。开发集 DIN-SQL EX 50.72、VES 58.79；GPT-4 基线 46.35、49.77。引言所说 VES 提升 9% 明确限于开发集（§1，p.2）；测试集上 DIN-SQL 的 VES 反而低于 GPT-4 基线 1.33（阅读者分析）。

**实验 3（Spider 开发集，Table 4，p.9）**：

| 方法 | 模型 | EX | EM |
|---|---|---|---|
| DIN-SQL | GPT-4 | 74.2 | 60.1 |
| DIN-SQL | CodeX Davinci | 69.9 | 57.2 |
| DIN-SQL | CodeX Cushman | 47.6 | 35.7 |
| 少样本 | GPT-4 | 67.4 | 54.3 |
| 少样本 | CodeX Davinci | 61.5 | 50.2 |
| 零样本 | GPT-4 | 64.9 | 40.4 |

按难度，GPT-4 下 DIN-SQL 的 extra 类 EX 为 43.4，少样本为 31.9。

**实验 4（消融，Table 5，p.10）**：见贡献栏；GPT-4 上 generic 自我修正有害。

**边界**：作者承认示例按类别手工固定；GPT-4 每题约 0.5 美元、60 秒（§7，p.10）。测试集成绩高于开发集，作者推测测试集较少依赖数据库内容、歧义较少，但无法验证（§5.5.2，p.8）。BIRD 结果使用了样本行和外部知识，与 Spider "不用 DB 内容"的条件不同。

依据：§5.4–5.6、§7，Tables 2–5，PDF pp.7–10。
