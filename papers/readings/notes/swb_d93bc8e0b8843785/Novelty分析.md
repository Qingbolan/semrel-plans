# 贡献与评价

作者陈述三项贡献（§1，PDF p.2）：

1. 一个包含“来访者—咨询师”和“同伴—同伴”对话的 MI 数据集，约 17K 个倾听者句子带 MITI 改编标签，并公开发布（脚注 3 指向 GitHub）。
2. 一个三阶段标注流程：两名标注者独立标注 → 高一致性标注者作为裁判解决分歧 → 删除表现最差标注者的标签后再由裁判裁决（§3.3、Figure 1，PDF pp.2、4–5）。
3. 咨询师与同伴回复的比较分析与改写建议（§5，PDF pp.5–8）。

阅读者分析：新意主要在“用临床行为编码比较同伴与专业回复”这一视角及其标注流程，而非方法创新。第三阶段删除“较差标注者”的标签再裁决，会提高覆盖率和一致性，但也把一致性提升部分建立在流程设计上；最终 kappa 0.5453 仍属中等（§4，PDF p.5）。比较只在两个来源各 1K 段对话上进行，没有显著性检验。

阅读者分析：数字存在小的不一致。§4 正文写最终 16,812 句，Table 3 为 16,811（97.39%）；Table 3 第一阶段 CC/RED 的一致句数（3,085/4,067）与 Table 2（CC 4,067、RED 3,085）位置互换，而 Table 2 的数值与百分比 41.11%=4,067/9,893 吻合（Tables 2–3，PDF p.6）（阅读者分析）。
