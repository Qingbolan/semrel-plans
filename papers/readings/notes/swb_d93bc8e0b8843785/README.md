# Welivita & Pu — Curating a Large-Scale Motivational Interviewing Dataset using Peer Support Forums

本文构建一个动机访谈（MI）对话数据集：从 CounselChat（专业咨询师回复）和自采的 Reddit 情绪困扰数据集 RED（同伴回复）中各随机取 1K 段对话，由 UpWork 招募的受训咨询从业者对 17,261 个倾听者句子按改编自 MITI 的 15 个标签做三阶段标注，最终覆盖约 97%（16,811/16,812 句），Fleiss' kappa 最终为 0.5453。随后比较咨询师与同伴回复的标签分布，给出用同伴数据训练治疗型聊天机器人时的改写建议。已阅读正文全部章节、Tables 1–5 与附录 A；附录混淆矩阵仅看图注，未逐格核对。
