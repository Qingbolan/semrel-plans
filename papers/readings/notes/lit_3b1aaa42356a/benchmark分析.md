# 评测与边界

**结论：本文没有基准评测。** 论文为 4 页 SIGMOD 演示论文，评估方式只有两个演示场景和一段在线演示视频（§1 脚注 1，p.2；§3，p.4）。

| 项 | 情况 |
|---|---|
| 基线 | 无。§1 只以论述方式对比 Text-to-SQL 方法、通用智能体框架和线性 ChatBI 系统 |
| 指标 | 无准确率、延迟、成本或用户研究指标 |
| 主结果 | 无数值结果；演示声称展示透明执行、自动优化（并行执行层）和人在回路可靠性 |
| 可复现性 | 文中未提供代码或数据链接，仅有演示视频链接 |

**阅读者分析的局限**：
- 三项挑战（异构鸿沟、上下文爆炸、不可靠低效）对应的设计都未经实验验证，例如上下文隔离是否减少幻觉、拓扑并行带来多少延迟收益，论文都没有测量。
- 校验器只做结构和类型层面的检查（无环、端口类型兼容、凭据存在），无法保证分析结论或生成 SQL 的语义正确性。
- “production-ready”“self-driving”等是作者自述，论文没有部署规模或用户数据支撑。
- 论文没有局限性章节。

若 atlas 需要该方向的定量证据，应转向作者引用的 DeepEye-SQL（文献 [1]）或其他带评测的数据智能体论文，而不能从本文抽取性能数字（阅读者分析）。
