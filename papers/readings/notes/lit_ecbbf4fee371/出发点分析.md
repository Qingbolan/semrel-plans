# 出发点

数据预处理（DP）把原始数据转成干净、可处理的格式。2021 年前的研究多只针对一两个任务（ED、DI、SM 或 EM），而这些任务性质不同，分别要求检测、修复、对齐，难以用通用方案统一（§1，PDF p.1）。

LLM 凭借自然语言生成、内部知识、推理和少样本/零样本适应能力，催生了通用 DP 方案；但现有 LLM 方案（Narayan et al. 2022 等）依赖 GPT API，引发数据泄露担忧（文中举 OpenAI 已确认的泄露事件）。同时，面向高度专业领域时，GPT-3.5 训练昂贵、GPT-4 参数冻结，难以定制（§1，PDF p.1）。

因此作者主张在本地、单张低价 GPU 上运行 7–13B 模型，通过构造 DP 指令数据进行指令微调，在保证数据安全的同时允许继续定制（§1，PDF pp.1–2）。他们还希望微调后模型的通用 NLP 能力基本不受损，以便泛化与二次定制（§1，PDF p.2）。

出发点的核心约束是“隐私与可本地部署”，因此本文的比较对象天然包括更大的闭源模型；结论应读作“小模型经指令微调可接近 GPT-4”，而不是“全面超过”（阅读者分析）

依据：§1，PDF pp.1–2。
