# novelty

论文声称三点贡献（§1，p.2）：(1) 把 last-mile forecasting 定义为介于基线生成与业务消费之间的独立系统问题；(2) 提出以动作为中心的 agent 框架，把情境推理转化为共享工作表上的受约束修订动作；(3) 用真实案例展示其提升精度并支持可控、可审计、迭代的修订。

组件：统一预测工作表（y 与 y_baseline 不可变，只能改 y_final）；工具取证（历史窗口检索、节假日查询、记忆查询、map-reduce 规划器）；长时域 map-reduce——主 agent 识别事件窗口，每个事件派一个只读局部推理器输出结构化修订，再统一经同一动作接口应用；事后反思把实际值与基线/修订比较后写入模式化的记忆库，供后续会话检索（不重训骨干）。实现基于 smolagents，代码执行型 agent。

阅读者评价：概念贡献（问题命名与"受约束修订+轨迹"接口）清楚，接近 judgmental adjustment 的计算化；技术上是常见 agent 组件（工具、map-reduce、反思记忆，参考 ExpeL）的组合。实证只有单条序列、单次运行的案例研究，不足以支撑一般性的精度结论；所用 LLM 名称未在文中给出，这影响可复现性。

依据：[arXiv:2606.02497v1，14 页](https://arxiv.org/abs/2606.02497)，§1–2、§4.1–4.6、§5.1，PDF pp.1–5；附录 B，pp.9–11。
