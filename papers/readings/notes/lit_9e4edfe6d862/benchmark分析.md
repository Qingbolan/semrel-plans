# benchmark

- **对比**：Prophet（含节假日信息拟合）、TimesFM（零样本，也是本框架的基线骨干）、本框架；同一预测起点、同一时域。§5.5 只报告本框架有/无记忆。
- **指标**：全时域与事件窗口上的 MAE、MAPE；另以修订日志做定性分析。
- **结果**：
  - 节假日（Table 3）：全程 MAE 342.45 / 530.25 / 119.17，MAPE 82.66% / 131.06% / 22.33%；春节窗口 MAE 507.28 / 857.28 / 101.59，MAPE 155.95% / 262.76% / 32.84%（Prophet / TimesFM / 本框架）。
  - 长时域（正文称 Table 5，实际表号为 Table 4，p.6）：全程 MAE 182.92 / 259.81 / 185.72，MAPE 27.3% / 38.1% / 18.91%；四个节假日窗口本框架均最低（如春节 MAE 508.63 / 742.70 / 89.28，清明 199.37 / 324.18 / 169.32）。四条修订记录分别用乘法（元旦 0.60、清明 0.65）与逐日覆写（春节、劳动节）。
  - 自我改进（Table 5）：W2 无记忆 MAE 172.03、有记忆 176.19（有记忆略差）；W3 无记忆 92.94、有记忆 60.10。记忆条目显示实际/基线比从 1.025 升至 1.181。
- **局限（原文 §7）**：重形式化与系统设计，缺少大规模实证；需要专门评测修订正确性、可解释性与用户效率的 last-mile 基准；目前只有结构化文本与日历情境；外部证据检索的可靠性取决于来源。
- **阅读者分析**：单条序列、单次运行、无方差估计；W2 记忆无益，W3 的改进只是一次观测。被比较的 Prophet/TimesFM 不接受同样的类比证据，提升主要来自"同期历史类比覆写"，没有与简单规则（如上年同期比例调整）对比。所用 LLM 未说明。

依据：[arXiv:2606.02497v1，14 页](https://arxiv.org/abs/2606.02497)，§5.3–5.5、§7、Tables 3–5、附录 C.2–C.3，PDF pp.5–7、12–14。
