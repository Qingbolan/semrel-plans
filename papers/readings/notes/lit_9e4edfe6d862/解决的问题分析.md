# problem

- **输入**：历史序列 X_{1:T}；骨干模型给出的基线 F_base = F(X_{1:T}) ∈ R^H；情境信息集合 C（用户指令、日历事件、检索到的历史类比、外部信号、专家反馈）。
- **过程**：在工作表状态 W_t = (X, F_base, F_t, E_t, A_t) 上做受约束的序列修订。每步从合法动作集合 A_valid(W_t) ⊆ A_tool ∪ A_revise ∪ {stop} 中选一个：工具动作只更新证据 E_t；修订动作通过有限算子（初始化、区间乘/加/截断、指定日期覆写、合并修订列表）修改 F_t。合法性约束：历史观测与基线不可改，修订必须在预测时域内，重复或冲突修订可被拒绝。
- **输出**：二元组 (F_final, A)——最终预测加完整动作轨迹，在 stop 或步数预算 t* 时终止。
- **工作单位**：一次"预测会话"＝一个预测起点 + 一个时域；实现中工作表是含 ds、y、y_baseline、y_final 四列的 dataframe。

阅读者分析：这是"带不变量的表格编辑"问题，修订的正确性没有单独的标注或指标，评价只用事后 MAE/MAPE。

依据：[arXiv:2606.02497v1，14 页](https://arxiv.org/abs/2606.02497)，§3 式(1)–(6)、§4.2–4.3、Tables 1–2，PDF pp.2–4。
