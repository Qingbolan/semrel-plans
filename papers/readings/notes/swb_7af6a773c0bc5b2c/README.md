# Thompson et al. — Enriching a biomedical event corpus with meta-knowledge annotation

本文为 GENIA 事件语料（1,000 篇 MEDLINE 摘要、36,858 个事件）增加事件级元知识标注。每个事件标注五个维度：Knowledge Type、Certainty Level、Polarity、Manner、Source，并标出作为判断依据的线索词；由此还能推导出 New Knowledge 和 Hypothesis 两个超维度。在 104 篇双人标注的摘要上，各维度的 Kappa 为 0.84–0.93。本文没有训练自动系统。全文来自 PMC 开放获取 XML，因此用章节和表号定位，没有页码。
