# novelty

原文声称的贡献（§1.1、§6，PDF pp.4、42–43）：
1. 当时论证挖掘领域最大的标注语料之一，覆盖 4 种体裁、6 个教育话题；
2. 以论证理论为依据选择并改造模型，并做了详细的可靠性研究；
3. 在 token 级标注上使用 Krippendorff unitized αU，并说明了跨多篇文档时的计算方式：把整个语料拼成一个连续体，并对 100 次随机拼接取平均（脚注 19，PDF p.22）；
4. 公开标注指南、数据、代码和系统输出。

阅读者分析（诚实评估）：
- 方法上的新意主要在语料和标注方法，自动模型是 SVMhmm 加大量手工特征，属于当时的常规做法。
- 标注只标成分、不标成分之间的关系，作者也承认这是相对于“论证解析”类工作的局限（脚注 30，PDF p.33）。
- 一致性高度依赖体裁：评论 + 论坛帖的联合 αU 为 0.60，文章 + 博客只有 0.09（Table 4）；作者最终只推荐在短文档上使用 Toulmin 方案（PDF p.43）。因此“跨体裁”主要体现在原始语料覆盖上，可靠标注实际集中在短文本。
- 原文规模表述不一致：摘要写 90k tokens，Table 3 合计 84,673 tokens（PDF pp.1、21）；§4.3 写 Fleiss’ κ=0.59，§4.5 写 Fleiss’ π=0.59（PDF pp.15、32）。

依据：[Computational Linguistics 43(1):125–179, 2017（ACL Anthology J17-1004），55 页](https://aclanthology.org/J17-1004)。
