# problem

本文包含两个标注研究和一个主要的自动识别任务。

**研究 1：说服性文档判定**（§4.3，PDF pp.15–16）
- 输入：评论或论坛帖，以及对应的争议话题。
- 输出：二值标签，切题且有说服意图（on-topic persuasive）或非说服性（包括离题、讲故事、提问等）。
- 自动分类只在脚注中报告：SVM + n-gram 的 Macro-F1 为 0.69（脚注 28，PDF p.32）。

**研究 2：论证微结构标注**（§4.4，PDF pp.17–22）
- 模型：改造的 Toulmin 模型，成分为 claim、premise、backing、rebuttal、refutation；去掉 qualifier 与 warrant（数据中几乎不出现），新增 refutation（反驳 rebuttal），允许隐含 claim（PDF p.18）。另有 pathos 维度（诉诸情感）。
- 标注单位：默认整句，句中有多个成分或断句出错时改用 token 级；成分之间不标显式关系。

**自动任务：论证成分识别**（§5.1，PDF pp.33–35）
- 输入：文档的句子序列；输出：每句一个 BIO 标签（11 类：O 加 5 种成分的 B/I）。
- 评测在 token 级进行：句子级预测被展开到 token 后与金标准比较。
- 简化假设：每篇文档只含一个论证（只有 4% 文档同时包含正反两方论证）；只做 logos 维度；一句含多个成分时取最长成分。

依据：[Computational Linguistics 43(1):125–179, 2017（ACL Anthology J17-1004），55 页](https://aclanthology.org/J17-1004)。
