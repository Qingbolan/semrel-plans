# usecase

原文中的具体用例：范围 3 排放趋势。抽取结果显示总范围 3 排放中位数在 2014–2020 年基本持平，之后到 2023 年增加约 5.6 倍（Fig.5c Δ +504.2%）。作者进一步按 GHG Protocol 的 15 个范围 3 类别分别查看，各类别本身无明显上升（Fig.6），但公司报告的类别数大幅增加（补充 Fig.S21），回归也显示总量上升部分由报告类别数增加驱动（补充 Table S4）。结论：该增幅主要反映披露扩大，而非真实排放上升，政策制定者应谨慎解读范围 3 数据。

另一个用例是透明度差距：2023 年 MSCI ESG 评级前 10% 的公司平均披露 186.5 个指标，后 10% 为 174.7（差 6.8%）；2014 年为 144.7 对 103.8（差 39.4%）。摘要中的"22%"来自 Table 1 Panel B 模型（1）的拟合值比较，不是 2023 年的原始均值差。

阅读者分析：这个用例说明"抽取到的值"与"披露覆盖度"必须一起分析，否则聚合查询（如中位数趋势）会把覆盖率变化误读为实质变化；这对语义抽取后再做 SQL 聚合的流水线是一个重要警示。

依据：[Nature Communications 17:5940，17 页](https://www.nature.com/articles/s41467-026-75160-z)，Results，PDF pp.3–4、Fig.5–6（pp.8–9）、Table 1（p.7）。
