# problem

| 项 | 内容 |
|---|---|
| 输入 | 每个"公司–年"的年报与可持续发展报告 PDF（拼接为一个文档 d），以及 501 个 ESRS 定量指标的描述 q（子主题+ESRS 描述） |
| 输出 | 每个（公司–年, 指标）一个 JSON：数值与单位，若未披露则弃答；后处理统一单位与币种（USD）后写入 CSV |
| 工作单元 | 一次 LLM 调用 = 一个公司–年 × 一个指标；共 N_trans = 2,880,249 次，其中 N_perf = 847,835 次返回数值（约 29%） |
| 下游分析 | 透明度分 = 已披露指标数 / 501；绩效 = 披露值的年度分位数趋势 |

原文强调未抽取到值不等于未披露：可能因非实质性（non-material）而不披露，也可能是抽取失败（报告含糊）。

阅读者分析：2,880,249 恰为 5,749（Fig.1b 中拼接后的公司–年报告数）× 501，说明对每个公司–年都对全部 501 个指标发问，属于"文档 × 属性"的笛卡尔积抽取，而不是先判断相关性再抽取。

依据：[Nature Communications 17:5940，17 页](https://www.nature.com/articles/s41467-026-75160-z)，Results "ML framework overview"、Fig.1，PDF pp.2–3；Methods Step 1–5，PDF pp.13–14；Limitations，PDF p.12。
