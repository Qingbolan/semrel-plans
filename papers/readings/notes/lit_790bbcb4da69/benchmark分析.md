# 评测与边界

**实验 1（BIRD 排行榜，Table 2，PDF p.9）**：基线结果全部取自排行榜。

| 方法 | 开发集 EX | 测试集 EX | 测试集 R-VES |
|---|---|---|---|
| MCS-SQL + GPT-4 | 63.36 | 65.45 | 61.23 |
| CHESS | 65.00 | 66.69 | 62.77 |
| Distillery + GPT-4o（微调） | 67.21 | 71.83 | 67.41 |
| OpenSearch-SQL + GPT-4o，不用自一致性 | 67.80 | — | — |
| OpenSearch-SQL + GPT-4o | 69.30 | 72.28 | 69.36 |

Figure 3 显示，自一致性与投票对难题的提升最大，绝对差为 7.64%；对简单和中等题目没有明显差异（p.9）。

**实验 2（Spider 测试集，Table 3，p.10）**：本文为 87.1（GPT-4o）和 86.8（GPT-4）；DAIL-SQL 为 86.6；MCS-SQL 和 CHESS 的论文自报值分别为 89.6\* 和 87.2\*。

**实验 3（Mini-Dev 消融，Table 4，p.11）**：EX_G 为生成阶段单条 SQL 的准确率，EX 为全部流程后的最终准确率。

| 配置 | EX_G | 最终 EX |
|---|---|---|
| 完整管线 | 65.8 | 70.6 |
| 去掉抽取 | 61.6 | 67.4 |
| 去掉值检索 | 64.4 | 69.2 |
| 去掉列过滤 | 63.2 | 68.6 |
| 去掉 Info Alignment | 62.8 | 68.6 |
| 去掉少样本 | 60.4 | 66.0 |
| 去掉 CoT | 63.0 | 69.2 |
| 去掉对齐 | 65.8 | 69.6 |
| 去掉精修 | 65.8 | 67.0 |
| 去掉自一致性与投票 | 65.8 | 68.2 |

**实验 4（少样本与 CoT，Tables 5、7，pp.11–12）**：在生成阶段，Query-CoT-SQL 比 Query-SQL 高 2.8（EX_G 65.8 对 63.0）。不用少样本时，结构化 CoT 的 EX_V 为 65.0，非结构化 CoT 为 63.0，不用 CoT 为 59.2。

**成本（Table 6，p.12）**：每个问题耗时 7–60 秒，消耗 9,000–25,000 token。

边界（阅读者分析）：

- 正文与表格有多处不一致：正文说 CoT 少样本比 Query-SQL "高 3.0%"、比无少样本"高 6.4%"，Table 5 算出来分别是 2.8 和 6.2；Table 4 与 Table 5 中"无少样本"的 EX_G 分别为 60.4 和 59.6；摘要中 R-VES 为 69.36%，正文 p.2 写成 69.3%。
- "Main Result"一段把 Table 2 和 Table 3 的内容对调描述了（p.9）。
- 消融只在 Mini-Dev 上做，没有报告方差。
- 文中没有独立的局限章节，§3.8 只提到提示和列值选择还未细调，以及 SFT 方向的潜力。
