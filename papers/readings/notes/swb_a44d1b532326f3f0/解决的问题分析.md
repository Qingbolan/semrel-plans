# 解决的问题

要解决的是"如何程序化地访问并浏览一个结构复杂的词汇语义资源"。输入是 FrameNet 1.7 数据发行（解压后 855 MB，数千个 XML 文件，§4.1，p.2）和用户的查找请求（名称正则、ID、框架过滤等）；输出是 Python 对象（AttrDict）及其可读文本展示（§4.3，p.4）。

工作单位是数据库对象：框架、词汇单元（LU，lemma 加词性后缀如 `revenge.n`）、框架元素（FE）、框架关系、语义类型、标注集和句子（§3、§4.2–4.5，pp.2–5）。

主要访问方法（§4.2、§4.5，pp.3–5）：`frames`、`frame`、`lus`、`lu`、`fes` 查词汇；`frame_relations`、`fe_relations`、`semtypes`、`propagate_semtypes` 做高级访问；`annotations`、`exemplars`、`ft_sents`、`sents`、`doc`、`docs` 取语料标注。

阅读者分析：这里没有预测任务或学习问题；"问题"是软件接口设计，不提供标注语料划分或评测指标。

依据：[EMNLP 2017 Demo，D17-2001，6 页](https://aclanthology.org/D17-2001.pdf)，§3–4，PDF pp.2–5。
