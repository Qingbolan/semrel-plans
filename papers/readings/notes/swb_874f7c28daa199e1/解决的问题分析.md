# 解决的问题

**输入**：一句英语句子（标注时不看上下文）。**输出**：该句的 AMR，即有根、有向、边带标签、叶子带标签的图（§2，p.2；§3 共指段，p.3）。

**等价写法**：逻辑三元组合取、PENMAN 文本记法（人读写用）、图（程序处理用）。例如 “The boy wants to go” 写作 `(w / want-01 :arg0 (b / boy) :arg1 (g / go-01 :arg0 b))`，变量 b 的复用表示男孩同时是 want 和 go 的施事（Figure 1，p.2）。

**基本原则（§1，pp.1–2）**：
- 易读、易遍历的有根图；
- 尽量抽象掉句法差异，意义相同的句子给同一个 AMR；
- 大量使用 PropBank 框架集（如 “bond investor” 用 `invest-01`）；
- 不规定字符串与意义之间的推导或对齐；
- 明显偏向英语，不是中间语（interlingua）。

**表示内容（§3，pp.2–6）**：概念为英语词、PropBank 框架集或特殊关键词；约 100 种关系（核心论元 :arg0–:arg5、一般语义关系、数量、日期、列表）及其逆关系与具体化（reification）；处理否定 :polarity、情态、疑问 `amr-unknown`、约 80 类命名实体、系词 :domain 等。

阅读者分析：工作单位是“句子 → 图”，评测单位是图之间三元组的重合，不涉及跨句文档结构。

依据：§1–§3，PDF pp.1–6。
