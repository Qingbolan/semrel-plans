# 解决的问题

**输入**：某任务族训练实例上 ReAct 智能体的轨迹（每个训练实例一条），只保留最终答案正确的轨迹 T+。正确性只在轨迹层面判断，中间步骤不单独验证。

**输出**：子程序库 L，最多 K 个（默认 K=5）。每个子程序 = 名称 + 任务族共享的固定输入输出签名 + 自然语言规格。

**归纳流程**：（1）按标签过滤出正确轨迹；（2）抽取每步 ReAct 的思考与动作；（3）一次 LLM 调用为每项打上推理动作标签，若超过 10 个则再合并为 5–10 个规范类别；（4）按频次排序，对支持数至少 m=3 的类别取前五条示例，让 LLM 生成子程序名和规格，直到达到 K 或没有类别满足 m。

**执行**：测试时，用 L 加上 FINISH 替换原动作集，模型参数和 ReAct 循环不变。智能体只看名称、参数模式和简短描述，自己决定调用哪个、传什么 focus；实例输入自动绑定。另一个 LLM 调用按完整规格执行，看不到智能体的交互历史，结果作为观察返回。

依据：[arXiv:2606.02994v2，27 页](https://arxiv.org/pdf/2606.02994)，§3.1–3.3、附录 C，PDF pp.4–5、16–17。
