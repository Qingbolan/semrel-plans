# 贡献与评价

**论文自述贡献**（§1，p.2）：

1. 比较截断、检索和结构化文档处理等基于 LLM 的结构化文档问答方法；
2. 发布带问题类别标签的数据集及模型回答；
3. 提出 PDFTriage 提示方法，提升 LLM 回答结构化文档问题的能力。

**阅读者评价**：

- 方法本质是“结构元数据 + 函数调用式检索”，与 ReAct、Toolformer 等工具调用思路一致，作者也说可改用 ReAct 式组织（§3.2）。新意在于把文档结构（页、章节、表、图）暴露成可调用的检索单元，而不是新的模型或训练方法。（阅读者分析）
- 正文列出的贡献 1 提到“截断”，但实验只有按页检索和按块检索两个基线，没有截断基线。（阅读者分析）
- 数据规模的表述前后不一：摘要写“80 篇文档上 900 多个问题”，§1 写“约 900 个问题、90 多篇文档”，§4 与 Table 1 为 908 个问题、82 篇文档。以 Table 1 为准。（阅读者分析）
- §1 预告 §7 会描述局限，但 §7 只有未来工作与结论，没有局限讨论；附录 B.2 称“GPT-4 评测”，而同节写明用的是 gpt-3.5-turbo。（阅读者分析）
- 论文写“代码和数据集即将在 GitHub 发布”，未给出地址（Abstract、§5）。

依据：Abstract、§1、§3.2、§4、§5、§7，Table 1，PDF pp.1–6；附录 B.2，p.14。
