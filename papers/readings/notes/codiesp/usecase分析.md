# 具体用例

编码辅助场景：系统为一篇病例提出候选诊断/操作代码，编码人员定位到支持文本后复核。例如仅预测到疼痛代码与同时定位完整疼痛短语，是 D 与 X 的不同输出要求。本项目按代码筛选病例、汇总病种或检查证据缺失，属于基于数据的派生查询；论文没有提供这些 SQL 或查询执行成本实验（阅读者分析）。使用公开病例模拟医院文书是作者的资源策略，不能据此推断已在多医院真实病历上验证。

依据：[CLEF eHealth 2020，CEUR Vol.2696 paper_263，29 页](https://ceur-ws.org/Vol-2696/paper_263.pdf)，Table 1、§2.1、§6，PDF pp.4–5、18–20。
