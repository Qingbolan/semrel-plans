# 解决的问题

论文要解决的是"评测资源不具代表性"问题，而非提出新的共指算法。

- **任务定义**：事件被建模为四个组件——动作、时间、地点、参与者（人类/非人类）。两个动作提及共指，当且仅当它们指同一实例：同一时间、同一地点、同一参与者（§1 Table 1、§4.2，PDF pp.1、5）。
- **诊断输入/输出**：输入 ECB 0.1（Lee et al. 2012 重标注版本）的事件动作提及；输出按词元匹配生成的共指链，用 MUC、B3、CEAFm、BLANC、CoNLL F1 评估（§3.1，PDF p.2）。
- **资源产出**：为每个 ECB topic 补充同事件类型的另一实例的新闻（如 topic 1 从 Tara Reid 2008 年进戒毒所扩展到 Lindsay Lohan 2013 年），并对新旧两部分统一标注动作类别、实体类型、时间以及文档内与跨文档共指（§4.1–4.4，PDF pp.3–6）。
- **工作单位**：提及（mention）为标注单位；共指链为评测单位；跨文档共指在每个 topic 内建立（含 ECB 与 ECB+ 两部分文本）。

依据：§1、§3.1、§4.1–4.4，PDF pp.1–6。
