# 贡献与评价

**论文声称的贡献**（§1，p.1）：

1. **动作抽象压倒架构**：原始动作空间相对高层 API 损失 47.1 点，比额外智能体的效应大一个数量级，且原始动作版本净效果低于"什么都不做"。
2. **反思提升准确率，分解改变失败形态**：Reflection +4.5（p=0.013），Manager +1.4（p=0.68）；但 Manager 把静默错误从 33% 降到 25%（p=0.010），在公式和录入任务上有帮助，在数据透视表上有害。反思器必须判断"刚执行的这一步"而非整个子任务。
3. **能力饱和**：GPT-5 与 GPT-5-mini 无显著差异且共享 83 个失败任务；GPT-3.5 失败方式不同。

**评价**：系统组件本身（三智能体、A/B/C 判定）多来自 Mobile-Agent 等已有工作（§2，p.2）；新意在于受控消融设计与配对 McNemar 检验，而不是新系统。作者也说明 Table 1 的跨系统比较因执行后端不同只是"定位"而非排名（§5，p.3）。

阅读者分析：结论"动作接口决定准确率"对语义算子系统有直接启示——算子的粒度/抽象层级可能比编排智能体数量更重要；但该结论只在 SCB-221 这类单工作簿操作任务上被验证（阅读者分析）。

依据：§1–§5，pp.1–4。
