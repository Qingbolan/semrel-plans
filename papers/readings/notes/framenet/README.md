# The Berkeley FrameNet Project

这篇早期 FrameNet 论文介绍语料驱动的框架语义词典、人工标注流程和工具。它是资源建设与架构说明，不是现代 FrameNet 发布版的规模报告，也不包含语义角色模型排行榜。写作时实际完成：近 10,000 句标注、不到 200 个 lemma。
