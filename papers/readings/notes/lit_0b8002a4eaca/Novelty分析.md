# 贡献与评价

**原文声明的贡献**（§1）：

1. 第一个能从给定规则集合中自动选择有效规则来改写 SQL 的 LLM 增强改写系统。
2. 构建高质量示例池：Stage-1 用零样本 LLM-R2 与基线改写训练查询，实际执行后保留有改进的结果；Stage-2 用随机、查询树编辑距离、Sentence-Transformer 三种启发式选示例，再改写一次，收集改写元组（§4.1–4.2）。
3. 对比式查询表示模型：对查询树每个节点编码算子类型（one-hot）、算子条件（Sentence-Transformer 文本编码）、基数与代价（MLP），再用 QueryFormer 的树偏置注意力汇总；按 SimCSE 风格损失训练，正例为带来改进的示例查询，难负例为带来退化的示例查询（§5.1、式 3）。
4. 课程学习：每轮从未访问数据中选模型置信度最高的子集加入训练，共 4 轮（Algorithm 1、式 4、§6.1.5）。
5. 跨数据集与数据规模的鲁棒性分析（§6.4）。

**阅读者评价**：把 LLM 限定为“规则选择器”是务实的设计，复用了工具调用思路；新意主要在示例选择模型。代价是示例池和训练三元组都依赖实际执行查询，作者自己也承认数据稀缺（§5.1–5.2）。消融显示示例选择方式的影响比较大（Table 8），但提示内容变化同样敏感且“没有明显规律”（§6.5.3），说明结果对提示工程依赖较强。

依据：[PVLDB 18(1) 53–65](https://www.vldb.org/pvldb/vol18/p53-yuan.pdf)，§1、§4–5、§6.5，PDF pp.1–2、5–8、10–11。
