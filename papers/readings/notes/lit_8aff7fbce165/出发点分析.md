# 出发点

本体匹配（OM）是数据互操作和知识共享的基础，与知识图谱对齐、数据库模式匹配有很多相似之处（§1，PDF p.2）。近期效果好的 OM 系统往往需要大量领域训练数据来微调；LLM 方法则可以直接利用预训练知识，无需微调（§1.1，p.3）。

如果对所有实体对都询问 LLM，复杂度为 O(n²)。因此主流 LLM 方法采用"先检索再提示"：先为每个实体检索 k 个候选，再让 LLM 判断，复杂度降为 O(n·k)。作者指出这一做法仍有两个问题（§1.1–2，pp.3–4）：

- 效果不够好：候选召回可接近 100%，但经 LLM 提示后效果可能下降多达 30%，在生物医学领域甚至达 50%；
- 运行太慢：对大型本体逐个询问 LLM 仍然耗时很长。

已有文献建议先用快速、高精度的匹配器处理简单情况，只把复杂或模糊的情况交给 LLM（§2，p.4）。MILA 就是对这一思路的具体实现。

依据：[arXiv:2501.11441v2，25 页](https://arxiv.org/pdf/2501.11441v2)，§1–2，PDF pp.2–4。
