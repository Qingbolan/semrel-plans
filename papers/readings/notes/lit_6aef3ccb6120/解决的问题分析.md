# 解决的问题

**形式化**：给定含 NaN 的表 T，寻找公式 f，使每个缺失位置的填补值 x=f(T) 近似真值 x_g（§3.1，Eq. 1，p.4）。

**输入**（Algorithm 1，p.6）：脏表 T、用户提供的 Meta-Sketch、待填补列 V。

**输出**：填补后的数据 D′，以及可供人工审阅的 Python 函数 F。

**流程**：

1. 从 T 中随机抽 k 行干净数据 C，并在 V 列随机遮蔽 λ 行得到 C_m；同时把 T 切成若干块。
2. Domain-Sketch 生成器按 Meta-Sketch 的七步（找缺失值、找相关列、起草方案、算中间变量、找示例行、用示例行验证、构造方案）生成具体草图 S；代码生成器把 S 转为代码 P。
3. 执行 P 填补 C_m；Evaluator 用 CloseMatch（|C′_m−C|<ε）判定是否与真值一致。
4. 不一致则 Reflector 诊断（如行索引错、公式假设错）并生成新草图，最多重试 3 次；仍失败则返回“无法填补”。
5. 一致则 Summarizer 把 P 泛化为函数 F，Executor 在各数据块上执行（§3.2–3.6，pp.5–7）。

**处理单元**：一个待填补的列（变量）；同一列的公式学到后应用于全部缺失位置。

该方法假设表中存在足够的完整行可供抽样验证，且同一列所有缺失值遵循同一公式（阅读者分析）

依据：§3、Algorithm 1、Fig. 3，PDF pp.4–7。
