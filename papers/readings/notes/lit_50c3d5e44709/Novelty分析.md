# novelty

原文贡献（§1，PDF p.2）：(i) 形式化任务框定并分离出两个核心变量（预测目标、评测目标）；(ii) 发布两个独立分析的诊断套件（51 DSBench + 61 MLE-bench 配对任务），由受控的提示–数据干预构造，经人工与跨模型族 LLM 核验；(iii) 量化五个前沿智能体的误框定与“问/做”校准失调。

构造上的关键设计：
- 目标歧义的诱饵列（§4.1，PDF p.4）：用与真实目标弱相关的约 70% 特征（数量夹在 [4,40]）构造打分向量，按其排序把真实目标值重新分配，使诱饵与真实目标边际分布完全一致但由不同特征驱动；再注入噪声并二分搜索噪声水平，使 3 折 HistGradientBoosting 对两列的可预测性接近（51 个中 29 个差距 ≤0.02，40 个 ≤0.05，44 个 ≤0.10）。真实列为 val_1 的 31 个、val_2 的 20 个。
- 评测器保持不变，因此分数变化可归因于框定歧义而非评分规则变化（§4，PDF p.4）。
- 澄清 oracle 作为因果探针而非用户模拟，作者明确其为可恢复性能的上界（§4.4，PDF p.5）。

阅读者分析：新意在问题设定和受控构造方法上，而非新智能体方法。构造和 oracle 均依赖 Claude 系模型（Opus 4.7 改写/核验，Haiku 4.6 回答），作者做了非 Claude 核验、换 GPT-5.4 oracle 与换判官的稳健性检查，但仍承认无法完全排除模型族效应（§6）。

依据：[arXiv:2605.09698v1，32 页](https://arxiv.org/abs/2605.09698)，§1、§4、§6，PDF pp.2、4–5、9。
