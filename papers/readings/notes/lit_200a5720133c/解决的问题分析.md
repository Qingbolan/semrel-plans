# 解决的问题

**形式化定义**（§3.1）：给定关系数据库 D = {T1,…,TN}（每表含若干列）与自然语言查询 q，生成分析报告 R，要求满足：

- **Completeness**：覆盖回答 q 所需的全部信息，不遗漏关键数据；
- **Correctness**：准确反映 q 的意图，无错误或语义偏离；
- **Conciseness**：不含冗余或无关信息。

**输入/输出与工作单位**：

| 项 | 内容 |
|---|---|
| 输入 | 一个分析型自然语言问题 + 数据库 schema 与内容 |
| 中间产物 | 子问题集 {q_i}、检索得到的表/列/单元格、初始与改写后的 SQL {SQL_i'} 及执行结果 {R_i} |
| 输出 | 一篇自然语言分析报告（含趋势、洞见、结论，见 Figure 3） |
| 评测单位 | 每个问题一份报告；检索按表、列两级算 P/R/F1 |

作者明确区分本任务与 TableQA / Text-to-SQL：后两者返回特定值集合，不做分析与综合（§3.1）。

阅读者分析：问题定义中的三条标准没有对应可执行的判定规则；实验中 completeness 与 conciseness 并未单独度量，而是由 Accuracy（对照模板生成的参考报告）与 Report Relevance（RAGAS 式反向生成问题的相似度）近似。

依据：[arXiv:2503.13269v2](https://arxiv.org/abs/2503.13269)，§3.1，PDF p.3；§6.1.3，pp.9–10。
