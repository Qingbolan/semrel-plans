**DA-Dataset**（§5、§6.1.2）：

| 项 | 内容 |
|---|---|
| 总量 | 正文写共 735 条：201 条来自 HangSeng 金融 Text-to-SQL 数据集（DA-CCKS），535 条来自 BIRD（DA-BIRD）。201+535=736，与 735 不一致，原文未解释（阅读者分析） |
| 复杂度 | 每题平均需检索 4.5 张表、10.8 列 |
| 领域 | DA-CCKS 以金融分析为主（资产评估、风险管理等）；DA-BIRD 覆盖 BIRD 的多领域数据库（Figure 2 示例为苏格兰足球比赛数据） |
| 划分 | 未给出训练/验证/测试划分；LoRA 训练数据来源亦未说明 |

**构建流程**（Figure 2）：

1. **问题合成**：从两个源数据集抽取全部 question-SQL 对，随机取 10 对输入 GPT-4o，让其组合成一个分析型问题；所有输出人工审核，不合格者修改或替换。
2. **报告合成**：GPT-4o 先做语义增强（结合 schema 改写问题）→ 交叉编码器检索相关表列 → GPT-4o 生成候选 SQL → 自动执行保留有效结果，并人工核查语义 → 执行结果按问题类型与 SQL 结果结构填入固定句式模板，生成参考报告。

阅读者分析：参考报告是"模板化文本+SQL 执行结果"，因此它衡量的是能否取回与参考 SQL 相似的数据，而非开放式分析的多种合理路径；题目由 10 个已有 Text-to-SQL 问题拼合，分析深度受原问题集限制。

依据：[arXiv:2503.13269v2](https://arxiv.org/abs/2503.13269)，§5.1–5.2、Figure 2–3，PDF pp.7–9；§6.1.2，p.9。
