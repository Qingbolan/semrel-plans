# 贡献与评价

**论文自述**（Introduction，pp.1–2）：

| 贡献 | 内容 |
|---|---|
| 基准 | BLM-Guard Benchmark：真实短视频广告，7 个风险场景及细粒度违规类型，三级标签 |
| 冷启动 | 规则驱动的 ICoT 数据合成 + 规则锚定 SFT：答案交叉熵加上让 `<think>` 分布靠近规则关键词先验的 KL 项（p.4） |
| 强化学习 | 自适应 GRPO：r = r_rule + r_format + r_scaR；token 级归一化、退火裁剪系数、跳过零方差组的动态采样（pp.4–5） |
| 多任务 | 建模模态内操纵与跨模态不一致以提升鲁棒性 |

SCA-R 的做法是：裁判模型读取 `<think>`、真实标签和审核准则，动态生成带权重的评分原则（如因果清晰度、风险归因），每条原则给 {0, 0.5, 1} 分后加权（p.5）。

**评价**：消融（Table 2，p.7）显示逐步叠加 Rule-SFT、Rule-RL、SCA-R 都有提升，最后一步 SCA-R 让严格准确率从 0.801 升到 0.914，是最大的单步增益。

阅读者分析：
- “多任务架构”在方法部分没有对应的结构或损失描述，无法核实其具体形式。
- 基准被称为“release”，但正文没有给出视频数量、类别分布、训练/测试划分或下载地址；消融中出现 13k 和 5k 两种 SFT 规模，是唯一的数据量线索。
- 评估“一致性”的 GPT-4o 裁判与训练奖励中的裁判模型可能偏好相同，存在用同类裁判训练又评测的风险；原文未说明 RL 裁判的具体模型。

依据：Introduction、Methodology、Ablation Study，PDF pp.1–7。
