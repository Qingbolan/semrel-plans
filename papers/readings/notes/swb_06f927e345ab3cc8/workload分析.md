# 工作负载

**BLM-Guard Benchmark**（Task Formulation 与 Data Construction，p.2；Figure 1，p.2）：

- 来源：某短视频平台上的 5–45 秒商业广告，覆盖电商、健康、教育、生活方式等领域。
- 三类样本：专业审核员已核实风险类型的广告；规则审核系统标记的广告；高曝光、低投诉的合规广告（用于提升泛化）。
- 标签：一级严重度（高 / 中 / 低）；二级场景，共 7 个核心违规场景（如违法内容、虚假营销、误导操作）；三级违规类型（如收入夸大、隐私泄露、封建迷信）；另设“无风险”类别。
- 部分样本附带结构化推理链，用于 SFT 和奖励学习。

**规模与划分**：正文没有给出视频总数、各类别数量、训练/测试划分比例，也没有说明测试集是否与训练数据去重。唯一的规模线索是消融中的 Full-SFT（13k）与 Part-SFT（5k），以及 Rule-SFT（5k）（Table 2，p.7）。

**RL 数据构造**（p.4）：对 SFT 集合用高温采样 4 次，收集持续答错的困难样本；再把语义相关的提示或风险 ASR 片段拼接，提高风险密度。

**外部泛化集**（Datasets，p.6）：LSPD（色情）、XD-Violence、UCF-Crime（暴力/异常）、FakeSV、FVC（虚假信息）；未见政策领域的评估遵循 SafeWatch 协议。这些数据集上的结果只以 Figure 3 热图呈现，正文没有数值表。

阅读者分析：由于缺少规模与划分信息，外部读者无法判断主结果的统计稳定性，也无法据此复现基准。

依据：Task Formulation、Data Construction、Methodology、Experiments，PDF pp.2、4、6–7；Figure 1，p.2。
