# 贡献与评价

论文声明（pp.3）：(1) 首个面向 LLM 表抽取的预算感知优化框架；(2) 分块索引与 LLM 生成参考句的查询增强；(3) 以包含概率与抽取概率估计每个策略质量；(4) 跨策略分配预算的 DP 算法；(5) 4 个真实数据集的基准，20 名研究生约 1,000 小时标注。

与相关工作对比（§8，p.12）：FrugalGPT 对所有任务采用同一策略顺序，论文认为因此只得局部最优；LOTUS 与 Palimpzest 依赖 LLM 处理整篇文档，成本高；Evaporate 的代码生成对复杂文档不够准确。

阅读者分析：
- 新意在于把“单元格级策略选择 + 质量估计 + 预算约束”合成一个优化问题；DP 本身是标准背包解法。
- 质量估计依赖两个假设：抽取概率在含属性输入间稳定（Fig.9 用 5 个聚类、每数据集 3 个属性做了支持性检验），以及 DistilBERT 包含概率足够准（Fig.7 与 GPT-4o 比较）。这些检验规模较小。
- 预算以 token 计，DP 的状态维度包含预算 b∈[0,B]；在百万级 token 预算下的求解开销正文未给出数值（时间复杂度分析在 §6，没有实测求解时间）。

依据：[PVLDB 18(11)，13 页](https://www.vldb.org/pvldb/vol18/p3695-chai.pdf)，§1、§6–§8，pp.3、8、11–12。
