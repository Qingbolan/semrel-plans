# 解决的问题

形式化（§2，pp.3–4）：给定文档集合 D={d1..dn}、属性集合 A={a1..am} 与 token 预算 B，输出 n 行 m 列的表 T，第 i 行由 d_i 抽取。每个单元 r_ij 有候选策略集合 S_ij={OpenIE(d_i), Codegen(d_i), PLM(d_i), LLM(t1), LLM(t2), …}，其中 LLM 策略的输入 t 是检索块的不同组合。目标是选映射 f，使期望准确率 Σ P(v_ij = v*_ij) 最大，且所选 LLM 策略输入 token 之和不超过 B（Eq.4）。非 LLM 策略视为零成本；输出 token 因很少而忽略。

- 处理单位：（文档，属性）单元格；选择在单元格粒度进行，因此同一属性在不同文档上可以用不同策略。
- 质量估计（§5）：P = 包含概率 P(a∈t) × 抽取概率 P(v=v*|a∈t)，并处理真值为 NULL 的情形（Eq.8）。包含概率由在验证集上微调、并经块组合/句子重排/随机删句增强的 DistilBERT 预测；抽取概率按属性和策略在验证集上统计（假定对含属性的不同输入稳定）。
- 检索（§3.1、§4）：SemanticChunker 切块、E5 编码、PQ 索引；参考句来自验证集（k-means 去冗余）与 LLM 生成（按与文档集合的相关度选 top-k），拼接为查询向量；检索阈值 τ 由验证集自动设定。
- 求解（§6）：问题被证明为 NP-hard（证明在技术报告），映射为分组背包，用经典 DP 求解。

阅读者分析：假设每个文档每个属性只有单值、行与文档一一对应；这排除了一份文档产生多行或多值属性的情形，论文结论段也承认这一点。

依据：[PVLDB 18(11)，13 页](https://www.vldb.org/pvldb/vol18/p3695-chai.pdf)，§2–§6，pp.3–8。
