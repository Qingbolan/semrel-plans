# 出发点

英文已有大量 LLM 基准，且很快被刷满（例如 GPT-4.1 在 MMLU 上超过 90%），新基准越来越关注多步推理。相比之下，评测阿拉伯语 LLM 生成能力的基准很少，不少还是从英文翻译而来，在涉及社会文化规范的场景中可能遗漏或带偏差（§1）。

作者认为阿拉伯法律领域适合做这类基准：法律推理需要结构化论证和语境敏感的灵活推断，语言复杂、格式严谨；而且主流多语法律数据集中缺少阿拉伯语（§1）。

已有法律基准多为判决预测、条款识别等分类任务，很少要求理解或生成支持判决的论证链（§2.2）。

依据：[arXiv 2510.00694v1，18 页](https://arxiv.org/abs/2510.00694)，§1–2，PDF pp.1–3。
