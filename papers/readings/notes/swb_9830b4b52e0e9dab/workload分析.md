# 工作负载

**案件**（§3.2、Figure 3、Table 2）：13,344 个沙特商事法院案件，总字数分布峰值约 500 词。作者说明有意选取了不太长的案件。

| 字段（Table 2） | 字数 最小/最大/平均 | 步数 最小/最大/平均 |
|---|---|---|
| 事实 | 31 / 398 / 181 | 3 / 11 / 8 |
| 推理 | 18 / 296 / 129 | 1 / 11 / 6 |
| 引用法条 | 0 / 977 / 186 | 0 / 15 / 3 |
| 判决 | 5 / 26 / 13 | — |

判决分布（Table 3）：支持原告 62%、支持被告 5%、法院驳回（多因不属于本院管辖）33%。

**法规**（Table 1）：8 部法规及实施条例，共 2,427 条（阅读者按表中各法规条数相加）；平均每条约 47 词。被引用次数最多的是商事法院法（9,652 次）、沙里亚诉讼法（Sharia Procedure Law，3,824 次）和证据法（4,665 次）。

**评测子集**：判决任务在 1,329 个案件上评测（§5）；法条识别为每种难度 1,159 道选择题（§5.2）；英文推理实验从测试集随机取 100 个案件（§6.3）。微调使用 12,012 条指令—输出对，来自数据集的训练部分（§6.1）。

阅读者分析：原文没有明确写出训练/测试的案件划分方式；13,344 − 1,329 = 12,015 与 12,012 条指令接近，但指令数与案件数的对应关系文中没有说明。数据集在 Hugging Face 发布（首页链接 `HarethahMo/ALARB`）。

依据：[arXiv 2510.00694v1，18 页](https://arxiv.org/abs/2510.00694)，§3.2、§5、§6.1、§6.3、Tables 1–3，PDF pp.4–8。
