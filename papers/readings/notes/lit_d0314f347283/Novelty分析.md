# 贡献与评价

**原文声称的贡献**（§1，pp.1–2；§5，pp.5–6）：

1. 把五类数据清洗与集成任务统一为自然语言生成任务，用同一个未微调的 FM 处理。
2. 实证显示 GPT-3-175B 少样本在多个基准上达到或超过全量微调的专门方法。
3. 对提示调优做消融：属性选择、提示措辞、示例选择分别带来平均 13.7、9.4、14.7 个 F1 点的差异。
4. 提出研究议程：自然语言交互、原型开发、从"数据尾气"学习、GUI 集成、可调试性、领域特化、隐私和提示自动化。

**阅读者分析（评价）**：

- 新意主要在问题设定和实证观察，而非新算法；序列化格式沿用 Ditto [57]。
- "SoTA"结论依赖人工挑选示例（每任务至多 1 小时），且该过程用到 10% 验证集；与全量训练的基线比较时，人力成本未量化为同一尺度。
- 每个任务只选 1–2 个"具有挑战性"的数据集，Adult 只评 1K 行，消融只评至多 200 个样本，统计置信度有限。
- 使用闭源 API 模型，模型可能在预训练中见过这些公开基准，原文未讨论数据污染。
- 成本（API 调用费用、延迟）未系统报告，仅提到预算限制导致抽样（§4.1，p.4）。

依据：§1、§3.3、§4、§5，PDF pp.1–6。
