# Narayan et al. — Can Foundation Models Wrangle Your Data?

本文是一篇探索性研究：把实体匹配、错误检测、数据填补、模式匹配和数据转换五类数据清洗/集成任务改写为提示（prompt），直接用 GPT-3-175B（text-davinci-002）做零样本和少样本推理，并与各任务的专门系统比较。主要结论是：在人工挑选示例的少样本设置下，GPT-3 在多数所选数据集上达到或超过此前最好方法，例如数据填补 Restaurant 上 k=10 准确率 88.4（IMP 77.2），Walmart-Amazon 实体匹配 F1 87.0（Ditto 86.76）；但对属性选择、提示措辞和示例选择很敏感。

已通读正文 §1–§6 与 Tables 1–4；未阅读文中多次引用的"full report"。
