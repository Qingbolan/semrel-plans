# 贡献与评价

**作者声明的贡献**（§1）：

1. **基于课程的性能提升**：由易到难的课程在数据分析与因果推理基准上优于其他 DS agent。
2. **更好的知识利用**：检索更简单且相关的示例，并按相似度递增排列，提高 agent 对既往经验的利用。
3. **渐进学习因果问题**：逐步引入更复杂任务，增强因果推理能力。

**消融支撑**（§4.4）：

- 难度定义：Mentor 仅凭题目判定的难度（problem-based）总体优于 LeetCode 人工难度、参考代码复杂度、弱模型通过率三种替代；唯一例外是 Llama 在 LeetCode 上用 Llama-3.1-8b 通过率作难度时更好（0.800 对 0.792）。
- 课程顺序：由易到难与由难到易都优于随机；由易到难通常最好，但 DSEval-Kaggle 上由难到易略高（Llama：0.583 对 0.577）。
- 记忆：加入答错示例对小数据集帮助更大（Llama LeetCode 0.733→0.792），对大数据集提升较小。

**阅读者评估**：

- 新意在于把课程学习移到推理时，并和在线记忆结合，思路简单清晰；但"课程"相对"随机顺序"的增益不大（如 Claude SO 0.837 对 0.800、Exercise 0.781 对 0.775，Table 6），主要提升可能来自记忆检索本身（阅读者分析）。
- 记忆写入依赖环境给出的对错标签，相当于使用测试反馈；论文未与同样使用在线反馈的 Reflexion 类方法比较。
- 运行次数少（课程 3 次、随机 5 次），未给方差或显著性。
- 难度指导标准、各数据集的检索示例数 K、DSEval 评测修正等细节均放在 arXiv 版未包含的补充材料中。
