# usecase

论文 Fig. 2 给出的场景"灌溉与土壤侵蚀"（R2 偏差诊断 · forbidden-controls 输出变体 · IV 结构 · 困难观测变体）：

- **故事**：半干旱地区农民获得灌溉激活补贴（Z），补贴与不可观测的地下土壤渗透性（U）共同决定是否执行灌溉（X，二值）；土壤侵蚀率（Y）既受灌溉影响，也受渗透性直接影响。
- **私有真值 DAG**：Z → X → Y，U → X，U → Y，U 为潜变量；Z 是工具变量。
- **公开数据**：Z1–Z3 是补贴的带噪声测量，X1–X3 是灌溉执行的带噪声测量。
- **问题**：用协变量调整估计 X 对 Y 的 ATE 时，哪些观测变量**不能**被条件化？返回 {"forbidden":[...]}；若不存在有效调整集但 ATE 可识别，返回 "no_backdoor"；若 ATE 不可识别，返回 "non_id"。

阅读者分析：此例中 U 是 X 与 Y 的未观测混杂，后门调整不可行，答案应在 no_backdoor/non_id 两个哨兵值之间根据概念图判定，需要智能体先做结构推理、再决定是否需要碰数据。论文指出最常见的推理错误正是"图不支持却声称可识别"，且通常源自工具变量（§6），这与该例的结构类型一致。原文未在图中给出本题的标准答案，此处推断仅供理解，不作为原文结论。
