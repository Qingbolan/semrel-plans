# 评测与边界

**实验 1（自动成对评测）**：由 GPT-4.1 读取主题、学习要点和引用，对两份报告在 5 项指标上分别打 1–5 分再比较胜负，报告顺序随机（PDF pp.5–6）。Table 1 的结果（本方法胜/负/平，%）：

| 指标 | Claude 3.7 Sonnet | Qwen3-235B + Qwen2.5-VL-72B |
|---|---|---|
| 信息量与深度 | 75 / 25 / 0 | 50 / 50 / 0 |
| 连贯与组织 | 76 / 21 / 3 | 41 / 51 / 8 |
| 可核验性 | 86 / 5 / 9 | 66 / 21 / 13 |
| 可视化质量 | 80 / 16 / 4 | 48 / 46 / 6 |
| 可视化一致性 | 78 / 17 / 5 | 52 / 42 / 6 |
| 总体 | 82 / 16 / 2 | 55 / 40 / 5 |

**实验 2（人工评测）**：5 位标注者在 20 个主题上做成对比较（Claude 3.7），总体胜率 100%；可视化质量一项为 75% 胜、20% 负。与 GPT-4.1 的判断一致率为 80%（Table 2，pp.6–7）。

**实验 3（单图评测）**：五项指标各打 1–10 分。Claude 配置下：

| 指标 | 本方法 | DataNarrative |
|---|---|---|
| 可读性 | 8.97 | 8.52 |
| 布局 | 9.23 | 8.48 |
| 美观 | 9.12 | 8.38 |
| 数据忠实 | 9.83 | 9.59 |
| 目标符合 | 9.75 | 9.24 |

Qwen 配置下，本方法的数据忠实分为 7.93，略低于基线的 7.99（Table 3，p.7）。正文没有写明单图评测用的是哪个评估模型。

**实验 4（消融，20 个主题）**：分别去掉范例学习、规划、修图后，变体对完整系统的输率为 70%、85%、80%（Table 4，p.7）。改用 GPT-5 和 Gemini-2.5-Pro 评判范例学习消融时，完整系统的胜率为 70% 和 60%。附录 Table 7 用 Gemini-2.5-Pro 做主评测，总体胜率为 90%（p.13）。

**效率**：每份报告平均耗时 767.20 秒，DataNarrative 为 372.94 秒；修图过程占了大部分时间（p.8）。

边界：错误分析指出，最常见的错误是图中元素重叠；数据不足时模型仍会编造，例如在等值区域图中把缺数据的区域标成红色（p.8；附录 D.3、E）。

阅读者分析：所有主要指标都是 LLM 或少数人工的偏好比较，没有把图中数字与来源逐条核对。基线由作者改造，与本系统共用研究阶段和渲染流水线，差异主要来自写作、规划和 FDV。附录 Table 6 中 Qwen 行的指标名被写成单图指标，与正文不一致，属于原文排版问题（阅读者分析）。
