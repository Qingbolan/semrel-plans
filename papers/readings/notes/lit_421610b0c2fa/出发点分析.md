# 出发点

NL2VIS 把自然语言描述转成基于表格数据的图表。作者认为现有 LLM 方法（Chat2Vis、LIDA、CoML4Vis 等）多为“一次前向”生成代码，在需要跨多表推理的查询上容易出错：连接错误或过滤条件错误会直接导致图表错误，而真实数据往往分布在多张相关表里（§1，p.1）。

Figure 1 的例子是“按教职级别统计其指导的学生数并画柱状图”：系统必须意识到 Student.Advisor 与 Faculty.FacID 对应同一实体，才能正确连接两表（§1，p.1–2）。作者据此主张需要三种能力：先预处理元数据，再分步规划，最后迭代验证（§1，p.2）。

阅读者分析：这一出发点本质上把 text-to-SQL 中已成熟的“模式链接 + 分解 + 执行反馈纠错”套路迁移到可视化场景；论文自己也在 §4.3 引用“The Death of Schema Linking”解释强模型下 processor 收益变小。
