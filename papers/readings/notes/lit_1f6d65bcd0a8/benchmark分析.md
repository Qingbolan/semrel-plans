# 评测与边界

**比较条件**：web 搜索（参与者自选搜索引擎，分屏）、仅文本 LLM、文本+视觉 LLM；模型为 GPT-4-32k（§4.3、§5.3，pp.5–6）。

**指标**：最偏好辅助类型；洞察数（只计 Lundgard–Satyanarayan 四级语义模型中的 2–4 级，因 1 级由图注提供）；NASA-TLX；视频编码得到的看图时间与使用辅助时间（空闲超过 10 秒不计）；文本提问类型（§5.4，pp.8–9）。

**实验（三种辅助条件的被试内对照，26 人）**：

| 结果 | 数值 | 位置 |
|---|---|---|
| 最偏好辅助 | web 3、仅文本 7、文本+视觉 16；χ²(2)=10.23，p<.05 | §6.1，p.9 |
| 自评表现（TLX 第 4 分量表） | 文本+视觉显著优于 web；Friedman+Nemenyi，Q=7.68，p<.05 | §6.3，p.11 |
| 洞察数 | web 显著多于文本+视觉；Q=7.40，p<.05 | 同上 |
| 偏好分组与洞察 | 偏好 web（3）或仅文本（7）者洞察多于偏好文本+视觉（16）者；t(24)=3.30，p<.05 | pp.11–12 |
| 偏好分组与看图时间 | 偏好文本+视觉者看图时间显著少于偏好 web 者；F(2,75)=3.66，p<.05 | p.12，Fig. 7 |
| 提问类型 | 少洞察组多用 broad-specific 问题（p=0.08，d=0.72）；多洞察组多用 narrow-abstract 问题（p=0.07，r=0.41），均未达显著 | p.12，Fig. 8 |

**边界**：作者承认只用了三种图表，且未考虑更复杂/复合图表（§7.4.1）；参与者多为 20–30 岁、不少人有数据分析经验，需扩展人群并控制数据素养（§7.4.5）；需要用文本细致描述每个可见元素才能让 LLM 理解图表，难以推广（§7.4.4）；幻觉导致误读需要防范（§7.1）。阅读者分析：论文未报告 LLM 回答的正确率；洞察数以单次口述计，未做延迟测验，学习效果的结论需谨慎。

依据：§5.4、§6、§7，PDF pp.8–15，Fig. 7–8。
