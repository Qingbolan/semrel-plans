# 出发点

新闻与社交媒体中越来越多出现气泡图、树图、平行坐标等复杂图表，而多数人只熟悉条形图、折线图；现有可视化素养教育主要依赖课堂、在线课程或针对特定图表的教学工具，难以在“碰到一张看不懂的图”时提供即时、贴合上下文的帮助（§1，p.1；§2.1，p.3）。

已有 LLM 可视化工具多用于根据自然语言生成图表或做数据分析，而不是帮助读者理解图表含义；且大多只支持文本交互。作者认为读图时人会切换视角、指点和高亮元素，视觉线索对理解很关键，纯文本对话可能限制新手（§1，pp.1–2；§2.3，p.3）。

形成性研究（6 名新手）进一步发现：给定具体问题时，参与者倾向于用最少精力找答案、把问题直接转发给 LLM 并不加批判地接受，因此主实验改为“为团队会议准备讲解”的自由探索任务，以促进深入参与（§3，p.4）。

依据：§1–3，PDF pp.1–4。
