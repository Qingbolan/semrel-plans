# 具体用例

论文 Fig. 6-D 给出的场景：参与者在树图条件下询问某只股票（Naver）的价格变化。LLM 智能体编写 Python 查询图表底层数据，回答文字说明，同时返回一个视觉回答——把时间滑块调到更晚的年份、缩放到 Naver 所属的服务业板块、并高亮 Naver。用户点击快照即可把该标注应用到左侧主图上（§4.2，p.5；§6.2.2，p.11）。

另一个例子（Fig. 5-A，p.9）：P14 看到散点图中标记向左移动，误以为数值下降；智能体指出是坐标轴值域变化，实际数值在上升，纠正了误读。Fig. 5-B 中，P18 认为两张树图的“非红色”面积差别很大，智能体计算后表明差别不显著。

反面情况（§6.2.2，p.11）：P3 在仅文本条件下被告知哪只股票最大，但在图上找不到，于是放弃寻找；有视觉回答的 P24 则能自行核对。

阅读者分析：从数据管理角度看，这是“自然语言 + 视觉选择 → 对一张表的代码查询 → 文本与视觉结果”的交互式问答管线；论文本身没有评测查询正确性，用例的价值主要在交互形态。

依据：§4.2、§6.1–6.2，PDF pp.5、9–11，Fig. 5–6。
