# 贡献与评价

**论文声称的贡献**（§1.1、§7，pp.758、767）：
1. 提出“对不同统计性质的数据子集使用不同执行计划”的概念，消除单计划限制；
2. 定义分类属性，并给出在线、低开销地学习分类属性和元组类的算法 Content-Learns；
3. 在 TelegraphCQ 的 Eddies 中实现，说明基于内容的学习与路由可以同时做到低开销和自适应。

**机制要点**：

| 组件 | 做法 |
|---|---|
| 画像（§4.1） | 轮转选择一个算子；以概率 P 抽取输入元组先送该算子，收集 |R| 个样本，记录每个属性每个分区的进出计数 |
| 分区 | 离散属性哈希到 d 个桶，连续属性按运行中的最小/最大值范围分区 |
| 分类属性选择 | 对每个属性算 gain ratio，取最大者；先试用并比较 Eddy 吞吐，有提升才保留，直到下次画像该算子 |
| 选择率维护 | 类内选择率矩阵 S 与全局选择率 W 每个元组都更新，指数平滑 α=0.95 |
| 路由（§4.2） | 送往估计选择率最小的算子：有分类属性的用类内选择率，否则用全局选择率 |
| 剪枝（§4.4） | 忽略很便宜/很有选择性（或相反）的算子，忽略时间戳、序号、长字符串等属性 |

**阅读者评价**：
- 优点：例子说明了何时需要不同计划，没有把“路径不同”本身当作收益（§1）。
- 优点：直接测量了学习与路由开销，并说明收益依赖算子足够昂贵（§4.3、§6.7–6.8）。
- 优点：给出“CBR 不会比 SBR 更慢适应”的论证：失效的类内选择率会很快收敛到全局值（Example 5.1）。
- 不足：一次只画像一个算子，两次画像之间出现又消失的相关性可能被漏掉（§5，作者承认）。
- 不足：只用单属性分类器，多属性共同决定的相关性捕捉不到（§3）。
- 不足：非过滤算子只有讨论没有实验（§4.5）；真实数据上收益不大（§6.6）。

依据：§1–7、Example 5.1，pp.757–767。
