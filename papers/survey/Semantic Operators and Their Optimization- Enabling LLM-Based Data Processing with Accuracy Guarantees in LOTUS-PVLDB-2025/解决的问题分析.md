# 解决的问题

**算子与参考算法**（Table 1、§2.4，pp.4173–4175）：

| 算子 | 语义 | 参考算法 | LLM 调用复杂度 |
|---|---|---|---|
| sem_filter | 保留满足自然语言谓词的元组 | 每行一次批量 LLM 调用 | O(\|T\|) |
| sem_join | 保留满足谓词的元组对 | 嵌套循环，逐对判断 | O(\|T1\|·\|T2\|) |
| sem_topk | 按自然语言排序标准取前 k | 两两比较 + quick-select | 比二次排序少至少一个数量级 |
| sem_agg | 按自然语言归约函数聚合 | 分层归约（hierarchical reduce） | — |
| sem_group_by | 发现 C 个组标签并归类 | 先逐行投影候选标签、嵌入后 k-means 聚类，再逐行分类 | O(\|T\|) |
| sem_map | 自然语言投影 | 每行一次调用 | O(\|T\|) |

**正确优化的定义**（§2.3 p.4173）：优化必须降低成本，并以概率 1−δ 满足相对参考算法的准确率目标 γ。

**各算子的优化**（§3，pp.4175–4176）：
- **filter**（Algorithm 1）：用小 LLM 输出 True/False 的对数概率作代理分数，并按 50 个分位数重新标定。先用带均匀混合的重要性采样抽样，并用 oracle 打标签；再学出两个阈值 τ+、τ−，分别以 δ/2 的失败概率保证精确率和召回率目标。分数 ≥ τ+ 直接通过，≤ τ− 直接拒绝，中间区间交给 oracle。
- **join**：两种嵌入代理计划并存。sim-filter 直接比较左右键的嵌入相似度；project-sim-filter 先用 LLM 对左键做一次不看右表取值域的投影，再与右键比相似度。两者各自学阈值，选所需 oracle 调用更少的一个。
- **group-by**：沿用参考算法发现组中心，再以“候选标签与中心的嵌入相似度”为代理；学一个阈值，相似度不够时才调用 LLM 分类。这里用均匀抽样而非重要性抽样，因为样本要覆盖所有类别。
- **top-k**：按嵌入相似度选第 (k+ε) 个元素作首个 pivot，减少后续比较轮数。这是无损优化；排序标准与相似度无关时退化为随机 pivot，最坏只多一轮。

**未覆盖的部分**：map 和 aggregation 的优化不在本文范围（§3 p.4175）；保证只针对单个算子，多算子查询的端到端误差分配留作未来工作（§7 p.4182）。
