# 解决的问题

本文要解决的是“如何评测”，提出两类任务，输入输出和评分方式不同。

**数据分析任务**（§2.1，p.4）：输入是任务介绍 I、数据文件集合 D = {d1, …, dNd}（可只有一个）和问题 Q，agent 输出答案 Â = G(I, D, Q)。题型为选择题和填空题。评分用 LLM 实现的语义比较函数 S(A, Â)，判断与标准答案语义是否相同；作者对 100 个 GPT-3.5 答案做人工核对，与该函数一致率为 100%（附录 F）。

**指标**：任务级准确率（答对题目比例）；比赛级准确率（先按 challenge 求准确率再平均）。两种平均口径不同，不能混用。

**数据建模任务**（§2.2，pp.5–6）：输入是竞赛描述 E、训练集、测试集和示例提交文件 M，agent 需设计算法、写代码并生成与 M 格式一致的提交文件。

**指标**：
- 任务成功率：在固定步数内无 bug 地建好模型并生成提交文件；
- RPG = (1/N) Σ max((p_i − b_i)/(g_i − b_i), 0)，其中 p_i 为 agent 提交的成绩，g_i 为该竞赛的最高成绩，b_i 为竞赛原始示例提交的成绩（附录 E）。RPG 越高越好，是相对基线到最高分区间的归一化表现，不要因名字含 Gap 就以为越低越好（阅读者分析）。

**边界**：分析题与建模题的指标不同，不能共用一个“代码运行成功”指标；benchmark 不限定工具，可用 Python 或 Excel（§2.1）。

依据：[arXiv 2409.07703v2](https://arxiv.org/abs/2409.07703v2)，§2.1–2.2、附录 E–F，pp.4–6、附录。
