# Parametric Query Optimization

缓冲区大小、索引、查询常量等运行时参数在优化时往往未知；为某个假定值优化出的计划，在另一个实际值下可能代价很高。Ioannidis、Ng、Shim、Sellis 把参数化查询优化形式化为求一个“计划函数”：给定参数的实际值，就返回对应的最优计划；运行时只需按参数值查表。论文以缓冲区大小为主要参数，改造随机化优化算法（II、SA、2PO），让不同缓冲区值的搜索并发进行，并在相邻值之间“侧向传递”候选计划。

在随机生成的 1–20 连接查询上，sipIIs(1) 用 2PO 优化单个缓冲区值所需的时间，就为 [2,70] 全部缓冲区值求出计划函数；小查询在 T/3 时间内即达到最优的 1% 以内，20 连接查询在 2T 时间内平均相对代价在 4% 以内。
