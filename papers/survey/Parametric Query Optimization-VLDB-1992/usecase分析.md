# 具体用例

**原文示例**（Example 2，§4.2，Figure 3，pp.108–109）：当前计划函数在缓冲区 13–16 上有 3 个像分区：13 用计划 S1，14 和 15 用 S2，16 用 S3。

1. 本轮随机选中 b = 14，其随机算法从 S2 生成一个邻居 S4：把关系 R1 与 R2 之间的嵌套循环连接换成归并扫描；
2. 深度 k = 1 时，S2 所在分区为 [14, 15]，朋友范围扩展为 13–16，于是对 b′ = 13、14、15、16 分别比较 S4 与当前计划的代价；
3. 假设 S4 在 13、14 上分别比 S1、S2 便宜，在 15、16 上不如 S2、S3，则本轮结束后变为 3 个分区：13–14 用 S4，15 用 S2，16 用 S3；
4. 若 k = 0（无侧向传递），只有同一分区的 14、15 会比较 S4，结果为 13、14、15、16 分别用 S1、S4、S2、S3。

这说明侧向传递让一个缓冲区值上找到的好计划能直接惠及相邻缓冲区值，而不必各自从头找到它。

**运行时使用方式**（§6，p.113）：查询执行时系统已知参数的实际值，只需一次查表就能取出对应计划，无需重新优化。

依据：§4.2 Example 2、Figure 3、§6，VLDB pp.108–113。
