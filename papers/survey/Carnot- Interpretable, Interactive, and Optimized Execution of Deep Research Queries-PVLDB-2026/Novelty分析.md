# 贡献与评价

**主要贡献（阅读者归纳）**：让 agent 生成的计划成为用户能干预的执行对象。它保留 DAG 依赖和成本约束，又提供 notebook 式的逐步检查与修改，把数据库查询计划的可优化结构与 agent 的迭代灵活性结合起来（§1）。

**与相近工作的区别**：
- 与 Deep Research 系统（Claude、Gemini、OpenAI、Perplexity 等）相比：中间步骤可见、可控，可设成本/延迟预算；
- 与语义算子系统（Palimpzest、LOTUS、DocETL、MOAR）相比：计划可在执行中逐步运行、修改并复用上游结果；
- 优化器沿用 Abacus 的规则，但用 LLM agent 从 Pareto 前沿中挑选计划（§2.3）。

**优点（阅读者分析）**：比只展示最终答案或静态逻辑图更贴近分析人员核对证据的过程；三层查看粒度（意图、代码/提示、原始数据）让非程序员也能检查。

**边界**：
- 原文 §4 明确：不提供计划准确性或正确性保证；可以借 oracle 提供统计保证，但 oracle 本身也会错；Web 搜索和通用工具调用是未来工作。不能因标题含 “Deep Research” 就认为已支持开放网络研究。
- 阅读者分析：复用的是同一工作区内修订时未受影响的上游物化结果；没有评测跨无关查询的联合优化或大批量并发。Figure 2 中的成本标注只是一次界面示例，不能当作系统费用基准。
