# 具体用例

**原文示例：100 条房源筛选**（§5.2 Figure 5，§5.3 PLAN 2，pp.14–16）。每条输入是一条房源，含文本描述和 3 张图片。用户程序声明两个目标 schema 和四个条件：

1. 从文本 convert 出 address 与 price；
2. 用两个 UDF 过滤：距 MIT 两英里内、价格在范围内（`depends_on="address"`、`depends_on="price"`）；
3. 对剩余房源用图像生成 is_modern_and_attractive、has_natural_sunlight，再过滤；
4. 输出满足全部条件的房源记录。

**优化器做了什么**：附录 PLAN 2 先执行文本算子、后执行图像算子，从而对不合格房源完全跳过 GPT-4V 调用；文本部分改用 GPT-3.5，并把房源文本裁掉 50%（地址和价格通常在开头）。

**效果**：PLAN 2 相对全 GPT-4 基线运行时间低 3.3 倍、费用低 2.9 倍，F1 最高为基线的 1.1 倍（§5.3）。这是候选计划之间的比较；优化器在给定 policy 下实际选中什么计划，是 §5.4 的另一项实验，两者不能互相代替。

**记录建议**（阅读者分析）：原始查询是论文中的 Python 程序，而非一句英文；Figure 3 的字符串含作者省略号，不应自行补全后当作原文。
