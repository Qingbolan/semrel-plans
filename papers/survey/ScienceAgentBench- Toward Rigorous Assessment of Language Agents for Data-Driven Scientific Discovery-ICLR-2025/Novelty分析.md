# 贡献与评价

**作者的三条设计原则**（§1，p.2）：

1. **科学真实性**：任务直接取自同行评议论文，并由领域专家共同设计和验证；
2. **严格分级评测**：输出统一为自包含 Python 程序，用多种指标检查程序、执行结果（如图表、测试集预测）和费用；另有逐任务的分步评分细则（rubric）；
3. **多阶段质控**：标注员与专家多轮人工验证，并提出两种缓解数据污染和捷径的策略。

**与已有基准的区别**（§2.4、Table 2，p.6）：

| 基准 | 代码生成粒度 | 任务来源 | 异构数据处理 | 防捷径 | 学科数 | 测试任务数 |
|---|---|---|---|---|---|---|
| SWE-Bench | 文件级编辑 | GitHub | ✗ | ✗ | 1 | 2,294 |
| ML-Bench | 行级 | GitHub | ✓ | ✗ | 1 | 260 |
| DiscoveryBench-Real | 间接（经自然语言假设） | 27 篇论文 | ✓ | ✗ | 6 | 239 |
| SciCode | 函数级 | 论文 | ✗ | ✓ | 5 | 80 |
| ScienceAgentBench | 文件级生成 | 44 篇论文 | ✓ | ✓ | 4 | 102 |

（Table 2 另含 TaskBench、BioCoder-Py、MLAgentBench、BLADE，此处略。）

**阅读者评价**：

- 新意在于把任务真实性验证、按执行结果判定和细粒度 rubric 结合起来；重划分数据、删测试点和隐藏测试标签用来抑制背诵代码或直接读答案（阅读者分析）。
- 区分"能运行"（VER）与"达成目标"（SR），后者以前者为前提（§2.3）。
- rubric 来自参考实现，可能低估等效的替代算法；作者在 §4.2 举了随机森林替代神经网络的例子（阅读者分析）。
- 102 个任务规模中等，作者认为考虑到标注难度与评测成本是合理的（§2.4）。

依据：[arXiv 2410.05080v2](https://arxiv.org/abs/2410.05080v2)，§1、§2.3–2.4、§4.2、Table 2，pp.2–9。
