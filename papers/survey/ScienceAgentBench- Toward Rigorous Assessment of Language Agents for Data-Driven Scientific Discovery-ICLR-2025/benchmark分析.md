# 评测与边界

**指标**（§2.3，p.5）：

- VER（有效执行率）：程序无错运行并以正确文件名保存输出；
- SR（成功率）：输出满足任务的成功标准；以有效执行为前提；
- CBS（CodeBERTScore）：与标注程序的上下文嵌入相似度 F1；若 SR=1，CBS 记为 1.0；
- Cost：完成一个任务的平均 API 费用（美元）。

图表输出由 GPT-4o 与金标准图比较打分，采样 3 次取平均。另有按五个阶段（数据加载、数据处理、建模或可视化、输出格式、输出保存）的 rubric，用于人工评估。

**三种框架**（§3，pp.6–7）：直接提示（一次生成，不接触环境）；OpenHands CodeAct v1.9（Python 解释器、bash、浏览器）；self-debug（执行后根据结果迭代修改，作者去掉了反思步骤，连续两轮相同即提前结束）。

**实验 1（主结果，Table 3，p.8）**：SR / VER / Cost（$），左为无专家知识，右为有专家知识。

| 框架 | 模型 | 无知识 | 有知识 |
|---|---|---|---|
| 直接提示 | Llama-3.1-405B | 3.9 / 35.3 / 0.010 | 2.9 / 25.5 / 0.011 |
| 直接提示 | GPT-4o | 11.8 / 52.9 / 0.011 | 10.8 / 41.2 / 0.012 |
| 直接提示 | Claude-3.5-Sonnet | 17.7 / 51.0 / 0.017 | 21.6 / 41.2 / 0.017 |
| OpenHands | GPT-4o | 19.6 / 78.4 / 0.803 | 27.5 / 73.5 / 1.094 |
| OpenHands | Claude-3.5-Sonnet | 21.6 / 87.3 / 0.958 | 24.5 / 88.2 / 0.900 |
| Self-debug | Llama-3.1-70B | 13.7 / 80.4 / 0.007 | 16.7 / 73.5 / 0.008 |
| Self-debug | Mistral-Large-2 | 23.5 / 83.3 / 0.034 | 27.5 / 78.4 / 0.036 |
| Self-debug | GPT-4o | 22.6 / 83.3 / 0.047 | 23.5 / 71.6 / 0.046 |
| Self-debug | Claude-3.5-Sonnet | 32.4 / 92.2 / 0.057 | 34.3 / 86.3 / 0.061 |
| Self-debug | OpenAI o1（仅供参考） | 42.2 / 92.2 / 0.636 | 41.2 / 91.2 / 0.713 |

（表中省略了部分模型–框架组合，完整数据见 Table 3。）o1 因推理时额外计算、超参不同，作者不与其他模型比较，因此"Claude + self-debug 最好"是在排除 o1 后成立的。

**主要发现**（§4.1，pp.7–9）：

- 执行反馈很关键：self-debug 让 Claude 的 SR 近乎翻倍。
- 框架要匹配模型：5 个模型中 4 个用 self-debug 比 OpenHands 好，只有 GPT-4o 例外；无知识时 Claude 用 self-debug 比 OpenHands 多解 10.8 个百分点（21.6 → 32.4），API 费用低 17 倍（$0.958 → $0.057）。
- 专家知识多数情况下提高 SR 和 CBS，却常降低 VER：智能体会改用不熟悉的指定工具，出现错误或幻觉 API 调用。
- 成功的任务超过 75% 的金标准程序短于平均的 58.6 行；生物信息与计算化学主要败在数据处理和模型开发，地理与心理学主要败在 Geopandas、Biopsykit 等领域工具的使用（Figure 3）。

**实验 2（人工 rubric 评估，§4.2，Figure 4，pp.9–10）**：对 Claude + self-debug + 专家知识的 102 个程序，由两位评估者按 rubric 打分。数据加载和处理两个阶段最能区分成败：25% 的失败程序在加载阶段得分低于 50；输出格式与保存两组无差异。

**核对发现**：§4.1 正文写 Claude 直接提示的 SR 为 16.7%（无知识）和 20.6%（有知识），并据此算出 1.94× 和 1.67×；但 Table 3 中对应数值是 17.7 和 21.6（阅读者分析）。

**边界**：

- 3 次尝试取最佳，报告的是 best-of-3 而非单次表现；单次均值与标准差在附录 D（阅读者分析）。
- 复现实验须锁定数据版本；官方后来发布的 2026 verified 数据与本文数字不可混用（阅读者分析）。

依据：[arXiv 2410.05080v2](https://arxiv.org/abs/2410.05080v2)，§2.3、§3–4、Tables 1、3、Figures 3–4，pp.5–10。
