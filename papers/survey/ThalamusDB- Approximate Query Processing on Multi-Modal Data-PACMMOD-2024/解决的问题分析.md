# 解决的问题

**输入**：扩展 SQL 查询，含 `NL(column, 'text')` 形式的自然语言谓词，作用于 PICTURE、AUDIO 或 TEXT 列，可与关系谓词、连接、聚合组合；用户对三项指标（近似误差、计算时间、标签数）的偏好：至多对一项设约束，其余两项给权重（§2，pp.186:4–186:5）。

**输出**：聚合查询返回下界与上界；无聚合查询返回“必定满足”与“可能满足”两个行集合（§4.3）。

**执行阶段**（§2，pp.186:5–186:6）：
1. 初始化：为每个 NL 谓词建一张临时表（元素 ID，相似度分），初值为 NULL；
2. 预处理：对每个谓词在小样本上算相似度，并请求 3 个标签，收集选择率等统计；
3. 优化：在约束下最小化加权代价，生成执行计划；
4. 执行：两类动作交替进行：按某列排序的优先数据处理（用模型给一批元素打分）与标签请求（类似二分查找，从相似度中位数附近的元素问起，缩小阈值区间）；
5. 后处理与提前终止：计算超出约束时中断；误差未达标时追加动作。

**界的计算**（§4.3，Table 3）：把每个 NL 谓词改写为基于分数阈值的 SQL 条件。“可能满足”= 分数高于阈值下界或尚未计算；“必定满足”= 分数高于阈值上界。最小值的下界用“可能满足”的行求，上界用“必定满足”的行求；最大值、求和、计数相反；平均值由求和与计数的界推出。

**保证的范围**（§1，p.186:3）：假设神经模型无误，界必定包含处理全部数据时得到的值；模型本身的分类错误不在保证之内。优化器使用的误差与代价估计没有保证，但只影响选哪些数据，不影响结果界的正确性。

依据：§1–2、§4、Table 3，pp.186:3–186:12。
