# 解决的问题

**输入**：查询（值查询、范围谓词、平均等聚合），误差容限 ε 与置信度 1−δ；由历史数据学习的概率模型 p(X1,…,Xn)，每个 Xi 是某节点的某类属性；各属性的采集能耗；已知网络拓扑与链路质量估计（§2–4）。

**输出**：一个观测计划（要读哪些节点的哪些属性、按什么路径收集），以及满足置信度要求的近似答案。

**查询的概率语义**（§3.1，pp.592–593）：
- 范围查询：计算 P(Xi ∈ [ai, bi])；很高则判真，很低则判假，否则需要更多观测；
- 值查询：要求 P(Xi ∈ [x̄i − ε, x̄i + ε]) 达到置信度，x̄i 为后验均值。

**观测选择的优化问题**（§4，pp.593–595）：在 R(O) ≥ 1 − δ 的约束下，最小化代价 C(O) = Ca(O) + Ct(O)。
- Ca(O)：所选属性的采集能耗之和；
- Ct(O)：一条访问所有被选节点并返回基站的路径的期望通信代价，边权为 1/(p_ij·p_ji)，体现丢包与重传；选路是 TSP，用 k-OPT 等启发式；
- R(O)：观测后的期望置信度；对值查询和平均查询，在高斯模型下后验协方差与观测值无关，可用误差函数闭式计算；范围查询需数值积分；
- 该问题是 NP-hard；论文给出指数时间的穷举算法与贪心增量启发式（每步加入收益/代价比最高的属性，直到达到置信度）。

**模型**（§3.2）：BBQ 使用随时间变化的多元高斯；每小时一个转移模型，用 Kalman 滤波把上一时刻的观测带入当前估计。

依据：§2–4，VLDB pp.589–596。
