# 贡献与评价

**作者的贡献**（Abstract、§2–3）：

1. **任务统一**：提出"语言模型驱动的查询规划"新范式，把 SQL 难以独立处理的图像、文本与关系分析放进一个自然语言规划框架，输出可以是数值、表或图。
2. **分阶段规划**：仿照传统规划把发现、逻辑步骤和物理算子映射分开，让每个 prompt 只负责一类决策，并把 LLM 的计划落到已有可执行工具上。
3. **执行反馈**：逐步映射并执行，利用中间结果选参数（如看到 VisualQA 输出 "yes"/"no" 后再写选择条件），出错时回退修正；不是一次生成的全静态 DAG。

**阅读者评价——优点**：

- 示例清楚说明为何需要跨模态工具，而不是为工具找任务（Figures 1、4）（阅读者分析）。
- 区分逻辑计划与物理计划的正确率，错误分析能定位到缺步骤、参数错等类别（Tables 1–2）。
- 坦承执行反馈不保证正确，并展示两个模型都失败的查询（§3.2、§4.3）。

**阅读者评价——不足**：

- 假定检索完美，隔离了规划能力，也掩盖了真实数据发现的错误（§4.2）（阅读者分析）。
- 只有两个自建领域共 48 个查询，没有最终答案质量和成本的统一对照（§4）（阅读者分析）。
- 计划正确仍依赖 VisualQA/TextQA 模型本身的准确性；"计划正确比例"不能等同于答案准确率（阅读者分析）。

依据：[arXiv 2308.03424v1](https://arxiv.org/abs/2308.03424v1)，§2–4、Figures 1–4、Tables 1–2，pp.1–6。
