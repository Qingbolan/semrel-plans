# 解决的问题

**输入**（§2.2 p.3）：
- 必需：一个由 Table 1 算子（scan、map、filter、join、top-k、project、aggregate、limit）组成的程序；一个优化目标（在质量、费用、延迟中最大化或最小化一项，可对其他维度加零个或多个约束）；待处理的输入数据集。
- 可选：一个小验证集（典型为 5–10 条，标签可以不全）；先验，即把算子映射到 [0,1] 上（质量、费用、延迟）三元组的字典；一个 LLM judge（默认 o4-mini），用于没有标签时打分。

**输出**：一个物理计划，即为每个逻辑算子选定的实现（Figure 2，p.4）。

**代价模型**（式 (1)，§2.3 p.4）：假设算子相互独立，计划质量等于各算子质量之积，费用等于各算子费用之和，延迟取 DAG 中最长路径上的延迟和。这样少量算子级测量就能组合出大量计划的估计；代价是忽略上下游相关性，例如下游 filter 的表现取决于上游 map 摘要的质量。

**算法流程**（Algorithm 1，p.4）：
1. 编译成逻辑计划，用实现规则为每个逻辑算子枚举物理算子；
2. 每个逻辑算子随机（有先验时按先验）抽 k 个物理算子组成“前沿”，每轮在 j 个样本输入上运行，记录质量、费用、延迟；
3. 更新前沿（Algorithm 5，§3.3 p.7）：对每个指标算 UCB/LCB，探索系数取所有算子观测值极差的 0.5 倍；若某算子的 UCB 与当前 Pareto 算子的 LCB 都不重叠，就淘汰它，从未采样的储备池中补一个；
4. 采样预算（按调用次数或美元计）用完后，把各算子的平均估计交给 Pareto-Cascades 选出最终计划。

**Pareto-Cascades**（§3.2 pp.6–7）：Theorem 3.1 证明，在算子独立假设下，Pareto 最优计划的每个子计划也是 Pareto 最优的。因此每个组只需保留 Pareto 前沿上的物理表达式，最后按目标在前沿上选点。分支因子不超过该语义算子被采样的物理算子数。无约束时退化为普通 Cascades。

**两个容易误读的点**：
- 若找不到满足约束的计划，算法返回目标最优的那个计划（§3.2 p.7），所以约束不是硬保证；实验中约束满足率也低于 100%（见“评测与边界”）。
- 采样阶段只使用实现规则；filter 下推、join 重排等变换规则只在最终选计划时使用（§2.2 p.4）。采样费用以预算为上限，采样延迟随计划深度增长（§2.2）。
