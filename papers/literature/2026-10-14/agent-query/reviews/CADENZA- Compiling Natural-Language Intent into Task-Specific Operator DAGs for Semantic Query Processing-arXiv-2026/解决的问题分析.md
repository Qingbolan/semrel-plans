# 研究问题与方法

§3 TxRA扩展关系代数，以Apply把OCR、文本问答、图像分类等结果变成带类型的关系属性。算子类别包括结构、属性、关联、生成和向量表示。属性依赖可用于验证FilterPushdown和CommutativeReordering；OCR→TxtQA有依赖，不能互换。

§4逻辑规划先在固定预算内生成、检查和修复多个seed，再展开结构重写和语义替代。分区提取或图像转文本的替代并不默认等价，需用验证信号比较效果。

§5物理规划给每个任务选择symbolic、specialized、general-purpose、composite实现，按便宜特征生成难度评分与百分位分桶router。BO联合调路由切点、后端参数和关系阈值，而不是分别调每个局部模块。默认3个seed、50验证样本、20次BO，计划参数最多15个连续维度。

§6错误处理包括schema smoke test、隔离执行、限时重试与LLM安全执行；少量输入可绕过优化。它们是作者系统设计，不能据此证明所有合成代码正确。
