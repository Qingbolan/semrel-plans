# 查询中文译文

`queries-zh.json` 为 8-17 与 7-30 的逐查询中文标题，键为稳定 query_id。每条包含英文原文、中文译文及原文 SHA256。查询表、参考计划、EAL 和原始 JSON 不被翻译覆盖。

浏览器中文模式使用译文，英文模式显示原文；侧栏支持两种语言搜索。构建检查完整覆盖和原文一致性，查询发生变化后必须更新对应译文。

初稿通过 Google Translate、Microsoft Translator 和本地 Qwen 模型生成，并对部分领域表达做人工修订；不代表逐条专家审校。`scripts/translate_queries.py` 是可选的联网维护工具，保护数字、下划线字段标识及反引号片段，支持断点续传。正常构建和网页使用不需要联网或调用翻译服务。不要在已有原文与译文一致的情况下删除翻译文件重新生成，以免覆盖修订。
