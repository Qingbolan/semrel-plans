# Data agent literature search — 2026-10-14

Scope: end-to-end data analysis, data science agents, heterogeneous data workspaces, and their benchmarks; adjacent SQL and scientific experimentation benchmarks are included where they evaluate agent environments. General software agents, generic memory benchmarks, and unrelated table models are excluded from this branch.

Discovery queries: Data Interpreter agent arxiv DS-Agent data science; DABstep DiscoveryBench ScienceAgentBench KramaBench data agent benchmark; DataVoyager arxiv; DataSciBench DA-Code InfiAgent DABench; Spider 2.0 BIRD-INTERACT; MLE-bench.

Citation expansion used the authors’ [HKUST companion list](https://github.com/HKUSTDial/awesome-data-agents) and [SJTU list](https://github.com/SJTU-DMTai/Awesome-Data-Agent-Papers). Candidate titles were checked against arXiv citation metadata. Metadata-only entries have not been independently reviewed for methods or experiments. Venue defaults to arXiv where conference status was not independently checked.

Five reviews read main-text methods, task definitions, experiments, and limitations from versioned arXiv HTML. Relevant appendices were consulted selectively. No experiments were rerun and no benchmark-wide query extraction is claimed. The seven review files preserve the existing Survey structure. Evidence snapshots retain source versions; exact query snippets are short and no generated examples are entered into canonical query JSON.

The list is a dated search result, not a proof of exhaustive coverage. Distinct papers such as InfiAgent-DABench, DABstep, and DAB are retained separately. DataVoyager refers here to Data-driven Discovery with Large Generative Models, not an unrelated synthetic-data project using the same name.
