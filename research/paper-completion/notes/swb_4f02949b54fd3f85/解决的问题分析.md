# 解决的问题

**标注任务**：对 Sequoia 中每个句子，标出所有 NE 与 MWE 的 token 集合，允许不连续、嵌套和重叠（§4.1，p.434）。

| 项目 | 内容（原文） |
|---|---|
| 输入 | Sequoia 句子，已有形态句法依存标注 |
| 输出 | NE 的 token 集合 + 类别（PERS、LOC、ORG、PROD、EVE；转喻时同时标原始与最终类别）；非动词 MWE 的 token 集合 + 一条满足的充分条件；动词 MWE 沿用 PARSEME 1.1 的类别（IRV、LVC.full、LVC.cause、VID、MVC） |
| 不标注 | 日期、金额、数值表达（§5.1）；纯统计性的搭配（collocations）（§3.3） |
| 判定流程 | Figure 2：动词性分布 → PARSEME 规范；名词性且特指实体、命名约定只连到该实体、且属五类语义 → NE 规范；其余多词候选 → 非动词 MWE 规范（§4.2，pp.435–437） |

**NE 与 MWE 的区分**（§3.2）：(A1) 纯专名与 (A2) 语义可组合但须单独学习命名约定的实体名记为 NE；(B) 可实例化的概念名，以及 (A3) 唯一抽象实体名（如 `physique quantique`），若为多词则记为 MWE。同一序列不能同时标为 NE 和 MWE。

**非动词 MWE 的 10 条充分条件**（§7.3，p.447）：语义类 ID、PRED；词汇固定类 CRAN、LEX、DET、ZERO；形态句法固定类 MORPHO、IRREG、SYNT、INSERT。

这是“语料标注与规范”问题，而不是模型任务；论文没有定义自动识别的划分或评测协议。§10.2 的 10 折只用于统计变异性（阅读者分析）。

依据：[JLM 8(2) 2020, pp.415–479，65 页](https://jlm.ipipan.waw.pl/index.php/JLM/article/download/265/249/2149)，§3–5.1、§7.3、Figures 1–2，期刊 pp.427–446。
