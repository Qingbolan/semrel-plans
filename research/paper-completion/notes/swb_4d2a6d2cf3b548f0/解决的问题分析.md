# problem

**标注对象**：经济事件，定义为"文本报道的、涉及公司的现实发生、行为、关系和情境"（§4，PDF p.8）。

**单个事件提及包含的要素**（§4，pp.9–11）：
- **触发词**：token 级标注，允许不连续 span，例如 "sales … stall"。
- **事件类型与子类型**：18 个类型，见 Table 2。
- **参与者论元**：只在事件提及范围内标注，可以是代词。
- **填充论元**：时间、地点、金额等，可以出现在全文任意位置，必须是完整名词短语。
- **事实性属性**：Polarity（肯定/否定）和 Modality（确定/其他）。ERE 中的 Generic realis 因在试标注中很少出现而没有标注。
- **关系**：事件共指沿用 Rich ERE 的 "event hopper"；代词或回指名词短语还要链接到最近的规范指称（canonical referent）。

与 ACE/ERE 的主要区别：不预先标注实体类型和关系，因此论元角色不受实体类型约束（p.9）。

**本文实际评测的任务**比语料设计要窄：只做句子级、18 类的多标签事件类型检测；触发词、论元和共指的抽取都没有评测（§7，p.20）。

依据：[LRE 56:225–257，33 页](https://doi.org/10.1007/s10579-021-09562-4)，§4、§7，Table 2，PDF pp.8–13、20。
