# Segura-Bedmar et al. — SemEval-2013 Task 9: Extraction of Drug-Drug Interactions from Biomedical Texts (DDIExtraction 2013)

这是 DDIExtraction 2013 共享任务的综述：基于 DDI 语料（784 篇 DrugBank 文本 + 233 篇 MedLine 摘要），设 Task 9.1 药物实体识别与分类、Task 9.2 药物相互作用（DDI）检测与分类。14 支队伍提交 38 个 run；9.1 最佳严格 F1 为 71.5%，9.2 检测 F1 为 80%、检测并分类 F1 为 65.1%。已阅读全文正文与全部结果表；Table 1 已渲染核对。
