# Wang et al. — VizTA: Enhancing Comprehension of Distributional Visualization with Visual-Lexical Fused Conversational Interface

VizTA 是面向箱线图、密度图、小提琴图和分位点图等分布型可视化的对话式读图助手：读者可把图元拖进提问，回答中的行内引用在悬停时高亮对应图元。后端是 GPT-4o，初始化时注入图表规格、图元 ID、数据值和图元语义知识。24 人被试间实验中，VizTA 组单选正确率 75.5%，基线为 62.5%；口头推理通过率分别为 97.9% 与 75.0%。已读全部正文；补充材料中的完整场景与题目未获取。
