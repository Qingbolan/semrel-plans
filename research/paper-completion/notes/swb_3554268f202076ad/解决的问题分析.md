# 解决的问题

**输入**：MASC 书面语文本，经 SPADE 篇章解析器自动切分为限定子句片段，再做启发式后处理（§4.2，p.154）。标注者可标记“无情境”（如标题、署名）或“应与其他片段合并”。

**工作单位**：一个子句片段。

**输出**：每个片段的 SE 类型及三项特征（§3，pp.150–153）：

| 标注项 | 取值 |
|---|---|
| SE 类型 | EVENT（含子类 REPORT）、STATE、GENERALIZING SENTENCE、GENERIC SENTENCE、FACT、PROPOSITION、QUESTION、IMPERATIVE |
| 主指称类型 | specific / generic / expletive |
| 基本体貌类 | stative / dynamic / both |
| 惯常性 | episodic / habitual / static |

**流程**（§3，p.150）：先标易识别的言语行为（疑问、祈使）和抽象实体（事实、命题，限于特定许可谓词的子句补语）；否则先定三项特征，再按 Table 1 的映射得出 SE 类型。抽象实体内嵌子句还需另标其内嵌 SE 类型。

**派生类型**：否定、情态、将来时、条件等会把本应是 EVENT 的子句强制转为 STATE，如“John did not win the lottery”（§3.1，p.151）。

依据：§3.1–3.3、Table 1，pp.150–153；§4.2，p.154。
