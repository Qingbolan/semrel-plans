# Zhou et al. — A Survey of LLM × DATA

这是一篇双向综述：DATA4LLM 梳理为大模型各阶段服务的数据处理、存储与服务技术；LLM4DATA 梳理用大模型做数据清洗/集成/发现、结构化/半结构化/非结构化数据分析及数据库系统优化。作者基于 400 余篇论文提出评价 LLM 数据质量的“IaaS”四维概念（Inclusiveness、Abundance、Articulation、Sanitization）。本文没有自有实验或基准。已阅读引言、数据特征与 Table 1、LLM4DATA 全节及第 4 节挑战；DATA4LLM 的具体技术小节（§2.3–2.5）只做浏览。
