# Jia, Irger et al. — VOICE: Visual Oracle for Interaction, Conversation, and Explanation

VOICE 是面向科学传播的对话式三维可视化系统：用户语音提问，一组分工不同的 GPT bot 判断意图，或回答分子生物学问题，或把指令转成相机、剖切面和场景导航操作，并按回答文本自动生成飞越动画。系统在 T4 噬菌体、SARS-CoV-2、HIV 三个分子模型上演示，由 3 位科学教育专家做定性评估；正文给出的量化结果主要是延迟：优化后 Explorer 约 1 秒、Pilot 约 2 秒、Encyclopedia 约 3–4 秒（§7.2）。所读为 arXiv v2 预印本，期刊正式版未获取。
