# Prasertsom, Jaroonpol & Rutherford — The Thai Discourse Treebank: Annotating and Classifying Thai Discourse Connectives

本文构建首个 PDTB 风格的泰语篇章语料：在 LST20 新闻语料的 384 篇文档、10,602 句上标注 18,374 个显式篇章连接词实例（33 种关系），并给出 148 个连接词、340 个“形式–义项”对的分类清单。基于该语料，作者比较词典、CRF/MaxEnt 与 WangchanBERTa 微调模型，最好结果为连接词识别 F1=0.96、叶级义项分类宏 F1=0.46。已阅读正文全部章节（§1–§7）及全部表格；未下载核对其 GitHub 语料文件。
