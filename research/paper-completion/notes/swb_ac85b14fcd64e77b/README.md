# Adjibi et al. — Repairing Trust in Domain Name Disputes Practices: Insights from a Quarter-Century's Worth of Squabbles

本文用 NER 模型从 1999–2024 年的 90,153 件英文 UDRP 裁决书中抽取结构化信息，度量 forum shopping、注册商/机构/仲裁员延迟、域名转移速度和利益冲突等七类行为。主要结论：约三分之一有代理的案件有 forum shopping 迹象，WIPO 多数仲裁员指定超时，部分恶意域名在转移裁决后仍被控制达 4 个月。已阅读正文全部章节和附录 A/B；图中只看了图注和正文给出的数值。
