# CAIL2018: A Large-Scale Legal Dataset for Judgment Prediction

这是一篇刑事判决预测数据集论文：给定判决书中的事实描述，预测法条、罪名和刑期。核心贡献是数据构建和基线，不是从完整判决书检索答案或生成司法意见。关键结果：CNN 罪名准确率 97.6%，但宏平均召回率仅 21.4%（Table 2），长尾罪名是主要难点。
