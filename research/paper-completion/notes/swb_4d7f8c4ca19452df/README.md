# Shahmohammadi, Veisi, Darzi — Persian Rhetorical Structure Theory

本文构建了首个波斯语 RST 篇章结构标注语料：从三家新闻来源选取 150 篇社论/评论文本（平均约 400 词），按英语 RST-DT 标注手册和粗粒度关系集手工标注；并基于开源 DPLP 训练了分割器与篇章解析器。在 10 篇测试文本、使用金标准 EDU 切分时，解析器的 span/核性/关系 F1 约为 78.7/64.0/44.3。已阅读全文（正文以图片表格为主，Tables 1–9 已渲染核对）。
