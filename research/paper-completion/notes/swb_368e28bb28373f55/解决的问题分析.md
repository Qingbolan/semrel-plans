# 解决的问题

本文主要是数据集构建，论文用以下监督任务验证标注是否够用（§4.6）。样本单位以招标公告的"章节"或"标的段落"为主。

| 任务 | 输入 | 输出 |
|---|---|---|
| 章节类型分类 | 章节标题+内容 | Object / Qualification / Accreditation / Judgment / Others 五类之一 |
| 标的性质分类 | Object 章节文本（全文或关键短语） | 工程、耐用品、消耗品、服务四类之一 |
| 标的正确性/允许性 | Object 章节文本 | 两个独立二值标签：抽取的标的是否正确、是否允许限制性要求 |
| 关键短语抽取（NER） | Object 章节文本 | 描述采购核心内容的短语片段 |
| 标的相似度 | 一对标的描述 | 相似/不相似（BERTScore>0.7 判为相似） |
| 红旗分类 | 公告资格相关章节 | 7 类违规资格要求的多标签 |

7 类红旗都是资格审查阶段的禁止性要求：场所证明、无拒付证明、实缴资本、财务资信、技术能力证书数量限制、良好实践证书、环境许可（Table 7）。

阅读者分析：红旗标签判断的是"文本中是否出现某类要求"，并不判定该采购是否实际构成舞弊；论文也没有给出公告级的舞弊结论标签。
