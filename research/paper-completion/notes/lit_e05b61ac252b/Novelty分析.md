# 贡献与评价

**作者列出的贡献**（§1，p.2）：

1. SUC 基准，评测多种结构理解能力；
2. 基于大量组合实验给出表格输入设计的经验指南；
3. 自增强提示，一种模型无关、利用 LLM 自身知识的两阶段提示方法，在五个表格推理数据集上验证。

**主要发现**（§5.2.1，pp.7–8）：HTML 比 NL+Sep 高 6.76%；去掉 1-shot 使总体准确率降 30.38%；分区标记与格式说明会削弱单元格查找，但对合并单元格检测等任务有利。

**评价**：作为较早系统比较表格序列化格式的实证工作，其价值在于问题拆分与变量控制；方法部分（两次调用、让模型先总结关键值）本身较简单，提升幅度为 1–6 个点。

阅读者分析（论文内部不一致）：
- 文本顺序的表述互相矛盾：§5.2.1 称“外部信息应放在表格之前”，并说放到表格后总体降 6.81%；但 Table 3 标题称最佳配置是“保持原始顺序，即把问题和陈述放在表格之后”，Table 2 标题又把 change order 定义为“放在表格之前”（阅读者分析）。
- 摘要称 FEVEROUS 提升 0.84%，但 Table 4 中 1-shot 为 75.56%，三种 SA 为 76.15%/76.32%/77.28%，差值为 0.59/0.76/1.72，均不等于 0.84；TabFact 2.31、HybridQA 2.13、SQA 2.72、ToTTo BLEU-4 5.68 与 Table 4 中“关键值与范围识别”行相符（阅读者分析）。
- 只评测 OpenAI 闭源模型，基准题目经 GPT-3.5 过滤（剔除其稳定答对的题），对同一模型存在选择偏差（阅读者分析）。

依据：§1、§3.3、§5、Tables 2–4，PDF pp.2、4、6–8。
