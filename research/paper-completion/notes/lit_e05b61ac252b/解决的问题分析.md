# 解决的问题

论文包含两部分问题。

**（一）SUC 基准：测量结构理解能力**（§3，pp.3–5）。能力分两类：分区与解析（Partition & Parsing），搜索与检索（Search & Retrieval）（Fig. 1）。每个样本输入一个序列化表格（可夹带描述、上下文、陈述或问题）加一个问题，输出为结构化短答案，按准确率计分：

| 任务 | 输出 |
|---|---|
| 表格分区 | 表格首尾 token (b_h, b_e) |
| 尺寸检测 | (行数 m, 列数 n) |
| 合并单元格检测 | 合并单元格的列索引（仅 ToTTo） |
| 单元格查找 / 反查 | 值→位置（可多个）/ 位置→值 |
| 列 / 行检索 | 指定列名或行号的值列表 |

（Table 1，p.4）

**（二）下游任务提示**（§4，p.5）：输入表格与下游问题，输出 TabFact/FEVEROUS 判定、HybridQA/SQA 答案或 ToTTo 描述。自增强提示调用 LLM 两次：第一次让模型生成格式说明、关键值与范围、或结构信息描述（各限 5 句以内，Table 6）；第二次把这段中间输出加入提示求解原任务（Fig. 3）。另一个手工选项是在输入中附加表格尺寸与合并单元格位置。

输出格式约束（如“用 | 分隔答案”）约 90% 被遵守，其余用正则解析（§3.4，p.5）。

依据：§3–4、Tables 1、6、Figs. 1–3，PDF pp.3–5、8。
