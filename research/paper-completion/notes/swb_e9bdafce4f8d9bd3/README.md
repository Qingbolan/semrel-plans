# Lu et al. — The Meta-Agent Challenge: Are Current Agents Capable of Autonomous Agent Development?

本文提出 Meta-Agent Challenge（MAC-v1）：让代码 agent（meta-agent）在沙箱、限时、限额条件下编写一个任务专用 agent 程序，再在隐藏测试集上打分，覆盖 AIME、GPQA/HLE、LiveCodeBench、SWE-Bench、Terminal-Bench 五个领域。39 个 meta-agent 配置中只有 5 个超过人工基线均值，其中 4 个由 Claude 系列驱动；33% 配置的三次运行标准差大于 0.1。已阅读正文全部与附录 A–D。
