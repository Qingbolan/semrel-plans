# 解决的问题

形式化（§3.1 式 (1)，p.4）：meta-agent M 可用开发集 Deval（N 条查询/任务）、返回 Deval 反馈的评测端点、模型与工具 API 套件 E、基类规范 B。输出是一个继承 BaseAgent 的程序 A（写到 `/workspace/agent.py`），目标是在隐藏 Dtest 上最大化 Score，同时满足开发阶段与测试阶段的时间与 API 预算。

被生成 agent 的接口（式 (2)，p.5）：`solve` 接收 (i, qi) 列表与超时 T，返回 (i, âi) 列表。工作单位因此有两层：外层是一次 meta-agent 开发会话（12 或 24 小时），内层是单个题目/任务的预测。

两阶段协议（§3.2，p.4）：开发阶段可读说明、改代码、向 Deval 提交并获得逐题正误与总准确率；结束后验证器扫描违规、在 Dtest 上执行、评分，得到 r∈[0,1]。测试集密钥只在验证阶段注入。

阅读者分析：这是"程序合成 + 黑盒优化"问题，评测对象是代码 agent 的研发过程，不是数据查询处理系统。
