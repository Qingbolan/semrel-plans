# 贡献与评价

论文声称的贡献（§1，p.2；§4.3，p.5；Table 1）：

| 方面 | Self-RAG / CoN / SAIL | REAR |
|---|---|---|
| 相关性评估 | 生成判断文本/特殊 token | 显式评估模块（线性打分头） |
| 训练 | SFT | SFT + 对比/偏好损失（双粒度融合） |
| 数据构造 | 依赖 GPT 标注 | 110M 的 cross-encoder 重排器打分 + 二值标签，无需 GPT API |

另两项训练技巧：双粒度相关性融合（二值交叉熵 + 基于分数差的成对偏好损失，Eq. 7–8）；抗噪训练（在训练中加入经改进 SimANS 采样的负例文档，Eq. 9、11）。作者称首次在 LLM 生成架构中加入显式评估模块（§1，p.2）。

架构上“打分头 + 分数嵌入”接近把 cross-encoder 重排器与阅读器合并到一个模型；其新意主要是工程组合与训练目标，而非新的检索理论。评估只在 7B 规模、单一基座（LLaMA2）上做，泛化到更大模型未验证。Table 5 消融显示去掉评估模块 Hit@1 从 66.79 降到 13.80，说明打分头是主要来源；但去掉 knowledge-consistency 的 EM 只降 0.22，验证策略的贡献较小（阅读者分析）

依据：§1、§4.3、Tables 1、5，PDF pp.2、5、7。
