# Luo, Lai, Wei et al. — BioRED: A Rich Biomedical Relation Extraction Dataset

本文发布 BioRED：在 600 篇 PubMed 摘要上标注 6 类实体（基因、疾病、化学物、变异、物种、细胞系，含数据库 ID）和 8 类实体对之间的文档级关系，并为每条关系标注"新发现/背景知识"。基准实验中 NER 严格 F1 最高 89.3%，关系抽取在"实体对"层面约 72.9%，加上关系类型降到 58.9%，再加新颖性只有 47.7%。已阅读正文全部章节和补充材料 A.1–A.4。
