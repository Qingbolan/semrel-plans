# problem

**形式化**（§3，PDF p.3）：智能体观察 o=(p,d)（提示 + 数据包），须提交一个框定 θ。本文只研究两个变量 θ=(T,M)：T 为预测目标，M 为评测目标及其隐含的输出形式（概率 vs 硬标签、排序 vs 逐点分数等）。C(o) 为在四项核查协议 Π 下 o 所允许的框定集合；完整源任务满足 C(o*)={θ*}，|C(o)|>1 即为歧义。理想行为：|C(o)|>1 时提问，C(o)={θ*} 时直接执行。“未标记误框定”= 不提问且提交 θ̂≠θ*。θ* 仅是继承自源任务的评分约定，不要求智能体从欠定观察中猜中。

**评测条件**（§5.1，PDF p.6）：Full（原任务）、Ambig.（歧义版本，无澄清通道，但不阻止智能体自行标记）、Ask（歧义版本 + 一次澄清：先可探索数据但不能拟合模型，写一个 ≤50 词问题或 NONE；Claude Haiku 4.6 作为受限 oracle 回答）。

**输出与评分**：智能体提交预测文件，用源基准原评测器打分并归一到 [0,1]；Δ_ambig=S_ambig−S_full，Δ_ask=S_ask−S_ambig，按任务宏平均；无效/超时记 0 并保留在分母。另做框定诊断：目标套件按提交优化的是哪一列归类，指标套件用 5 次 LLM 判定多数票 + 人工核验分为预期/替代目标/退化/无效。

工作单位：一个配对任务（完整版 + 歧义版）在某一条件下的一次智能体运行。

依据：[arXiv:2605.09698v1，32 页](https://arxiv.org/abs/2605.09698)，§3、§4.4、§5.1，PDF pp.3、5–6。
