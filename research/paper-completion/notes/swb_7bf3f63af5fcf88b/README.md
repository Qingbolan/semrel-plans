# Forster et al. — Assessing corporate sustainability with large language models: evidence from Europe

本文用 RAG + Llama-3.1-70B 从 STOXX Europe 600 公司 2014–2023 年的年报与可持续报告中，按 ESRS 定义的 501 个定量指标抽取数值，得到约 288 万次指标提问、84.8 万个数值的开放数据集，并据此分析 ESG 透明度与绩效趋势。与 Refinitiv 和人工标注对比的回归斜率均为 0.885（调整 R² 0.91/0.93）。已阅读正文、Methods 与验证部分；补充材料（SI S1–S4、补充图表）不在该 PDF 中，未阅读。
