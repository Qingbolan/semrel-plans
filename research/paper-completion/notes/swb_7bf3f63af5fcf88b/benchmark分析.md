# benchmark

本文不是基准论文，没有与其他抽取方法或基线做比较；"评测"指抽取质量验证与描述性统计。

- 与 Refinitiv（38 个指标、212,713 值）对比：OLS 斜率 β = 0.885（p<0.001），调整 R² = 0.91。
- 与人工标注（21 个指标、210 值）对比：β = 0.885，调整 R² = 0.93；按指标 IQR 标准化的宏平均 sMAE = 0.21（95% CI [0.08, 0.37]），sRMSE = 0.39（[0.15, 0.54]），bootstrap 2,000 次；IQR=0 的指标及一个仅 3 个观测的指标被排除在宏平均之外。
- 逐指标与 Refinitiv 相关性：多数指标正相关且显著，温室气体相关指标最高（补充 Fig.S2）。

局限（原文 Discussion）：结果为描述性、非因果；ESRS 被回溯应用到其强制实施前的报告，透明度分应理解为与当前 ESRS 的对齐度；报告为自我披露，无法识别策略性不披露；未抽取到值可能是未披露或抽取失败；样本为欧洲最大上市公司，未必推广到中小或非欧洲公司；抽取精度依赖报告质量，LLM 可能幻觉。作者在高文本质量子集上重复得到相近趋势，以排除"抽取质量随年份/公司规模变化"导致的伪趋势。

阅读者分析：验证只覆盖 38/501 和 21/501 个指标，且回归斜率/R² 衡量的是数值一致性，而非"是否披露"的检测精度（召回/精度），因此透明度分本身的误差没有被直接量化（原文提到补充 Table S6 有逐指标检测率，本次未读补充材料）。另外文中若干 Δ 与图中 Δ 口径不同：例如正文称能源消耗下降 37.7%，Fig.5e 标为 −36.7%；正文称游说支出"自 2019 年"增 747.6%，Fig.8b 的 2014–2023 Δ 为 −93.8%；性别薪酬差距正文为 −4.7 个百分点，图中为相对变化 −36.3%。
