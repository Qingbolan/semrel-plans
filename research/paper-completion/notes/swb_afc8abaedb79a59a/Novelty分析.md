# 贡献与评价

**论文声称的贡献与发现**（§1，p.2）：
1. MMST 很难：即便 GPT-4.1，识别准确率也只有 43.9%；
2. 开源模型与 GPT-4.1 差距明显：最好的开源模型 Qwen2.5-VL-72B 识别准确率约 29.8%、推理分 2.47/4；
3. 提出用多个推理型 LLM 组成评审团的评测框架，细分维度包括准确性、相关性、完整性和诊断简约性（Parsimony）；
4. 揭示泛化差距：LoRA 微调后 Qwen2.5-VL-3B 在已见实体上可达 28.4%，在未见实体上仅 14.6%，相差约 14 个百分点；
5. 部分可观测下的决策仍然困难：MMMT 上最好的模型决策准确率只有约 63%。

**数据构建**（§3.1、附录 C.2）：四步流程——清洗（人工抽查后用 GPT-4o-mini 过滤：转介他人、只追问不回答、表达不确定、表示无法帮助等对话，以及含失效 URL 的回答）→ 分类（识别 / 管理两个子集，抽取主实体名，标注是否依赖上下文）→ 改写（去除个人信息，用 GPT-4.1 根据专家给出的 URL 补充问题内容，用 GPT-4.1-mini 重写识别任务答案，使其格式统一并包含视觉描述与推理链）→ 划分。

**阅读者评价**：
- 主要贡献是数据（真实咨询来源、长尾实体、clarify-or-respond 决策点）以及多评审员的评测流程，而不是新模型。
- 金标准答案经过 GPT-4.1/4.1-mini 改写和补充，并非纯粹的专家原文；这有利于格式一致，但可能引入模型风格偏向（例如偏向 GPT 系列表述）。论文没有专门分析这种偏差。
- MMMT 决策点由 LLM 自动构造，以“后续用户是否补充了信息”作为追问标签的依据；这只是专家行为的代理，专家实际追问的原因可能更复杂。
- 实体数量的表述不一致：摘要写“超过 7,000”，§2.1 写全语料“超过 7,600”、基准集 6,856；附录 C.1 把 Standard 集的 4,485/1,732/639 也说成“数据集包含超过 7,000 个实体”。
