# 评测与边界

**指标**（§4，PDF p.5）：分类用 P@n、R@n、S@n（至少命中一个真实标签的报告比例）和 EM（所有标签全对的比例）；LDA 用人工判定的 P 与 S；摘要用 ROUGE-1/2/L 的精确率与召回率。

**实验 1（BERT 多标签分类，Table 1，PDF p.6）**：

| 指标 | ASRS 人因 | CADORS 事件类别 |
|---|---|---|
| P@1 / P@2 / P@5 | 0.67 / 0.56 / 0.37 | 0.88 / 0.56 / 0.24 |
| R@1 / R@2 / R@5 | 0.34 / 0.53 / 0.81 | 0.77 / 0.92 / 0.98 |
| S@1 / S@2 / S@5 | 0.67 / 0.80 / 0.92 | 0.88 / 0.95 / 0.99 |
| EM | 0.20 | 0.70 |

正文把 0.92 称为 S@3，而表中是 S@5（阅读者分析）。ASRS 只看样本超过 1,000 的类别时 EM 也只升到约 30%；作者归因于标注一致性低、每篇标签更多、自报告来源及类别边界不清（§5.1）。

**实验 2（LDA，§5.2、Table 3，PDF pp.6–7）**：40 个主题中 32 个被判为"好"主题。65 份抽样报告上 P@1/2/3 = 70.8/56.2/46.2%，S@1/2/3 = 70.8/83.1/87.7%。作者认为它不适合用于推断原因之间及因果之间的关系。

**实验 3（BART 摘要，Table 4，PDF p.8）**：ROUGE 精确率 R1/R2/RL = 59.7/39.0/52.8，召回率 49.4/32.1/43.8；高于 BART 在 CNN/DailyMail 上的召回（44.2/21.3/40.9），作者归因于 NTSB 语言同质化。

**边界**：无同划分的基线比较；LDA 评估样本小，主题好坏判断主观；摘要只用 ROUGE，未做专家评估；分类质量受原始标注一致性限制（§5–6）。阅读者分析：跨数据集比较 ROUGE 并不能说明模型更好。
