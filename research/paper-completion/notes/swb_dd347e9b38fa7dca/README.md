# Herrero-Zazo et al. — The DDI corpus: An annotated corpus with pharmacological substances and drug–drug interactions

本文描述 DDI 语料：792 篇 DrugBank 药物相互作用描述文本与 233 篇 MedLine 摘要，共 1,025 篇，人工标注 18,502 个药理物质提及（4 类）和 5,028 个句内药物–药物相互作用（4 类，含药代动力学 PK 与药效学 PD）。实体一致性 Kappa 多在 0.80 以上，MedLine 部分的关系一致性仅 0.55–0.73。该语料是 SemEval-2013 DDIExtraction 的金标准；系统评测结果只在摘要中概述，详见另一篇任务论文。已读正文 §1–§6 与 Tables 1–5。
