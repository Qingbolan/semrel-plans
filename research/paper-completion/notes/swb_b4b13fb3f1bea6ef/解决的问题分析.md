# 解决的问题

**任务**：被主张违反条款预测（alleged violation prediction），多标签文本分类（§3，PDF p.4）。

| 要素 | 内容 |
|---|---|
| 输入 | 一个 ECtHR 案件的事实段落列表 D=[P1…PN]（按时间顺序编号） |
| 输出 1 | 40 个可违反 ECHR 条款中，申请人主张被违反的条款集合（多标签） |
| 输出 2 | 一个段落级硬掩码 Z，选出最能支撑预测的事实段落（理由） |
| 处理单位 | 案件（文档）；理由单位为整段事实 |
| 约束 | 稀疏度阈值 T（默认 0.3，即约选 30% 段落，取自银标准理由平均稀疏度） |

模型训练时看不到主张条款，只看事实；法院最终是否认定违反（violated articles）虽包含在数据集中，但本文实验不使用（§3，PDF p.4）。

理由是“构造式”产生的：分类器只看被掩码选中的段落（hard attention + max-pool），而不是事后用显著性方法解释（§1、§4.1，PDF pp.1、5）。

**评测三方面**：分类表现（micro-F1）、忠实度（sufficiency / comprehensiveness，借自 ERASER）、理由质量（与银/金标准比较的 mRP 与 F1）（§5，PDF p.7）。

依据：§3–§5，PDF pp.4–7。
