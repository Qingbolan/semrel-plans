# 贡献与评价

**原文所述贡献**：
1. 在一个 text-to-SQL 基准中同时覆盖范围、附着、模糊三类歧义，并给出自然语言写的解读（Table 1，p.7）。
2. 受控数据库生成。流程是：选领域 → 按歧义模板用 OpenChat-7B 生成关键概念与关系 → 生成 CREATE TABLE 与 INSERT INTO。不可执行或不符合所选配置的生成结果被拒绝，再人工过滤不自然的数据库。1,883 个概念预测中保留 881 个（47%），最终得到 846 个数据库（§3.3，pp.5–6）。
3. 问题与解读由 Prolific 众包标注者撰写。范围和附着歧义的 SQL 按模板自动生成，并执行验证结果非空且互不相同；模糊问题的 SQL 由 10 位专家从头写（§3.4，pp.6–7）。
4. 对 6 个 LLM 做 Prompt 和 Beam 两种设置的评测，并分析模型偏好哪种解读（§4）。

**阅读者分析**：
- 新意在于“让数据库结构本身支持歧义”的构造方法，而不是事后改写现有库。
- 数据库较小（平均 4–6 张表、每表 3–5 行），可以整库放进提示。这让评测聚焦在语言歧义上，但离真实规模较远，作者在 §5 也承认这一点。
- 歧义类型不全：未覆盖词汇歧义（如 Mississippi 是河还是州）（§3.2，p.4）。

依据：[arXiv:2406.19073v2，29 页](https://arxiv.org/pdf/2406.19073v2)，§3.3–3.5、Table 1，PDF pp.5–7；§5，p.10。
