# workload

**场景池**：用于报告结果的数据集共 953 个 scene（§3.6）。

**两套考试（§4、App. A.10、Table 17）**
| 项 | 真实考试 | 困难考试 |
|---|---|---|
| 任务数 | 100 | 200 |
| 抽样方式 | 从 953 场景池按 App. A.7 的经验分布加权 | 固定可识别性与图结构分层配额；聚焦识别、偏差诊断、R2/R3 效应估计 |
| 数据驱动 / 纯符号任务 | 51 / 49 | 167 / 33 |
| 观测变体（仅数据驱动任务） | clean 22、proxy 10、proxy_hard 19 | proxy 24、proxy_hard 55、proxy_severe 88 |
| 结果变量连续/二值 | 59 / 41 | 118 / 82 |
| 固定真值二值池 | n=34 | n=97 |

困难考试抽样前，用 Claude Fable 5.1 对 686 个候选场景各做一次筛查，剔除 67 个触发安全拒答的场景，再从剩余 619 个中按配额抽样（App. A.10，p.30）。真实考试未做此筛查。

**执行设置（§3.7、App. A.18）**：mini-swe-agent，模型只能发 bash 命令；断网的 Singularity/Docker 容器，固定版本的 Python 数据科学栈；每任务新开对话；真实考试每任务至多 100 次模型调用、困难考试 150 次，成本上限约 10–15 美元，单命令超时 120 秒。12 个模型（5 闭源、7 开放权重），每套考试完整重复 3 次；另有 45 题小考，对 3 个模型各跑 10 次以估计 pass@k 与 pass^k。

阅读者分析：工作单元是"一个因果数据科学问题 + 一个小型表格数据目录"，没有多表关系型数据库，也不是 SQL 查询；与语义查询处理的联系主要在"何时弃答"和"在有噪声的观测上估计"两方面。

依据：[arXiv:2607.08093v2，74 页](https://arxiv.org/abs/2607.08093)，§3.6–3.7、§4，PDF pp.4–8；App. A.10、Table 17，PDF pp.30、33；App. A.18，PDF p.61。
