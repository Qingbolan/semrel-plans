# novelty

原文声称的贡献（§1，pp.2–3）：
1. 证明现有数据科学基准存在不读数据也能求解的捷径；
2. 统一、可复现的框架，单一 API 跨基准执行；
3. DSGym-Tasks：审核并标准化代表性基准、过滤捷径题，新增 DSBio 与 DSPredict；
4. 对前沿闭源和开源模型的系统评测，归纳出领域扎根错误、简单化偏好与缺乏验证；
5. 用执行扎根的轨迹合成做 SFT，并发布小模型。

**捷径过滤**的具体规则：去掉数据文件后让 5 个前沿 LLM 作答，若 ≥3 个答对则剔除（§4.1，p.6）。这是可直接复用的数据依赖性检验。

阅读者分析：框架层（容器、Jupyter、只读挂载）是工程整合，新意有限；真正的增量是捷径过滤协议和 DSBio。需要注意捷径过滤用的是“当前”前沿模型，判定会随模型更替而漂移；DSPredict-Hard 与 MLE-Bench 的区分主要在时间更新和仍可提交（§4.3，p.8），而不是任务形式上的不同。合成训练数据只从 QRData 与 DABStep 的种子出发，SFT 后在这两个基准上的提升可能部分来自分布接近，原文没有对此做隔离。

依据：[arXiv:2601.16344v1，37 页](https://arxiv.org/pdf/2601.16344)，§1、§4.1、§4.3、§6.2，PDF pp.2–3、6、8、12。
