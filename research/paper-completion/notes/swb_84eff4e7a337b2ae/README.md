# Wang et al. — MAVEN: A Massive General Domain Event Detection Dataset

MAVEN 是基于英文维基百科和 FrameNet 构建的通用领域事件检测（ED）数据集。它包含 4,480 篇文档、111,611 个事件、118,732 个事件提及和 168 个层级化事件类型，事件数约为 ACE 2005 的 20 倍以上。六个复现的神经 ED 模型在 MAVEN 上的 F1 为 60.6–67.8，明显低于在 ACE 2005 上的结果。已阅读正文 §1–7；附录 A–D（复现细节、ACE 映射、层级 schema、框架映射）未细读；未复现实验。
