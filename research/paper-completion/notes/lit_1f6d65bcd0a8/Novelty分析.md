# 贡献与评价

论文陈述的贡献（§1，p.2；§7，pp.12–14）：

1. 设计了支持文本 + 视觉双向交流的 LLM 读图助手：用户可把图上标注发给模型，模型也可回以同步高亮或并排比较的图表标注，并推荐追问。
2. 26 人被试内对照实验，比较 web 搜索、仅文本 LLM、文本+视觉 LLM 三种辅助。
3. 归纳了视觉提问的三类意图（探索型、定向型、确认型）和视觉回答的两种作用（同步型、比较型）（§6.2，Fig. 6）。
4. 发现“感知表现”与“实际洞察”冲突，以及两类使用模式：数据分析经验少/动机低者更依赖 LLM，经验较多者把 LLM 当辅助（§6.3）。

阅读者分析：系统层面的新意主要在交互设计（标注 ↔ JSON ↔ 代码查询的管线），LLM 部分基于现成 CSV agent 模板；论文核心价值是实证发现，尤其是“偏好最高的条件反而洞察更少”这一过度依赖信号。样本量小（26 人、每格约 8–9 人次）、图表仅 3 种，且未评测 LLM 回答准确率或幻觉率，因而结论属于探索性用户研究，不是模型能力基准。

依据：§1、§4、§6–7，PDF pp.2、4–14。
