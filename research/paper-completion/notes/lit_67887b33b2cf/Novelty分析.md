# 贡献与评价

原文列出三点贡献：

1. 提出用 KG 外部知识增强 LLM CTA 提示的问题，以及端到端框架 RACOON。
2. 探索从 KG 检索的信息粒度（实体标签与实体三元组），并给出检索后的压缩和序列化方法。
3. 实验显示 RACOON 在不同设置与检索方式下均优于普通 LLM 推理，micro-F1 最高提升 0.21。

阅读者分析：方法本身很轻，是“实体链接 + 类型统计 + 提示模板”，价值在于用一个简单可控的对照说明 KG 上下文对 LLM CTA 有用，且实体链接质量是关键瓶颈。局限明显：只比较一个普通 LLM 基线，没有与 CHORUS/ArcheType 完整系统、KGLink 或精调 PLM 对比；只用 GPT-3.5 和一个数据集；未报告成本或 token 开销。论文称与示例/后处理类方法正交，但没有组合实验。

依据：[arXiv:2409.14556v2](https://arxiv.org/pdf/2409.14556v2)，§1、§3，PDF pp.2–4。
