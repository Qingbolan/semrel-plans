# 贡献与评价

**原文声称的贡献**（§1，p.3）：

1. 多智能体 FSM：MDP 推理智能体生成推理链；改写智能体抽取和增强 SQL 候选；助理智能体做语法和等价校正；决策智能体基于代价变化、计划特征、资源利用等四维报告决定是否继续（Table 1、Algorithm 1，pp.5–6）。
2. 改写中间件：从官方文档和 Stack Overflow 收集 3,432 个问答单元，经过点赞过滤、LLM 共识判定和多数投票保留 241 个，再用 BM25 检索（Table 2：连接 122、谓词 21、CTE 20、常量 2、其他 76）；混合 SQL 校正器先用 SQLSolver，结果未知时再用 LLM 迭代校验，超时则退回原查询；以及智能体记忆缓冲（§5，pp.6–8）。
3. 提示注入：在算子级选择 HashJoin、NoNestLoop、NoMergeJoin、Rows，以及作者新增的 NOT_MATERIALIZE 提示（Table 3，p.8）。

**阅读者分析**：与 LLM-R2、R-Bot 等“由 LLM 选规则”的方法相比，QUITE 让 LLM 直接生成 SQL，并用工具和反馈兜底，这是方法层面的主要区别。正确性仍然依赖 SQLSolver 的覆盖范围和 LLM 自我判断。实验中的“等价率”是比较执行结果得到的（§7.1，p.9），不是形式化证明。

依据：§1、§4–6、§7.1，PDF pp.3–9。
