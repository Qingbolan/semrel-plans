# 贡献与评价

原文列出三项贡献（§1，PDF p.2）：（1）把 EM 表述为条件生成，显示 FlanT5-base 同域上与 Ditto 相当，但二者在分布外都大幅下降；（2）用大模型生成的 CoT 式解释增强训练集，显著提升分布外表现；（3）对解释做系统消融，分析哪些成分影响下游效果。

**方法要点**：每个数据集类型用两个作者手写解释的 ICL 示例（match/not match 各一）提示 Mistral-7B-Instruct 或 Alpaca，生成 5–128 token 的解释（top-k=50、top-p=0.95），每条约 2–5 秒（Mistral）或 7–12 秒（Alpaca）（§2.3，PDF p.5；附录 C）。

**评价（阅读者分析）**：
- 思路属于已有"推理蒸馏"路线（Ho et al., 2022 等）在 EM 上的应用；新意主要在 EM 分布外评测框架与消融，而非新算法。
- 消融 D 中与实例无关的固定解释仍能带来部分提升，作者在 Limitations 中承认无法说明解释的哪部分真正有用（PDF p.9），因此"蒸馏推理"的机制解释并不充分。
- Figure 2 提到 GPT-* 的 API 成本，但正文主表 Table 2 只报告 Alpaca 与 Mistral 生成的解释；GPT 的对应结果在正文中未见。
- 只用一个学生模型 FlanT5-base，未比较其他规模。
