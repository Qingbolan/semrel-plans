# Kłeczek et al. — AvalancheBench: Evaluating Enterprise Data Agents Through Latent World Recovery

本文提出把企业数据分析评测视为"潜在世界恢复"：先由专家声明式地指定潜在结构 Z（客群、驱动因素、时间事件），再生成表格与评论观测 X，并按从 Z 导出的评分细则衡量 agent 恢复了多少结构。在一个电商用例（20 产品、23k 交易、10k 评论、18 条细则）上，Cortex Code + Claude Opus 4.7 的最佳配置（Orchestrator）仅得 25.9%。全文 4 页已全部阅读。
