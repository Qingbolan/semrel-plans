# Cheng et al. — MDACE: MIMIC Documents Annotated with Code Evidence

MDACE 是第一个公开的医疗编码证据数据集。专业编码员在 MIMIC-III 病历子集上，为 ICD-10（自动映射到 ICD-9）和 CPT 编码标注了支持性文本证据：302 份住院（Inpatient）病历有 3,934 个证据片段，52 份 Profee 病历有 5,563 个证据片段。基线基于 EffectiveCAN，其中监督注意力在出院小结上的 token 级 F1 最好，为 43.0。已阅读正文 §1–8；附录 A–F（编码体系、映射流程、分歧示例、参数、指南、输出示例）未细读；未复现实验。
