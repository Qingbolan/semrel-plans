# 解决的问题

**形式化**（§2.1，p.3）：数据集原为 `D = {(q_i, c_i, a_i)}`，q 为指令、c 为电子表格、a 为在 c 上执行 q 后的结果表格。加入多测试用例后变为 `D = {(q_i, {(c_ij, a_ij)})}`（§2.2，p.5）。

**输入**：一条自包含指令（由 GPT-4 从帖子整理并经人工核对，附带答案位置约束）和一个 XLSX 文件。

**输出**：模型生成的代码解法 `s_i`（评测中用 Python 操作文件），把它应用到每个测试用例表格上得到结果表格。数据集不包含参考解法，只判最终结果（§2.1）。

**两类操作**（§2.1–2.2，pp.3–4）：

- 单元格级：修改若干单元格，答案位置写成具体范围，如 `D2:D6`；
- 工作表级：修改整个表，答案位置为整张表范围，如 `A2:D6`。

**判定**：对答案位置中的单元格做精确匹配。一次模型推理生成一个解法，作用于该指令的全部测试用例（§2.4，p.7）。

**防泄露**（§2.2，p.5）：改写原帖问题、修改表格数值生成新用例、移动表格数据与答案位置，使帖子中的原解法不能直接套用。

**软件无关性**：只选聚焦单元格值的问题，文件统一为 XLSX，并允许任意方式（如 Python）操作文件（pp.5–6）。

依据：§2.1–2.4，pp.3–7。
