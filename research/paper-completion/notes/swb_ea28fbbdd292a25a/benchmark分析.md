# 评测与边界

**评测内容**：论文没有基线模型、没有自动指标，也没有数据划分；可报告的“结果”只有标注一致性和语料统计（§4–5）。

**实验 1（标注一致性）**：两名标注者间 Krippendorff α，单元类型 64.8%，支持关系 44.1%（§4，p.4）。类型分歧主要在 VALUE vs TESTIMONY（证言中夹杂主观评价）和 VALUE vs FACT（同一单元兼有主观与客观表达）。作者指出更细粒度的切分可减少分歧，但会增加自动切分难度。

**实验 2（语料统计）**：见 Table 2 与 Figure 2；支持比例随客观性升高而下降，POLICY 51% 有支持、VALUE 28%（§5）。

**原文承认的局限**：约 75% 支持关系位于相邻单元，这可能部分源于标注者更容易发现邻近关系，真实分布未必如此偏斜（§5，pp.4–5）；每个领域单独建库成本高，需要领域迁移（§6）。

**阅读者分析**：单一规则、单一网站的数据，领域和人群有限；REFERENCE 仅 32 个、Evidence 仅 46 条，稀有类别难以支撑可靠学习；关系 α=44.1% 使关系层上限受限。使用该语料做评测需自行定义划分与指标。

依据：[LREC 2018，ACL Anthology L18-1257，6 页](https://aclanthology.org/L18-1257.pdf)，§4–6、Table 2、Figure 2，PDF pp.4–5。
