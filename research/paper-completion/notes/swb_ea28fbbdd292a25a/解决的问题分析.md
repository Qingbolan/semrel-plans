# 解决的问题

**任务定义**：给定一条用户评论，识别其中的基本单元（elementary unit）及类型，并识别单元之间的支持关系；据此判断论证是否可评估，以及缺少何种支持（§3.3，p.3）。

| 项目 | 内容（原文） |
|---|---|
| 输入 | 单条 eRulemaking 评论文本（去除问候、署名等非论证部分） |
| 样本单位 | 基本单元 = 一个句子或从句；多个独立从句或含 because 类从属从句时再切分（§4，p.3） |
| 单元类型 | POLICY、VALUE、FACT、TESTIMONY、REFERENCE 五类（§3.1） |
| 关系 | Reason（提供理由）、Evidence（证明真伪，仅可由 TESTIMONY 或 REFERENCE 充当）（§3.2） |
| 输出 | 每单元的 ID、文本、类型、作为理由/证据所支持的单元 ID 列表（Table 3） |

**可评估性规则**（Table 1）：POLICY、VALUE 需要 Reason；FACT 需要 Reason 或 Evidence；TESTIMONY 可以有支持但不强制。当论证中每个命题都有至少一个合适类型的显式前提时，论证可评估。

阅读者分析：标注只在单条评论内部进行，没有跨评论关系；可评估性是由类型与关系推导的规则结果，论文没有直接标注“可评估/不可评估”标签，也没有报告评论层面可评估比例。

依据：[LREC 2018，ACL Anthology L18-1257，6 页](https://aclanthology.org/L18-1257.pdf)，§3–4、Tables 1、3，PDF pp.2–5。
