# Zhang et al. — DataPuzzle: Breaking Free from the Hallucinated Promise of LLMs in Data Analysis

立场/愿景论文。作者反对把 LLM 当作“Prompt-to-Answer”式的黑箱分析器，提出概念性多智能体框架 DataPuzzle：分解问题、为子问题选择结构（表/图/树）、检索并抽取成结构化数据，再在结构上推理，全程由 Thinker 监督。原文明确说这是范式而非完整方案，没有实现或定量评测。已读全部正文（PDF pp.1–9）。
