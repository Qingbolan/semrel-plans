# 贡献与评价

原文列出三项贡献：归纳 LLM 分析的断层与可信多模态分析的需求（§2）；提出 think-extract-verify 迭代式 agent 框架 DataPuzzle（§3）；列出开放问题（§4）。

DataPuzzle 的流程：问题分解 → 为每个子问题选择结构 Si → Seek 检索相关片段 → Extraction 抽成结构化数据 Di′ → 在结构上推理并组合答案（§3.2）。

Thinker 是中心编排者，检查子问题是否合适、结构是否匹配、信息是否充分、抽取结果是否一致；必要时触发局部重检索或全局重规划（§3.1–3.2）。

评价：框架接近已有的分解—检索—抽取—推理 agent 流水线（如作者引用的 SYMPHONY、VerifAI），新意主要在于强调先抽成显式结构，并把六项需求逐一映射到各阶段（阅读者分析）。

§3.3 的映射全部用 can、could、may 表述，属于未经验证的设计主张（阅读者分析）。
