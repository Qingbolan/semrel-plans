# 解决的问题

**输入**：一份数据集（CSV，场景中另有地图 JSON）和一句高层分析目标，例如"分析影响汽车燃油效率的因素"（§III-C1，p.3；§V，p.8）。

**输出**：一个以任务流图组织的交互式 VA 系统——多个任务卡片（交互图 + 富文本 insight）、用户选择合并的联动多视图、以及汇总 insight（§III-C2、§IV-B，pp.4–7）。

**核心原语**（§III-C1，pp.3–4）：

| 原语 | 定义 |
|---|---|
| task | ⟨type, data variables, method, progress⟩；type 如找极值、离群、变点、趋势 |
| insight | ⟨type, parameters, data variables, data values⟩；如 trend + increasing |
| visualization | ⟨type, encoding, interaction, coordination⟩，用 Vega-Lite 表示 |

任务流是有向复合图 G=(V,E)，节点是任务，边分"推荐"（面向目标、拓宽范围）和"分解"（面向具体任务、细化）两类（§III-C2，p.4）。

**工作单位**：一次任务执行 = 生成数据分析代码 + 可视化代码（第一轮），再执行代码生成结构化 insight（第二轮）（§IV-A2，pp.5–6）。分解采取"按需"策略：先执行，执行器之后由 LLM 给任务完成度打 1–10 分，判定需要时才分解为不超过 n 个子任务，子任务以 AND（并行，多代理）或 DOWN（串行，单代理）连接，深度受 kmax 限制（Prompt Template 3，p.7）。
