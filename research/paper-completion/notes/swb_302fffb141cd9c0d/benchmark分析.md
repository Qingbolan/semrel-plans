# 评测与边界

**实验 1（主结果，Table 2，准确率 %）**：

| 模型 | Val | Test | Test simple | Test complex | Small test |
|---|---|---|---|---|---|
| BERT 无表格 | 50.9 | 50.5 | 51.0 | 50.1 | 50.4 |
| Table-BERT 横向 拼接 | 50.7 | 50.4 | 50.8 | 50.0 | 50.3 |
| Table-BERT 横向 T+F 模板 | 66.1 | 65.1 | 79.1 | 58.2 | 68.1 |
| NSM（LPA 引导 ML+RL） | 63.2 | 63.5 | 77.4 | 56.1 | 66.9 |
| LPA-Ranking（含标题） | 65.1 | 65.3 | 78.7 | 58.5 | 68.9 |
| 人类 | - | - | - | - | 92.1 |

结论：直接拼接的线性化学不到东西，自然语言模板是 BERT 生效的关键；横向扫描优于纵向；LPA-Ranking 优于投票；LPA 无外部预训练即与 Table-BERT 相当（§4 Results）。

**实验 2（人工诊断，dev 抽 100 条）**：仅 58% 陈述实体链接完全正确；链接正确时程序搜索召回 51%，故正确程序覆盖率低于约 30%，存在严重的虚假程序问题。Table-BERT 一致性差，会错简单例却对难例（§4 Results）。

**实验 3（附录错误分析，200 条 val）**：语言推理类 BERT 明显更好，LPA 接近随机；Count、Superlative 等高阶逻辑 LPA 更好；推理步数集中在 4–7（附录、Figures 11–12）。

**边界**：两类方法各有缺陷，如何结合仍是开放问题；LPA 依赖手工 API 与实体链接（§4）。评测只报准确率，无置信区间。

依据：[ICLR 2020 会议版，arXiv:1909.02164v5（2020-06-14），25 页（含附录）](https://arxiv.org/pdf/1909.02164v5)，§4、Table 2，附录 Figures 11–12，PDF pp.7–8、15–17。
