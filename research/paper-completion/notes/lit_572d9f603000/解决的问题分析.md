# 解决的问题

| 要素 | 内容 |
|---|---|
| 输入 | 一个 SR 骨干（SASRec 或 HSTU）、一个数据集（已冻结的数据预处理流程）、以 markdown 文件定义的动作空间与沙箱协议（§3.1） |
| 代理可改动 | 标量超参数以及“选定的”结构开关和训练技巧（如相对位置偏置、SwiGLU、嵌入绑定、双向注意力等案例，§4.4） |
| 工作单位 | 一次试验 = 一次训练加验证集评估；每次试验后一次 LLM 反思 |
| 输出 | 在验证集 NDCG@10 上选出的最终配置，仅该配置在测试集上评估；另输出一份 Cognition Summary 写入长期记忆 |
| 约束 | 测试集对代理完全隐藏，数据准备流程不可变（§3.1） |

成本模型（§3.3，式 1–2）：AutoML 成本 = |S|×C_train；代理成本 = |S_effective|×C_train + |S_trials|×C_LLM_reflection，作者称为“非正式”表述。

阅读者分析：可改动的结构选择范围由沙箱文件定义，但论文正文未列出完整动作空间与基线配置空间（网格 729 个配置）的具体维度，因此代理与 HPO 基线的搜索空间并不严格相同。

依据：[arXiv:2606.03221v1，7 页](https://arxiv.org/abs/2606.03221)，§3.1–3.3、§4.1、§4.4，PDF pp.2–5。
