# ChEMU-Ref: A Corpus for Modeling Anaphora Resolution in the Chemical Domain

ChEMU-Ref 研究化学反应描述中的指代和桥接：同样叫“混合物”的两处文本可能表示不同加工状态，不能只按词面合并。本文实验使用 220 个片段，而非计划中的 1,500 个最终共享任务片段。关键结果：联合模型总体关系 F1 为 68.6，加入 ChELMo 后为 73.1（Tables 2、4）。
