# 贡献与评价

**原文声称的贡献**（Abstract；pp.3–5；Conclusions p.29）：

1. 据作者所知，PV 领域首个同时标注药物、疾病和受试者三类实体并以事件方式连接它们的免费语料。
2. 事件结构允许嵌套成因（DDI/Combination 作为 AE/PTE 的 agent）和人群信息；415 个事件（约五分之一的 AE+PTE）的 agent 本身就是事件，约 28% 的事件有 has_subject（p.22）。
3. 提供详细指南和 IAA 数据；用 HYPHEN 自动添加概念 ID（"银标准"，未经人工核对）。
4. 用现成工具训练基线，表明自动识别可行。

**阅读者分析**：

- 新意主要在于把 BioNLP 式事件标注迁移到 PV 领域，而非提出新算法；基线均为默认配置的现成系统。
- 语料主体由单个标注者完成，第二标注者只在中途独立标注了 150 篇（四分之一）用于 IAA，且 IAA 后指南被修订、主标注者复查旧标注（p.12）；因此报告的 IAA 反映的是修订前的一致性，整体标签质量没有逐篇双标。
- 概念 ID 为自动结果，作者在未来工作中计划人工核对（p.29），使用时应视为噪声标签。
- 同句约束会漏掉部分信息：20 篇样本中 278 个事件，18 个事件因隐式指代未标，作者估计若跨句标注事件数仅增约 6.5%（pp.22–25，Table 21）。

依据：pp.3–5、12、22–25、29。
