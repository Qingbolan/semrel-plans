# 解决的问题

**标注任务定义**：输入一篇 MEDLINE 摘要，输出五个层次的结构化标注（pp.4–11）：

| 层次 | 内容 |
|---|---|
| 实体 | Pharmacological_substance、Disorder、Subject；允许不连续跨度（Table 2，Fig. 1） |
| 事件 | Adverse_effect（AE）、Potential_therapeutic_effect（PTE）、Combination、DDI，带触发词与语义角色 has_agent / affects / has_subject / has_participant（Table 3） |
| 事件属性 | Negated、Speculated（二值）、Manner（Low/High/Neutral），可标注提示词（Table 5） |
| 关系 | Subject_Disorder（受试者给药时所患疾病）、is_equivalent（同句内同一概念的不同名称） |
| 共指 | 仅把作为事件参与者的代词性表达（如 it、this drug）链接到邻近句中的实体 |

**约束**：事件触发词和参与者必须在同一句内；AE 至少一个 has_agent，PTE 还须至少一个 affects 或 has_subject，DDI/Combination 至少两个 has_participant（Table 4，p.8）。AE/PTE 的 has_agent 可以是另一个 DDI 或 Combination 事件，从而表达多药成因（p.8）。

**自动任务**：在固定划分上做实体识别（NERSuite）和事件抽取（EventMine，输入为已识别实体的文本），见 pp.25–29。

依据：Methods，pp.5–12，Tables 2–5；Results pp.25–29。
