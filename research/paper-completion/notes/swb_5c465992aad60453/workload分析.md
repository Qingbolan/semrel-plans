# 工作负载

**来源**：在保密协议下获得 Cochrane 系统综述（RM5 XML 格式），从其 RoB 表中解析（研究引用、偏倚类型、风险标签、引文）；从 PubMed/PMC 获取被这些综述引用的开放获取文章，共 7,334 篇（§4.2，PDF p.6）。

**构建与清洗**（§4.2，PDF pp.6–7）：

| 步骤 | 数量 |
|---|---|
| 一名作者校验的实例 | 23,873 |
| 因解析错误或答案不符剔除 | 6,915 |
| 训练集 | 13,554 |
| 测试集 | 3,404 |

阅读者分析：23,873 − 6,915 = 16,958 = 13,554 + 3,404，比例约 80/20，与 Figure 2 一致（阅读者分析）。划分按偏倚类型分层；原文未说明是否按试验或综述分组划分，同一篇试验的不同问题可能同时出现在训练和测试集中。

**标签**：二分类，低风险为正类。低风险多于高/不明风险；选择偏倚实例最多（两个信号问题）。分布只在 Figure 3 给出，正文无具体数字（§4.2、§7，PDF pp.7、14）。

**局限**：校验者是对 Cochrane RoB 工具有一定了解、但缺少系统综述经验的计算机科学人员；提及试验方案（protocol）细节的实例被剔除，因为只使用了已发表论文（§7，PDF p.14）。
