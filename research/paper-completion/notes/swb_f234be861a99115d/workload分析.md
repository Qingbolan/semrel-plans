# 工作负载

数据来自剑桥法律语料库（CLC）中的 UKET 书面判决（Table 1）：

| 项目 | 数值 |
|---|---|
| 判决（案件）数 | 13,253 |
| 诉求数 | 33,158，平均每个判决 2.50 个 |
| 训练集 | 32,030（96.6%），DeepSeek 抽取的弱标签 |
| 测试集 | 1,128（3.4%），专家人工标注金标准 |
| 类别分布 | Win 39.5%、Loss 48.8%、Other 11.7% |
| 测试集泄露诉求 | 289（25.6%），两位标注者中至少一人判为泄露 |

划分按判决进行，同一案件的诉求不会同时出现在训练和测试中。评测遵循“在合成标签上训练、在真实标签上测试”。泄露审计对象为 TF-IDF 模型的 5,000 个三元词特征，最终“污染特征集”为 200 个（4%）。

依据：[arXiv:2607.04261v2](https://arxiv.org/pdf/2607.04261v2)，§2.1–2.4、Table 1，PDF pp.5–8。
