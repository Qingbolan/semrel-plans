# 评测与边界

**模型**：TF-IDF（一元/二元/三元词，前 5,000 特征）+ 逻辑回归或线性 SVM；冻结的 all-MiniLM-L6-v2 句向量 + LinearSVC；DeepSeek 零样本和 5 示例少样本（温度 0）。基准为随机猜测、最频繁类和两位法律博士生在同样输入下的“匹配输入人类基准”。

**实验 1（总体表现，Fig.1）**：监督模型最高约 0.623，零样本/少样本 LLM 为 0.47/0.54，人类基准约 0.51；所有模型都高于随机基准。

**实验 2（泄露差距，Fig.2，已渲染核对）**：

| 系统 | Leaky 减 Clean 的 Macro-F1 |
|---|---|
| DistilBERT+SVM | +0.11 |
| 零样本 / 少样本 LLM | +0.07 / +0.06 |
| TF-IDF 三元词 / 二元词 | +0.05 / +0.05 |
| TF-IDF 一元词 | −0.01 |
| 人类基准 1 / 2 | +0.04 / +0.08 |

**实验 3（干预，TF-IDF 三元词，Fig.4）**：只用 200 个泄露特征训练 Macro-F1 56.07；原模型在屏蔽测试集上从 62.27 降到 60.85；训练时屏蔽后重训为 61.62。

**边界**：LLM 泄露审计在 30 个特征样本上与两位专家的一致率为 53% 和 67%，两位专家之间 73%。讨论中指出 LLM 可能在预训练中见过公开判决，存在记忆和时间前视偏差。阅读者分析：干预只在一个线性模型上做，未对 DistilBERT 或 LLM 做屏蔽；测试集 1,128 条，未报告置信区间，0.65 点的差异是否显著未检验。

依据：[arXiv:2607.04261v2](https://arxiv.org/pdf/2607.04261v2)，§2.3–2.5，pp.7–9；§3.1–3.4，Fig.1–4，pp.9–14；§4，pp.14–16。
