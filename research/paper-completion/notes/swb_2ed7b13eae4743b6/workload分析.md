# 工作负载

**来源与过滤**（§4.1）：FinTabNet 中 1999–2019 年 S&P 500 公司的公开财报。保留至多含一张表的页面；排除超过 20 行、超过 2 个描述表头或有嵌套结构的表格及目录类表格；2 个表头合并为 1 个。共选出 12,719 页供标注。

**标注**（§4.2、§8）：11 名美国金融专业人士（CPA、MBA 等），每页 1–2 名专家，每页至多写 2 题，可跳过；每题约 2 美元，平均时薪 35 美元，历时约 8 周。

**规模与切分**（§4.4、Table 1）：

| 统计 | 值 |
|---|---|
| 样例 / 报表页 | 8,281 / 2,789 |
| 训练 / 验证 / 测试 | 6,251 / 883 / 1,147（75/10/15%，三者无重叠报表） |
| 平均输入 token（文本+表格） | 687.53，最大 2,679 |
| 平均文本句数 / 表格行数 | 24.32 / 6.36 |
| 平均问题长度 | 16.63 |

**事实来源**：仅文本 23.42%，仅表格 62.43%，两者都需 14.15%。

**程序**：1 步 59.10%、2 步 32.71%、≥3 步 8.19%；divide 45.29%、subtract 28.20%、add 14.98%、multiply 5.82%。

阅读者分析：2,789 页远少于 12,719 页候选，说明多数页面被专家跳过或未分配；论文未给出跳过率。（阅读者分析）

依据：[EMNLP 2021，14 页](https://aclanthology.org/2021.emnlp-main.300)，§4.1–4.4、§8、Table 1，PDF pp.3–5、9。
