# Chen et al. — FinQA: A Dataset of Numerical Reasoning over Financial Data

FinQA 是 11 名金融专家基于 S&P 500 公司财报页面（来自 FinTabNet）编写的 8,281 个问答对，每题附可执行的推理程序（10 种运算的领域专用语言）和支持事实，要求在表格与文本之间做多步数值计算。作者提出"检索器 + 程序生成器"的 FinQANet，RoBERTa-large 版测试集执行准确率 61.24%，远低于人类专家的 91.16%。已通读正文、伦理说明与附录 A–B，附录 C–D 的案例与界面图只浏览。
