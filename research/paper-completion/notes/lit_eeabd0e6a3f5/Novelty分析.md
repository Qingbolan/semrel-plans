# 贡献与评价

| 组件 | 原文做法 |
|---|---|
| 异质文档检索 | 冻结 Sentence-BERT，为问题与手册分别训练全连接 Alignment 层，用 InfoNCE 对齐；正负样本按 knob 是否重叠构造，分 question-manual、question-question、manual-manual 三类训练（§4.1） |
| 训练数据合成 | 逻辑链“触发行为 → 导致问题的行为 → 解决问题的功能 → 对应 knob”，逐边让 LLM 回答后拼成真实感问题（§4.2） |
| 遥测分析 | STL 分解后对残差用中位数和 MAD 计算异常度，转为文本并附相关 knob，再按与问题的语义相似度选 top-K（§5） |
| 推理 | 两阶段提示：先选 knob，再定值（§3） |

阅读者分析：RAG 加 LLM 推理的总体框架常见；增量在面向 DBMS 配置的异质源对齐、逻辑链数据合成和遥测转文本。Panda（同样检索文档与遥测）是最近的相关工作，但实验未把 Panda 或 D-Bot 作为基线（Table 2 只有 PLM 与各类 LLM 变体），因此相对这两项工作的优势缺少直接实验证据。

依据：§2.2、§3–5、Table 2，PDF pp.3–9、11。
