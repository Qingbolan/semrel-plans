# Satyapanich — Modeling and Extracting Information about Cybersecurity Events from Text

这是 UMBC 2019 年博士论文（导师 Tim Finin），即 CASIE 网络安全事件抽取工作的完整版本。作者定义了 5 类网络安全事件（数据泄露、钓鱼、勒索、发现漏洞、修补漏洞）、20 类事件论元及语义角色，标注 1,000 篇 2017–2019 年的安全新闻，并构建 CASIE 流水线（事件触发词检测、realis、论元检测、角色链接、事件共指、知识图谱映射）。测试集上触发词检测微平均 F1 约 77–80，论元检测 70.5–74.8，角色链接 84.81，共指五指标平均 72.62。已阅读第 1、3–6、12–14 章，并选读第 7–11 章的实验设置；未复现实验。
