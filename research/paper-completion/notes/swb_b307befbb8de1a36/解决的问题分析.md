# 解决的问题

研究三类判别式任务，每个样本是一篇 PubMed 文献（标题/摘要）或句子：

- **NER**：输入文本，输出带类型的实体提及。LLM 输出采用 HTML 标签格式，如 `<Type = "{entity type}"> {entity mention} </Type>`，以替代 BIO 序列标注；
- **关系抽取**：输入文本，输出实体对。BC5CDR-RE 只有化学物–疾病交互（CDI）一种关系，输出二元组 (entity1, entity2)；BioRED 有多种关系类型，输出三元组；
- **多标签分类**：输入文献，输出 JSON，每个键对应一个标签，值表示是否选中。

**问题拆解（Table 2）**：（1）语义上合理但违反标注指南，包括层级、类别、边界/粒度错误和忽略例外；（2）语义理解不足导致的推理错误；（3）解析错误，作者在开发阶段之后未再遇到。

**更大的问题**：能否在“人工标注—训练模型—推理”的生产流程中，用 LLM 部分替代人工标注者。

依据：[arXiv:2503.03261v2，21 页](https://arxiv.org/pdf/2503.03261v2)，§1.2，PDF pp.2–3；§2.2 Table 2，PDF pp.4–6；§3.1.2，PDF p.7。
