# Yan, Li & Lodewijks — UAV Accident Forensics via HFACS-LLM Reasoning: Low-Altitude Safety Insights

本文提出 HFACS-UAV：在 HFACS 8.0 四层框架上增加 26 个无人机专属增强模式，并用分层提示、YAML 知识库和 few-shot 示例，让 LLM 从 NASA ASRS 无人机事件叙述中做 18 类多标签人因归因。论文同时提供带人在环信息补全的 Streamlit 原型。在 200 篇报告（3,600 个编码点）上，7 个 LLM 的宏 F1 为 0.576–0.763，最佳为 GPT-4o-mini（P 0.712 / R 0.821）。已阅读全文正文与附录 Table A1 的结构；附录 A2/A3 的逐类数值只抽查。
