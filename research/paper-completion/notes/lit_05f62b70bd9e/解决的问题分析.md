# problem

**任务**：对单个语义过滤或单个语义连接，在执行前估计其输出基数（§3，p.3）。

**输入**：基表（products、reviews，含文本、半结构 JSON 文本列与图像列）、预计算嵌入列（可选使用）、一条语义谓词（自然语言，可引用一列或多列）、所用 LLM 与系统提示（在 TOML 配置中指定）。**输出**：估计基数 ĉ，同时记录估计成本（美元）、延迟（秒）与额外元数据内存（字节）（§4，p.5）。

**真值定义**（p.3）：真值是“部署系统实际会观察到的基数”，即用指定 LLM 与系统提示真正执行谓词得到的结果，而不是基于人工标注的“客观真值”；框架每次运行前重算这一模型相关真值，并为常见模型和若干 scale-factor 提供缓存。连接真值必须用嵌套循环连接计算，因为已知的语义连接优化都是近似的，可能扭曲复杂谓词的基数。

**规模参数**（p.3）：scale-factor = 抽取的商品数（如 10 个商品约对应 200 条评论，平均每商品约 20 条）；抽样是嵌套的，大 scale-factor 包含小的；另有单独的 join-scale-factor。

**工作单位**：一条查询 = 一个基表语义过滤或一个语义连接；查询形状刻意简单，不考虑算子间交互（p.3、§5）。

**评价指标**（§4，p.5）：q-error = max(max(ĉ,1)/max(c,1), max(c,1)/max(ĉ,1))，两者都下限截断为 1，以处理零或接近零的高选择性情形；与 STATS-CEB 惯例相同。
