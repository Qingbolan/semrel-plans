# 出发点

LLM 进入客服、报税这类场景后，答错规则会带来真实损失。论文开头举的例子是加拿大航空聊天机器人给出错误指引后被判赔偿（§1，PDF p.1）。作者认为，已有的指令遵循基准主要考格式、长度、主题等“风格约束”；规则推理基准大多停留在单步一阶逻辑或人工合成的逻辑题。

真实规则用自然语言写成，规则之间相互依赖，还要并行套用多条规则再汇总。例如行李费要同时考虑基础托运费、超重费、超尺寸费，以及这些费用如何合并（§1，PDF p.1；§2，PDF pp.2–3）。作者把这种能力称为“rule-guided reasoning”，并认为现有工作没有测到它。

阅读者分析：出发点是评测缺口而非方法缺口。论文不提出新的推理方法，只在附录 D.2.5 用写 Python 代码作为“工具增强”的对照实验。

依据：§1–2，PDF pp.1–3。
