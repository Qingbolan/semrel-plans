# Deng et al. — Unstructured Data Analysis using LLMs: A Comprehensive Benchmark

UDA-Bench 是 LLM 非结构化数据分析系统的基准：30 名研究生人工标注 5 个数据集的关系视图作为真值，构造 240 条查询，比较 7 个系统的质量、成本和延迟。关键结果是这套真值与查询负载本身；系统比较基于作者复现或改造的实现。
