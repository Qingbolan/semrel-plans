# 贡献与评价

**原文主张的贡献**（§1，PDF p.2；§2，pp.3–4）：

1. 条款图框架：把义务强度和时间限定作为显式实体，在文档级别建立条款间的类型化关系；作者将其与 OLG++（单条规则内部的图）和 GOLDCOIN（只适用于隐私信息流的情境完整性模式）对比。
2. ACE：作者称其为首个需要多条款推理的合同合规基准，含 4,700 个场景。
3. 对抗式场景生成：生成"带干扰的合规"与"带貌似合理辩解的违规"场景，以降低合成数据的表层特征（§3.2.2，p.6）。
4. 蒸馏训练的小模型在 ACE 上大幅提升，并迁移到 PrivaCI-Bench 和 ContractNLI。

**组件质量验证**（Tables 1–2，pp.4–5）：实体抽取在 50 个条款上的人工评估精确率 95.8%、召回率 93.8%；10 张合同级条款图的人工评估聚类准确率 96.1%、边正确率 91.4%。

**阅读者评价**：

- 摘要称"最先进模型"在 ACE 上只有 34–57%，但正文实际只评测了 5 个 1.5B–8B 的开源指令模型，没有 GPT-4o 等前沿模型的结果；"对最先进模型是根本挑战"缺乏直接证据（阅读者分析）。
- 生成用 GPT-4o、验证用 Claude Sonnet 4、教师为 DeepSeek-R1，人工专家只抽查了 50 个场景，标签主要依赖 LLM。
- 正文称微调模型在 ContractNLI 上 F1"始终优于"基础模型，但 Table 8 中 Qwen-7B 的 F1 从 59.6 降到 58.6（阅读者分析）。
