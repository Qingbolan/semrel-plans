# Semantic Types for Computational Legal Reasoning: Propositional Connectives and Sentence Roles in the Veterans’ Claims Dataset

论文从退伍军人伤残申诉文本出发，构造法律规则的命题连接类型和裁决句子的推理角色类型，供论证挖掘使用。它报告类型定义、实例和小样本频次，没有报告分类器准确率。原目录 CEUR Vol.2385/paper1.pdf 实为另一篇 2019 年修辞角色分类论文；本条已改用作者仓库中标题与作者相符的 2017 年预出版稿，并保留原 source_id 和查询来源关联。
