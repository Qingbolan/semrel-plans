# 解决的问题

本文的问题是"如何构建并描述一份多层、多语种、跨文档对齐的语义标注语料"，不是提出某个预测任务。

**文档级标注**（§3.1，PDF pp.2–3）：

- **Markable**：实体提及（Person、Organization、Location，以及为经济金融领域新增的 Product、Financial）；事件提及（动词、名词、代词等，含词元、词性和事实性属性）；按 ISO-TimeML 标注的时间表达式；数值表达式；时间信号与因果信号。
- **关系**：TLINK（时序）、SLINK（从属，用于转述）、CLINK（显式因果，含 cause/enable/prevent）、GLINK（语法依存）、HAS_PARTICIPANT（按 PropBank 角色）。
- **共指**：REFERS_TO 链接到不消耗文本的 ENTITY/EVENT 实例。

**语料级标注**（§3.2，PDF p.3）：不同文档中指向同一实例的共指链用统一实例 ID 和 DBpedia URI 链接。对 44 个种子实体，还在全文中标注其全部提及及其参与的事件。

**范围**：文档级标注只覆盖每篇的标题和前四句；语料级标注覆盖全文（§5.1，PDF p.4）。

**输出格式**：每篇文章一个 CAT stand-off XML 文件，另有一个列出跨语料实例的文件（含类型、DBpedia URI、时间锚点和参与者）（§5.2，PDF p.4）。

依据：§3、§5.1–5.2，PDF pp.2–4。
