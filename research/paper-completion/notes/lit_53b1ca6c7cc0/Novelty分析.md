# 贡献与评价

**论文声称的贡献**（§1 末，p.2）：
1. 指出直接用 LLM 做时序推理时，文本化会引发数据类型与 agent 过程两种错位；
2. 提出 TimeClaw：H = (T, E, M)，整合可执行工具、经验驱动的能力演化与情节多模态记忆；
3. 在多个真实领域上做大量实验。

**三个组件**（§3.2–3.4，pp.4–5；附录 B–C、E.2）：

| 组件 | 做法 |
|---|---|
| 可执行时序工具 T | 8 个原子种子工具（list_channels、series_overview、channel_stats、channel_values ≤500 元素/次、compute_acf、detect_periodicity、find_peaks、arima_forecast），在 MCP 工作区按全精度执行，只回传紧凑结果（Table 10，p.26） |
| 能力演化 E | 用代码专长 LLM 从聚类轨迹中抽象出自包含工具，在相似任务的留出子集上验证，成功率超过 γ=0.7 才加入 T（§3.3；E.2）。TSAIA 上演化出 portfolio_var、portfolio_sharpe、capm_regression |
| 情节多模态记忆 M | 记录 m=(τ, ϕ, ψ, ζ, ρ)；ϕ 为 text-embedding-3-small 文本嵌入（1536 维），ψ 为 20 维序列指纹（结构、统计、频谱、动态、多变量相关），按库内 z-score 归一化；先按文本余弦取 N=20 候选，再按指纹 L2 重排取 top-3（Table 11；附录 C.2） |

**阅读者评价**：
- 各组件单独看都有先例（工具增强 agent、技能库/工具自生成、情节记忆检索），新意主要在于把它们针对时序数据具体化：全精度服务端工作区、可审计数值证据链、以及“文本召回 + 序列指纹重排”的两阶段检索。
- 能力演化的实证仅有 TSAIA 金融这一例（三个工具）；附录 E.2 说其他领域的类似工具“预期会出现”，这是展望而非已验证结果。
- 指纹的第 5 槽“当前恒为零”（附录 B.2 p.21），实际有效维度为 19，属实现细节。

依据：[arXiv 2606.05404v1](https://arxiv.org/abs/2606.05404)，§1–3，PDF pp.2–5；附录 B–C、E.2–E.3、Tables 10–11，pp.20–27。
