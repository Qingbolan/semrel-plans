# 贡献与评价

作者列出的贡献（§1，pp.1–2）：

1. 把重复轨迹复用表述为在部分可观测下，对工作流结构、参数来源和残余 LLM 决策的编译问题。
2. 一条包含意图发现、行为去噪、依赖验证、来源分类和可执行工作流生成的管线。
3. 保守的参数级依赖规则：扫描非相邻生产者、给出显式证据元组，并通过 suspected 弃权。作者承认按值推断生产者–消费者关系和分级证据边都有先例，自称新颖之处是“排除其他来源后才承认，排除失败就弃权”。
4. 在两个互不共享机制的 ground truth 上，与基于顺序和基于频次的基线比较。
5. 案例研究（包括拒绝编译）、在留出实例上执行，以及两次被执行框架迫使的自我更正。

**评价（阅读者分析）**：

- 论文的诚实度很高：它主动撤回了“两个独立 ground truth”的说法（§6.6），承认 Table 1 无法复现（§6.4），并说明 0.992 不可审计（§6.5）。
- 核心机制的实证支撑比标题弱。Table 3 消融显示，在 T1 上起作用的是“最近幸存者”这一近因规则，排除过滤几乎为空操作；论文强调的排除纪律只在不可复现的 LLM skill 运行中体现（§6.5，p.10）。
- 编译器 v1 是一个 LLM skill（指令包），其所用的前沿模型版本没有记录（§5，p.5）。
- 没有报告 56 个场景上的编译/拒绝率，没有离线编译成本，也没有工作流 IR 运行时（§6.3、§7）。
