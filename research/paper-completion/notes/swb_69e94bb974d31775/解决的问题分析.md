# 解决的问题

**任务**（§4.1、§5）：对五类不公平条款分别做独立的句子级二分类，判断一个条款是否属于该类潜在不公平条款；同时输出被选中的理由作为解释。

| 要素 | 内容 |
|---|---|
| 输入 | 一个 ToS 句子/条款 q；该类别的理由库 M（每条是一个自包含英文句子） |
| 输出 | 是否潜在不公平（二分类）；被激活的记忆槽，即理由 ID |
| 样本单位 | 句子（语料共 21,063 句） |
| 类别 | ltd 责任限制、cr 内容删除、ter 单方终止、ch 单方变更、a 仲裁 |

**方法**（§4.1）：计算 q 与每个记忆槽 m_i 的相似度 s(q, m_i)，权重 w_i = σ(s)。作者用 sigmoid 替代 softmax，使模型可以不使用记忆，也可以同时激活多条理由。记忆读出 c = Σ w_i·m_i，与 q 拼接后分类。只做一跳（single hop）读取，相似度用两层 MLP。

**两种监督**（§4.2）：弱监督只给整个理由库；强监督额外告诉模型每个不公平条款对应哪些理由，并以 max-margin 损失（式 1–2，间隔 γ）要求目标理由得分高于非目标理由。

**理由标注**（§3）：每个不公平条款可对应多条理由。例如 Box 的责任限制条款被标为 extent、anydamage、reputation、dataloss、ecoloss、awareness、liabtheories。

依据：§3.1–3.5、§4.1–4.2、§5。
