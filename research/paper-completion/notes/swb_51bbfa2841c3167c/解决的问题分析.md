# 解决的问题

**标注任务**：输入是已标好事件与 timex 的文本（本研究沿用 TimeBank 原有事件、timex 与共指标注），标注者输出每个事件 span 的时间线位置、事件类型、分支和事实性（§3、§3.6，PDF pp.3–6）。事件识别不是本文贡献。

**机制**：

| 机制 | 内容 |
|---|---|
| 事件类型 | 有界 [B]、无界 {U}（含"永久"事件）、半有界 [U} / {U]，以及连续事件簇 [C] |
| 事实性 | 简化 FactBank：默认"发生"，另有 "-"、"m"、"m-" 三种标记 |
| 分支 | 顺序不明的事件放在挂接到主线某点的小时间线上，方向为 <] 或 [> |
| 事件簇 | 同时/连续/描述性事件可整体标注 |
| timex | 把 timex 包进事件 span 即完成锚定 |

**输出转换**：时间线被确定性地转换为 TimeML tlink，使用 before/after、includes/is_included、simultaneous、vague、overlap 7 类（§3.6、附录 B）。

**建模任务**（§5，PDF p.8）：输入整篇文档，对每一对事件/timex 预测关系类型。

阅读者分析：转换为 TimeML 时，凡理论上可能有多种关系的情况都映射为 vague，会丢失"单端/双端无界"与"分支导致不定"的区别（附录 B，PDF p.16）。
