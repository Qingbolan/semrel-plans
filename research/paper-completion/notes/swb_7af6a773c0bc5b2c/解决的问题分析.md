# problem

**输入**：已有 GENIA 事件标注的摘要，包括触发词、类型和参与者。

**输出**：为每个事件在 5 个维度各选恰好一个值。每个维度的取值互斥且完备，并在存在时标出线索词（Methods：Meta-knowledge annotation scheme）。

| 维度 | 取值（默认值加粗） |
|---|---|
| Knowledge Type (KT) | Investigation、Observation、Analysis、Method、Fact、**Other** |
| Certainty Level (CL) | **L3**、L2（较有把握或较常发生）、L1（低把握或很少发生） |
| Polarity | **Positive**、Negative |
| Manner | High、Low、**Neutral** |
| Source | **Current**、Other（来自已有研究） |

**超维度**：由已标维度按规则推导，不需要人工标注（Hyper-Dimensions）。
- New Knowledge=Yes：Source=Current、KT 为 Observation 或 Analysis，且 CL=L3（Table 1）。
- Hypothesis=Yes：KT=Investigation；或 KT=Analysis 且 CL 为 L1/L2（Table 2）。

**工作单元**：单个事件，而不是句子。嵌套的复杂事件中，参与者事件通常标为 KT=Other。这个设计是为了解决同一句话包含方法、事实、推测等多种信息时，句子级标注会丢失信息的问题（Related work 例 4）。

依据：[BMC Bioinformatics 12:393，PMC3222636 全文 XML](https://doi.org/10.1186/1471-2105-12-393)，Methods，Tables 1–2。
