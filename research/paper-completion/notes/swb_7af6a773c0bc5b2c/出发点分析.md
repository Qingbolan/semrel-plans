# motivation

事件抽取把句子转换成结构化表示：触发词、类型，以及 CAUSE、THEME 等参与者。用户可以按模板检索事件，比关键词检索更精确（Background：Event-based text mining）。但典型的事件标注不记录上下文信息，而这些信息会改变对事件的解读。

原文以 "the narL gene product activates the nitrate reductase operon" 的多种改写为例（Event interpretation…，例 2a–2f）：

| 改写 | 含义 |
|---|---|
| It is known that … | 已知事实 |
| We examined whether … | 调查 |
| … did not activate … | 否定 |
| These results suggest … might … | 推测 |
| … partially activated … | 低强度 |
| Previous studies have shown … | 来自他人研究 |

这些句子的事件类型和参与者完全相同，含义却不同。

已有的元知识语料多在句子或片段层面标注，且通常只标一个方面，例如推测或修辞区块。事件层面的标注一般只有否定；GENIA 原有的 Uncertainty 属性也没有清晰定义（Related work）。

作者希望通过事件级、多维度的元知识标注，支持以下需求：发现新的实验知识以辅助数据库整理、检测矛盾与蕴含、区分新知识与已有知识（Abstract、Background）。
