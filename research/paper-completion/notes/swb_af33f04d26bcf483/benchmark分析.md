# 评测与边界

**基线**：多数类与随机基线；模型为 Llama 3.1 8B（Base/捷克法律 CPT，全量微调或 LoRA PEFT）与 ModernBERT-large（Base/CPT）；T2 比较 BCE 与非对称损失（Asy）；T3 另有 MLP 与流水线（§5.3–5.4，PDF pp.14–21）。附录 B.1 提到 Llama 3.1 70B 零/少样本提示明显更差，但未给数字（PDF p.37）。

**实验 1（T1 论证检测，Table 4，PDF p.17）**：

| 模型 | Bal-F1 |
|---|---|
| 多数类 / 随机基线 | 46.6 / 42.0 |
| Llama 3.1 8B Base | 79.5 |
| Llama-3.1-8B-Czech-Legal（CPT） | 70.7 |
| Llama Base / CPT + PEFT（LoRA） | 49.7 / 51.3 |
| ModernBERT Large | 82.5 |
| ModernBERT-large-Czech-Legal | 82.6 |

**实验 2（T2 论证类型，Table 5，PDF p.19）**：

| 配置 | 宏 F1+ | 宏 Bal-F1 |
|---|---|---|
| 多数类基线 | 0.0 | 49.4 |
| Llama PEFT（最好） | 3.7–4.9 | 49.6 |
| Llama 全量 Base+BCE | 50.1 | 74.6 |
| Llama 全量 Base+Asy | 56.1 | 77.5 |
| ModernBERT CPT+Asy | 44.4 | 71.6 |

最难的是 HI、SI、PC；作者归因于低一致性、标签本身含糊（约一半 HI/PC 错误在法律上说得通）和低频（§5.4.2，PDF p.18）。

**实验 3（T3 形式主义，Table 6，PDF p.20）**：

| 配置 | Bal-F1 |
|---|---|
| 多数类基线 | 37.0 |
| 黄金论证 + MLP（上界，不可用于纯文本推理） | 91.7 |
| 端到端最好：ModernBERT-large-Czech-Legal | 82.2 |
| 流水线，无过滤 | 83.2 |
| 流水线，有过滤 | 83.8 |

**作者承认的局限**（§6.3，PDF pp.24–25）：仅 272 份判决；部分类型一致性低；测试集只有 29 份判决；文义解释 5.7% 的低比例部分取决于指南门槛（仅引用法条不算文义解释）。

阅读者分析：T3 测试集有 17 份形式主义、12 份非形式主义判决，但 Table 6 的部分召回值（如 R− 77.8、R+ 84.3）不是 1/12 或 1/17 的整数倍，像是多次运行的平均，论文未说明运行次数或方差；在 29 份样本上 83.2 与 83.8 的差距不足以说明流水线更优（阅读者分析）。

依据：§5.3–§6.3、Tables 4–6、附录 B–C，PDF pp.14–25、37–39。
