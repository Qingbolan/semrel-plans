# Savary et al. — PARSEME Corpus Release 1.3

本文介绍 PARSEME 动词性多词表达（VMWE）多语种语料的 1.3 版：首次把以往各版的 26 种语言统一到 Universal Dependencies v2 形态句法格式，新增阿拉伯语与塞尔维亚语，扩充希腊语、瑞典语、汉语，并按 1.2 版"未见 VMWE"标准重新划分训练/开发/测试。全集约 926 万 token、45.6 万句、12.7 万个 VMWE；作者用 Seen2Seen 和多任务 MTLB-STRUCT 重新训练并给出新基线。已读全文 §1–§11 与附录 Table 2。
