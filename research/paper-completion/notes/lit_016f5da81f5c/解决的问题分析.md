# 解决的问题

**任务定义**（§2，PDF p.3）：给定自然语言查询 N 与含 n 张表 {T1,…,Tn} 的关系数据库 D，生成 SQL 查询 Q。

**评测问题**：如何在同一平台上细粒度比较 NL2SQL 方法。NL2SQL360 有六个组件：基准数据集（Spider、BIRD、Spider-Realistic、Dr.Spider 等）、模型库、数据集过滤器、评测指标、执行器与日志、评估器（§3，Figure 4，PDF pp.4–5）。

**过滤场景**（§3，PDF pp.4–5）：

1. SQL 复杂度（沿用 Spider 难度划分）；
2. SQL 特征（子查询、逻辑连接词、ORDER BY、JOIN 数量）；
3. 数据领域（如金融、医疗、零售）；
4. 问句变体测试（QVT）。

**指标**：EX、EM、VES，以及新提出的 QVT。QVT 只纳入模型至少答对一个问法的 SQL，再计算该 SQL 所有问法的平均正确率（§3 公式 (1)，PDF p.5）。

**设计问题**：能否把 LLM 与 PLM 方法的模块（预处理、提示策略、SQL 生成策略、后处理）自动组合出更好的方案？作者用遗传算法 NL2SQL360-AAS 搜索，目标指标可为 EX/EM/VES（§5.1–5.2，Figures 13–14，PDF pp.10–11）。

评测单位是一条 (nl, sql) 对；正确性以执行结果等价或 SQL 精确匹配判定，并不涉及歧义问句的多答案（阅读者分析）。
