# 贡献与评价

作者列出四项贡献（§1，PDF p.2）：

1. **GDPR SOTA**：提出构建 GDPR 执法 SOTA 的必要性与方法，并对 GDPR 在欧洲的实施生态建模，识别信息来源及其特征。
2. **GDPRxiv 系统**：GDPR 专用爬虫与归档器，作者称其为第一个完全自动化、开源的系统，规模是已有 GDPR 语料的 5 倍。
3. **执法纵向刻画**：发现比例罚款原则及其在各国的偏斜。
4. **RTBF 分析**：从计算视角梳理十几类常见 RTBF 失败。

**与已有工作的对比（Table 2，PDF p.4）**：

| | Enforcement Tracker | GDPRhub | GDPRxiv |
|---|---|---|---|
| 收集方式 | 专有 | 志愿者手工整理 | 开源爬虫 |
| 内容 | 有罚款的执法 | 全部执法、法院判决 | 全部执法、法院判决、官方意见/报告/指南 |
| 文件数 | 1,428 | 1,594 | 8,943 |
| 可持续性 | 未知 | 人力随文件数增长 | 全自动 |

**阅读者评价**：

- 主要贡献是数据基础设施和"失败案例库"的视角，而不是新算法。
- "全自动"有保留：执法相关的四个元数据仍需人工标注，因为正则、NLTK NER、BERT 的精确率和召回率都只有 50–70%（§4.2–4.4，PDF pp.6–7）。
- "准确性"按定义推出（只收官方来源），没有对抽取、翻译或标签做定量审计；翻译质量作者自己也说尚未检查（§4.3、§5.1，PDF pp.7–8）。
- 写作时爬虫代码尚未开源（"将在评审后开源"），网站 API 也还在开发中（§4.1、Table 2，PDF pp.4、6）。

依据：[PoPETs 2023(4)，16 页](https://lawfulcomputing.org/papers/pets2023.pdf)，§1、Table 2、§4.1–4.4、§5.1，PDF pp.2、4、6–8。
