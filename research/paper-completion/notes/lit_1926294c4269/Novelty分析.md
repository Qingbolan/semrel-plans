# 贡献与评价

**原文声明的贡献**：作者称已有教程覆盖机器学习与数据库（引用 [4, 13, 25, 29, 33]），但尚无专讲“LLM 用于数据管理”的教程（§1 “Difference with Existing Audience”）。内容规划为 1.5 小时：背景 10 分钟、RAG 20 分钟、提示与 agent 20 分钟、领域微调 10 分钟、向量数据库 10 分钟、应用 10 分钟、开放问题 10 分钟（§1）。

**组件划分**（§2.1、Figure 1）：

| 组件 | 教程中的作用 |
|---|---|
| RAG | 检索领域知识与工具 API 描述，作为提示输入，缓解幻觉 |
| 向量数据库 | 加速知识检索；支持谓词过滤+向量检索；缓存热门请求及答案 |
| 领域微调 | 多任务微调、LoRA 部分参数更新、RLHF |
| 提示管理 | 意图抽取、模板、zero/few-shot、反思、CoT/ToT/GoT、记忆 |
| LLM agent | 任务分解、流水线编排（生成多计划择优）、工具管理 |

**开放问题**（§2.3）：数据库领域通用 LLM、标准化模型接口、模型轻量化以嵌入内核、提升训练数据代表性以增强泛化。

阅读者分析：新颖性在于把分散工作归纳成统一架构图，没有新算法或新实验；所列应用（D-Bot、LLMTune、LLM 查询改写等）都引用他人或作者团队已有工作。作为综述入口有用，作为证据来源很弱。

依据：[PVLDB 17(12) 4213–4216](https://www.vldb.org/pvldb/vol17/p4213-li.pdf)，§1、§2.1、§2.3、Figure 1，PDF pp.1–4。
