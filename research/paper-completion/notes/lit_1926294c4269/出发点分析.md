# 出发点

教程认为传统小型机器学习模型在数据管理任务中难以适应变化的环境（系统、查询负载、硬件），并且只能输入离散特征，缺少上下文理解和多步推理能力，难以胜任数据库诊断、根因分析这类任务。LLM 的语言理解与泛化能力被视为克服这些限制的机会，例如分析异常指标并给 DBA 报告根因，或把自然语言请求翻译成可执行查询。

但直接使用 LLM 有三项限制：幻觉、调用成本高、复杂任务准确率低。作者进一步指出现有做法（思维链、工具调用）过度依赖 LLM 自身知识、工具调用需大量针对特定 API 的微调数据、且难以综合多源知识。由此引出三项挑战：如何用表格数据与领域知识减少幻觉；如何管理并优化多步操作的流水线；如何减少 LLM 调用开销。

依据：[PVLDB 17(12) 4213–4216](https://www.vldb.org/pvldb/vol17/p4213-li.pdf)，Abstract、§1 Introduction/Background，PDF pp.1–2。
