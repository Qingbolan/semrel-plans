# 贡献与评价

原文声称的贡献（§1，PDF p.2）：
1. 首次把查询优化表述为可由生成式 LLM 求解的序列生成任务，构建在 PostgreSQL 执行引擎上的 LLM-QO。
2. 数据配方 QInstruct：查询、优化指令、辅助统计、高质量计划（按实际执行时间而非代价模型从多个优化器中选出）、同模板的一例规划示范（§5，PDF pp.5–6）。
3. 两阶段训练：Qit 为监督微调，模仿 k 个优化器中最佳计划；Qdpo 用 DPO，以最佳计划为偏好、t*/t_i < r0（默认 0.95）的计划为非偏好（Algorithm 1–2，§5.2、§6，PDF pp.6–7），均用 LoRA 实现。
4. 实验说明 LLM 具备作为优化器的潜力，并指出泛化、效率、适应性等后续方向。

核心思想是从多个优化器中按真实运行时间“取最优再蒸馏”，DPO 只是标准方法的直接应用。示范例取自与输入相同模板的查询（§5.1），作者称这是避免无效计划最有效的策略，这意味着在模板内分布下示范信息很强；OOD 实验中改用其他示范策略的效果见 Table 4。作为可行性探索，结论较为审慎（标题即为问句）。（阅读者分析）
