# 解决的问题

设定（§3 Notations）：表格分类，样本 (x, y)，x∈R^d 可含数值、有序和类别特征。目标是微调 LLM，使其给定序列化后的 x 输出推理轨迹 z=(z_1…z_k) 与标签 y。序列化示例：“The age is 31, the body mass index is …”；Diabetes 与 Creditg 采用 TabLLM 的 Text Template，AD 与 HomeLoan 用自定义模板（附录 A）。

ReSS 管线：
1. 训练决策树（网格搜索，附录 D.1），对每个 x 得到路径 S(x)：有序的特征级约束集合；
2. 只对决策树预测正确的子集 C，提示 GPT-4.1 依据 (x, y, S(x)) 生成 z=R(x, y, S(x))；
3. 脚手架不变增广：随机选特征，在不违反 S(x) 的有效范围内扰动；以一定概率（如 0.2）把不在路径上的特征置为 “unknown”；对增广样本同样生成推理；
4. 在原始 + 增广推理数据上 SFT。

工作单位是“一行表格样本 → 一段推理 + 一个类别标签”。对照基线 Direct SFT 只学 x→y；DRC+SFT 让 LLM 依据 (x, y) 无约束生成推理再 SFT。

依据：[arXiv 2604.13392v2，55 页](https://arxiv.org/pdf/2604.13392v2)，§3–3.3、Fig.1，附录 A，PDF pp.3–5、12–13。
