# 贡献与评价

论文自述贡献（§1）：
1. 以决策树路径作为符号脚手架，引导通用 LLM 用其领域知识生成有据推理数据，并训练表格推理模型；
2. 脚手架不变的数据增广，生成分布内与分布外推理样本；
3. 一组忠实度/可解释性指标：步骤级幻觉率（特征存在 FEH、特征值 FVH、比较 CH 三类）、解释充分性（遮蔽推理未提及的特征，看准确率是否稳定）和解释必要性（遮蔽推理提及的特征，看是否显著下降），遮蔽数 k=1…4；
4. 五个数据集上的实验。

阅读者分析：核心思想近似“用可解释模型的决策路径蒸馏 LLM 推理数据”，与 Tables2Traces（对比三元组生成推理）等工作相邻，区别在于以树路径作为硬约束并据此做标签保持的增广。

阅读者分析：消融显示去词汇化（只模仿树结构、不引入领域知识）的模型准确率接近决策树，说明增益主要来自 GPT-4.1 注入的领域知识（§5.4）——这同时意味着方法依赖教师 LLM 的领域先验，作者在结论中也承认仅在 LLM 有较强先验的医疗/金融领域验证。

阅读者分析：幻觉率的判定方式（自动规则还是人工/LLM 判断）正文未说明；充分性测试中的 “unknown” 遮蔽与增广训练时的 unknown 注入是同一操作，结果稳定性部分可能来自训练分布，作者未讨论。

依据：[arXiv 2604.13392v2，55 页](https://arxiv.org/pdf/2604.13392v2)，§1、§4、§5.4、§6，PDF pp.2、5–6、9–10。
