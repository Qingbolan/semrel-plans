# 工作负载

本文没有数据集或查询负载，只有实验材料与测量规模（METHODS、图注）：

| 项目 | 规模/设置 |
|---|---|
| 小鼠背景 | 由 C57BL/6-Sv129 杂合背景回交至 C57BL/6 至少 6 代 |
| 等位基因 | `Adarfn`（含 pgk-neo）经 Cre 切除得 `Adarf`；`AdarΔ2−13` 为 `Adar−` 无效等位基因 |
| 诱导系统 | Mx1-Cre（poly(I:C) 诱导，两周内 7 剂）；SCL-Cre-ERT（他莫昔芬 2 mg/天腹腔注射或 1 g/kg 饲料） |
| 胎肝移植 | 每基因型合并 2–3 个胎肝，移入受照射（2×5.25 Gy，间隔 3 h）CD45.1 受体，每只 3×10⁶ 活细胞 |
| 观察时长 | 移植后 5 周诱导；poly(I:C) 后持续追踪至 23 周 |
| 表型分析 | 每基因型 3–5 份组织（Fig. 1 图注）；细胞周期分析 3×10⁵ 个细胞 |
| 集落实验 | 每次 12,500 个骨髓细胞，双复孔，Methocult M3434 |
| 表达谱 | 每胎肝分选 500–1,500 个 CD150+CD48−CD244− HSC；GeneChip Mouse Genome 430 2.0；GSEA 使用 MSigDB C2，过滤后 1,247 个基因集，30,000 次置换 |
| qPCR | 10 只 12 周龄雄性 C57BL/6 小鼠的股骨/胫骨/髂骨分选细胞；归一化到 YWHAZ、Cyclophilin A 或 GAPDH，ΔΔct 法 |
| 公开数据 | GEO 序列号 GSE12772 |
