# 工作负载

**语料**：AAE（Stab & Gurevych, 2017），402 篇针对题目（prompt）写作的学生议论文。平均 357 token（207–550）、17 句（8–33）、约 5 段（3–7），每段平均 3 个 ADU（1–12）（§3.1、§3.5，pp.3–5）。

**标注规模**（Table 3，p.5）：

| 类型 | 数量 | 比例 |
|---|---|---|
| Policy / Value / Fact（claim，含 major claim） | 344 / 1,502 / 411 | 0.15 / 0.67 / 0.18 |
| Testimony / Statistics | 22 / 400 | 0.01 / 0.10 |
| Hypothetical-Instance / Real-Example | 917 / 717 | 0.24 / 0.19 |
| Common-Ground / Other | 1,774 / 2 | 0.46 / 0.00 |

**标注流程**：3 名标注员，先在 20 篇上迭代修订指南，第三人再训练 20 篇；三人共同标注 40 篇（10%）计算最终 IAA；其余由两人分别单人标注（§3.3，p.4）。

**分类划分**：每类 ADU 样本随机按 80/10/10 划分 train/dev/test，重复 10 次取均值（§4、附录 A，pp.5、12）。学习曲线用 20%–100% 训练数据，测试集固定（Figure 2，p.6）。

**题目分析**：去除重复题目后用 370 篇（题目类型分布 policy 0.37、value 0.48、fact 0.15）（§5，p.7 脚注 5）。

阅读者分析：80/10/10 是在 ADU 层面随机划分，原文未说明是否按作文隔离，同一作文的成分可能同时出现在训练与测试中。
