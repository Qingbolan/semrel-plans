# 贡献与评价

**原文贡献**：

1. 纯 Python 实现 MMAX2 的主要对象（basedata、markables、markable levels、discourse 等），基于 Beautiful Soup 等库，代码紧凑、可扩展（§2，PDF p.2）。
2. **混合实现**：标注方案的复杂业务逻辑（属性依赖、默认值、校验）不重写，而是用 JPype 在运行时实例化原 MMAX2 Java 类（§2.2，PDF p.3）。这让 Python 端获得与 GUI 一致的校验语义。
3. **语言无关的激进分词**：按 Unicode 字符类别切分，包括在连字符处切分，并在 `spc` 属性中记录前导空白，使原始字符串可被精确还原（§2.1，PDF pp.2–3）。
4. **分词无关的正则匹配**：在还原后的字符串上匹配正则，返回命中的 basedata ID（§2.1）。

**阅读者分析**：

- 这是工具说明，不是研究方法论文；没有性能、正确性或用户研究评测，贡献的价值取决于实际使用。
- 混合 JVM 方案避免了逻辑分叉，但要求安装 Java 和 MMAX2 jar；不提供 Java 绑定时，校验和默认值信息不可用（脚注 10）。
- 校验"报告而不修复"的设计把一致性处理留给用户，对数据管线而言更透明。

依据：§1–2.3，脚注 10，PDF pp.1–5。
