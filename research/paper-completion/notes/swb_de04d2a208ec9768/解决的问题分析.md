# 解决的问题

**数据模型（§2，PDF p.2）**：

- **basedata**：分词后的文本，每个 token 是一个带 ID 的 XML 元素，是标注的最小单位。
- **markable**：标注对象，通过 span 属性引用（可不连续的）basedata ID 序列，以属性—值对保存标注。
- **markable level**：按现象组织的标注层，每层可有一个 annotation scheme，规定允许的属性、取值及其依赖。
- 一个 MMAX2 项目由 `.mmax` 文件与 `common_paths.xml` 组织，通过单一 discourse 对象访问。

**API 要解决的事**：

1. 读取：给定 `.mmax` 文件，加载 basedata 与所有层的 markables，并按标注方案校验（§2.2）。
2. 创建：从原始字符串生成 basedata（自带分词器），从预标注数据创建 markable 层并写出 XML（§2.1、§2.3）。
3. 对齐：把字符位置映射到 basedata ID，从而把以字符偏移表示的外部标注转成 markable span（§2.1、§2.3）。

**输入/输出**：输入为 MMAX2 XML 项目或任意预标注文本；输出为 Python 对象，或新的 MMAX2 项目文件。校验只报告不一致并抛出异常，不负责修复（§2.2，PDF p.4）。

依据：§2–2.3，PDF pp.2–5。
