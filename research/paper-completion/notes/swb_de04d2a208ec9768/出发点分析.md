# 出发点

MMAX2 是一个 Java 实现的多层标注工具，侧重于中小规模语料上丰富的篇章级特征，被大量标注项目使用，因此有不少以 MMAX2 离位格式发布的标注数据集（§1，PDF p.1）。但这些数据处在 Java 与 XML 的生态中，难以直接用于当时主流的 Python NLP 与数据科学方法。

已有途径的不足（§1，PDF pp.1–2）：

- MMAX2 内置的 Project Wizard 功能简陋，MMAX2 Discourse API 依赖 Java。
- PAULA、PEPPER、discoursegraphs 等转换器适合常见格式之间的转换；但对少见或特殊格式，为一次性转换给 PEPPER 新增格式支持开销过大。
- brat、WebAnno、INCEpTION 等网页工具支持分布式标注和项目管理，但开销较大；MMAX2 则自包含、轻量、无需安装。

因此作者希望提供一个轻量的 Python 基础层：既让现有 MMAX2 数据可在 Python 中处理，也降低从原始或预标注数据创建新 MMAX2 项目的门槛（§1）。

依据：§1，PDF pp.1–2。
