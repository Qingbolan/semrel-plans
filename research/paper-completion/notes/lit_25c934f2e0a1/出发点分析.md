# 出发点

Code Interpreter、Excel/PowerBI Copilot、Jupyter AI、Chapyter、CoML 等数据科学智能体通过自然语言生成并执行代码，但可靠性参差不齐。Figure 2 中同一个“计算 2023 和 2050 年人口密度”的查询，四个智能体只有 Code Interpreter 正确：CoML 忽略已有的 pop2050 列而自行预测，Chapyter 没按要求把索引名大写并修改了原数据，Jupyter AI 用字符串除以整数后崩溃。

已有评测的不足：PandasEval、DS-1000 等只测代码补全或填空，不测智能体的完整流程；另一些工作要么依赖大量人工判断、规模受限，要么用更强的 LLM 打分，可能带来偏差。
