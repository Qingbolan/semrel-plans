# 工作负载

**文件采集**（§2.1，PDF p.3）：从 GitHub 收集真实 CSV，要求场景有意义、表头和内容以英文为主、列数大于 5 且行数至少 20。用 GPT-3.5 为每个文件生成列描述、数据类型和缺失值说明。

**问题生成**（§2.1、附录 E，PDF pp.3、13）：根据专家访谈得到的数据分析概念（去掉可视化）和文件描述，由 GPT-4 在同一对话内为每个文件生成三组问题：3 个单概念简单题、3 个单或多概念复杂题、3 个多概念更复杂题。
