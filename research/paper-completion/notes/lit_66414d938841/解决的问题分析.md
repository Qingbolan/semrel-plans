# 解决的问题

**评测任务**（§2、Figure 1、Figure 5，PDF pp.2–3、7）：
- **输入**：一个 CSV 文件、一个问题和对应约束（方法、流程或统计参数的具体要求）。
- **过程**：智能体按 ReAct 方式规划、写 Python 代码，在 Docker 本地沙箱中执行，根据输出继续推理，直到给出最终回答。
- **输出与判分**：GPT-3.5 用单样例提示把原始回答改写成格式要求中的 `@answer_name[answer]` 序列；再用正则抽取，与标签精确匹配。

每个 `@answer_name[answer]` 称为一个子问题。**准确率**是所有子问题都答对的问题比例（附录 P，PDF p.14）。

**示例**：问题要求用 Z-score 方法找出 `Credit.csv` 中“Limit”列的离群值；约束规定离群值是距均值超过 3 个标准差的点；格式为 `@outliers[outliers count]`；标签为 `@outliers[1]`（Figure 2，PDF p.3）。

**训练侧问题**：给定 CSV 与数据分析关键词，自动生成问题，用 GPT-4 智能体收集 ReAct 轨迹并过滤，得到指令微调数据（§2.5，PDF pp.5–6）。

依据：§2、§2.5、Figures 1–2、5，附录 P，PDF pp.2–7、14。
