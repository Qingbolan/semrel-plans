# 解决的问题

**问题形式**：给定一条锚记录 r 和 blocking 得到的 n 条候选 R = {r1, …, rn}，找出与 r 匹配的记录（若存在）。假设一对一：r 最多匹配 R 中一条（§3.1，p.3）。Table 1 用 DBLP-ACM 举例：锚记录是 VLDB 2001 的论文，候选含同名期刊版、相关 TODS 论文及作者名缩写的同一论文。

**三种策略**（§3.2–3.4，Table 2，pp.3–5）：

| 策略 | LLM 映射 | 每条锚记录的调用次数 | 输入记录数 |
|---|---|---|---|
| Matching | (r, ri) → Yes/No | O(n) | 2n |
| Comparing | (r, ri, rj) → A/B，交换顺序比两次 | O(kn)（冒泡取 top-k） | 3k(2n−k−1) |
| Selecting | (r, R) → 1..n，或 0 表示都不是 | O(1) | n+1 |

Comparing 能给黑盒模型产生相似度分数：ri 赢两次记 2 分、赢一次记 1 分并求和；全对比较称 comparing_all-pair，复杂度 O(n²)（§3.3）。实验中 comparing 只给出相对顺序，所以对排第一的候选再做一次 matching 来决定是否匹配（§4.1，p.6）。

**ComEM**（§3.5，Figure 2，pp.5–6）：先用中等规模 LLM 以 matching 或 comparing 排序并过滤候选，再用 LLM 对 top-k 做 selecting。实验配置为 Flan-T5-XL 按 matching 排序，保留 top-4（§4.1）。

**输出与指标**：每条锚记录的匹配结果，按记录对计算 F1；另报告 LLM 调用成本（美元）（§4.1）。

依据：§3、§4.1，Tables 1–2、Figure 2，PDF pp.3–6。
