# 贡献与评价

**作者声称的贡献**（§1，p.2）：

1. 多智能体协作 Text-to-SQL 框架，整合外部工具与模型协作；
2. 开源指令微调模型 SQL-Llama，填补开源 Text-to-SQL 智能体模型的空白；
3. BIRD 测试集执行准确率 59.59%，写作时为 SOTA。

阅读者分析：三个组件各有清晰前身——schema 裁剪对应 C3/DIN-SQL 的 schema linking，问题分解对应 DIN-SQL 与 CoT/least-to-most 研究，执行反馈修正对应 DIN-SQL 的自我纠正。新意主要在把它们组织成按需激活的“智能体”并统一由一个骨干模型完成，以及把这些中间任务蒸馏到 7B 模型；“多智能体”在实现上是固定顺序的三段流水线，加一个有上限的修正循环，并不存在智能体间的协商。

阅读者分析：Refiner 只能发现“报错或结果为空”的 SQL，附录 A.3 承认语义错误但可执行且非空的 SQL 不会被修正；这限制了它对 BIRD 主要错误类型的作用。

摘要称 SQL-Llama 达到 43.94、接近原始 GPT-4 的 46.35；按 Table 1，43.94 是 MAC-SQL+SQL-Llama 在 BIRD dev 上的结果，单独 SQL-Llama 为 32.87，两者都只有 dev 数字（阅读者分析）。

依据：§1，p.2；§3，pp.3–4；Table 1，p.6；附录 A.3，p.11。
