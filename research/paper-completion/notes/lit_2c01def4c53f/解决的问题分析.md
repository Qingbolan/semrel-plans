# 解决的问题

**任务定义**：输入三元组 X=(Q, S, K)：自然语言问题 Q、数据库 schema S={T, C}（表与列）、可选外部知识 K（BIRD 的 evidence）；输出 SQL Y。工作单位是“一个问题 + 一个数据库”。

**三智能体流程**（Algorithm 1）：

| 智能体 | 输入 | 输出 | 触发与约束 |
|---|---|---|---|
| Selector | Q、S、K | 子 schema S′（T′⊆T，C′⊆C），JSON 标注 keep_all / drop_all / 保留列 | 仅当 schema 提示超过阈值时启用；用 GPT-4-32k 时阈值为 >25k token；每表至少保留 6 列 |
| Decomposer | Q、S′ 描述（含列说明与高频取值）、K | 1–5 个子问题及子 SQL，最后一条为最终 SQL | 简单问题直接出 SQL；采用单次 CoT 而非迭代式 least-to-most；最多 2-shot |
| Refiner | 出错 SQL、执行报错、Q、S′、K | 修正后的 SQL | 检查语法、可执行、结果非空；最多 3 轮 |

**SQL-Llama**：用 GPT-4 在 BIRD 与 Spider 训练集上运行三类智能体任务，过滤错误 SQL，得到约 1 万条指令数据，对 Code Llama 7B 做多任务监督微调。
