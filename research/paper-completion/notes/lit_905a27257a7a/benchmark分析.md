# 评测与边界

**基线（§6.1，p.6）：** SGLang+HiCache 默认 LRU（HICACHE_RATIO=1）；KVFlow（仅静态工作负载）；消融 PBKV-LAE（仅生命周期感知驱逐）、PBKV-HE（加分层驱逐、无预取）。

**指标（§6.1，p.7）：** 工作流端到端延迟；每 agent 平均 TTFT；GPU 上 token 级平均 KV-Cache 命中率。

**主要结果（Table 1，p.7；Qwen3-32B）：**

| 工作负载 | LRU 延迟/命中率 | Full PBKV 延迟/命中率 | 备注 |
|---|---|---|---|
| HoVer+LangChain | 189.66s / 27.09% | 102.60s / 69.10% | 1.85× 延迟、2.55× 命中率 |
| SWE-bench+AutoGen | 271.90s / 46.34% | 160.18s / 79.94% | |
| FinanceBench+CrewAI | 130.34s / 27.95% | 80.53s / 53.44% | KVFlow 101.57s / 39.87% |

**敏感性与附加实验：** 并发 <60 时各策略无差别，LRU 在并发 84 时 10 次中崩溃 3 次、96 时全部 OOM（§6.3，p.8）；K=3 最好（Fig.5c）；换用 R-GCN、Markov-N3 预测器命中率单调下降但仍高于 PBKV-LAE（Fig.5b）；激进预取仅在噪声 λ<20% 时略优，λ≥30% 时低于不预取（附录 E，pp.17–19）；调度开销：预测推理均值 1.18ms，decode 步均值 12.34ms（Table 4，p.19）。

**局限（原文 §5，p.6）：** 预测器需针对具体工作负载训练；缓存复用模式依赖客户端消息传递约定，Aw(c) 只捕获基本形式。

**阅读者分析：** 所有敏感性、预测器和预取实验都只在 HoVer+LangChain 上做；静态场景下作者保留了为动态场景设计的机制而未调优（§6.2 Remark，p.8），这使与 KVFlow 的比较更保守但也不是最佳配置比较。命中率在运行首尾偏高，稳态内部 LRU 约 10%、PBKV 约 50%（§6.2），平均值受运行长度影响。
