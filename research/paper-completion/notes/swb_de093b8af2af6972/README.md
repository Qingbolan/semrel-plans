# Cybulska & Vossen — Using a sledgehammer to crack a nut? Lexical diversity and event coreference resolution

本文是 ECB+ 语料的发布论文：先用词元（lemma）匹配基线检验 EventCorefBank（ECB）的代表性，发现简单基线在 ECB 上即可接近当时复杂模型的结果，原因是 ECB 大多每个 topic 只有一个"种子事件"实例；随后为 43 个 topic 各补充同类型的另一事件实例，新增 502 篇新闻，形成共 982 篇、带事件组件与文档内/跨文档共指标注的 ECB+。关键结果：ECB 上 topic 内词元匹配 CoNLL F1 64.76（Table 2）；ECB+ 标注一致性 Cohen's κ 0.74（30 标签）与 0.76（跨文档共指）。已通读全文 8 页。
