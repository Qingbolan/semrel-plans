# 解决的问题

**输入**：一篇英文网络用户文档（评论、论坛帖、博客或论证性新闻），已分句、分词（§3–4，pp.3–4）。

**输出**：每个 token 的 BIO 标签，共 11 类：5 种论证成分（claim、premise、backing、rebuttal、refutation）× B/I，加非论证类 O（§3，p.3）。论证模型基于扩展的 Toulmin 模型，每篇文档通常只有一个论证；claim 常为隐含，部分句子不承担论证功能。

**分类单位**：句子。训练前把标注边界对齐到句子边界，每句一个标签（若一句含多个成分，取最大者，仅约 1% 的句子如此）；分类后映射回 token，并始终在原始 token 级标签上评测。作者称这种近似约损失 10% 的 F1（§4 及脚注 7，pp.3–4）。

**模型**：SVMhmm 序列标注，特征集 FS0–FS4（§4.1–4.2）：

| 特征集 | 内容 |
|---|---|
| FS0 | 1–3 元词袋 |
| FS1 | 首尾三词、句子位置、POS n-gram、句法树特征 |
| FS2 | 情感（5 类）与 LDA 主题（30 维） |
| FS3 | 语义角色、共指链、篇章关系 |
| FS4 | 论证空间特征（本文新增） |

依据：EMNLP 2015，§3–4.2，PDF pp.3–5。
