# Shen et al. — From Data to Story: Towards Automatic Animated Data Video Creation with LLM-Based Multi-Agent Systems

这是一篇短篇研讨会论文，介绍 Data Director：一个基于 GPT-4 的多智能体系统，把原始数据表自动转换为带旁白、注释和动画的数据视频。系统由"数据分析师"和"设计师"两个 LLM 角色加一个控制器组成，分工完成洞察提取、Vega-Lite 可视化、旁白、动画与注释、时间同步六个子任务。论文只用一个四家 IT 公司股价的案例做定性展示，没有定量评测，主体内容是开发中总结的经验与未来方向。已阅读全文 §1–6 与附录 A 的完整提示词。
