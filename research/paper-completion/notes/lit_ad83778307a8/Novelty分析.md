# 贡献与评价

**原文的贡献**（§1，p.2）：

1. Data Director，一个把原始数据自动转为动画数据视频的 LLM 多智能体系统；
2. 一个股价数据的案例研究；
3. 关于任务分解、性能优化与工作流设计的经验教训，以及未来方向。

**主要设计经验**（§4，pp.3–4）：

- 区分 LLM 擅长的任务（生成、推理、文本决策）与需外部工具的任务（渲染、语音、视频合成）。
- 把动画设计与时间同步合并为一个子任务可同时提高准确性与效率。
- 先由分析师生成基础图，再由设计师加注释的分层方式，比一次生成复杂注释效果更好（§2，p.2）。
- 用 LLM 生成表格的自然语言描述以丰富数据语义。
- 共享表示：可视化和注释统一用 Vega-Lite，洞察和动画信息用 JSON。
- 提示技巧：角色设定、思维链、要求先解释再决策、从预定义候选中选择类型、结构化输出。

**评价**：

- 阅读者分析：贡献属于系统原型与设计经验，"多角色 LLM + 外部工具"在当时已较常见；新意在于把它用于数据视频，并沿用作者此前 Data Player 的旁白-元素链接机制。
- 原文未给出任何量化证据来支持上述经验（如"分层注释效果更好"），这些判断来自开发过程中的观察。
- 作者在 §5 明确指出缺少全局优化框架和公认基准，数据故事质量本身也较主观（p.4）。
