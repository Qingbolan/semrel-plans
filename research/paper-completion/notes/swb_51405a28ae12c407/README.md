# Tamari et al. — Process-Level Representation of Scientific Protocols with Interactive Annotation

本文提出 Process Execution Graph（PEG），把湿实验室生化协议表示为文档级有向无环图，并用基于 TextWorld 的文本模拟器标注了 279 篇协议（X-WLP）。在 X-WLP 上，SciBERT 流水线和 DyGIE++ 式多任务模型在提及识别和局部关系上表现尚可，但跨句论元关系 F1 只有 32.5–39.1。已阅读正文全部章节与附录 A（本体构造、覆盖率、边约束）。
