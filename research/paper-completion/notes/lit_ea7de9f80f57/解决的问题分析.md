# problem

任务形式化为 T = (q, D, P, s, m, a)（§2.1，p.2）：q 为自然语言分析问题；D = {d1,…,dK} 为含 K 个源的数据环境，其中与问题相关的证据子集 R_q 不向智能体暴露；P 为任务级先验（源提示、schema 说明、噪声说明），本基准刻意不提供；s 为 N 步金标准推理轨迹；m 为 M 个里程碑键值对（关键中间结果）；a 为金标准答案。智能体接收 (q, D, P)，输出执行轨迹 ŝ 与答案 â。

**指标**（§2.2，pp.2–3）：
- Acc：LLM 评委对比 â 与 a，多子问题任务逐项打分后归一化。
- EE（执行效率）：仅对答对任务计算 N/T，T 为智能体步数。
- GPR：达成的金标准里程碑比例；TPE：在前 N 步内达成得满分、之后按 γ 指数折扣（实验中 γ=0.9）。GPR/TPE 只在答错的任务上计算。

**运行设置**（§4，p.5；附录 E，p.20）：OpenClaw 框架，每题独立 Docker 容器、数据只读挂载，允许 Python、读文件、网页抓取与搜索；但只有“国际比较”类任务的提示允许网络搜索，其余限定本地 ./database/。单题超时 1200 秒；所有评判由 GLM-5 完成。

依据：[arXiv:2605.02503v3，25 页](https://arxiv.org/pdf/2605.02503)，§2、§4、附录 E，PDF pp.2–3、5、20。
