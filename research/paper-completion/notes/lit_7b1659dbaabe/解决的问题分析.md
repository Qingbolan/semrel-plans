# 解决的问题

论文把数据驱动发现定义为一种启发式搜索：为给定观测集合寻找支配其数据生成过程的规律（§1，p.1，沿用 Newell & Simon）。

| 要素 | 原文描述 |
|---|---|
| 输入 | 数据集及其元数据；可选的自然语言查询，给出高层目标以缩小假设空间 |
| 两种设定 | 完全自主（只给数据与元数据，搜索全假设空间）；用户引导（数据+查询）（§3，p.4） |
| 中间过程 | 理解变量语义与类型 → 生成假设 → 多步计划 → 数据变换 → 调用统计工具或生成代码验证 → 解读结果、接受反馈 |
| 输出 | 经统计检验支持或否定的假设及解释，如 Figure 1 中 DISSAVED 与 BMI 交互项系数 0.52（OLS）/0.71（GLM），p<0.05 |

Figure 1（p.2）给出三类请求：明确假设（"DISSAVED 与 BMI 的关联对男性更显著吗"）、宽泛问题（"时间偏好与健康在人群中如何关联"）、以及持续生效的用户反馈（"处理财富差异时总是用 Gini 系数"）。

工作单元：一次"数据集 + 目标"的发现会话，由多轮智能体对话组成。论文没有把问题形式化为带标签答案的任务，也没有定义成功判据。

阅读者分析：该问题设定更接近"开放式统计分析代理"，与有标准答案的表格问答不同；结果是否"正确"在文中只能凭与原研究结论对照的定性判断。
