# 具体用例

**用例（XMODE，§5，p.22）**：查询"绘制每个世纪描绘战争的画作数量"。原文描述 XMODE 假设异构元数据已组织在数据库中，用 LLM 把自然语言查询分解为子任务，生成的操作序列为：

1. 用 SQL 从数据库检索画作元数据；
2. 对每幅图像调用视觉语言模型判断是否描绘战争；
3. 生成可视化代码，按世纪画出计数。

这个例子体现了综述所说的"把 LLM 驱动的语义操作与跨模态处理结合"（异构数据 Takeaway O3，p.22）：结构化过滤用 SQL，语义判断交给模型。

**补充示例（语义算子，§1.2 O3，p.3）**：在病历库中，常规查询只能聚合含 "fever" 字样的记录，语义聚合可把 "high temperature"、"febrile condition" 也归到一起；语义连接可以把 "Type II Diabetes" 与 "adult-onset diabetes" 这类不精确匹配的键连起来。

阅读者分析：XMODE 例子是"关系过滤 + 逐行模型判断 + 聚合"的典型语义查询形态，与本项目关注的语义过滤/语义连接直接相关；但综述没有给出该例的数据规模、准确率或成本，需要回到 XMODE 原文才能用于评测设计。

依据：§1.2，p.3；§5，p.22。
