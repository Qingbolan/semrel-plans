# Tang, Wang, Zhou et al. — LLM/Agent-as-Data-Analyst: A Survey

这是一篇综述，按数据模态（结构化、半结构化、非结构化、异构）梳理用 LLM 与智能体做数据分析的技术，并沿"封闭世界→开放世界、工具耦合→工具无关、字面分析→语义分析、手工开发→自主设计"四条演进轴总结设计目标，最后列出行业产品与各模态的挑战。全文没有自己的实验或统一评测。已阅读引言、结构化数据（含数据构造）、异构数据、行业实践、挑战与结论全文，半结构化表格数据集统计表；对图表、视频、文档、3D 各小节只浏览了结构与 Takeaway。
