# 工作负载

本文没有自己的工作负载：不提出数据集，不做实验，也没有训练/测试划分。

正文提到的数据集仅作为被综述工作的背景，例如 Turking Test 对照的 SNLI、SQuAD、NewsQA（§4.1），没有规模信息。

附录 C 的四张表是最接近“数据清单”的内容（PDF pp.24–28）：

| 表 | 内容 | 列 |
|---|---|---|
| Table 1 | 标注生成：指令与回复、推理依据、成对反馈 | 论文、数据类型、骨干、标注成本、会议、代码/数据链接 |
| Table 2 | 标注生成：文本反馈、其他领域数据 | 同上 |
| Table 3 | 标注评估与过滤 | 同上 |
| Table 4 | 标注利用：微调、对齐、推理 | 同上 |

示例条目：GPT3Mix 用 GPT-3 生成指令，成本记为“每样本 300 tokens”（EMNLP'21）；SELF-INSTRUCT 用 GPT-3 生成指令与回复，记为“整个数据集 600 美元”（ACL'23）（附录 C Table 1）。

阅读者分析：这些成本数字转引自各原论文，口径不统一（按 token、按美元、按 GPU 时间），不宜直接横向比较。

依据：[EMNLP 2024 main, pp.930–957](https://aclanthology.org/2024.emnlp-main.54.pdf)，§4.1、附录 C Tables 1–4，PDF pp.6、24–28。
