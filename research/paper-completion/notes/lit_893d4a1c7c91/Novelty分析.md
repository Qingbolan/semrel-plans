# 贡献与评价

原文声称的贡献（§1，PDF pp.4–5）：

| 贡献 | 内容 |
|---|---|
| 框架 | 内容画像（全表统计）+ 语义画像（LLM 列语义、主题）双画像，生成 UFD 与 SFD |
| 基准与方法 | 改造 ECIR、NTCIR 得到 ECIR-DDG、NTCIR-DDG；检索、参考对比、无参考 LLM 评审与专家评估组合 |
| 实验 | 检索相对原始描述最高约 30% 提升；成本与扩展性；两个优化变体 MT 与 GP |

阅读者分析：核心技术点是“用确定性 profiler 的全局统计约束 LLM 生成”，以及把检索扩写（SFD）与可读描述（UFD）分离；单个组件（Datamart Profiler、按 [45] 的主题生成、G-Eval 式评审）多为已有技术的组合。

阅读者分析：“第一个系统化 LLM 框架”的表述是作者自述，未见系统的先行工作对比。SFD 本质是 LLM 文档扩写，其提升部分来自关键词扩充；Fig.8 显示与 SPLADE 叠加仍有增益，说明并非完全等价于查询侧扩展。

按原文 Table 2 计算，ECIR NDCG@10 0.856/0.658≈1.30，与“最高约 30%”一致（阅读者分析）。

依据：§1、§4.2、Table 2，PDF pp.4–5、13–14。
