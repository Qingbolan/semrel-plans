# 贡献与评价

**原文贡献**（§1、§7，Figure 2）：

1. SARA 数据集：简化的 IRC 法条 + 人工案例（蕴含与数值两类），案例经法学教授审核合理性。
2. 手写 Prolog 求解器作为上界：每个子节一条规则，61 个新戴维森式谓词表示事实，每个案例一个 Prolog 查询，达到 100% 准确（§3）。
3. 法律领域资源：147M token 税法语料（case.law 税务判例 + IRS 私人信函裁定和未发表 Tax Court 判例）、税法 word2vec、在 900M token 判例上继续 MLM 训练的 Legal BERT（§4）。
4. 实证：现成机器阅读模型在该任务上接近基线（§5.3）。

**阅读者评价**：

- 与 COLIEE、JEC-QA 等基于司法考试的数据集不同，SARA 的法条集合是闭合的，案例只能靠这些法条回答，并带有可执行的符号对照，这是其主要新意。（阅读者分析）
- 数据量很小（蕴含测试 100 例、数值测试 20 例），作者报告的 90% 置信区间在蕴含上约 ±8.3 个百分点，数值上约 ±15.8，模型间差异大多不显著。（阅读者分析，基于 Table 5 注释）
- Prolog 100% 是作者手工把每个案例转写成事实后的结果，并不代表自动系统可达；原文 §3.2 自己也承认需要专家、语义解析和易崩溃三项局限。
- 实验只覆盖 2020 年前的 BERT 与词向量；作者把专门推理模型留作未来工作（§5.3 末）。

依据：[NLLP@KDD 2020，CEUR Vol-2645 paper5，8 页](https://ceur-ws.org/Vol-2645/paper5.pdf)，§1–5、§7、Table 5，PDF pp.1–6。
