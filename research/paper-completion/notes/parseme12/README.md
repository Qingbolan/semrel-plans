# Edition 1.2 of the PARSEME Shared Task on Semi-supervised Identification of Verbal Multiword Expressions

PARSEME 1.2 将动词多词表达识别的重点放在训练与开发数据中都未见过的表达。它提供多语言标注及未标注语料，并重新设计划分和排名口径；不是单一新识别模型的论文。关键结果：开放赛道 MTLB-STRUCT 未见表达 F1 仅 38.5，全部表达为 70.1（Table 5）。
