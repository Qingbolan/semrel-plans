# Abu Shairah et al. — ALARB: An Arabic Legal Argument Reasoning Benchmark

本文发布 ALARB：13,344 个沙特商事法院案件，每个案件被 LLM 整理为事实列表、法院推理步骤、判决和引用的法条，并关联 8 部法规的条文。基于此定义了判决生成（三种输入设置 + 推理补全）和法条识别（四选一）两类任务，评测 12 个阿拉伯语或多语 LLM，并用约 1.2 万条指令微调 Gemma-3-12B，使其接近 GPT-4o。主要结果：GPT-4o 在"仅事实"设置下判决正确率最高也只有 38.7%；微调后的 Gemma-3-12B 在三种设置下为 37.3%/65.9%/45.3%（各提升 15–22 点）；法条识别在语义相近干扰项下最好仅 77.30%（GPT-4.1）（Tables 4–6，PDF pp.5–7）。已读正文全部和 Limitations；Tables 1–4、6–7 已渲染核对。
