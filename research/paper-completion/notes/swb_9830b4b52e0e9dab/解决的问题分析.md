# 解决的问题

**数据单位**（§3.1、Figure 1）：一个案件 = 编号的事实列表 + 编号的法院推理步骤 + 判决 + 引用的法条（指向法规全文）。

**任务一：判决生成**（§4.1）

| 设置 | 输入 | 输出 |
|---|---|---|
| 仅事实 | 案件事实 | 推理链和判决 |
| 事实 + 法条 | 事实和法院推理中引用的法条 | 推理链和判决 |
| 事实 + 法院推理 | 事实和完整推理 | 判决 |
| 论证补全 | 事实、法条和前若干步推理（去掉最后 k 步） | 补全推理并给出判决 |

判决由 GPT-4o 作为评审，与真实判决比较，分为正确、部分正确、错误三档（§5.1、附录 B）。

**任务二：法条识别**（§4.2）：给出案件全部事实，从四个选项中选出法院实际引用的一条法条。干扰项有两种：同一部法规中随机抽取的 3 条（较易），或按嵌入相似度在全部法规中检索出的最相似 3 条（较难）。

阅读者分析：作者先试过直接用嵌入从全部法规中检索相关法条，效果"极差"（§4.2，未给数字），才改为选择题；因此 ALARB 不提供开放式法条检索的评测。

依据：[arXiv 2510.00694v1，18 页](https://arxiv.org/abs/2510.00694)，§3.1、§4、§5.1，PDF pp.3–6。
