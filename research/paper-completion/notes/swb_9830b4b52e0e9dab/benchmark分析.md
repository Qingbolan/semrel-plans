# 评测与边界

**实验 1（判决生成，1,329 个案件，Table 4，取"正确"比例 %）**：

| 模型 | 仅事实 | 事实 + 推理 | 事实 + 法条 |
|---|---|---|---|
| AceGPT-v2-32B | 28.9 | 41 | 25.1 |
| AceGPT-v2-8B | 33.4 | 58.4 | 28.9 |
| ALLaM-7B | 14.1 | 39 | 17.2 |
| aya-expanse-32B | 32.9 | 70.6 | 36.3 |
| aya-expanse-8B | 25.6 | 61.9 | 24.6 |
| Falcon3-7B | 8.7 | 28.7 | 8.7 |
| Gemma-3-12B | 15.8 | 51 | 29.6 |
| Gemma-3-4B | 13.3 | 46.9 | 24.5 |
| GPT-4o | 38.7 | 65.7 | 46 |
| o4-mini | 22.9 | 61.3 | 27.6 |
| Qwen3-14B（思考模式） | 31.5 | 64.5 | 44.6 |
| Qwen3-8B（思考模式） | 27.1 | 58.3 | 32.2 |

GPT-4o 在"仅事实"和"事实 + 法条"中正确率最高；"事实 + 推理"中 aya-expanse-32B 最高。作者指出 AceGPT-v2 两个版本、aya-expanse-8B 和 Falcon 在给出法条后反而变差（§5.1）。

阅读者核对：Falcon 两种设置的正确率都是 8.7%，差别在错误率（70.9% → 73.1%）；AceGPT-v2-32B 在"事实 + 法条"一行三档之和为 91.2%，不足 100%（阅读者分析）。

**实验 2（法条识别，每种 1,159 题，Table 5，准确率 %）**：同法规干扰项下所有模型超过 80%，GPT-4o 最高（90.42%）；语义相近干扰项下 GPT-4.1 最高（77.30%），AceGPT-v2-8B 只有 52.72%。

**实验 3（微调，Table 6）**：Gemma-3-12B 全参数微调后，三种设置的正确率为 37.3%（+21.5）、65.9%（+14.9）、45.3%（+15.7），与 GPT-4o 相当。推理补全实验中（Figure 5），去掉 3 步及以上推理时微调模型的错误率低于 GPT-4o。

**实验 4（用英文推理，100 个案件，Table 7）**："事实 + 法条"设置下，Gemma-3-12B 正确率从 29.6% 升到 39%，GPT-4o 从 46% 降到 45%。

**边界**（Limitations）：只有一个国家的商事法律，规模有限；LLM 评审的三档评分较粗；微调只试了一个中等规模模型。原文没有报告多次运行或置信区间。

依据：[arXiv 2510.00694v1，18 页](https://arxiv.org/abs/2510.00694)，§5–6、Tables 4–7、Figure 5、Limitations，PDF pp.5–9。
