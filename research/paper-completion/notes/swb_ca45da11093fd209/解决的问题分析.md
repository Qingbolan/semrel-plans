# 解决的问题

**基准对象**：每个任务是一组文本实例（句子、段落或文档，来自真实合同、披露、判决、诉状或人工合成）加标签；工作单位是“一个任务提示 + 一个实例 → 一个输出”。

**输出形式**（§4.2）：二分类 112 个任务、多选 35 个、开放生成 7 个、多类/多标签 8 个，合计 162。

**六类推理**（§3.2）：

| 类型 | 输入 → 输出 | 示例任务 |
|---|---|---|
| 问题识别 | 事实陈述 → 是否涉及某法律问题 | learned_hands_benefits |
| 规则回忆 | 问题 → 规则文本或规则是否存在 | rule_qa |
| 规则结论 | 事实 + 给定规则 → 法律结果 | ucc_v_common_law |
| 规则适用 | 同上任务，但要求解释推理，人工评正确性与分析 | 同规则结论任务 |
| 解释 | 法律文本 → 抽取/问答/分类 | cuad_audit_right |
| 修辞理解 | 判决论证片段 → 是否具有某功能 | definition_classification |

**约束**：所有任务都假定有客观正确答案，不处理“合理之人可有分歧”的情形；每个任务只测单一推理类型，而不像考试那样要求在同一事实上串联完整 IRAC。

依据：§3.1–3.2，pp.4–7；§4.1–4.2，pp.7–8；附录 D.2，pp.21–22。
