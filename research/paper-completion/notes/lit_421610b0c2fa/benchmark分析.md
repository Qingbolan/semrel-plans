# 评测与边界

**基线**：Chat2Vis、LIDA、CoML4Vis；三种骨干 GPT-4o、GPT-4o-mini、GPT-3.5-turbo。作者尝试过 Code Interpreter，但因 API 处于测试阶段、经常失败而未纳入（§4.1 脚注，p.4；附录 A，p.13）。

**指标**：Invalid（无法渲染）、Illegal（不满足查询要求）、Pass（可渲染且合法）、Readability（GPT-4o-mini 作为视觉评审打分）、Quality（非法或无效时为 0，否则等于可读性）（§4.1，p.4–5）。GPT-4o-mini 与人工可读性分的 Pearson 相关为 0.6503，高于 GPT-4o 的 0.5648（Table 6，p.13）。

**实验 1（主结果，Table 1，p.5）**：通过率如下。

| 骨干 | 场景 | CoML4Vis | LIDA | Chat2Vis | nvAgent |
|---|---|---|---|---|---|
| GPT-4o | 单表 | 75.17% | 77.66% | 77.75% | 85.63% |
| GPT-4o | 多表 | 71.84% | 1.62% | 1.40% | 81.07% |
| GPT-4o-mini | 单表 | 73.88% | 67.85% | 71.92% | 75.16% |
| GPT-4o-mini | 多表 | 56.92% | 1.51% | 2.27% | 65.85% |
| GPT-3.5-turbo | 单表 | 64.54% | 36.83% | 67.98% | 76.08% |
| GPT-3.5-turbo | 多表 | 55.98% | 0.86% | 1.55% | 64.29% |

注意 Table 1 的 Δ 口径不同：前三列是绝对差（百分点），后两列是相对变化；摘要中“近 20% 的优势”指的是多表 Quality 的相对提升（+18.15%），不是通过率（Table 1 注，p.5）。

**实验 2（智能体消融，Table 2，p.6）**：GPT-4o 下平均通过率 83.80%；去掉 composer 降到 23.99%，去掉 validator 降到 79.98%，去掉 processor 为 83.97%（略升）。GPT-3.5 下去掉 processor 使多表从 64.29% 降到 59.60%。

**实验 3（模块消融，Table 3，GPT-3.5）**：去掉 ICL 平均 44.82%，去掉 CoT 63.50%，去掉模式过滤 69.01%（多表降 6.52 点）。

**实验 4（Elo，Table 5，p.7）**：人工两两比较，nvAgent 单表 1538.27、多表 1529.86，均最高。

**边界**：作者承认依赖闭源 API、用 LLM 同时做生成和评审可能带来偏差、对时间信息（如折线图、按时间分箱）处理不足、VQL→Python 翻译函数简单（Limitations，p.9；§4.6，p.7）。阅读者分析：只在一个基准上评测；人工评测由论文作者自己完成；Table 7 称 LIDA/Chat2Vis 不能处理多表，但 Table 1 仍列其多表结果，二者口径需谨慎解读（阅读者分析）。

依据：§4、Tables 1–5，PDF pp.4–7；附录 A、Tables 6–7，PDF pp.13–14；Limitations，PDF p.9。
