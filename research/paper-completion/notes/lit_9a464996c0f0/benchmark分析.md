# 评测与边界

**基线**：BARGAIN（以记录嵌入相似度为代理分数，β=0，与 FDJ 有相同理论保证）；理想级联（看全部真值选最优阈值、且不计找阈值成本，代表任何基于相似度的级联的成本下界，实际不可行）。LOTUS 因只在数据量趋于无穷时有保证而被排除（§8.1，p.10）。

**指标**：成本比 = 方法成本 / 对全部对调用 LLM 的成本（Products 为训练集构造成本 + 测试集连接成本，除以只在测试集上用 LLM 的成本）（p.10）。

**实验 1（保证是否达成，Table 2，BioDEX，T_R=90%、δ=10%）**：LOTUS 平均召回 75.4、失败率 100%；BARGAIN 91.1、9%；FDJ 91.2、7%。

**实验 2（主结果，Table 3，T=90%，成本比）**：

| 数据集 | BARGAIN | FDJ（相对 BARGAIN） | 理想级联 |
|---|---|---|---|
| Citations | 28.0 | 6.80（0.24×） | 19.1 |
| Police Records | 81.3 | 44.7（0.55×） | 66.6 |
| Categorize | 27.6 | 23.0（0.83×） | 12.5 |
| BioDEX | 73.9 | 73.8（0.99×） | 72.6 |
| Movies | 69.9 | 6.70（0.09×） | 52.5 |
| Products | 36.2 | 25.0（0.69×） | 30.1 |

注意 Categorize、BioDEX 上 FDJ 的成本比高于理想级联（阅读者分析）。

**实验 3（敏感性，Fig. 7–9）**：数据量与召回目标（0.75–0.95）变化下 FDJ 都优于 BARGAIN；成本主要来自精化，构造成本可忽略。

**实验 4（合成，Fig. 10）**：句中人名增多或加入两句不足 20 词的无关文本，理想级联成本显著上升；FDJ 在人名数实验中成本比接近零，在不同文本长度下也保持良好。

**边界**：LLM 调用以真值模拟、成本按 token 估算（§8.1）；分类型任务难以分解为少量特征，收益有限（§8.2）；定理 6.1 有子句数与正样本数条件（§6.3）；放宽精确率目标收益有限，故默认 T_P=100%（p.10）。阅读者分析：未报告真实 LLM 抽取误差或端到端运行时间；结果对生成特征所用的 o3 依赖程度未单独分析。

依据：§6.3、§8，PDF pp.8–12，Tables 2–3，Fig. 7–10。
