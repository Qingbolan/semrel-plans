# 贡献与评价

原文所称的核心贡献是：在同一批文档中，以一致、整合的方式标注多种事件-事件关系和事件共指（§1，PDF p.1）。

| 设计 | 说明 |
|---|---|
| 两遍流程 | 先裁决 markable，再标关系，减少漏标或错标事件带来的误差传播（§3） |
| 标注单例 | 不在共指链中的事件和实体也标，可用于判断照应性（§3.1） |
| 显式情态 | 用情态与极性约束共指，不满足严格同一的关系改用桥接（§3.1） |
| 因果-时序融合标签 | CAUSES（按作者表述，X 发生则 Y 必然）与 PRECONDITION（没有 X 就没有 Y），各与 BEFORE/OVERLAP 组合（§3.4） |
| 子事件作为 CONTAINS 子类 | 关系存在时，两类区分的一致率为 90.2%（§3.3） |

阅读者分析：方案本身多沿用 THYME-TimeML、Ikuta et al.（2014）等已有指南，新意主要在"整合"与流程设计。论文未报告任何自动系统在 RED 上的结果；Table 1 中的 TempEval-2016 分数来自另一语料，只是近似参照。正文还有两处编号错位：§3.1 说"Figure 1"实指 Table 1，§3.4 说"Table 1"实指 Figure 1。
