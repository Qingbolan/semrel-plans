**语料规模**（§1，PDF p.1）：

| 项目 | 数量 |
|---|---|
| 文档 | 95 篇（新闻 + 论坛讨论） |
| token | 54,287 |
| 事件 | 8,731（每个都有 DocTimeRel） |
| 时间表达 | 1,127（TIMEX3、section time、document time） |
| 实体 markable | 10,320 |
| 同一链 | 2,390 |
| 桥接关系 | 1,863 |
| 事件-事件关系 | 4,969（含时序、因果、子事件、ALINK 和转述关系） |

Table 5 列出的 11 种时序/因果/子事件关系共计 4,218 条（阅读者分析：按表内计数相加；与 4,969 的差额应包含 ALINK 和转述关系，原文未给出其分项）。CONTAINS 983 条最多，SIMULTANEOUS 57 条最少。

**一致性子集**：所有一致性数字都在 55 篇论坛和新闻文档子集上计算；该子集也有 Rich ERE 标注，可跨方案比较（§3.1，PDF pp.3–4）。

**与 ERE 对比**：86.3% 的 ERE 事件提及与 RED 事件 span 完全相同，部分匹配为 89.5%；反之只有 25% 的 RED 事件在 ERE 中有对应（§3.1，PDF p.4）。

**关系分布**：约 18% 的事件链与其他事件或时间有两条及以上关系；CONTAINS-SUBEVENT 的跨句长程关系明显更多（§4.2、Figures 4–5，PDF pp.6–7）。
