# 解决的问题

**任务**：输入一段产品描述，输出该产品的 10 位 HTS 美国编码；训练时还要求输出一段说明为何选该编码的推理文本（§2.2、§3.1，pp.3–4）。

**工作单位**：一条 CROSS 裁定转换成的一个“问题–回答”对。问题模板为 “What is the HTS US Code for [product_description]?”，回答为 “HTS US Code -> …” 加 “Reasoning -> …”（§2.2，p.3）。

**数据转换**：原始裁定是冗长、格式不一的官方信函。作者用 GPT-4o-mini 读取裁定的编码、编号、标题、日期、URL、摘要和正文，生成 (a) 用户当初想查询的产品描述、(b) 推理路径、(c) 编码（§2.2，p.3）。

**判定层级**：10 位全对表示可直接报关；前 6 位对表示国际统一层面正确；另报平均正确位数（0–10）（§4，p.5）。

阅读者分析：评测输入并非原始报关描述，而是 GPT-4o-mini 在“已知正确编码和裁定全文”的条件下生成的描述，可能带有指向答案的措辞；论文未讨论这种生成方式是否让任务变易或分布偏移。

依据：§2.2–2.3、§3.1、§4，PDF pp.3–5。
