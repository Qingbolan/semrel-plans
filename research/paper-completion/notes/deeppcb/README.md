# Online PCB Defect Detector On A New PCB Defect Dataset

DeepPCB 同时提供成对 PCB 图像数据和缺陷检测模型。输入包含无缺陷模板及待测图，不能把该实验结果解读为无需模板、任意生产线上的通用缺陷识别能力。关键结果：最大池化版本 mAP 98.6%，F-score 98.2、62 FPS。
