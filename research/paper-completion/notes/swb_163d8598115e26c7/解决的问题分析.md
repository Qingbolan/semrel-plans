# 解决的问题

**输入**：锚记录 a 与 blocking 检索出的候选集 C(a)={c1,…,cn}（实验中 n=10）。**输出**：选出唯一匹配候选，或输出 NONE。场景限定为 clean-clean：每个锚在候选集中至多一个真匹配。

**MDP 建模**：每个锚是一个 episode。状态向量拼接候选置信分、MATCH 可用掩码、COMPARE 频次、全局信息（步数比例、当前最高分）、最近 H=10 步动作历史，可选拼接语义嵌入。动作包括：

- MATCH(i)：小模型 Flan-T5-xl 判断单对是否匹配，用输出 YES 的概率更新分数；
- COMPARE(j)：在“冠军–挑战者”两候选间二选一；
- SELECT(k)：对当前 top-k（k=4）做列表式选择，被选者加分、其余减分，但不终止；
- DECIDE(i)/DECIDE(None)：唯一终止动作。

**成本模型**：两级抽象成本，低成本（MATCH/COMPARE）为 κℓ，高成本 SELECT 为 ρκℓ，默认 ρ=2.5。奖励为终止正确性奖励减去 λ×成本，加提前停止奖励、低置信提前决策惩罚和基于势函数的塑形项；最大步数 Tmax=18。

依据：[ACL 2026 long 1258，13 页](https://aclanthology.org/2026.acl-long.1258.pdf)，§3.1–3.2，PDF pp.3–4；附录 A Table 5，PDF p.11。
