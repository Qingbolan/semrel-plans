# 工作负载

**采集与过滤**（§2.2、附录 B.1、B.3、Table 8，PDF pp.4–5、26–27、33）：通过 USPTO OA Text Retrieval API 获取 2015-01-01 至 2024-12-31 的非最终驳回书，每份申请只保留第一份；只保留最终获得授权通知且未经历最终驳回的申请。

筛选漏斗：初始 206,767 条记录，过滤后剩 12,839（6.21%），经一致性校验（GPT 解析格式错误 1,763、权利要求数不一致 1,055 等）后最终 8,143 条（总体保留 3.94%）。许可为 CC BY-NC 4.0（附录 A.6，p.26）。

**数据统计**（附录 A.5、Tables 4–5，PDF pp.25–27）：

- 初始权利要求平均 17.81 条/申请（SD 6.92，最多 118），平均长 434.88 字符；
- 驳回书平均 13,414 字符；
- 驳回次数：§103 65,158、§102 39,325、§112 23,193、§101 16,831；
- 6,170 份申请所有权利要求均被首次驳回。
