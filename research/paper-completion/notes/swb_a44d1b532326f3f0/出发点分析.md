# 出发点

FrameNet 收录 1,000 多个语义框架、10,000 个词汇义项和 100,000 条句中词汇标注，是语义角色标注等研究的基础（§1，p.1）。但计算用户常被其自定义 XML 格式困扰；部分细节（如框架间关系中的框架元素映射）在网站 HTML 页面上看不到，只能通过 FrameGrapher 工具查看（脚注 1，p.1）。

作者列举的已有开源接口（Python、Java、Grammatical Framework 各一或两个）近年都未更新，可能不兼容最新数据，也没有被广泛采用（脚注 2，p.1）。因此需要一个随 NLTK 分发、覆盖几乎全部数据且易于探索的 Python 接口（§1，p.1）。

依据：[EMNLP 2017 Demo，D17-2001，6 页](https://aclanthology.org/D17-2001.pdf)，§1、脚注 1–2，PDF p.1。
