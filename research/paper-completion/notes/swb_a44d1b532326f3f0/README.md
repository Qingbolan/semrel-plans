# Schneider & Wooters — The NLTK FrameNet API: Designing for Discoverability with a Rich Linguistic Resource

本文是系统演示论文，介绍集成进 NLTK 的 Python 接口，用于访问 FrameNet 1.7 的框架、词汇单元、框架元素、框架关系、语义类型和标注句。核心设计是"可发现性"：在交互式 Python 中打印对象时给出可读展示并标出属性名。论文没有任何定量实验或用户研究。已通读全文 6 页。
