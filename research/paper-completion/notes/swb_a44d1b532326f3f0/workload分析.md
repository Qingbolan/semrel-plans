# 工作负载

论文没有实验负载、查询集或数据划分。涉及的数据对象仅为 FrameNet 1.7 发行：

| 项目 | 原文数值或描述 | 位置 |
|---|---|---|
| 框架 | 1,000 多个 | §1，p.1 |
| 词汇义项 | 10,000 个 | §1，p.1 |
| 句中词汇标注 | 100,000 条 | §1，p.1 |
| 解压大小 | 855 MB | 脚注 5、§4.1，pp.1–2 |
| 存储形式 | 数千个 XML 文件：框架、关系、LU、全文文档的索引文件与逐条文件 | §4.1，p.2 |

语料标注分两类（§4.5，p.5）：词典学例句（exemplars，每句只标一个目标 LU）与全文标注（full-text，文档中尽量标出全部目标）。每个句子对象的第一个标注集是句子级信息（词性，有时含命名实体），其后为框架标注集。

运行环境：NLTK 3.2.2 及以上，支持 Python 2.7 与 3.x，通过 `nltk.download('framenet_v17')` 获取数据（§2，p.1）。

阅读者分析：若要把它作为语义任务数据来源，需自行定义样本单位和划分，论文不提供。

依据：[EMNLP 2017 Demo，D17-2001，6 页](https://aclanthology.org/D17-2001.pdf)，§1–2、§4.1、§4.5，PDF pp.1–2、5。
