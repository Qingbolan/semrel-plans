# 贡献与评价

**论文声称的贡献**（§1，p.3）：

1. 基于 MCP 的多模态分析系统，每个 MCP 服务器配一个为特定模态优化的 LLM（"一种尺寸不适合所有"）。
2. 覆盖结构化、半结构化、非结构化数据的分层语义算子，支持跨模态连接，并兼容关系、文档、图、图像、音频、视频的已有算子。
3. 查询驱动的模型微调与基于统一嵌入 + 混合索引的数据发现。
4. 动态知识与数据刷新：深度研究式数据增强 + 支持插入/更新/删除的轻量编辑与机器遗忘。

作者在结论中称这是"首个基于 MCP 的多模态分析系统架构"，并说明"未来将完成整个系统实现并做更多实验"（§6，p.11）。

**评价**：采样式代价估计、迭代 RAG、过滤感知向量索引、MinHash 去重、影响函数遗忘等均是已有技术的组合（§3，pp.5–9）；新意主要在以 MCP 作为模态分工与扩展的架构抽象（阅读者分析）。

阅读者分析：论文只实现了原型的一小部分（GPT-4.1 客户端 + Qwen2.5-VL-7B 图像服务器 + PostgreSQL 服务器），大部分贡献停留在设计层面；"更高准确率、更好可扩展、更低开销"三项优势只有 3 条查询的初步证据（阅读者分析）。

依据：§1、§3、§4、§6，pp.3–11。
