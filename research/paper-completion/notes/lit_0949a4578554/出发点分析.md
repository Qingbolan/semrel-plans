# 出发点

数据库性能对系统参数和物理设计（索引、排序、分区）高度敏感。基于机器学习的自动调优能找到接近最优的配置，但训练与探索开销大（§1，p.1）。

已有 LLM 辅助调优（DB-BERT、GPTuner）从手册等文本中为单个参数抽取建议，再在组合空间中搜索完整配置。作者认为这一设计受限于早期模型（BERT、GPT-2）只有几百 token 的输入输出（§1，p.1）。

GPT-4 等新一代模型可以接收和输出数十万 token，因此 λ-Tune 把全部调优上下文（工作负载、目标系统、硬件）放进提示，让 LLM 直接生成整套配置，从而免去组合搜索（§1，pp.1–2）。

随之而来的三个问题构成方法主体：提示 token 与费用成正比，需要在预算内挑选最有信息量的工作负载描述；LLM 可能给出极慢的配置，需要限制评测坏配置的时间；切换配置（尤其建索引）代价高，需要降低重配置开销（§1，p.2）。

依据：§1–§2，PDF pp.1–3。
