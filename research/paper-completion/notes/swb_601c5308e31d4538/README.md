# Caselli & Vossen — The Event StoryLine Corpus: A New Benchmark for Causal and Temporal Relation Extraction

本文发布 Event StoryLine Corpus（ESC）v0.9：在 ECB+ 的 22 个灾难/犯罪类话题、258 篇新闻上，加标时间锚定关系（TLINK，6,904 条）和解释性“情节关系”PLOT LINK（人工 2,265 条，借文档内事件共指扩展为 5,519 条），并提出 StoryLine Extraction 任务。三个简单基线在 PLOT LINK 检测上最高 F1 仅 0.265，分类 F1 最高 0.14。已读正文 §1–§5 与 Tables 1–3。
