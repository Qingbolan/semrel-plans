# 贡献与评价

原文声称（§1、§5，PDF pp.1、8）：

1. 首个 StoryLine Extraction 基准语料 ESC v0.9，并提出该任务。
2. PLOT LINK 介于时间与因果标注之间：涵盖因果、使能、阻止，也包括条件、子事件、蕴含、共同参与等事件关系；允许隐式与跨句关系（§2.3，p.4）。
3. 与 TimeML、RED、ECB+、Causal-TimeBank 等方案兼容；借助 ECB+ 的文档内/跨文档共指，可将关系扩展到跨文档层面，适合跨文档摘要（§1、§5）。
4. 公开数据、评测脚本与三个基线（GitHub cltl/EventStoryLine）。

阅读者分析：事件、时间表达式和共指全部继承自 ECB+，本文新增的是 TLINK 锚定与 PLOT LINK 两层。PLOT LINK 的“为什么发生”定义宽泛，IAA（Dice 0.638）中等，且按话题差异较大（0.48–0.723），作为金标准时噪声不小。基线仅为共现/PPMI 启发式，不足以说明任务的可学习上限。
