# Zhang et al. — SciER: An Entity and Relation Extraction Dataset for Datasets, Methods, and Tasks in Scientific Documents

SciER 是面向科研论文全文的实体与关系抽取数据集：106 篇 AI 论文、24,518 个实体（Dataset/Method/Task）和 12,083 条关系（9 种细粒度类型），另设 6 篇 2023–2024 年论文作为分布外（OOD）测试集。评测对比了 3 个监督方法与 3 个 LLM 的零/少样本 pipeline 和 joint 抽取；最好的端到端严格关系抽取 F1 仅 61.10（HGERE），LLM 最好 41.22。已阅读正文、Limitations 和附录 A–C。
