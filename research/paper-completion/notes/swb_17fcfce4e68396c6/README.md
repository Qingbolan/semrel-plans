# Habernal & Gurevych — Argumentation Mining in User-Generated Web Discourse

本文构建并分析了一个来自网络用户生成内容（评论、论坛帖、博客、新闻）的论证挖掘语料，覆盖 6 个教育争议话题。先在 990 篇文档上标注是否为“切题且有说服意图”（Fleiss κ=0.59），再在 340 篇文档上按改造的 Toulmin 模型做 token 级论证成分标注（logos 维度 αU=0.48）。随后把论证成分识别做成句子级序列标注，最佳 SVMhmm 的 Macro-F1 为 0.251，人类为 0.602；跨领域时只用词向量特征最好（0.209）。已读引言、语料构建、一致性、实验与结论；§2–3 理论背景与相关工作、§4.4.8 后半到 §4.4.10（各类分歧现象与 pathos 维度）只略读。
