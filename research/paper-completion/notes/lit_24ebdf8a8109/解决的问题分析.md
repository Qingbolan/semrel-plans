# 解决的问题

**形式化（§3.1，p.4）**：输入为下游任务 T、固定学习算法 a0、初始可执行数据状态 D0、训练与评测资源预算 B（时间或算力）。数据状态 D 是一个可执行配置：包括可用数据源、选择与组合后的训练子集、把它们转换成算法最终输入的处理逻辑。智能体在 B 内从 D0 可达的数据状态集合 Π_B(D0) 中搜索，输出 D* = argmax E(T, a0, D)，E 为下游性能。

| 项 | 内容 |
|---|---|
| 输入 | 任务描述与指标、固定训练代码/基座模型、初始 DataLoader（或仅算法骨架）、12 小时与相同算力预算（§4.2） |
| 动作 | 红节点：生成搜索查询、筛选外部来源、写入 Data Pool；黑节点：选源、组合、清洗、构造特征、产出可执行 DataLoader 并提交训练（§3.3） |
| 反馈 | 黑节点的下游评测分数 y_v 与诊断 φ_v，写入 Global Memory（§3.3–3.4） |
| 输出 | 最佳节点的数据状态及其训练出的模型/提交 |
| 工作单元 | 一个节点 = 一次数据工程步骤；评测单元为一个竞赛或一项后训练能力 |

**搜索控制（§3.5，pp.6–7；附录 C）**：每个红节点后接一小批并行黑节点（默认最多 5 个）；外部轻量控制器根据最新反馈决定继续加深还是开新红节点；调度用 UCB1 式分数 R_v/N_v + c_t·sqrt(log N_par/N_v)，黑节点分数沿根路径回传，红节点成功完成给 ε=0.01 奖励，c_t 分阶段线性衰减（c0=2、cmin=0.5、阶段比例 0.3/0.7）。

阅读者分析：与“给定数据上的语义算子查询”不同，本问题的输出不是查询结果而是一份训练数据配置，正确性只由下游指标定义，不存在逐条金标准。
