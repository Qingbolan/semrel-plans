# 贡献与评价

作者陈述的三项贡献（§1，PDF p.2）：（1）DeonticBench，作者称其为目前最大的、面向真实高风险领域的可执行规则推理基准；（2）对前沿模型的全面评测与失败模式分析；（3）训练策略研究，指出现有 RL 方法的局限。

**具体新增内容**（§2，PDF pp.3–5）：

- 新建 USCIS-AAO：从 2022–2025 年 AAO 非先例决定中筛出 6,483 个结构完整（Law / Analysis / Order 三段）的案例，按标签和年份分层抽样得到 242 个平衡案例；由于 Analysis 段会泄露判决，用 GPT-5-mini 生成“仅事实”叙述并经人工修订（§2.3，PDF pp.3–4）。
- 为全部实例生成参考 Prolog：用 o3 即时生成法条模块与问题程序，只有在 SWI-Prolog 中干净运行且答案与金标一致才保留；失败后带编译器反馈重试一次，再失败则丢弃该实例（§2.4，PDF p.4；附录 B.1，PDF p.15）。
- 困难子集：作者认为这是“最具推动作用的贡献”（§2.5，PDF p.4）。

阅读者分析：参考 Prolog 以“答案与金标一致”为过滤条件，因此被保留下来的实例天然偏向 o3 能形式化的样本；Housing 仅保留 6,853 个 rc 问题中的 5,314 个可能与此有关，但原文未说明丢弃原因的分布。困难子集候选的判定使用 o3、GPT-5.2、Claude 4.5 Sonnet 的失败结果，这些模型随后又出现在主表中，存在选择偏差（附录 B.2，PDF p.16）（阅读者分析）。
