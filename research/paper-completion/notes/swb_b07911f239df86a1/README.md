# Zeldes — The GUM Corpus: Creating Multilayer Resources in the Classroom

本文介绍在乔治城大学语言学课程中由学生建设的多层英文语料 GUM（首轮 25 篇、22,656 token，四种网络文体），涵盖 POS、TEI 结构、成分与依存句法、实体/信息状态/共指和 RST 语篇结构，并逐层评估学生标注质量。主要结果：学生校正后的依存准确率达到 90 多，共指 markable F1 0.9476、关系 F1 0.8616，RST 挂接/标签准确率约 87%；混合效应模型案例展示跨层研究。已阅读全文正文（§1–5）；未查对参考文献。
