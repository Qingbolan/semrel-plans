# 出发点

作者指出，安全分析师需要在大量异构日志中沿多跳证据链追查威胁，而 LLM 智能体已能在代码、数据库等环境中多步观察与行动，因此自动化威胁调查是有前景的方向（§1，p.1）。

现有网络安全 LLM 评测多偏向知识记忆或信息抽取，例如 CTIBench 的多选问答、SECURE 的抽取与理解，而不是检验智能体在真实日志上的调查与推理能力（§1、§2，pp.1–2）。作者因此要求新基准具备足量安全事件日志、跨多阶段攻击类型的异构性，并能交互执行查询。

另一个动机来自出题方式：直接让 LLM 读事件详情出题，会得到泛泛、缺乏确定答案或依赖数据库外知识的问题（§3.2，p.4）。作者观察到 SOC 调查本质上是"从种子告警/实体出发、沿 IoC 跳转"的关系式过程，这促成了基于二部图的出题方法。

依据：arXiv:2507.14201v3，§1–2、§3.2，PDF pp.1–4。
