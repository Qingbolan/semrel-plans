# 具体用例

Figure 4（p.7）给出 GPT-4o 基线智能体的一条完整轨迹。

**问题**：已知 2024-07-17 11:01:27 有来自匿名 IP `170.54.121.63` 的登录，这属于一个更大事件；问"可疑收件箱规则操作涉及的账户 SID 是什么"。

**智能体过程**：

1. `SHOW TABLES` 获取表列表，再对 SigninLogs 查询，先因列名 `Timestamp` 不存在报错，之后 `DESCRIBE` 获取 schema。
2. 按 IP 与精确时间查询结果为空，改用日期前缀匹配后得到用户 ID。
3. 用该 ID 查 EmailEvents 得到邮箱地址，再查 EmailPostDeliveryEvents 得到 NetworkMessageId。
4. 经 AlertEvidence 找到告警 ID，最后取 AccountSid 并提交，共 16 步。

**参考解法**只需两步：由登录取得用户 ID，再由该 ID 取得账户 SID。作者据此说明基准允许多种可行搜索路径，主要难点是对数据库建模准确以写出有效查询（§4.1，p.7）。

阅读者分析：这一用例体现了"空结果后放宽谓词""跨表用 ID 连接"的典型调查模式；但答案仍是表中已有的单个字段值，不涉及生成自由文本报告。
