# 解决的问题

论文回答两个研究问题（§1，p.2）：
1. 基准要满足哪些标准，才能指导公共部门安全、负责地采用 LLM 智能体？
2. 现有智能体基准在多大程度上满足这些标准？

**RQ1 的输出**：从 7 个公共行政与自动化理论（自动化任务理论、街头/屏幕/系统层官僚、数字时代治理、人工裁量、算法治理、创新扩散、TOE 框架）归纳出的标准，分两组（§3、Figure 1，pp.4–5）：

| 组别 | 标准 | 要点 |
|---|---|---|
| 构建 | 基于任务/流程 | 单个任务有意义，且任务之间有依赖关系 |
| 构建 | 任务真实 | 单任务真实，任务整体分布也代表真实工作 |
| 构建 | 公共部门特定 | 任务确实在公共部门出现，或受相同约束 |
| 指标 | 顶层性能 | 准确率、F1 等 |
| 指标 | 成本 | 单 token 成本 × 每任务 token 数，可画成本–性能帕累托曲线 |
| 指标 | 公平 | 不同群体之间的表现差异 |

**RQ2 的输入与单位**：在 arXiv 及 ICLR、NeurIPS、ACL Anthology 中用 “LLM”“Benchmark”“Agent” 检索得到的论文，工作单位是一篇论文；输出是对每篇论文每条标准的 Yes/No/Unknown 标签及一句分析（§4–§4.1，pp.7–8）。

阅读者分析：标准是“理想型”，作者明确不考虑实现成本和技术可行性（§3，p.4）；评估只检查是否报告了公平指标，不判断其是否合适（§3.2，p.7）。

依据：§1、§3–§4.1，PDF pp.2–8。
