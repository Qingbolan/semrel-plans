# Rystrøm et al. — Agent Benchmarks Fail Public Sector Requirements

本文从公共行政理论推导出公共部门 LLM 智能体基准应满足的标准（基于流程、任务真实、公共部门特定、报告成本与公平等指标），再用经专家校验的 LLM 辅助流程筛查 1,300 余篇智能体基准论文。结论是没有任何基准同时满足全部标准：漏斗从 640 篇到 518 篇智能体基准、308 篇真实、94 篇基于流程、8 篇公共部门相关、0 篇同时报告所需指标。已阅读正文、局限和附录 A–C（提示、模式、问卷、理论表）。
