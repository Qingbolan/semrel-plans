# Li, He et al.（Microsoft）— Table-GPT: Table-tuned GPT for Diverse Table Tasks

本文提出“table-tuning”：用从真实表格合成的（指令, 表格, 完成）三元组继续微调 GPT-3.5 与 ChatGPT，得到 Table-GPT，以提升表格理解与表格任务能力，同时保留对未见任务的指令泛化。主要结果是在 26 个测试数据集 × 2 个基座 × 零/少样本共 104 组比较中，调优模型胜 98 组、平 3 组、负 3 组（§5.2）。已阅读正文 §1–§6、Tables 1–6 与 Figures 10–15 的文字说明；附录 A（pp.16–47）为各任务提示词样例，只抽查开头。
