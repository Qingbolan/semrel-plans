# 解决的问题

**任务形式**（§4.1，PDF pp.5–6）：每个任务为 T=(I, G, C, M) 或 T=(I, G, C)，其中：

| 组件 | 含义 |
|---|---|
| I（Instruction） | 总体任务目标 |
| G（Guidelines） | 由多条领域规则组成的指南，每条规则含触发条件与操作 |
| C（Context） | 相关文本，如价格匹配中的商品信息、数学题描述、对话记录 |
| M（Multiple Options） | LLM 生成、质量不一的候选回答（只在部分类别中存在） |

模型先输出分析，再基于任务和分析输出最终答案：pθ(T)→analysis，pθ(T, analysis)→answer（§4.2，PDF p.6）。

**两种题型**：agent 对话、摘要、幻觉检测三类为多选题（选出最符合指南的选项）；审计算法、价格匹配、文本相关性、数学四类为问答题（直接生成正确答案）（§3.2 脚注 2，PDF p.3）。

**评价**：将模型答案与人工标注的参考答案或最优选项对比，计算标签准确率；对多选类另报告精确率和召回率（§4.2、§5.1，PDF pp.6–7）。

作者声称从三方面评测：遵守多样规则、对规则更新的鲁棒性、与人类偏好的一致性（摘要、§1，PDF pp.1–2）。

阅读者分析：正文没有单独报告"原规则与更新后规则"两组的对比结果，Table 1 只按类别报告整体准确率。因此"对规则更新的鲁棒性"体现在数据构建中（§3.2.3 用 LLM 改写规则），而不是一个可单独读出的指标。

依据：[ACL 2025，pp.11361–11399](https://aclanthology.org/2025.acl-long.557)，§3.2、§4.1–4.2、§5.1，PDF pp.3–7。
