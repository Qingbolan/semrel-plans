# 出发点

LLM agent 越来越依赖 skill（编码任务流程、领域知识和操作准则的可复用文档），瓶颈转向如何为每个领域编写并维护高质量 skill（§1，p.1）。

作者指出三点不足：

- 人工 skill 不能普适地帮助所有 agent：Table 1 中 Anthropic 官方 xlsx skill 让 122B agent 的 Vrf 从 27.67 升到 48.33，却让 35B agent 从 19.00 降到 9.67（p.4）。
- 仅凭参数化知识生成的 skill 缺少真实执行暴露出的失败模式与变通办法；Parametric 基线接近 No Skill（§3.2，p.5）。
- 已有经验利用方法或在测试时检索单条经验，或随轨迹到达顺序依次编辑 skill；前者把知识碎片化，后者使结果依赖更新顺序（§1、Figure 1，pp.1–2）。

作者借鉴人类专家的做法：先广泛查看大量轨迹、归纳反复出现的模式，再写出紧凑可复用的流程（§1，p.2）。
