# 贡献与评价

作者声明的贡献（§1，p.2）：

1. Trace2Skill 框架：并行地从大量轨迹提取补丁，再一次性多对一合并，用于 skill 创建与深化。
2. 实验证据：轨迹驱动的 skill 可跨模型规模、模型家族和 OOD 任务迁移。
3. 分析：并行合并优于顺序更新；单一合并 skill 优于检索式推理记忆（ReasoningBank）；agentic 错误分析产生更好的补丁；补丁价值具有组合性。

**评价（阅读者分析）**：

- 核心差异在于“并行 + 分层归纳合并 + 不依赖测试时检索”。与 ReasoningBank 和顺序编辑的对比在相同轨迹池和执行框架下进行（§4.1），归因比整系统比较更干净。
- 增益并不一致：Table 1 中多个单元为负，例如 122B 作者 Deepening +Success 的 WikiTQ −10.35，35B 作者 Creation 的 Soft 在 122B 用户下为 −7.70/−4.57/−5.83（p.4）。“通常 +Combined 最好”是对 Avg 的概括。
- Avg 把 ID 与 OOD 等权平均，且跨两种用户模型；作者选它作为主指标（§3.2，p.5）。单列方差较大，Table 7 给出 Avg 标准差 ≤3.4（p.13）。
- 与 XSkill/EvoSkill/SkillGen 的整系统对比在附录 G，由作者在自己的开放模型协议下复现，作者也承认这只反映这些系统在本设置下的表现（p.19）。
