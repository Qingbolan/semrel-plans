# 解决的问题

LexGLUE 要回答的问题是：在统一格式与指标下，通用与法律领域预训练模型在多种英文法律理解任务上的表现如何（§1、§3，PDF pp.1–4）。

**任务接口**（§3.2、§4.3，PDF pp.4–6）：

| 数据集 | 输入 | 输出 |
|---|---|---|
| ECtHR Task A | 案件事实段落列表 | 被判违反的 ECHR 条款集合（10 条 + 无） |
| ECtHR Task B | 同上 | 被指称违反（法院审议）的条款集合 |
| SCOTUS | 最高法院意见书全文 | 14 个议题领域之一 |
| EUR-LEX | 欧盟法律文本 | EuroVoc level 2 中最常见 100 个概念的多标签 |
| LEDGAR | 合同条款（段落） | 100 个最常见主题之一 |
| UNFAIR-ToS | 服务条款中的一句话 | 8 类不公平条款（可为空） |
| CaseHOLD | 判决摘录（holding 被遮蔽）+ 5 个候选 | 正确 holding |

**选择标准**（§3.1，PDF pp.3–4）：仅英文；需要一定法律理解；对当时最先进方法仍有提升空间；公开且有论文记录；排除少于 5K 文档的小数据集。

**为评测所作简化**：截取标签子集、按时间重新划分；多标签任务在评估时额外加入"无标签"类，否则 F1 会忽略真值与预测都为空的样本（附录 B，PDF p.17）。
