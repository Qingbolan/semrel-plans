# 贡献与评价

**原文贡献**（§1、§4.4，PDF pp.2、7）：
- 首个统一的英文法律 NLU 基准，含 7 个任务、统一指标（µ-F1、m-F1）和跨任务均值；
- 对现有数据做简化与时间切分，并在 Hugging Face Datasets 上发布（`lex_glue`），同时开源代码；
- 新发布 SCOTUS 数据集，把 SCOTUS 意见书与 Supreme Court Database 元数据结合（§3.2，PDF p.4）；
- 对 TF-IDF+SVM、BERT、RoBERTa、DeBERTa、Longformer、BigBird、Legal-BERT、CaseLaw-BERT 进行基线评测，对 512 token 模型使用分层变体处理长文档（§4.2，PDF pp.5–6）。

**评价（阅读者分析）**：
- 主要价值是整合与标准化，除 SCOTUS 外数据集均来自已有工作；新颖性在基准工程而非方法。
- 简化（只取高频标签、10 个 ECHR 条款等）降低门槛，但也让任务更易；附录 F 说明 CUAD 曾被考虑但未纳入（PDF p.19）。
- 每个模型只报告开发集最好种子的测试分数（§5.1），模型间差距多在 1–2 个点，缺少显著性检验，排序结论应谨慎。
- §4.2 脚注 13 给出标准 BERT 相对分层版本的差距为 −12.2% / −10.6% / −3.5%，附录 D 却写分层版本领先 +10.2 / +7.5 / +4.9 个百分点，两处数值不一致（阅读者分析，PDF pp.6、18）。
