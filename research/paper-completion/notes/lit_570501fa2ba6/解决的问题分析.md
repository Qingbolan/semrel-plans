# 解决的问题

**输入**：一个或多个已解析并索引到 OpenSearch 的 DocSet（文档树：内部节点为章节，叶节点为 11 类元素，如文本、表格、图片，各带 JSON 属性），以及用户的自然语言问题；规划时还提供 DocSet 模式（字段、类型、示例值和一个代表全文的 text-representation 字段）。

**输出**：表格结果或自然语言答案，同时向用户暴露 JSON 逻辑计划、生成的 Sycamore Python 代码、每个算子的中间数据和到原文的溯源；用户可修改计划或追问。

**工作单元**：一次查询对应一个逻辑算子 DAG。典型计划先用 queryDatabase 按元数据或关键词缩小候选，再用 llmExtract/llmFilter 在文档文本上做查询期抽取或过滤，最后用 groupByAggregate 或 llmGenerate 汇总。规划器看到的是整篇文档的模式，切块与重组由 Sycamore 处理（§6.1）。

依据：[arXiv:2409.00847v3，CIDR 2025，10 页](https://arxiv.org/abs/2409.00847)，§5.1、§6.1–6.2，pp.4–7。
