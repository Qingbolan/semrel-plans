# 解决的问题

**任务单元**：一个数据分析任务 u = (q, f, d, a)，即用户问题 q、数据文件 f（.csv、.xlsx、.sqlite 等）、可选数据描述 d 和答案 a（§2，p.3）。

**智能体形式**：遵循 ReAct，多轮 Thought–Action–Observation。Action 是写 Python 或 SQL 代码处理文件，或输出最终答案；Observation 是代码解释器的执行反馈。轨迹在输出答案或达到最大轮数 T（实验中 T=10）时终止（§2，p.3；§5.1，p.7）。

**输出**：最终答案文本（放在 `<answer>` 标签中），可能是数值、短语或描述性结论；评测时由 GPT-4o-mini 判定是否与金标准一致，BIRD 则把 SQL 结果物化为 CSV 后精确匹配（§4 Reward Design，p.6；附录 D，p.20）。

**范围限制**：只覆盖面向推理的分析问题；模型训练、预测和可视化类任务被有意排除，输入仅限表格文件与文本问题（附录 B，p.19）。TableBench 的趋势预测和图表生成题因无明确金标准被过滤（附录 D，p.20）。

依据：§2，p.3；§4，pp.4–6；附录 B、D，pp.19–20。
