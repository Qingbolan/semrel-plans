# Qiao et al. — Scaling Generalist Data-Analytic Agents

本文提出 DataMind：一套为开源数据分析智能体合成训练数据并训练的流程，产出 11,707 条轨迹的 DataMind-12K，并训练 Qwen2.5-Coder 7B/14B 模型。DataMind-14B 在 DABench、TableBench、BIRD 三个基准上平均 pass@1 为 71.16%，高于 GPT-5 与 DeepSeek-V3.1 的 ReAct 结果。已阅读正文 §1–§5 与附录 B（局限）、D–H（评测协议、基线复现、超参数、污染分析）；未审读附录 I 的全部提示词。
