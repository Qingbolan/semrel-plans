# MAVEN-ERE: A Unified Large-scale Dataset for Event Coreference, Temporal, Causal, and Subevent Relation Extraction

MAVEN-ERE 在同一批文档中统一标注事件共指、时间、因果与子事件关系。实验评估已给定事件触发位置上的关系识别；百万级关系数量不等于百万份文档，也不等于逐条独立的人工判断。关键结果：联合训练的时间/因果/子事件 F1 为 56.0/31.5/27.5，仅略高于独立训练。
