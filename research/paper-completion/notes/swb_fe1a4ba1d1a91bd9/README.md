# Vandamme, Cabay & Debeir — A Quantitative Evaluation of Trademark Search Engines’ Performances through Large-Scale Statistical Analysis

本文用 EUIPO 异议处 2016-03-23 至 2022-05-31 的 8,126 件图形商标异议决定作为“真值”，以申请人商标图像查询 EUIPO 与 BOIP 的官方图像检索引擎，看能否检索到异议人的商标及其排名。在相同的 5,757 次查询上，BOIP 的匹配率为 7.36%–11.72%，EUIPO（截断到前 50 条）为 62.01%–99.16%，且大多排在第 2 位；作者怀疑 EUIPO 系统可能就是用这些决定训练的。全文 8 页已通读，渲染核对了 Tables 1–5 与界值推导页。
