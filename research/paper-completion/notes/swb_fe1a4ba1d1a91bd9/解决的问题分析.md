# 解决的问题

**评测协议**（§2.1，p.3，Figure 1）：

| 项目 | 内容（原文） |
|---|---|
| 样本单位 | 一件 EUIPO 异议决定（双方均为图形商标） |
| 查询 | 申请人商标的高清图像（来自 EUIPO 注册簿，去除元数据并改为通用文件名后上传） |
| 系统 | BOIP 图像检索（最多返回 50 条）、EUIPO eSearch Plus 图像检索（可导出前 1,000 条）；另构造只取 EUIPO 前 50 条的 EUIPO-50 以便对比 |
| 相关项 | 异议人在决定中援引的商标 |
| 输出指标 | Match Ratio（结果中出现相关项的查询比例）；Rank（出现时的位置，从 1 开始） |

**基本假设**：无论 LoC 判定结果如何，异议人愿意承担异议成本，说明双方商标至少在其看来相似（§2.1）。

**两种匹配标准**（§2.3，p.4，Figure 2）：按商标 ID 精确匹配（偏严，同一权利人的近似变体排在前面也算未命中）；按权利人 ID 匹配（偏松，大权利人名下任一商标都算命中）。作者认为两者分别给出下界和上界。

**仅限单图对单图**：从 8,126 件决定中只保留申请人和异议人各一个图像的决定（§2.1；Table 1 中 1,121 件因多于一个图形商标被排除）。

这把法律决定转成了“以图搜图”的单相关项检索评测：每次查询只知道一个确定相关的结果，其余返回项未判定。论文 §2.2 承认，排在前面的其他商标可能同样构成 LoC，因此匹配率和排名都只是代理指标（阅读者分析）

依据：[ICAIL 2023, pp.343–350，8 页](https://orbi.uliege.be/bitstream/2268/322890/1/ICAIL2023.pdf)，§2.1–2.4、Figures 1–2、Table 1，PDF pp.3–5。
