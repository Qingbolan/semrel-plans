# Choi et al. — Taxation Perspectives from Large Language Models: A Case Study on Additional Tax Penalties

本文构建 PLAT 基准：从 100 篇韩国法院判例（50 篇认定存在免除加算税的“正当理由”、50 篇不认定）派生出二选一（含“不知道”选项）、带理由四选一和论述题三类共 300 题，用来检验 LLM 能否判断加算税处分是否合法。10 个 LLM 中 o3 与 Gemini2.5-pro 在 PLAT-MC 上 F1 最高，为 0.79；论文用 IRAC 框架分析，认为模型在“适用/结论”阶段最弱，RAG 帮助有限，ReAct 智能体检索主要提高作答率。已阅读正文与附录 A–I。
