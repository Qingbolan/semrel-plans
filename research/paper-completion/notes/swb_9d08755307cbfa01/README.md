# Saadat & Fellay — Large Language Models for Variant-Centric Functional Evidence Mining

本文以 ClinGen 专家注释为锚点，构建遗传变异功能证据（ACMG/AMP 的 PS3/BS3）挖掘基准，并比较 gpt-4o-mini 与 o4-mini。两项任务是摘要筛选（是否报告了直接检验变异的湿实验）和全文证据抽取与分类。摘要筛选召回率达 0.88–0.90；在变异匹配成功的论文上，o4-mini 的 PS3/BS3 方向分类准确率为 0.963，特异度 0.828（gpt-4o-mini 为 0.371）；证据强度分级仍很差。作者还发布了端到端流水线 AcmGENTIC。已阅读全文，含附表与提示词。
