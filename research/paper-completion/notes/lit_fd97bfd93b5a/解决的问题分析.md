# problem

形式化（§III-A，PDF p.2）：给定查询集合 Q、计划空间 P 和约束 C={c_mem, c_lat}，cost(q,p)=latency(q,p)；feasible(q,p)=1 当且仅当内存 ≤ c_mem 且延迟 ≤ c_lat；目标是在 feasible=1 的前提下最小化 cost。

- **输入**：一个 SQL 查询（来自固定模板）与数据库 schema/统计信息、资源约束。
- **动作空间**：teacher 对 6 个二值开关（early filtering、projection pushdown、pre-aggregation、join reordering、sampling、limit pushdown）的组合生成 SQL 改写，每个计划表示为 f∈{0,1}^6（PDF p.3）。
- **输出**：被选中的计划配置（在 DuckDB 上执行）。bandit 奖励：可行时 1 − latency/baseline_latency，否则 −1（式 5）。
- **工作单位**：单条查询的计划选择；student 学习“查询特征 → 计划”分类。

阅读者分析：这实际上是“查询改写开关组合选择”，不是完整的物理计划枚举；其中 sampling 会改变结果精确性，原文只说“在可接受精度范围内”，未定义精度约束或校验结果正确性。

依据：[arXiv:2605.17831v1，6 页](https://arxiv.org/abs/2605.17831)，§III，PDF pp.2–3。
