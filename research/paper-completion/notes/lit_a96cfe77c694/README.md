# Suri, Mathur et al. — VisDoM: Multi-Document QA with Visually Rich Elements Using Multimodal Retrieval-Augmented Generation

本文提出 VisDoMBench：由 5 个现有文档 QA 数据集改造的多文档、多模态问答基准（2,271 个查询，含表格、图表和幻灯片，每个查询混入干扰文档），以及 VisDoMRAG：并行运行文本 RAG 与视觉 RAG，再按推理链一致性融合答案。在 GPT-4o 上平均 F1 为 50.01，高于视觉 RAG 的 49.02 与长上下文的 32.78。已读正文、限制节与附录 A 中的数据和人工审核部分。
