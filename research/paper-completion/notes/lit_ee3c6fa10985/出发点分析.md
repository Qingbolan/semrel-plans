# 出发点

LLM 仅依赖参数知识，常产生事实错误。传统 RAG 不论是否需要都检索固定数量的段落，可能引入无关内容、降低模型的通用性；而且模型没有被训练去遵循段落，输出也不一定与检索内容一致（§1，PDF p.1）。

已有改进各有代价（§2，PDF pp.2–3）：
- 自适应检索或 API 调用方法会牺牲运行效率、对无关上下文的鲁棒性和可归因性；
- RLHF 依赖在线奖励模型，训练成本高；
- 迭代自我修正提示会增加推理开销。

因此作者希望用一个模型同时学会“何时检索、检索结果是否相关、输出是否有据”，并在推理时可控，同时为每段输出给出引用和自评，便于事实核查（§1，PDF pp.1–2）。
