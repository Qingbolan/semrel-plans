# 解决的问题

**形式化（§3.1，PDF pp.3–4）**：给定输入 x，模型 M 依次生成多个段落 y = [y1…yT]，实验中每段为一个句子。输出中夹带四类反思 token（Table 1）：

| token | 输入 | 取值 |
|---|---|---|
| Retrieve | x 或 x, y | yes / no / continue |
| IsRel | x, d | relevant / irrelevant |
| IsSup | x, d, y | fully / partially / no support |
| IsUse | x, y | 1–5 |

**推理（Algorithm 1）**：每段先预测 Retrieve。若需要检索，就取 K 个段落并行生成 K 个候选，并分别预测 IsRel、IsSup、IsUse，然后按加权得分排序；否则直接生成，并只预测 IsUse。

**训练**：先用 GPT-4 标注的 4k–20k 条/类数据训练 critic C（Llama2-7B）。C 离线给 15 万条指令数据插入反思 token 和检索段落，再用标准下一 token 目标训练生成器 M。检索段落不计入损失（§3.2，PDF pp.4–5）。

阅读者分析：工作单位是“一条指令/问题 → 带引用的生成文本”。检索语料为 Wikipedia 等段落集合，不涉及结构化数据。
