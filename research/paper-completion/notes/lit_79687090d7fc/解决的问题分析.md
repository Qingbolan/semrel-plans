# 解决的问题

**任务形式**：给定文字描述的用户查询 x 和数据 D，系统输出满足要求的图 V，即 V = f(x, D)；f 可以是单个 LLM 或 LLM 智能体（§2，公式 1，p.3）。

- x 规定图的类型、要画的数据、单个元素或整体的结构/空间要求、审美偏好；
- D 是一组数据点，可由用户在查询中给出，也可存放在外部数据文件（如 data.csv）中。

**评测单元**：一个“查询＋原始数据＋标准图”三元组，共 100 个（§3.1，p.4）。

**评分方式**：把模型生成的图和标准图一起交给 GPT-4V，要求以标准图为 100 分给生成图打 0–100 分，主要看与标准图的相似程度；空白图（代码运行失败）记 0 分；若查询要求随机数据，则不必与标准图完全一致（§3.2，附录 A.1、Figure 6，pp.4、12）。

**MatPlotAgent 的模块分工**（§4，Figure 3，pp.4–5）：

| 模块 | 输入 | 输出 |
|---|---|---|
| 查询扩展 | 用户查询 | 分步骤的详细编码指令（用哪些库、函数、参数、如何处理数据） |
| 代码智能体 | 详细指令；运行报错 | 绘图代码；自调试最多 3 轮 |
| 视觉智能体 | 用户查询、当前草图 | 改进建议，交回代码智能体 |

视觉智能体不参考标准图，只看当前草图（§5.4，p.7）。

阅读者分析：正文没有说明视觉反馈循环的轮数上限，只给出自调试上限 3 轮；成本和延迟也未报告。
