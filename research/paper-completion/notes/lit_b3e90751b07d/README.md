# Freire, Fan, Feuer et al. — Large Language Models for Data Discovery and Integration: Challenges and Opportunities

这是 NYU 团队发表在 IEEE Data Engineering Bulletin 2025 年 3 月刊的综述/观点文章，梳理 LLM 在数据集发现（表搜索、可连接/可合并表搜索、其他目标导向发现）与数据集成（模式匹配、实体解析）中的用法，并给出局限与研究方向。核心判断是：LLM 能缓解语义异构，但在可扩展性、实例数据处理、成本与评测细粒度上仍有明显缺口；可连接/可合并表搜索中尚无直接用 LLM 的方法。全文无自己的实验。已阅读正文全部（§1–5）与 Tables 1–2。
