# 工作负载

本文是综述，没有自己的数据集、查询集、实验划分或指标；以下只记录论文转述的、与工作负载相关的内容。

**CleanML 基准**（§2.2，p.7）：收集 13 个真实数据集，含离群值、重复、不一致、错误标签、缺失值 5 类错误，测试这些错误对 7 种典型 ML 模型（如逻辑回归、决策树、随机森林）的影响。Table 3 汇总结论：

| 错误类型 | 清洗有正面影响 | 清洗有负面影响 | 模型选择能改善 |
|---|---|---|---|
| 重复 | - | ✓ | ✓ |
| 离群值 | ✓ | ✓ | ✓ |
| 不一致 | - | - | ✓ |
| 错误标签 | ✓ | - | - |
| 缺失值 | ✓ | - | ✓ |

论文文字解读：清洗重复值会降低模型效果，但可通过选择模型缓解；离群值清洗的正负影响取决于数据集；修正错误标签和填补缺失值有正面影响（p.7）。

**数据来源类别**（Table 1，p.4）：Web、人工与知识库、隐藏数据库（deep web）、训练数据本身、数据湖、数据仓库。

**众包规模**（§2.3.1，p.7）：借助 AMT 这类平台可雇佣数十万众包工人。
