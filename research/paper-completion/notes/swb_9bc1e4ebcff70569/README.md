# Zhu, Lei, Feng, Wang, Zhang & Chua — Towards Complex Document Understanding By Discrete Reasoning

本文提出 TAT-DQA：一个基于真实财报的文档视觉问答数据集，共 2,758 个文档（3,067 页，来自 182 份财报）和 16,558 个问答对，答案常需加减乘除、计数、比较等离散推理。作者同时提出 MHST 模型（LayoutLMv2 编码 + 答案类型分类 + 序列标注 + 表达式树生成）。测试集最佳结果为 EM 41.5、F1 50.7，远低于人类专家的 84.1/90.8。已读全文 §1–§6 及全部表格。
