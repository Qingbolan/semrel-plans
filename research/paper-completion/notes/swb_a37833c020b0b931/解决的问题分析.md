# 解决的问题

**任务**：给定一篇文档，自动切分为子句（SPADE + 启发式后处理），为每个子句预测 SE 类型（§4，p.1759；§5，p.1760）。

**标签集**（7 类 + undecided）：STATE、EVENT、REPORT（EVENT 的引语子类）、GENERIC SENTENCE、GENERALIZING SENTENCE、QUESTION、IMPERATIVE（Figure 1、Table 2）。抽象实体（FACT、PROPOSITION）不进入主分类，作为单独的识别步骤（§2、§7）。

**输入单位与输出**：输入为文档的子句序列；输出为同长度的标签序列。模型是线性链 CRF，特征函数包括“标签×观测特征”和“相邻标签对”两类；只用前者时等价于 MaxEnt（§5.2，p.1761）。

**关键语言学线索**（§2，p.1758）：主动词（依存树中最高的非助动词）决定基本体貌类；主指称（通常为主语）区分类指/特指；惯常性是整句属性。情态、否定、完成体等会把本应是 EVENT 的子句转为 STATE，例如 “John might win”。

**附带子任务**：名词短语类指性与子句惯常性。作者也试过“先预测这两个子任务、再规则推出 SE 类型”的流水线，但不如直接建模（§5.2、§6.3）。

依据：§2、§4–5，pp.1758–1761；§6.3，p.1763。
