# 贡献与评价

**作者声称的三点优势**（§1，PDF p.2）：

1. **完整 schema**：162 个事件类型、612 个论元角色、14,655 词定义。一位作者和两位语言专家耗时三年设计，以 FrameNet 框架元素为基础，并按 5W1H 补充（§2.1，PDF pp.2–3）。
2. **规模大**：107,507 个事件提及（触发词）、290,613 个论元、129,126 个实体提及，全部人工标注（§1、Table 2，PDF pp.2–4）。
3. **标注穷尽**：文档级、全部细粒度事件、实体与非实体论元都标注，因此支持 EAE 的所有任务变体（§3.1，PDF p.4）。

**质量控制**（§2.2–2.3，PDF p.4）：

- 实体标注由 47 人完成，三人独立标注后多数投票；实体识别 Fleiss' κ 73.2%，实体共指 78.4%。
- 论元标注由 202 人分三阶段完成；抽 100 篇文档做两次独立标注，κ 为 68.6%。
- 总标注成本约 85,000 美元（附录 A.2，PDF p.15）。

**阅读者分析**：

- 贡献主要是资源和集成，不提出新模型。
- "612 个角色"指定义不同的角色数，独立角色名只有 143 个（§2.1，PDF p.3）；与其他数据集比较 schema 规模时口径不同。
- 本文依赖 MAVEN 的触发词和 MAVEN-ERE 的共指。构建中修正或丢弃了部分触发词，因此三个版本的触发词数不一致：118,732 / 112,276 / 107,507（附录 Table 9，PDF p.16）。联合使用时需要对齐。
