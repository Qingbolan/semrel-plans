# Wang et al. — MAVEN-Arg: Completing the Puzzle of All-in-One Event Understanding Dataset with Event Argument Annotation

MAVEN-Arg 在 MAVEN（事件检测）和 MAVEN-ERE（事件关系）的基础上补充了事件论元标注，形成同时覆盖事件检测、论元抽取和关系抽取的英文数据集。它包含 162 个事件类型、612 个论元角色、4,480 篇文档、98,591 个事件和 290,613 个论元。微调模型最高 F1 约 40%，GPT-4 两例上下文学习约 30%。已阅读正文、Limitations 和附录 A–E；未复现实验。
