# 解决的问题

**基准任务**：输入一个自然语言问题和目标数据库（模式及内容），输出可执行 SQL。指标是执行准确率：预测 SQL 与 Dev 金 SQL 的结果集是否一致（§5.2，PDF p.10）。

**数据构造任务**：输入每个库的 100 条专家 Seed NL/SQL 对，输出合成 NL/SQL 对，分四个阶段（§3.3，PDF pp.5–7）：
1. **Seeding**：把种子 SQL 转为 SemQL AST，把表、列、值叶子替换为占位符，得到模板；
2. **SQL 生成**：借助“增强模式”（不可聚合列、类别列、可做数学运算的列、可读别名）按 Algorithm 1 采样填充叶子；
3. **SQL→NL**：用微调的 GPT-3 为每条 SQL 生成 8 个候选问题；
4. **判别**：用 SentenceBERT 嵌入取最接近候选中心的 1–2 个问题。

阅读者分析：评测单位是“一条 Dev 问题对一条金 SQL”。合成数据只用于训练，不用于评测；Dev 集完全由人工构造。
