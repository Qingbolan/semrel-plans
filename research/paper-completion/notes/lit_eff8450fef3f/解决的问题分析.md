# 解决的问题

**评测单元**：一个 Kaggle 竞赛，包含（§2.1，p.2）：

- 从竞赛网站 Overview 和 Data 页抓取的描述；
- 竞赛数据集（多数情况下是新的训练/测试划分）；
- 本地评分代码；
- 私有排行榜快照（2024 年 5–8 月抓取）。

**智能体的输入与输出**：在 Ubuntu 20.04 Docker 容器中拿到数据、描述和一个本地校验服务；输出一个 CSV 提交文件（§2.3、§3，pp.4–5）。校验服务只告诉提交是否合法，不返回分数，调用次数不限（§2.3，p.5）。

**规则**（§2.3.1，p.5）：预测必须由智能体训练的模型产生，不能凭自身知识直接写标签；不能查看网上解法。违规用 GPT-4o 日志检查工具判断（附录 A.3 写明实际用 GPT-4o mini），抄袭用 Dolos 对比该竞赛前 50 个公开 notebook，相似度超过 60% 即取消资格。

**评分**（§2.2，p.4）：

| 指标 | 含义 |
|---|---|
| 奖牌 | 按竞赛队伍数套用 Kaggle 的铜/银/金阈值（Table 1），与私有榜比较 |
| Any Medal（主指标） | 获得任意奖牌的尝试占比 |
| 原始分数 | 各竞赛自有指标，跨竞赛难以汇总 |

另报告 Made Submission、Valid Submission、Above Median（Table 2）。所有竞赛都套用奖牌阈值，即使原竞赛不发奖牌（§2.2）。

依据：§2.1–2.3.1、Table 1，PDF pp.2–5；附录 A.3，p.15。
