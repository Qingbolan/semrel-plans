# Chan Jun Shern et al. — MLE-bench: Evaluating Machine Learning Agents on Machine Learning Engineering

MLE-bench 把 75 个 Kaggle 竞赛离线化，作为评估 AI 智能体端到端机器学习工程能力的基准：智能体拿到竞赛描述和数据集，在 24 小时内产出 submission.csv，本地评分后与竞赛私有排行榜比较是否达到奖牌线。最佳配置 o1-preview + AIDE 在 16.9% 的竞赛中拿到奖牌（pass@1），pass@8 时为 34.1%。已阅读正文 §1–7 及附录 A.1–A.3、A.6、A.7 开头、Tables 9–10；未逐行核对 Table 8 全部 75 个竞赛的划分说明。
