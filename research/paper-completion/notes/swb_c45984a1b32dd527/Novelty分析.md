# 贡献与评价

**论文声称的贡献**：
- 执行接口决定归纳知识的价值：同一段文本作为子程序执行，在全部 10 个模型–任务设置上优于作为检索技能（两个模型平均 +11.6、+15.6 个百分点），在 9/10 上优于改写成 Python 工具（+7.9、+19.1）。
- ARISE 比 ReAct 最多高 45.4 个百分点，比各模型最强的经验适应基线高 6.1–10.8 个百分点，比 ASI 高 11.5 个百分点。
- 不需要专家设计工具；库可以不经修改迁移到其他模型。

**阅读者分析**：与 DSPy、分解式提示等“每个模块一次 LLM 调用”的方法相比，新意在于模块及其规格从轨迹自动归纳，并由智能体在运行时组合。附录 F 的内容消融有助于区分“额外 LLM 调用”与“归纳内容”的作用：换成通用描述后，Gemini 五任务平均从 78.4% 降到 67.7%。但主表多为单次运行；每个模型只在 5 个任务上评测，Gemini 的会议安排（AWM 88.0 vs 80.0）和 NBA（AWM 74.2 vs 71.2）上 ARISE 并非最佳。DeepSeek-V3 上 ARISE 的平均总成本最高（5.23 美元/任务，NBA 21.26 美元）。

依据：[arXiv:2606.02994v2，27 页](https://arxiv.org/pdf/2606.02994)，§1、§5.1–5.2、Table 2、附录 F、I（Table 12），PDF pp.2–8、18–22。
