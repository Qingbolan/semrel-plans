# Ramisch et al. — Edition 1.1 of the PARSEME Shared Task on Automatic Identification of Verbal Multiword Expressions

本文是 PARSEME 共享任务第 1.1 版（2018）的综述。论文介绍改进后的动词性多词表达（VMWE）标注指南、新类别体系和统一判定树，20 种语言的语料（共 79,326 个 VMWE），cupt 数据格式，评测指标，以及 12 支队伍提交的 17 个系统的结果。封闭赛道最佳 TRAVERSAL 的宏平均 F1-MWE 为 54，开放赛道 SHOMA 为 58.09；未见过的 VMWE 是最大难点。已阅读正文 §1–8 与附录 B 结果表，渲染核对了 p.14 的 Table 2。
