# 解决的问题

**任务 1：法律合规判断**（§4.3，PDF p.6）

| 要素 | 内容 |
|---|---|
| 输入 | 一个案例情境文本（判例、隐私政策、合成情境）及目标法规域（HIPAA / GDPR / AI Act / ACLU 相关法律） |
| 输出 | 三分类：允许（permit）、禁止（prohibit）、不适用（not applicable） |
| 单位 | 单个案例；用正则解析模型回答，解析失败计为错误 |
| 指标 | 准确率，另报每类 P/R/F1（Table 3）与 micro-F1（Table 12）；单次运行 |

**任务 2：情境理解探测**（§3.2.2、§4.3，pp.4、6）：由 GPT-4o 先把样本拆成原子信息流，再抽取 CI 参数；每题询问情境中的某个 CI 要素，四选一。干扰项按 BERT-base 嵌入余弦相似度采样分三档：Easy 取最不相似、Medium 随机、Hard 取最相似。

**辅助知识**（§3.3，p.5）：法规被解析为按条款编号组织的文档树，叶子节点抽取 CI 参数（传输原则拆为 Purpose 与 Consent）；另建角色层级图 R 与属性层级图 A（WordNet + GPT-4o 扩充），用于把案例中的具体实体（如某公司）对齐到法规术语（如 Controller）。

**判定模块**（§4.1，p.5）：DP、CoT、RAG（LLM 先解释情境，BM25 检索子条款，再过滤）；消融时加入金标准 CI 参数（DP+CI）及适用法条（DP+CI+LAW）。

依据：§3–4，PDF pp.3–6；附录 B、Tables 15–16，pp.13、15–16。
