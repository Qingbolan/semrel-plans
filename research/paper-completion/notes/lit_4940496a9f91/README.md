# Hsu et al. — WebDS: An End-to-End Benchmark for Web-based Data Science

WebDS 是一个端到端的网页数据科学 benchmark，包含在 29 个网站上人工编写的 870 个任务：智能体从指定网址出发，找到数据，完成分析、可视化或报告，部分任务还要执行发帖等后续动作。评测分为 live 和 dockerized 两个赛道，用 LLM 判定成功与否，另给 1–5 分轨迹评分。最好的智能体 BrowserUse（GPT-5.1）成功率为 22.2%，人类约为 90%。已读正文和全部附录。
