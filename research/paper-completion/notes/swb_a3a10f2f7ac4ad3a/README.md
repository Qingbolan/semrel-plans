# Martí, Taulé, Bertran & Màrquez — AnCora: Multilingual and Multilevel Annotated Corpora

本文描述 AnCora：加泰罗尼亚语（AnCora-CAT）和西班牙语（AnCora-ESP）两份各 50 万词的新闻语料，多层标注 PoS、成分句法与句法功能、依存转换、论元结构与题元角色、动词语义类、强/弱命名实体，以及名词的 WordNet 义项。文中没有模型实验，质量证据是标注者一致性（成分标注 5 轮迭代后 LP 0.87、BP 0.91、CB 0.95），并说明语料用于 CoNLL-2006/2007 和 SemEval-2007 Task 9。已读全文正文（§1–6）与附录 1 的首尾部分。
