# Bunt & Prasad — ISO DR-Core (ISO 24617-8): Core Concepts for the Annotation of Discourse Relations

本文概述 ISO 24617-8（ISO DR-Core），即 ISO 语义标注框架 SemAF 中篇章关系标注的第一部分。它提出互操作标注的基本假设，定义 20 个“核心”篇章关系及其论元角色，给出抽象语法、具体 XML 语法 DRelML 与基于 DRS 的语义，并提供到 RST、SDRT、PDTB、Sanders 等分类的映射。本文是标准说明，没有语料统计或实验评测。已读全文正文（§1–5）。
