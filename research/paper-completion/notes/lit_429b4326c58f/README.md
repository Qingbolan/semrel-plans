# Luo, Ou, Zheng et al. — AutoMind: Adaptive Knowledgeable Agent for Automated Data Science

AutoMind 是面向 Kaggle 式数据科学任务的 LLM 智能体：用 455 个竞赛的 3,237 篇方案帖和近三年论文构建专家知识库，在解树上执行起草/改进/调试三类动作，并按计划复杂度在一次性生成与分步验证编码之间切换。在 15 个任务的 MLE-Bench 子集上，avg@3 胜率为 0.39（o3-mini）和 0.41（DeepSeek-V3），AIDE 同骨干为 0.28 和 0.36。已阅读正文 §1–7 与附录 A–C；未核对开源日志。
