# 评测与边界

**评测对象**：只有人工标注一致性，没有自动分析模型、基线或任务指标。

**指标选择**：EDU 切分在不同标注者之间很少完全相同，因此 Cohen's κ 和 token 级 Fleiss' κ 都不适用。作者选用 Krippendorff 单元化 α：它可处理多 token 单元、任意人数、稀疏数据和名义特征；切分与关系标注原则上可分别计算（§2.2）。

**实验 1（初始 22 关系集）**：3 篇文本的 α 为 0.2792、0.3173、0.4965，远低于约 0.8 的期望（§2.2）。

**实验 2（精简关系集后）**：另 3 篇文本的 α 为 0.7768、0.691、0.7615（§2.3）。

**边界**：

- 两轮使用不同文本，样本都只有 3 篇短新闻，前后对比不是同一文本上的受控比较（阅读者分析）。
- 计算时忽略 span 关系；以拼接文本为 key，切分不同的关系会被视为不同单元。原文未单独报告切分一致性与关系一致性（阅读者分析）。
- 后续标注改为单人标注、他人检查，需要定期复测 IAA；自动 EDU 与关系识别实验计划在约 100 篇文本后开展（§3）。

依据：[Dialogue 2017，12 页](https://dialogue-conf.org/media/3938/pisarevskayadetal.pdf)，§2.2–§3，PDF pp.5–10。
