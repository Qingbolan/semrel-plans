# 工作负载

**规划规模**：语料将包含科学、科普、新闻和分析性评论等体裁，3 年内标注超过 100,000 token，并提供浏览、关系检索和 XML 下载（§2）。这是计划，不是已完成规模。

**实际报告的标注数据**：

| 轮次 | 文本 | 句数 | 关系集 | Krippendorff α |
|---|---|---|---|---|
| 第一轮 | 3 篇短新闻 | 34 / 26 / 38 | 初始 22 种 | 0.2792 / 0.3173 / 0.4965 |
| 第二轮 | 另 3 篇短新闻 | 37 / 44 / 28 | Fig. 4 精简集 | 0.7768 / 0.691 / 0.7615 |

第一轮约 190 个 EDU（§2.2）。作者认为可接受的 α 约为 0.8，第一轮“远低于”该值（§2.2）。原文未写明参与 IAA 的标注者人数。

**数据可得性**：第二轮 3 篇 XML 已放在 GitHub 仓库 `nasedkinav/rst_corpus_rus`；Web 界面待达到足够规模后再建（§2.3）。

没有训练/测试划分，也没有自动模型实验。

依据：[Dialogue 2017，12 页](https://dialogue-conf.org/media/3938/pisarevskayadetal.pdf)，§2、§2.2–§2.3，PDF pp.4–5、8–9。
