# 具体用例

**在 GitHub 模式集合上浏览与检索**（§3，Figure 4，p.4）：

1. **层次目录**：用户先看到少量主题，它们是底层约 170 万张表经聚类与 LLM 概括得到的。点击某个主题节点，它展开为一组更具体的短语，最终连到具体表与列。
2. **语义检索**：用户在左上角输入“user”或“info about users”，LEDD 改写查询、嵌入、在 Milvus 中检索，并把与用户信息相关的表和列从 IGinX 取回、在图中高亮。
3. **实时关系分析**：展开节点时，新节点与原图中最相似的 m 个节点交给 LLM 判断关系，关系描述作为边显示；Figure 4 展示了一条跨越非相邻层的边，帮助用户发现潜在相关数据集。
4. **算法扩展**：用户可在 Web 界面用类似 `CREATE FUNCTION UDSF 'gencatalog' FROM 'UDFGenHierarchy' IN 'UDFGenHierarchy.py'` 的语句注册自己的目录生成算法。

阅读者分析：该用例展示的是交互流程，没有说明检索结果的准确率，也没有给出用户研究；下游的训练数据选择、text-to-SQL 模式链接等应用只在 §1 与 §4 提及，未演示。
