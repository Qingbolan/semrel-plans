# 贡献与评价

原文列出的贡献（§1，PDF pp.2–3）：

| 贡献 | 内容 | 位置 |
|---|---|---|
| 框架 | SLM 候选检索 + LLM 或二分图重排的两阶段组合，可按代价选择变体（zs/ft × bp/llm） | §2.2，pp.3–4 |
| 自监督微调 | `llm-aug`：用 LLM 为目标表每列生成语义等价但写法不同的列（Figure 4 提示），配合 struct-aug，用 Batch Hard 三元组损失与在线难例挖掘训练 MPNet | §3.2，pp.5–6 |
| 列表示 | 优先级抽样（priority sampling，带协调的频率加权抽样）与三种序列化 Sdefault/Sverbose/Srepeat | §3.1，pp.4–5 |
| 重排提示 | 一个源列 + Top-k 候选，要求逐个打 0.00–1.00 分并给一例 one-shot；解析失败最多重试 3 次，再退回嵌入分数 | §4，pp.6–7 |
| 基准 | GDC 基准：10 项肿瘤研究数据与 GDC 标准的人工对齐 | §5，p.7 |

阅读者分析：两阶段“检索—重排”在信息检索与本体匹配（OLaLa、LLMs4OM，§7）中已有先例，本文的新意主要在于把它落到表模式匹配、用 LLM 合成训练数据替代人工标注、以及打分式列级提示；GDC 基准的价值在于真实生物医学异构性。微调只在目标表列上进行，以避免把未知真匹配误作负例（§3.2）——这让方法依赖目标模式固定的场景（阅读者分析）。

依据：§1–§5、§7，PDF pp.1–7、11–12。
