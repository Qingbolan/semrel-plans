# 贡献与评价

论文自述四点贡献（§1，p.2）：

1. 用 `F_T(R, S, D)` 统一描述多类数据操作任务；
2. 抽象出三步通用求解流程：上下文检索 → 上下文解析 → 目标提示构造；
3. 为每步设计提示模板：属性级检索 `p_rm`、记录级打分 `p_ri`（0–3 分取 top-k）、把序列化的 `attr:value` 转为逻辑句子的 `p_dp`、以示例把“claim”改写为完形填空的 `p_cq`（§4.2–4.4，pp.5–7）；
4. 在四类任务上实验并做组件消融（§5）。

与 FM 的区别在于：FM 的上下文示例和目标提示由人按规则选，且只做序列化；UniDM 用 LLM 自动选属性和记录，并多做一步自然语言改写和提示改写（§5.1，p.8）。

阅读者分析：创新主要在流程编排和提示工程，不涉及新模型或新的检索索引；记录级检索是从随机抽取的 50 条候选中打分（§5.1，p.7），并非对整个数据湖做检索。称为“统一框架”的形式化较宽松，四类任务的 Q 和 S′ 仍需逐任务设定（§4.5，p.7）。消融（Tables 8–10）只覆盖填补与转换，没有覆盖检错和实体解析。

依据：§1、§4–5，PDF pp.2–10。
