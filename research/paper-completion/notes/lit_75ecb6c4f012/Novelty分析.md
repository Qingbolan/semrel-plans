# 贡献与评价

论文声明（p.2）：(1) 首个通过端到端优化生成可执行、等价、高效查询的 LLM SQL 改写框架；(2) 带课程多阶段训练的 RL 框架；(3) 基于查询计划的执行引导上下文，以及结构—语义混合检索；(4) 在常用基准上显著优于现有改写方法。

与相关工作区别（pp.1–2）：不再从规则集中选择规则，而是直接生成改写，可以表达规则难以描述的 CTE、求值顺序改写；相对 QUITE，这里是训练期把执行反馈纳入策略，而非推理时多轮修正。

消融支撑（Table 4，p.7）：去 RL 等价率 99.6%→90.1%；去执行提示平均延迟 29.67→39.56 s；去示范检索改进查询数 210→177；未经训练和结构输入的 vanilla 为 56.71 s。

阅读者分析：
- GRPO、课程学习、执行计划提示、示范检索各自都是已有技术，新意在把它们组合到 SQL 改写，并以可验证奖励替代规则。
- “首个”的说法正文未与同类 RL 改写工作做系统对比。
- 等价性保障依赖混合检查，论文没有报告三级检查各自覆盖的比例，也没有报告最终输出中由 LLM 判定为等价的部分。

依据：[arXiv v2，9 页](https://arxiv.org/abs/2508.09023)，pp.1–2、7。
