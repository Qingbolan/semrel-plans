# 评测与边界

**基线**（p.5）：LearnedRewrite（MCTS + 学习代价模型）、LLM-R²（示范提示 + Calcite 规则）、R-Bot（检索增强逐步选规则并反思）、LLM only（GPT-4o 直接改写，无效则保留原查询）。

**指标**：查询延迟（平均/中位数/p90）、等价率（同一实例上输出元组相同的比例）、改进查询数（延迟至少降低 10%）。

**平均延迟（s，Table 1，p.6）**：

| 方法 | TPC-H | IMDB | DSB |
|---|---|---|---|
| 原始 | 78.81 | 5.74 | 38.83 |
| LearnedRewrite | 41.34 | 5.73 | 32.61 |
| LLM-R² | 54.76 | 5.32 | 20.12 |
| R-Bot | 39.89 | 5.54 | 27.75 |
| LLM only (GPT-4o) | 74.92 | 5.72 | 38.44 |
| E3-Rewrite (Qwen) | 29.67 | 5.01 | 16.93 |
| E3-Rewrite (LLaMA) | 33.72 | 5.19 | 18.06 |

TPC-H p90 从 300.00 s 降至 51.37 s；DSB p90 从 300.00 s 降至 38.47 s。

**改写质量（Fig.3，p.6）**：等价率 / 被改进查询数。

| 数据集 | E3-Rewrite | 对比基线 |
|---|---|---|
| TPC-H | 99.6% / 210 | R-Bot 96.8% / 194；LLM-R² 91.2% / 190 |
| IMDB | 99.4% / 98 | LLM-R² 99.2% / 103；LearnedRewrite 100% / 57 |
| DSB | 98.8% / 151 | R-Bot 95.5% / 96 |


**模型规模（Table 2）**：Qwen 14B 35.58 s、158、94.8%；Qwen 32B 29.67 s、210、99.6%。

**数据规模（Table 3）**：TPC-H 1GB/5GB/10GB 平均 12.39/16.14/29.67 s，p90 9.47/16.28/51.37 s。

阅读者分析：
- 摘要“延迟最多缩短 25.6%”与 TPC-H 上相对 R-Bot 的平均延迟一致（1−29.67/39.89≈25.6%）；“等价改写多 24.4%”无法从正文数字直接复算。
- 在 IMDB 上 LLM-R² 的改进查询数（103）多于 E3-Rewrite（98），并非所有维度全面领先。
- 改进查询数相对约 2,000 条查询只占约 5%–10%，平均延迟的下降主要来自少数长查询（含 300 s 超时截断）。
- 正文对 vanilla 等价率写 84.0%，Table 4 为 84.8%；正文称 LLM-R² 用 GPT-3.5，另一处又说 GPT-4o 是其骨干，存在不一致。无方差报告，无单列局限章节。

依据：[arXiv v2，9 页](https://arxiv.org/abs/2508.09023)，Experiments，Tables 1–4、Fig.3，pp.5–7。
