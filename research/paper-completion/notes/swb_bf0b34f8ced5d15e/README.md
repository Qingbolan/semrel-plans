# Hu, Lu & Clune — Automated Design of Agentic Systems

论文提出“智能体系统自动设计”（ADAS）这一研究方向，并给出算法 Meta Agent Search：由元智能体用 Python 代码编写新的智能体（一个 `forward` 函数），在验证集上评估后加入不断增长的存档，供后续迭代参考。在 DROP 与 MGSM 上，搜索出的智能体比最好的手工设计基线高 13.6 F1 和 14.4 个百分点，并能迁移到其他领域和模型。已读正文及附录 C–F、H–J。
