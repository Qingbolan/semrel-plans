# Lin et al. — Data Journalist Agent: Transforming Data into Verifiable Multimodal Stories

Data2Story 是一个多智能体“虚拟新闻编辑部”：从原始数据出发，经 Detective（检索背景）、Analyst（执行统计代码）、Editor（选角度）、Designer（生成多媒体素材）、Programmer（生成 HTML 文章）、Auditor（审页面），最后由 Inspector 把文章中的句子、图表与代码行或外部 URL 绑定。它是一个系统论文，不是数据集基准；在 18 篇与人类原作配对的文章上，53 名读者的评分均值为 4.21 对 3.38（1–7 分），可审计声明比例为 93% 对 25%，但作者承认人类在编辑角度和创意设计上仍明显领先。已阅读正文与附录 A–C；未逐个阅读附录中的全部文章对比案例。
