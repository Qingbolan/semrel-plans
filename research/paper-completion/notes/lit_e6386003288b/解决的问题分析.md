# 解决的问题

**输入**：一个过滤节点，其布尔表达式树 T 以 n 个语义谓词 F={f1,…,fn} 为叶、以 AND/OR 为内部节点；流入该节点的数据行 r；每行的预计算文档嵌入以及每个谓词的嵌入（§3、§3.1，pp.4–5）。物理计划可包含多个这样的过滤节点，Larch 分别优化。

**单位操作**：对行 r 求值谓词 f_i 需要一次 LLM 调用，token 代价 c(f_i, r)，返回布尔值。结果代入 T 后做短路归约：AND 遇 False 即为 False，OR 遇 True 即为 True。由于 AI_FILTER 输出是单 token 布尔值，代价完全由提示（文档 + 谓词）决定，可在求值前算出（§3.2.3）。

**输出**：一个自适应排序策略 σ，给定部分求值的树选出下一个要求值的谓词；目标是最小化所有行的期望总 token 代价：σ* = argmin E_r[Σ_t c(f_{σt(r)}, r)]（§3.1，p.5）。因为 AND/OR 可交换，求值顺序不改变查询结果，只改变代价（§1 p.2）。

**难点**：谓词选择率与相关性事先未知，并且可能随数据变化，σ* 不能预先计算，只能在执行中从反馈在线逼近（§3.1）。

**评测口径**：代价以 token 计（沿用 PZ 与 Quest），辅以 LLM 调用次数；“Optimal”是对每行穷举所有合法顺序后取最小值，作为下界（§4.1）。

阅读者分析：这是一个纯物理层优化问题，与级联/代理模型等改变调用对象的逻辑层方法正交（原文 §2.1 亦如此声明）；问题不涉及结果准确率，因为在假设 LLM 输出确定的前提下结果集不变。

依据：[arXiv 2606.07923v1](https://arxiv.org/abs/2606.07923)，§1、§3.1、§3.2.3、§4.1，PDF pp.2、5–7。
