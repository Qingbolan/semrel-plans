# 贡献与评价

**原文所述贡献**（§1，p.2）：
1. 作者称这是第一个从数据检索到部署、与任务无关的 LLM AutoML 框架；
2. 检索增强规划，加上按角色的计划分解和基于提示的执行，从而实现免训练搜索、可并行；
3. 结构化指令解析：用约 2.3K 条 EvolInstruct 生成的指令-响应对，以 LoRA 微调 Mixtral-8x7B；以及三阶段验证；
4. 在 7 类任务、14 个数据集上的实验。

**阅读者分析**：
- 新意集中在“用 LLM 推断代替真实训练”来筛选计划，然后只实现最有希望的一个。与 SELA 相比，搜索时间约快 8 倍（Table 12）。
- 方法依赖每类任务事先准备的全流程骨架脚本（§4.1；附录 B.1）。作者承认，对于全新任务，没有骨架会增加幻觉风险（A.4）。所以“任务无关”有前提条件。
- 骨干模型是 GPT-4o。小模型（LLaMA-2-7B、Qwen1.5-14B 等）在早期尝试中无法生成可执行代码（A.2），所以方法的可迁移性依赖强模型。
- Table 1 中六项全部打勾是作者自己的归类。

依据：[arXiv:2410.02958v2，48 页](https://arxiv.org/pdf/2410.02958v2)，§1、§3、§4.3，PDF pp.1–9；附录 A.2、A.4，pp.13–14。
