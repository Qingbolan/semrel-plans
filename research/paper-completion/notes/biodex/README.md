# BioDEX: Large-Scale Biomedical Adverse Drug Event Extraction for Real-World Pharmacovigilance

BioDEX 用真实药物警戒报告为生物医学文献构建不良事件抽取任务（65,648 篇文章、256,240 份报告），要求从全文生成结构化报告。关键结果：最佳微调 FLAN-T5-Large 测试 F1 59.1%，而同文献不同报告的一致性下界约 72%。
