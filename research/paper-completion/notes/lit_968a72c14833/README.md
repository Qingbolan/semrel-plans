# Chen, Wang, Yu, Zhan, Wang — Large Language Model-based Data Science Agent: A Survey

这是一篇关于 LLM 数据科学智能体（DS Agent）的综述，用"智能体设计 + 数据科学流程"的双视角组织文献：前者分角色设计、执行结构、外部知识、反思四个维度，后者沿数据预处理、统计计算、特征工程、模型训练、评估、可视化的循环展开，并汇总 35 个基准、提出三个研究方向。全文没有自己的实验。已阅读引言、相关工作、第 3 节各小结、第 4–7 节全文与 Table 5；第 3 节对具体系统的逐一介绍为浏览。
