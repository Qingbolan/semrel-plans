# 贡献与评价

**原文贡献（§1–2）**：

1. **自动课程**：GPT-4 以"发现尽可能多的不同事物"为总体目标，按探索进度和当前状态自底向上提出任务，作者称之为上下文内的新颖性搜索。
2. **技能库**：用可执行代码表示技能，通过描述嵌入索引与检索；复杂技能由简单技能组合，缓解灾难性遗忘。
3. **迭代提示机制**：结合环境反馈、执行错误和 GPT-4 自我验证（同时判断成功并给出改进建议）。

全程仅以黑盒方式调用 GPT-4，不做参数微调。作者称其为"首个 LLM 驱动的具身终身学习智能体"（摘要）。

**阅读者分析**：

- 三个组件各自都有前驱（Code as Policies、Reflexion、新颖性搜索等），本文的价值主要在组合方式与在开放世界中的系统验证；"首个"是作者的定位。
- 基线 ReAct、Reflexion、AutoGPT 原为 NLP 任务设计，由作者重新实现到 MineDojo 中，且都没有课程模块；结果优势中有一部分来自基线并不面向该环境。
- 依赖 Mineflayer 的高层 API（如 craftItem）和对死亡后保留物品栏等环境改造（附录 B.1），因而结论限于"代码 API 可用"的环境。
- 技能库可迁移给 AutoGPT 并提升其零样本表现（Table 2），这是较有说服力的独立证据。

依据：摘要、§1–3，Table 2，附录 B.1，PDF pp.1–8、38。
