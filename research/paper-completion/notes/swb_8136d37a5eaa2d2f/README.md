# Wang et al.（NVIDIA 等）— Voyager: An Open-Ended Embodied Agent with Large Language Models

Voyager 是在 Minecraft 中由 GPT-4 驱动的终身学习智能体，不微调模型参数，靠三部分实现开放探索：自动课程（GPT-4 依据状态提出下一任务）、可执行代码技能库（以描述嵌入为键检索）以及融合环境反馈、执行错误与自我验证的迭代提示。关键结果：160 次提示迭代内发现 63 种独特物品，为基线的 3.3 倍；木/石/铁工具解锁分别快 15.3×、8.5×、6.4×，且是唯一解锁钻石工具的方法（§3.3、Table 1）。已读正文 10 页及附录 B（实验细节），附录 A 的完整提示仅浏览结构。
