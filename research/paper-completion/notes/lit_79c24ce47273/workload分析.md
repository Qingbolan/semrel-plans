# 工作负载

**规模与类别**（Table 2，p.4）：

| 类别 | 数量 |
|---|---|
| 数据整理 DW | 100 |
| 机器学习 ML | 100 |
| 数据操作 Data Manipulation | 73 |
| 数据洞察 Data Insights | 79 |
| 可视化 Visualization | 70 |
| 统计分析 Statistical Analysis | 78 |
| 合计 | 500 |

后四类属于 EDA，DW:ML:EDA = 1:1:3（§3.1，p.3）。难度：Easy 105、Medium 292、Hard 103。表中百分比写为 22.8% / 57.3% / 19.9%，而按 500 计算应为 21.0% / 58.4% / 20.6%，两者不一致，原因未说明（阅读者分析）。

**数据来源**：Kaggle、GitHub 及其他网络来源的近期真实数据集，要求真实、复杂、及时、编码量大；10 名熟悉数据分析、SQL、Python 的标注者负责采集与标注，多数任务由“显式代码指令改写为抽象任务”得到（§3.5，pp.4–5）。ML 任务包括分类、回归、聚类，参考解不用深度学习（§2.2，p.4）。

**划分**：论文未描述训练/开发/测试划分，500 题整体用于评测；另随机抽 100 题组成 DA-Code-100，用于框架比较和消融，并为其标注了参考计划（§5.2–5.3，p.7）。

**运行设置**：贪心解码，最多 20 步，最大历史 15 步，单动作时限 300 秒（§5.1，p.6）。

依据：§2.2、§3.1、§3.5、§5.1–5.3，Table 2，PDF pp.3–7。
