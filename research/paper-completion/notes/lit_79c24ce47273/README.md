# Huang et al. — DA-Code: Agent Data Science Code Generation Benchmark for Large Language Models

DA-Code 是面向“智能体式数据科学编程”的基准：500 个任务，覆盖数据整理（DW）、机器学习（ML）和探索性数据分析（EDA），每个任务在 Docker 沙箱中提供多份真实、带干扰的数据文件，由智能体用 Python / SQL / Bash 多步完成，并用执行结果评分。作者同时给出 DA-Agent 基线；最强的 GPT-4 总分仅 30.5%。已阅读正文 §1–§7、Limitations 与附录 B、C（评分细节），附录 A/D/E 的示例与提示词只抽查。
