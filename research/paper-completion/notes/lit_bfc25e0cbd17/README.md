# Sah et al. — Generating Analytic Specifications for Data Visualization from Natural Language Queries using Large Language Models

这是一篇 6 页短文，提出 NL4DV-LLM：一个给 GPT-4 使用的长文本提示，输入表格数据（列名加 10 行随机样本）和自然语言查询，输出与 NL4DV 工具包同构的分析规格（属性映射、分析任务、Vega-Lite 图表列表），并支持歧义查询和追问。在 NLVCorpus 加 NL4DV 网站追问共 740 条查询上，人工判定准确率 87.02%，NL4DV 为 64.05%，但平均响应 25 秒。已阅读全文。
