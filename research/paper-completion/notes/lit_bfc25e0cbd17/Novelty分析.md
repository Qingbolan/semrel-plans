# 贡献与评价

论文列出的贡献有三项（§1，PDF p.2）：一个把 NL 查询翻译为完整分析规格的 LLM 提示；提示的迭代构建过程；与 NL4DV 的初步对比及讨论。

**提示组成**（§2.1，PDF pp.2–4）：

| 组件 | 内容 |
|---|---|
| 任务 JSON | Amar 等的 7 种低层分析任务（相关、分布、派生值、趋势、过滤、排序、找极值），每项含定义、示例、属性类型与编码、推荐图表 |
| 追问 JSON | 增加、删除、替换 × 属性、任务、图表类型的组合，附说明和示例 |
| 查询类型指令 | 歧义、完全指定、欠指定、追问四类的处理步骤 |
| 回复 JSON | 带字段说明的示例输出 |
| 数据子集 | 全部列名 + 10 行随机样本 |

作者先探测发现 GPT-4 不了解这一分析任务分类，所以把知识写入提示（§2.1.1，PDF p.2）。提示经过 5 个版本：从 4 种任务、只输出 Vega-Lite，逐步加入示例和规格结构、新任务、歧义/欠指定指令、追问支持（§2.2、Figure 3，PDF p.4）。

阅读者分析：这是提示工程和工具集成工作，没有新模型或算法。贡献主要在于把 NL4DV 的中间表示迁移到 LLM 输出中，从而获得可检查性。评估规模小、由作者标注，且未与其他 LLM 方法在同一数据上比较，新意和效果都应按“初步”理解。

依据：§1–2，PDF pp.1–4。
