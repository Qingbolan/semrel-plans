# Bonn et al. — Building a Broad Infrastructure for Uniform Meaning Representations

本文报告 UMR（Uniform Meaning Representation，统一意义表示）数据集的首个发布版本（UMR 1.0，2023 年 7 月）：六种语言（英语、汉语、阿拉帕霍语、纳瓦霍语、萨纳帕纳语、库卡马语）共 2,202 句句级图、1,525 句文档级图，并介绍正在进行的英文 AMR 转换（87,038 句）、低资源语言半自动构建、多模态扩展，以及标注指南与 UMR-Writer 工具。论文是资源与基础设施描述，没有模型实验、基线或标注一致性数字。已通读正文全部 7 节。
