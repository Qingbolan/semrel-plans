# 解决的问题

**定义 2.1**：给定两表 R1、R2 和用自由文本表达的连接谓词 j，求满足 j 的全部行对 R ⊆ R1×R2。行可以是文本文档，也可以是结构化记录的文本表示（§2，p.3）。论文不专门针对等值连接，而是一般 θ-join。

**LLM 模型假设（定义 2.2）**：费用与读入、生成的 token 数成正比，二者单价可以不同（生成相对读入的倍率记为 g）；每次调用读入加生成的 token 总数有模型相关的上限（§2，p.3）。

**工作单元**：块连接中一次 LLM 调用处理一对批次（R1 取 b1 行、R2 取 b2 行），输出“x,y”下标对并以 “Finished” 结尾；若末尾不是 Finished 即判定为溢出（Overflow），结果不完整（§4.1，Figure 2，pp.4–5）。

**可调变量**：只有 b1、b2 可选；行数 r1/r2、行 token 大小 s1/s2、结果对大小 s3、选择率 σ 由数据决定，g 由模型决定，提示固定部分 p 由用户给定（§4.2，p.5）。优化目标是总费用 c(b1,b2)=(r1/b1)(r2/b2)(p+b1s1+b2s2+b1b2σs3g)，约束为单次调用 token 不超过 t（Corollary 4.4、式 1，p.6）。

阅读者分析：输出是“LLM 能找到的”全部匹配对，正确性依赖模型；论文的代价模型不包含召回损失。
