# Xu et al. — EVADE-Bench: Multimodal Benchmark for Evaluating and Enhancing Evasive Content Detection

本文提出中文多模态电商"规避内容检测"基准：2,833 条文本和 13,961 张图片，均来自真实电商平台，覆盖六类广告违规（如塑形、增高、保健品），由广告法专家标注。作者在 Single-Violation 和 All-in-One 两个评测轨上测试了 26 个 LLM/VLM，所有模型都低于人类（人类 Partial/Full 约 69/51–57）。合并语义重叠的规则后，多数模型准确率上升。已阅读全文 8 页（§1–6），核对 Tables 1–6。
