# 贡献与评价

**论文声称的贡献（§1，pp.2–3）**：
1. 研究支持广泛算子（31 种）的自主数据准备问题，并提出 LLM 智能体框架（plan–orchestrate–execute 循环）；
2. **树式智能体推理**：在物化执行状态树上的结构化动作，支持非局部回溯并复用有效的算子前缀；
3. **渐进式智能体训练**：冷启动课程（阶段 1 算子语法学习，从真值流水线切出（子流水线, 输入表, 输出表）三元组做 SFT；阶段 2 以 DeepSeek-R1 等教师在 ICL 下生成树式轨迹、经过程奖励筛选后做带掩码 SFT）+ 多轮 GRPO（环境 token 不计梯度）+ 混合奖励 R = α·R_out + β·R_part + γ·R_llm（§5.1–5.2，pp.7–8）；
4. **数据合成**：执行 NL2SQL 真值查询得到目标表，由 LLM 生成目标 schema 描述，生成候选流水线并选执行结果完全一致的最短者；再用“清洗算子的逆变换”注入噪声，只保留能被对应清洗算子精确还原的扰动（§5.3，p.8）；
5. 承诺发布代码、数据和 0.5B–14B 模型权重（脚注称需机构批准后公开，p.3）。

**诚实评估（阅读者分析）**：
- 与 MCTS 类方法（MCTS-OP、MontePrep）的区别在于：节点是物化表状态，分支选择由 LLM 读取结构化执行反馈决定，而不是标量 rollout 统计（§7，p.12）；这一区分清楚，但“树”由 LLM 生成式地扩展，没有搜索预算或完备性分析。
- 训练与域内测试都来自同一合成流程；唯一独立数据集 Parrot 上，DeepPrep 8B 准确率 39.93，仅比 IL 的 36.15 高约 3.8 点。
- 过程奖励依赖 LLM 评审（如 GPT-4o），奖励权重 α/β/γ 与其他超参未在正文给出（指向外部报告 [1]）。
