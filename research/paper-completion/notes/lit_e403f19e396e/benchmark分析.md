# 评测与边界

**基线（§6.1，p.9）**：提示类——CodeGen、Plan-and-Solve（PaS）、ReAct、MCTS-OP、MontePrep（作者发布代码、默认设置）、DeepAnalyze（智能体 LLM，SFT+RL）、AutoPrep（按原设计扩展到更多算子）；训练类（同骨干）——模仿学习 IL（蒸馏教师推理轨迹）、仅结果奖励的 RL-GRPO。闭源骨干为 GPT-5（即 gpt-5-mini-2025-08-07）与 Claude-4（claude-sonnet-4-20250514）。

**主结果（Table 2，p.10；准确率 / 完成率）**

| 方法（骨干） | Synth-Spider | Synth-Bird | Parrot |
|---|---|---|---|
| CodeGen（Qwen3-14B） | 45.47 / 68.18% | 29.48 / 49.20% | 30.83 / 81.08% |
| IL（Qwen3-14B） | 61.70 / 85.26% | 48.01 / 81.23% | 37.95 / 89.39% |
| DeepPrep（Qwen3-14B） | 67.18 / 97.21% | 54.09 / 92.26% | 40.44 / 96.41% |

| DeepPrep（Qwen3-8B） | 65.99 / 97.46% | 53.39 / 92.78% | 39.93 / 98.46% |

**成本（Exp-2、Fig.5，pp.10–11）**：Synth-Spider 上 DeepPrep（Qwen3-14B）67.18，与 Claude-4 上 ReAct 的 69.92、GPT-5 上 ReAct 的 67.03 相当，成本约低 57 倍和 15 倍。注意摘要中的“GPT-5”实为 gpt-5-mini，且开源模型的成本是按 GPU 时租换算的，与 API 计价口径不同。

**消融（Table 3，Qwen3-8B，p.11）**：仅冷启动 60.66 / 91.63%，去掉算子语法学习（OSL）59.65 / 90.54%；去掉 R_llm 64.54，去掉 R_llm 和 R_part 61.85（完成率最高 98.71%，作者解释为稀疏奖励诱导保守行为）。阅读者发现“w/o OSL”一行与 Table 2b 的 IL 一行数值完全相同，论文未解释二者是否为同一模型。

**规模与数据（Exp-4/5）**：用 Synth-Spider 训练比用 Parrot 训练在 Synth-Bird 上准确率高 37.0（8B）和 29.4（14B）点；Qwen3 从 0.6B 到 14B，Synth-Spider 准确率从 31.20 升到 67.18（Fig.8）。

**局限（阅读者分析，论文无局限性章节）**：只报告单次运行；域内与 Synth-Bird 均来自作者自己的合成流程；精确匹配不给部分正确的分数；超参与提示词放在外部报告中。
