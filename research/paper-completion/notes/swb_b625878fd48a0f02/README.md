# Lin, Lyu, Xu & Luo — INS-MMBench: A Comprehensive Benchmark for Evaluating LVLMs' Performance in Insurance

INS-MMBench 是面向保险领域的分层多模态基准，覆盖车险、财产险、健康险和农业险，含 22 个基础任务、12 个元任务和 5 个场景任务，共 12,052 张图像、10,372 个问题。作者评测 11 个 LVLM，GPT-4o 总体最高（69.70）；场景任务的多步推理普遍较差，错误主因是缺乏保险知识/推理。图像全部取自公开数据集，并非真实保单案例。已读正文 §1–5（pp.1–8），参考文献未细读。
