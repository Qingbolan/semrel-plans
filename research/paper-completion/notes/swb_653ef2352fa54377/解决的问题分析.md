# 解决的问题

- 输入：一份企业可持续发展报告（年报或独立的可持续发展/ESG/CSR 报告）的 PDF。
- 输出：该报告中符合规范的排放值记录，每条记录为“报告（公司名+报告年）× 排放年份 × scope 类型（1、2lb、2mb、3）× 页码”，带数值、原始单位、归一化单位、指标名称和展示形式（表格/图形/文本）。
- 有效值的四项判定规则：覆盖整个公司；按 scope 的运营边界报告；以 CO2 或 CO2e 绝对量报告；是总量而非子类（Table 1 给出正反例）。不满足的值即便被 LLM 抽出也标为错误。
- 工作单位：标注以报告为路由单位——两名非专家只要在任一行的值或单位判断上不一致，或打了歧义标记，整份报告转给专家。

阅读者分析：这是一个带严格口径的文档级结构化抽取任务（PDF → 表），难点在口径判定（如未注明方法的 Scope 2 归入位置法），而不是定位数字本身。

依据：[Scientific Data 12:1497 (2025)，9 页](https://www.nature.com/articles/s41597-025-05664-8)，Methods、Table 1、Data Records，PDF pp.4–7。
