# Altreuter et al. — MatchMiner-AI: Open-source, Privacy-preserving Cancer Clinical Trial Matching using Artificial Intelligence

MatchMiner-AI 是 Dana-Farber 的开源肿瘤临床试验匹配流水线：用开放权重 LLM（Gemma-4-31B-IT）从试验入组标准中抽取目标人群“space”、总结患者纵向 EHR，并以完全合成的 EHR 数据把检索、重排和排除检查蒸馏到小模型。回顾性蒸馏保真评测中，相对通用嵌入基线，患者→试验 MAP@20 从 0.44 提升到 0.95（入组队列）。已读正文、Figure 2、Table 1 与补充表 3–8；未逐项阅读全部提示词与 TRIPOD 清单。
