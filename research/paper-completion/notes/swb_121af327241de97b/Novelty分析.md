# 贡献与评价

| 组件 | 做法 | 位置 |
|---|---|---|
| 合成训练数据 | 每个 space 由教师 LLM 生成 5 名符合与 5 名“差一点”不符合的患者病程（20–30 个事件），再为每个文档事件生成完整文书；加入药名缩写/商品名替换，10% 患者加第二原发癌 | pp.6–7 |
| TrialSpace | 微调 Qwen3-Embedding-0.6B，联合 MNR 损失与 CoSENT 损失；用困难候选迭代再训练共三轮 | p.9 |
| TrialChecker | ModernBERT-large 交叉编码器，回归教师的 0–5 分，用于过滤与重排 | p.10 |
| BoilerplateChecker | ModernBERT-large 分类器，预测通用排除 | pp.10–11 |
| 开放发布 | 合成数据、模型权重、推理工具与演示前端公开；PHI 评测数据不公开 | p.15 |

作者称三个小模型均不到 10 亿参数，可在 CPU 或消费级 GPU 上运行；预计算后检索秒级，单个患者摘要约 3 分钟（p.15）。

阅读者分析：主要新意在“完全合成数据 + 开放权重教师蒸馏”的工程组合，以及以 space 为单位的检索；嵌入、交叉编码器和损失函数均为现成方法。主要评测指标衡量的是学生模型对教师 LLM 的复现度（蒸馏保真），并非真实入组资格的准确率；人工评审样本较小。

依据：Methods、Discussion，PDF pp.6–15、20–22。
