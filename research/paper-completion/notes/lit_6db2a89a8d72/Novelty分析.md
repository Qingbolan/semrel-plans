# 贡献与评价

**论文声称的贡献（§1，p.2）：**
1. 分层多智能体架构（Manager + Cleaner/Featurizer/Modeler/Visualizer/Debugger），子 agent 动作空间互不相交（Eq.2），并作为 Manager 的高层动作被调用（Eq.1）。
2. ASA：合成 → 执行验证 → 缓存到候选库 → 同名技能生成次数 ≥3 才永久加入（§4.2，p.4）。
3. ACC：子 agent 以全局目标为条件把执行结果蒸馏成摘要返回；Manager 拥有可自主调用的摘要工具，而非超长阈值触发（§4.3）。
4. 两阶段训练：DeepSeek-V3.1 教师轨迹 SFT；随后多角色联合 GRPO，主轨迹用混合奖励 R=R_outcome+0.2R_sub−0.1P_context−0.1P_turn，子轨迹用 ±0.1 规则奖励，奖励广播到摘要切出的各段（§4.4，p.5）。
5. 理论：分层工具选择的错误率上界严格低于扁平框架（Theorem 5.1）；Manager 目标等价于信息瓶颈问题（Theorem 5.2）（§5，p.6）。

**阅读者评估。**
- 各组件单独看都有先例（论文自己引用了 LATM 的工具创建、MATPO 的共享参数多角色训练、折叠/摘要式压缩），新意主要在于把它们组合进同一 RL 训练框架并面向数据科学任务。
- 消融（Table 2）中 EvoDS 行与 Table 1 的 EvoDS-evo 行数值完全一致（0.911/0.355/0.118/0.311/0.424），即消融基准是开启技能复用的版本；摘要中的 28.9% 也是 EvoDS-evo 相对 DataMind-14B 计算得到（0.424 vs 0.329）。
- Theorem 5.1 被用来解释 “w/o hier” 的消融差距，但定理只比较给定上下文下的错误率上界，不能直接推出端到端分数差异（阅读者分析）。
