# 工作负载

10 个公开基准、12 个评测轨道（Table A.1，PDF p.14），单位均为"一道题"：

| 类别 | 数据集 | 评测规模 / 划分 | 输入形态 | 答案 |
|---|---|---|---|---|
| C1 金融数值 | FinQA | 1,147 / test（全集 8,281 = 6,251/883/1,147） | 文本+表格（S&P 500 10-K） | 数值（程序） |
| C1 | DocMath-Simplong | 100 / testmini | 长文档+多表 | 数值 |
| C1 | DocMath-Complong | 300 / testmini（平均上下文约 1.8 万词） | 长文档+多表 | 数值 |
| C1 | FinanceMath | 200 / validation | 文本+表格 | 数值 |
| C2 通用表格 | HiTab | 1,584 / test | 层级表 | 数值/片段 |
| C2 | MultiHiertt | 1,044 / dev（test 答案不公开） | 文本+多层级表 | 数值 |
| C2 | TabMWP | 1,000 / test 子集 | 半结构表 | 数值/选择 |
| C2 | WikiTableQuestions | 4,344 / test | 半结构表 | 片段/数值 |
| C3 领域知识 | ESGenius | 1,136 / 全集 | 文本（金标准来源段落） | 四选一 |
| C4 多模态 | FinChart-Bench TF/MC/QA | 2,384 / 2,350 / 2,284 | 图表图片（1,200 张，2015–2024） | 判断/选择/开放数值 |

依据：Table A.1 与附录 A，PDF pp.13–15。

**评测口径要点**：
- ESGenius 把每题的金标准来源段落直接作为上下文，作者称之为"oracle-RAG 等价"设置，与原排行榜开源 RAG 列比较（附录 A，PDF p.15）。
- FinChart-Bench 只多一次 VLM 转写，把图表变成表格后进入纯文本流程（§3.6，PDF p.5）。
- 所有角色共用 Qwen3.6-27B（vLLM 部署），提示词跨数据集相同，只换数据加载器（§4.3，PDF p.6）。

阅读者分析：TabMWP 只评 1,000 题子集，而对比行来自全量测试集的已发表结果，二者并非严格同口径；ESGenius 使用金标准段落，等于跳过检索，和真实 RAG 检索器结果比较时对 MoCA 有利。
