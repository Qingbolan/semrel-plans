# 解决的问题

**输入**：三元组 ⟨q, T, C⟩——自然语言问题 q、可选表格 T（纯文本、层级表，或由 VLM 从图表转写）、自由文本上下文 C（§3.1，PDF p.4）。

**输出**：可执行 Python 程序 P，其打印结果即最终答案 a；同时保留一份声明级审计记录（§3、§3.5，PDF pp.3–5）。

**处理流程与中间对象**（§3.2–3.5，PDF pp.4–5）：

| 阶段 | 产出 |
|---|---|
| 声明目录 | K={(id, 类型κ, 一句话摘要σ, 候选值ν, 证据引文ϵ)}，κ∈{fact, formula, unit, sign, direction, other}，M_max=10；并给问题打题型 τ（百分比变化、比率、求和、差、平均、比较、其他） |
| 交易员 | EXTRACTOR、FORMULA、ACCOUNTANT、SKEPTIC 各给每条声明下单 (买/卖, 数量 1–5, 价格 0.01–0.99, 理由)；权重 1.00/1.00/1.10/0.95 |
| 清算 | 价格 π=B/(B+S+ε)，置信 γ=|B−S|/(B+S+ε)；π≥0.62 接受、≤0.38 拒绝，否则不确定 |
| 合成与验证 | 只能引用接受/不确定的声明；10 秒沙箱执行；六项结构检查（执行成功、事实数量足够、所需公式/单位/符号声明存在、未引用被拒声明、答案极性与尺度一致、源码中确实出现对应运算），每违规 −0.45，Φ≥2.20 视为通过 |
| 兜底 | 失败则一次修复；若 Φ<2.20 或 Γ<0.78，调用无市场的基线方案，由四视角委员会比较，票数分裂时仲裁者写第三个程序 |

**工作单元**：一道题。阈值（2.20、0.78）在 FinQA dev 的 100 题留出集上校准后冻结，所有基准不做单独调参（§3.5 脚注，PDF p.5）。
