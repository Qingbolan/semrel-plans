# Huang & Wu — Cocoon: Semantic Table Profiling Using Large Language Models

Cocoon 是哥伦比亚大学提出的数据画像系统：在统计画像之外，用 LLM 依次生成语义上下文、语义画像和语义复核，判断统计异常是真错误还是语义上正常，以减少误报和漏报。它覆盖重复、列类型、唯一键、伪装缺失值、缺失值、数值异常、字符串异常和缺失记录 8 类问题。评估只有一项两名研究生参与的试点访谈，没有定量指标。已通读全文。
