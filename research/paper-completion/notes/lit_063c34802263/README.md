# Chi et al. — Spreadsheet-RL: Advancing Large Language Model Agents on Realistic Spreadsheet Tasks via Reinforcement Learning

本文提出在真实 Microsoft Excel 环境中用 GRPO 训练电子表格智能体的框架：自动从 ExcelForum 帖子构造"初始表—目标表"训练对（目标表由编码智能体生成），提供带专用工具与路由规则的 Spreadsheet Gym，并发布 1,660 个任务的 Domain-Spreadsheet 评测集。Qwen3-4B-Thinking-2507 在 SpreadsheetBench 上 Pass@1 从 12.0% 提升到 23.4%（其中 RL 本身贡献 19.3%→23.4%），在 Domain-Spreadsheet 上从 8.4% 到 17.2%。已读正文与全部附录。
