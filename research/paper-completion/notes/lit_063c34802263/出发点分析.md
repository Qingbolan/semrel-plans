# 出发点

已有电子表格智能体（SheetCopilot、SheetAgent、ChatGPT Agent）主要依赖强大的闭源通用 LLM 加提示工程，对真实世界常见的多步骤工作流表现不稳定；引言引用 ChatGPT Agent 与 Copilot 在 SpreadsheetBench 上分别为 45.5% 和 20.0%（§1，p.2）。业界的专用表格智能体使用内部基准和封闭训练流程。

作者希望沿用 DeepSeek-R1 式"在线 RL + 可验证结果奖励"的路线，但指出表格领域三个难点（§1，p.2）：(1) 最终表格由值、公式、布局的一长串操作产生，收集足够的初始—最终表格对昂贵；(2) 缺少逐步 SFT 数据，RL 只能从较弱的交互策略起步；(3) 因此必须有表格专用的 harness 来提供结构化动作空间和工作流先验，使初始成功率不至于过低。

依据：§1–2，PDF pp.2–3。
