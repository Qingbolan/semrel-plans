# Banarescu et al. — Abstract Meaning Representation for Sembanking

本文提出抽象语义表示（AMR）：用有根、有向、边带标签的图记录整句英语的逻辑意义，并以 PropBank 框架集为核心概念，目标是像 Penn Treebank 推动句法分析那样建设一个统一的语义库（sembank）。论文介绍 AMR 的格式、内容、局限、标注编辑器与 Smatch 指标，并报告初步标注一致性（Smatch 0.83/0.79/0.71）和当时约数千句的 AMR 语料。它是资源与表示方法论文，没有提出或评测自动解析器。已阅读全文。
