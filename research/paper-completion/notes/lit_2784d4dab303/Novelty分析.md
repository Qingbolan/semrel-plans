# 贡献与评价

**论文声称的贡献**（§1，p.4862）：

1. 实用 ChatBI 系统：四个功能模块统一集成，已在腾讯财经、广告、云业务部署，服务数十家企业客户，把数据分析延迟从分钟级降到秒级。
2. MRD-Q：语义补全、知识引导澄清、主动追问。
3. 经济的领域适配：按数据条件切换生成策略；用 SQL 日志 + LLM 逆向工程合成训练数据（负例约占 5%）；两步法用 SIR 支持冷启动。
4. 开源 MRD-BIRD 多轮 NL2SQL 基准（96 个 3–5 轮对话序列）。

**评价**：对话分析建立在 Lian et al. [46] 的基础上，主要改动是用 LLM 替代微调 PLM 判断语义完整性，并增加用户澄清（§2.1、§3.3.1，pp.4862–4865）。策略切换是基于两个阈值的规则，而非学习得到的选择器（Eq.6）。

阅读者分析：本文的贡献主要是系统集成与工程经验，算法新意有限；评测中基线是单轮 NL2SQL 方法与自行复现的 MRD-SQL，没有与其他完整 ChatBI 系统端到端比较。生产准确率（93–97%）的测量口径（样本、判定者）未说明（阅读者分析）。

依据：§1–§4，pp.4860–4871。
