# problem

- **任务定义**：T = (q, F, a*)。q 为自然语言分析指令；F = F_target ∪ F_distractor 为包含目标文件与同社区干扰文件的文件系统；a* 为真值答案（§4.1）。
- **输入**：agent 从根目录出发，只收到 task_description.txt 中的问题，无文件位置、文件名或 schema 提示；数据目录只读挂载（附录 E.1）。
- **输出**：写入 result.txt 的答案，经归一化（取整、去空白、大小写）后与 a* 精确比较。
- **评测单位**：单个任务；两项指标——Discovery Accuracy（DA）：agent 解中实际使用的文件集合与目标文件集合**完全相等**的任务比例；Execution Accuracy（EA）：答案正确的任务比例（§4.2 式(4)–(5)）。
- **资源约束**：每任务 4GB 内存、2 CPU 核、600 秒超时；Python 3.11 及 pandas、numpy、scikit-learn 等，允许 agent 自行安装包（附录 E.1）。

阅读者分析：这把"数据发现"（在同主题干扰中选表/文件）与"数据分析代码生成"串成一个端到端任务，类似数据湖上的表发现 + 分析问答；答案是封闭数值/列表，不评价解释性洞察。

依据：[arXiv:2606.15300v1，37 页](https://arxiv.org/abs/2606.15300)，§4.1–4.2，附录 E，PDF pp.5、27。
