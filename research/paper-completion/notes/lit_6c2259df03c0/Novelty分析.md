# novelty

作者称 CoDA-Bench 是首个在数据密集环境中联合评测代码智能与数据智能的基准（与 Table 2 中 GAIA、SWE-Bench、MLE-bench、DA-Code、DABstep、DAComp 等对比，唯一同时具备"未使用数据"、代码、终端和无指引条件）。构造方法有三部分：

1. **基于共现图的环境构造**：从 Kaggle 笔记本中数据集的共同使用构建加权无向图（21,122 个数据集节点、全部 529,739 个文件），用 Leiden 算法（γ=1.0）划分出 323 个社区，模块度 0.711；任务环境＝目标数据所在社区的全部数据，其余作为同分布干扰项（§3.1、附录 B）。
2. **基于解的反向构造**：从笔记本单元输出中挑选可验证且非平凡的数值结果作为"solution anchor"，经静态数据流分析找出最小输入文件集与变换序列，重新执行确认结果在 1e-6 内一致，再由 LLM 生成不泄露解法的问题，人工审核去歧义（§3.2）。
3. **对抗式任务演化**：由 GPT-5.2、Claude-Sonnet-4.5、Gemini-3.0-Flash-Preview、Kimi-K2 轮换，3 个作判别器求解、1 个作生成器；解出率 >0.667 则加难，=0 则诊断缺陷并修复或拒绝，介于两者间交人工验证，最多 5 轮（附录 C Algorithm 1）。

阅读者评价：同社区干扰的设计比随机噪声更可信，构造流程可扩展、答案可验证。但演化用到的模型家族与被评测模型重叠（GPT、Claude、Kimi），可能引入针对性偏差；正文"低于阈值即诊断"与 Algorithm 1"仅解出率为 0 才诊断"的描述略有出入。
