# CASIE: Extracting Cybersecurity Event Information from Text

CASIE 面向安全新闻中的事件触发词、参与者、角色及事件现实性抽取。该论文实际研究四个抽取环节，完整事件共指与知识图谱整合属于后续工作。关键结果：BERT 配置的触发片段 F1 为 79.94、论元 F1 为 74.76（Table 5）。
