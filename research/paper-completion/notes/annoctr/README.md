# AnnoCTR: A Dataset for Detecting and Linking Entities, Tactics, and Techniques in Cyber Threat Reports

AnnoCTR 是网络威胁情报报告数据集：400 份报告标注实体与时间表达，其中 120 份另有链接到 MITRE ATT&CK 的战术/技术标注（13,244 个）。关键结果：用 ATT&CK 概念描述做数据增强能改善少样本的技术识别，但各任务收益不同。
