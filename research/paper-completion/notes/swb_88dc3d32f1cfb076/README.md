# Kusa et al. — CSMeD: Bridging the Dataset Gap in Automated Citation Screening for Systematic Literature Reviews

本文把 9 个已公开的系统综述引文筛查数据集统一为 BigBio 格式的元数据集 CSMeD（325 篇综述），并从 Cochrane 网站补充综述协议与纳入/排除标准；另外新建全文筛查数据集 CSMeD-FT。基线实验显示：零样本标题/摘要排序中，以纳入标准为查询的神经模型 TNR@95% 约 0.55；全文筛查中微调的 Clinical-BigBird 在 TEST 上 F1=0.609。已阅读正文全部章节；论文多次引用的附录 A–G 不在该 PDF 中，未能阅读。
