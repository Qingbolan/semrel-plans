# Sun et al. — DSAEval: Evaluating Data Science Agents on a Wide Range of Real-World Data Science Problems

DSAEval 是面向“数据科学智能体”的评测基准：641 个问题、285 个数据集，智能体在带 GPU 的持久 Jupyter 沙箱中多轮执行代码，最终交付 notebook 与文字报告，由两个 LLM 评委对推理、代码、结果三维打分。13 个模型中 Claude-Sonnet-4.5 总分最高（8.164），多模态观测（把生成的图像回传给模型）在视觉相关类别上带来 2.04%–11.30% 的相对提升。已阅读正文、局限及附录 A–C、K；未逐条审阅附录中的全部案例与按领域一致性表。
