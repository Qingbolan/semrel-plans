# workload

| 项目 | 数值 / 说明 | 位置 |
|---|---|---|
| 原始来源 | 2,000+ 开源数据集与竞赛（如 Kaggle，取最高票 notebook）+ 50 本数据科学/统计教材 | §3.1，p.3；附录 A，p.12 |
| 候选 → 保留 | 2,421 个候选 QRA，拒绝 1,780（73.5%），保留 641（26.5%） | 附录 B，p.13；§3.1，p.4 |
| 拒绝准则 | 数据可访问性、问题清晰度、答案有效性 | 附录 B，p.13 |
| 数据集 | 285 个异构数据集 | Figure 3，p.5 |
| 数据类型 | 表格 79.1%、时间序列 9.1%、文本 5.8%、图像 4.2%、地理 0.6% 等 | Figure 3，p.5 |
| 领域 | 数据分析 54.3%、时间序列 10.4%、领域应用 7.2%、NLP 6.0%、CV 4.4% 等 | Figure 3，p.5 |
| 任务类型 | 数据准备 21.9%、报告与解释 14.7%、特征工程 13.4%、EDA 12.3% 等（多标签） | Figure 3，p.5 |

样本单位是“问题”（QRA），按数据集组织成 session；论文没有训练/测试划分，641 题全部用于评测。641/285 约为每个数据集 2.2 题，这是阅读者按总数推算的平均值，原文未给出每个 session 的题数分布。附录 B 的示例：接受的 ID 92（Animal Crossing 评论词频与 Shifterator 熵移图）、因参考答案缺少 R² 数值而被拒绝的 ID 6325（COVID-19 Prophet 预测）。

作者自己说明的偏差：79.1% 为表格、54.3% 为数据分析，总体分数不能代表所有模态（Limitations，p.10）。

依据：[arXiv:2601.13591v3，35 页](https://arxiv.org/pdf/2601.13591)，§3.1、Figure 3、附录 A–B，PDF pp.3–5、12–14。
