# 工作负载

本文是临床试验，不是数据集或查询基准。可确认的研究负载如下：

| 项目 | 低素养诊所 | 高素养诊所 | 位置 |
|---|---|---|---|
| 随机化人数 | 149 | 301 | §3.1，Abstract |
| 干预后评估缺失 | 13 | 0 | §3.1 |
| 完成 2 周随访 | 89（59.7%） | 263（原文写 84.1%） | §3.1，Table 2 |
| 可接受性分析人数（娱乐/小册子） | 65 / 70 | 148 / 153 | Table 3 |
| 参与度分析人数（仅娱乐组） | 64 | 146 | Table 4 |
| DCS 总分分析人数（娱乐/小册子） | 38 / 46 | 108 / 131 | Table 5 |

按 Table 2，高素养诊所完成随访 263 人、失访 38 人，263/301=87.4%，与正文 84.1% 不符；本笔记保留原文数值并标注差异（阅读者分析）。

数据收集时间为 2004 年 1 月至 2006 年 2 月（§2.1）。样本量目标为每组 75 人，以检测知识测量上的中等效应（§2.7）。分析方法：知识用重复测量方差分析（时间 × 组 × 诊所），DCS 和 PSAS 用以基线为协变量的协方差分析，按诊所分开建模；控制既往 PSA 检测不改变结果（§2.7）。

**基线差异**：低素养诊所完成随访者 73.0% 为非裔，高素养诊所为 17.1%；高中以上学历分别为 29.2% 与 90.1%；低素养诊所完成随访者平均 55.6 岁、失访者 52.2 岁（P=.005），完成者更常有家族史（15.7% 对 3.3%）和既往 PSA 检测（37.1% 对 22.0%）（Table 2）。§3.1 正文把这一年龄差描述为"完成者稍年轻"，与表格方向相反（阅读者分析）。

依据：§2.1、§2.7、§3.1，Tables 2–5。
