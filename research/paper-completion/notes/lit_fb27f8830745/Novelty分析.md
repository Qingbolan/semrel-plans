# novelty

原文自述两项贡献：（1）在 FRTR-Bench 上比较五个多模态嵌入模型，为表格+视觉混合数据的嵌入选择提供首个实证参考；（2）BRTR 框架：给 LLM 结构化检索工具和上下文预算机制，以迭代检索取代单次检索，并扩展到表格编辑和多模态交互，覆盖计算、格式、可视化与跨文件校验等组合工作流。

阅读者评估：索引与检索沿用作者此前的 FRTR；新意主要在 ReAct 式迭代检索 + 规划器 DAG 分解 + 图像上下文剪枝的工程组合，以及规模较大的人工评测（200+ 小时）。方法没有新的学习组件。文中有几处不一致需注意：§3.3 称有六类执行器（Excel、IO、web、validation、OCR、search），但附录 D 的规划提示只列 search/excel/io/web 四类（OCR 作为 excel 的工具），附录 A 也只统计这四类；§4.3 称全量 FINCH 失败 8 个任务，§4.4 又称消融子集"包含 BRTR 在全量上失败的全部六个任务"。另外，未与 SheetAgent、SheetBrain、TableMind 比较，作者以任务形式不同或缺少公开实现为由。

依据：[arXiv:2603.06503v1，15 页](https://arxiv.org/abs/2603.06503)，§1、§3.3、§4.2–4.4，PDF pp.2、5–9；附录 A、D，PDF pp.13–15。
