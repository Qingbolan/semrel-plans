# problem

| 项 | 内容 |
|---|---|
| 输入 | 自然语言任务 q 与语料 C（一个或多个工作簿；FINCH 中还有 PDF、图像、网页等） |
| 输出 | 答案 a（文本、新/修改后的工作簿、文档或二者兼有）和完整工具调用轨迹 τ，用于审计 |
| 工作单元 | 问答基准中为一个查询；FINCH 中为一个由多个相互依赖子任务组成的工作流 |

方法三部分：
1. **多模态索引**：沿用 FRTR，抽取行、列、矩形窗口、嵌入图像四类块，保存表名、坐标、表头等元数据，用 NVIDIA NeMo Retriever 1B 嵌入；稠密余弦 + BM25 混合检索，按“块类型 × 检索方式”的多个排序列表用 RRF（k=60）融合，初始取 top-10。
2. **agent 工具循环**：五个检索工具（search rows / columns / windows / images / all），行列检索可加坐标过滤；每次调用最多 T=50 次工具迭代；“始终剪枝”：检索到新图像时删除早先工具结果中的 base64 图像，仅保留元数据。
3. **planner-executor（Algorithm 1）**：先按引号内术语向量检索列位置，LLM 生成子任务 DAG 与输出类型；就绪子任务并行交给类型特定执行器，依赖结果以摘要传入；最后综合。

依据：[arXiv:2603.06503v1，15 页](https://arxiv.org/abs/2603.06503)，§3.1–3.3、Algorithm 1，PDF pp.4–5；附录 D，PDF pp.14–15。
