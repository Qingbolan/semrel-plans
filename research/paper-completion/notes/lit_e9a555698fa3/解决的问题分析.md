# 解决的问题

**形式化**：论文把 LLM 预测分析写成 `(query, data) → (text, code)`（式 1，§2，p.3）。

| 要素 | 内容 |
|---|---|
| 输入 query | 一条针对特定数据集的预测性问题：预测未来趋势或识别数据中的隐含模式；每条仅含单一问题、只依赖数据本身、不需外部知识（§1–2、§3.2，pp.2–3） |
| 输入 data | 多行多列的表格，以 CSV 文本形式完整放入提示；另附列名、数据类型、数值列最小/最大值、分类列类别数的"数据摘要"（§3.3，p.3） |
| 输出 text | 解释如何做预测、为何选此方法 |
| 输出 code | 实现分析的代码 |
| 评测单位 | 每个 (LLM, query) 的单次回答，按 7 个维度各打 0–4 分 |

提示由"查询与指令（扮演专业数据科学家）+ 数据摘要 + 数据明细"三部分组成（§3.3，p.3；附录 E 示例，p.17）。功能正确性不是打分，而是人工执行生成代码、统计无错误执行比例后映射为 0–4（§3.4，p.4；Table 2 注）。

阅读者分析：任务中没有标准答案或留出测试集，模型给出的"预测数值"是否正确并不在评测范围内。
