# novelty

论文声明四项贡献：异构工作区基准、执行落地的构造框架 DataSpace-Builder、语义感知的确定性表格评测器，以及跨 6 个骨干模型和 5 个 harness 的实证研究。Builder 分四步：(1) 跨语言转换——按外键、同名列或值重叠把列分组联合翻译，生成表/列/单元格三级映射，再确定性地改写数据库和 SQL，用执行等价性加 LLM 判定器校验问题与 SQL 的对齐；(2) 约束感知关系采样——从 SQL AST 中提取主外键、连接列、谓词与边界值作为保护集，按任务采样子库，并重新执行 SQL 得到候选答案；(3) 模态路由与渲染——用带种子的规则把每张表分配给 CSV/JSON/SQLite/Markdown/PDF 渲染器，由 LLM 按块生成“事实落地”的文档；视频则根据查询生成，可以把谓词条件移入视频（谓词抽象），或把答案单元格分散到多个场景；(4) 从 11 名专家中抽 2 人盲解复核，并独立编写评测配置，意见一致才收录。

阅读者分析：每个任务的底层分析逻辑始终是原 Text-to-SQL 的一条 SQL，所以金标准可以精确执行；“异构性”则来自对同一关系数据的重新渲染，是合成的而非自然产生的。源数据只有英文，中文来自翻译；88.5% 的任务来自金融类 BULL，领域分布偏向金融。
