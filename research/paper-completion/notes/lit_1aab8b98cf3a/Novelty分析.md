# 贡献与评价

**作者声称的贡献**（§1，p.2）：

1. 提出“用 SQL 查询现有预训练 LLM”这一问题，并给出数据库优先原型 Galois，在一定假设下执行 SPJA 查询；
2. 逻辑计划把复杂任务分解为 LLM 能处理的简单步骤，物理算子由 schema 和逻辑算子自动生成提示；
3. 在 46 条查询上，结果“与 DBMS 执行可比”，且优于人工改写为自然语言后的问答。

作者把查询计划类比为自动生成的思维链分解：计划写出中间步骤，传统算子弥补 LLM 在求平均、比较数值上的弱点。作者也把它与 CrowdDB（用众包回答开放世界问题）类比。

阅读者分析：这是语义算子/LLM 增强查询处理方向较早的数据库社区愿景论文，核心思想（逐元组提示、算子级 LLM 调用、类型约束清洗）后来被许多系统采用。但实验规模小、只做定性证明：“与 DBMS 可比”的说法与 Table 2 中连接查询 0% 匹配、整体 50% 匹配的结果有距离，应理解为“对可回答的通用知识查询有前景”。

阅读者分析：与本库多数语义算子论文不同，Galois 的数据源是 LLM 参数中的世界知识，而非用户提供的文档集合，因此正确性还受 LLM 知识覆盖与热门偏置影响。

依据：§1，p.2；§2，p.3；§4，p.3；§5、Table 2，p.5。
