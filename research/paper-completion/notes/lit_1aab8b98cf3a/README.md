# Saeed, De Cao, Papotti — Querying Large Language Models with SQL

这是一篇愿景论文：主张用 SQL 直接查询预训练 LLM 中存储的事实，并以“数据库优先”架构实现原型 Galois——用 DuckDB 生成逻辑计划，把扫描、选择、补取属性等物理算子实现为提示模板，再在 Python 中执行连接与聚合。在 46 条 Spider 通用主题查询上，ChatGPT 版 Galois 的单元格匹配率平均 50%，高于把同一查询改写为自然语言问答（44%）和链式思维问答（41%），但连接类查询为 0%。已阅读全文正文 §1–7。
