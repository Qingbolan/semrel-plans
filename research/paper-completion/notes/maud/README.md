# MAUD: An Expert-Annotated Legal NLP Dataset for Merger Agreement Understanding

MAUD 是并购协议的专家标注阅读理解数据集（152 份协议、47,457 项标注），按固定的交易要点问题体系对条款作多选判断。关键结果：单任务最佳 BigBird 总体 AUPR 57.8%（Table 3），MAE 等复杂类别仍有明显差距。
