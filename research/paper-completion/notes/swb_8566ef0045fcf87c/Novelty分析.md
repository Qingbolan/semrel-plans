# 贡献与评价

**论文的贡献**：

1. **OUAT 框架**（§3.2，PDF pp.4–6）：
   - 用 boto3 脚本按种子事件搭建 EC2、S3、IAM 等真实资源；
   - 从另一个 AWS 账户中的 Kali 实例执行攻击序列，时间线压缩但保留因果顺序；
   - 自动把执行的动作与 CloudTrail 事件关联，生成候选发现，再由安全工程师增删；
   - 用前沿 LLM 生成表面细节不同的变体，约 15% 被人工拒绝；
   - FP 用例由合法管理操作、有意公开的资源、CI/CD 痕迹、合作方跨账户访问等构造。
2. **评测框架**：M1 分诊（F3 加权，β=3）、M2 新发现召回、可选的 M3 工具覆盖（§4，PDF pp.6–11）。
3. **自家 SIR 智能体的基线结果**。

阅读者评价：“新发现召回”这一指标确实能区分复读告警和真正的调查，用真实攻击执行产生遥测也比纯合成日志可信。但有几处明显不足：

- 只评测了作者自己的智能体，没有其他架构或模型作对照。
- 人类基线来自 SOC 运营数据，人类并未在本基准上作答。
- 数据未公开（§6，PDF p.11）。
- 只用 CloudTrail 遥测。
