# 贡献与评价

**论文声称的贡献（§1，p.2）：**
1. 提出语义算子的编译式执行范式，作为提升效率与成本的实用方案。
2. 实现原型并做初步评测，显示效率显著更高、成本更低，质量只有小幅近似损失。
3. 讨论研究挑战：算子可编译性、语义保真度、未来的优化器集成，以及对更广领域的影响。

**解释式与编译式对比（Table 1，p.2）：** LLM 角色为运行时执行器 vs 编译器；调用次数为每行/每对 vs 每算子一次；执行目标为 LLM API vs 本地确定性代码；优势为灵活推理 vs 快速执行；弱点为高延迟高成本 vs 行为近似。

**研究机会（§6，pp.5–6）：** 保真度与验证（能否在信任前估计保真度，例如小验证集、给代码附置信分数）；可编译性与算子路由（可编译性应与选择率、基数一样成为代价模型一等属性）；混合/部分编译（编译谓词的确定性骨架，仅对剩余难例回退 LLM）；复用、漂移与重编译；多模态算子；语义算子之外的任务（垃圾过滤、文档排序、LLM Text-to-SQL）。

**阅读者评估。** 这篇的新意主要是立场与问题框架；实现很简单（单一提示、无路由、无验证），实验规模小（每类算子 100 个自建谓词、SemBench 10 条查询、单一后端 Palimpzest、单一模型 gpt-5-mini）。§6 中的“路由”“验证”在后续 SemBaker 论文中被实现为代价模型和可选 refine/validate，而后者的结果显示验证并不稳定提升质量。论文没有与已有的代理模型/级联/模型选择类优化方法做实验比较。
