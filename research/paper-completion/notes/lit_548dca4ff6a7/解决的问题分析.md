# 解决的问题

**输入**：一个表格数据集（CSV 或 SQLite，预先加载为 pandas DataFrame），加一条自由文本查询；用户还要选择 LLM 并提供 OpenAI Key（§3.1，p.5）。**输出**：一段 Python（matplotlib）绘图脚本，以及渲染出的图。图的类型由 LLM 自行决定（§3，p.5）。

**工作单元**：一次"查询 + 数据集"的请求。提示由两部分组成（§3.2，pp.5–8；Figure 4）：
- **描述提示**（Python docstring）：说明要使用名为 `df` 的 DataFrame；列出每列的名称和类型；object 类型且不同值少于 20 个的列视为类别型，并把值全部列出；要求模型自行命名坐标轴和标题，不要加 super-title；给出 Python 版本；最后附上用户查询。
- **代码提示**：import 语句、固定尺寸的单个子图，以及 `df = df_<name>.copy()`。

**调用参数**（Table 1，p.8）：temperature=0，max_tokens=500，stop="plt.show()"。正文说明，当时 ChatGPT 没有官方 API，作者是在网页界面中手工完成调用的（脚注 4，p.5）。返回的脚本前会拼接代码提示，必要时手工删去多余语句后再渲染；用户可以继续追加要求来修改图（§3.3，p.8）。

这里的"问题"更接近一个系统演示：从自然语言直接生成可执行的可视化代码，并让模型选图。论文没有正式的输出规范，也没有正确性定义（阅读者分析）

依据：§3，Table 1，Figure 4，pp.5–8。
