# Maddigan, Susnjak — Chat2VIS: Generating Data Visualisations via Natural Language using ChatGPT, Codex and GPT-3 Large Language Models

Chat2VIS 把用户的自然语言请求与数据集描述（列名、类型、少量类别值）拼成一个"描述提示 + 代码提示"，交给 GPT-3（text-davinci-003）、Codex（code-davinci-002）和 ChatGPT，让它们生成 Python 绘图脚本，再在 Streamlit 界面中渲染。评测只有 6 个人工目视检查的案例，没有定量指标。阅读的是 arXiv 预印本 v2，不是 IEEE Access 正式版。
