# problem

- **评测单位**：一条查询的一次试验。
- **输入**：自然语言问题；各数据库逻辑名称与 schema 的描述（descriptions）；说明人为注入的数据质量问题和领域定义的 hints。代理通过 harness 的工具与真实数据库交互：Claude Code/Codex 通过 bash 调用 psql、sqlite3、duckdb、mongosh 或 Python；ReAct 只有 list_db、query_db、execute_python、return_answer 四个工具。
- **输出**：自由格式答案。
- **判分**：每题配人工编写的 Python 验证函数——数值答案在容差内即可；单值答案用子串匹配，格式略有差异时用 Levenshtein 距离（平均阈值约为答案长度的 20%）；集合答案要求每个元素都出现；字典答案要求键出现且值位于键附近。只检查是否“包含完整正确答案”，不惩罚额外的错误信息。
- **入选条件**：每题至少满足 (i) 多库集成，并至少满足 (ii) 脏连接键、(iii) 文本抽取之一。依赖实时外部 API 的问题和开放式问题被排除；实验中禁用网络，以防代理下载 ground truth。

依据：[arXiv:2603.20576v3（2026-10-07），27 页](https://arxiv.org/abs/2603.20576)，§3.1–3.3、§4.1，Figure 1，PDF pp.2–7；附录 B，p.20–21。
