# Dorafshan, Thomas, Maguire — SDNET2018: An annotated image dataset for non-contact concrete crack detection using deep convolutional neural networks

这是一篇 Data in Brief 数据论文，发布 SDNET2018：用 230 张混凝土桥面、墙面、路面原图切分出的 56,092 张 256×256 子图，每张标注为有裂缝或无裂缝。论文附带 AlexNet 的完全训练（FT）与迁移学习（TL）基准，各类别测试准确率为 87.5%–95.5%。全文很短（数据描述 + 方法 + 两张表），已完整阅读；PMC 的 PDF 入口返回 Cloudflare 验证页，因此保存的是 PMC 全文 HTML。
