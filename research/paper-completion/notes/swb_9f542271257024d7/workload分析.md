# 工作负载

**来源**：58 篇 Cochrane 综述评估的 204 篇论文，以及 496 篇非 Cochrane 综述评估的 496 篇论文；全部为开放许可。用 BioC API 从 PMC 下载，其余手工下载，GROBID 解析 PDF，Stanza 分句（§4.1，p.4；附录 A.4，p.13）。

**任务规模**（Table 1，p.3；Table 11，p.13）：

| 任务 | Cochrane 训练 | Cochrane 测试 | 非 Cochrane 测试 |
|---|---|---|---|
| SSR | 235 | 313 | 无 |
| SJS | 346 | 465 | 无 |
| 主任务 | 774 | 906 | 2,489 |

非 Cochrane 综述没有支持判断，因此只能用于主任务，也没有单独训练集（脚注 1，p.3）。SJS 原有 906 条，经人工核查确保干扰项确实错误后保留 465 条（§4.5，p.6）。

**规模细节**：SSR 测试每篇论文平均 9,215 token、218.6 个句子，平均 1.9 个要点，最优句数平均 1.4（1–5）（Table 9，p.13）。主任务 Cochrane 测试标签为低 562、不清楚 195、高 149；非 Cochrane 测试为 1,465、574、450（Table 11）。

**按类别计数**：结果表中各类别 n 之和高于测试集大小，因为一个偏倚可属多类（§5.2，p.7）。阅读者核算：SSR 各类 n 之和为 332，高于 313（阅读者分析）。
