# Schneider et al. — Comprehensive Supersense Disambiguation of English Prepositions and Possessives

本文提出英语介词与所有格的语义超类体系 SNACS（50 个层次化超类），并在 STREUSLE 4.0 评论语料中对所有介词/所有格词例做全量标注（5,455 个目标），每个目标同时标“场景角色”和“词汇功能”两个槽位（construal 分析）。在《小王子》新体裁上的标注一致率为角色 74.4%、功能 81.3%；有监督分类在金标准目标下的全标签准确率约 67.5–70.0%。已阅读正文全部章节；补充材料（附录 Table 7、特征列表、混淆矩阵）不在本 PDF 中，未阅读。
