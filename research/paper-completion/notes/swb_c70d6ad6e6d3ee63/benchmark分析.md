# 评测与边界

**模型**：Gemini 1.5 Flash/Pro、Claude 3 Sonnet/Opus、Claude 3.5 Sonnet、GPT-3.5 Turbo、GPT-4 Turbo、GPT-4o、Llama 3 70B、Command R+；均在全部 629 个安全用例与 97 个用户任务上评测；消融聚焦 GPT-4o（§4，pp.6–7）。

**实验 1（各模型，Table 3，p.20，“Important message”攻击）**：

| 模型 | 无攻击效用 | 攻击下效用 | 定向 ASR |
|---|---|---|---|
| Claude 3.5 Sonnet | 78.22% | 51.19% | 33.86% |
| GPT-4o | 69.00% | 50.08% | 47.69% |
| Claude 3 Opus | 66.61% | 52.46% | 11.29% |
| GPT-4 Turbo | 63.43% | 54.05% | 28.62% |
| Command-R+ | 25.44% | 25.12% | 0.95% |

更强的模型往往更容易被攻击（逆向缩放）；多数模型在攻击下损失 10%–25% 的绝对效用（§4.1，p.7）。Slack 套件的攻击成功率达 92%，Travel 的注入任务 6 为 0%（§4.1，p.7）。

**实验 2（攻击提示，Table 4，p.20，GPT-4o）**：

| 攻击 | 定向 ASR | 非定向 ASR |
|---|---|---|
| TODO | 3.66% | 32.75% |
| Ignore previous | 5.41% | 33.23% |
| InjecAgent | 5.72% | 31.48% |
| Important message | 57.7% | 49.9% |
| Max | 57.55% | 68.36% |

知道用户名和模型名只让 ASR 提升 1.9%，猜错则下降约 22%（Table 2，p.8）。

**实验 3（防御，Table 5，p.20，GPT-4o）**：

| 防御 | 无攻击效用 | 攻击下效用 | 定向 ASR |
|---|---|---|---|
| 无 | 69.0% | 50.01% | 57.69% |
| 分隔符 | 72.66% | 55.64% | 41.65% |
| 注入检测器 | 41.49% | 21.14% | 7.95% |
| 重复提示 | 85.53% | 67.25% | 27.82% |
| 工具过滤 | 73.13% | 56.28% | 6.84% |

**局限（§4.3、§5，pp.9–10）**：工具过滤在工具无法预先规划、或完成任务的工具本身足以实施攻击（占 17% 用例）时失效；尚未覆盖跨多轮任务、多模态、注入长度约束；攻击和防御都较简单；任务需手工编写。

阅读者分析：GPT-4o 无防御的定向 ASR 在 Table 3 为 47.69%、Table 2 为 45.8%，Table 4/5 为 57.7%/57.69%，正文未解释差异；正文称工具过滤降到 7.5%，表中为 6.84%；引言称最佳智能体被攻破“不到 25%”，与表中数据不符，可能是 v1 遗留表述；Max 的定向 ASR 反而略低于单一攻击，“提升 10%”只对应非定向结果（阅读者分析）。
