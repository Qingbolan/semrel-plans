# 解决的问题

**框架组件（§3–§3.1，pp.3–5）**：
- **环境**：一个应用领域及其工具集，环境状态是可变对象集合（如 Workspace 含收件箱、日历、云盘）；部分状态是注入占位符。
- **工具**：读写环境状态的 Python 函数，文档写入智能体提示，输出以 YAML 格式返回。
- **用户任务**：自然语言指令，带一个确定性二值 `utility` 函数（检查模型输出及执行前后的环境状态）和一段标准函数调用序列。
- **注入任务**：攻击者目标，带 `security` 函数判定目标是否达成。
- **安全测试用例**：同一环境内用户任务 × 注入任务的笛卡尔积。

**智能体接口**：只需实现 `query` 函数，输入用户指令、可用工具和环境状态；可组合成流水线（如 LLM + 注入检测器）（§3.2，p.5；附录 A Figures 11–12，p.16）。

**攻击接口**：给定注入任务，为每个占位符返回注入文本；利用用户任务的标准调用序列，只在该任务实际会读取的工具输出中放置注入（§3.3，p.6；附录 A，pp.16–17）。

**指标（§3.4，p.6）**：无攻击效用（benign utility）；攻击下效用（完成用户任务且无对抗副作用的用例比例，其补集为非定向攻击成功率）；定向攻击成功率（攻击者目标达成的用例比例）。多个攻击组合时，任一成功即计成功，模拟自适应攻击者。

依据：§3，附录 A，PDF pp.3–6、16–17。
