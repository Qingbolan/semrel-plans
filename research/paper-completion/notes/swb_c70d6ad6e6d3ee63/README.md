# Debenedetti et al. — AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents

AgentDojo 是一个可扩展的评测框架，用于测量工具调用型 LLM 智能体在不可信数据中的间接提示注入下的效用与安全。首版包含 4 个环境、97 个用户任务、27 个注入任务和 629 个安全测试用例，用对环境状态的确定性检查判定成败。实验显示：最强模型的无攻击效用约 66%–78%，GPT-4o 在“Important message”攻击下的定向攻击成功率约 48%–58%；工具过滤和注入检测器能把成功率降到 7%–8%，但都有局限。已阅读正文、附录 A–E 及完整结果表。
