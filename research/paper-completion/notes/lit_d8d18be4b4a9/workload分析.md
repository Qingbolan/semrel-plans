# 工作负载

论文没有基准数据集、查询集或训练/测试划分，也没有定量指标。

**系统内置数据**（§3，pp.2–3）：一组预定义图表，涉及人口调查、失业率、汽车数据、奥运奖牌等数据集；正文未给出图表或数据集的总数和规模。

**用户研究**（§4，p.3）：

| 项目 | 内容 |
|---|---|
| 参与者 | 11 名数据从业者（P1–P11），有数据驱动文章或类似报告写作经验；包括内容写作者、仪表盘设计者、项目经理、顾问，来自多个组织 |
| 招募 | 相关兴趣频道的 Slack 社区 |
| LLM 使用经历 | 多数接触过 LLM 工具，5 人曾用于写作辅助 |
| 任务 | 20 分钟数据故事写作，之后半结构化访谈；鼓励出声思考 |
| 材料 | 4 种数据集+图表组合之一（堆叠柱状图、折线图、散点图、等值区域地图） |
| 编辑环境 | 在单独的文档编辑器中写草稿 |

**使用量**（T3，p.3）：平均每人生成 4 篇故事，其中约 3 篇带标注。T5 报告 3 人在 20 分钟内完成初稿（p.3）。

样本单位是会话与访谈陈述，数量小且没有对照组，无法据此推出生成质量或节省时间的效应量（阅读者分析）。

依据：§3–4、T3、T5，PDF pp.2–3。
