# 解决的问题

论文定义两个评测任务，样本单位都是一份法律决定书（案件）。

**任务 1（LLM 自动标注）**：输入一份决定书全文和零样本结构化抽取提示，输出符合预定 JSON 结构的字段集合（涵盖命名实体识别、分类、摘要等子任务）。与金标准比较：字段完整率 FCR = 平均（重叠字段数 / 参考非空字段数）；Overall Accuracy 对重叠字段中"精确字段"（日期、金额）用完全匹配、"语义字段"（事件描述、摘要）用 ChatLaw-Text2Vec 嵌入余弦相似度 ≥0.6 判对，再按字段数加权平均（§4.2，PDF pp.5–6，式 1–4）。

**任务 2（LLM 法律推理）**：输入角色设定、任务说明和案情描述（可附加人工设计 CoT 或自拟 CoT 指令），输出完整推理链与责任结论。IRAC Recall = 平均（模型正确覆盖的专家 IRAC-Trace 字段数 / 参考字段数），匹配规则沿用任务 1；LLM Score 由 DeepSeek-R1 按 A/B/C 三级评分，A=1、B=0.5、C=0 取平均（§4.3，PDF pp.6–7，式 5–6）。

阅读者分析：原文没有说明案情描述是如何从决定书中切出、是否去掉了结论段；也未给出训练/测试划分，评测看起来是在整套数据上零样本（另有一次 one-shot 实验）进行。
