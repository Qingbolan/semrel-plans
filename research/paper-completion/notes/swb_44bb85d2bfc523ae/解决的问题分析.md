# 解决的问题

**输入**：一项试验的自由文本入排标准（如来自 clinicaltrials.gov）；一名患者上传的病历 PDF（可含扫描件、表格、手写）。

**输出**：对每条准则的判定——Eligible / Not Eligible / Insufficient information（评测中记为 met / unmet / unknown），附理由与来源引用；用户随后可确认或修正每条判定，并把患者标为 “To screen” 或 “Not eligible”。

**评测单位**：患者-准则对，每对视为独立样本；论文明确不做患者级自动汇总推荐。

**流程**（Fig. 1）：

- **试验预处理**（三次独立 LLM 调用）：拆分准则；生成“相关性准则”（通常为试验主要疾病）；生成检索指引（研究人员会先假设信息在病历哪里）。
- **患者预处理**：PDF 拆页成图像，用 Google Cloud DLP 去标识化，送入多模态嵌入模型（引文为 voyage-multimodal-3），存入向量库。
- **匹配**：先用相关性准则检索最相关的一页，交 GPT-4o 判断是否相关；通过后，按检索指引为每条准则检索页面，交 o1 判定。

阅读者分析：这是一个“检索 + 逐条语义判定”的文档级过滤问题，判定的三值输出中 unknown 是显式类别；从准则级到患者级的汇总被作者列为未解决问题，所以不能把 87% 理解成患者筛选准确率。
