# 解决的问题

**任务**：全文中的化学实体识别（NER）与归一化（映射到 MeSH 标识符）。

| 要素 | 内容 |
|---|---|
| 输入 | PMC 开放获取全文（BioC 格式；参考文献与表格正文被去除，保留表格标题） |
| 输出 | 化学提及的字符区间 + MeSH ID（可为多个 ID 的组合，或未知） |
| 样本单位 | 提及（mention）；归一化评测以"文档内概念集合"为单位 |
| 标注者 | 10 位 NLM 标引员，有 10–40 年 MeSH 标引经验 |

**标注范围**（Annotation guidelines，p.4）：不标太泛的概念（atom、moiety）和不能直接对应结构的词（molecule、drug、polymer）；不标蛋白质、酶、脂质、核酸等大分子；嵌在其他实体里的化学概念（如 "sodium channel gene" 中的 sodium）标为 OTHER。

**评测定义**（Usage Notes，pp.9–10）：NER 采用严格边界，起止字符都匹配才算真阳性；归一化比较文档级的标注概念集合与预测概念集合。

**配套工具 MTCR**（pp.5–6）：在 BlueBERT 识别出的提及上，先用 Ab3P 解析缩写，再依次尝试 MeSH 精确匹配、宽松匹配、宽松复数匹配，以及 UNII、ChEBI、DSSTox、UMLS 等多术语表匹配，命中后经交叉引用映射到 MeSH；最后用文档内无歧义的 ID 做消歧，并剔除不在 MeSH 化学树中的 ID。

依据：Methods、Usage Notes，PDF pp.2–6、9–10。
