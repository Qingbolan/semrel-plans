# Overview of automatic clinical coding: annotations, guidelines, and solutions for non-English clinical cases at CodiEsp track of CLEF eHealth 2020

CodiEsp 是西班牙语临床病例自动编码共享任务的综述，提供诊断编码、操作编码以及编码证据定位三种评测。正文报告的是公开病例报告上的编码实验，不能直接视为真实医院电子病历的部署效果。本文阅读覆盖正文问题、资源、参赛方法、结果与讨论，未逐条复核附录所有提交运行。关键结果：诊断子任务最高 MAP 0.593（IXA-AAA），证据子任务官方最高 F1 0.611（FLE）（Table 7）。
