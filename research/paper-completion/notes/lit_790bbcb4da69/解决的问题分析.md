# 解决的问题

任务定义（§2.2，PDF pp.2–3）：给定自然语言问题 Q、数据库信息 S、模型 F(·|θ) 和提示 P，输出 SQL：Y = F(Q, S, P | θ)。工作单位是单个问题，最终输出一条 SQL。

| 阶段 | 输入 → 输出 |
|---|---|
| 预处理 | 数据库与训练集 → 只对字符串类型值建立的向量库、数据库模式、由 LLM 补写 CoT 的 Query-CoT-SQL 示例库、按错误类型准备的纠错示例（§3.3，pp.4–5） |
| 抽取 | Q、模式 → 实体、相似值（向量检索并按阈值过滤）、LLM 选出的列加上向量检索召回的列；Info Alignment 把 SELECT 内容与问题中的短语一一对齐，并补回主键和同名列（§3.4，p.5） |
| 生成 | 用 MQs 相似度检索出的 top-K 少样本，按"理由→列→值→SELECT→SQL-Like→SQL"的顺序生成多个候选（§3.5，pp.5–6） |
| 对齐 | Agent 对齐（值与库中存储一致）、Function 对齐（聚合函数与 JOIN）、Style 对齐（数据集风格，如 IS NOT NULL）（Listing 6，p.6） |
| 精修 | 根据执行报错或空结果，用对应错误类型的少样本纠错；再按执行结果多数投票，票数相同时选执行最快的那条（式 (3)，p.7） |

对齐智能体的形式定义为 A_Alignment(x + A′(x)) = A(x) − A′(x)，用于消除实际输出与期望输出之间由幻觉造成的差异（§3.1，p.4）。
