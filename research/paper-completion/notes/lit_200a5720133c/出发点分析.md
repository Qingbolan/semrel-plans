# 出发点

作者的出发点（§1）：

- 企业大部分数据仍存于关系数据库，做分析需要写复杂 SQL 并解读结果，通常依赖数据科学家，对中小企业成本过高。
- 现有 TableQA 与 Text-to-SQL 只解决"查找"类任务——返回单个值或简单聚合，不支持跨表推理、多步操作和把结果综合成报告。作者举例："各地区销售趋势如何、与营销投入有何相关？"超出单查询能力。
- 没有专门的数据集：Spider、BIRD 以精确取值为目标，缺少需要多表推理、大规模信息整合与报告撰写的分析型问题。

因此论文同时给出方法（DAgent）与基准（DA-Dataset + 指标）。

阅读者分析：动机与"自然语言数据分析/报告生成"方向一致，但论文把"报告"的质量主要落在检索覆盖与 LLM 打分上，没有像后续数据智能体基准那样检验报告中的数值是否被正确计算或可执行核对。

依据：[arXiv:2503.13269v2](https://arxiv.org/abs/2503.13269)，§1、§2.3，PDF pp.1–3。
