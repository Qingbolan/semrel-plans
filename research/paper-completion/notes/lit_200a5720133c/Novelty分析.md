# 贡献与评价

**作者声明的贡献**（§1）：

1. DAgent：面向 RDB-DA 报告生成的 LLM agent，整合规划、工具、记忆。
2. DA-Dataset：强调多表推理、大规模数据汇总与报告综合的新数据集。
3. 实验表明 DAgent 在报告完整性、正确性、简洁性上优于现有方法。

**方法要点**（§4）：

- 规划模块判断是否需要分解；分解工具与 SQL 改写工具均为 LLaMA2-13B + 按领域动态加载的 LoRA（r=32），领域由问题嵌入与领域关键词嵌入的相似度选择。
- 检索采用两路：直接编码检索（表元数据+列元数据+单元格值拼接后嵌入，先比 schema 选表，再在表内检索单元格；text-embedding-ada-002）和 Text-to-SQL（低资源用 C3、高资源用 FinSQL）。
- SQL 改写工具把返回过多行的查询改写为聚合查询（例：`SELECT GovernmentSavings FROM ed_moneyauthoritybs` → 按 Year 求和）。
- 记忆存三类：历史问题与结果、当前问题的中间结果、历史问题与规划路径对应关系。
- 报告由 DeepSeek v2.5 依提示模板生成（§6.1.4）；Figure 1 标注则写 Tools④ 为 GPT4，正文与图不一致（阅读者分析）。

**阅读者评估**：

- 各组件（问题分解、C3/FinSQL、TableRAG 式单元格检索、LoRA 领域适配）多为已有技术的组合；新意主要在任务设定与数据集。
- LoRA 的训练数据、训练集/测试集划分均未说明，无法判断是否存在与 DA-Dataset 的重叠。
- 记忆模块（尤其"相似问题直接复用历史结果"）没有单独消融，对结果的贡献不明。
- 数据集参考报告由同一类流程（LLM 生成 SQL + 模板生成报告）合成，与 DAgent 自身的"分解+SQL+生成"范式高度同构，可能偏向此类方法。

依据：[arXiv:2503.13269v2](https://arxiv.org/abs/2503.13269)，§1、§4、Figure 1，PDF pp.2、4–7；§6.1.4，p.10。
