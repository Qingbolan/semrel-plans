# Li, Gao et al. — MedGUIDE: Benchmarking Clinical Decision-Making in Large Language Models

MedGUIDE 用 55 棵 NCCN 肿瘤指南决策树生成临床情境多选题，检验 LLM 能否按指南路径选出"下一步处理"。经奖励模型与 LLM 评审双重过滤后保留 7,747 题，评测 25 个模型：最好的 GPT-4.1 准确率 0.6439，医学专用模型普遍更差（Meditron-7B 仅 0.1701）；把指南树放进上下文可显著提分，继续预训练收益有限。已阅读正文 §1–§6 与附录 B–I（局限、标注者、评分细则、全量结果表、相关性、改进方法），未复现实验。
