# 解决的问题

三项任务都假定论证成分已从判决中切分出来，工作单位是一个论证成分（一段文本，可跨多句，也可一句含多个成分）（§2、§3.2，pp.2–4）。

| 任务 | 输入 | 输出 | 形式 |
|---|---|---|---|
| Argument Component | 一个论证成分 | `prem` 或 `conc` | 二分类 |
| Premise Type | 一个前提 | `F`（事实）、`L`（法律）或两者 | 多标签 |
| Argument Scheme | 一个法律前提 | Rule、Prec、Class、Itpr、Princ 中的一个或多个 | 多标签多类 |

若一个成分既是某论证的结论、又是另一论证的前提，按前提标注（§2，p.2）。Precedent 只计引用意大利最高法院或欧盟法院的判决（§2，p.3）。

每行数据还带 Document、Chain_id（文档内论证链编号）和 Id 字段（§3.3，p.4），但三项任务的提示只输入单条文本，不提供上下文或论证链（§3.4，p.4）。

阅读者分析：任务不包含成分切分和关系（支持/攻击）预测，属于论证挖掘流水线中的分类子步骤。

依据：§2–§3.4，PDF pp.2–4。
