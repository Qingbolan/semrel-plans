# 具体用例

论文 §2 给出的 Rule 图式例子（附录 A 有英译）：一段法律前提写到“根据 D.Lgs. n.546/1992 第 54 条与第 23 条的合并规定，上诉被告须在上诉通知送达之日起 60 日内出庭”（§2，p.3）。

使用流程（阅读者按论文三个提示串联，论文未给出该例的逐步模型输出）：
1. 先用 Argument Component 提示判定这段文字是 `prem` 还是 `conc`；
2. 若为前提，用 Premise Type 提示判定为 `L`（法律）；
3. 再用 Argument Scheme 提示，模型应输出包含 `Rule` 的列表，因为文本显式引用了法典条款（§3.4，p.4）。

另一个例子说明 Classification 图式：法院先界定“compro oro（黄金回收店）”的含义和特征，再判断某事实是否具备这些属性（§2，p.3）。

阅读者分析：在语义查询场景中，这对应“对已切好的判决段落做多标签语义分类”，例如筛出所有引用先例的法律前提。论文未提供跨段落或整份判决层面的查询，也没有给出 LLM 在这些例子上的输出。

依据：§2、§3.4、附录 A–B，PDF pp.2–4、7–8。
