# MedMNIST v2 - A large-scale lightweight benchmark for 2D and 3D biomedical image classification

MedMNIST v2 把 18 个生物医学影像数据集统一为 MNIST 式的小尺寸分类基准（708,069 张二维、9,998 个三维样本），并给出 ResNet 与 AutoML 基线。关键结论：它是轻量算法基准，作者明确说明降分辨率数据不用于临床。
