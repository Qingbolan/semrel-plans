# 解决的问题

**任务**：给定数据科学题目集合 D（每题含自然语言描述与数据，需生成 Python 代码，由环境执行并判定输出），提高 agent 的整体通过率。

**方法流程**（§3、Figure 2）：

| 阶段 | 输入 | 输出 |
|---|---|---|
| 课程生成（Step 1–2） | 全部题目描述（不看参考代码或评测结果） | 每题难度等级及理由；按由易到难排序的课程数据集 D_c |
| 检索（Step 3） | 当前题描述 p_i、记忆 M_i = {(p_k, c_k, t_k)}，k<i | 按嵌入余弦相似度取 top-K 示例（含答对与答错的） |
| 解题（Step 4） | 当前题 + 按相似度递增排列的示例 | 生成的代码，交由环境执行评测 |
| 积累（Step 5） | 题目、代码、评测标签 t_k ∈ {Correct, Incorrect} | 追加到长期记忆 |

**工作单位**：单个问题（DSEval 中多轮 problem-set 内的每个 question）；评测为通过率。

阅读者分析：记忆中的 t_k 来自环境对测试题的评测结果，即推理过程中使用了测试集的正确性反馈；Mentor 需要事先看到全部测试题描述才能排序。这两点意味着该设定是"批量离线解一整套题"，与逐题独立评测的常规基线不完全同条件，论文未讨论这一差别（阅读者分析）。
