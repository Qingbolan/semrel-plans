# 贡献与评价

**作者声称的贡献**（§1，p.3）：

1. 用 LLM 预测相关行列索引，把大表缩为子表；
2. “解析—执行—回填”问题分解，用中间 SQL 产生可靠的数值/逻辑子问题，无需大量标注数据；
3. 在 TabFact、WikiTableQuestions、FetaQA 上优于基线，TabFact 上首次超过人类；
4. 子证据与子问题带来一定可解释性。

两个模块各自都有前身——行列选择类似 TaBERT 的 content snapshot 或检索子证据，SQL 辅助推理与同期 Binder 接近。Dater 的区别在于把 SQL 执行结果回填进自然语言子问题，再交给 LLM 推理，而不是让程序直接产出答案；这是一个工程化组合，增益在消融中可分解验证（Table 4）（阅读者分析）。

“首次超过人类”依赖把 Dater 分解注入 PASTA 的设置（93.0%）；纯 LLM 的 Codex+Dater 为 85.6%，低于人类 92.1%。此外，§5.1 称 LLM 预训练数据不含表格数据所以无泄漏风险，这只是作者断言，文中没有给出检验（阅读者分析）。

依据：§1，p.3；§5.1，p.7；§5.5，p.9；Tables 1、4，pp.8、10。
