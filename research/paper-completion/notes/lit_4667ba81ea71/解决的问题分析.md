# 解决的问题

**形式化**：每个样本由表格 T（RowT 行、ColT 列，单元格 v_ij）、自然语言问题/陈述 Q 和答案 A 组成。两个任务：表格事实核查（FV），A∈{0,1}；表格问答（QA），A 为自然语言序列（WikiTableQuestions 为短答案，FetaQA 为长句）。工作单位是“一张表 + 一个问题”。

**流水线中间产物**：

| 阶段 | 输入 | 输出 |
|---|---|---|
| 证据分解 | T、Q、少样本示例 C^ED | 行索引集合与列索引集合 → 子表 T̂ |
| 问题分解（解析） | T、Q、C^QD | 数值处以 `{...}` 掩码的完形子问题 |
| SQL 生成与执行 | T、子问题、C^PR | 形如 `SELECT COUNT(*) FROM w WHERE ...` 的 SQL，在表上执行得到数值 |
| 回填与联合推理 | T̂、回填后的子问题、C^JR | 最终答案 A |

注意 SQL 只作为生成子问题的桥梁，最终答案仍由 LLM（或微调模型）读子表与子问题后给出，而非直接返回 SQL 结果。

依据：§3，p.5；§4.2–4.4、Prompt 4.2–4.5，pp.5–7；Figure 2，p.4。
