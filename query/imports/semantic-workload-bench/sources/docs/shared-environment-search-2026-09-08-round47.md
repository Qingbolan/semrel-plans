## 为什么暂不计入

长法规公开存在的线索，不等于这些案子的历史适用环境已经冻结。数据重构及缺源编号也使法院 gold 的原始来源难以逐案核验。另一方面，不能把这些缺口夸大成该路线不可构造：下一步优先检验完整官方法规覆盖、可恢复日期和原案关联。

本例 facts 已包含最终和解金额和日期；主要语义工作是判别确认和解的程序效果，不是从复杂长法规中算出金额。不能据此声称几十页 E 必须被反复推理。需与同资源固定检索、仅 E 编译、Coding Agent 和整批 Agent 比较，允许静态程序同样正确。
