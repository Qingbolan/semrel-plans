# Shared-environment执行家族核验：HSCodeComp

**△ Partial fit，不进入Strong fit。** 结构比AnnoCTR更接近目标：商品归类会用不同的材质、用途、工艺、价值与基本特征判断。但目前既没有20条完整的事实—条款闭合，也没有完整环境下固定预处理不足的证据。缺失事实不能作为Agent能力差距。

## 1. 来源、任务与事实边界

原论文HSCodeComp（Yang等，2025）§3定义商品归类，§4说明构造/专家标注，§5和附录F描述实验。作者原PDF10042953bytes已随完整仓库取得。固定作者commit `ee329e98f92b51bd797785f648c7c4e42e678ad7`，完整ZIP77541590bytes/536blob；原商品JSONL1840855bytes。[^1][^2]

共享E为2025HTS Revision15：官方JSON13731683bytes、35950行，29932非空不同code；官方完整税则PDF19160545bytes、4429页，已取得GRI及章注。官方JSON与作者副本字节一致。旧“缺章注”的描述已由历史第9轮补取解决；当前缺口不能仍写为整个章注未下载。CROSS/eWTP历史使用范围、标注时实际页面和案例未逐条冻结。[^3]

q是一项固定任务：按此冻结税则对单条商品输出10位HTS。原632项由两名专家标注，分歧交高级专家；另有第四专家复查10%样本。gold为专家归类，不是632份海关裁决。专家曾访问完整商品网页；公开记录删除图片及URL，不能假定公开文字与专家信息相同。[^1]

| 任务表列 | 一句话定义 | 取值 |
|---|---|---|
| record_id | 返回商品标识 | 字符串 |
| hts_code | 输出冻结版本的10位code | 10位字符串，未知时null |
| facts_used | 列出记录中实际给出的决定性事实 | 字段引用，不从gold补写 |
| rule_refs | 列出适用GRI、章注、层级条目位置 | 文件/页/行引用 |
| status | 区分结论、不足及执行失败 | OK / UNKNOWN / ABSTAIN |

状态为建议实验契约，原数据没有完整UNKNOWN gold。不能把原code改成UNKNOWN后继续称原基准准确率。恢复或补标需要独立协议。

## 4. DAG（表3）

```python
paths = build_paths_by_indent(E.hts_rows)      # 普通预处理；保留无编号父行
notes = index_notes(E.full_tariff)             # 普通预处理；共享E
for batch in disclosed_static_batches(items):
    facts = sem_map(extract_facts, batch)      # 材质/功能/工艺/件价；未知不补
    candidates = retrieve(paths, facts)        # 固定检索，可返回多个候选
    applicable = sem_map(resolve_exclusions,  # 语义步骤，依赖E与事实
                         facts, candidates, notes)
    codes = sem_map(classify_hierarchy,       # 关键结果决定10位gold
                    facts, applicable, E.gri)
    emit(validate_code_and_evidence(codes))   # 普通校验
```

这是一条可竞争的固定程序，不是已经证明失败的弱基线。材料冲突、套装基本特征等步骤可以作为固定语义列；只有实测证明这些列仍无法覆盖记录差异，才有证据主张额外动态探索价值。相同循环导航不同税则节点不自动形成多个operator家族。

## 5. 四臂及重复工作拆分（表4）

| 臂 | 拿到什么 | 预期质量/风险，均未新实测 | 过程 |
|---|---|---|---|
| 静态只有任务表 | 任务+公开商品 | 已知商品可能答对；税则版本及细分易错 | 单次归类，不得拿缺图失败当机制证据 |
| 静态+完整E | 同输入+全部冻结税则 | 4429页很大，不说明固定索引无效；完整事实缺失同样无法解决 | 一次构建树/注释索引→固定事实抽取→候选/排除/细分类 |
| 逐记录Data Agent | 同输入+可探索E | 可以调整候选和查询，不能补出未公开材质 | ==查材质、用途对应章注及排除项==→==核每件价值或工艺条件==→归类/不足 |
| 批处理Data Agent | 整批+相同可探索E | 可共享路径、常见排除和功能规则；增益未知 | ==预建共同树与章注索引==→按早期语义事实分组→==复用组内规则==→逐项核特有事实 |

ρ_E：税则读取、索引、祖先展开，可一次预处理。ρ_P：提取属性、候选检索、逐级比较和合法code校验，可固定程序覆盖。ρ_G：候选包括材质主导、功能/部件主导、工艺主导、按件价值、复合品基本特征等约5类检查模板；这是研究假说，非轨迹中测得的5个家族。它们可重叠，路由部分为关键词/结构，部分需语义判断。ρ_R：商品事实冲突、主要用途或基本特征的个案判断。没有真实执行轨迹，四类比例与K不可填伪精确数字。

章数27、code数352不是K；本轮强制抽20章更不能从20条观察推算K/N。若约5类语义模板成立，则数量级可能满足1≪K≪632，但其可复用性、路由预测性和相对静态程序的增益均未实测。

## 7. 两个真实实例

Task591：玻璃管套装，属性each pack=20，价格8.3375USD。源gold7013999090的祖先包含“Valued over $5 each”。价格究竟按套还是单件、是否法定估值，公开字段未说明；因此缺口是输入充分性。Agent不能为匹配gold默认为单件价。

Task485：尼龙表带，gold9113904000，路径明确指纺织材料表带。它展示一个可能由简单材质/用途匹配完成的记录；不能因同湖另有复杂商品就断言每条都需要探索。两例表明异质性存在，但不能直接得出家族复用优势。

## 8. 实验主张与十问结论

原论文§5.1无工具模型主要使用内部知识，部分VLM有图片；不能将其低分作为“完整E的固定调用失败”。附录F又称所有baseline有搜索资源，并说明部分决策规则及网页访问因未改善开放Agent而未在最终评测使用；与§5.1需要按具体臂核对，不能拼成统一同资源结果。没有充分依据将作者最优Agent与人类差距归因为缺少家族复用。

q/输出/不足状态见任务表；E及事前版本见来源，但外部资源未冻结；x为真实商品而非每条新问题；y为专家而非模型标签；C审计见20条。D目前无法证明。候选分支及K假说见拆分；共享与独有工作亦已区分。G缺事实而非可凭推理修复。相较普通RAG，可能需要跨规则排除和复合品语义，但固定多步RAG/分类程序可同样实现，尚无证据排除它。

首批实验优先级：高于纯定义链接的AnnoCTR，因条件确实因商品而异；但不能直接开性能实验。先补图像/事实与依据，否则结果不可解释。最大风险是UNKNOWN事实，最可能击败拟议方法的baseline为E-only生成的税则树程序+固定语义属性抽取+候选复核。预处理会覆盖ρ_E及大量ρ_P，是否剩ρ_G待证。

目前严格审计2个：0Strong、2Partial、0已审Reject；其余历史来源待审。暂不给虚构Top5，仅给已审两项的有条件优先顺序：HSCodeComp、AnnoCTR。
