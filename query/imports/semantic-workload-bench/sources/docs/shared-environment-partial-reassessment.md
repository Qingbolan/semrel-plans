# 五个Partial的可执行性复核

本轮重新读取当前status及五张卡片的具体后续证据。没有任何一个已经具备C/D/E全部通过的依据；不启动以缺失事实为输入的性能比较。

| 候选 | 必须先解决的具体问题 | 可接受的补证 |
|---|---|---|
| AnnoCTR | 泛指mention与特定技术的链接范围；原生技术ID泄漏 | 对应标注规则及可审计输入契约；同资源消歧基线 |
| HSCodeComp | 单价、进口组合等商品事实及删除图像 | 原始属性/图像或独立复核，不能从gold反填 |
| UDRP | panel实际Google/Archive等历史调查未冻结 | 原时点调查证据；当前网页不能冒充历史结果 |
| CodiEsp | 代码/事实冲突及外部缩写资源未冻结 | 标注版本资源、官方纠错或独立审核；不能私改gold |
| STARD | 相关法条标签不等于充分裁决依据 | 冻结相关性契约；不把关联检索换成事实不足的裁决 |

本轮实际尝试补齐CodiEsp的SEDOM资源。公开索引显示2026年9月7265缩写，但原标注时点版本未确定；两条卫生部历史PDF候选路径404，原msc主机连接失败，当前词典域名TLS名称不匹配。未关闭TLS校验，未下载字典。即便取得当前版本，也需要明确其与原gold的版本关系，不能自动视为完全补齐。

这不是五个Partial不可研究或所有公开数据不存在的证明。当前仍缺可用于Strong升格的独立事实、规则/标签解释与匹配实验，不以重复检索或材料数量当作完成。
