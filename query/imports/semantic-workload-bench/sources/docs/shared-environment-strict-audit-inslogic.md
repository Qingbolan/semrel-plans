## 论文Table8真实存在的合成实例

位置：印刷页22613。条款2.3.1包括意外导致180天内死亡；2.4(5)排除酒驾、无有效驾驶证或无有效车辆证件等情况。叙述为避让行人撞护栏，治疗45天后死亡，车辆证件已过期一个月；参考拒赔。**这是真实出版样例，不是真实理赔案件。**

值得继续校验的细节：Table8真值第三项写的是无有效驾驶证，叙述及解释却说车辆证件过期。两者在同一OR免责分支下可能产生相同最终结论，但不是同一个事实命题；因此“裁决正确”并不证明中间解释/命题对齐正确。这里只记录原表局部差异，不裁定全数据错误率。
