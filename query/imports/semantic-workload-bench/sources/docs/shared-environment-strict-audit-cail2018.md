# CAIL2018：现成严格共享环境路线 Reject

[原论文](https://arxiv.org/abs/1807.02478)已下载并读取数据构造、任务及基线部分；[完整官方仓库](https://github.com/china-ai-law-challenge/CAIL2018)18个tracked文件已取得。来源哈希见[收据](../artifact/evidence/shared-environment-strict-cail2018/source.json)。官方全数据ZIP约984.6MB，下载及内容统计尚未完成，不计入已审候选。

论文报告从刑事裁判文书抽取fact，正则抽取法条、罪名、刑期，删除多被告及低频类别；预测标签不含前102条刑法总则。2,676,075案件、183法条、202罪名是论文统计，尚未本地复算。原始司法裁决标签与自动抽取误差需要区分。仓库baseline/law.txt只有183个法条编号，不是法条正文。

待核：全包真实划分/实体字段，20例fact与法条证据，冻结当时刑法及必要司法解释，排除fact内罪名/裁判内容泄漏。准确率高、macro指标低的旧分类结果不能证明现代完整E静态不足；183标签不是K。当前C0，未定Strong/Partial/Reject。未运行模型或作者脚本，未安装依赖。

## 交通肇事两例：法条预测与独立法律重判的区别

哈希样本valid第3152行：2014-03-23碰撞致一人死亡，原文载明全部责任、逃离现场、两日后投案并供述、44万元赔偿及谅解；gold第133条、36个月。valid第3240行：仅给违章驾车致一人死亡、遮蔽词及逃逸的指控，未给责任划分、自首、赔偿或量刑理由；gold也是第133条、36个月。

本地下载[最高法院2011年刑一庭负责人答记者问](https://www.court.gov.cn/zixun/xiangqing/2149.html)。该官方访谈解释第133条的量刑区间，并说明逃逸后投案、自首及从宽涉及刑法第67条等规则。它是历史官方解释性材料，**不是完整司法解释原件**。2000年交通司法解释公报页搜索命中，但直接下载HTTP502、web超时，未冒称取得原件。

从这些材料可以判断：只给183个预测法条编号无法覆盖完整量刑依据；第3240行输入也不足以复核全部具体量刑考量。不能据此宣称该gold错误，也不能声称所有法条推荐均不可回答。两个实例的同标签不证明相同执行家族；第3152行较详尽也不等于完整闭合。当前完整C仍0/20。

## 阶段判定：Reject 当前现成路线，不否认法条预测用途

完整源下载和规模已确认；尚无版本固定、足以支持当前事实与标签的完整共享法律环境。按任务本来的罪名/法条推荐可以开展文本分类研究，但不能直接将该发布包称作完整规则下的可回答决策集。要恢复此路线，需要独立法源、日期/地域、证据充分性和去重构造，而不是给模型堆入当前刑法全文。
