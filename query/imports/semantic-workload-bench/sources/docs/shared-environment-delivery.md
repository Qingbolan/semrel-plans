## 可以支持的研究结论

UDRP重复适用同一解释体系，因而为`E + fixed q + cases + decisions`提供现实依据。不能据此宣称现有公开事实材料已经无泄漏，也不能用正式结果的存在保证模型能依据这些材料逐案复作判断。

规则例外、构式、代谢关系等提供“重复但不完全相同”的处理动机。它们没有证明`1 << K << N`，没有证明K对应程序而非标签，也没有证明执行经验比直接读E产生的分支更好。当前支持的是**开展有失败出口的检验**，不是提前构建动态算子库或宣称新机制有优势。

第一组比较应包含完整必要输入上的直接语义调用、固定检索/规则流程、E-only Coding Agent、整批Data Agent。若没有质量差距，应保留阴性结果。只有观察到真实可重复动作及中间结果后，才比较单轨迹提取与同轨迹摘要、简单重放；完整计算构造、验证、逐条执行和fallback成本。

本次交付是调研与方法预期，不包含新LOTUS/Agent实验、已学习operator或新的确认集。用户要求的模型执行结果均以“目标gold/未实测”标注，不能以推演代替性能证据。
