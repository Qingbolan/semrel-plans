## 额外开发检查与本轮判断

取dev中按原标签顺序出现的前三个含“biops”且有诊断性7位码的病例，只用于有gold的开发审查，不作为随机质量估计。

- `S0004-06142006000500002-3`：同一左睾丸活检的较短提及标4位`0vbb`，较具体提及标`0vbb3zx`；后者目录为经皮入路，正文为腹股沟入路。不能仅从这几个词断定标错，但需专家核入路及同操作不同粒度规则。
- `S0211-69952011000400013-1`：正文有肾活检及颈部淋巴结活检，发布操作集合仅4项；不足以把P集合当完整实际操作清单。
- 上表第三例：内镜回肠/直肠活检规则可核，另有明确经皮肾活检未收录。记录原P/X与正文，不自行修gold、不据gold剔除整篇。
