- 原facts中不含`××`、所有紧接“年”的四位公历年份集合恰好为`{2014}`，选出1050行、1049个唯一精确facts。选择只看facts；其余年份批次统计保存在subset-private.json。**不等于已经验证犯罪日期/审判日期全部2014**，文本还可能有中文年份、历史事件和未记载的裁判时间。
- 检查包：`data/shared-environment-audit-20260908-v50/inspection-v1/`。public含1050条`record_id,fact`、完整两份候选规范、task；private含原meta及源行号。5个资产的大小/哈希写manifest，ID一对一及字段allowlist通过；不构成OS隔离或科学VALIDATED。
- task明确`inspection_only=true`且E不完整。不让读取工具见private，不将本次按gold检查过的三个例子称确认数据；本轮无模型执行。

## 可行性边界

本轮获得了长E实体资产、非gold筛选批次、明确的规则—例子对应和公开私有检查包，较单纯“有法条标签”更进一步。仍需：核日期语义及从旧兼从轻问题、补充不同罪名所需规范、病例证据充分性和原来源对齐、处理精确重复/实体重叠。不能把事实中只出现2014直接当已绑定历史裁判环境。

第87行已经写有“扒窃”这一法律化行为词，因此该例可验证规则与gold对应，不能证明必须反复阅读7万字全文，更不能证明从轨迹提取优于仅E编译。最终方法比较保留强固定基线。

合格仍1/10；本轮为检查包构造，不是新增通过项。模型/作者代码/新工程测试0；只执行下载、文本抽取、选择与资产核验脚本。全部下载正常结束，无后台等待。
