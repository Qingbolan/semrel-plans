# 第四十一增量：CGBench可否通过改变DAG范围转为可行湖

结论：固定DAG中的sem_map适合这一来源，但仅把任务换成证据集合抽取，仍未解决输入和gold对应问题。本轮不新增湖，累计1/10。复用已经下载的原论文、完整作者仓库和全部作者数据；未重复下载。完整来源版本、数据三表与方法三表沿用[第20轮](shared-environment-search-2026-09-08-round20.md)和[第29轮](shared-environment-search-2026-09-08-round29.md)，本轮补充原论文对任务含义的直接证据。

实际重读原论文第4–5页任务定义和第8页附近GCI结果讨论（本地paper.txt第275–335、520–542行）。GCI定义是给定gene/disease/MOI、全文和对应SOP，抽取类别、解释、分值和调整原因的集合。因此sem_map是原生任务，没必要强改成普通二分类。原论文也明确讨论：模型抽取的证据比curator保留的多，可能因为某些证据未被curator认为重要。故发布集合之外的证据不自动是假；我们此前“是否存在高分模型证据”的外层filter，不能未经审查就把未标注视为穷尽阴性。这个边界来自原论文，不是要求Agent先赢。

VCI两项也重新核对：E-Score原论文239样本/33VCEP，平均7.24样本每VCEP；E-Ver286样本/39VCEP。不能把所有不同VCEP拼成一个长共享环境大批次。这些是论文计数，本轮未重算VCI文件，不另计湖。
