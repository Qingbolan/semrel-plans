# 固定DAG语义瓶颈：三方对抗搜索与裁决

2026-09-05，Asia/Singapore。本轮执行用户授权的三智能体搜索：候选发现/辩护、输入真实性/构造攻击、研究严谨性/价值攻击；协调方独立复核关键源码与发布预测。范围是来源审计与候选筛选，没有调用被测模型、下载完整图像集或证明新方法优势。

## 冻结判据

研究单位必须能写成固定环境、共享任务、一次示范、后续关系和私有gold。优先完整输入上的直接语义调用确有质量缺口，而真实工具、文档或固定推理可改善关键步骤并改善下游的场景。固定程序有效是允许的结果；不强制每条记录在线动态规划。

区分三层证据：

1. **可构造**：真实来源、完整必要输入、同任务记录、独立gold、资源及合法获取路径。
2. **质量有改善空间**：同模型同资源的直接调用/固定推理/工具流程之间有可追溯实证；没有则仅作假设。
3. **单轨迹研究有增量**：业务执行轨迹提供的可迁移信息优于仅任务+环境的Coding Agent、既有流程优化、同轨迹摘要或简单重放。

不能通过不给默认路径必要规则、只给Agent人工感知答案、按测试标签选专家、忽略失败行或削弱模型制造差距。传统LOTUS版本与调用模式必须锁定；当前整个LOTUS不等于只会直接调用LLM。最终固定程序、DocETL等强对照必须保留。

## 攻击后裁决

没有候选在本轮直接通过“真实可构造＋无泄漏质量改善＋单轨迹研究增量”全部门槛。下一项优先的是输入审计，不是正式实验或已验证benchmark。

| 候选 | 决定效果的语义步骤 | 攻击后状态与原因 |
|---|---|---|
| LOCO 单产品 | 识别组件、数量、位置并应用完整装配规则 | 首选规则/视觉输入审计。LogicAD有固定分解线索；AnomalyClaw有发布差距，但原工具环境有测试条件提示且域表混合5产品。需要无泄漏重建和同资源强固定对照 |
| SDNET2018 | 区分裂纹与阴影/接缝/污渍 | 保留感知工具控制。固定专家在论文更强；母图代理跨split重叠，需恢复原图分组。没有复杂验收手册或结构安全gold，不以此冒充手册驱动判断 |
| TrialGPT | 患者事实与固定试验纳排条件匹配 | 条件保留。真实试验、合成患者；需核验固定试验下足够患者judgments，不能将未标pair作负例；已有固定分解很强 |
| DABstep | 交易费则适用性 | 暂缓。手册/关系文件存在，但规范疑点和逐交易独立gold待解决；业务任务来源不等于交易为真实日志，payments-readme声明synthetic |
| FinQA | 同指标的操作数、年份、范围、单位绑定 | 暂缓。真实报告与程序gold存在，但同业务指标family规模未核验；算术计算器收益需与语义收益分开 |
| GuideBench | 优惠规则组合及例外适用 | 降为规则诊断。实际文件含规则与参考解冲突；最多相同指南小组不等于真实业务批环境，先审gold |
| UNDERWRITE | 企业行业/规模与承保规则匹配 | 当前构造阻断。已核验公开资产为轨迹等，完整独立规则/数据库未确认；不从测试轨迹回填环境 |
| V*Bench | 高分辨率图像中的局部属性识别 | 感知工具诊断。异质QA没有自动形成共享谓词；目标bbox评价资料须与运行器隔离 |
| MedGUIDE | 临床指南分支选择 | 降为合成指南控制。发布path包含正确终点，不能当独立手册；完整树可获取性尚待核验 |

发现方接受了输入方对测试条件工具和源图隔离的攻击，将AnomalyClaw从优势证据降为重建线索；研究方明确固定检测器/规则程序胜出不淘汰环境，却会削弱“必须探索”或单轨迹新增价值的主张。协调方保留不同模型的调用差异，不以一个问题推翻所有模型/域的结果。

## 协调方独立复核：AnomalyClaw

来源：[官方仓库](https://github.com/jam-cc/AnomalyClaw)、[论文v1](https://arxiv.org/html/2605.10397v1)。源码/预测锁定commit `1a0c4b4e8e25d8a231f694b264a6669925b6d0b6`。

具体任务可写为：同类产品图像与批准的正常参考 → sem_map异常分数/判断 → 冻结阈值或Boolean筛选 → 输出实例清单和数量。这里的下游DAG是本研究拟构造，原论文主要评价图像排序；不能把其AUROC直接当筛选accuracy或count质量。

协调方从固定commit读取D3的三个发布JSON，用全部正负样本对的比较独立计算AUROC（同分计0.5）。每个模型120条、60正/60负，官方过滤后仍120条，error0：

| 发布模型 | Direct AUROC | Refutation AUROC | 0.5融合 AUROC |
|---|---:|---:|---:|
| GPT-5.5 | 0.666806 | 0.781528 | 0.770417 |
| Seed2.0-lite | 0.683056 | 0.824028 | 0.819444 |
| Qwen3.5-VL-27B | 0.607222 | 0.639722 | 0.673333 |

这是360条已有预测的算术复核，实际底层关系为同一120条；不是360独立图像或本次模型复跑。论文差距有发布数据支撑，但不能自动归因工具/Agent。

独立读到[工具源码](https://github.com/jam-cc/AnomalyClaw/blob/1a0c4b4e8e25d8a231f694b264a6669925b6d0b6/benchmark/scripts/agent_tools_v8.py)：85–87注释说明专家可靠性来自v2 manifest与test cache交集的AUROC；119–128将test cache百分位和正常/异常中位数写成range hints；132–140将这些提示格式化返回。输入攻击方进一步核验agent_v12→v8 dispatch调用链，并在D3发布日志中确认：Qwen有6次expert调用，其中3次obs_keys含range_hint/domain_auroc；Seed有2次，其中1次含这些字段；GPT-5.5 D3没有expert调用。日志未保留完整数值payload，因此不能逐值认证与当前源码相同，更不能将GPT D3提升归因这条路径。329–330还把1−AUROC解释为flagged项的误报比例，这一推导不成立。1069–1106的domain_knowledge实际是文本LLM调用，不是独立手册检索。

[aggregate_v12.py](https://github.com/jam-cc/AnomalyClaw/blob/1a0c4b4e8e25d8a231f694b264a6669925b6d0b6/benchmark/scripts/aggregate_v12.py)只计AD、两支分数齐全、无error且有label的行。因此其他域必须另核coverage，不能由D3无缺失推出全部域无缺失。

[源BENCHMARK_SPEC.json](https://github.com/jam-cc/AnomalyClaw/blob/1a0c4b4e8e25d8a231f694b264a6669925b6d0b6/benchmark/BENCHMARK_SPEC.json)仍为CrossDomainVAD-11和旧domain ID，而当前README为12域。论文Appendix M中旧11域/1298条及legacy预算对照不能与12域headline混用。Appendix R已给Seed的AUPRC/FPR，但未建立本研究所需的冻结阈值转移、清单质量及count证据。

以上问题不否定LOCO原始输入和异常标注的价值；它们阻止将该发布实验直接作为本研究已通过的无泄漏优势证据。

## 最小后续验证顺序（尚未执行）

1. 原始来源与任务审计：先选择LOCO一个产品类别，核验完整正常规则、原图、原始异常gold和训练参考；初轮明确保留原始“任意异常（结构或逻辑）”语义；若改为仅逻辑装配异常，必须作为独立版本核对结构异常处理与gold映射，不能沿用表中全异常效果。同类别共享谓词。按源实体划分开发/示范/确认，记录历史暴露；不把公开看过的AnomalyClaw结果再当新确认。
2. 公开环境重建：不带原测试集选择的expert policy、range hints、答案路径或按gold挑参考；专家从原图与批准训练参考真实计算，模型及训练来源记录在案。手册、规则和工具所有对照同样可用。
3. 冻结直接与固定对照：同一backbone、同图像分辨率/必要规则/参考，比较传统LOTUS语义调用、固定分解推理、固定工具组合、一次Coding生成批程序、Agent探索。额外模型调用与专家初始化/推理成本完整报告；若固定程序达到质量目标，它就是有效强对照。
4. 在任何确认运行之前冻结输出语义、失败处理、阈值/预算和实用改善界；记录逐记录改正与退步、coverage、macro-F1/recall、清单precision/recall、count error。AUROC作为辅助排序指标。gold替换关键语义输出检查下游敏感性；只看count可能被正负错误抵消。
5. 只有质量与环境证据成立才进入一次真实执行轨迹提取；与task+environment无轨迹生成、同轨迹摘要/重放及现有优化方法比较，在新关系上检验质量和包含构造/失败的完整摊销成本。
