# PCB environment resource card

Sources are fixed per URL, commit, size and SHA256 in sources.lock.json. Lock includes gold URLs and must remain outside model-visible assets. Builder transforms source IDs to opaque hash IDs, copies raw image bytes unchanged, maps class5 bbox presence to private Boolean labels, and seals exact public/private inventories. Construction receipt reports class balance and source-group count.

Source roles: tested image=input; paired clean template=reference; raw annotations=private scoring. tools.json documents a geometric baseline, not an oracle detector. Other unused categories, fabricated manuals or random noise have not been added.

License: source repository MIT file and README research-only data statement require separate treatment. Follow original data terms; do not assume unlimited commercial redistribution. Copied legacy detector code has no independently established release license; review before external release. No upstream license is replaced by this repository.

Gold annotation quality, source-level near-duplicate detection, validity of alternative task formulations and image polarity robustness require follow-up. Hash integrity confirms bytes, not scientific validity.
