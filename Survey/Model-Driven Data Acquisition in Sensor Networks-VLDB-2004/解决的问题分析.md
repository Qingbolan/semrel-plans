# 解决的问题分析

**输入与输出。** 输入为查询、误差/置信度要求、已知传感属性、历史模型及获取成本；输出近似答案和所选观测。

**困难。** 新观测价值取决于对其他属性不确定性的降低，选择集合还需计入通信路径成本。

**范围。** 主要实现采用 Gaussian/Kalman 模型，选择观测集合；不是后续 ICDE 工作的条件决策树。质量依赖模型与数据，不能直接转成 LLM 自报置信度保证。

依据：§2查询模型，§3统计模型，§4获取优化，§5实验；[原文](https://ai.stanford.edu/~guestrin/Publications/VLDB04/vldb04.pdf)。
