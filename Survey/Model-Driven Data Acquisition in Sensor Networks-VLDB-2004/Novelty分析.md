# 贡献与评价

**论文声称的贡献**（摘要、§1.1）：
1. 在交互式传感查询中引入统计模型，使答案更有意义，并通过带概率置信度的近似，大幅节省时间与能耗；
2. 定义“选择最佳读数”的优化问题，同时考虑统计收益的相关性与多跳无线网络中的代价依赖；
3. 给出指数时间的最优算法与多项式时间的启发式；
4. 在考虑真实测量数据与通信质量的真实传感轨迹上验证。

**机制要点**：

| 组件 | 细节 |
|---|---|
| 架构 | 用户的 SQL 查询带误差与置信度，被翻译为模型上的概率计算；模型不够确定时生成观测计划下发网络，收回读数后更新模型（§2，Figure 1） |
| 模型 | 时变多元高斯 + 每小时的 Kalman 转移模型；作者强调架构对模型通用（§2、§3） |
| 收益 | 范围查询：观测后判真或判假的较大概率；值查询：后验落在 ±ε 内的概率；多属性时取平均收益（§4.2） |
| 代价 | 采集能耗 + 单条巡回路径的期望通信代价（§4.1） |

**阅读者评价**：
- 优点：直接把用户可接受的误差与数据获取费用联系起来，目标明确；代价同时包含采集与通信，比只计计算更贴近应用。
- 优点：训练与测试数据时间上不重叠，并用未观测读数的真实值核验错误率（§5.1、§5.4）。
- 局限一：质量依赖模型与时间演化假设；Lab 数据中空调开关带来的随机性使温度比室外更难预测，作者只报告了一组实验（§5.8）。
- 局限二：贪心算法不保证最优；与最优算法、静态模型的对比实验因篇幅省略（§5.6）。
- 局限三：已提交的观测计划会执行到底，不能根据中途观测提前停止或分支；拓扑变化时重新评估计划，在高度动态网络中不适用；不适合离群点检测（§6）。
- 局限四：与基线的错误语义不同：TinyDB 与近似缓存在实验中“不犯错”，BBQ 允许按置信度犯错，比较时必须同时看质量与代价。

依据：§1–6，VLDB pp.588–599。
