# 解决的问题分析

**输入与输出。** 输入为已知查询及相关来源，输出完整查询结果；来源统计、顺序与适合预聚合的程度可事先未知。

**关键约束。** 不同分区分别执行后，简单合并输出会漏掉跨分区连接。系统通过状态共享、监测和 stitch-up 补齐结果。

**覆盖范围。** 支持运行时切计划、利用排序和预聚合，不是从任意环境中推断查询语义或发现全新任务。
