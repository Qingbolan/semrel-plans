# 具体用例

**原文示例**（Example 2.1，§2.2，PDF p.3）：模式含 F(fid, from, to, when) 航班、T(ssn, flight) 旅客、C(p, num) 每位旅客的子女数，三表随机存储。查询求“子女最多的旅客所乘航班、子女数及出发地”：

```
Group[fid, from] max(num) (F ⋈fid=flight T ⋈ssn=p C)
```

**执行过程**（Figure 1）：
1. 缺乏统计时，优化器先算 T ⋈ C，再连 F（阶段 0），处理的元组记为 F⁰、T⁰、C⁰；
2. 监控统计后发现先连 T 与 F 更好，系统暂停阶段 0（可能已返回部分答案），不重启，而让新计划 ((F ⋈ T) ⋈ C) 读取剩余数据（阶段 1）；
3. 两个阶段结果的并集只是部分答案；stitch-up 阶段还要计算 6 个跨阶段组合，如 F⁰⋈T⁰⋈C¹、F¹⋈T⁰⋈C⁰ 等，并复用两阶段已建的哈希表；
4. 分组算子在各阶段之间共享，最终给出完整答案。

**预聚合变体**（Example 2.3）：若旅客常多次乘机，在 T ⋈ C 后按 flight 预聚合 max(num) 的计划更优；若很少重复，原计划更好。ADP 可把数据分成每段 k 个元组，先在两种计划上各试几段，再把剩余数据交给表现好的计划。

**实测对应**（Table 1，§4.4）：无统计时 Q10A 分 3 个阶段执行，stitch-up 用时 36.2 秒（均匀）/ 33.5 秒（偏斜），复用约 79.4 万个中间元组，丢弃 0 个。
