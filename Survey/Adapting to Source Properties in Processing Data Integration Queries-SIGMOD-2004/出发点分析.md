# 出发点分析

异构自治来源往往缺少可靠统计，数据到达后才看出选择率、顺序或聚合特征。固定执行计划会因此产生大量中间结果；直接重启又浪费已经完成的工作。ADP 将数据分段送往不同计划，并处理分段之间遗漏的组合，使执行中发现的来源特性可以真正转成收益。

**支持哪一环。** 异构来源、运行时发现属性、多计划和中间结果共享都不是新现象；本项目需说明新增证据的语义有效性有何不同。
