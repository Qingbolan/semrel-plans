# 出发点

**任务难点**（§1，p.2）：TQA 除了要理解自然语言问题，还要面对三类表格特有的问题：
1. 数据语义复杂，信息常压缩在一个字符串里；
2. 数据有噪声或不一致，生成的代码容易执行出错；
3. 需要多步、较复杂的数据变换才能得到答案。

**例子**（Figure 1）：问“哪个国家的车手进入前十最多？”，表中没有国家列，国家缩写藏在 Cyclist 值的括号里（如 “Alejandro (ESP)”）。人工解法是：先意识到国家在哪里，写变换抽取它，再按名次过滤、按国家分组计数。

**研究空白**（§1）：CoT 和 ReAct 已证明“分步推理 + 外部工具”有效，但作者称尚无人把 ReAct 用于 TQA。已有 LLM 方法（Binder、Dater、Lever）多为一次生成程序，或需改造 SQL 执行器（Binder，§5.2）。

依据：[arXiv 2310.00815](https://arxiv.org/abs/2310.00815)，§1、§2.3、§5.2、Figure 1，PDF pp.1–2、11。
