# 解决的问题

**输入**：一张关系表 T0（模式与全部数据都可见）和一个关于它的自然语言问题 Q（§2.4）。

**输出**：答案；可以是元组列表（WikiTQ，如 `2001|2002|2003`）、是/否（TabFact）或自然语言句子（FeTaQA）。

**迭代流程**（§3.1–3.3，Algorithm 1）：
1. 提示包含表的表头与行、问题、分步指令和静态 few-shot 示例；
2. LLM 输出三选一：SQL、Python、或 `Answer:`；
3. SQL 在 SQLite 中执行，Python 在 Pandas DataFrame 上执行，结果成为新中间表并追加进提示；
4. 重复直到 LLM 直接作答。

**异常处理**（§3.3）：SQL 引用不存在的列时，按逆序在之前的中间表和原表上重试，并规范化列名；Python 缺模块时运行时安装后重跑；其他异常则在提示末尾加 `Answer:` 强制作答。

**投票**（§3.4，Algorithms 1–3）：s-vote 整链重复 n 次取多数；t-vote 每步采样 n 个并遍历整棵树取多数；e-vote 每步采样 n 个，执行后把产生相同表的候选合并 log-prob，取最高分作为下一步。

阅读者分析：问题限定为单表、表已给定，不涉及多表连接或在数据湖中找表；作者在 §5.4 将多表列为未来工作（阅读者分析）。

依据：[arXiv 2310.00815](https://arxiv.org/abs/2310.00815)，§2.4、§3.1–3.4、Algorithms 1–3、Figure 2，PDF pp.3–6、11。
