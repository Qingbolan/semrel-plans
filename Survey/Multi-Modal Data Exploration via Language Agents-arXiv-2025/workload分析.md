# Workload 分析

**要验证的问题。** 检验LLM能否规划、并行执行并按反馈修订多模态分析，比较正确性及运行成本，而非单独测视觉或SQL模型。

**数据、任务单位与gold。** ArtWork：100图及元数据，24原问题+6新增，共30题(18多模态/12关系)；RotoWire：100 NBA报告及关系数据，12题；EHRXQA：18表432图，随机抽100问题。底层为真实/已有基准数据，问题含作者构造；答案有值、表、JSON、图。测答案准确率、失败步骤、token、费用及时间，按原题gold核验。

**具体use case：输入目标 → 使用前 → 使用后。** 原文图2：病人18061894在指定时间前是否开过acetaminophen、胸片有无technical assessments？使用前单一表查询或单一视觉回答都不完整；使用后并行查药物与相关胸片，调用视觉专家并合成结果，不足时重规划。这里不是临床使用建议，也未虚构单例疗效。

**Baseline与比较条件。** CAESURA用于ArtWork/RotoWire，NeuralSQL用于EHRXQA。共同用GPT-4o规划，ArtWork保留BLIP-2，医疗保留M3AE；RotoWire的M2EX文本分析用GPT-4o而CAESURA原工具为BART，工具能力混杂需保留。小样本/缩小数据部分源于CAESURA内存与API预算限制。

**证据边界。** 动态replan已实现，不能归为纯静态DAG；但工具/数据域给定，未证明任意环境的新源发现。解释步骤可追溯不自动证明忠实。
