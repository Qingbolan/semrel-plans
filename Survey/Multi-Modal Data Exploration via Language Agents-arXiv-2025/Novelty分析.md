# 贡献与评价

**论文声称的贡献**（§1，p.2）：
1. DAG 优先的统一规划：自然语言直接编译为执行 DAG，独立子任务并行，无需第二阶段物理计划；
2. 自调试与选择性重规划：工具自检一次，失败时只重连受影响子图；作者称在 ArtWork 上端到端延迟最多降 51%、token 降 18%；
3. 零样本跨域泛化：同一套提示、无上下文示例，在三个数据集上准确率比 CAESURA、NeuralSQL 最多高 42%。

**机制要点**：

| 组件 | 实现 |
|---|---|
| 规划/重规划 | GPT-4o，planner / replanning prompt（附录 B） |
| text-to-SQL、文本分析、决策 | GPT-4o |
| 图像问答 | ArtWork 用 BLIP-2；EHRXQA 用 M3AE（作者提供的微调权重） |
| 数据准备、绘图 | GPT-4o 生成 Pandas / Matplotlib 代码 |

（Table 4，附录 C）

**阅读者评价**：
- 优点：给出明确的跨模态例子（Figure 2、附录 D 的三个例子），并做了按失败环节划分的错误分析，能区分“规划错”与“专家模型错”（§4.5、Table 3）。
- 优点：Algorithm 1 显示重规划确实已实现，因此不能把这类语义 DAG 系统都看成一次性静态计划。
- 贡献 2 的“token 降 18%”与 Table 1 合计不符：ArtWork 总 token 为 M2EX 485,612、CAESURA 482,932，M2EX 略多；总延迟降幅为 47.8%（3,040 s 对 5,821 s）。论文未说明 18%/51% 的计算口径（阅读者分析）。
- “最多高 42%”是百分点差（RotoWire 25.00%→66.67%），不是相对提升（阅读者分析）。
- RotoWire 上 M2EX 用 GPT-4o 做文本分析，CAESURA 用微调 BART，准确率收益不能全部归于执行架构（§4.2）。
- 题量小（30/12/100 题）、只用 GPT-4o 一个模型，结论的一般性有限（§4.1、Limitations）。

依据：[arXiv 2412.18428v2](https://arxiv.org/abs/2412.18428v2)，§1、§3、§4.2–4.5、Tables 1、3、4，附录 B–D，PDF pp.2–8、13–16。
