# 解决的问题

**场景**（§2，p.949）：在一组以流方式送入查询处理器（来自磁盘或网络）的有限关系上执行声明式的选择—投影—连接查询；讨论中忽略选择谓词，连接采用流水线式对称哈希连接。

**输入**：SPJ 查询块、各关系按未知速率和顺序到达的元组。

**输出**：完整的查询结果，在使用状态操作时也不重复、不遗漏。

**单位操作**（§3.1，pp.951–952）：
- `insert(R.a, t)` / `probe(R.a, val)`：STAIR 是建在某关系某连接属性上的哈希表，可存中间元组；一个连接对应一对互为 dual 的 STAIR；
- Dual Routing Property：元组被送去某个 STAIR 探查时，必须同时插入其 dual；
- `demotion(R.a, t, t')`：把存储的中间元组 t 降为它的子元组 t'（撤销部分已做的工作）；
- `promotion(R.a, t, S.b)`：把 t 替换为经另一个连接得到的超元组。

**状态迁移**（§3.2，Fig. 6，pp.952–953）：发现把 S_τ^R 送进 R ⋈ S 是错误时，先把 S.b 中的 R_τS_τ^R 降级为 S_τ^R，再把 S.a 中的 S_τ^R 提升为 S_τ^R ⋈ T_τ。结果状态等同于当初就把它们送入 S ⋈ T。

**正确性**（§3.4，附录 A）：Theorem 3.1/A.1 证明无环查询在任意提升、降级后仍产生所有结果；去重依赖一个局部不变式（Invariant B），对应的 Theorem A.2 因篇幅未给证明。

**范围**：关系、连接条件与算子都是已知的；本文不处理语义证据或开放来源。

依据：[VLDB 2004](https://www.vldb.org/conf/2004/RS24P2.PDF)，§2、§3.1–3.4、附录 A，pp.949–954、958–959。
