# 工作负载

**应用收集**（§5.1，p.10）：从 F-Droid 72 个官方类别中各取前三个展示的应用，按 URL 去重后得到 171 个应用，下载各自最新的源码发布版。作者没有用 TaintBench 等既有基准，理由是其目标 API 级别仅 7–22，不能代表当代应用。

**任务单位**：一个任务 = 一个保留下来的源点出现位置 + 六类共享目标 sink。源点由预定义规则发现（读数据的 API 调用、接收输入的回调参数），再按变量名与 manifest 声明过滤，排除测试和生成代码，覆盖五类来源。

**两个工作负载**（Table 3，p.11）：

| 负载 | 应用 | 任务 | 存储 | UI | ICC | 平台 API | 网络 |
|---|---|---|---|---|---|---|---|
| Main49 | 49 | 4,649 | 2,284（49.1%） | 1,074（23.1%） | 484（10.4%） | 342（7.4%） | 465（10.0%） |
| Sub15 | 15 | 1,284 | 592（46.1%） | 308（24.0%） | 119（9.3%） | 149（11.6%） | 116（9.0%） |

Main49 取源点最多的 50 个应用并去掉 1 个重复；Sub15 从 Main49 随机选 15 个，用于重复运行、基线对比、跨模型和消融。

**实验配置**（Table 4，p.11）：

| 负载 | 系统 | 模型 | 用途 |
|---|---|---|---|
| Main49 | Standard、FlowArk | GLM-4.7 | 总体与逐应用费用、复用统计 |
| Sub15 | Standard、FlowArk | GLM-4.7、GLM-5.3、DeepSeek-V4-Flash、MiniMax-M3 | 跨模型、重复运行稳定性、知识替换（314 个任务） |
| Sub15 | Standard、FlowArk、Mem0、RAG、w/o M1–M3 | GLM-4.7 | 基线与消融、人工审计（257 个任务） |

重复运行与知识替换实验改用 GLM-5.3，因为 GLM-4.7 已无法通过其 LLM 服务获取。

**执行条件**：所有系统对每个任务接收相同输入；每个任务一个独立 agent 实例，只读代码；同一应用内各系统按相同任务顺序执行，复用只能使用该应用中更早完成的任务（§5.1，p.11）。

依据：[arXiv 2607.11308v2](https://arxiv.org/abs/2607.11308)，§5.1、Tables 3–4、Figure 8，PDF pp.10–11。
