# 解决的问题分析

**输入与输出。** 输入为 Android 应用代码及一批 source-to-sink 分析任务，输出各任务的数据流分析结果。

**困难与解法。** 从已完成轨迹提炼可共享的中间代码知识，在工具输出暴露相关代码锚点后匹配并注入。共享分发逻辑不意味着不同输入具有相同泄漏结论；任务特定的下游检查仍需完成。

**覆盖范围。** 主要验证固定代码环境中连续任务的知识复用；代码修改后的失效处理、跨领域有效性和大规模并发调度尚未得到同等验证。

依据：§I–II 问题与例子，§III–IV 方法，§V 实验，§VI 局限；[论文](https://arxiv.org/abs/2607.11308)。
