# 工作负载

**数据集**（§4.0.1，p.7）：

| 数据集 | 模态 | 推理特点 |
|---|---|---|
| MMQA | 表、文本、图片 | 多跳；共 15 种问题类型 |
| ManyModalQA | 表、文本、图片 | 多为单跳 |
| HybridQA | Wikipedia 表 + 关联段落 | 每题都跨源 |
| HotpotQA | 纯文本 | 多跳（bridge / comparison） |
| TAT-QA | 财报表格 + 段落 | 跨源数值推理 |

**抽样**：每个数据集按问题类型分层抽 300 题，共 1,500 题，每题在三个后端（Palimpzest、LOTUS、Nirvana）上各跑一次。作者估计 5 种主要方法 × 3 后端 × 5 数据集已需 22,500 次编译 LLM 调用，若跑全量数据约需 104 天（§4.0.1）。Codex (agent) 只在 6 个（后端，数据集）组合上各抽 100 题（§4.0.2、Table 4）。

**模型**：NL2Pipe 与 Naive、Hardcoded、CodeTree 的编译用 gpt-5-mini；Codex 两个基线用 gpt-5.1-codex-mini；后端执行一律用 gpt-5-mini（§4.0.2，p.8）。

**单位**：一题 = 一个问题 + 其数据上下文；300 与 100 是评测题数，不是批大小。数据上下文是已给定的表/文本/图片、schema 与预览，以及后端 API 文档，不要求开放 Web 搜索。

阅读者分析：这些是带标准答案的 QA 基准，而不是数据分析工作负载；每题的数据上下文很小（一张表加若干段落），与需要扫描大集合的语义查询不同。论文未逐题发布输入字段清单。

依据：[arXiv 2606.04641v1](https://arxiv.org/abs/2606.04641v1)，§4.0.1–4.0.2，pp.7–8。
