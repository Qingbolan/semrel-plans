# Workload 分析

**要验证的问题。** 检验从旧轨迹抽取子过程能否改善后续网页任务，及这种收益能否跨任务模板、网站和领域保留。

**数据、任务单位与gold。** WebArena有812个人工任务、5个可交互网站，按环境最终状态验证功能成功；Mind2Web是带人工动作标注的真实网页任务集合，论文按cross-task/website/domain评估步骤成功、元素准确率、动作F1及任务成功。网页数据是真实/仿真网站环境，评测任务由人构建；在线实验按网站分组顺序处理。

**具体use case：输入目标 → 使用前 → 使用后。** 原文图6：先完成“按名称找地点”，再遇到“找该地点邮编”。使用前要重新摸索搜索框和地点页面；使用后复用查地点的方法，再读取当前地点邮编。共享的是行动方法，邮编不是从旧任务复制；这是案例解释，不是单例消融结果。

**Baseline与比较条件。** WebArena比较BrowserGym及仅accessibility tree的BrowserGym版本、AutoEval、SteP；同模型GPT-4。SteP带14个人写工作流，监督条件不同。Mind2Web比较MindAct、Synapse，需区分离线训练示例与在线自判成功的经验。WebArena AWM35.5%和BrowserGym23.5%是任务成功；Mind2Web相对24.6%改善指步骤指标，不能混用。

**证据边界。** 归纳、判断成功及携带记忆有额外成本；平均步骤减少不等于总费用减少。该评测不证明事实证据可以共享，也未独立验证记忆入库错误的长期影响。
