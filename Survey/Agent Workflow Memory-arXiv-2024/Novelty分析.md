# Novelty 分析

网页任务需要长链操作，但新目标往往包含过去已经完成过的子目标。独立执行会重复摸索；逐字复制旧轨迹则无法适应新的参数和页面。AWM 研究如何将已有执行变成后续可用的操作经验，让长任务更容易完成。

## 作者贡献：用自己的话概括

1. **「经验表示」抽取可带参数的子过程。** 把任务特有值与可重复的操作方法分开，让旧轨迹指导新目标而不要求整项任务相同（§2.2–2.3）。
2. **「在线学习」把已完成任务变成后续任务的工作流记忆。** 同时支持预先归纳与运行中积累，缓解只有固定示例、无法随经验适应的问题（§2.3）。
3. **「实证贡献」检验经验在新任务与新网站上的作用。** 以两个网页基准及表示消融，区分抽象子过程与具体示例的效果（§3–5）。

## Strong points（我们的判断）

1. 参数化子过程有清楚用例，说明复用什么及为什么比整条旧轨迹更可迁移（§2、图2）。
2. 同时报告执行任务与步骤指标，并检验跨任务、网站和领域，避免只证明同模板重放有效（§3）。
3. 不只报告最终分数，还分析工作流覆盖、重叠与利用率，使记忆作用更可诊断（附录A.3、表10）。

## Weak points（我们的判断）

1. 在线入库由模型判定成功；若误判失败轨迹，后续经验可能有误，缺少形式正确性保证（§2.3；这是我们对入库条件的判断）。
2. 记忆内容并非越多越好：加入网页HTML、合并离线在线记忆均出现退化，长期积累需要更强的选择机制（§4.3、附录C）。
3. 步骤减少不能代替净成本结论；主实验没有完整核算归纳、评价和逐轮携带记忆的费用及延迟（§3–5指标范围）。

对本项目：这是操作经验复用的基线，不是共享事实证据的正确性方案；路径可从经验学习，也不等于路径无法预先写成条件程序。
