# 解决的问题分析

输入是自然语言目标、网页观察及历史成功轨迹；输出为完成当前目标的动作序列。经验表示包含子目标、环境描述、推理与动作，将具体值替换为参数，作为后续决策的上下文（§2）。

离线模式从已有示例归纳；在线模式处理任务后由模型判断是否成功，再将经验加入后续任务。当前页面仍需观察和操作，记忆不是直接跳过执行的结果缓存。

评测区分 WebArena 的执行成功与 Mind2Web 的步骤/任务指标；不能把步骤成功率当作任务完成率。在线效果依赖历史顺序及成功判别，正文并未提供可安全省略哪些业务证据的保证（§3、附录C）。
