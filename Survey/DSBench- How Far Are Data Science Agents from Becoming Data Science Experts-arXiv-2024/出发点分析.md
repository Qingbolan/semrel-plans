# 出发点

**已有评测太简化**（§1，pp.1–2）：DS-1000 等是代码补全题，MATH 等是数学题，都不能反映真实数据科学任务。作者指出三点不足：
1. 指令短且单模态，而真实任务有长描述和多种模态；
2. 只评估简单的代码补全或填空，几行代码就能解决，缺少对整个系统的端到端评估；
3. 限定在特定环境（如特定 Python 包），而真实任务与工具无关、以数据为中心。

**难点**：任务要复杂到接近真实场景，同时答案又要容易验证（§1，p.2）。

**具体场景**：一份金融案例附带 Excel 工作簿和多道问题，需要读懂长背景、在多张表中找到相关数据再计算；或一项 Kaggle 竞赛附带训练集、测试集和提交格式，需要自己设计模型并生成提交文件（§2）。

**对比现有 benchmark**（Table 1，p.3）：作者按是否含数据文件、表格、图片，描述长度，是否有可执行评估，是否固定环境，是否只要求生成代码等维度与 MLAgentBench、SWE-Bench、WorkArena 等比较。

依据：[arXiv 2409.07703v2](https://arxiv.org/abs/2409.07703v2)，§1–2、Table 1，pp.1–4。
