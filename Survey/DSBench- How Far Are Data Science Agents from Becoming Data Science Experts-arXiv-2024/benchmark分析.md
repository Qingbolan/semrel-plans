# 评测与边界

**被测系统**（§3.1，p.7）：纯模型（Llama3-8b/70b、LLaVA、GPT-3.5、GPT-4、GPT-4o、GPT-4o mini、Gemini、Claude）；agent（AutoGen 搭配 Llama3 与 GPT 系列；OpenAI Code Interpreter 搭配 GPT 系列）。

**实验 1（数据分析，Table 4，p.7）**：

| 框架 | 模型 | 任务级准确率 % | 比赛级准确率 % | 成本 $ | 时间 s |
|---|---|---|---|---|---|
| 纯模型 | GPT-4o | 28.11 | 19.26 | 67.56 | 14.9 |
| 纯模型 | Gemini | 31.55 | 24.81 | 18.26 | 686.5 |
| 纯模型 | Claude | 6.01 | 3.83 | 64.98 | 668.1 |

| AutoGen | GPT-4o mini | 28.11 | 21.01 | 2.95 | 48.9 |
| Code Interpreter | GPT-4 | 26.39 | 21.82 | 128.85 | 43.1 |

（摘录；完整表含 19 行。）AutoGen 搭配 GPT 系列都优于对应纯模型，但 Code Interpreter + GPT-4o 低于纯 GPT-4o。人类平均每题约 18.5 分钟。在 10 个抽样 challenge 上，最好的 agent 为 33.65%，与人类差 30.41 个百分点（附录 B）。

**难度分析**：
- 分析任务准确率随输入长度下降：<500 token 时 0.74，500–5k 为 0.30，5k–20k 为 0.14，>20k 为 0.13（Figure 5，AutoGen + GPT-4o）；按年份，2012–2013 年题约 62–67%，2014 年后降到 13–18%（Table 5）。
- 建模任务成功率与输入长度没有明显趋势（Figure 6）；按年份为 50.00%、53.33%、25.00%、51.61%（Table 7），作者称“差别不大”，但 2021–2023 年明显偏低（阅读者分析）。

**边界（阅读者整理）**：
- 摘要的最佳 RPG（34.74）与 Table 6 的最高值（45.52）不一致；
- 人类结果只覆盖 10 个分析 challenge 和 22 个建模竞赛；
- 分析题由 LLM 判定语义是否一致；表中成本与时间的统计口径（总计还是每题）原文未写明，跨表比较需谨慎；
- 建模测试集是重新切分的，与 Kaggle 排行榜不可直接比较。
