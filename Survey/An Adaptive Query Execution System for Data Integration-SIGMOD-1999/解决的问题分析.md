# 解决的问题分析

**输入与输出。** 输入是 mediated relational schema 上的 select-project-join 查询、来源目录与 wrappers；输出来自已知来源的查询答案。目录包含来源语义描述、重叠关系及可能不可靠的统计。（§2）

**调整对象。** 缺少关键统计时只提交部分计划；片段结束物化并重新优化。事件规则还控制双流水连接、内存溢出，以及 dynamic collector 的来源启停。（§3–4）

**正确性与成本。** 换镜像不等于可以任意遗漏其他来源；collector 的策略依据来源重叠与应用要求。重规划需计入物化和优化器状态维护；保存状态若不配合依赖指针，实验中甚至比从头优化更慢。（§4.1、§6.4–6.5）

**未覆盖。** 给定目录外的来源语义发现不在本篇执行器范围；§2已将 query reformulation 单独处理。

依据：§1–4；§6.4–6.5；§8。 [原文](https://www.cis.upenn.edu/~zives/research/adaptive_exec.pdf)。
