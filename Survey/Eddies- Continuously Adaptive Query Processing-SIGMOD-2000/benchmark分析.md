# 评测与边界

**方法**：受控合成实验，没有采用具名公共 benchmark。核心指标是查询完成时间，以及记录先经过哪个算子的比例。固定顺序也通过限制 Eddy 的路由来实现，各方案共享实现基础（§4）。

| 实验 | 对照与变化 | 观察到的结果 |
| --- | --- | --- |
| 两个筛选代价不同 | 两种固定顺序、仅靠背压的 Naive Eddy、Lottery Eddy；两条件都保留 50%，改变其中一个的代价 | 背压已能让较快算子优先处理更多记录；两种 Eddy 都接近较好的固定顺序 |
| 两个筛选通过比例不同 | 两条件代价都为 5，一个通过比例固定 50%，另一个在轮次间变化 | Naive Eddy 对过滤效果不敏感；Lottery 更接近较好的顺序 |
| 三表连接 | 哈希连接与索引连接组合，以及两个哈希连接；比较两种固定顺序和 Eddy | Lottery 在这些设置下接近较好的固定顺序 |
| 运行中交换索引访问代价 | 两个远程索引先快后慢、先慢后快；Eddy 使用窗口票数 | Eddy 能在运行中换序，完成时间优于两种始终固定的顺序 |
| 一个连接输入延迟到达 | R 的输入延迟 10 秒，比较两种固定顺序与 Eddy | Eddy 起初偏向暂存记录而不产出的连接，未达到本可取得的适应效果 |

**边界（阅读者整理）**：
- 这些对照说明路由策略在指定条件下的作用，不是与独立商业优化器的端到端比较；
- 输入延迟实验说明“没有输出”不等于过滤有效，算子内部积累的状态会影响后续调整；结果不能概括为动态路由在任何情况下都更快；
- 单处理器原型、合成数据与合成代价，没有真实负载。

依据：[SIGMOD 2000 原文](https://dsf.berkeley.edu/cs286/papers/eddies-sigmod2000.pdf)，§4、Table 1、Figures 4–13；§5 为相关工作（本轮未重新对照）。
