# 贡献与评价

**论文声称的贡献**（§1，p.3）：
1. 提出 DATA AGENT 系统，探索能在最少人工干预下自主处理数据任务的新范式；
2. 设计语义数据组织、语义算子、智能体式编排、反馈闭环、短/长期记忆、主动适应等技术；
3. 设计数据分析智能体与数据科学智能体（§5）；
4. 在真实基准上显著优于现有方法（§6）；
5. 列出开放问题（§7）。

**组件要点**：

| 组件 | 关键做法 | 位置 |
|---|---|---|
| 语义数据组织 | 树形语义目录、嵌入链接、向量索引，存于共享记忆层 | §2，p.4 |
| 编排与优化 | 任务图 + 规划/验证智能体，A2A 协议传 JSON 消息；基于语义基数估计的 DP 选计划 | §2，pp.4–5 |
| 反馈 | 覆盖分数（多流水线结果频次之和）选优；注入带真值数据；LLM 生成样本作参考答案 | §2 p.5、§4 pp.8–9 |
| 记忆 | 版本图 + 三种冲突规则（最新优先、置信度、LLM 确认）；价值/时间/指令驱动的遗忘 | §3，pp.6–8 |
| 数据分析智能体执行 | 批处理 LLM 调用、嵌入预筛、小模型级联；向量化执行与按共享前缀分组以提高 KV cache 命中 | §5-A，p.10 |

**阅读者评价**：
- 贡献主要是把已有思路（语义算子、级联、语义基数估计、自一致性校验、记忆）整合到一个架构里；各组件多为描述性设计，很少给出算法细节或单独评测。
- 一致性检查能暴露偏差，但多个候选结果一致、或与 LLM 生成的“参考答案”一致，都不等于语义正确；作者在 §7 也承认“执行成功不等于分析正确”。
- 主动适应只通过“去掉记忆”的消融“部分验证”；作者明确说自主发现事件、无提示发起任务等更强的主动能力仍是开放问题（§6-B、§7）。
- 实验只评测了整体 DATA AGENT；§5 的数据科学智能体没有单独的实验。

依据：[arXiv 2609.24137v1](https://arxiv.org/html/2609.24137v1)，§1–7，pp.3–13。
