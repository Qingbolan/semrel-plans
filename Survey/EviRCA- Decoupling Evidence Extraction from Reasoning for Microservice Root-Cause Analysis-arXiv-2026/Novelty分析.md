# 贡献与评价

**论文声称的贡献**（§I，p.2）：

1. **找出瓶颈**：通过过程级失败分析和受控消融，说明主要难点是对已呈现证据的推理，而不是用 LLM 搜索原始遥测；
2. **两阶段框架**：确定性证据抽取与 LLM 语义推理分离，异构遥测表示为紧凑的多模态证据卡，系统特定知识隔离在声明式适配器中，同一引擎跨三个企业系统运行；
3. **实验**：三个系统、两个不同家族的 LLM 上，Correct 率 40.6–43.9%（同模型基线最高 15.2%），token 减少 15–26 倍，并能解出要求完整三元组的 hard 档案例。

**阅读者评价——优点**：

- 确定性抽取方案构成必须比较的强基线，避免把全部遥测计算都交给智能体（§III）（阅读者分析）。
- 基线用相同两种模型重跑，而非只引用旧模型的数字；消融检验了各模块的增量（§IV-A、§IV-D）。
- 区分"证据未呈现"与"判断错误"两类失败，便于定位真正瓶颈（§IV-E、§V）。
- 去掉人工写的每系统指导段落后，只有 Telecom 下降 11.8 个点，Market 不变、Bank 反升 0.7 个点，说明收益主要不是靠 prompt 调优（Table V）。

**阅读者评价——不足**：

- 证据卡构成召回上限，模态缺失或检测未覆盖时模型无法补救；Market 的网络故障尤其明显（§IV-E、§V-B）（阅读者分析）。
- 已知故障数与封闭候选空间降低了不确定性，不能与没有这些提示的设置直接比较（§II-A、§V-B）（阅读者分析）。
- Telecom 与 Market 的每分钟调用摘要预先算一次、供所有案例复用，其构建与摊销成本需另计，Table IV 的时间不能直接等同端到端冷启动成本（§IV-C）（阅读者分析）。

依据：[arXiv 2609.19825v1](https://arxiv.org/abs/2609.19825v1)，§I、§III–V、Tables IV–V，pp.2–10。
