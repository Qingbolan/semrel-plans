# 贡献与评价

**论文声称的贡献**（§1–2，pp.1–3）：
1. 首个对相关过滤器与连接给出多项式时间、可证明质量保证的排序算法：把问题映射到 pipelined set cover，静态贪心是 4-近似（Theorem 4.1）。
2. A-Greedy：在线维持贪心不变式，能检测并立即修正违反。
3. 识别“收敛性—运行开销—适应速度”三方权衡，给出位于不同权衡点的变体。
4. 说明星型 MJoin 的 drop-probing 阶段就是流水线过滤器，Theorem 4.1 直接适用；无环与有环连接可推广（§8）。
5. 在 STREAM 中实现全部算法并评测（§9）。

**机制要点**：

| 组件 / 变体 | 做法 | 代价与性质 |
|---|---|---|
| Profiler | 被丢弃元组以概率 p 抽样，继续执行剩余过滤器，记录 n 个布尔位与处理时间，存入滑动画像窗口（§4.1） | 对位置 i 丢弃的元组需多执行 n−i 个过滤器 |
| Reoptimizer | 在画像上增量维护 n×n 上三角矩阵视图 V，V[i,j] ∝ d(j\|i−1)；检测违反后按列选最大比值交换（§4.2，Figs.3–5） | 更新访问至多 n²/4 项；修正需 1 到 n−i 次全窗口扫描 |
| 防抖参数 α | 只有 V[i,i]/a < α·V[i,j]/a 才视为违反（Eq.4） | 界变为 4/α |
| Sweep | 每阶段只画像一个位置 j 的过滤器（§5） | 稳定时仍收敛到 GI 顺序；开销 O(n)，但违反可能 n−2 个阶段后才被发现 |
| Independent | 假设独立，只维护 V 的第一行（§6） | 与原始 Eddies 类似；相关时可比 GI 顺序差 O(n) 倍（Example 6） |
| LocalSwaps | 只检查相邻过滤器（§7） | 开销最低；可能卡在局部最优，差 O(n) 倍（Example 7） |

**阅读者评价**：
- 把“获取条件选择率的观察代价”显式算入，实验也没有把统计视为免费（§4.4、§9.3）。
- 理论条件写得清楚，便于判断哪些结论不能搬到语义算子（§4.3）。
- 论文报告了对自身不利的结果：n 增大或过滤器变贵时 A-Greedy 的开销拖累吞吐，Sweep 在变化稀少时反超（§9.3–9.4）。
- 不足：理论界只覆盖稳定状态；继续执行已丢弃元组的剩余过滤器，对 LLM 调用这类昂贵或有副作用的算子代价很高（阅读者分析）。
- 不足：要求过滤器可交换、语义固定；所有实验都是合成过滤器，没有真实网络流量（§9）。

依据：§1–9、Theorem 4.1、Examples 6–7、Figures 3–7，PDF pp.1–11。
