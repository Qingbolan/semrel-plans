# 评测与边界

**比较方法**（§9）：A-Greedy、Sweep、Independent、LocalSwaps；小 n 时加入 Optimal——用输入统计离线穷举得到的最优顺序，作为可达上限，不是同等信息下的在线方法。

**指标**：收敛后的平均处理速率（tuples/sec）；运行时间分解百分比；适应实验中每 2000 个输入元组被执行的过滤器数；周期性变化负载的总运行时间（秒）。

**实验 1（收敛，§9.2，Figs.9–11）**：A-Greedy 始终优于 Independent，差距随 n 扩大；小 n 时接近 Optimal，n 增大时因开销而下降。选择率居中时 A-Greedy 相对优势最大；相关因子 Γ 增大时优势先增，Γ 接近 n 时缩小。

**实验 2（A-Greedy 开销，§9.3，Table 2，%）**：

| 组成 | n=3, p=0.01 | n=3, p=0.05 | n=8, p=0.01 | n=8, p=0.05 |
|---|---|---|---|---|
| 元组处理 | 98.77 | 94.17 | 96.62 | 84.77 |
| 画像元组生成 | 0.88 | 4.17 | 2.92 | 13.34 |
| 画像窗口维护 | 0.20 | 0.93 | 0.20 | 0.91 |
| 视图更新 | 0.15 | 0.73 | 0.22 | 0.98 |
| 违反检测/修正 | 0 | 0 | 0.04 | 0 |

**实验 3（全部算法与过滤器代价，Figs.12–15）**：p=0.05 时，A-Greedy 与 Sweep、LocalSwaps 的差距随 n 增大，完全来自运行开销。n=8、四个过滤器代价为 1、另四个为 c 时，c=100 时 A-Greedy 开销约 25%；Sweep 优于 LocalSwaps，因为后者在 c=50、100 时找不到最优顺序。

**实验 4（适应性，§9.4，Figs.16–21）**：A-Greedy 比 Sweep、LocalSwaps 更快收敛到新顺序；Independent 同样快，但变化前后的顺序都更差。变化周期短时 A-Greedy 与 Independent 显著优于 Sweep；周期为 10^5 元组时，即使过滤器很贵 A-Greedy 仍领先；周期为 10^6 元组时，Sweep 随 A-Greedy 开销增加而反超。

**边界**：
- 理论界（Theorem 4.1）只在稳定状态成立，证明在技术报告中；
- 全部实验是合成过滤器和人工置换的选择率，相关性模型很简单（同组 80% 一致）；
- 作者自己指出，A-Greedy 无论变化快慢都付同样的画像开销，如何在执行与画像之间平衡留作未来工作（§10）；
- MJoin 的完全流水线执行会重复计算中间结果，作者在后续 A-Caching 工作中处理（§10）。
