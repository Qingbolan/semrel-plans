# 工作负载

**系统与环境**（§9，p.9）：四个算法都实现在 STREAM 原型 DSMS 中；实验机为 700 MHz Linux，1024 KB 处理器缓存，2 GB 内存。

**合成过滤器**：n 个过滤器作用在流 S0 上，每个过滤器探测另一条流 Si 上 10,000 元组滑动窗口的内存哈希索引，再按设定的条件选择率随机决定是否通过；相当于 MJoin 的一条流水线。

**相关性模型**（§9.2，p.9）：n 个过滤器分成 ⌈n/Γ⌉ 组，每组 Γ 个；同组过滤器在 80% 的输入上结果相同，不同组相互独立。Γ=1 完全独立，Γ=n 最相关。

**默认参数**（Table 1）：

| 参数 | 默认值 |
|---|---|
| 丢弃画像概率 p | 0.01（A-Greedy）、0.005（Independent） |
| 画像窗口 | 500 个画像元组（Sweep）、1000（其他） |
| 防抖参数 α | 0.9 |
| 相关因子 Γ | 2 |
| 无条件选择率 | 50% |
| 过滤器代价 | 在 10,000 项索引上 1 次哈希探测；变代价实验中代价 c 表示 c 次随机探测 |

**变化模式**（§9.4）：n=8，过滤器选择率各不相同，周期性地随机置换各过滤器的选择率来模拟特性变化。

**任务单位**：一条连续查询的过滤流水线；正确输出由过滤器定义，无人工标注。

阅读者分析：所有数据都是受控合成流；Example 1 的网络监测只用于动机说明，没有真实流量实验。（阅读者分析）
