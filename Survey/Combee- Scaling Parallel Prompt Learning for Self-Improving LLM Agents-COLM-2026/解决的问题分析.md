# 解决的问题分析

输入为已有 Agent 轨迹、反思及 ACE/GEPA 等提示学习过程；输出为改进的提示或 playbook，并衡量学习完成时间与后续任务质量。

将更新分成较小的并行聚合，复制并打乱反思以减少分组造成的信息丢失，再根据收益调整 batch 大小。它优化经验更新，不改变当前业务查询的证据依赖定义（§3、§5）。

实验包含 AppWorld、Terminal-Bench 2.0、FiNER、Formula。Terminal-Bench 设置为60条训练轨迹、29个留出任务，最高17倍是学习耗时改善，不能改写为业务任务执行加速17倍（§4.1–4.2）。
