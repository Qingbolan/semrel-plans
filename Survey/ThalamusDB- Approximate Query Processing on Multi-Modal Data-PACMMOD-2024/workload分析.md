# workload分析

**验证什么。** 在已指定自然语言谓词的SQL中，少量模型处理和标签能否足够收紧最终结果界，节省完整扫描费用。

**数据、单位与gold。** 表4：AudioCaps/YouTube46,774视频行，Craigslist3,000广告与14,674图片，Netflix17,770电影（附IMDb评论）及100M评分。原始数据真实，关联与查询由作者构建。§7.1列24/25/6查询（合计55），§7.2却用49作比较分母，原文口径不一致，保留而不自行修正。单位是SQL聚合或LIMIT查询；人工确定分数阈值模拟用户标签，参照完整模型评估结果。指标计算时间、标注数、加权成本和确定性结果界，gold不等于独立人类语义真值。

**最有说服力用例（按§1/§4家具例重述）。** 找木制家具最低价格：输入广告价格与图片。使用前给所有图片做昂贵判断；使用后优先检查可能改变最小值的候选并更新上下界，满足误差要求后停止。省掉的是对当前聚合答案无必要的处理。

**baseline及公平性。** MindsDB仅支持其中12/49文本查询，免费给gold阈值；BART在二者一致，ThalamusDB允许10%误差而MindsDB精确。ABAE仅支持8/49，免费给标签及oracle代理分数，分别最少/最大标注配置，误差5/10/50%。另有Exact、+Ordered、+Approx消融。

**效果范围。** §7图7：对MindsDB支持子集平均35×，不是同误差、全模态的普适加速；图8展示ABAE比较。确定性界只保证相对于正确模型/阈值的未处理误差，不消除模型分类错误。
