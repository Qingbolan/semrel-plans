# Computing Complete Answers to Queries in the Presence of Limited Access Patterns

Web 表单等来源只允许“给定某些属性值才能查”（binding pattern），系统无法取回整张关系，因而不知道自己算出的答案是否完整。Chen Li 研究“完整答案”（假如能取回全部元组时的答案）何时可算：若一个查询对任意数据库都能用合法访问算出完整答案，则称其稳定（stable）。

论文证明合取查询稳定当且仅当其最小等价查询存在可行的子目标顺序，并证明判定 CQ 稳定性是 NP 完全的；给出并集查询、带算术比较的合取查询的判定算法；证明 datalog 程序的稳定性不可判定。对不稳定查询，完整答案是否可算取决于数据，论文用一棵决策树指导执行，并在无法确定时给出答案的上下界。这是纯理论论文，没有实验。
