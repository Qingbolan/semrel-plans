# 具体用例

**例 1（稳定查询，Example 1.1，p.2）**：r(Star, Movie) 每次访问必须给演员名，s(Movie, Award) 每次访问必须给电影名。查询“Fonda 出演电影获得的奖项”：

```
Q1: ans(A) :- r(fonda, M), s(M, A)
```

先用 fonda 查 r 得到电影，再逐部电影查 s 得到奖项。虽然没有取回两张表的全部元组，但满足第一个子目标的 r 元组已全部取回，能与之连接的 s 元组也都取回，所以答案完整。若 r 改为必须给电影名才能查，就无法得到完整答案。

**例 2（无可行顺序但稳定，Example 1.2，pp.2–3）**：加入一个冗余子目标：

```
Q2: ans(A) :- r(fonda, M), s(M, A), r(S, M)
```

变量 S 无法被绑定，Q2 没有可行顺序；但 r(S, M) 是冗余的，Q2 等价于 Q1，所以 Q2 稳定。

**例 3（完整性依赖数据，Example 7.1，pp.24–25）**：r(A, B, C) 模式 bff，s(C, D) 模式 fb，p(D, E) 模式 ff。两个查询 Q1: ans(B) :- r(a, B, C), s(C, D) 与 Q2: ans(D) :- 同样的子目标，都不稳定。
1. 用 a 查 r，假设得到 (a, b1, c1)、(a, b2, c2)、(a, b2, c3)；
2. 无法直接用 C 值查 s，但可以借查询之外的 p 取得 D 值，用穷举计划访问 s；
3. 若取回 (c1, d1) 与 (c2, d2)，则 Q1 的完整答案就是 {b1, b2}，因为两个 B 值都已被证实；
4. 若只取回 (c2, d2)，就无法确定 b1 是否属于答案；
5. Q2 则永远无法确定，因为 s 中总可能有未取回的 (c1, d)，而 D 是输出变量。

依据：§1 Examples 1.1–1.2、§7.1 Example 7.1，修订稿 PDF pp.2–3、24–25。
