## 为什么不计长E合格项

输入真实、batch与gold存在，这两项已核实。缺的是目标所要求的复杂/长共享环境：每类规则160–719词，理由被作者设计为自包含文本。把更长EU法规或判例集额外挂入，不自动证明当前任务需要它们；把合同自身当E还需证明逐句判断依赖其余条款，不能仅按合同ID分组就成立。

原行49的4个理由链接也有值得核对的细节：理由0是非法/有害行为，正文没有直写illegal，而是违反政策/法律风险等表述。保留原gold，不自行删理由0，不声称用一次词面匹配就能精确复现。

这是一条理由映射开发候选，不能挤入严格通过列表。新工程测试0、模型/作者代码执行0；无性能/成本结果、无确认划分/自动提取。下载86056正常结束，无活动进程。合格仍1/10，goal继续。
