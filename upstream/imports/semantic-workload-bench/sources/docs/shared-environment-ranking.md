## 评分规则

`Score=.15*C+.10*B+.15*G+.25*D+.10*S+.15*R+.10*A`，七项0—4分，总范围0—4。

- C环境复杂度：1短规则字段；2多节中等规范；3长且含多类条件的相关规范；4大型关联词典/本体或长规则体系。不用无关页面凑长度。
- B原生batch量：1少于10；2为10—99；3为100—999；4为至少1000。给定target任务按target计，但独立统计仍按文档聚类；不得将B解释为独立样本量。
- G gold：1弱代理；2人工来源但映射/输入契约有未闭合项；3可追溯人工gold与明确输出契约；4再有独立完整复核。本表无人获4。
- D完整环境必要性：0有证据说明无关；1已见局部短标准作用；2复杂规则依赖的部分证据；3任务定义及实际适用支持；4有受控消融。未知用“?”，绝不等于0。
- S语义算子潜力：1简单输出；2单一语义节点；3有明确中间结构和下游；4中间步骤的下游因果效应已验证。本表无人获4。
- R中间复用证据：0本任务结构未建立；1来源提供分支假设；2实际轨迹显示跨记录族；3独立复用质量保持；4完整成本收益优于强对照。本表最多1。
- A现实性：1合成病例；2混合来源；3真实材料的人工语料整理；4真实业务决定。现实性不代替输入充分性。

未知维度只给数学上下界，不报告点估计，不以区间上界排名。区间下界中的0只是可能范围端点，不是把未知评分成0。D未知不能进入最高入场等级。相同分数不意味着相同科学风险。

## 五个优先验证对象：不是五个合格推荐

UDRP是结构证据第一顺位。其余四项为Partial内部的诊断优先顺序，只值得先检验环境价值；没有依据排成四个最高优先级正式workload。选择以可验证的语义输出和不同失败机制为依据，不用重叠区间制造精确排序。SENTiVENT、CASIE也有可行开发构造，但当前没有证据说明其完整规范比短schema更必要。

## 判定下一步的最小证据

先比较同模型、相同原始事实上的短schema与完整E；若完整E未改善，应将该来源作为阴性结果保留，而不是靠人为扩大上下文制造成本。再比较同资源固定检索、E-only Coding Agent生成程序和整批Agent。只有观察到可解释的质量/成本差别，才分析可观察轨迹中哪些查询、证据检查和中间结构跨记录重复。

分析执行族时，应按公开的动作和依赖结构定义族，再报告K、各族覆盖、未归类比例与跨批稳定性；不能按gold类别切好组后声称发现K。单轨迹提取与环境编译必须使用同E、相同历史监督，计入构造、失败、验证和fallback成本。

目前只能回答：**共享长规则的真实批量适用存在；本次证据尚未证明中间执行复用比环境预处理和固定逐项程序更有价值。** 即使这五项都可完成工程构造，也不能据此断言有五项支持该研究机制。
