## 实例与20条映射核验

query_id=0问题“谁可以成为个体工商户？”；gold为705（民法典第五十四条）和49282（个体工商户条例第二条）。实际库文本分别讨论自然人工商业经营登记及有经营能力公民登记、个人/家庭经营。这是一般法律咨询，不是真实申请人的批准/驳回裁定。

query_id=437询问劳动者严重违纪的认定；gold三条是劳动合同法第四条、第三十九条、劳动争议解释（一）第五十条。它体现规章制度成立程序、解除条件与司法适用可能需联读，但不能据三条推断三个执行家族。

query_id=903问在校未成年人伤人致死时学校是否承担责任，gold为刑法第十七条与第二百三十四条（未成年人刑责和故意伤害）。引用可定位，但没有直接解决题目所问学校责任；本轮只登记充分性疑点，没有重标gold或推断标注者意图。

[20条收据](../artifact/evidence/shared-environment-strict-stard/sample20.json)：对query_id按SHA256("stard-strict-v1"+NUL+ID)取前20。初次将match_id与match_name按位置zip得到6处差异，检查发现两列表顺序不同；改按corpus ID解析名称并在gold字典中连接，42/42匹配。40正文采用字面反斜线n，换行规范化后42/42一致；原始字节精确2/42。没有修改源文件。映射正确不代表法律必要性/充分性通过。

## 固定任务口径纠正

此前将“没有统一实体裁定gold”列为A失败，收紧了用户的输出要求，现撤回。这里q是统一的相关法条选择，咨询内容是x，输出是ID集合；这与任意QA直接答题有区别。缺少批准/驳回标签不构成淘汰依据。基于已取得的真实批、大共享E和人工标注，修订为Partial，与AnnoCTR/CodiEsp采用相同证据门槛；D/E未知不被升级为通过。20引用映射和query903疑点保持原状。

## query903：责任主体与评分边界补证

本轮实际读取同一冻结库的1149/1150/1151（民法典1199/1200/1201），均讨论教育机构义务与受教育者损害；903两个gold规范行为人刑责。queries.json与dev qrels对903一致，排除展示层字段错配。邻近咨询900/901/902/904已有学校责任法条gold；相关规则并未完全缺失于E。

903没有受害人身份/年龄和学校管理行为等事实，不能自行重标为1149、1150或1151，也不能给出学校应否担责的结论。较窄发现是：问题所问责任主体与已标条款直接规范主体不同，现有gold不能证明已覆盖咨询问题。刑责条款仍可能是背景相关项，不能认定原gold全部错误。

已读BM25/test.py和QLD/test_qld.py：两者含命中、召回和MRR计算。追加非gold项不直接降低Recall，只有占用固定top-k位置并挤掉gold时才可能降低；不能声称补学校条款必然受到召回惩罚。反过来，仅返回两个刑责gold可获得完美gold召回，却不能证明回答了学校责任问题。这是检索评分与下游咨询充分性之间的具体缺口。未执行作者脚本或模型。
