# Heterogeneous workload pilot — 2026-09-05

结论：两条各8文档的开发pilot均未通过预先定义的Agent优势筛选。CUAD主F1未超过固定复核；BioDEX主RP@10未提高，且出现任务提示口径与gold范围对齐风险。不能据此宣称一般静态能力上限或异构资源因果增益。

### 任务有效性风险

本轮提示词要求“患者不良药物反应”，并排除只在背景讨论的条件；但BioDEX的关联报告标签还包括耐药、治疗失败、暴露等更广编码事件。例：一篇讨论创伤患者克雷伯菌耐药模式的文章，三臂都输出空列表，而gold为Drug resistance。这不能直接算作静态方法内在能力不足。需要先依据原始任务和公开编码定义重新对齐完整事件范围，形成显式新开发版本；本轮输出和评分不改写，也不复用这些样本作为确认集。

另一个病例中，gold为Pathogen resistance，Agent为Drug resistance；gold术语既在完整目录，也在初始候选中。因此“目录检索不到”不是这个错误的解释。术语粒度/编码选择和报告标注范围需要独立审查，本文不判断两者临床等价。

与初始相比，Agent新增2个gold标签、删除1个gold标签；并不能从净增加1个匹配推断总体优越。具体工具查询、gold对照变化和范围审计见runs/biodex-gap-pilot-v1/scope-and-tool-audit.json。

## 本轮决策

暂不进入单轨迹提取。CUAD保留为“静态仍有质量缺口，但固定复核已解释大部分收益”的阴性开发结果；BioDEX先解决任务—gold对齐与编码资源定义，不能用范围问题制造静态失败。只有新版本在完整必要输入、强静态对照和同资源Agent之间形成稳定差距，才值得扩展独立确认、资源消融与提取实验。

本轮没有使用独立历史纠错案例、原生DocETL优化器、Coding Agent或多模型确认；没有评价病理/PCB并行任务的新结果。这里只报告本任务的CUAD/BioDEX运行。
